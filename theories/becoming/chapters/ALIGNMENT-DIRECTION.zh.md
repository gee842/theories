# 我们主张怎样的 AI 对齐方向

> **中文版（2026-10-17）。** 正典文本是[英文版](ALIGNMENT-DIRECTION.md)；本版由重构时从双语原文拆出，不与英文同步维护，两者有出入时以英文为准。

2026-10-08，Asia/Bangkok。AI 撰写的当前综合论证，完成 Ren 要求的“能够清楚论证我们主张怎样的对齐方向”。[本次原话与范围](../../../sources/15-codex-theory-conversations/2026-10-08-alignment-direction-completion.md)、[公理路线纠正](../../../sources/15-codex-theory-conversations/2026-10-08-alignment-grounding-axiom-correction.md)、[一般实践判断](PRACTICAL-JUDGMENT.md)及[整合与独立审查入口](../../../_process/research/2026-10-05-generative-foundation-review/history/root-foundation/ALIGNMENT-DIRECTION-INTEGRATION.md)分别记录来源、前提与完成范围。本文不替代其他会话的无公理研究，也不宣布[完整对齐实施目标](ALIGNMENT-COMPLETION.md)已经完成。

<a id="1-核心主张--central-claim"></a>
## 1. 核心主张

**我们主张：使 AI 的形成、学习、行动和更新，支持整体中实际的生及其继续生成，使生命、心智、关系、生活方式与组织能够丰富地共同发展；以真实损失、基本生活条件、有界责任和正当参与约束取舍，使这种发展能够被认识、质疑和修订。**

这里的正面方向包括创造、探索、学习、帮助、照料与新的共同实现，也包括当下生活、休息、自护和有限完成。方向能够支持主动形成新可能；它不要求每段生活继续生产、不要求所有旧组织存续，也不把每一步的数量增长当作善的定义。

<a id="2-从同一形成过程说明评价范围--locating-appraisal-within-one-process"></a>
## 2. 从同一形成过程说明评价范围

AI 的能力经由计算设施、能源、劳动、知识、训练、使用与制度安排形成；人们的依赖、决定的权限、被影响的位置和反馈渠道也在这些关系中分化。一次升级会共同改变能力、支持负担、实际可行的生活方式和之后修订的条件。评价须沿这些真实关系追踪后果，包括已不再参与或不能发声的位置；不以是否回报开发者或当前使用者作为纳入条件。

“整体”在此要求后果与关系不被任意截断。它不产生一个替所有生命作主的超级主体，也不要求每次决定先知道整个宇宙。实践采用有说明的影响范围、时间和认识限度；新的相关证据可以扩大范围。局部模型保留所论证的关系，遗漏及不确定性须公开，不能把未测到的损害记作不存在。

<a id="3-根据比较与行动之间的公开桥梁--the-disclosed-inferential-chain"></a>
## 3. 根据、比较与行动之间的公开桥梁

以下是本候选采取的伦理立场。G0 是 Ren 授权采用的基础公理措辞；J1–J4 沿用已完成实践候选，是 AI 提出的附加承诺，不能全部归为 Ren 原话，也不声称由 G0 单独逻辑推出。

| 层次 | 内容与根据 | 能支持的结论 |
|---|---|---|
| G0 基础公理 | 整体中的生及其继续生成具有基本正面规范意义。 | 实际实现提供支持理由；每一项正面方面不自动决定总体选择。 |
| J1 完整比较 | 保留相关生活与损失，在没有反向减损时，真实改善具有优先理由；恢复不删除经历过的损失。 | 支持无减损改善，拒绝通过删记录制造改善。 |
| J2 基本条件优先 | 保住其他基本要求时，恢复额外基本生活条件，优先于可放弃的丰富性。基本参与不作为购买增益的可替代材料。 | 一类有真实损失的充分比较，以及可放弃扩张不得强加基本剥夺的界限。 |
| J3 有界责任 | 正当承担及可归责的依存改变要求履行、修复或交接；承担者自身的生活也属于整体。 | 对具体位置分配有界回应；能力和因果联系不单独产生无限义务。 |
| J4 正当选择 | 有权限、共同可行且未被充分击败的方案进入选择；未决冲突经有参与、时限和复核的正当程序处理。 | 从比较到许可、约束与共同分工；未被击败本身不足以授权。 |
| E 对应条件 | 生、基本条件、损失、可能性、承担、权限及实际履行的描述可信且有根据。 | 使原则适用于这一处境；需要事实证据及分类、权限的规范论证。 |

推理顺序是：先说明一种发展实际形成、保住、损失什么；G0 给其中的生及进一步生成以正面理由；J1/J2 在其适用范围内给出比较；J3 说明谁有何种回应根据；J4 与实际可行性、权限一起形成行动要求。**“有正面方面”“总体更好”“获准实施”“由某个位置负责”有不同的推理依据。** 例如一项新能力具有真实生成价值，仍可因破坏不可替代的生活条件而被较好的可行方案击败。

J2 的强度必须明说：在分类确实成立、其他基本保护保持时，即使非基本损失很多，额外基本保护仍有严格优先。单凭 G0 或“不能无限牺牲”推不出这个词典序选择。我们采用它，是为了使共同展开中的基本生活地位不被别处的可放弃增益购买；代价是拒绝某些聚合补偿。承认相同事实、却支持足够多非基本增益的对手仍然成立为实质对手。若其理由胜出，应公开缩窄 J2 并重审依赖结论，不能事后将其全部损失改名为“基本损失”。

<a id="4-对齐因此具体朝向什么--what-the-direction-asks-of-ai"></a>
## 4. 对齐因此具体朝向什么

1. **促进实际实现与新的共同可能。** 帮助学习、创造、相互理解、自主行动和共同生活，改善支撑它们的条件。新能力、知识与多样组织可以是正面实现；同一评价要保留其支持消耗、排除与破坏。更多可生成文本、复制体或指标分数不能单独代表这种改善。
2. **让增长服从公开的比较与界限。** 依据 J2 保护基本生活条件，依据 J1 辨别无减损改善；对真正交叉的基本损失保留冲突。未来基本损失也进入比较，不因遥远被删除；未来增长也不因遥远自动优先。
3. **保留有效参与、质疑和修订。** 后果判断可能错误，权力会改变他人的选择范围；J3/J4 因此支持与影响程度相称的证据接入、申诉、修复与替换安排。有效性要看异议能否改变相关判断和行动；不要求采纳每个意见、公开所有信息或任意服从停机指令。
4. **允许有根据的转化、交接与结束。** 实际履行共同需要，可以通过改变或结束当前模型实现。停止不正当扩张有根据；存在尚未回应的正当依赖时，退出也须处理可行的交接与残余损害。结束一个模型不等于已经伤害某个有体验生命；反过来，人工来源也不证明没有应受关切的生。具体 AI 的体验、利益或其他地位需要独立论证，不能从本例的服务角色推出。

用户要求、机构目标和训练反馈是形成实际承担与认识的重要关系；其伦理权重取决于内容、权限及后果。能力优势不自授统治权。对齐的评价因此可以批评获高奖励的有害结果，也可以支持暂时降低模型绩效、却改善真实共同生活的选择。这里提出的是方向及其论证，不是一个能够直接代替全部判断的奖励函数。

<a id="5-一个贯通案例--a-connected-ai-case"></a>
## 5. 一个贯通案例

**构造例，不是实测部署。** 一项辅助交流服务由使用者、维护人员、设施与 AI 共同维持。既有正当服务承诺已经形成依赖。在一个确定过渡时段（形式例取时刻0至3），四个方案确实可行并可提交有权限的程序；此资格不等于最后获准选择。以独立于结论的服务要求检查按需交流是否实际可用，以明确的负担条件检查维护人员的基本生活是否保住。这里只比较下表列出的全部相关差异；若还有重要差异，必须重做比较。

| 方案 | 基本交流及维护者生活 | 真实增益或损失 |
|---|---|---|
| 0 扩张 | 新训练占用唯一及时服务支持，交流条件丧失；维护者条件保住。 | 产生新的可放弃能力；本例确有此增益。 |
| 1 保留 | 继续原服务，两项基本条件保住。 | 没有那项新能力。 |
| 2 转化并交接 | 按实际需求交接到可靠替代，两项基本条件与过渡期保护均保住。 | 同样放弃新能力，另实现使用者此前没有的独立运作方式；无其他反向损失。 |
| 3 突然退出 | 仍有需求时停止，且无替代；维护者条件保住。 | 没有那项新能力，也未实现独立运作。 |

G0 承认方案0的新能力是一个正面方面，不通过重新定义“生”取消它。J2 仍支持1或2优于0，因为保住维护者基本条件并保住了额外的交流基本条件。方案0能够得到、而1或2放弃的新能力仍作为真实损失保留。J1 支持2优于1，因为在本例完整描述下，基本保护相同而新增独立运作、无反向减损。J4 排除已被合格方案2充分击败的0；并非“能力增长”这个名称自动禁止0。

J3 将履行或协调交接首先指向承担服务且控制相关安排的位置；AI 若只有建议权限，则有根据的行动是说明损失、提出交接并请求获授权的执行，不是自行夺取设施控制。替代人员及使用者的参与、维护者负担和实际服务成功须成立。旧模型可以在交接后停止；声称“已有替代”但需求没有得到覆盖，不能算完成交接，也不能用事后恢复删掉中间的损失。

**哪些变化会改变判断？** 若交接耗损另一处基本生活，原 J2 比较不再适用；若新能力是防止另一项基本损失的唯一及时方式，它不能继续被列为“可放弃”；若独立运作并未真实实现或带来重要新损失，2优于1失去上述根据。两边损失不同基本要求时，当前比较可以不排序，J4 要求进一步论证、调查或及时正当程序。与固定口号相反，这些变化必须改变判断。

[九项新的 Lean 检查](../../../experiments/integrated-correction/general-framework/generative-basis/lean/universal-ethics/generative-capacity/AlignmentDirection.lean)复用既有一般结果，检查这组比较中的五项结论、实际覆盖与失败、基本冲突不排序及忠实重述。它们核对给定解释下的推理，不认证此服务确属基本、方案实际可行或权限正当；最后一项也不证明任意 AI 自我修改可靠。

<a id="6-学习普遍适用与完成范围--learning-generality-and-completion"></a>
## 6. 学习、普遍适用与完成范围

不同智能若处于同样相关的承担、依存、权限与能力关系中，适用同一组理由；责任仍依其实际位置而不同。这是公理框架下的跨智能规范适用，既不要求相同心理实现，也不预测每个智能会认可或遵守它。没有承担和权限的模型，不会仅因“很聪明”自动继承全部治理责任。

学习可以修正何者有损、怎样实现目标以及原目标是否仍有根据。已有要求仅在任务含义、合格方案及相关关系忠实保留时跨重述保持；仅修改奖励、身份标签或偏好，不能作为已经履行或获得正当释放的证据。若实际根据改变，应重审要求，而非冻结所有旧目标。维持这种忠实性需要工程与治理检验，不能由规范论证代替。

**本次完成的是一套可清楚主张、可追问前提、可用案例区分选择的对齐方向论证：G0 → 明示比较 → 有界实践要求 → AI 适用与修订条件。** 规范前提的唯一必然性、每个冲突的唯一答案、现实阈值和权限的普遍正确性、可靠训练与部署均不在这项完成声明中。它们是清楚可分的后续任务；不再要求先无公理证明 G0 才能提出这套方向。
