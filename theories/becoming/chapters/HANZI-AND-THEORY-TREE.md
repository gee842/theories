单字可以十分凝练，多字与句式可以补出关系、对象和作用层次。要做好的工作不是强迫每个节点缩成一个字，而是让中文表达保留理论中的必要区分，并接受历史文句与反例的检查。

## 1. 先把四种对应分别建立

| 所说的对应 | 示例 | 要检查什么 |
|---|---|---|
| 字形内部的构成 | 武中的戈与止；情中的心与青 | 当时字形、形符声符、异体和构形争议 |
| 字词的意义 | 生表示产生，另一些场合表示生命或生存 | 具体篇章、时代、所指、语法与多义 |
| 组合表达的结构 | 止戈、推恩、正名、生生 | 两部分怎样相关，整句是否另有背景或规范前提 |
| 理论的依赖和推导 | 有根据的他者证据，经理由与可行行动形成保护 | 前提、对象、机制、代价、失败域与逻辑关系 |

前三种都可能为第四种提供线索，却不能直接互相替代。尤其是形声字：如《说文》以“里声”分析理、“青声”分析情，不能把每个可见部件都当作一个独立的哲学前提。[中大理条](https://humanum.arts.cuhk.edu.hk/Lexis/lexi-mf/search.php?word=理)、[情条](https://humanum.arts.cuhk.edu.hk/Lexis/lexi-mf/search.php?word=情)

声音与意义也不是绝对排斥的两盒；某些部件兼具作用，需要逐字判断。因此“都是纯会意”与“有声符就毫无意义联系”都过强。[字库方法说明](https://peach.arts.cuhk.edu.hk/Lexis/lexi-mf/guide.php)

## 2. “武＝止戈”怎样保留下来并研究得更深

你的组合确有重要古典根据。《左传·宣公十二年》记楚子拒绝收晋军尸骨筑京观，以止戈论武，进一步用禁暴、戢兵、安民等要求衡量武功。它在追问：**获得了战胜他人的力量之后，这种力量应该为了什么、受到什么约束？**[《左传》该段](https://zh.wikisource.org/wiki/春秋左氏傳/宣公#宣公十二年)

文字史层面，中大字库采用的早期构形解释是戈与足形的止相合，联系武装出征；古形的止不能无条件代入今天的“停止”。字库因此没有把止息战争当作已经证实的最初造字意图。[武条](https://humanum.arts.cuhk.edu.hk/Lexis/lexi-mf/search.php?word=武)、[止条](https://humanum.arts.cuhk.edu.hk/Lexis/lexi-mf/search.php?word=止)

这两个层次都值得保留。字形提示武力与行动，古典规范解释则要求重新评价行动的目的和后果。后者与当前理论中“能力增长不等于智慧；保护还须约束保护者”这一问题有直接可比性。但该段仍认可某些征伐，不能改写为反对一切使用武力。

因此可暂记：**武〔采用《左传》这段规范义〕→有约束的保护能力**。它更像一个能力结构的入口，涉及识别伤害、可行干预、限制越权、实际安民及纠错，并非一个不需说明条件的原子概念。这里列出的现代条件是我们的分析，不是从两个偏旁演算出来的古代定理。

该例在仓库旧研究中已有记录与字源提醒；本轮新增的是直接原文与字库核查，以及它在当下推导中的位置。[六字构形证据](../../../_process/research/2026-10-05-generative-foundation-review/history/root-foundation/HANZI-FORM-EVIDENCE.md)

## 3. 第一批有用的对应

下表是**当前理论的候选中文表达**。斜线不是宣称同义或等价；同组不同词仍需分开定义。历史用法提供语义动机，精确界定则属于本次建构。它们不是已经验证的十二组古今双射。

| 候选字词及所取义项 | 可对应的概念或连接 | 必须保留的区分 |
|---|---|---|
| 分／别：形成或辨认差别 | 可区分状态、观察所作区分 | 实在差别不等于观察者已识别，也不自动产生动力 |
| 生：产生；成：形成某物 | 变化产生后果、实际构造出组织或能力 | 发生、完成、继续存在不同；成不等于善 |
| 化：转变 | 状态或结构的实际变化 | 变化可能改善或损害；规则改变不同于依规则改变 |
| 系／相依：相连及依赖 | 关系、组织和支持条件 | 相关、因果依赖、互利分别检查；相依不保证相助 |
| 养／续：供养与延续 | 支持、维护、留存及后继 | 得到一次支持不等于能持续；养育不等于取得支配权 |
| 知／辨：知道及辨识 | 事实对应、目标辨识、可用信息 | 事实准确、证据充分、记得下来及能调用并非同一能力 |
| 学／习：习得与反复实践 | 由历史形成或改变预测、反应及习惯 | 重复未必学习，学习未必向善；不同形成路径仍须说明 |
| 择：选择 | 候选响应的选择、选择器 | 有可选项、实际选择、产生选项与改变选择标准分属不同环节 |
| 省／改：检查与修改 | 反思、证据修正、规则修订 | 发现错误不保证有权限、资源或能力修正 |
| 仁／恕／推恩：关切与向外推及 | 他者后果进入评价的候选路线 | 一时不忍、换位、稳定关切与实际保护不能合并 |
| 义：合宜及有理由的要求 | 正当理由、冲突中对行动的判断 | 社会赞许、私人收益与理由成立不相同；不能由字形供应伦理根据 |
| 护／智：有效保护及有根据的综合判断 | 保护能力与可修正的实践智慧 | 帮助可能误伤；聪明、知道很多与伦理智慧有别 |

与现行理论文件逐项对应、包括未采用的候选词，见[十八项理论节点表](../../../_process/research/2026-10-05-generative-foundation-review/history/root-foundation/HANZI-THEORY-MAP.md)。生、化、成、习、知、智、间、系的实际字书读例见[八字试读](../../../_process/research/2026-10-05-generative-foundation-review/history/root-foundation/HANZI-LEXICAL-PILOT.md)；仁、信、义等构形争议另见[六字证据](../../../_process/research/2026-10-05-generative-foundation-review/history/root-foundation/HANZI-FORM-EVIDENCE.md)。

这一批对应已有用处：它帮助核清现有中英文表达中容易糊在一起的过程，也允许从古文反过来发现现有节点遗漏的内容。理论已有中文原生词汇和长期修订史，本轮不是首次为它添加中文。新词表的有用程度需要实际解析与推理检验，不能仅以读起来贴切来确定。

## 4. 双字和组合可以比单字更准确

若让“生”在同一受控词表里同时无标记地承载发生、出生、生存、生命等不同概念，映射会冲突；“生成”“续存”等表达可以限定我们讨论的过程。域外多义本身不妨碍在域内把“生”唯一用作一个概念。知与智在古文字和文献中又有通用，因此现代词表可以约定一个明确分工，但不能把这项约定追认成所有古人的固定用法。[知条](https://humanum.arts.cuhk.edu.hk/Lexis/lexi-mf/search.php?word=知)、[智条](https://humanum.arts.cuhk.edu.hk/Lexis/lexi-mf/search.php?word=智)

组合还可以标明作用对象与层次：修正记录、修正判断、修正选择规则，都是改，却在理论图中改变不同部分。一个短词能指认一段结构，不必对应一个无内部结构的节点。这里的短语是当前解释语言，不声称全是已经稳定的古代术语。

古典组合本身也须逐例保留内容。“推恩”涉及把已有响应推向别处；“正名”可能同时涉及名称准确、角色要求与谁有制名权；“止戈”表达对力量用途的限制。“生生”则需要讨论前后生成及延续的关系，不能仅因重叠两个生字就推出无条件永续或普遍向善。[前轮相关原文研究](../../../_process/research/2026-10-05-generative-foundation-review/history/root-foundation/WENYAN-CONFUCIAN.md)、[易传研究](../../../_process/research/2026-10-05-generative-foundation-review/history/root-foundation/DAO-CLASSICAL-SOURCES.md)

**值得研究的更强假说是：某些字词及其组合，是否能较稳定地保留概念之间的关系与操作，而不只是逐个对应名称。** 例如，在明确使用范围内，能否用少量表达区分产生、保留、反复、识别、选择、修订和保护，并准确表达这些过程怎样依赖、怎样失败。

## 5. 一一映射应怎样验收

先固定理论中一个有限概念集合，再选择有明确义项的中文表达，为每项写出对象、条件、结果与反例。可以让这个**受控词表**做到一项一名；那是一个可检验的设计成果。若进一步主张它忠实对应历史词义或自然语言结构，还需独立证据。

本轮采用四个逐级增强的标准：

1. **命名一致。** 同一工作词在声明范围内不偷换定义；两个必须区分的概念不被同一个未加限定的标签遮蔽。
2. **义项忠实。** 指定古文中的实际意义能对应候选概念，同时承认不适用的用例和另一种解释。
3. **关系保留。** 两个概念的必要条件、反例及依赖顺序，也能在表达中保留。若主张历史关系对应，关系须由原文独立确定，再检查类型、方向和条件是否保持；若主张同构，还须反向检查。不能先按理论编排历史词表再据此自证，共享一个偏旁也不当作共享理论前提。
4. **组合可检验。** 固定规则后，在未参与设计的域内样本上检查能否解读，并能否从中文表达恢复关键区分；域外样本只测覆盖，不直接否定有限子集。

任意编号也可以一一对应概念，所以“找到一组不重名的字”不是充分发现。更有价值的是：命名受到独立历史语义约束，组合保持关系，解释负担没有全部藏在注释或读者先验中。局部层级仍可以用树表示；若要覆盖当前理论的交叉依赖、反馈和不同证据层次，则需另记有类型的关系，或用概念图呈现，不必为了词字对应先改掉所有树形入口。

本轮已做定向对照：生的发生／生命两义，知智通用，以及化可借写祸，都会阻止不分语境的自动替换；它们没有反驳采用限定义项的有限子集。Ren 较早明确提出过子集与表达完整性的研究方向，本次沿用它。[谱系与十八项表](../../../_process/research/2026-10-05-generative-foundation-review/history/root-foundation/HANZI-THEORY-MAP.md)、[映射标准与反例审查](../../../_process/research/2026-10-05-generative-foundation-review/history/root-foundation/HANZI-MAPPING-REVIEW.md)

## 6. 对生成主线的作用与下一步

此研究对应[生成派生图](../history/GENERATIVE-GROUNDING.md#the-derivation-and-the-existing-work)中的语义接口：真实后果怎样被区分和记录，事实证据如何与理由的适用建立有根据的联系，再影响行动。用字若混淆发生与存续、知情与认同、关切与保护，就会在表达层提前抹掉本应解释的过渡；合理的词表能让这些过渡更容易检查。本轮改善的是这些接口的表达和审查，未新增其因果形成机制。

下一步以“知／辨—学／习—择—省／改—仁／义—护／智”为工作组，在既有理论定义与实际古文之间双向核对，逐个保留反例。它是工作索引，不宣称这些节点只能按一条线生成。需要新增双字、短语或关系标记时就明确新增；不要为了一个字一个节点而删去成本、权限、他者差别或规范前提。

本轮建立候选对应、来源与检验约束，没有从字源推出伦理，没有证明某个语言独占真理，也没有完成子语言的形式完备性或语料基准。它给出的正面进展是：**可以在已有中文术语基础上，进一步整理出有历史语义根据、精确限定、可组合与修订的词表。** [整合与内部审读记录](../../../_process/research/2026-10-05-generative-foundation-review/history/root-foundation/HANZI-INTEGRATION.md)
