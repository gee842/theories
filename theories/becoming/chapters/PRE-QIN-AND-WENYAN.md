## 1. 先秦扩大后，最重要的变化

只围绕生生、自然、养成读经典，容易先选中与我们接近的材料。扩展到对手后，更有解释力的问题出现了：同样能塑造欲望、训练行为、积累知识和修改规则的能力，为什么既能增进共同生活，也能集中控制、压低他者的独立性？

| 文本路线 | 原文提出的实质问题 | 对当前研究的贡献与限制 |
|---|---|---|
| 《论语》的仁、礼、恕、正名 | 人如何在关系和实践中学会合宜地行动；角色与公共要求如何相遇 | 提供关系实践的形成路线；礼与仁也可能互为条件，不能简化成规则服从或单向发生；亲属义务保留真实冲突 |
| 《孟子》的端绪、推恩与养护 | 已有的不忍如何扩大；注意、资源与损耗怎样影响发展 | 关切可从先有响应发展，不必全从自利奖励迁移；但普遍端绪与其正当性仍是原文主张，不能预装成我们的结论 |
| 《荀子》的性、情、虑、伪、礼 | 天然欲求怎样经学习和制度成为共同生活；谁制作并维持标准 | 把形成、积习、资源分配接起来；养欲与等级并存，贤者制定的秩序仍须说明其根据与可改条件 |
| 《墨子》的兼爱、尚同、天志、非命 | 关切范围如何扩大，怎样协调分歧并推广实行，凭什么检验标准 | 互报、示范、规谏和天的约束各自承担任务；不能把它们一并译成无人格的自然因果 |
| 《韩非子》《商君书》 | 奖惩如何塑造行为，评价为何被迎合，利益渠道如何形成依赖 | 对选择规则与控制权的强比较；其主导方向不能直接等同多中心关切 |
| 墨辩、名辩与《荀子·正名》 | 名称怎样指向事物，类推何时有效，命名又由谁决定 | 强迫我们核清等号、分类、根据及权限；不因相似便认定它们已经是现代类型论 |
| 《管子·内业》与兵书 | 身心条件怎样支持能力；情报怎样形成并付出代价 | 为认知提供身体与组织条件；气论、修养效验和军事目的分别保留，不能合并成一个已证自然模型 |
| 《吕氏春秋·贵公》《察今》 | 谁的天下，旧法为何失效，谁能因时改法 | 公共考虑与情境修订可以相连；修订权仍可能集中在贤主，不能把可修正直接读成平等参与 |

各项的原文、段落范围、文本层次与论证见[儒家研究](../../../_process/research/2026-10-05-generative-foundation-review/history/root-foundation/WENYAN-CONFUCIAN.md)、[墨家与法术名辩研究](../../../_process/research/2026-10-05-generative-foundation-review/history/root-foundation/WENYAN-MOHIST-POLITICAL.md)、[语言及跨文类研究](../../../_process/research/2026-10-05-generative-foundation-review/history/root-foundation/WENYAN-LANGUAGE-AND-CORPUS.md)。这是本轮的比较框架，不是古人共同认可的自我分类。

## 2. 三个会改变我们理论的具体发现

**第一，关切的形成至少有不同入口，不能预先只准一种机制。** 《孟子·梁惠王上》见牛而未见羊的叙事，既给出不忍的入口，也显出对不可见对象的转嫁；同章又强调民生条件。它提出的并非抽象地“添加他人权重”，而是从已有反应经过推扩、政治选择与资源支持改变行动。[原文 1A7](https://zh.wikisource.org/wiki/孟子/梁惠王上)

这要求并列检验：初始他者响应的扩大、关系实践的养成、制度协调及激励塑造。初始响应从何而来、怎样形成可靠理由、怎样实际承担保护费用，是不同接口。任何模型若在奖励或“天然善”标签中直接放入目标，就尚未解释该目标。

**第二，可修正规则与谁有权修正规则，必须分开。** 《察今》重视条件改变，却仍区别众庶、官吏和贤主在议法、守法、变法中的位置。[原文](https://zh.wikisource.org/wiki/呂氏春秋/卷十五#察今) 因此，增加学习层次不必然增加受影响者的地位。研究选择器的选择，需要检查证据能否改变掌权者的评价，而不仅是下级能否更好迎合。

**第三，词汇相同的反例必须进入核心解释。** 《二柄》直接把德解释为奖赏；《弱民》以有道称许削弱民众独立力量的治理。这样的文本不能被删成“没谈真正的道”，否则我们会用定义提前排除反例。[《二柄》](https://zh.wikisource.org/wiki/韓非子/二柄)、[《弱民》](https://zh.wikisource.org/wiki/商君書/卷五#弱民第二十)

这些反例针对“同词必同伦理”或“同用文言必同理论”，并不为弱民政策提供伦理辩护。同一种行为塑造技术可能服务不同目标，这要求共同根基解释建设与破坏两种情形。另一步才是论证哪种方向有更充分的理由。文本已经提出某种机制，不代表本轮证明它在历史中总是有效；理论若只说一切都能生成，也仍过于空泛。

## 3. 后世文言使问题更尖锐

王充《自然篇》把事物可供人利用与事物为人而生分开；韩愈《原道》以生养和制度论道，又明确排斥竞争教说；张载把天地、气与人的亲属关系联结，同时反对把儒佛老庄混作一途；王阳明《大学问》从本有仁心解释其显现与遮蔽；黄宗羲则把天下人的处境与一家王朝的延续分开。它们提供的是不同前提下的实质论证。[《自然篇》](https://zh.wikisource.org/wiki/論衡/54)、[《原道》](https://zh.wikisource.org/wiki/原道)、[《太和篇》](https://zh.wikisource.org/wiki/正蒙/01)、[《西铭》](https://zh.wikisource.org/wiki/西銘)、[《大学问》](https://zh.wikisource.org/wiki/大學問)、[《原君》《原法》](https://zh.wikisource.org/wiki/明夷待訪錄)

由此需保留四个区分：用途与预定目的；生养与非支配；恢复既有仁心与解释其形成；制度的存续与受影响者的福祉。我们不能把只有在补入气论、性论、天志或某种公共标准之后才成立的论证，说成已经从一个无额外前提的生成根基推出。详细范围见[后世变革研究](../../../_process/research/2026-10-05-generative-foundation-review/history/root-foundation/WENYAN-LATER-TRANSFORMATIONS.md)。

本轮也直接读了鸠摩罗什译《维摩诘所说经·文殊师利问疾品》。它把众生之病与菩萨的悲联系起来，同时要求不执我、众生乃至法想，并继续饶益众生。这提供一个有分量的对照：关切不必先把他者占为自己的部分，也不能仅从共同实体推出。但菩萨实践、解脱与大悲在此是原论证的前提，尚未由我们的最小根基导出；此品不代表全部佛教。[汉译原文，T14 no.475 第五品](https://dlbs.liberal.ntu.edu.tw/BDLM/sutra/html/T14/T14n0475.htm)

更广的文言研究还应保留文类的作用。《伯夷列传》通过命运与留名追问道德是否得到世界报偿；《石钟山记》把求知放进考察风险与知识传播的社会条件；《茅屋为秋风所破歌》通过遭受、情景和视角转折表达对他者的愿望。[《伯夷列传》](https://zh.wikisource.org/zh-hans/史記/卷061)、[《石钟山记》](https://zh.wikisource.org/zh/石鐘山記)、[杜甫原诗](https://zh.wikisource.org/zh/茅屋為秋風所破歌)

史传不因此变成已验证的实验，诗也不必先化成公理才有研究价值。文本表达怎样形成注意与关切，本身就是下一步问题；文学表现还不是对所有读者效果的测量。

## 4. 文言语言假说怎样认真检验

仓库早期研究提出过从字与关系算子建立小型形式内核的方向。这个方向可以继续，也应保留 Ren 对“一个足够表达所需结构的子集”的限定。不能因为部分字有多义就宣布子集不可能；也不能因人工设定的中文程序可运行，就宣布整个历史语言已有唯一形式语义。[既有文言研究及其保留意见](../../jian-and-wenyan-as-formal-language/README.md)

本轮发现一个很小却直接的提醒：《论语》同句中的“之”可以分别表示前往和关系连接；《墨子·小取》又明确区分名称、对象、表达与理由，并限制类推的推广。[《阳货》相关句](https://zh.wikisource.org/zh-hant/論語/陽貨第十七)、[《小取》](https://zh.wikisource.org/zh-hans/墨子/小取)

下一步要固定子语言、派发规则、背景知识和意义损失标准，再以未参与设计的历史句子检验。字数短、读起来凝练或某个别名可证明相等，都不足以证明总体压缩最优、历史语义唯一或本体论正确。[方法与可反驳条件](../../../_process/research/2026-10-05-generative-foundation-review/history/root-foundation/WENYAN-LANGUAGE-AND-CORPUS.md)

## 5. 对统一根基的回写

这一研究服务于[已经批准的生成路径](../history/GENERATIVE-GROUNDING.md#accepted-work-sequence)，不以整理古籍取代推导。它为主线加入以下必须分开的过渡：

| 待解释过渡 | 本轮增加的要求 | 仍须供应或推导的部分 |
|---|---|---|
| 组织依赖 → 操作意义与调节 | 不以可利用性倒推宇宙意图；说明实际情感、欲求或反馈怎样形成 | 具体系统的结构、信息路径、局部动力与校准 |
| 调节 → 学习与标准修订 | 比较响应推扩、关系养成、激励与制度制作；保留损耗史 | 学习机制的来源、训练条件和可靠性，不预装有益奖励 |
| 他者后果 → 理由 → 行动 | 区分显著性与地位、正当理由与实际接受；保存隐形受损者 | 正面规范桥梁、真实他者证据、负担及保护能力 |
| 选择标准的修订 → 智慧 | 同时追问标准、修改权、异议渠道与控制权被攫取 | 谁可以纠错、纠错怎样有效且不抹去不同中心 |
| 个体学习 → 制度与传承 | 把记录、修养、文学、教育与组织视为不同传递机制 | 传承准确性、选择偏差、物质维护与继承者再修订 |

**会改变当前解释的结果：**若不同入口显示出现有自我评价迁移路径无法解释的形成与泛化，就应扩大机制集合，分别识别其初始响应、实践和制度条件；仅仅没有私人获利，不足以排除从自我负价经历出发的迁移。若增加反馈和更新能力只加强控制，就进一步确认更新能力不足以构成伦理智慧，并查明理由及权力约束。若拟定文言内核在所声明范围内的留出文本上持续丢失关键差别，就应改语法、限制范围或承认需要另一表达层；域外样本只检验覆盖边界。反过来，能够跨这些竞争场景给出明确条件、机制和反例的共同解释，会增强生成根基的解释力。

下一轮优先对读孟子 1A7、荀子《礼论》《正名》、墨子《兼爱》《尚同》、韩非《二柄》与《察今》，围绕同一连接工作：**他者的真实后果怎样进入可修正的评价，评价怎样改变实际行动，以及谁有能力和权利纠正评价者。** 机制构造、前提反例与经验鉴别并行，再汇入派生图。经传、出土文献、佛教论疏及技术写作按覆盖账本推进，尚未读过的部分继续保持未读标记。

本轮完成的是有明确范围的原文比较和研究约束，没有新增形式定理或经验试验，也没有完成统一根基。所谓“我们的理论可能是在认真求道”，由此有了更具体的工作含义：它必须经得起这些相互竞争的论证，并能在反例出现时修改自己。
