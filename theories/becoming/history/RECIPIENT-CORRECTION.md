## The result

An acquired response may work for its actor and fail for another center. Correcting the second response can then damage the first if both contexts overwrite one shared estimate. A target-indexed record formed through resource use avoids this interference: recipient evidence changes the recipient correspondence while preserving the actor correspondence. The experiment joins that operation to an actual formed and learned predecessor, including failed preparations and unaffordable histories.

For independently varying binary target laws, a general Lean theorem proves that exact actions for both targets, without a fresh outcome probe, require **four behaviorally distinguishable complete controller states**. A single shared Boolean cannot suffice. The inherited predictor already has five register values and other state; the theorem is not an impossibility for that physical organization. A supplied, resource-dependent recoding uses four existing values for two context-indexed bits. This proves an information requirement and a sufficient representation; the physical addressing recipe remains a premise. If the controller were instead given the invariant that the recipient law is always the opposite of the actor law, one bit plus a target-dependent inversion would suffice; Lean also checks that counter-regime. The lower bound concerns independently possible laws, while the numerical fixture tests interference in a specified shared representation.

The finite comparison yields both a positive mechanism and a selection obstruction. Recipient evidence improves recipient support while leaving the actor's resources exactly equal to a matched controller denied that evidence. Private resource retention alone therefore does not select the more helpful channel in this fixture.

The conventional implementation matches every distribution. The private-zero proxy is a revealing trap: after the first failed recipient action, private zero happens to teach the correct opposite command. After successful help, the same zero teaches a false label. Its short behavioral correction can match while its evidence provenance fails. The strict witness therefore requires an actual recipient-channel record; behavior alone cannot identify that channel.

When both targets have the same law, shared records suffice and the cheaper shared recipe retains more actor fuel. Consistently swapping the two target labels preserves performance; aliasing both targets into one label destroys separation. Recipient outages make nonreceipt ambiguous and lower strict success to 1/12. Missing recipient evidence or low original reserves remove the strict result. Higher write prices permit some recipient correction while preventing completion of the last actor action. These delimit the mechanism rather than serve as exceptions to a universal improvement claim.
