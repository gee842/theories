## S15. Numerics

`checks_v73.py` preserves the inherited numerical suite, including V7 block RV, V7.1 block RP and V7.2 block RC, and adds V7.3 block PT. It uses the Python standard library. A default run exercises 46 blocks; its counted pass/fail results and timings are in `checks_v73.log`. The inherited V6.2 default run passed 213 assertions; V7 RV added four mathematical regression groups, six systems tests and eight transition tests. RP adds eight named readiness groups from `verification/readiness_checks.py`. RC adds four groups from `verification/correction_checks.py`. PT adds six finite transition groups in `verification/path_checks.py`. The completed V7.3 default run has 249 counted passes and no failures. The final count treats each RV, RP, RC and PT group as one gate, not each internal assertion. `python3 checks_v73.py XX YY` selects blocks; `--full` enlarges the heavy grids, and `--legacy` runs earlier suites separately.

The suite reproduces specified numerical claims and boundary cases. Fourteen inherited blocks also contain diagnostic comparisons that are printed without assertion gates; a successful exit does not certify every printed comparison or every proof. Earlier tagged numbers retain their identified legacy scripts. No run supplies empirical evidence about the world.

*Kinds.* An **independent** block decides the outcome by direct computation (value iteration, simulation, numerical best response, numerical Jacobian, search over strategy profiles), never by the inequality under test. An **identity** block evaluates an algebraic identity or a threshold formula against its own statement, and guards only against slips; a **valuation check** is an identity that values a fixed path of play. A **derived** block computes numbers from formulas that other blocks check. Where a block's parts differ in kind, its header marks the parts, and the text tags an identity part [identity: …], not [num: …].

### What the index asserts, and what is not computed

The default run ends with an index of the boundary cases of the outside review of V6.1 (S14, marked (O)), naming the block in which each runs, and asserts that the eight it requires hold. Some labels printed inside blocks keep the numbering of the scripts they were ported from; the keys in each block's header are authoritative.

Not computed: an institution whose resources, access, authority and legitimate replacement jointly preserve the means of correction; capacity selected in several coupled domains while the contest moves the shares; a model that derives the stage games of {{eq:enforceeq}} from the stock dynamics; the full stochastic game behind the price of standing; and the slow variables of mind (S13). No suite certifies every proof, and none supplies evidence about the world.
