## Finding CR1 — Medium, narrow: state which side of the comparison margin rejects efficacy

**Locator:** `src/reg/TESTS.md:201`, final paragraph of §6.6.

The sentence saying that an interval “excluding the registered improvement” rejects comparative efficacy is ambiguous in a way that reverses the intended decision for some outcomes. An interval entirely above the minimum useful difference excludes that exact value too, although it supports rather than rejects improvement at that margin. The surrounding text correctly distinguishes the feasibility study from a later confirmatory sample; this is a wording error in the latter's rule, not a reason to require a completed experiment before issuing the paper.

**Action:** State that an upper confidence bound below the registered minimum useful difference rejects comparative efficacy at that margin. An interval spanning the margin is inconclusive; a lower bound above it supports comparative efficacy, subject to the service and appeal conditions. This retains the intended conservative decision rule without making an unexpectedly large benefit count against the reform.

**Status at initial review:** Reported to the integrating agent for correction; no source text edited by this reviewer.

**Resolution verified:** The revised `src/reg/TESTS.md:201` now distinguishes the upper bound below the registered minimum useful difference, an interval spanning that margin, and the lower bound above it. These lead respectively to rejection at the margin, inconclusiveness, and support for comparative efficacy. The service-floor and valid-appeal conditions remain in the same paragraph. CR1 is resolved; no claim-review release blocker remains within this review's scope.
