## 三、本次新增的连接

1. **三层生生不息。** 把事实持续性、实践可延续性和公共生生不息分开，以免对压迫系统的持续性给出错误的道德背书。
2. **R1—R4。** 用目的与必要条件、可修正判断、公共理由非任意性和基本地位连接规范层。前两项的实践论证承接原稿；后两项是本次对普遍化缺口的明确重建，不能假称已由动力学证明。
3. **双重检验。** 共同条件使生活成为可能；实际生活也检验“维护条件”的活动是否变成无止境牺牲。把幸福、爱、照护、游戏和创造放回最终理由。
4. **稳健保持集合。** 把旧稿中的“存在路径”与“行动能对扰动保持条件”分开，建立可实际检查的离散核心。
5. **含纠偏的反馈模型。** 用 βγ 与 δₐδᵣ 的比较替代“有正反馈即已形成吸引子”的跳跃。
6. **约束与不完备改进。** 基本保护先说明理由，候选方案再按可辩护维度比较；不假装一个总分解决所有价值冲突。
7. **共同体与组织推论。** 将后果范围、参与范围和问责范围联系起来；明确研究可信度、规范正当性与组织授权不能相互替代。

## 四、证明修正记录

| 原尝试或潜在推论 | 问题 | 本稿采取的修正 |
| --- | --- | --- |
| 以 γ=lim log 可达终点数/n 刻画生成的本质 | 有限状态空间中这一增长率为零；噪声又可能提高分枝数 | 保留为特定模型指标，改以实际能力、结构与纠错共同评价 |
| 无分枝或未来信息熵为零就无判断／价值 | 已知的确定性系统仍可能拥有复杂内部结构；物理分枝与判断接口不是同一对象 | 用确定循环反例分离这些概念；本稿未宣称定义出了意识 |
| 离开生核就绝无可能回返 | “存在安全路径”和“对所有扰动能安全”的量词不同 | 给出固定模型下的原路径解释；对稳健集合证明较弱命题并提供幸运回返反例 |
| 不可逆等于恶，开放等于善 | 有价值的承诺与有限生命也有不可逆性 | 问清失去了什么、影响谁、有无理由；重点保护生活与纠错条件 |
| 每次有非零毁灭风险就必然最终毁灭 | 风险可能递减，暴露可能有限；非零并非统一正下界 | 明示每次存活条件下的 ε 下界及无限暴露条件 |
| 保留信息和选项永远严格更好 | 信息可能无关，选项可能有维护成本，等待可能失去时机 | 在有限行动、可积收益、无额外成本、可忽略信息下证明弱不等式 |
| 最大最小法自动严格偏好保留未来 | 模型集合和收益可能使方案最坏值相同 | 未纳入一般严格优势定理；需要分别建立收益界与可行保留方案 |
| 一切长期目的都要求无限延续 | 有些目的只需有限跨度 | N1把延续要求限制在目的所需跨度；无限时域仅为特定理想化 |
| 世界无外部奖励，故内部支配必然不合理 | 内部行动者仍可一致地追求支配或自毁 | 区分目标一致性与公共正当性，以 R3—R4评价后者 |
| 通吃总会耗尽自身基质 | 替代、再生与消耗速度需要假设 | 保留明确资源不等式；不满足条件时不声称定理适用 |
| 共存优于通吃的充分条件不成立，就能推出通吃占优 | 否定充分条件不能推出相反结论 | 将比较重新交给具体收益、知识贡献与冲突成本；旧 B2 的普遍表述未沿用 |
| 正交叉反馈直接证明总体化吸引子 | 正反馈可被纠偏压过；局部失稳也不同于全局吸引 | 增加含阻尼的 M1；全局吸引与经验存在另列研究任务 |
| 主特征方向总是特定政治经济目标 | 取决于矩阵、变量、谱隙及初值 | M2只证明固定矩阵下方向选择；现实含义必须估计与检验 |
| 一个依赖者维护成本过高就不应保护 | 净贡献并不能决定人的基本地位 | 资源稀缺进入公开分配与照护论证，不自动取消脆弱者地位 |
| 反对总体化就必须建立可以战胜一切的善的力量 | 新力量可能重现所反对的条件垄断 | 将防御者可问责和可受限制保留为核心未解问题 |
| 一套道德方向能自动解决对齐、框架问题或所有新情况 | 方向不提供完整世界模型和可靠执行能力 | 将技术实现、验证、治理和规范论证分别列明 |

这些修正服务于更强的论证：削去不成立的普遍化，同时保留原稿真正能够支持的结论。它们没有修改或删除任何原文件。

## 六、仍然不能宣称的结果

- 未从纯自然事实、无规范前提地推导全部伦理。
- 未证明所有可能的智能都会认可公共理由或关心他者。
- 未证明现实世界已经进入某个唯一的全球吸引子。
- 未完成 AI 风险、技术丰裕、保障或合作效果的实证研究。
- 未证明所有价值冲突存在唯一最优解，或所有基本保护条件永远可共同满足。
- 未给出一个已经解决对齐和治理的可部署通用算法。
- 未通过论文为任何组织取得对外部人的决定权。

已经提供的是完整的论证长稿、可追踪的前提与来源、对旧证明的具体修复、二十项机器检查结果，以及可用于组织研究与公开讨论的共同立场。
