# 开放未来：新增的三个结构结果

用于[白皮书v0.2](../history/WHITEPAPER-v0.2.md)第四、六、九节。源码：[OpenFuture.lean](OpenFuture.lean)。检查记录：[OpenFuture-verification.txt](OpenFuture-verification.txt)。原有二十项结果及其文件保持不变。

本文件使用Lean 4.29.1与Std，没有新增公理，没有跳过证明；三个结果的依赖报告不含`sorryAx`。部分简化使用Lean标准命题外延基础`propext`。本次源码SHA256在检查记录中。

| 定理 | 实际证明内容 | 未证明内容 |
| --- | --- | --- |
| `observation_limit` | 两情境的输入相同、相关布尔事实不同，则任何只看输入的确定性判断器无法在两者中都正确 | 不是所有新事物都无法预测；没有证明人无法扩展信息或拒绝下判断 |
| `local_maximum_violates_protection` | 在明定回报3与5、前者满足保护而后者不满足的两行动模型中，局部回报最大化必定违反保护 | 没有将所有利润活动判恶，也没有从数字自行产生道德标准 |
| `zero_sum_without_closure` | 一方得分、另一方相反得分，可以同时保持一个明定的背景条件 | 没有证明现实竞争普遍无害；只是排除“零和标签本身足以判恶”的普遍断言 |

第一个命题给出环境遗漏与情境不确定性的认识限制。第二个命题给出局部优化可能破坏共同保护的直接反例。第三个命题限制批判对象，使对伤害性竞争的否定落在实际机制上。

三项均为结构推导。白皮书N6、N7关于非善与结构性恶的结论，还需要其明示的生活价值、公共理由、损害及可避免性前提。把这些前提隐藏进谓词，不会使伦理问题变成无需论证的算术。

复现时，在本目录运行：

```bash
lean OpenFuture.lean
```

本目录的`lean-toolchain`固定为`leanprover/lean4:v4.29.1`。成功编译后会显示三项基础依赖报告。
