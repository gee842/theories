# Meta-Attractor 诊断工作表

对应[白皮书v0.3](WHITEPAPER-v0.3.md)第七、十一、十四节。用于具体行动、项目或制度的分析；名称不代替证据，诊断不取消对眼前严重伤害的处理。

## 1. 先写清这次决定

**需要决定的行动：**

**可比较的替代方案（包括维持现状）：**

**受影响者与关键外部条件：**

**时间范围及其依据：**

**已经明确的基本保护要求：**

避免只以“市场”“AI”“国家”作为整个判断对象。写到具体安排，例如某项奖金如何分配、模型依据什么获得部署、谁有权改变一项评估标准。

## 2. 找到循环，不先贴标签

| 环节 | 本次应记录什么 | 可用证据例子 |
| --- | --- | --- |
| 实际奖励 | 什么决定收入、资源、职位、影响或继续参与？ | 预算与晋升决定、合同条件、评价标准及实际执行 |
| 行为选择 | 哪些做法更易留下、扩大和被复制？哪些退出？ | 方法传播、项目存续、招募和退出记录 |
| 认知选择 | 什么问题被问或不再被问？坏消息怎样处理？ | 议题和研究资源变化、反对意见的处理、核查机会 |
| 规则反馈 | 获胜者能通过什么渠道改变下一轮标准与门槛？ | 标准制定权、信息入口、基础设施和监督关系 |
| 共同后果 | 生活、学习、修复、信任、实际退出得到改善还是受损？ | 多来源的实际后果、受影响者经验与独立核查 |
| 再生产条件 | 谁为循环提供资源？谁承担未计入的成本？ | 维护成本、资源补充、损耗与责任分配 |
| 可改变性 | 反馈能否改变决定？是否有替代、恢复和退出方式？ | 实际纠正案例，而不只是制度文字 |

每条记录标明：**已经观察到／有根据的推断／尚待检验**。若没有优势反馈到规则的证据，可以诊断为激励问题或选择假说，不必强称为完整的Meta-Attractor。

## 3. 认知筛选的四个关键追问

1. 一个人准确指出对项目不利的重要事实以后，会得到什么实际后果？
2. 能够展示指标，却忽略重要外部代价的方法，是否更容易获胜和被学习？
3. 不适应现有奖励的人离开后，留下者的看法是否被误当作所有人的共同认识？
4. 某种模型是否通过分配机会塑造了结果，然后把这个结果当作自身普遍正确的证明？

这些问题检查机制，不推测个人隐秘动机。一个人有利益关系，并不自动使其论证为假。

## 4. 写出竞争解释与反证

**当前最有根据的反馈假说：**

**至少一个不同解释：**

**哪一条证据出现，会使我们削弱或撤回当前诊断：**

**当前最关键的未知环节，以及可相称取得的信息：**

应区分实质质量提高与指标适应，任务差异与方法选择，真正问题减少与报告渠道受损。不能把任何结果都当作同一个吸引子的证明。

## 6. 决定要改变哪一环

可考虑的环节包括：奖励与保留方式；优势转化为规则权力的渠道；独立观察和纠正的能力；基本保障、替代和退出条件；公共维护与修复的资源。

**本次决定：** 执行／改条件推进／限制特定范围／停止特定机制／先补足关键证据。

**具体改变的规则或关系：**

**谁负责、需要哪些资源：**

**什么可观察结果支持该改变有效：**

**什么结果要求重审、停止或修复：**

**本次改进是否也可能成为新的控制或认知垄断：**

## 7. 一段可交付的诊断结论

> 在________范围和时间内，我们观察到________实践因________奖励得到更多保留与影响。优势能够通过________改变下一轮规则，进一步支持________。这对________共同条件产生________影响。已得到证据支持的关系是________，仍未知的是________。与________相比，我们决定________，以改变________环节。其代价和副作用是________；若出现________，应重新判断并采取________。

一个最短示例：组织增加了风险报告要求，却仍按速度奖励团队；若报告使团队失去机会，报告者和相关调查可能逐渐减少。需要验证这一选择是否发生，并使准确报告获得核查资源和影响决定的能力；不能将报告数下降直接解释为安全改善。
