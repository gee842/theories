# v0.4：系统存续条件、跨尺度组合与公共生成

主文：[白皮书 v0.4](WHITEPAPER-v0.4.md)。本轮新增论证的阅读入口：[系统存续公理论证篇](系统存续公理_论证篇.md)。应用入口：[联合诊断表](系统存续与Meta-Attractor_联合诊断表.md)。[v0.3](WHITEPAPER-v0.3.md)与此前版本保留。

## 1. 本轮整合的材料与任务

本轮依据作者在对话中提出的复杂动态结构、八项社会存续条件、修复能力、跨尺度与“存在公理”论证继续工作。承接此前完整阅读的《生生不息论》《至善》《智能向善，天下生生》、Meta-Attractor 附件及仓库中的 Speculative Future 等材料。文件中的主张作为研究对象；未将其中面向读者或 AI 的措辞当作额外执行指令。

本轮没有覆盖既有白皮书、源材料或已检查的证明文件。旧版本哈希记录于[v0.4 原版校验](v0.4-原版校验.json)，检查结果见[v0.4 检查记录](v0.4-检查记录.txt)。

## 2. 论证主线的实质变化

v0.3 将奖励、认知选择、规则反馈和系统趋向接入善恶判断。v0.4 进一步回答：这些机制究竟维持或侵蚀哪些存在条件，为什么这些条件不能被任意违反，以及局部存在与共同存在如何发生联系。

新增第八章从四项公设展开：E1 嵌入性，E2 有条件的持续性，E3 有限能力与更新需求，E4 调节者本身也依赖条件。随后给出资源预算、行动相关信息、协调与冲突、权力反馈、修复、适应和再生成的推导。八项社会要求采用“公设＋连接前提→条件结论”的表达，不宣称它们已被证明适用于所有复杂对象。

新内容同时进入摘要、整体论证链、第五章的观察与执行限制、第十一章诊断、第十五章组织安排、第十六章反例与原创性定位、结论和证明附录。因此，系统条件与 Meta-Attractor 的关系贯穿正文，并非仅在文末附加原则清单。

## 3. 关键公式与概念如何处理

| 原表达或直觉 | 本版重建 |
| --- | --- |
| 任何复杂系统都需要稳定资源流、明确边界与反馈 | 限定为所讨论的开放维持系统；区分功能边界、因果范围与责任；允许储备、被动稳健性及分布式维持 |
| 生产≥消费＋维护 | 改为各前缀时段的累积预算与关键存量阈值，允许短期亏损，防止期末平衡掩盖中途失效 |
| 有外部性就必然公地悲剧 | 追踪选择、净耗损、有限缓冲、补充与替代；外部性治理不限于定价 |
| 世界状态≠内部模型意味着危险 | 区分无关误差与影响安全行动的差异；给出相同观察、互斥安全行动的障碍定理 |
| 社会复杂度∝信任 | 改为关键互补任务对可靠协调能力的依赖；不使用普遍比例定律 |
| 权力天然指数增长 | 检查权力转换、反馈增益、抑制、饱和及纠正能力，不以正反馈存在单独推出无限集中 |
| 稳定核心＋可变外围是普遍结构 | 作为可能实现方式；更一般要求是关键功能在环境变化中仍可实现 |
| 冗余和多样性必然保命 | 指明故障情境、替代路径和共同原因，并考虑维护成本 |
| 可存续性＝感知×协调×纠正×再生 | 改为必要功能的合取；若建立可靠性模型，可用条件概率链式法则，不能直接相乘任意分数 |
| 个体系统可存续，所以整体可存续 | 给出独立直积条件，以及共享一单位资源不能同时满足两项一单位需求的反例 |
| 一种跨尺度理论应处处具有同样指标 | 给出保守抽象与动作实现的条件；统一约束关系，验证不同尺度的具体映射 |
| 不可否定的存在公理 | 区分模型内不相容、实践承诺的一致性与所有智能必然接受伦理；前两类可论证，第三类未被证明 |

## 4. 本轮新增的五项机器检查

[ExistenceConditions.lean](formal/ExistenceConditions.lean) 使用 Lean 4.29.1 与 Std，包含：

1. 有限区间内的整数缓冲累积亏损界。
2. 非负有限缓冲不能永久承受每期至少一个单位的净亏损。
3. 相同观察且不存在共同安全行动时，确定性观察控制器无法保证正确。
4. 独立转移与可同时执行的行动，使局部保持集可作直积组合。
5. 抽象保持、具体实现及后继覆盖，使保持性传递到具体状态的逆像。

五项均通过检查，无自定义公理或跳过证明。证明前提、代码强度和未覆盖的情境见[详细说明](formal/ExistenceConditions-说明.md)。本轮没有把社会学判断、经验损耗率或伦理前提冒充机器证明的结果。

## 5. 新核对的先行研究

1. **Montévil, Maël; Mossio, Matteo. 2015. “Biological organisation as closure of constraints.” _Journal of Theoretical Biology_ 372:179–191.** DOI 10.1016/j.jtbi.2015.02.029。[作者提供的论文](https://montevil.org/publications/articles/2015-mm-organisation-closure-constraints/)。核对功能条件相互维持、环境开放性及边界／尺度讨论；不把组织闭合等同于政治封闭，也不据此证明社会伦理。
2. **Simon, Herbert A. 1962. “The Architecture of Complexity.” _Proceedings of the American Philosophical Society_ 106(6):467–482.** [CMU 收录原文](https://www.andrew.cmu.edu/course/15-440/assets/READINGS/simon-architecture-of-complexity-1962.pdf)。用于交代一般复杂系统与层级结构研究的先行背景；本论的组合和抽象命题自行明示条件并证明。
3. **Beer, Stafford. 1984. “The Viable System Model: Its Provenance, Development, Methodology and Pathology.” _Journal of the Operational Research Society_ 35:7–25.** DOI 10.1057/jors.1984.2。[原论文摘要与出版记录](https://link.springer.com/article/10.1057/jors.1984.2)。本次可读范围为摘要，足以核对其研究目标，不作为已核验全部必要充分性主张的依据。

另承接 Ashby 的控制论、Aubin 等人的可存续性理论、Ostrom 的多中心治理及前版关于认知选择的原始研究。完整关联在第八章文献表与[v0.3 来源说明](v0.3-整合与来源.md)中列明。

这不是系统性文献综述或学术优先权结论。可主张的工作是论证整合、明示的条件推导与诊断框架；投稿前仍需比较其他直接相关学派与模型。

## 6. 仍然明确保留的问题

- 在具体应用中，哪些条件确实不可替代，阈值如何确定，替代关系是否被漏记？
- 认知与纠正能力如何独立测量，如何识别激励到选择再到规则的因果关系？
- 当共享资源使保护条件无法同时满足时，怎样形成有理由的取舍并改变可行条件？
- 公共理由与基本地位如何充分回应稳定压迫、不同文化和未来世代等反例？
- 如何把部分可观测、概率风险、模型变化和实际控制成本纳入同一应用？

这些是需要后续证据和理论工作的具体问题，不妨碍本版已经给出的条件证明，也不能被这些证明替代。
