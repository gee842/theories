# 从差异到生生：认知、生成与共同条件的递归推导

2026-09-05。承接作者对[完整性审计](v0.6-完整性与形式化审计.md)的回应，独立保存本轮推演；[白皮书 v0.6](WHITEPAPER-v0.6.md)及此前文件保持不变。下列新命题为纸面论证，未增加 Lean 定理，也未作新的经验验证。

## 一、先修正研究方式：把已有机制向前推

前轮审计将若干问题并列为未闭合部分，但没有充分区分：核心命题尚缺理由、已有理由尚未整理成统一模型、已有学科提供方法而本框架需要接入。这三者所需工作不同。

作者原《生生不息论》已经提出“像亦象也”：人的模型具有实际因果作用；也提出“成生之限”：某种限制可以形成更深的能力；“教”则包括价格、奖惩、关系、恐惧与环境对认知的持续塑造。此前[物理补篇 §4.2](物理生成与内在规范性_论证补篇.md)也已定义有时间和资源边界的有效可能性。它们都应被用于继续推导。

因而，认知与制度塑造、知识更新和未知未来，并不是必须由作者另外逐项补上的全新地基。本轮把它们接成一条更明确的生成论证。同时保留区别：能够改变某个机制，不等于在任意资源和冲突条件下都能成功改变它。

## 二、三个起点，各自承担什么

| 起点 | 能够支持的起始工作 | 需要另行说明的内容 |
| --- | --- | --- |
| 有对差异与变化的观察 | 区分、记录、跨时比较和表征的最低结构 | 观察者如何形成，什么使它持续，何种变化有利于它，以及对他者的公共责任 |
| 我们是生命，存在于生命与环境的耦合之中 | 自我维持、功能利害、适应、条件再生产和环境依赖 | 不同生命的利害如何协调；为何不能把整体延续当作任意牺牲个体的许可 |
| 生生：生成者继续生成，并参与更新生成条件 | 将维持、创新、认识和共同关系放入同一个递归对象 | 哪些具体过程符合此结构，如何处理代价，以及公共评价范围和正当理由 |

这三个起点可以衔接。差异提供认识入口；生命把差异与实际利害连接；生生把利害推进到生成条件本身的继续形成和修订。

### 2.1 单独的“差异与变化”不能推出全部后续

若所谓观察变化包含比较先后状态，那么至少需要某种跨时联系：记忆、记录或能够保留历史影响的结构。这个要求不等于必须有神经或显式语言。

但“已经出现过这种观察”与“观察过程将持续更新”仍然不同。一个有限过程也可以记录两个不同状态，此后终止。它满足前一个描述，而没有提供无限延续、结构再生产或公共伦理。

因此，仅凭 D＝“存在对差异与变化的观察”，还不能演绎出完整的生生论。障碍在于 D 留下了太多没有确定的结构，不在于后续内容一概不可形式化。也不能把“观察”一个词预先定义成包含生命、公共地位与开放未来，然后将这些内容当作已经从一个简单前提证明出来。

### 2.2 更有内容的起始事实

本论可以从作者实际上已经指出的事实出发：

> **我们正在进行的认识与行动，是世界内部形成的过程；它依赖能够维持和更新的结构，而其行动又会改变自身及他者后来能够存在、认识和行动的条件。**

这句话应拆出可检查的内容：世界内的实现、构成依赖、变化中的维持，以及行动的反馈。它是一组联系紧密的起始事实，不是由“差异”二字自动产生的全部物理定律。

其优势是让研究对象一开始就包含观察者。关于世界的模型，也属于世界中会得到维持、传播、修改或淘汰的结构。这里已经可以接入三层现实和 Meta-Attractor。

## 三、以生命为起点，可以建立内在利害

本节的对象是通过活动维持组织、在环境中更新其条件的生命及相关适应系统。若把“system”扩展为任何可以命名的集合，就不能要求它们都具有代谢、认知或再生产。

### 3.1 维持生命是一种持续发生的活动

若某项组织功能依赖正在被消耗、损坏或更新的条件，那么功能持续就要求这些条件得到足够补充、替代或修复。需要哪个条件、允许多久的中断、存在什么替代，依系统与任务而定。

这给出了一个跨尺度的条件命题：

\[
\operatorname{Continue}(L,H)\Rightarrow
\operatorname{MaintainRequiredConditions}(L,H).
\]

证明不神秘：若某条件在所声明期限内不可替代地必要，而它在需要时不成立，相应持续活动就不能成立。实质研究在于识别必要性、期限与替代关系。

生物组织研究已讨论构成约束如何相互维持，以及这种组织如何依靠与环境交换物质和能量。它为“产生自身条件的活动”提供具体理论资源。[Montévil 与 Mossio，2015](https://montevil.org/publications/articles/2015-mm-organisation-closure-constraints/)

### 3.2 有利与有害，可以具有实际的因果依据

如果改变某项条件，会改变生命维持、修复、感受或行动的能力，那么这种差别不只是外部观察者随意规定的分数。它对相关生命具有实际利害。

因此，可以先建立功能评价：某机制在什么条件下支持或破坏某生命的活动。这样的判断可以适用于不能说出判断的生命，也不依赖破坏者承认后果。

这提供了规范研究的自然基础，却仍需区分评价尺度：对一个细胞复制有利，未必对其所在身体有利；对某群体的控制有利，未必对其他人的生活有利。公共善恶要把相关生命、基本利益与共同条件连接起来，不能只把观察范围扩大后计算一个“整体分数”。

### 3.3 没有神经的生命，也可以具有调节机制

环境相关的差异，可以通过分子状态、反应网络和行动倾向影响后续活动。研究者能够分析其中的反馈，不需要假定细胞先理解一条语言命题。

例如，Yi 等人在细菌趋化模型中分析了积分反馈与鲁棒适应的关系。该研究支持“无神经系统中也可以存在可分析的适应机制”，没有证明每个细胞都会形成一套公共伦理。[Yi 等，2000](https://pmc.ncbi.nlm.nih.gov/articles/PMC18287/)

因此，本论可以区分几种实现：演化形成的响应结构、个体学习形成的调节能力，以及能够反思和公开检验的知识。它们可能承担相通的功能，但不宜全部不加区别地叫作显式认知。

### 3.4 Gaia 可以作为共同生成的视角

论证不必先决定地球是否与一个细胞同属一种个体生命。生命改变环境，环境又影响生命，两者构成耦合的研究对象，这已经足以要求我们考虑共同条件。

Daisyworld 原始研究正是用简化模型研究这种反馈；它可以展示特定机制下的调节，不是地球必然自愈的证明。[Watson 与 Lovelock，1983](https://onlinelibrary.wiley.com/doi/abs/10.1111/j.1600-0889.1983.tb00031.x)

将 Gaia 作为理解关系的视角，有助于防止把环境当作无限外部资源。把它进一步视为一个必定会保护成员的超个体，则需要额外证据。

## 四、从 AB 到 ABC：新增结构怎样扩展有效可能性

作者指出，A 与 B 形成 C 后，现实已从只有 A、B 的结构条件，变成具有 A、B、C 的条件。这抓住了新生改变后来生成条件的机制。

严格表达时，最有用的对象不是宇宙中无限步可达的一切状态，而是此刻在时间、资源和环境中真正做得到的事情。沿用已有补篇：

\[
\mathcal E_{H,B}(x)=\{q:q\text{ 可从 }x
\text{ 出发，在期限 }H\text{、预算 }B\text{ 内实现}\}.
\]

### 4.1 一个需要注意的尺度区别

若 C 可以从 A、B 生成，而 C 又能生成 D，那么在允许任意长路径的同一模型里，D 原本就可能通过 A、B→C→D 达到。C 出现不必扩大那个抽象的无限步可达集合。

但 C 成为现实时，可以改变实现 D 所需的距离、时间、材料、风险和组织成本。一个此前无法在救援窗口内完成的任务，可以在设施、知识或合作网络已经建立后及时完成。因此，有效可能性的扩大仍然是真实变化。

### 4.2 生成扩展命题

考虑生成前后的 x 与 x′，使用相同含义的任务、期限和剩余预算。如果：

1. 原来可以完成的任务，在 x′ 中仍有实际可执行的方式；
2. 存在一项新任务 q，在 x 中不能于该边界内完成，在 x′ 中能够完成；

则：

\[
\mathcal E_{H,B}(x)\subsetneq\mathcal E_{H,B}(x').
\]

**证明：** 第一项给出集合包含；第二项给出属于右边而不属于左边的元素。∎

这个证明不要求枚举全部未来，只需要证明原有任务的保留关系，并找到至少一个新增能力的证据。生成成本、原结构是否被消耗、环境能否继续供给，必须计入实际状态；不能将 A+B→C 偷换成不付代价的 A+B→A+B+C。

这说明作者的直觉可以成为严格命题。限定条件的作用，是识别何时确实发生这种扩展，而不是取消生成的方向。

### 4.3 递归生成无需预知全部产物

可以研究 C 是否获得维持、是否能与后来出现的结构相互作用、是否能够参与生产或修复其他生成条件。生成规则可以在已有框架内反复执行；新发现则可以要求扩展当前模型的对象和规则。

我们可以预先约束资源、风险、必要保护和可纠正性，在过程中识别新能力，并继续检验它的后果。这是一套关于生成过程的研究方法，不需要先知道每一代产物的名字。

## 五、理解怎样成为实际能力的一部分

新结构能产生何种物理效果，与我们是否已经理解它，是两个相关问题。某结构可以在被发现以前发挥作用；认识会改变我们能否识别、组合、部署、维护和纠正它。

令 Π(m,e,σ) 表示在内部知识 m、物质环境 e、共同安排 σ 下能够实际执行的策略族。这里的执行包括资源、权限、技能、协作和反馈；知道一个方法的名字，并不等于能够执行它。

### 5.1 认知扩展能力的条件命题

如果一次知识或组织更新后，所有原来有效的策略仍能执行，又新增了一个能够完成原来做不到的任务的策略，则相应有效能力扩大。

这由策略保留与新任务见证得到。重要的条件是新知识能进入行动，并且其成本和后果没有破坏所比较的能力。错误知识、无法承担的学习负担、被锁在少数人手中的知识，都不保证这样的扩大。

Kolchinsky 与 Wolpert 通过干预系统与环境之间的信息关联，研究某些关联对系统维持的因果作用。这为知识不能脱离环境评价提供了形式研究背景；其存续度量不等于本论全部生活价值。[Kolchinsky 与 Wolpert，2018](https://arxiv.org/abs/1806.08053)

因此，“知识是一半，环境是另一半”可理解为两者共同构成能力，并不需要给它们规定各占 50% 的数值。科学积累、教育、公共设施与合作规则，可以一起改变后来能够做出的选择。

### 5.2 判善恶必须连接方向与证据

“用善恶区分真实生成和透支未来”可以表达为：先说明哪些生活与共同生成条件具有保护理由，再用证据判断具体过程是维护、修复还是损害它们。

善恶尺度决定为什么值得关注；对实际依赖的认识决定具体事情应如何判断。若仅把“好的生成”解释成“善的生成”，而不提供观察和因果判断，这两个词会互相解释而没有实际内容。

可用的观察包括维护是否赶得上损耗、人的健康和行动能力是否改善、相关代价由谁承担、反馈是否真实到达、错误是否可修正，以及后来者能否接续。它们需要在情境中解释，不是一个固定指标清单可以自动替代全部判断。

## 六、智能与权力也是可塑的机制

### 6.1 将目标和预期纳入状态

“权力可能拒绝退场”是一种需要解释和干预的机制可能性。它可以来自对权力本身的追求，也可以来自对他人的不信任、对交权后报复的担忧，或“只有我掌权才能保护共同目标”的判断。后几种情况即使不以权力为最终价值，也可能产生持续控制。

这些都要求考察内部模型、共同预期和真实保障。形式上可以写为：

\[
Z_t=(e_t,m_t,\sigma_t,k_t),\qquad
a_t=\pi_{\theta_t}(Z_t^{\mathrm{可获得}}),
\]

\[
(Z_{t+1},\theta_{t+1})=
\Phi(Z_t,\theta_t,a_t,d_t).
\]

其中 k 表示可用能力，θ 包括政策与目标表征的可变参数；m 是主体模型，σ 是共同规则与预期。观察仍受限，Φ 也需要实际建模。这一结构允许理解、目标、环境和规则共同变化。

因此，固定的“必然争权者”不应成为不加检验的默认人性。治理既可以改变收益与权限，也可以改变真实的不安全、交接能力和相互预期。

### 6.2 认知改变必须有环境支持

如果交权确实导致基本安全丧失，只要求个体相信别人，不能构成可靠改善。如果实际交接条件已经改变，而主体仍受错误预期支配，公开证据、实践经验和学习可能改变判断。

例如，假想组织可以同时安排可信的职责交接、真实的成员保障、可核验的行为记录、对临时权限的期限限制，以及不依赖掌权者单方解释的复核。它们分别作用于能力、物质条件、共同预期和权力反馈；具体效果需要检验。

“塑造认知”也受同一伦理约束：操纵证据、剥夺异议或制造一致表态，会侵蚀主体判断与共同认识。因此，共识的评价应包含形成方式、可反对性和实际后果。

### 6.3 与 Meta-Attractor 的关系

Meta-Attractor 由此同时成为诊断与干预对象：哪些理解受到奖励，什么实际处境使某种理解看起来合理，获胜者如何改变后来可见的证据，以及什么安排能使修正被保留和传播。

可以塑造这些可能性，并不意味着一定存在无代价的解决方案。资源冲突可能仍然存在。但我们应先允许模型、主体和制度改变，再判断哪些冲突仍不可避免，不能把当前机制产生的选择当作唯一可能的选择。

## 七、“Pareto 前沿积分”的可用解释

这个想法指出：评价应沿时间追踪多个生活与能力维度，并把选择对以后选择条件的影响纳入比较。它可以得到形式表达。

### 7.1 先对可执行路径作跨时评价

设 π 为依据实际可获得信息行动的策略，Zₜ^π 为它产生的轨迹；D 为明确的评价维度集合，q_d 为各维度的表示。选定有限期限 H、非负时间权重 w_d，并在预期有定义时，写成：

\[
V_d(\pi\mid\mathcal I_t)=
\mathbb E\left[
\int_0^H w_d(\tau)q_d(Z_{t+\tau}^{\pi})\,d\tau
\ \middle|\ \mathcal I_t
\right].
\]

这得到一个向量 V，而非先将不同人的生活与所有价值压成同一个分数。期望需要说明所依据的模型与概率；缺乏可辩护的单一概率时，可以分别比较多个模型下的向量、区间或稳健结论。

先限定符合已说明保护要求与风险约束的可执行策略，再比较向量：

\[
\pi\succ\rho\iff
[\forall d,\ V_d(\pi)\ge V_d(\rho)]
\land[\exists d,\ V_d(\pi)>V_d(\rho)].
\]

这给出“跨时多维评价后的 Pareto 比较”。它与直接计算 Pareto 前沿的面积并不相同；后者还需要坐标尺度、参考点和测度。当前解释保留作者关注的跨时关系，同时避免在名称中隐藏这些选择。

### 7.2 两个可以证明的性质

**积分保持同向改进。** 在同一明确概率模型下，若 π 在每个评价维度、几乎所有相关时刻都不劣于 ρ，非负权重下的期望积分也不劣。若某维度的加权差具有严格正的期望积分，则该维度严格改善。证明来自积分与期望的单调性。

**保留旧策略的扩展不减少可达评价集合。** 若知识、设施或协调更新允许继续执行每个旧策略并取得相同评价，又增加新策略，则旧的可达评价向量集合包含于新的集合。这里不能声称旧 Pareto 前沿必是新前沿的子集：原来的前沿点可能被更好方案支配。

这两个性质都具有实际条件，不保证学习总是免费，也不保证评估维度已经选对。

### 7.3 必须保留的判断

不同时间的利益如何比较，不能由积分符号自行决定。不可逆损害、基本地位和某些风险也需要路径约束，而不能允许大量后期收益自动抵消。H 之后的责任需要终端条件或接续安排，不能在计算窗口外消失。

还不能在每个时刻分别挑选一个最优前沿点，再拼成现实中无法执行的历史。比较对象应是可共同实现的策略和路径。

若方案仍不可比，就需要需要程度、权利、负担和证据方面的具体理由，或继续研究能够改变可行集合的干预。作者强调的 situational 判断因此保留在方法内部；它不意味着凭信仰替代证据。

## 八、科学方法能够直接成为本论的方法资源

我们不需要重新发明如何根据观察学习。可以继承可检验假说、误差分析、独立核验、干预比较、预测检查和模型修订等方法。

不过，应区分同一模型中的参数更新与对模型结构、变量和备选解释的修订。Gelman 与 Shalizi 的研究明确讨论模型检查和模型修订，说明它们不能简单等同于给定模型内的贝叶斯确认。[Gelman 与 Shalizi，2013](https://arxiv.org/abs/1006.3868)

这意味着科学提供了可用的方法传统，并非对每个新情境都已有唯一无争议的改模指令。对生生不息论而言，工作可以具体化为：

1. 在行动前留下模型、重要假设、保护要求和预期后果。
2. 在行动中观察真实后果，允许他者提出遗漏与反例。
3. 判断偏差来自参数、遗漏变量、因果结构、目标表示，还是制度过滤。
4. 修订模型、行动或制度，并比较修订后的实际表现。
5. 保存修订记录，保护提出有效纠正的人及其工作条件。

前四项可接入既有科学实践；第五项把科学方法放回它依赖的社会环境。Meta-Attractor 进一步追问：如果系统持续奖励拒绝上述修订的人，方法为什么还能有效运行？

## 九、演化：维持、生成与选择规则共同变化

把进化概括为弱肉强食，会遗漏合作、构成关系和环境改变。作者强调的系统维持与新生，是值得明确建模的内容；但不能因此将自然选择与它们设为互相排斥的解释。

选择可以作用于合作实践及支持合作的结构。Powers、Penn 与 Watson 的模型研究了社会行为与群体结构共同演化：合作机会可以影响支持合作的结构如何形成。这与本论把规则纳入生成过程的方向相接。[Powers 等，2011](https://arxiv.org/abs/1208.0482)

这里可以提出有条件的方向判断：在所研究环境中，能够维持生成条件、并使这种维护机制得到传承的组织，具有某些继续生成的机会；若相关差异进入存续和传播，演化就可能积累相应结构。它不是一条每步复杂度增加或所有个体趋向公共善的定律。

一个需要保留的实证边界是：Sanchez 与 Gore 的酵母研究中，部分小种群即使合作相关等位基因频率持续增加，仍然崩溃。这说明维护趋势、维护速度和共同条件能否撑到修复完成，必须一起分析。[Sanchez 与 Gore，2013](https://journals.plos.org/plosbiology/article?id=10.1371/journal.pbio.1001547)

因此，本论最有力的推进是：生命可以通过演化形成维持和调节机制；具有反思能力的生命与智能，还可以研究这些机制，在损害成为淘汰结果以前改变行为和规则。向善由此可以成为对生成方向的主动认识与实践，而不必期待所有错误都会被历史及时纠正。

## 十、从现有生生不息论重建完整主线

现有原稿中的词语可以承担明确的功能：

| 原有概念 | 在本轮推导中的位置 |
| --- | --- |
| 象 | 能改变后来过程的实际结构，包含材料、制度与观念 |
| 像 | 对结构的表征；它自身也进入因果过程 |
| 理 | 结构形成、维持、相互作用与失效的条件关系 |
| 生生 | 生成的结果再次参与生成，并更新相应条件 |
| 智 | 在具体情境中判断后果、限制与生成方向的能力 |
| 教 | 环境、奖惩和共同实践持续塑造认识与行动 |
| 善恶 | 对生活、生成能力、共同条件及纠正能力的支持或毁损的评价，包含理由与责任 |
| 治、势与 Meta-Attractor | 行动结果怎样改变后来策略、认知与规则的生存条件 |

由此，主线可以逐步表达为：

1. 生命及认识者由世界中的生成形成，并继续依赖具体条件。
2. 条件变化对其生活、行动和更新具有实际利害；相关区别能够被研究。
3. 认识者可以改变自身及他者的条件，因此判断需要覆盖重要依赖和后果。
4. 新结构与新理解可以扩展有效能力；成本、替代与损害决定实际方向。
5. 未来结果无法被当前模型穷尽，因此持续观察与修订属于生成实践的组成。
6. 模型、目标与共同规则也会被行动改变；制度应使可靠认识与维护共同条件的实践能够持续。
7. 公共评价进一步要求说明受影响者的地位，不能仅因删除某人便有利于当前胜者而排除其基本利益。
8. 对具备相应能力并影响共同条件的智能，向善具体体现为：支持有价值的生活与共同生成，维护观察、纠正和再次形成新能力的条件，并接受同样的检验。

第七步仍需要公共理由的独立论证；它既不是宇宙之外任意加入的命令，也不能被前六步的因果关系无声代替。把“系统健康”称作一种功能上的善，可以有明确客观依据；从这里走向完整公共伦理，还要处理各生命的地位与冲突。

这套起点可以支持跨尺度的条件关系，而不要求所有尺度具有相同目标、器官、制度或寿命。它也不要求生命先理解全部规律才能行动。反思性智能的特别之处，在于能够把自身的模型与行动一并置于观察和修订之中。

本轮因此将前次审计的判断推进为：**现有生生不息论已经具有认知、生成与制度塑造的连接资源；研究应把它们落实为可检验的关系和有前提的推导，继承科学方法，在具体情境中持续形成较好的认识与行动。**
