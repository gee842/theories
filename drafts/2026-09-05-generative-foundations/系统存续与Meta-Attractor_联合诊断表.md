## 3. 检查局部是否能够共同成立

- 分别可行的计划，是否争用同一资源、注意力、时间或基础设施？
- 所有人同时采用这一做法，重要条件是否还能补足？
- 所谓整体改善，是否掩盖某些人的基本生活或地位受损？
- 抽象指标是否删除了会改变判断的差异？提出的干预在现实中能否执行？
- 本期成功是否依赖下一期承担未说明的成本？届时谁还有能力处理？

| 规则反馈：获益者能否改变评价、证据入口、责任和退出条件 |  |
| 反向补充：训练、独立核验、保障或其他机制能否抵消侵蚀 |  |
| 改判条件：什么观察会证明我们的循环假说不成立 |  |

分别标注“已观察到”“有依据的推断”“尚未知”。相关性不自动证明因果；没有规则反馈证据时，不强称完整的 Meta-Attractor。

## 5. 区分三层问题

**直接损害：** 已经发生或有充分依据预见的伤害是什么？

**纠正受损：** 哪些发现、表达、授权、修复或退出能力被削弱？

**侵蚀者被选择：** 削弱这些能力的做法是否更易留下、扩散并改写规则？

同时记录独立的规范判断：即使实施者能够长期维持，这项安排是否仍无正当理由地剥夺他者？不能以“尚未崩溃”作为无害证据。
