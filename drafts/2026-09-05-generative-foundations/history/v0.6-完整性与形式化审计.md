# v0.6 完整性与形式化审计

2026-09-05。审计对象：[WHITEPAPER-v0.6.md](WHITEPAPER-v0.6.md)、三份 Lean 源码及其检查记录、论证来源与相关补篇。本文件独立保存，不改写白皮书或旧稿。本次核对现有源码与成功检查记录的 SHA256，未重跑未修改的证明。

## 一、直接判断

**主题覆盖已经较完整，核心论证尚未全部闭合，形式化只完成了部分结构结果。** 当前版本可以作为供研究、讨论和批评的理论白皮书；还不能称为已经从统一公理体系推出全部结论、完成经验验证的论文。

主要问题不再是缺少更多原则，而是几个关键连接仍由文字承担：物理生成如何形成可再生的能力；个体的功能利害如何支持公共规范；相互依赖的主体如何实际执行共同可持续的行动；规则、认知与反馈如何使这样的实践能够持续存在。

**情境性、跨尺度关系、模型更新和规则变化，都可以成为形式化的对象。** 但“能够形式表达”“已经证明”“现实中可以计算”“模型真实”“伦理理由成立”是不同要求。本版不能把其中一个当作其余几个的完成证明。

本审计按对话中的核心主张与当前正文检查主题覆盖；没有把全部历史版本逐句建立溯源对应。因此，“主题较完整”不等于已经证明每一段历史表述都被完整保留在最新正文中。旧的 29 条原则对应表仍可用于追溯主题，但其章节定位需要随新版重新核准。

M1—M3、G3—G5、H1 等目前主要是有明确假设的纸面数学。把它们继续纳入证明助手具有可行性；但即使全部检查通过，也不会自动补齐公共规范、模型真实性及现实实施之间的连接。

## 四、最重要的六个未闭合部分

### 1. 对“保持”的形式化，比对“生”的形式化充分

当前数学核心给出状态空间 X、转移 T 和保护条件 S，再研究哪些状态可以持续满足 S。它很适合检查耗损、失去控制与约束冲突。

然而，你的核心命题还包含：**产生新的结构，并使这些结构成为后来新能力与新结构的条件。** 这一层不能仅凭“留在 S 内”体现。一个保持系统可以非常静止；一个产生很多不同状态的系统也可能只制造噪声与伤害。

下一步需要单独定义：什么算新增的有效能力；什么算能力的维持与再生产；什么只是名称变化、资源转移或未经兑现的承诺。形式对象可以包括结构、依赖、可实现的任务、生成规则与模型扩展之间的映射。

关键不是立刻选择某个数学流派，而是使如下区别可以在模型内被检查：新结构只消耗条件；新结构暂时补充条件；新结构能够帮助重新生产生成条件。还要允许前两种判断因新观察而修订。

这不要求所有可能性单调增加。停止某项有害活动、结束失效组织，可能保护更广泛的生成能力。正面生成关系需要与公共保护和具体生活价值相接，而不是退回“状态数越多越好”。

### 2. 从功能利害到公共伦理，还需要独立承担论证责任

当前已有三个层次：什么维持一个系统；什么有利于它的活动；什么能够对受影响者成立为公共理由。R3—R4 承担了第三层的关键工作。

**这不是要求被评价者同意评价。** 一个行为者否认损害或拒绝公共要求，不会因此使事实和充分的理由失效。需要继续论证的是评价根据本身：为什么他者的对应利益不能被排除；为什么当前有权者不能通过取消他者地位来证明自己正当；未来成员及不能发言者如何被代表。

这些关系可以形式化为规范前提、地位关系、义务与例外规则，再检查推导、一致性、前提独立性与反例。但把“他者具有地位”直接写成公理，并不等于已经说明了它为何有充分理由；把“善”定义为满足某些条件，也不能代替对那些条件的辩护。

有前提并不使论证软弱。需要检查的是：前提是否足够明确，是否可以独立辩护，是否暗中包含了想得到的全部结论，以及现实中是否满足应用条件。

### 3. 跨尺度的可行性，还没有变成多主体的实际可执行性

现有独立组合定理处理各自转移与行动可以分开组合的系统；现实中的共同资源、相互影响和行动冲突，需要另外处理。抽象实现定理则要求抽象行动确实可以由具体行动实现；它本身不创造这种实现能力。

这里至少有四个不同命题：存在一个共同可行方案；主体能获得选择它所需的信息；主体有能力联合执行；激励和权力安排使这种执行能够持续。证明第一个，不能省去后三个。

因此还缺耦合资源、部分观察、协调成本、偏离激励与模型误差之间的统一关系。否则，“每个局部都对齐”与“整体会安全”，“理论上有正确行动”与“现实能采取正确行动”之间仍会断开。

### 4. Meta-Attractor 尚缺从机制到长期结果的完整推导

v0.6 已表达规则选择策略、胜者改变规则、奖励改变认知，以及证据渠道也会被塑造。当前线性模型检查了特定反馈的局部失稳条件；选择恒等式刻画一轮分布变化；H1 展示特定反馈规则可以让成绩和确信提高，而真实损害被过滤。

这些是不同的结构结果。尚需把它们连接到一个明确模型，并分析在什么条件下某种长期趋向形成、能够维持、被扰动打断，或者被纠正机制改变。

特别是，“维护共同条件有益”不会自动变成“维护者获得选择优势”。共同收益可能被搭便车者同样获得；纠正可能太晚；纠正机构本身可能受到俘获。真正有行动价值的结果，应说明哪种规则改变了这些反馈，以及修正规则的人为什么仍受有效约束。

不能用“存在一个环”代替吸引子证明，也不能用特定参数下的演示代替实际领域的因果识别。

### 5. 三层现实已经进入，但表征与检验接口还不充分

把物质状态、主体模型和公共规则写成相互更新的函数，明确了研究对象。然而，写下函数名还没有确定函数本身。

需要进一步区分：现实中的损害；主体得到的信号；公共记录如何筛选信号；主体如何更新认识；人的实际感受和能力怎样变化。模型准确率、满意度、共同赞同和实际生活，不应互相替代。

这些关系可以分别建模，也可以使用不完全测量、多个指标和不确定范围。形式化人的某些体验关系，并不等于已经穷尽体验；缺乏一种完整测量，也不意味着体验不能进入伦理理由。智能系统的内部模型亦不能直接当作其具有主观体验的证明。

此外，理论自身也属于这三层循环：它可能获得认同、资源与制度影响，并开始选择支持自己的证据。因此，对理论的反例、修订权限和受影响者反馈，需要成为研究与组织的实际制度。

### 6. 从方向到困难决策、转型与组织运行，仍有实质空缺

当前保护条件与严格改进关系能排除一些明显有害方案，但不能处理所有利益冲突。当没有任何方案同时满足全部保护时，正文给出举证、替代、减害与补救要求，尚未形成更细的判断程序。

需要区分最低条件与可权衡利益，明确紧迫程度、证据负担、不可逆风险、责任与代表机制。允许结论暂时不完备，可以比强行总分更准确；但“不完备”不能成为始终不作决定的借口。

原 Speculative Future 的三个难题仍然重要：制止确定破坏者的权力如何受到限制并能退场；退出恶性竞争的人如何在转型中继续生存；提供真实退出所需的资源如何避免成为新的控制工具。当前文本承认它们，没有解决它们。

一份有力的组织理论还需要说明资源、权力、纠错和转型的实际安排。论文所提供的认识和规范支持，也不能自动替代成员与受影响者的授权。

## 五、“都可以形式化吗”需要怎样回答

| 所问的“形式化” | 判断 |
| --- | --- |
| 把主要概念、依赖和判断前提明确表达 | 核心部分大多可以继续做；其中也会发现需要拆分的概念 |
| 在给定模型和前提下证明结构命题 | 可以；本版已完成一部分 |
| 把情境、观察局限、反馈、规则和目标变化纳入模型 | 可以；不能仅以“情境性”为由排除形式化 |
| 用机器检查规范前提到结论的推理 | 可以检查已明确表达的推导；不会自动提供规范前提的正当性 |
| 证明模型正确描述现实 | 不能只靠模型内部证明完成；需要观察、干预、测量及替代解释的比较 |
| 把所有冲突化成一个总分并得出唯一答案 | 本框架没有证明其必要性或可行性，也不以此为目标 |
| 一次性形式化所有未来情境并给出可部署的通用判断器 | 当前没有这种结果；本审计也没有给出证明它普遍不可能的定理 |

例如，可以写出情境判断 J(a,c,I,H;N)。但这最初只是接口：还须说明行动、情境、受影响者、时间与规范的类型，J 是许可、禁止、风险还是比较关系，以及输入改变时哪些结论仍然成立。

同样，可以形式化“模型会更新”，但仍需说明更新允许改变什么、怎样保留已得到理由支持的保护、如何发现遗漏的新主体与风险，以及谁能改变判断标准。**可修正的形式化本身，正是本理论应该研究的对象。**

不需要借助“哥德尔不完备”或“世界太复杂”来笼统拒绝这项工作。本次审核得到的是当前模型和证明的具体缺口，不是针对所有可能形式系统的普遍不可能性结论。

## 六、如何把“系统奖励毁损自身的行为”串成有力论证

下面是一条适合优先完成的证明路线，**不是宣称现有代码已经完成了整条链**。

令 Bₜ 为某项共同必要条件高于临界线的有限缓冲，Dₜ 为把补充、维护成本与损耗全部计入后的净消耗。若在所分析路径和期限内：

\[
B_n=B_0-\sum_{t=0}^{n-1}D_t,
\]

则一旦累计净消耗超过 B₀，就不能继续保持 Bₙ≥0。若每步 Dₜ≥ε>0，并且相应过程持续，则任何 n>B₀/ε 都不能保持这一条件。现有 C1—C2 已检查其非负整数缓冲版本。

接下来还需要证明或用证据支持：

1. 这项条件确实是所声明成员和期限内不可替代的必要条件；不是选错指标，也没有漏计可行替代。
2. 现有奖励、认知和规则更新，使相应净消耗持续或使其累计达到失效阈值，而非仅在某一步出现损耗。
3. 反馈和干预未能在阈值前恢复条件；如果可以恢复，必须将修复成本、所需时间与执行能力计入。
4. 受影响者确实失去有公共保护理由的基本利益；存在相称、可行的替代或预防方式，并审查相关相反理由。

前面三项可以建立系统性不可持续或风险结论；结合第四项及 R3—R4，才能得到相应行为或制度具有非善性质的规范判断。追究具体人的责任，还要另看其知识、能力和选择空间。

这条论证的力量在于指出实际机制与必要条件，而不是要求毁损者承认它，也不需要证明每一个获益者终将获得完全相同的个人报应。

反方向同样需要完成：一个修复方案即使立即改善 B，也可能耗尽维修者、压制异议或形成不可撤回的控制。应当对修复行动本身使用同样的条件、选择和认知分析。这才把“维护生”推进到“维护生能够继续生成和修正的条件”。

## 七、下一轮应当怎样收束工作

### 第一优先：建立主张与证明的逐项对应

每项中心主张应记录原始表达、严格改写、对象、量词、前提、正文推导、代码位置、适用边界、经验输入、反例和当前状态。保留作者原意与收窄后的定理之间的差别，而不是悄悄把弱结果当作原主张的全证。

对八类存续条件，逐项判断它是定义、在何种系统类别中的必要条件、常见实现方式，还是待检验的经验主张。对 R1—R4，则分别检查其独立理由及删除某项后还能得到哪些结论。

### 第二优先：完成三个连接，而非扩充更多并列原则

一是从结构产生到生成能力再生产的正面模型；二是从共同依赖和基本地位到公共判断的清晰规范推导；三是从可行的共同方案到认知、激励和制度能够持续执行的动力学模型。

三层现实和 Meta-Attractor 应进入这三个连接的内部。否则它们虽有各自章节，仍可能只是附加解释。

### 第三优先：把关键纸面结果机器化，并做一个完整应用

优先选择真正支撑主链的结果：耦合约束与可实现性、反馈维护、模型更新和选定的选择机制。继续证明小型反例仍有价值，但不能用容易增加的定理数量替代关键连接。

一个完整应用应从实际问题开始，明确主体和依赖、公共保护理由、三层反馈、资源与规则、可能干预和反证条件，再检查观察结果是否支持诊断。现有文献与假想案例可以提供背景，不能冒充这一应用已经完成。

### 完成标准

作为下一版核心论文，至少应做到：中心概念稳定；中心结论都能追到明确前提；关键形式模型之间有接口；规范与经验输入可识别；主要反例得到处理；至少一个应用能够让他人重复检查。未解决的治理问题可以明确保留，但不能再被放进“已经推出”的结论中。

因此，当前最准确的定位是：**理论主线和主题覆盖已经形成，部分形式核心可靠可查；要获得你要求的完整推理力量，下一步应补齐生成、公共规范与实际反馈执行之间的连接。**
