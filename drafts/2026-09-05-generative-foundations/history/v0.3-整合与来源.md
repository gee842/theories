## 二、整合结构的改变

v0.2较多讨论优势改写规则，以及这种反馈为何可能损害共同条件。v0.3增加中间最重要的一层：系统不仅选择行动，也选择哪些认知实践能够获得保留、资源、传播和规则影响。认知因此不是始终独立于被研究系统的外部裁判。

新的主线是：

> 奖励与生存条件 → 行为与认知的选择 → 资源和解释权的分布 → 标准与环境的改变 → 下一轮选择；同时考察这一循环对共同生活和纠正能力的影响。

善恶判断保留基本保护要求，并增加对这个循环的诊断。行动可以产生混合效应，应逐项说明；不将“吸引子”当作新的善恶标签，也不以系统复杂为由回避明确伤害。

## 四、本次新增的实质内容

### 1. 三种认知变化

区分群体或方法的选择与替换、个体内部的学习适应、以及解释进入规则和基础设施的固化。不能把这些不同机制混成“所有人都变坏”，也不能以观点直接推断动机。

### 2. M3选择协方差

在明定比例、正保留权重与一轮内固定特征的条件下，正文给出平均特征变化等于选择协方差除以平均权重的恒等式。其作用是说明需要测量什么，而不是把人固定分类或把现实认知压成一个善恶分数。这属于已有数学家族，本次提供纸面推导，未新增Lean证明。

### 3. 共同现实的递归作用

若一个系统降低发现和表达不利事实的能力，它可能同时降低修复其他损害的能力。诊断因而需要区分问题减少与报告受阻，并给出独立证据和不同解释。

### 4. 从一次结果到下一轮选择

第十一节加入行动如何改变参与者、奖励、规则权力和后续路径的比较，提供八步流程、结论写法与一个完整假设案例。同样的风险报告要求，在不同奖励与责任条件下，可以产生不同的认知选择方向。

### 5. 对改善方案与诊断者作反身检查

反向结构必须有维护、补充和传播的实际条件；同时不能将支持变成忠诚奖励，将评审变成正统审查。诊断者自身也须保留反例与改判机会。

## 五、保留的限定及其用途

| 需要限定的表达 | 本版的处理 |
| --- | --- |
| 某种正反馈存在，所以已证明Meta-Attractor | 区分反馈假说、吸引趋势和严格吸引子；给出证据强度 |
| 市场、国家或AI本身就是某种坏吸引子 | 定位具体奖励、权力转换与后果，不按名称判断 |
| 控制总会降低信任 | 检查实际控制与反馈关系，也允许可问责控制改善信任的反证 |
| 竞争必然筛掉诚实与整体关怀 | 以实际选择权重和制度条件检验；允许好的认知获得稳定支持 |
| 模型预测实现，所以模型具有普遍正当性 | 区分预测影响结果、事实准确与规则的规范判断 |
| AI必然指数增长，制度必然线性调整 | 作为情景假说，使用具体增益、延迟与纠正能力 |
| AI进入某行业必然产生单一后果 | 比较部署、分配、劳动与反馈条件，不仅看行业标签 |
| 公共或分布式结构自动构成counter-attractor | 检验其资源、实际退出、问责、替代与规则控制 |
| 长期系统诊断可以覆盖眼前伤害 | 保留基本保护要求，长期图景仍须接受证据与相称性检查 |

这些限定使方法可以被反驳、修正和用于决策；它们没有取消对明确剥夺和封闭机制的规范判断。
