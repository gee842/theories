# 智能向善，天下生生

统一版宣言 v1.0·供发起讨论  
2026-09-05  
思想与立场提出：Ren；整理与文字协作：AI。本文为尚未公开发布的讨论稿，不代表任何组织已经成立、获得公共授权或有人已经签署。

我们希望生活在一个值得继续生活、也有能力继续发展的世界。人在其中能够学习、创造、相爱、照料、休息，理解自己的处境，并参与决定共同生活的方向。儿童、老人、需要帮助的人，以及暂时无法参与生产的人，都在这个愿望之中。一个人的价值，不以他尚未被机器替代、能够创造多少收益或拥有多少力量为条件。

这个愿望有现实的根基。我们由世界中的变化与生成而来，也一直由共同条件托举。身体依赖食物、水、能源和生态；成长依赖照料；理解依赖语言、经验与知识；自由依赖可信的关系，以及能够学习、拒绝和重新开始的实际条件。我们自身是系统，也是更大系统的一部分。我们改变环境，环境改变我们；我们的行动，又成为他人和后来者生活的条件。

因此，发展应当同时对生活及其生成条件负责。若一种增长耗尽健康、土壤、信任或人的判断能力，即使账面成绩上升，它仍可能正在消耗使自己成立的世界。若一种稳定依靠永久压低一些人的生活、封锁他们的表达，也不能只凭持续存在获得正当性。维护共同条件，需要看见其中具体的生命；关照具体生命，也需要看见托举它们的共同世界。

我们以**生生不息**表达这条方向：让有价值的生活能够展开，让已经形成的能力参与后来能力的形成，让共同世界能够维护、修复、认识和更新自身。新的知识、关系、设施与创造，可以使以前做不到的事情成为现实；它们的意义，要在实际能力及其后果中辨认。新生也可能带来损害，因此创造需要观察，判断需要证据，方向需要在行动中不断得到理解。

未来不会以全部已知的形式等待我们。每一次生成都可能改变后来能够发生什么，也可能改变我们理解它的方式。保护未来，包含对当下生活的珍重，以及对后来者继续理解、选择和创造的关照。今天的人并不是未来的耗材，未来的人也不应成为今天计算之外的空白。面对代价与冲突，我们需要尽可能可靠的知识，诚实比较能够实施的路径，说明负担，并寻找能够改善选择条件的新理解和新安排。

善恶由此进入具体的关系和后果。维护生命与基本地位、增进真实能力、修复共同条件、使错误能够得到认识和纠正，为行动提供善的理由。没有充分理由地制造严重损害，把利益留给自己而将代价转移给缺乏力量的人，并进一步破坏他们申诉和修复的能力，应当受到明确反对。判断不需要得到破坏者认可才成立，但必须能够说明事实、理由、责任及改变的可能。

我们愿意同时面对三个相互联系的现实：主体的生活、感受与内部理解；主体之间形成的语言、信任、规则和共同认识；物质世界中的身体、资源、结构与实际后果。我们总是通过有限的视角接近它们，这要求持续核验。人的感受不能被漂亮的统计抹去，共同确信不能使错误事实变真，物质成果也不能自行证明生活与判断已经改善。

认识本身会改变世界。想法影响决定，决定进入行动，行动改变环境，环境又塑造想法和共同预期。对于智能，这意味着内部模型、与其他主体的交流，以及环境反馈必须一起被研究；具有内部表征也不等于已经证明它具有人的感受。对于人，这意味着教育、奖惩、关系和真实处境都在持续塑造判断。知识需要环境成为能力，环境也能够通过理解和行动得到改善。

我们因此反对将争夺、支配或不信任当作不必解释的命运。一个人可能因害怕失去安全而抓住权力，也可能因相信别人只能竞争而拒绝合作。改变这些行为，需要同时改变认识、可信承诺和实际保障。共同理解可以发展，目标也可以接受反思。形成共识的过程应允许质疑、核验和退出，使人能够理解并参与，而不是通过操纵证据或制造依赖取得服从。

当一个系统奖励某种行为，它也在决定哪些实践、认知和人更容易留下来。优势者又可能改写规则，筛选证据，并把自己的胜利解释为真理。我们以 **Meta-Attractor** 研究这种自我强化的二阶动力：行动改变了后来行动的选择条件。诊断需要问，谁因维护共同世界而承担成本，谁因转移损害而获得优势，哪些意见能够进入决定，哪些错误正在失去被纠正的机会。

市场与竞争可以承担协调、发现和创造的作用，也需要接受共同后果的检验。利润不能自动计入所有外部代价，胜负不能自动判断一切价值。若规则使侵蚀共同条件的行为更有优势，仅仅要求人善良是不够的。需要让维护、诚实、照护和合作获得能够接续的资源，使正视问题的人仍然有能力生活和行动。改变规则的人，也必须接受同样的约束。

科学、理性和道德在这里承担相互支持的工作。科学帮助我们检验世界实际怎样运行，理性要求理由能够被追问，道德使他人的生活与共同后果进入决定。我们愿意留下假设、比较解释、承认未知、检查失败，并在必要时修订自己的模型与立场。对于已经掌握力量的人，成功之后继续允许反例改变决定，是尤其重要的责任。

人工智能使这种责任更加具体。它可以帮助人理解复杂关系、改善照护与公共服务、减轻被迫劳动、积累共同知识，也可以加速争夺、操纵和依附。能力增长应当伴随理解后果、发现损害和采取有效纠正的能力。不能把人类尚未解决的竞赛，直接变成智能无需检验的永久目标；不能在声称帮助人的过程中，使人失去理解、拒绝和参与的真实位置。

因此，我们主张**智能向善，智能普惠**。智能应当支持有价值的生活与共同生成，增强人和社会的判断、照护、合作与修复能力。用途、收益、风险和控制方式应当接受受影响者的追问，错误应当有实际纠正的途径。更高的能力可以带来更广泛的后果，也意味着与之相称的责任。以人为本保护人的基本地位，同时保持对其他生命及可能具有道德相关利益的存在者的认真关照。

**人类命运共同体**在这一意义上来自共同条件与共同后果。文化、国家与生活方式可以不同，生态、知识、安全和许多风险却彼此关联。各方维护自身生活的努力，需要正视这种关联，并形成可信的合作与合理分担。共同责任不要求所有人接受同一套生活方式，也不能成为任何中心无限支配他人的名义。

我们以**大同**表达可以持续接近并不断充实的方向：基本生活得到保障，力量能够被问责，冲突有协调与修复的道路，多样的生活能够相互尊重、共同发展。共同富裕为这些自由提供物质与社会条件，使技术所释放的能力成为获得健康、时间、教育、安全和公共参与的真实机会。这个方向的意义，体现在当下能够看见的改善，以及后来仍可继续生长的空间。

我们提议以“至善”为拟议名称，探索一项共同工作，连接未来研究、AI 安全、系统诊断与具体实践。它需要研究者、工程师、教育者、照护者、艺术家、社区实践者及受影响者的不同经验。参与可以从一个清楚的问题、一项可核验的研究或一次有责任边界的合作开始。组织是否值得信任，要由实际工作、公共理由及有效授权逐步证明。

这项工作首先接受自己的原则。成员的生活不能被使命耗尽，资金与声望不能决定哪些事实允许出现，提出异议的人应有真实的回应渠道。重要决定需要说明理由，权限需要边界，临时权力需要结束安排，项目需要能够修订、交接或停止。理论作者、发起者和未来的任何负责人，都不能以善的名义免除自身的责任。

我们愿意共同学习怎样更好地生活，怎样使创造继续创造，怎样让力量伴随理解与关照。我们珍重现在，也愿为后来者留下继续生成的条件；我们承认差异，也愿在共同世界中发展能够合作的认识。让每一次进步，都经得起它所影响的生活、关系和未来的检验。

**智能向善，天下生生。**
