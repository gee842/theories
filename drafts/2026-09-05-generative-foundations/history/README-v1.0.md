# 生生不息统一版 v1.0

2026-09-05。第一份将现有理论、形式核心和最新认知／生成推导重组为同一论证的研究版本。文件尚未对外发布，旧版本全部保留。

## 主文与宣言

- [生生不息：智能向善的生成论基础](WHITEPAPER-v1.0.md)：十二章、三个附录，约 6.64 万汉字。包含正文论证、公式、反例、行动方法、组织程序、研究边界与来源。
- [智能向善，天下生生](宣言-v1.0.md)：约 2,670 汉字。面向公众表达同一条理由与承诺，供发起讨论。

## 阅读路径

首次整体阅读，可从白皮书摘要、第一章与第四章进入，再读第六、八、九、十章和结论。关注形式推理，可重点读第二、五、七、八章及附录 A。关注组织实践，可读第十一章，再检查它如何接受第四章的公共要求和第六章的选择机制分析。

白皮书目录可跳转到各章。附录 A 逐项对应 28 个已有机器检查定理，并区分新的纸面推导；附录 B 对应 Speculative Future 的 29 条原则；附录 C 列出作者材料与研究来源。

## 本版范围

本版将“新结构成为新生成条件”、知识与环境共同形成能力、主体与目标的可塑性、三层现实、跨时 Pareto 比较和科学修订接入主文。组织章节进一步提出保护条件如何形成、谁能异议、怎样暂停和修订的程序框架；其中角色与首项研究仍是提案，未宣称已经实施或取得授权。

形式证明代码未修改，已核对与成功检查记录一致。新命题 P1—P4 等为明确前提下的纸面推导，未冒充新的机器证明。实践诊断和首项应用尚未完成实证验证。
