# No assumptions, no axioms: a rule for every agent

6 October 2026, 20:43–20:44 UTC. Source: Ren's two messages in the Claude project chat. The quotations are Ren's wording; the context is AI-authored.

Ren quoted a list that the thread working on the process law had posted as "Still assumed":

> * the requirement to arrive knowing both values;
> * the unknown start;
> * the cell count, which is read from the Python source rather than proved;
> * the 3 to 8 bound.

and wrote:

> This is a problem, we should have no assumption, no axioms

followed by:

> this should be a rule that every agent knows

This restates the earlier [no-assumptions directive](2026-10-06-no-assumptions-directive.md) as a standing rule for all work in the project. The project's coordinating session read it as: every input a result relies on must be derived in Lean from the process or proved necessary for the stated claim, and Lean axioms count among the assumptions. The [dependency map's ledger](../../_process/research/2026-10-05-generative-foundation-review/root-foundation/PROCESS-LAW-ENTRY-DEPENDENCY-MAP.md#7-no-assumptions-ledger) tracks each input against this rule.
