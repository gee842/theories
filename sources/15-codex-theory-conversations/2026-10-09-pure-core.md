## Operational reading — AI-authored

The core is the foundation (`GenerativeCore`, `InquirySufficiency`, `RelationalRenewal`) together with the spine layers `BecomingFrame`, `BecomingModal`, `BecomingRenewal` and `MetaethicalCore`. It must satisfy three conditions:

- its import closure is exactly these modules;
- every declaration in that closure has an empty axiom report;
- the closure compiles from Lean's prelude alone.

The [spine checker](../../experiments/integrated-correction/general-framework/generative-basis/lean/becoming/check_becoming.py) enforces all three on every run. The foundation's `import Std` line is vestigial and stays. Removing it would change L0's bytes and invalidate the receipts of every module built on it, so the checker instead compiles the core with that line removed.

The periphery may use whatever tool fits: Mathlib for real analysis, Python for builds, data and numerical work. A new mathematical proof claim still needs an actual Lean check. Existing modules connect to the core through the bridge module `BecomingInstances`, and the dependency runs from them to the core. Mathlib is already installed: the existing checkers use the project in `~/repos/生生不息`, which `SYSTEMS_MATHLIB_PROJECT` can override.
