# Activity history and subsequent synaptic plasticity — primary source

6 October 2026. Source preservation for the [focused comparator review](../../_process/research/2026-10-05-generative-foundation-review/root-foundation/CONSEQUENCE-ORGANIZATION-COMPARATORS.md). This is one published empirical study, not a new experimental cohort or reproduction.

Hulme, Jones, Ireland and Abraham (2012), *Calcium-Dependent But Action Potential-Independent BCM-Like Metaplasticity in the Hippocampus*, Journal of Neuroscience 32(20):6785–6794. [DOI](https://doi.org/10.1523/JNEUROSCI.0634-12.2012); [primary PMC article](https://pmc.ncbi.nlm.nih.gov/articles/PMC6622209/).

The [original HTML](original/hulme-2012.html) was returned by PMC's `?report=xml` URL with HTML content type; it is not XML. [Figure 4](original/hulme-2012-figure4.jpg) and [Figure 6](original/hulme-2012-figure6.jpg) are exact separately retrieved PMC image bytes. Other images linked in the HTML are not locally bundled. The [reading edition](reading/hulme-2012.txt) is a normalized text extraction, not an original publication file. Do not infer missing visual details from it.

[Provenance](metadata/provenance.json) records requested/final URLs, HTTP status, retrieval time, headers, size, hashes, extraction method, bounded failed attempts and reading scope. Set-Cookie headers are deliberately omitted; document bytes are unchanged. The [manifest](manifest.json) binds package files, and [verification](verification.json) records local preservation checks. No raw electrophysiology data, supplementary archive or statistical reanalysis was obtained or performed.

The review contains the substantive interpretation. This package supplies traceability; preserving a source does not independently validate its causal claims.
