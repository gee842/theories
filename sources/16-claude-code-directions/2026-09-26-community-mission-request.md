## Ren — verbatim

我现在在组织中国的ai安全社区，已经有包括各个模型厂商的员工、政策治理研究，和学术机构。我们现在需要一个立场性文件，一个mission

我对我们的立场的理解：
人工智能向善，普惠
ai是一种“文明级”技术，不能被用于搞零和博弈，不能被拿来做军备竞赛
无论中美还是任何国家，个人，我们所有人的立场都是一致的，虽然很多人还无法意识到，但是最终的好的结果只能建立在合作，互信的基础上，我们必须以人类命运共同体的视角，而不是竞争的视角来斗争
ai应该创造一个幸福的未来，而不是让权力收敛，社会变得不稳定，不能让普通人因此失去未来
当下，为全世界共同建造一个满足所有人的necessity的基础设施，包括衣食住行，都可以通过自动化来解决，我们认为现在可以进行共产主义转型，至少技术基础满足，但是在协调和分配上，我们依然依赖市场，所以保证市场的稳健，并且在同时以commons，共享普惠的逻辑去发展ai，而不是让ai冲击，甚至摧毁市场，保证所有人的生活的基础上，逐渐走向一个共产主义，没有剥削的基础设施层，在ai发展的过程中逐步提升幸福，而不是在加速中导致社会创伤和混乱，是非常重要的
指数加速是不合理的，因为我们的组织方式和认知并无法跟上
科技，包括ai，并非好坏善恶，而是我们如何利用它
剩下的就是，把我的理论完整的融入进去
