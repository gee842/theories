## Pasted context (supplied by Ren in the same message; authorship unverified)

中国的"大同"表达大致可以分成几条线：经典文本、异端与民间、以及近代的重新激活。
源头：《礼记·礼运》
"大道之行也，天下为公，选贤与能，讲信修睦……是谓大同"。核心要素是公有（天下为公）、选举（选贤与能）、社会保障（老有所终、幼有所长、矜寡孤独废疾者皆有所养）、按需劳动（货恶其弃于地也，不必藏于己）。它和紧接着的"小康"（大道既隐，天下为家，礼义以为纪）构成一对，大同是三代之前的失落理想，小康是禹汤文武的现实秩序。值得注意的是这段文字带有明显的道家甚至墨家色彩，宋儒（尤其朱熹）一直怀疑它非孔子之言。
先秦同源异流

* 墨子的"兼爱""尚同"——尚同是政治上统一意志于天子，兼爱是伦理上无差等，这两者被后世视为大同的另一个来源。
* 老子"小国寡民"、庄子"至德之世"——一种去政治化、去文明化的大同，人与禽兽居而不知君子小人之分。
* 孟子的井田、王道，虽是小康路线，但"老吾老以及人之老"常被拿来与大同对读。

汉代：历史哲学化
董仲舒、何休的公羊三世说（据乱世→升平世→太平世）把大同从失落的过去改写成可以抵达的未来，这是后来康有为的直接资源。《太平经》则把"太平"作为道教的社会理想，财物共有、周穷救急，是农民运动（黄巾）的思想底本。
中古：无君论与桃花源
阮籍《大人先生传》、鲍敬言的无君论，认为"曩古之世，无君无臣"，君臣制度本身是压迫之源。陶渊明《桃花源记》把大同私人化、田园化——不再是天下秩序，而是一个逃出秩序的飞地。佛教这边则有弥勒下生、龙华三会，成为宋以后白莲教等民间起事的千年王国想象。
宋明：仁的宇宙论化
张载《西铭》"民吾同胞，物吾与也"，把大同从制度理想转成一种存在论感受——万物一体。程颢"仁者浑然与物同体"、王阳明《大学问》"以天地万物为一体"都在这条线上。这一路不谈制度，谈的是主体状态，是后来谭嗣同《仁学》"通"的来源。
明清之际与太平天国
黄宗羲《明夷待访录》"天下为主，君为客"、"公天下"，把《礼运》的"天下为公"转成明确的反君主专制论。洪秀全《原道醒世训》直接大段引用《礼运》大同章，《天朝田亩制度》的"有田同耕，有饭同食，有衣同穿，有钱同使，无处不均匀，无人不饱暖"是大同第一次被写成施政纲领。
近代：三次激活

* 康有为《大同书》——集大成也最激进：去国界、级界、种界、形界（男女）、家界、产界、乱界、类界、苦界。他把公羊三世、佛教普度、西方社会主义和进化论全部揉进去，大同从此变成一个可以论证的乌托邦方案。
* 孙中山"天下为公"——他反复题写这四字，并把民生主义解释为"就是社会主义，又名共产主义，即是大同主义"。国民党党歌"以进大同"也是这个脉络。
* 共产主义的本土翻译——李大钊、毛泽东（《论人民民主专政》："经过人民共和国到达社会主义和共产主义……到达世界大同的境地"）都用大同来解释共产主义，大同成了马克思主义中国化最早的接口之一。

一个值得注意的结构
"大同"在两千多年里位置一直在换：《礼运》里它在过去，公羊学把它移到未来，张载把它移到内心，陶渊明把它移到别处，康有为和孙中山又把它移回未来并配上路线图。而无论在哪个位置，它始终和"小康"这个更务实的替代品成对出现——今天的"小康社会"提法也是这对概念的延续。
