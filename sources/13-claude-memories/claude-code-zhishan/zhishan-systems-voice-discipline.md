仍有效的部分（2026-07-04）：用户驳回"AI 是可置于纠偏侧的加速器"——该表述只调转了加速主义语法的方向，没有离开它；反总体化语法的文本若以该语法书写即自败。速度问题的立场出自其英文前作（~/repos/speculative_future/FOUNDATION-PRINCIPLES-REVISION-PROCESS.md）：纠偏必须快于伤害，举证责任在加速一方，首要杠杆是降增益而非竞速。自查加速、赢、抢占、杠杆等词以肯定语态出现之处。这是内容关，不是风格关。

已被取代的部分：我曾把该裁定扩展为"情境化系统诊断优先于立场宣告"的风格律。2026-07-08 用户裁定宣言转向后，此律失效：宣言既诊断也宣告，立场句正面说出正是文本的目的；机制诊断是宣言的骨，不是立场的替代品。见 [[zhishan-manifesto-turn]]。

**How to apply:** 写智善文本守内容关（不借加速语法、不服务博弈方），不守风格关（声部/语域规格已废）。
