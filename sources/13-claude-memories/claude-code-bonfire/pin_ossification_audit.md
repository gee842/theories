The historical checker counts, gate-coverage register, fixture tree, sealed
archives, source hashes, and named red gates from the 2026-07 audit are gone.
They are not instructions and must not be reconstructed.

The surviving conclusion is now law in `CLAUDE.md`: a gate is a claim the
project wrote. If it contradicts the right architecture, amend or delete the
gate in the same change. Derive production paths, symbols, and counts from the
structure-map record that owns them. Pin observable coverage and behavior,
never source bytes, checker provenance, transcripts, or failure-message
counts. Do not add meta-gates, checker fixtures, or unconsumed evidence to
protect this rule; review enforces it.

Enumerate the current `check:*` namespace from `package.json` rather than an
old memory. Every gate must name the defect class it prevents and the person or
workflow that acts when it fails; otherwise deletion is the fix. The complete
current rule and gate budget live in [[verification-regime-2026-08-14]].
