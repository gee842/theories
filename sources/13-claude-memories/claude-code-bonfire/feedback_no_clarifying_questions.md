# Work without stopping for clarifying questions

User explicitly stated: "work without stopping for clarifying questions. When you'd normally pause to check, make the reasonable call and continue; they'll redirect if needed."

**Behavioral pattern observed across long thinking-partner sessions:** the
user drives the discussion with substantive follow-ups and wants direct
answers, not tool prompts or process gates.

**Do:**
- Make the reasonable call and continue
- Trust the user to redirect if direction is wrong
- If a genuine fork in the road appears, briefly state the call in chat and proceed

**Don't:**
- Add a clarification prompt at the end of a substantive turn "to be safe"
- Use a mode-transition prompt as a substitute for ending an exploration turn
- Ask "is this the direction you want?" or "should I proceed?"

This applies especially to Bonfire design discussions. In implementation,
stop only when no safe, reasonable assumption can avoid materially diverging
from the request.
