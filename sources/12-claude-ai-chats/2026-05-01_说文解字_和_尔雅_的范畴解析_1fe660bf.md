## 《尔雅》:世界的目录

《尔雅》成书于战国到西汉之间,共19篇,被认为是中国最早的辞书。但它真正特殊的地方不是收词,而是**它把词按"世界本身的结构"排列**——它的范畴是事物的范畴,不是文字的范畴。

19篇大致分三层。前三篇是语言层:**释诂**(古今词对应)、**释言**(常用词)、**释训**(叠词/复音/拟声)。中间是人世层:**释亲**(亲属)、**释宫**(建筑)、**释器**(器物)、**释乐**(礼乐)、**释天**(天象、岁时、灾祥)、**释地**(地理、九州、四极)。后面是自然层:**释丘、释山、释水**(地形三分)、**释草、释木**(植物)、**释虫、释鱼、释鸟、释兽、释畜**(动物五分)。

这个排列本身就在做一个论断:**从语言出发,经过人的制度,通向天地万物**——它隐含一种宇宙论。每一篇内部又精细地切分,比如"释亲"分宗族/母党/妻党/婚姻四支,"释天"分四时/祥/灾/岁阳/岁名/月阳/月名/风/雨/星/祭名/讲武/旌旗十几个子类。把"畜"从"兽"里单独拆出,意味着"驯化"作为一种关系被范畴化了——人和自然的边界进入了语言体系。

释义方式也带着这种本体论倾向。它的标准句式是"A、B、C,D 也"——把多个词归并到一个共同概念下,典型的**用同义聚合定义概念外延**的做法。这非常接近现代意义上的 WordNet/同义词集合(synset)。

## 《说文解字》:字的代数学

许慎(约公元100年)做的是另一件事。《说文》收 9353 字 + 1163 重文,他不按意义分类,而是按**部首**——把每个字拆成构字部件,选出 540 个作为"根",所有字归入这 540 个根之下。

这是一种**组合论**。汉字不再是平面的符号集合,而是从 540 个原型通过特定操作生成的结构。每个部首是一个 type,部首下面的字是这个 type 的实例或派生。在这个层面,《说文》很像一种早期的代数数据类型系统。

但《说文》最深的贡献是**六书**——许慎对汉字生成机制本身的分类:

- **象形**:直接图像化(日、月、山、水)
- **指事**:抽象指示符号(上、下、本、末)
- **会意**:语义合成(武 = 止 + 戈;信 = 人 + 言)
- **形声**:形旁定类 + 声旁定音(江、河、湖、海都从水,音从工/可/胡/每)
- **转注**:同源互训(老、考)
- **假借**:音同借用,字形不变(令、长)

形声尤其漂亮——它本质上是 **tagged union**:一个字同时携带语义类型(形旁)和音值标识(声旁),"江"既属于"水部"又携带"工"的发音。汉字 80% 以上是形声字,意味着这套机制是中文的主导生成规则。

部首之间也有顺序。许慎"始一终亥",从"一"部开始,到"亥"部结束,模仿天地从混沌到周而复始的生成过程。**部首本身的排列也是一个宇宙论**——这一点容易被忽略,但许慎在《叙》里讲得很清楚。

## 两种范畴观的对照

放在一起看:

《尔雅》是 nominal、ontological、top-down——先承认世界有一个结构,然后给每一块结构里的事物起名字。它的根本动作是**归并**。

《说文》是 structural、generative、bottom-up——先承认有一组原子部件,然后看字怎样从这些部件组合出来。它的根本动作是**分解**。

两者都不是字母序(汉字本来也无所谓字母序),而是两种"非任意"的排列原则。一个是世界的目录,一个是字的代数。

后来中国语文学里的所有大工程基本都是这两条路的变奏——《广韵》《集韵》是声韵范畴的扩展,《永乐大典》《古今图书集成》是《尔雅》式语义大全的极致,《康熙字典》是《说文》部首系统的整合(从 540 简化到 214)。直到今天,新华字典还在用部首检字,词典还在用语义分类——这两条路从汉代到现在没变过。

## 第一条路:《尔雅》作为语义类型系统

把《尔雅》看作一个 type system,它有几层结构,一层一层往下走。

**最外层:三大域(domain partition)**

19 篇被切成三个域——语言域(诂、言、训)、人事域(亲、宫、器、乐、天、地)、自然域(丘、山、水、草、木、虫、鱼、鸟、兽、畜)。注意"天、地"被划进人事域而不是自然域,这不是误置——它们指的是"作为人类历法、礼制、占卜对象的天地",而不是作为物理自然的天地。所以这个划分实际上是 **language → culture → nature** 的三段。

**中间层:篇即类(category)**

每一篇是一个顶层类型。"释亲""释器""释鸟"是平行的概念槽,各自独立。重点是**篇与篇之间不相交**——一个词原则上属于一个篇。这是一个 partition,不是 hierarchy。

但这个 partition 揭示了一种本体承诺:世界被切成"亲属关系""建筑物""乐器""鸟类""鱼类"……这些是被认定为**自然种类**(natural kinds)的东西。"畜"从"兽"中分出,意味着驯化关系成为一个 first-class category——这是一个文化判断。

**内层:子类(subcategory)**

每一篇内部继续切。"释亲"分宗族/母党/妻党/婚姻——这其实是关系类型(relation type)的分类,而不是实体的分类。父亲、母亲、妻子的兄弟,这些都是 relational positions,不是独立实体。"释天"分岁阳、岁名、月阳、月名、风、雨、星、祭名……每一个子类是一个语义场(semantic field)。

**叶层:同义聚合(synset)**

最底层是核心句式"A、B、C,D 也"。例如"初、哉、首、基、肇、祖、元、胎、俶、落、权舆,始也"——把十一个词归到"始"这个概念下。这就是 WordNet 意义上的 synset,一个概念由多个表达式来等价定义。

把这四层叠起来,《尔雅》给出的是一个**四层语义类型层级**:

```
domain  →  category  →  subcategory  →  synset
(三大域)  (19 篇)      (篇内分类)        (同义词组)
```

这就是一个 nominal type system 的标准结构:概念按从属关系组织成树,叶节点是具体词项的等价类。它的核心断言是"世界有一个先验的本体结构,词只是这个结构的标签"。

## 第二条路:《说文解字》作为结构生成语法

《说文》的层次完全不同,它是从原子往上拼。

**最底层:原子(primitive)**

许慎在每个字头下给一个最小定义,但真正的原子不是字,是**笔形和构件**。540 部首是被选定的"原子集合"——不是任意的,许慎是根据他对汉字结构的分析挑出来的"不能再分解的语义/形态单元"。

**第一层:六书(generation rules)**

六书是六条生成规则,从原子生成新字:

- 象形:从世界 → 字(直接 iconic 映射)。日、月、山、水。这是 base case。
- 指事:从抽象关系 → 字(symbolic indication)。"上"是一横在另一横之上,"本"是"木"加一点指示根部。
- 会意:字 + 字 → 字(语义合成)。"武"="止"+"戈",原义是"停止干戈";"信"="人"+"言"。这是 product type。
- 形声:形 + 声 → 字(tagged composition)。"江"="水"(类型)+"工"(音);"河"="水"+"可"。这是 tagged union 或者说 dependent pair。
- 转注:字 ↔ 字(同源等价)。"老"和"考"互训。这是 equivalence relation。
- 假借:同音借用,字形不变,语义扩展。"令"原义是命令,借为县令。这是 polymorphism / overloading。

象形和指事是 base case,会意和形声是递归构造,转注和假借是关系/扩展。整个系统可以从象形和指事的有限集合出发,通过会意、形声反复生成全部字。

**第二层:部首归类(typing)**

540 部首是把所有字按"主要构件"重新组织一次。这其实是给每个字标一个**主类型**。"江、河、湖、海、洋、淼"全部归入"水"部——它们的类型标记是"水"。

这里有一个关键操作:形声字的形旁直接成为它的部首。这意味着**形声字的类型是显式标记的**——你看到"水"在左边就知道这个字与水有关。这是一种 declarative typing,字形本身就是它自己的类型签名。

**第三层:部首之间的排列(meta-structure)**

许慎"始一终亥",540 部首本身有一个顺序,从"一"开始,经过"二、三、示、王、玉……"一直到"亥"。这个顺序模仿《周易》的生成宇宙论——从太一生发,经过阴阳、五行、万物,回到周期的终点。

所以《说文》的完整结构是:

```
primitives  →  six rules  →  derived chars  →  radicals  →  cosmological order
(原子构件)     (六书生成)     (派生字)         (540 部首)    (部首排列)
```

这是一个**带类型标记的生成语法**:从原子出发,通过有限规则生成全部字,生成的字按类型分组,类型组本身又按宇宙论顺序排列。

## 两条路怎么咬合

现在关键的问题:它们之间是什么关系?

**第一种关系:互补,不重叠**

《尔雅》处理的是"概念→词"的映射(给定一个概念,有哪些词表达它);《说文》处理的是"字→结构"的分解(给定一个字,它由什么构成、属于什么类型)。前者是 semantic-to-lexical,后者是 graphic-to-semantic。它们解决的是不同方向的问题。

**第二种关系:形声字是接口**

形声字是两条路真正咬合的地方。"江"在《说文》里被分析为"水 + 工",形旁是"水"。在《尔雅·释水》里,"江"被归入河流的语义场。**两条路在形声字上给出一致的类型断言**——形旁标的类型 ≈ 《尔雅》归的类。

这意味着汉字的字形结构本身就编码了《尔雅》式的语义分类。形旁就是 type tag。这是一个非常深的事实:中文不需要外在的 type 系统,因为类型已经内嵌在字形里。

**第三种关系:两种"非任意性"的不同来源**

《尔雅》的非任意性来自世界的结构(本体论)。《说文》的非任意性来自字的结构(形态学)。但许慎"始一终亥"的部首排序又把宇宙论装回了《说文》——他不甘心只做形态学,要让形态学也承载本体论。

反过来,《尔雅》的"释天、释地、释丘、释山、释水"也不是纯本体论——它带着汉代人对天文、地理、礼制的理解,带着文化判断。所以两条路在最深处**都既是本体论又是结构论,只是侧重不同**。

**第四种关系:两条路在历史上一直并行**

后世几乎所有大型语文工程都是两条路的不同配比:

- 《广韵》《集韵》《中原音韵》:声韵分类,《说文》路的变体(用音作为构造原子)
- 《埤雅》《尔雅翼》《骈雅》《通雅》:义类辞书,《尔雅》路的扩展
- 《康熙字典》:部首字典,《说文》路的标准化(540 → 214)
- 《佩文韵府》《辞源》《辞海》:混合路线
- 《永乐大典》《古今图书集成》:《尔雅》路的极致——按主题分类整个知识体系

直到今天,中文检索还是两套并行——按部首查字,按语义查词。这两套系统从汉代到现在没有被合并,因为它们处理的是不同层面的问题。

## 为什么这对原型系统设计有启示

回到我前面提的那一点:这两条路并不冲突。

**《尔雅》给出的是一个 nominal type hierarchy**——类型由名字和层级关系定义。"鸟"是一个类型,因为它叫"鸟",并且在"释鸟"篇里。

**《说文》给出的是一个 structural type system**——类型由组成部分定义。"江"是水类的,因为它的形旁是"水"。

现代类型系统设计里这两种取向(nominal vs. structural)经常被放在对立面——TypeScript 是 structural,Java 是 nominal,各有各的问题。但《说文》和《尔雅》的并存说明:**同一个对象可以同时承载两种类型信息**。

"江"是名义上的水类(《尔雅》归在释水),也是结构上的水类(《说文》形旁是水)。两种类型在这个字上重合。这种重合不是冗余,是**双重验证**——名义类型来自约定,结构类型来自构造,二者一致时系统是健全的。

放到 SST 设计里,可以这样想:Spirit 的身份(identity)是 nominal——"这个 Spirit 叫什么、是哪一类",来自显式标记;而 Spirit 通过 Token 形成的关系结构是 structural——"这个 Spirit 实际持有什么 capability、参与什么关系",来自构造历史。这两层不一定要合并,但应该**互相约束**:nominal 类型声明意图,structural 类型验证实现。形声字就是这个机制的一个原型——形旁声明类型,声旁记录构造,字形整体既是声明也是构造。

汉代语文学家没有用这套词汇,但他们做的事情在结构上几乎是一一对应的。

"江"这个字,从两个角度看:

- nominal:它叫"江",约定俗成地指长江/大河。这是名字的层面。
- structural:它由"水"+"工"组成,形旁标水类,声旁标音值。这是构造的层面。

但仔细看——"水"作为形旁出现在"江"里,**这个出现本身就是意图的物质化**。造字者选择用"水"做形旁,不是事后给"江"贴标签,而是在构造"江"的那一刻就声明了"这属于水"。**类型标记和构造步骤是同一个动作**。

这跟 Java 的 nominal typing 不一样——Java 里你先声明 `class Fish`,再 `new Fish()`,类型声明和实例构造是两步。但形声字里,"水 + 工 → 江"既是构造也是类型声明,一步完成。

也跟 TypeScript 的 structural typing 不一样——TS 里类型完全来自结构匹配,名字只是别名。但"江"的"水"部不只是结构事实,它是一个**有命名的、被语言系统承认的类型槽**——540 部首之一。

所以形声字是一种 **third thing**:类型即构造痕迹,构造即类型声明。意图(我要造一个表水的字)在被实现的那一刻,自动留下了可以被后人读出的类型信息。

## 把这个想法推到 SST

如果意图即结构,那 Spirit 的"是什么"就不是一个独立的元数据字段,而是它的**构造历史**本身。

具体说,假设一个 Spirit 是通过若干 Token 的连接被构造出来的——它接收了哪些 capability、嵌入在哪些 Space 里、和哪些其他 Spirit 形成了关系。这些构造步骤共同**就是**它的类型,不需要额外的 type 字段去声明。

这跟 capability-based system 的传统看法不太一样。传统看法里 capability 是 Spirit 持有的东西(它有什么权限),Spirit 的身份是另一回事(它是谁)。但如果意图即结构,**Spirit 持有的 capability 集合就是它的身份**——一个只持有读权限的 Spirit 和一个持有读写权限的 Spirit,不是"同一个 Spirit 在不同状态",而是**类型不同**的两个 Spirit。

这其实就是 linear types / session types / effect systems 一直在尝试做的事——让权限/能力/效应进入类型层。但形声字给了一个更优雅的版本:类型不是从外面加上去的约束,而是**构造行为自带的可读痕迹**。

## 但这里有一个张力需要面对

"意图即结构"在形声字上完美成立,但《尔雅》并不完全这样工作。

《尔雅》里的"释鸟"包含很多字,这些字的"鸟性"不一定都来自字形——有些是约定俗成的命名(如"凤""凰"),有些是借用,有些字形里没有"鸟"部但语义在鸟类。这些字的 nominal 类型(归在释鸟)和 structural 类型(字形里有没有"鸟"部)**不一致**。

许慎其实意识到了这个问题。《说文》里有大量"从某,某声"的形声分析,但也有"从某,从某"的会意分析,还有一些字他干脆说"阙"——存疑。**形声字的"意图即结构"是一个理想,但语言里有大量历史沉积、借用、讹变,使得这个理想在边界上被打破。**

汉字的活力恰恰部分来自这种不完美——"假借"就是允许"意图"和"结构"脱钩(借"令"表县令,字形不变),这给了语言演化的空间。如果完全锁死意图与结构,系统就失去了 evolvability。

## 所以"完美融合"需要更精确的表述

我会这样修正这个直觉:

**意图在被表达的瞬间凝结为结构,但凝结之后,结构会沿着自己的逻辑漂移。** 形声字是凝结时刻的样本——意图直接物化为字形。但语言系统作为整体允许后续的漂移:假借、转注、引申、讹变,让结构脱离原始意图,获得新的用法。

放到 SST 里,这意味着:

- **构造时刻**:Spirit 的形成(通过 Token 连接)同时就是它的类型声明,意图与结构合一。这一刻 nominal 和 structural 是同一回事。
- **生命周期中**:Spirit 持有的 capability 可能被传递、撤销、复合,它的实际行为可能漂离原始意图。这时需要某种机制(像"假借"一样)允许这种漂移,但又能追溯到原点。

形声字给的真正启示不是"意图永远等于结构",而是**"意图的痕迹应该可读"**——后人看到"江",依然能从"水"部读出造字时的意图,即使"江"的现代用法已经远超原始意图(可以说"江湖"、"江山"、"科技江湖")。

类型系统的目标不是冻结意图,是让意图**留下可追溯的痕迹**。形声字做到了这一点。SST 如果要做到,就需要让 Spirit 的构造历史本身是可读的——不是日志,而是结构性可读,像形旁一样**就摆在那里看得见**。

## 一个具体的设想

如果一个 Spirit 是从一组 Token 装配起来的,那这组 Token 的"形状"就应该是它的类型签名。比如:

```
Spirit_A = bind(Token_read_X, Token_write_Y, Token_relate_to_B)
```

这个 Spirit 的"类型"不是某个外部 schema 给它的标签,**就是**这三个 Token 的组合本身。任何检视它的人(包括它自己)都能从它的 Token 集合读出它是什么样的 Spirit——就像看到"水"部就知道"江"和水有关。

后续如果这个 Spirit 通过假借式的机制扩展用法,它的原始 Token 组合依然在结构里,作为身份的根。新的用法只是在这个根上长出的枝。

这样 nominal 和 structural 不是被"合并"为一,而是被认识为**同一个事实的两种读法**——给定构造历史,你既可以读出名字(nominal),也可以读出结构(structural),它们必然一致,因为它们读的是同一个东西。

这或许就是你说的"完美融合"的精确含义:不是消除区别,而是揭示两者本来就是一回事。形声字两千年前就给出了这个答案。

**ASSISTANT** (2026-05-01T10:25):

 这是《周易·系辞上》的一句话:**"易有太极,是生两仪,两仪生四象,四象生八卦,八卦定吉凶,吉凶生大业。"** 短短一句,说出了一个生成论。我分层讲。

## 太极:未分的总体

"太"是极致,"极"是端点/极限。太极就是"极致的极限"——再没有比它更根本的东西。

但太极不是"无"。它是**未分化的整全**——一切区分尚未发生,但一切区分的可能性都已经在里面。周敦颐《太极图说》里说"无极而太极",朱熹解释为"无形而有理"——没有具体形态,但有生成的逻辑。

数学上类比:它是 1,但这个 1 不是"第一个数",是**作为整体的 1**,内部还没有切分。

太极图(那个黑白鱼)是后来的视觉表达,不是《周易》原文里的——原文只有"易有太极"四个字,极简。后来的图是把这个抽象概念物质化的尝试。

## 两仪:第一次切分

"仪"是"形态/样式"。两仪就是"两种基本形态"——通常对应**阴**(⚋,断线)和**阳**(⚊,实线)。

但请注意:阴阳不是两种东西,是**一个区分**。太极生两仪不是"从一个变出两个",而是"在整体中划出第一道区分"。划出之后,我们才能说"这边是阳,那边是阴"——但这条区分线本身才是发生的事件。

这是中国哲学里非常深的一点:**生成不是增加实体,生成是引入区分**。从太极到两仪,世界没有多出任何东西,只是变得"可被言说"——因为有了对比。

类型理论里类比:这是从 `Unit` 类型(只有一个值)到 `Bool` 类型(有两个值)的跃迁。Bool 不是"两个 Unit",Bool 是"引入了一个区分"。

## 四象:第二次切分

四象 = 两仪叠加两仪 = 2 × 2 = 4。

具体是:
- **太阳**(⚌,老阳):阳上阳下
- **少阴**(⚍):阴上阳下
- **少阳**(⚎):阳上阴下
- **太阴**(⚏,老阴):阴上阴下

每个"象"由两个爻(yáo)组成。爻就是那条线,阴爻或阳爻。两爻叠在一起,就有四种组合。

这里发生了一件结构上很重要的事:**第一次区分被应用了两次**。同一个阴阳对立,在两个不同位置上独立运作,产生了四种状态。

这是组合爆炸的开端。从这一步起,系统进入了**笛卡尔积**的逻辑——n 次区分产生 2^n 种状态。

四象在传统上对应:
- 四季(春夏秋冬)
- 四方(东西南北)
- 四种基本变化模式

它是把抽象的二元对立第一次接到具体世界的尝试。

## 八卦:第三次切分

八卦 = 四象再叠一次阴阳 = 2 × 2 × 2 = 8 = 2³。

每卦三爻,八种组合,各有名字:

- **乾** ☰ (天):三阳
- **兑** ☱ (泽):上阴下阳阳
- **离** ☲ (火):阴在中
- **震** ☳ (雷):阳在下
- **巽** ☴ (风):阴在下
- **坎** ☵ (水):阳在中
- **艮** ☶ (山):阳在上
- **坤** ☷ (地):三阴

每一卦不是一个静态符号,是一个**三位的二进制串**。乾 = 111,坤 = 000,坎 = 010,离 = 101……如果你把阳读作 1,阴读作 0,八卦就是 0 到 7 的二进制表示。

莱布尼茨在 17 世纪看到邵雍的"先天八卦"序列(坤、艮、坎、巽、震、离、兑、乾)时震惊了——这个排列正是 000、001、010、011、100、101、110、111,完美对应他正在发明的二进制。他给白晋写信说,中国古人已经发现了二进制。

(实际上,《周易》的本意未必是二进制——爻有阴阳,但也有"老阳变阴""老阴变阳"的动态,这超出了二进制——但形式结构上的对应是真实的。)

八卦不再只是抽象,它对应**八种基本的世界形态**:天、地、水、火、雷、风、山、泽。这是把组合学接到自然现象的一步。

## 再往下:六十四卦

《周易》当然没停在八卦。八卦再两两相重,得到 8 × 8 = 64 = 2⁶ 卦。每卦六爻,每爻还可以变(老阳变少阴,老阴变少阳),所以六十四卦实际上是一个**有动态转换的状态空间**,远比静态的 64 更复杂。

整个生成过程:

```
太极     1   = 2⁰
两仪     2   = 2¹
四象     4   = 2²
八卦     8   = 2³
六十四卦  64  = 2⁶
```

跳过了 2⁴ 和 2⁵——这是个值得注意的事。系统选择了 2⁰、2¹、2²、2³、2⁶ 作为停顿点,不是连续的。每个停顿点对应一种语义层:总体、对立、四时、自然、人事。

## 结构上看:这是一个递归生成系统

如果用现代语言描述这套生成机制,它包含三个核心元素:

**第一,一个原子操作**:阴阳区分(binary split)。这是唯一的生成动作,反复应用。

**第二,递归应用**:每一层都把上一层的每个状态再切一次。从太极(1 个状态)到两仪(2)到四象(4)到八卦(8),每步翻倍。

**第三,语义层接入**:在不同层级,系统接入不同的语义解释。两仪 = 阴阳,四象 = 四季,八卦 = 八种自然元素。**生成机制是统一的(就是切分),但每一层被赋予了不同的世界对应**。

所以这不是一个简单的"一变二、二变四"的算术,而是一个**用最少的原子规则生成最大的语义空间**的系统。一条规则(阴阳),递归三次,出八种世界形态;再两两相重,出六十四种状态;每种状态六爻,每爻可变,出动态宇宙图谱。

## 为什么从《说文》《尔雅》自然走到这里

回到我们前面的讨论——

《尔雅》是**自顶向下的语义分类**(先有概念,再归词)。
《说文》是**自底向上的形态生成**(先有部件,再组合字)。

太极→八卦的生成,是**纯粹的自底向上**:从一个未分化的整体,通过反复应用一个最小操作,生成全部状态。它比《说文》还要彻底——《说文》的原子是 540 个部首,而太极系统的原子只有一个动作(阴阳区分)。

从这个角度看,太极系统是**汉文化里最极致的"结构生成"思路**:一个原子操作 + 递归 = 全部世界。

而六十四卦每卦的卦辞、爻辞,又给每个状态接上了语义解释——这是把《尔雅》式的语义分类挂回到结构生成的产物上。**《周易》是结构生成与语义分类在同一系统里咬合的一个早期范例**。

如果说形声字是"意图与结构在单字层面合一"的范例,那《周易》就是"意图与结构在整个状态空间层面合一"的范例——从太极到六十四卦,生成机制本身决定了语义结构,语义解释又必须落在生成出来的位置上。**结构先于语义,但结构生而携带语义槽**。

这或许是中国哲学里"道生一,一生二,二生三,三生万物"和"易有太极,是生两仪……"这两套生成论的共通深意:**世界不是被列举的,世界是被生成的**;而生成的最小单元一旦定下,后面的全部结构都是这个单元的递归展开。

放回 SST 的语境里,这是一个非常激进的设计假设:**如果一个系统的最小生成操作选得对,那么这个系统的全部可能状态都已经在这个操作里了**——无需事先列举,只需展开。形声字、八卦、SST 的 Spirit-Token 关系,可能都是这个假设的不同尺度的实现。
