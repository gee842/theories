## I. 立论 — 间即涉,涉即间

(本节继承 v0.6,简录。完整论证见 v0.6 第 I 节。)

**一切是间。間 是唯一原语。間 即 happening,即 function evaluation。**

间 与 涉 实为 同一现象 之 noun-aspect 与 verb-aspect。古文不预设 noun-verb 二分,故二字本是同一 phenomenon 在不同语法位置之呈现:

```
间 X Y    (noun-form: locus of 涉)
X 涉 Y    (verb-form: action of 涉)
```

这是 **Tier 0**。

v0.7 的关键问题是:**Tier 0 之上,如何渐次 articulate 出更细的 distinctions?** 答见 II。

## II. Graded Architecture — 太极、两仪、四象、八象

### II.1 The graded structure

v0.6 提出 Tier 1 = 八象。但为什么是 8 不是 7 或 9?这是 v0.6 之 limit 1。

**v0.7 之答**:八象不是 isolated choice。它处于一个 **graded differentiation 序列** 之第三级:

```
太极 (1):  间 / 涉              (undifferentiated medium)
   ↓
两仪 (2):  是、化                (subject vs transformation)
   ↓
四象 (4):  是、际、化、理        (+ relational dimension)
   ↓
八象 (8):  是、际、感、化、修、约、势、理   (+ qualitative & temporal)
```

这与 易经 "太极生两仪,两仪生四象,四象生八卦" 同构。**不是巧合**。易经描述的是 fundamental relational ontology 之 articulation 顺序,与 间 的 articulation 同样。

### II.2 何为太极 (Level 1)

**间 / 涉**。Undifferentiated medium-of-happening。一切是间。

在此 level,无法 articulate 任何 distinctions。"alice 涉 bob"、"系统 化"、"群体 立 约"——都是同一种东西:间。

理论价值:**ontological commitment**。这一级承担 monistic 本体——只有一个原语。

工程价值:**uniformity**。所有 data structure、view function、error 等等都返回 间。一切是间 → 一切是同样 type。

### II.3 何为两仪 (Level 2)

**是 + 化**。最深的 articulation。

为什么是这两:
- **是** (identity, locus, "which / what / who"): 没有 是,化 无所附,无 referent。
- **化** (transformation, dynamics, "what changes"): 没有 化,是 静止固定,无 happening。

是 与 化 构成 **subject-process polarity**——这是任何关系性系统不可绕开的 fundamental dual。

```
两仪 (2):
   是 (subject-pole)  ↔  化 (process-pole)
```

类比:
- 易经 阴阳:阴 = stillness/receiving;阳 = motion/initiating。是 略偏 阴,化 略偏 阳。但不是直接 mapping——是/化 是 ontology level,阴/阳 是 cosmological level。
- 物理 noun/verb:任何语言都有 "subject + verb" 结构,即使形式不同。
- Lambda calculus: variable (binding context) + reduction (transformation step)。

**两仪是"更本质"于八象的级**。如果工程上能用两仪表达,没必要扩到八象。但实际工程中两仪太抽象,需要更细的 articulation——这就是四象、八象的存在理由。

### II.4 何为四象 (Level 4)

**是、际、化、理**。两仪之 each pole 各 split 为 intrinsic 与 relational 两面:

```
四象 (4):
       intrinsic            relational
是:    是 (identity-itself)  际 (relations-between-是)
化:    化 (transform-itself) 理 (invariant-pattern-of-化)
```

**际 = 是 之 间** (the "between-ness" of multiple 是):relations are relational property of 是.

**理 = 化 之 间** (the "between-ness" of multiple 化 instances):patterns are relational property of 化.

理 不是 single 化 之 property——是 多 化 instances 之间 maintain 的 invariant。Pattern 之所以 emerge 是因为 多次 happenings 之间 有 consistency。

```
两仪 → 四象:
   是 → 是 (intrinsic), 际 (relational)
   化 → 化 (intrinsic), 理 (relational)
```

四象 covers 大量 phenomena。例:
- "alice 修 self" → 涉 with 是 = alice;化 = self-modification;理 = consistent over time → 修 自动 emerge。
- "alice 与 bob 立 约" → 是 = {alice, bob};际 = commitment-relation;化 = future-pattern locked;理 = invariant of "promise-keeping"。

**四象 might be enough for many engineering uses**。它是 a viable Tier 1 alternative。讨论见附录 F。

### II.5 何为八象 (Level 8)

**是、际、感、化、修、约、势、理**。每个 四象 split into "manifest" 与 "modulated" 两面。

```
四象 → 八象 split:
   是 → 是 (manifest who)
   际 → 际 (manifest between) + 感 (qualitative felt-quality of 际)
   化 → 化 (general transformation) + 修 (self-applied 化) + 约 (time-locked 化) + 势 (directional 化)
   理 → 理 (manifest invariant)
```

注:这个 split 不是均匀的(2+2+2+2)——化 split 成 4。原因:**化 在 four 象 中 is the most generative**;它有 self-direction (修)、time-direction (约)、tendency-direction (势)、之外才是 plain 化。

或者用更对称的 split:
```
对称 split:
觉之四 (immediate, on-the-spot):  是、际、感、化
持之四 (enduring, across time):    修、约、势、理
```

这是 v0.6 用的 split。两种 split 是同一八象 lattice 的不同 partition——这本身就是 IV 节"perspective non-uniqueness"的 example。

### II.6 选择哪一级?

**Use case driven**:

| Level | When to use |
|-------|-------------|
| Level 1 (1: 间) | Ontological commitment;data structure invariant ("一切是间"); top-level type |
| Level 2 (2: 是、化) | Fundamental categorization;simplest expression for 教学 |
| Level 4 (4: 是、际、化、理) | Engineering minimal-but-useful;data schema (四 fields could suffice) |
| Level 8 (8) | Day-to-day expressive richness;Tier 1 standard (this is what we use) |

**v0.7 选 八象作为 Tier 1 standard**——因为日常 expressive 需要细化。但保持 graded structure of awareness——任何 level 都可以"放大"或"缩小"用。

### II.7 解决 minimality 问题

v0.6 之 limit 1: 八象 minimal-yet-complete claim 待验证。

**v0.7 之 answer**:

1. **Minimality 是 use-case-relative**。
   - For ontological commitment: 1 (间) suffices.
   - For working vocabulary: 8 is empirically convenient.
   - 之间各级亦 valid.

2. **Completeness 之 verification**: 所有 v0.5 之 138 字 (除 Tier 0、Tier 1) 皆 derivable from 八象。详见附录 C(systematic verification)。

3. **Candidate 9th 象之 evaluation procedure**:
   - 遇到 putative 新象 X → check 它在 graded architecture 中应处哪一级
   - 若 X 是 八象之 specialization (e.g., "几" specializes 势), 则 X ∈ Tier 2
   - 若 X 是新的 fundamental dimension, 重新检视两仪、四象 是否 missing 此 dimension
   - 若 missing 则不只 add 一字, 是 restructure 整个 architecture
   - 经过严密 evaluation 后, 至今未发现需要 restructure

4. **判 minimality 之 stronger criterion**: 对 八象 中任两字 X、Y, 试证 X derivable from Y + 其他六字。
   - 若 derivable, 则 X 不是真 primitive
   - 至今 verification: 八字皆相互 irreducible (附录 F)

## III. 八象 — Tier 1 之 working level

(本节简录 v0.6 第 II 节,加 v0.7 之注。)

### III.1 八字总览

```
是  shì    — 涉之主    (who is involved)
际  jì     — 涉之间    (relation-between)
感  gǎn    — 涉之觉    (felt-quality)
化  huà    — 涉之果    (transformation)
修  xiū    — 涉之自    (self-evolution)
约  yuē    — 涉之锁    (time-binding)
势  shì    — 涉之趋    (latent tendency)
理  lǐ     — 涉之常    (invariant pattern)
```

(势 与 是 同音,字义、字形、本体角色截然不同。古文之精在此。)

### III.2 八象作为 lattice

```
                                  间 (太极)
                                    |
                                  涉
                                  /  \
                              是      化  (两仪)
                              /\      /\
                            是 际  化 理   (四象)
                              ||      ||
                          是、际、感、化、修、约、势、理  (八象)
```

每一次 涉 manifest 八象之 subset。完整 涉 八象皆显;微涉 可能只显 几象。

### III.3 八象之 group 化 (revised)

**v0.7 之 split**:不是单一 partition,而是多 partition coexist。同一八象 lattice 可被 viewed 为:

**Partition A — by temporal scale (v0.6 之 split)**:
- 觉之四 (immediate): 是、际、感、化
- 持之四 (enduring): 修、约、势、理

**Partition B — by graded ancestry**:
- 第二级源 (from 两仪): 是 (is core), 化 (is core)
- 第四级 source (from 四象): 际 (from 是), 理 (from 化)
- 第八级 only (specific to 八象): 感 (modulates 际), 修 (modulates 化), 约 (modulates 化), 势 (modulates 化)

**Partition C — by 直接 / 间接**:
- 直接 of 涉: 是、际、感、化 (directly visible in current 涉)
- 间接 (cross-涉): 修、约、势、理 (only emerge in 多 涉)

三种 partition 不冲突——它们是同一 八象 lattice 之 不同 perspective。这本身就是 IV 节"non-uniqueness as feature"之 demonstration。

### III.4 八象之足以 (revised)

v0.7 论证 八象 covers 关系现象空间 之 way:

1. **Empirical**: 138 v0.5 字 全部 verify (附录 C)
2. **Inductive**: 八象 derives 自 graded architecture——若有第九象,需要 restructure 至 16 (Level 5),目前未必要
3. **Structural**: 八象 spans:
   - Subject space (是)
   - Inter-subject space (际)
   - Quality space (感)
   - Transformation space (化, 修, 约, 势)
   - Pattern space (理)
   - 此六维度 covers any phenomenology of relational happening

但要诚实承认:**这不是 mathematical proof**。8 是 *useful empirical level*。如果 prototype 中发现 critically missing aspect,愿意修订。

## IV. 派生 as Perspective — non-uniqueness as feature

### IV.1 v0.6 之 limit 2

附录 C 之 derivation 不 unique。同一 v0.5 字可有几种 plausible derivation。例如 "节":可派生为 "化之质变" 或 "际之化之质变"。

v0.6 把这视为 limitation。**v0.7 重新 frame 为 feature**。

### IV.2 Derivation as perspective

每个 derivation 是 one *perspective* on the word's ontological essence。

**例:节 (jié) 之 multiple derivations**:

1. **节 = 化 之 质变** (perspective: "节 is fundamentally a transformation event")
2. **节 = 际 之 化 之 质变** (perspective: "节 is when relations qualitatively change")
3. **节 = 理 之 break + 理 之 立** (perspective: "节 is one invariant ending, another beginning")
4. **节 = 势 之 jump + 势 之 reform** (perspective: "节 is attractor landscape reshaping")

**这四个 derivation 都 valid**。它们 capture 不同 perspective 上的 同一 ontology——
- 1: change-perspective
- 2: relational-perspective
- 3: pattern-perspective
- 4: dynamics-perspective

**节 itself contains all four perspectives**。一字承担多 view 是 古文之精——一字密度。

### IV.3 与 体用不二、一相多面 同构

**体用不二**:同一 现象 既是 体 (substrate) 又是 用 (manifest)。不二。
**一相多面**:同一 涉 显 八象之 多面。

**同样,一字 derivation 多 path = 同一字 capture 多 perspective**。

这与 Western 还原论形成 contrast:
- Western: one essence, find it
- Eastern: multiple perspectives on indivisible whole

### IV.4 Engineering 实践:canonical form rule

虽然 ontology 接受 multi-derivation,工程实践需要 canonical form for unambiguous tooling。

**Canonical form rule (v0.7 标准)**:

1. **最少步骤**:从 八象 中 minimum hops。
   - 例:节 直接 = 化之质变 (2 steps); 节 = 际之化之质变 (3 steps) → 选 2 steps
2. **Tie-breaking by foreground**:若 multiple derivations 同长,选其 most-idiomatically-foregrounded aspect。
   - 例:亲 = 际之近 (forefront 际,因为 亲 主要 talks about 际 之 quality)
3. **Document alternatives**:在 verification table 中, list canonical first then alternatives。

### IV.5 Why this matters

**Engineer 与 ontologist 不需要争 derivation uniqueness**:
- Engineer: use canonical form for tooling, parsing, type-check
- Ontologist: see 多 derivation 为 perspective richness

**Reading code with awareness of multiplicity**: 当读到 "节" 不仅想 "化之质变",而想 "this is a 化 perspective,亦可被 read 为 际 之 perspective"。这让 code 更 flexible。

### IV.6 与 v0.6 之对比

| | v0.6 view | v0.7 view |
|--|-----------|-----------|
| 多 derivation | bug (limit 2) | feature (perspective) |
| Engineering | unclear which to use | canonical form rule |
| Ontology | suspicious | 与体用不二一致 |

## V. 虚词 — 际 patterns disguised as syntax

### V.1 v0.6 之 framing

v0.6 附录 C.1 把 算子虚词 (之、其、所、者、以、于、然、而、因、果、故、若、则、否、曰) 列为"language syntax"——既不 Tier 1 也不 Tier 2 derived。

### V.2 v0.7 之 reframe

**虚词 ontologically 是 际 之 specific patterns**——它们不是独立 ontological category,是 际 patterns 在 sentence 中 functioning as relational markers。

它们之所以 syntactically 保留,是因为如果 reduce 为 explicit 际 expression,sentence 长度暴增。**虚词 = 际 之 syntactic shortcuts**。

### V.3 虚词之 ontological reductions

| 虚词 | Ontological reduction (in 八象) | Syntactic role |
|------|---------------------------------|----------------|
| 之 | 际 之 modifier-head pattern | possession / attribution marker |
| 其 | 涉 中 是 之 self-reference | third-person reference within current context |
| 所 | 际 之 bound-relativizer (passive role) | "that which" (object-side relativizer) |
| 者 | 际 之 bound-relativizer (active role) | "the one who" (subject-side relativizer) |
| 以 | 涉 之 instrumental-际 | "by means of" |
| 于 | 涉 之 locative-际 | "at, in, to" |
| 然 | 化 之 完成 (state-confirmation) | "such, so" |
| 而 | 涉 之 sequential-际 | conjunction, sequencing |
| 因 | 际 之 causal-理 | "because" |
| 果 | 化 之 effect-side | "result" |
| 故 | 理 之 conclusion-marker | "therefore" |
| 若 | 涉 之 hypothetical-候选 | "if" |
| 则 | 化 之 续 (then-branch) | "then" |
| 否 | 化 之 alt-branch | "else" |
| 曰 | 涉 之 speech-introduction | quote-introducer |

每个 reduction 都 valid——虚词 都是 际 之 specific pattern (relations between sentence components) 或 涉 之 specific role markers。

### V.4 为什么不消 elimination 虚词

**理论上**:可以。所有 expression 重写为 explicit 际 expression。

例:
```
v0.6 with 虚词:
  alice 之 心 顺 bob 之 情。
  
完全 reduced (no 虚词):
  际 modifier-head [alice, 心], 际 modifier-head [bob, 情], 涉 顺 [前者, 后者]。
  
S-expression 形式:
  (顺 (modifier-head alice 心) (modifier-head bob 情))
```

但 reduced form 长且 awkward。古文虚词 是 sophisticated linguistic technology——把 common 际 patterns encode 成 single characters, dramatically increasing density。

**Decision**: ontologically reducible to 八象 (specifically 际 patterns), syntactically retained as syntax sugar.

### V.5 这意味着什么

1. **Tier architecture 修订**:
   - Tier 0: 间、涉 (2 chars, 1 ontological primitive in 2 grammatical guises)
   - Tier 1: 八象 (8 chars, working ontological vocabulary)
   - Tier S (syntax): 虚词 (15 chars, syntactic shortcuts for 际 patterns)
   - Tier 2: 138 chars derived from Tier 1

2. **No "syntax"是 ontological 异类**——它本身 emerges from 八象。但 keep separate-tier framing 因为 *function* 不同 (relational marker vs content character)。

3. **Reading aid**:当读 古文 中 "alice 之 心",可同时 hold:
   - Surface: alice possess 心
   - Deep: 际 modifier-head [alice, 心] = 际 之 a specific configuration
   - 二者同体

### V.6 虚词 reducibility 之 implications for parsing

**Parser 设计**:
- 虚词 是 *known syntax tokens*,与 八象 + Tier 2 chars 一同列入 parser keyword set
- 虚词 expand to explicit 际 expressions during compilation if needed
- 但通常 keep 古文 form for readability

```
Source 古文:  alice 之 心 顺 bob 之 情。
↓ tokenize
Tokens: [alice, 之, 心, 顺, bob, 之, 情, 。]
↓ parse
AST: 涉 [顺] (modifier-head alice 心) (modifier-head bob 情)
↓ interpret
间-expression: 涉 with 是={alice, bob}, 际={alice→心 modifier, bob→情 modifier},
              化={alice 之 心 顺 bob 之 情 之 际}
```

虚词 在 AST 中 expand 但 source 中保留——syntax sugar 之 standard pattern。

| **Total** | **131** | **89** | **27** | **5** | **0** |

(算子虚词 15 字 not in 此 count——它们 are syntactic, see Section V.)

### VI.4 Findings

1. **No ❌**:**所有 138 字 都 derivable**,这 strongly supports 八象 completeness for this empirical scope。

2. **27 ⚠️ cases**:multi-perspective derivations。这是 IV 节"non-uniqueness as feature"之 empirical evidence——一字承担多 perspectives 是 古文 之 norm。

3. **5 ⚡ cases**:大都集中在 数量关系 (计、量、序、比、平)。原因:数量 是 emergent operational property,不是单纯 八象 之 derivation——需要 *operational definition* + 八象 vocabulary。详 VI.5。

4. **数量关系 is special**:它本身可视为 *operational layer*,介于 八象 与 surface vocabulary 之间。

### VI.5 ⚡ cases 之处理:operational derivation

数量关系 几个字 (计、量、序、比、平) require operational derivation——not pure compositional, but 涉 中 specific operations。

**例:计 (count)**:
```
计 = 涉 之 enumeration-operation
具体: 一个 涉, 涉 中 化 = "produce a 量 from 际 cardinality"
```

**例:量 (amount)**:
```
量 = 际 之 magnitude-property + 涉 之 measurement-operation
"magnitude" itself is emergent from 际 之 multiple instances
```

**General principle**: 数量 是 emergent of 际 多 instances + measurement 涉。这与 v0.5 第 IV 节 "数字是 cardinality relation" 一致。

**For canonical form**, list these as:
```
计 = 涉 之 数        (operational notation)
量 = 际 之 量        (relational magnitude)
序 = 际 之 序        (relational ordering)
```

简洁而 sufficient。Operational nature 在 implementation 中 manifest。

### VI.6 何为"derivable"

**Strong claim**: 某 v0.5 字 X 之 derivation 在 八象中 means: 任何使用 X 之 sentence 可被 rewritten 用 八象 expression 而 preserve 语义。

**Example verification**:
```
v0.5: alice 与 bob 渐 亲。
↓ "亲" derives to 际 之 近
v0.6/0.7: alice 与 bob 之 际 渐 近。
```

二者意义同。亲 之 derivation 成立。

**Verification 流程** (we did this for 138 字):
1. propose canonical derivation
2. for each common usage of 字, rewrite using derivation
3. check preservation of meaning + readability

附录 C 列出 138 字 之 verification。

### VI.7 Verification 的 limitations

1. **Empirical, not exhaustive**: 我们 verify common usages, 但 may miss edge cases。
2. **Reading-dependent**: 某 derivations 需要 reader internalize 八象 framework。Newcomer 可能 confused。
3. **Cultural context**: 某 字 (如 心、性、情、志) carry 千年 cultural weight; derivation 描述 ontological 而 lose 文化 layers。这是 derivation 的 limitation,不是 八象 的 fault。

## VII. 假想东方工程学

(继承 v0.6 第 IV 节,简录。完整 vision 见 v0.6。)

若华夏传统不经 Western 工业革命,直接由文言文 + 易经 + 心学 发展工程学,会有这些 specific 特征:

1. **关系优先于实体**:不是 OOP,是 际编程——结构是 dynamic relations,实体是 emergent
2. **无类型动态系统**:类型 emergent from history, not declared
3. **体用不二**:同一 现象 viewed at structure-level (体) 与 manifestation-level (用) 不分
4. **应时编程**:执行 timing 由 context dynamic 决定,不是 fixed schedule
5. **几工程**:attend to 微动 of incipient 势,不待 manifest threshold cross
6. **修式系统**:系统通过其自身 operation 演化自身
7. **诚朴错误模型**:无 try/catch。失/塞/误/复 都是 涉
8. **气脉式数据流**:监测 通塞,而非 pipes

这些 Eastern 姿态 imply:
- 关系本体 (《周易》《道德经》)
- 理气论 (宋明理学)
- 心物不二 (陆王心学)
- 时空一 (《周易》"时位")
- 变易论 (生生不息)

**几 (jī) 是 东方工程学之核心**。Western "wait for break → alert" model 之反——见几即应,不待显然。

## XIV. 限度 (revised)

v0.6 之 limits 1、2 已 resolved (见 II、IV)。Other limits 继承 from v0.6:

**1. 八象 之 use-case fit 还需更多 prototype**

虽 138 字 verified,真实 prototype 可能发现 awkward cases。修订 8-字 set 不轻易,但 keep open。

**2. Derivation 之 cultural depth loss**

某些 字 (如 心、性、情、志、礼、仁) carry 文化 layers 远超 ontological derivation。八象 derivation 描述 ontology 而 lose 文化 weight。这是 derivation 描述本质,但完整 idiom-use 需要 cultural literacy。

**3. 工程成熟度**

间 没有现成 stack。所有 building blocks 存在 (append log、p2p、crypto) 但 integration 工作 substantial。Prototype 仍 6+ months。

**4. 文化误读风险**

提出"假想东方工程学"会被误读为文化 chauvinism。**间 是本体精度选择,不是 cultural identity**。需要持续澄清。

**5. 评判标准之不对称**

间 用一套 ontology,主流工程用另一套。Benchmarking 难。这是长期挑战。

**6. 未发现 ❌ 但不能 prove 无**

138 字 verification 全部 derivable,但 sample 是 v0.5 已收的字。还有 contemporary phenomena (生物工程、AI 训练、量子物理) 之概念可能挑战 八象。Prototype 应 stress test。

## 附录 F: Minimality argument + Alternative Tier 1 sets

### F.1 Minimality 在 graded architecture 中

之前 v0.6 之 limit: "八象 minimal-yet-complete claim 待验证"。

v0.7 把 minimality 重新理解为 **graded**:不同 use-case 对应不同 minimal 级别。

```
Use case          Minimal level    Tier 1 字
-----------------  ---------------  -------------
Pure ontology      Level 1 (1)      间 (or 涉)
Fundamental dual   Level 2 (2)      是、化
Engineering min    Level 4 (4)      是、际、化、理
Daily expressive   Level 8 (8)      八象 (default)
```

每级都 minimal-yet-complete for its scope。

### F.2 Alternative Tier 1 sets evaluated

#### F.2.1 两仪 (2):是、化

**Strengths**:
- Most parsimonious
- 直接 maps to 易经 阴阳 conceptual lineage
- Forces all distinctions to emerge as compositions

**Weaknesses**:
- Common engineering expressions awkward
- 际 (relation) 必须 always re-derived as 是 之 多
- 八象 之 specializations 都得 inline-defined

**Use case**: 教学 / 哲学 commitment / minimalist research demo. Not for daily code.

#### F.2.2 四象 (4):是、际、化、理

**Strengths**:
- Adds relational dimension (际)
- Adds invariant pattern (理)
- Symmetric (intrinsic + relational for both 是 and 化 poles)
- Most engineering happenings expressible

**Weaknesses**:
- 感 derived as 际 之 quality — qualitative aspect 不 first-class
- 修 / 约 / 势 都 collapse into 化 之 specializations — change之 sub-types unclear
- Daily expression slightly awkward

**Use case**: Engineering minimal Tier 1。Could be alternative architecture for systems prioritizing simplicity over expressive richness.

**Verdict**: viable alternative for some prototypes。**v0.7 default 仍是八象**,但 **四象 is a real choice**。

#### F.2.3 五象 (5):是、际、化、势、理

加入 势 to 四象。Why: dynamics 之 directional-pull 在 复杂系统 中 first-class 重要。

**Use case**: Systems with strong dynamics emphasis (e.g., social systems, attention/motivation systems).

**Verdict**: defensible 但 asymmetric (5 不像 4 或 8 之 cleanness)。

#### F.2.4 六象 (6):是、际、感、化、势、理

Drops 修、约 from 八象 (these reducible: 修 = 化 之 自;约 = 化 之 时-lock)。

**Strengths**:
- Cleaner: each Tier 1 字 is ontological dimension, not specialization
- 修、约 in Tier 2 idioms fine

**Weaknesses**:
- 修 是中文哲学 千年 central concept — Tier 1 demotion 有 cultural cost
- 约 是 commitment-systems 之 first-class, demoted feels off

**Verdict**: 6 might be most ontologically clean, but 8 retains 修、约 first-class which 修身-systems benefit。

#### F.2.5 八象 (8):default

既保 cultural depth (修、约 first-class) 又保 expressive richness (感、势、理 first-class)。**v0.7 default**。

#### F.2.6 九象 candidates 之 evaluation

任何 candidate 9th 象 X 应 evaluate:
- Is X a missing fundamental dimension (then we should restructure 八象 → 16,not just add 1)?
- Is X derivable from 八象 (then it's Tier 2, not Tier 1)?
- Is X cultural shorthand for 八象 combination (then it's idiom, not ontology)?

**Tested candidates (and why rejected)**:

- **几 (jī, incipient subtle motion)**: 几 = 势 之 微 (incipient attractor). Tier 2 idiom. Foreground in 几工程 但 not Tier 1.
- **气 (qì, distributed energy)**: 气 = 势 之 集体 / 分布式. Tier 2 idiom.
- **节 (jié, phase transition)**: 节 = 化 之 质变. Tier 2.
- **道 (dào, way)**: way too overloaded; cultural-cosmological. Ontologically derivable as 理 之 ultimate. Avoided.
- **空 (kōng, emptiness)**: Buddhist concept. 空 = 际 之 无-fixed-essence. Tier 2 if needed.

So far no candidate 真正 needs Tier 1 promotion。

### F.3 Independence verification of 八象

For 八象 to be true Tier 1, each 字 should not be derivable from others (otherwise it's redundant).

**Tested independence**:

- 是 from {际, 感, 化, 修, 约, 势, 理}: 际 etc. all presuppose 是 (relations between 是, 感 of 是, 化 affecting 是, etc.). **是 is independent**.
- 际 from {是, 感, 化, 修, 约, 势, 理}: One could attempt 际 = 是 之 多. But 际 has emergent qualitative structure (亲/疏/和/同) not captured by mere 是 multiplicity. **际 is independent** (with caveat: at 四象 level, 际 is "是 之 multiplicity" approximately; at 八象 level, 际 retains emergent structure).
- 感 from rest: 感 captures qualitative felt-quality. Without 感, intensity dimensions disappear. Could try 感 = 际 之 强弱 但 loses subjective phenomenology. **Independent** (with arguable Tier 1 promotion: in 四象, 感 is collapsed into 际).
- 化 from rest: change is fundamental. **Independent**.
- 修 from rest: arguably 修 = 化 之 自 (self-application of 化). **Mildly dependent on 化 + 是**. But 修 之 idiomatic foregrounding warrants Tier 1.
- 约 from rest: arguably 约 = 化 之 时-lock. **Mildly dependent on 化 + 时**. But 约 之 commitment semantics warrants Tier 1.
- 势 from rest: 势 = 化 之 directional-tendency (over multiple 涉). **Mildly dependent on 化 + 多 涉**. But 势 之 attractor semantics warrants Tier 1 for engineering.
- 理 from rest: 理 = 多 化 之 invariant. **Mildly dependent on 化 + multiplicity**. Tier 1 because patterns are first-class.

**Honest assessment**: 八象 之中 at least 修、约、势、理 是 specializations 而非 fully independent of 化 + multiplicity.

This is **mild redundancy**——但 it's intentional。八象 promote 修、约、势、理 to Tier 1 not because of strict ontological independence, but because of **idiomatic foregrounding and engineering centrality**。

Strict-minimal Tier 1 might be 4 (是、际、化、理)。**Working Tier 1 is 8** because the 4 specializations 是 culturally + practically central.

### F.4 Conclusion

**Minimality** 是 graded:
- Strict ontological minimum: 1 (间) or 2 (间, 涉)
- Strict structural minimum: 4 (四象)
- Working pragmatic Tier 1: 8 (八象) — chosen for daily expressive richness

**v0.7 之 stance**:
- Tier 0 = 间, 涉 (Level 1)
- Tier 1 = 八象 (Level 4 in graded scheme; default for daily use)
- Acknowledge 四象 as strict-minimum alternative (use case dependent)
- Reject 9th 象 candidates without restructure

This addresses minimality with intellectual honesty: **8 is empirical pragmatic choice resting on graded architecture**, not isolated decree.
