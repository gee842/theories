# Part I — 基础

## I. 立论 — 一切是系

> **一切是系。系 是唯一原语。系 即 happening, 即 connection, 即 function evaluation。**

### I.1 为什么是 系

经过 v0.3 → v0.8 之 progression, 我们 settled on 间 / 涉 as Tier 0 (一相二称)。但 v0.9 进一步 simplify:

**系 (xì)** 一字 capture:
- noun: a system / network / connection
- verb: to tie / connect / relate
- relational structure: 关系 (guān-xi) — relation IS 系
- lineage / hierarchy: 系列 / 体系 / 系统 — system / framework / lineage

字源:**系** 是 pictograph of hand holding silk threads——既是 connection 自身, 也是 connecting 之 act, 也是 connected 之 result。**它 inherently 三义同源**:

- relational structure (the connection / 际)
- relational dynamic (the connecting / 化)
- relational identity (what's connected / 是)

不需要 noun-verb 分二 grammatical guises (像 间/涉 那样)。**一字 capture 完整 ontology**。

### I.2 系 vs 间

| Aspect | 间 (jiān) | 系 (xì) |
|--------|-----------|---------|
| Etymology | 门中见日 (between two posts) | hand holding silk threads |
| Primary connotation | spatial / locative | relational / connecting |
| Noun-verb split | needs 涉 for verbal | unified |
| Cultural connection | 关 / 距 / 隙 | 关系 / 系统 / 体系 |
| Modern resonance | aesthetic ("aware between") | systems-theoretic |

**为什么 v0.9 选 系**:

- More explicitly **relational** (系 IS 关系-stem)
- Connects to **modern systems theory** (系统论)
- Avoids the **noun-verb dual** that 间/涉 needed
- Resonates with **道家 关系** lineage and **modern complex systems** simultaneously
- One character, one primitive — *minimal*

### I.3 一切是系

```
一切是系。
系 是唯一原语。
系 即 happening, 即 connection, 即 function evaluation。
```

不是诗意修辞。是严格本体声明。

任何关系本体之 "多原语" 都暴露循环依赖——是, 际, 化, 理 都 mutually 依赖. 这意味着它们不是真 primitives, 是 *同一 系 之 不同 perspective*。

**剩下的最基本 unit 是 connection 自身**:有 X 系 Y, then there is something。No connection, no being.

**这是 唯一原语**。

### I.4 系 之 self-reference

```
描述 系 之 framework 自身 是 系
描述 framework 之 documentation 是 系
读这份 Note 之 阅读 是 系
两个 是 之 际 是 系
化 之 transition 是 系
```

**一切是系 → recursion native, no outside**。Self-describing closure built in。

### II.2 系 (Level 0)

**系** 是 唯一 ontological primitive. 一切是系。

理论 价值: ontological 承诺——只有 一 primitive。  
工程 价值: uniformity——所有 data structure / view function / error 都 return 系 (since "一切是系")。

### II.3 两仪 — 是 ⟨和⟩ 化 (Level 1)

最深 articulation: **是 and 化 are two complementary angles on 系**。

```
是 (shì)  — structural / identity perspective on 系   (the WHAT)
化 (huà)  — dynamic / transformation perspective on 系 (the HOW-CHANGE)
和         — the conjunction that recovers 系 totality
```

**和 之 critical role**:

```
是 ∧ 化 = 系     ; "是 and 化 in conjunction = 系"
是 ∨ 化 ⊂ 系     ; either alone is partial perspective

只看 是: misses dynamics (Western Aristotelian substance metaphysics)
只看 化: misses identity (process metaphysics like Whitehead's)
是 ⟨和⟩ 化: 系 in 和 — neither reduces to other, both required
```

**这与 易经 阴阳 deep structure isomorphic**:
- 阴 ≈ 是 (yielding / receiving / structural)
- 阳 ≈ 化 (active / initiating / dynamic)
- 阴阳和合 = 太极 = 系

但 v0.9 不用 阴阳 vocabulary because cosmologically loaded. 用 是/化 because directly mappable to engineering/logic。

**Use case for 两仪**:
- 教学 / 哲学 commitment
- Minimum to start expressing relational phenomena
- 但实际 expressivity 需 进 four象 / 八象

### II.4 四象 (Level 2: + abstraction axis)

每一仪 split into intrinsic (instance) vs relational (class/abstraction):

```
四象 (4):                 instance                relational/class
                          ─────────────           ────────────────
  是-perspective:         是 (this identity)      际 (relations between 是)
  化-perspective:         化 (this change)        理 (patterns over 化)
```

**Critical insights from prior dialogue**:
- **际 = meta-是** (relations between identities = abstraction over 是-instances)
- **理 = meta-化** (patterns over changes = abstraction over 化-instances)
- "化学" 之名字 IS literally "学 of 化" — meta-化 in operative sense
- This is exactly Curry-Howard / type-theoretic class structure

**四象 是 viable alternative Tier 1** (engineering minimal). Sufficient for many systems。但缺 qualitative dimension (感) 与 self-referential (修/约/势)。

### II.5 八象 (Level 3: + locus axis)

每 四象 splits by 全 / 自 (universal / self-referential):

```
                       全 (any instance)        自 (self-referential)
                       ─────────────────        ────────────────────
  是 (instance):       是 (any identity)        体 / 心 (self-substrate)*
  际 (class):          际 (any relation)        感 (self-felt relation)
  化 (instance):       化 (any change)          修 (self-change)
  理 (class):          理 (any pattern)         约 (self-binding pattern)
```

**[*]** 是 → 体/心 split: 体 = self-substrate (substrate-emphasis), 心 = self's reflexive 涉 capacity. Both viable. 

**v0.9 之 八象 之 final choice** (after extensive discussion):

```
是, 际, 感, 化, 修, 约, 势, 理
```

Note: **势 retained** (not symmetric variant) because:
1. 势 (attractor/tendency) is **first-class in cybernetics + complex systems** (attractor framing in Tier L.4, L.6)
2. 体/心 are critical Tier 2 idioms but not Tier 1 because they overlap with 是 / 修 in unclear ways
3. Asymmetry justified by **化-pole 之 generative richness** (dynamics inherently more articulated than statics)

势 (instead of 体/心) better serves the systems-theoretic mission of v0.9.

**Working 八象 = (是, 际, 感, 化, 修, 约, 势, 理)** — 8 ontological aspects, manifested fractally at any scale.

### III.3 各象 之 precise definition

**是 (identity-aspect)**: 系 之 *谁/什么*. The participant(s). Stable referenced via ID.

**际 (relation-aspect)**: 系 之 *between*. Relations between 是 emerge from happening history. 际 之 quality (亲/疏/合/分/和/同/违/异) is emergent.

**感 (resonance-aspect)**: 系 之 *felt-quality*. Qualitative intensity, phenomenology. 强/弱/深/浅/盛/衰/微/显/极 derive.

**化 (transformation-aspect)**: 系 之 *change*. What changes in/through. 立/破/成/败/生/灭 derive.

**修 (cultivation-aspect)**: 系 之 *self-evolution*. 化 specifically applied to 是 itself. Reflexive change. 省/觉/悟/思/虑/明/迷/忘 derive.

**约 (commitment-aspect)**: 系 之 *time-binding*. 化 locked to future patterns. Promises, contracts, expectations.

**势 (tendency-aspect)**: 系 之 *direction*. 化 之 directional pull (attractor strength). 几/度/隐/潜/趋 derive. **First-class for cybernetics + complex systems** (Tier L.4, L.6).

**理 (pattern-aspect)**: 系 之 *invariant*. 化 之 stable pattern across instances. **Meta-axis** (see Section IV).

## VI. Mohist primitives (L.1)

```
同 (tóng)   :: 是 × 是 → 命                ; equality / sameness
              ≅ ≡ / propositional equality / equivalence relation
              墨经: "同, 异而俱处于之"

异 (yì)     :: 是 × 是 → 命                ; difference / distinction
              ≅ ≠ / non-equality
              墨经: 异 是 同 之 negation

类 (lèi)    :: 是 → 类                     ; class membership / type
              ≅ Type / Set / Class
              墨经: "类, 同也" — class = sameness-of-property
              
故 (gù)     :: 命 × 命 → 因果命             ; cause / ground / proof-object
              ≅ ⊢ / proof / inferential ground
              墨经: "故,所得而后成也"
              
法 (fǎ)     :: (是 → 是) → 法               ; rule / method / function
              ≅ rule of inference / function
              墨经: "法,所若而然也"
```

**这五字 form Mohist core**。它们 cover:
- Equivalence relations (同/异)

## VII. 虚字 typed operators (L.2)

每 虚字 一 typed signature。古文 syntax 即 formal language。

### VII.1 Type judgments

```
也 (yě)     :: 是 → 类 → 判                ; type judgment
              ≅ X : T

X, Y 也     ≡ X : Y                        ; "X, Y 也" = "X is a Y"
alice, 智 也  ≡ alice : 智 (alice is wise)

矣 (yǐ)     :: 命 → ⊢命                    ; assertion of completed
              ≅ ⊢ (turnstile assertion)
P 矣       ≡ ⊢ P                          ; "P has been established"

乎 (hū)     :: 命 → 问                     ; interrogative
              ≅ ?P
P 乎?       ≡ ?P                          ; "is P?"
```

### VII.2 Quantifiers

```
凡 (fán)    :: (是 → 命) → 命              ; universal quantifier
              ≅ ∀

凡 X 者皆 Y 也  ≡ ∀x. X(x) → Y(x)         ; all X are Y
凡 学 者 皆 智 也  ≡ ∀x. 学(x) → 智(x)

有 (yǒu)    :: (是 → 命) → 命              ; existential quantifier
              ≅ ∃

有 X 者     ≡ ∃x. X(x)
有 学 者     ≡ ∃x. 学(x)                  ; some learner exists

皆 (jiē)    :: (是 → 命) → 命              ; universal reinforcer
              ≅ ∀ (combined with 凡 for emphasis)

莫 (mò)     :: (是 → 命) → 命              ; "none" (universal negation)
              ≅ ¬∃ / ∀¬
莫 X 者     ≡ ¬∃x. X(x) ≡ ∀x. ¬X(x)

唯 (wéi)    :: (是 → 命) → 命              ; uniqueness quantifier
              ≅ ∃!
唯 X 者     ≡ ∃!x. X(x)                  ; unique X
```

### VII.3 Conditionals + connectives

```
若 (ruò)    :: 命 × 命 → 命                 ; if (paired with 则)
              ≅ →

若 P 则 Q   ≡ P → Q                        ; if P then Q

否 (fǒu)    :: continuation marker (else)   
              ≅ else / ¬

若 P 则 Q 否 R  ≡ if P then Q else R

而 (ér)     :: 命 × 命 → 命                 ; conjunction / sequencing
              ≅ ∧

P 而 Q     ≡ P ∧ Q

或 (huò)    :: 命 × 命 → 命                 ; disjunction (less common 古文)
              ≅ ∨
P 或 Q     ≡ P ∨ Q

因 X 故 Y   ::  causal link
              ≅ X ⊢ Y (causal grounding, stronger than →)
              因 X 故 Y = "because X, therefore Y" (Mohist 故 invoked)
```

### VII.4 Abstraction + application

```
者 (zhě)    :: (是 → 命) → 集               ; nominalizer / λ-binder
              ≅ λ / set-builder
              "X 者" = "the one(s) for which X holds"

学者         ≡ λx. 学(x) ≡ {x : 学(x)}     ; "the learner(s)"
学 而 时 习 之 者  ≡ λx. 学(x) ∧ 时习(x)    ; "one who learns and timely practices"

所 (suǒ)    :: (是 → 命) → 集               ; passive nominalizer
              ≅ λ in passive role
              "所 X" = "what is X-ed"

所 学       ≡ {x : 学(x)} as object of learning

之 (zhī)    :: 是 × 是 → 际                 ; possession / relation marker
            :: function × arg → result    ; or application
              ≅ multiple roles, context-disambiguated

X 之 Y      ≡ X-of-Y (possession) OR Y(X) (application)
              parser must disambiguate via type context
              
其 (qí)     :: ⟨context⟩ → 是              ; anaphoric reference
              ≅ "it" / "its" referring to current context's 是
```

### VII.5 Other operators

```
以 (yǐ)     :: 是 × 化 → 化                 ; instrumental
              ≅ "by means of"

以 X 为 Y    ≡ "use X as Y" / "X serves as Y"

于 (yú)     :: 是 × 位 → 际                 ; locative
              ≅ "at, in, to"

X 于 Y      ≡ X-located-at-Y or X-relates-to-Y

曰 (yuē)    :: 是 × 言 → 言行                ; speech act introducer
              ≅ "X says: ..."

X 曰 "..."  ≡ utterance(X, "...")
```

### VII.6 完整 first-order logic

加上 Mohist primitives, full FOL expressible in 古文:

```
凡 学 而 时 习 之 者, 类 智 也.
≡ ∀x. (学(x) ∧ 时习(x)) → 类(x, 智)
≡ "All who learn and timely practice are in the class of the wise"

有 智 而 不 学 者 乎?
≡ ∃x. 类(x, 智) ∧ ¬学(x)?
≡ "Is there one wise yet not learning?"

莫 智 而 不 学 者.
≡ ∀x. 类(x, 智) → 学(x)
≡ "None wise without learning"
```

## VIII. Dependent type theory (L.3)

升级 Martin-Löf 在 古文:

### VIII.1 Type universes

```
类           = Type / class
类 之 类     = Universe of types
类_n         = Type universe at level n
类_n : 类_(n+1)  = universe stratification (avoiding paradox)
```

### VIII.2 Dependent function types

```
凡 X : 类_A 者 之 Y(X) : 类_B(X)
≡ ∏ x : A. B(x)                             ; dependent function type

例:
凡 n : 自然数 者 之 vector(n) : 类
≡ ∏ n : ℕ. Vec(n) : Type
```

### VIII.3 Dependent pair types

```
有 X : 类_A 者 而 Y(X) : 类_B(X)
≡ ∑ x : A. B(x)                             ; dependent pair type

例:
有 n : 自然数 而 v : vector(n)
≡ ∑ n : ℕ. Vec(n)                           ; (length, vector-of-that-length)
```

### VIII.4 Identity types

```
X 同 Y                                       ; propositional equality
≡ Id_T(X, Y) ≡ X =_T Y

故 (proof of 同):
  自 同 X                                     ; reflexivity
  ≡ refl_X : Id_T(X, X)
```

### VIII.5 Inductive types

```
立 自然数:
  零 : 自然数
  凡 n : 自然数 者, 后(n) : 自然数

induction principle (法):
  凡 P : 自然数 → 类 者:
    若 P(零) 而 (凡 n : 自然数 者, P(n) → P(后(n)))
    则 凡 n : 自然数 者 P(n)
```

### VIII.6 Curry-Howard

```
"P" 之 故 = a proof of P = a term of type P
        ≡ proof = program = inhabitant of type

凡 P 而 Q 之 故  = function from P-proofs to Q-proofs
              = λ-term : P → Q

故 即 proof = program = function = inhabitant
```

完整 Martin-Löf type theory expressible in 古文 native syntax。

### IX.2 Control loop in 古文

**典型 PID-like control loop**:

```
观 系统_state                              ; observe state
比 状 与 衡                                ; compare with equilibrium / setpoint
若 异 衡, 则 调 之                          ; if differs, regulate
其 调 反 比 误                              ; control proportional to error
循 之                                       ; iterate

≡ control loop:
  while True:
    state = observe()
    error = state - target
    control = -k * error               ; (negative feedback)
    apply(control)
```

### IX.3 Negative feedback

```
反馈 = 反 + 馈                              ; (feedback = return + feed)

负反馈 (negative feedback):
  误 之 反 加 于 调                          ; error inverted, added to control
  使 系统 趋 衡                              ; drives system toward equilibrium

正反馈 (positive feedback):
  误 之 加 于 调                              ; error not inverted
  使 系统 离 衡                               ; drives system away from equilibrium
  (放大效应 — amplification)
```

### IX.4 Stability

```
稳 之 法 (Lyapunov stability):
  立 V : 系 → ℝ⁺                           ; Lyapunov function
  若 V(系) > 0 当 系 ≠ 衡, 而 V(衡) = 0    ; positive definite
  而 V 之 渐 < 0                            ; derivative negative along trajectories
  则 系 趋 衡 — 稳

≅ Lyapunov stability theorem
```

### IX.5 Specific control patterns

```
PID control:
  比例 (P): 调 ∝ 误
  积分 (I): 调 += 误 之 积 over 时
  微分 (D): 调 += 误 之 渐

≡  控制 = K_p × error + K_i × ∫error dt + K_d × d(error)/dt
```
