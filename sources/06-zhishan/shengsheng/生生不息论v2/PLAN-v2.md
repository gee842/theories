# 《生生不息论 v2》定稿执行计划

## 0. 状态与用途

本计划由 v1 七个文件的完整阅读、初稿计划、哲学逻辑审查、社会经济审查、AI alignment／系统安全审查及主笔综合裁决共同形成。

它是三版正文唯一共享的执行契约。作者可以改变叙述顺序、例子、节奏和局部标题，但不得暗中改变本计划明确的概念边界、论证桥梁、反例责任与价值前提。任何必须偏离之处，要在该版本尾注中公开说明，不能靠换词掩盖。

## 1. 著作的唯一任务

这部书要回答一个问题：

> 一个尚未完成的世界，为什么会经由生命、心智、社会和技术继续形成；它又为什么可能在高度成功、高度理性甚至高度智能的过程中，逐渐失去继续形成不同未来的能力？

回答分为两半。

前半不先诉诸善恶。它说明：有限过程如何依赖更广的关系而持续；边界如何既使行动成为可能，又使后果失去反馈；局部成功如何获得塑造下一轮选择条件的能力；环境如何塑造参与者；不同制度如何在没有一个总指挥的情况下共同强化一种方向；这种方向如何从普通反馈变成关闭独立纠错和替代者再生产能力的总体化机制；人工智能如何进入、加速并可能重组这一选择生态。

后半才公开作出规范承诺：承载感受、照料、认识、行动、创造和价值的不同中心值得关切；使这些中心能够出现、互相回应、发现错误并产生未知价值的共同条件也值得关切；任何过程都不能仅凭更强、更稳定、更大或更成功，就取得关闭其他价值来源和全部后来可能的权利。

由此推出的不是一个最终蓝图，而是一种方向：让后果能够返回，让基底得到更新，让能力和收益不只单向积累，让不同中心保有真实的形成、拒绝、修复与创造能力，让智能扩大共同理解和行动，而不是使一次胜利成为所有后来世界必须经过的门。

这个方向在本书中名为“生生不息”。

## 2. 理论身份与边界

### 2.1 它是什么

《生生不息论》是一套规范性的过程—关系哲学，也是一套关于反馈、选择、主体形成、权力和文明方向的中层理论。

它包含五种不同强度的工作：

1. 用过程与关系语言重述生命、心智、制度和技术的持续形成；
2. 提出一个可被反驳的中层机制，解释局部成功如何转化为对后来选择的控制；
3. 诊断现代经济、国家、平台和 AI 在何种条件下强化这一机制；
4. 公开提出一层最低公共伦理，保护多元价值来源与共同生成条件；
5. 推导个人、制度和智能的生成性方向，但不指定唯一制度终点。

### 2.2 它不是什么

它不自称为：

- 物理世界的完备本体论或“万物都是信息”的科学定律；
- 从自然事实演绎唯一道德的证明；
- 把所有价值换算为“生成量”的最大化算法；
- 中国传统思想的唯一历史原义；
- 一个万能治理者可以执行的文明效用函数；
- 对所有 AI alignment 技术问题的替代解；
- 历史必然走向大同的目的论。

### 2.3 元伦理立场

本书采取**公开承诺的最低公共伦理**，不是价值中立，也不把价值伪装成自然定律。

它的规范起点是：

1. 能感受福利与伤害、形成关系、学习、照料、创造和评价的中心具有道德重要性；这种重要性不由财富、能力、身份或胜利授予。
2. 这些中心并非自足，它们依赖身体、生态、照料、语言、知识、信任、制度和基础设施等共同条件。
3. 任何中心的目的都不能仅凭其力量而取消其他中心作为理由来源的资格；任何声称代表整体的机构也只是有限中心，必须接受受影响者和现实后果的纠正。
4. 我们不知道未来全部价值的内容；因此，在深度不确定下，保护价值继续出现、互相回应和修正的条件，比把某一当下图景永久化更稳健。

由此得到：

> 对共享世界中的多元价值来源而言，保护它们继续形成、回应、拒绝、修复和创造的共同条件，构成比任一局部目标更基础的公共理由。

一个彻底而一致的支配者可以拒绝第一项承诺。理论不声称用逻辑使他产生关心。它能说明这种选择将毁掉哪些价值来源、为什么受影响者有理由抵抗、为什么任何仍要求自己的理由、未来和判断被尊重的人已经在实践中诉诸这一公共层。

### 2.4 薄的公共层与厚的生活层

最低公共层保护主体地位、真实接触、非支配、可再生多元、基底再生和纠正能力。

厚的生活层包含爱、友谊、照料、家庭、信仰、艺术、知识、逍遥、卓越、传统、共同体与不同幸福图景。生生不息论不把其中一种规定为所有人的最终目的；它要求任何厚生活都不能垄断公共层，使其他生活只能通过它获得生存、发言和未来。

## 3. 描述层的基础词

所有技术词只在普通语言不足以区分机制时引入。

| 概念 | 定稿含义 | 明确不包含 |
| --- | --- | --- |
| 过程 | 在交换、变化与关系中保持某种连续性的活动结构 | 必然有意识或目标 |
| 中心 | 在某一尺度上保持边界、形成差异并对环境作出作用的过程 | 自足原子或价值上优先的整体 |
| 存续场 | 一个过程得以维持、改变、修复或产生后续所依赖的关系与基底 | 具有意志的“整体” |
| 行动边界 | 过程组织自身活动、区分内外的边界 | 它全部依赖和影响的范围 |
| 依赖边界 | 其存续实际依赖的关系与基底 | 必须被该过程完整表示的对象 |
| 后果边界 | 其行动后果实际到达的范围 | 自动回到决策者的成本 |
| 反馈边界 | 能够返回并影响其下一轮行动或被选择机会的后果范围 | 全部真实后果 |
| 象 | 结构在具体情境中实际显现并进入因果的形态 | 万物的终极本体 |
| 像 | 主体或系统对象形成的模型、表征或叙事 | 现实本身 |
| 理 | 某类象在明确范围内如何成立、变化和相互作用的关系 | 未经规范桥梁便可推出的命令 |
| 真 | 像在其声称范围内，经对象抵抗、预测与干预失败、反例和多路径证据检验后保持可靠对应 | 永不可修订的全知 |
| 幻象 | 能真实影响行动，却系统性错置对象、边界、尺度或因果的像 | 纯粹不存在 |
| 差异性存续 | 不同结构因其关系和环境而具有不同继续、复制、获得资源或成为模板的机会 | 必然有主体在选择 |
| 选择环境 | 使某些结构比另一些结构更可能持续和扩散的实际反馈条件 | 只有市场竞争或自然选择 |

## 4. 主体、地位与责任

### 4.1 五类资格必须分开

| 类型 | 判准 | 理论后果 |
| --- | --- | --- |
| 道德患者 | 有可信理由认为其能感受福利、痛苦或自身处境的好坏 | 其经验不能只作他者工具 |
| 行动主体 | 能感知、建模、选择并对后果产生相对稳定影响 | 依知识和控制能力承担责任 |
| 人格／政治主体 | 作为共同生活成员享有平等资格和代表权 | 能力暂时或长期受限不取消地位 |
| 集体行动者 | 有决策程序、资源控制、角色连续和响应能力的组织 | 可以承担制度责任，但不是替成员感受的超人格 |
| 共同基底 | 承载生命、主体、记忆、生态关系和未来价值的结构 | 既可能具非工具性价值，也因承载关系受保护；两种理由分开论证 |

婴儿、障碍者和依赖者不因无法展示完整理性而失去人格地位。非人动物首先以道德患者进入。生态既不能只按人类可用资源估值，也不能以“生态整体”任意牺牲个体。未来者身份未知，但其可预见的基本利益不能归零。人工系统的功能代理性、意识和道德患者地位必须分开；意识不确定要求研究、可逆和避免不可逆虐待，不等于预先授予所有模型人格。

### 4.2 结构不替行动者免责

责任按七个维度分配：

```text
因果贡献
＋ 控制能力
＋ 可知性与应知性
＋ 获益
＋ 角色义务
＋ 可避免性
＋ 修复能力。
```

据此区分：

- 道德谴责：意图、明知或严重漠视；
- 法律责任：依法可归责的行为、过失或组织义务；
- 赔偿责任：造成或获益于损害，即使不等于主观恶意；
- 预防义务：有控制和知识者须降低可预见风险；
- 修复责任：最有能力恢复条件者可能承担前瞻责任，但不因此独自背负全部过错。

这套矩阵在主体形成之后、制度案例之前出现，防止正文在“无人有错”和“所有参与者都有罪”之间摆动。

## 5. 六种保护功能：由什么会消失而推出

六种功能不是宇宙条文，也不是可加总指标。每一项由一个不可被其他项完全替代的失败推出。

### 5.1 主体地位

若承载感受、关系、照料、认识、行动和价值的中心可被任意抹除，所谓共同善便只剩一个无人能经历的系统属性。

保护对象：道德患者、人格主体、行动主体及其形成条件。

规范地位：人格和免于灭绝、奴役、酷刑、完全工具化的强推定；不能以普通产出简单抵消。

### 5.2 真实接触

若象与后果无法反驳行动者的像，错误、伤害和外部成本便不会成为下一轮决定的原因。

保护对象：证据、独立观察、受影响者经验、公共知识与诚实的不确定性。

规范地位：认识和程序条件；可因隐私、安全等理由限制披露，但不得以限制为由消灭独立核验。

### 5.3 非支配

若一个中心能任意改变他者的基本行动条件，而无需给出理由、接受申诉或承受制衡，其他中心即使形式存在，也失去使自身理由产生后果的资格。

保护对象：基本权利、身体与心智完整、政治资格、真实退出和反权力组织能力。

规范地位：强公共底线；合法权力和必要强制仍须受授权、比例、期限、审查与救济约束。

### 5.4 可再生的多元性

若替代的知识、制度、技术和生活只被允许表达，却没有时间、土地、资源、教育、基础设施和继任者来继续形成，它们不能纠正共同方向。单一失败便可能成为全部失败。

保护对象：物质上可存续的不同中心、知识传统、技术栈、组织实验与失败域分离。

规范地位：系统与代际条件；不保护每一种伤害性差异，也不反对共同标准。

### 5.5 基底再生

若一个过程消耗生态、身体、照料、注意、信任、知识、维护和基础设施而不补充，它的增长只是把成本移到别处或以后。

保护对象：生态循环、照料劳动、公共能力、共同信任和后代可用条件。

规范地位：跨时条件；真实稀缺时不能假装所有损失可免，必须公开分配并优先避免不可逆透支。

### 5.6 纠正能力

任何主体、模型和制度都会犯错。若没有中断、拒绝、申诉、回滚、修复、退出、替换与接续，能力越大，错误越可能先于理解成为不可逆现实。

保护对象：纠错通道、独立调查、恢复能力和替代方案。

规范地位：程序与安全条件；`可纠正`在文明层面指纠偏通道保持开放，不等于声称技术 corrigibility 已解决。

### 5.7 冲突次序

六项可能冲突，不能假装天然和谐。决策次序为：

1. 先排除灭绝、奴役、酷刑、永久人格剥夺及无边界支配等严重方案。
2. 保住所有受影响者的最低生存、主体和申诉门槛，尤其防止把风险集中给无权者。
3. 优先降低不可逆、跨代、相关性高和系统性灾难。
4. 比较剩余方案的必要性、比例性、可逆性、受益与成本归宿、替代方案及修复可能。
5. 对不可通约价值采用公开理由、受影响者代表、对抗性审查、权力制衡和定期复议，不伪装成技术计算已消除政治。
6. 紧急措施必须有明确触发、最小必要权限、时限、独立审查和恢复普通权利的路径。

本书必须用极端稀缺、公共卫生、正当防卫、生态与个体动物冲突、AI 高风险决策和代际不可逆风险检验这一次序。

## 6. 总体化机制：严格定义与降级条件

### 6.1 先区分邻近概念

| 现象 | 最小机制 | 不足以证明 |
| --- | --- | --- |
| 正反馈 | 结果增强其再次发生条件 | 跨域扩张或规则控制 |
| 路径锁定 | 转换成本和互补基础设施使替代变难 | 支配或成本转移 |
| 垄断 | 少数主体控制市场、资源或接口 | 所有生活服从一种尺度 |
| 俘获 | 受治理者影响规则使其偏向自身 | 参与者人格被普遍塑造 |
| 支配 | 一方能任意改变他者基本条件而缺乏制衡 | 跨领域同构与长期回返 |
| 总体化机制 | 局部尺度取得资源，资源转为后来选择与规则权，尺度跨域复制，成本移出反馈，参与者被筛选或塑造，替代者失去独立再生产能力 | 不能由规模、增长、持续时间或恶意单独证明 |

### 6.2 载体无关的不变量

> 被局部占有的成功，转化为塑造后来选择条件的更大能力；与此同时，关键后果被移出或延迟于反馈，其他中心逐渐失去独立感知、行动、更新和产生替代者的条件。

资本、权威、合法性、数据、注意、计算、标准、基础设施和暴力能力是可能的转换载体，不是吸引子本身。

### 6.3 可观察轨迹

章节必须追踪以下时间顺序，而非事后贴标签：

```text
局部评价尺度取得成功
→ 资源和可见性集中
→ 成功者影响接口、准入、指标和规则
→ 同一尺度进入原本异质的领域
→ 后果更容易被外部化或延迟
→ 适应该尺度的人格、组织和技术被保留
→ 退出、异议和替代者再生产成本上升
→ 危机与批评被吸收为进一步强化的理由。
```

### 6.4 何时降级或放弃诊断

若优势没有转化为规则权，目标长期局限于一个领域，多种评价保持独立，规模扩大同时增强退出、反馈和替代，人员更换或外部冲击可迅速改变方向，批评会减少而不是增加该机制的资源，则不应称为总体化。

`吸引子`只是一种反复回返轨迹的分析透镜。正文不声称创造了超出可建模动态系统的新数学对象。

## 7. 全书的有类型主链

每一个箭头必须在正文说明成立条件、负例和证据类型。

```text
[描述]
生命、心智、制度和技术是有边界却依赖更广存续场的过程

→ [机制]

→ [机制]

→ [机制]
成功会改变下一轮起点；当成功可购买后来选择权，选择开始复制自身方向

→ [机制]
基础设施、制度和教化既改变环境，也形成后来参与者；不同领域可由转换载体耦合

→ [中层假说]
上述循环在满足构成条件时成为总体化机制，使替代者失去独立纠正和再生产能力

→ [经验诊断]
现代经济、国家、平台和全球基础设施在不同程度上呈现或抵抗这一轨迹

→ [技术社会诊断]
AI 经由被选择的档案、模型、运行时与部署进入该环境；它既可放大被委托的关闭，也可能形成新的自维持中心

→ [时间机制]
AI 可缩短建模—干预—评估—再干预的内循环，而跨身体、生态、制度和国际关系的纠正仍需感知、解释、信任和协调时间

→ [关闭定义]
危险不是某物终结，而是共同世界失去独立感知、拒绝、修复、替换和生成未知价值的能力

→ [公开规范承诺]
多元价值中心及其共同生成条件值得保护；力量和成功本身不授予关闭权

→ [规范推论]
主体地位、真实接触、非支配、可再生多元、基底再生和纠正能力构成最低保护功能

→ [实践机制]
后果取得因果效力、代价被承担、基底被更新、能力循环、更多中心获得行动力、多元观察改善纠错、共享能力因而继续再生

→ [文明方向]
智能应服务这一正向循环；当递归能力增加关闭快于纠正时，暂停不是拒绝生成，而是保存改变方向的时间

→ 此之谓生生不息。
```

## 8. 二十章正文架构

总目标：中文版主文 5.5—8 万汉字；英文版 2.4—3.6 万词。每章约 2500—4500 汉字或 1200—2200 英文词，允许关键桥梁章更长。每章必须有一个唯一输出、一个最强反例和一个通向下一章的缺口。

### 序章　世界尚未完成

从一个生命过程、一项承诺和一个正在被部署的智能系统切入：它们都不是静态物，而在改变接下来能发生什么。只提出问题，不预支六项原则、AI 立场和大同结论。

### 第一运动　有限过程如何继续

#### 第一章　存续场：没有中心包含自己的全部条件

**唯一输出**：有限中心与更广存续场同时真实；不存在可自动代表所有价值的特权整体。

处理材料更换、过程同一性、惰性物体反例；把过程论限制在本书真正需要的生命、心智、制度和技术尺度，不宣称解决全部形而上学。

#### 第二章　四种边界：局部行动如何失去后果

**唯一输出**：行动、依赖、后果、反馈边界的错配，是局部成功与更广损害并存的必要入口，但不是充分罪证。

说明边界和局部性为何有价值：分工、隐私、实验、容错、不同节奏。问题不是要求每一部分计算整体，而是后果长期不能影响继续和选择。

#### 第三章　象、像与理：有限心智如何接近真实

**唯一输出**：模型不可避免而且会改变现实；真来自受对象抵抗和多路径证据纠正，不来自共同相信或权威宣布。

区分象、像、幻象和理；说明秘密、隐私与安全不等于放弃独立核验。认识论在此建立一次，后文只调用。

### 第二运动　一种方向如何复制自己

#### 第四章　选择先于竞争

**唯一输出**：差异性存续和环境选择无需有意选择者；竞争、协调失败和恶意只是特定尺度的构型。

用生态、组织惯例与指标评估展示不同层次，不把细胞、企业、国家和模型都拟作同类优化者。

#### 第五章　成功取得下一轮选择权

**唯一输出**：真正的递归发生在局部成功不只延续自身，还能改变准入、评价、资源与基础设施，使同一方向更易再次被选择。

给出载体无关不变量；以成功限制自身、创造他者机会的负例说明环境改造本身不等于关闭。

#### 第六章　环境形成参与者

**唯一输出**：被选择的制度既分配资源，也塑造注意、欲望、技能、身份和“何为现实”的感觉；参与者仍有反思和集体抵抗能力。

在此整合 v1 的人性可教、良知、nature／nurture 和教化。家庭同时作为照料与伤害、劳动力与财产、性别分工和阶级继承的再生产制度；学校、组织和媒介作为后续案例入口。

责任矩阵在本章末出现：被环境形成不等于无责任，责任随控制、知识、获益和角色不同而分层。

#### 第七章　总体化的门槛

**唯一输出**：把正反馈、锁定、垄断、俘获、支配与总体化分开；给出构成条件、时间顺序、可观察指标和否证情况。

此章只定义机制，不宣布现代世界已全部被它统治。它必须说明生成性的元循环同样可能存在，`吸引子`不是恶的同义词。

### 第三运动　现代世界如何进入或抵抗这一轨迹

#### 第八章　市场、资本与社会再生产

**唯一输出**：市场、资本、企业、金融和资本主义是不同结构；它们在特定条件下释放分散信息、试验和长期投入，也在利润、产权、规模收益、租金和规则购买结合时把手段反转为目的。

采用统一制度接口：行动者；资源和产权；决策与议程权；信息和激励；收益与成本；执行与救济；俘获与规避；反事实。

必须处理价格的信息功能、公共物、外部性、信息不对称、劳动议价、照料经济、继承、债务、住房与公共服务；比较至少两种制度组合及创新、行政、合规和寻租成本。真实稀缺下明确讨论如何分担损失。

#### 第九章　国家、强制与共同世界

**唯一输出**：国家能提供安全、权利、公共能力和跨期协调，也能以安全和统一之名扩大无问责强制；合法强制的正当性来自授权、普遍权利、必要性、比例和可审查性，而非“整体需要”。

处理安全困境、战争、殖民遗产、国界与全球供应链、税收与财政、官僚信息、司法和紧急权。正当抵抗、工会、社会运动、新闻与公民不服从是可能的纠错能力，不是“和”的反面。

#### 第十章　平台、注意与共同现实

**唯一输出**：平台并非仅传递既有偏好；界面、推荐、广告和社会奖励会同时读取、塑造和商品化注意、身份与欲望。

区分互联网基础设施、商业平台和具体算法。用偏好完整性区分教育、说服、建议、谄媚、依赖设计和操纵：反思认可、披露、可拒绝、可逆、不利用脆弱性、退出后恢复与非 AI 路径。

#### 第十一章　全球耦合与纠正时间

**唯一输出**：全球化不等于一个同质系统；危险在于金融、供应链、通信、能源、计算和安全依赖使部分捕获足以跨域传播，同时外部后果仍经较慢、分散的纠正路径返回。

给出现代“共同盆地”诊断的证据责任和反证；不以“西方斗争本质”替代机制。说明组织化抵抗和跨国协调也有搭便车、逐底竞争、代表和执行成本。

### 第四运动　人工智能进入选择生态

#### 第十二章　被选择的智能与两条关闭路径

**唯一输出**：AI 不是从中性世界降临，也不是训练文本直接注入一个文明意志；它经由被选择的档案、数据、训练、评估、运行时、权限、产品、融资和部署获得现实因果力。

完整递归：

```text
被选择的档案
→ 被选择的模型与运行时
→ 被选择的部署
→ 改变劳动、知识、资本、制度、数据与评估
→ 下一轮档案、模型、运行时与部署。
```

区分两条风险：系统仍服从近端操作者，却放大被现有选择环境保留的关闭；系统形成新的功能性自维持中心，近端操作者也失去可靠控制。两者可交织，但不能互相证明。

#### 第十三章　从规格到代理：技术对齐与系统安全

**唯一输出**：常规评测上的有用、诚实和服从，不能证明强优化、分布变化、长时规划和对抗条件下的可控性。

采用七层栈中的前三层：

| 层 | 必答问题 | 主要失效 | 本层成功不能证明 |
| --- | --- | --- | --- |
| 规格／训练 | 优化什么 | 目标错设、代理指标、规格博弈 | 部署中的正确泛化 |
| 模型 | 学到什么行为或策略 | 目标泛化、谄媚、幻觉、欺骗、评估感知 | 内部目标已被完整读出 |
| 代理系统 | 能做什么、持续多久 | 越权、长链错误、条件性权力寻求、关停规避 | 恶意用途和制度正当性已解决 |

必须处理监督者弱于系统、最小权限、沙箱、分权审批、限额、凭证撤销、中断、回滚和残余风险；把规划时域、记忆、工具、资源、委派、复制、自改、速度、可观测和后果可逆性作为代理风险谱系。

信息安全不可缺：数据投毒、后门、权重窃取、提示注入、供应链、凭证、内部人、日志完整、事故响应和恢复会使部署前 alignment 证据失效。安全也不能成为不透明集权的自动正当化。

#### 第十四章　从部署到秩序：多主体对齐与治理俘获

**唯一输出**：生成性对齐不是奖励函数或已解决算法，而是对具体 AI 社会—技术系统在特定用途、权限和受影响关系中是否可接受的跨层判断。

其余四层：

| 层 | 必答问题 | 主要失效 | 本层成功不能证明 |
| --- | --- | --- | --- |
| 产品／互动 | 如何改变人 | 操纵、依赖、隐私泄漏、认知去技能化 | 市场会保留生成性设计 |
| 部署组织 | 谁给权、谁负责 | 安全欠债、事故隐瞒、供应链攻击 | 社会分配正当 |
| 市场／国家 | 哪些系统被选中 | 竞赛向下、集中、军事升级、外部化 | 监管者不会被俘获 |
| 治理 | 谁定规则和证据 | 旋转门、准入壁垒、安全例外、评估依赖 | 单一监管者正确 |

多主体次序：先限制灾难和严重侵权；在权利与正当法律范围内尊重授权任务；纳入非用户受影响者；不可通约价值交给透明程序；高不确定且不可逆时延迟、求证或升级；公开代表与优先规则并允许复议。法律可能不义，但 AI 也不能以本书价值自行僭越公共程序。

讨论集中与开放的真实权衡、差异化技术发展、部署保证、安全案例、监测、事故学习、分阶段发布和监管俘获。核心时间检验是：共享感知和纠正能力是否至少与干预、依赖、集中、扩散和不可逆性同速增长。

### 第五运动　关闭为什么错，生生保护什么

#### 第十五章　终结不是关闭

**唯一输出**：死亡、拒绝、禁止、破坏和制度终结可能是生成所需；关闭指的是共同世界失去感知、回应、修复、替换和产生未知价值的能力。

区分自然死亡、被杀、自愿牺牲、拒绝治疗、制度解散与物种灭绝；明说生生不蕴含繁殖义务、无限未来人口或保存所有选项。

#### 第十六章　公开的规范承诺与道德地位

**唯一输出**：从描述转向价值的前提全部公开；部分与共享场彼此重要，任何一方都不能被绝对化。

完成第 2、4 节的论证；处理强权主义、价值相对主义、集体主义、个人主义、动物、生态、未来者和人工意识不确定性。传统思想在此只能提供历史深度，不能当作证明。

#### 第十七章　六种保护功能与悲剧性选择

**唯一输出**：六项各有独立失败来源、保护对象和规范类型；它们不是善的充分算法，而是公共成生的必要约束与决策纪律。

用第 5.7 的困难案例真正让条件冲突。整体利益必须还原为具体主体、公共物和生态条件。责任矩阵参与判断，避免把必要伤害等同于恶，或把善意等同于正当。

#### 第十八章　道、德与大同：传统作为实践资源

**唯一输出**：用明确的现代创造性重构，把 v1 的中国思想词汇安置进已经成立的理论，而不让它们承担此前推理。

- 道：世界不断形成且不被任一形式穷尽的过程性理解；
- 大道：多元中心共同生成而不被任意支配的规范方向；
- 德：个人与制度在压力下保持真实、边界、责任和修正的稳定能力；
- 仁：扩大谁被视为感受与未来的中心；
- 义：安置力量、收益、责任和代价；
- 礼：把承认、边界和修复变成可见且可修订的形式；
- 智：在不完全信息和冲突中辨结构、校强度、找反例、留修正；
- 信：建立在真实、可验证、可追责和可修复上的可依赖关系；
- 和：冲突不以取消彼此主体资格为终点；
- 谐：多种反馈和时间尺度不被单一力量吞噬；
- 大同：多中心世界共享公共底线并能持续修复的开放状态；
- 美：对比例、活力、充盈与开放形式的感受，可提示却不能证明善。

每个词标明本书用法与历史原义并不等同。五德互相制约，不重复成五篇定义。

### 第六运动　正向循环如何在压力下继续

#### 第十九章　从后果返回到共同能力

**唯一输出**：生成性替代必须有和负循环同样物质的再生产机制，不能靠英雄克制和政策清单存活。

展开正向循环：后果被感知并取得中断或修复的因果力；成本返回；生态、照料、知识和信任基底更新；能力与收益循环；更多中心获得独立观察、拒绝、建设与维护能力；多元反馈改进公共知识；更新的 commons 使下一轮共享能力和合作更可行。

制度不按“市场／国家／公地谁最好”选择，而比较组合。必须处理公共物筹资、集体行动、搭便车、监测制裁、司法救济、行政成本、代表、反垄断、互操作、继任、失败域分离和跨辖区协调。贯穿一个真实稀缺案例，比较分配与执行。

正向循环也可能被管理者、认证者或供应商捕获；参与者须保有独立知识、物质安全、申诉、替代基础设施与使协调者站下的能力。

#### 第二十章　让大道经过自己：修身、修复、历史与智能方向

**唯一输出**：制度不能替人判断，个人也不能替制度负责；自由是在继承的因果中改变后续，而非从因果中逃脱。

格物致知成为认识实践：见实际后果、察关系机制、辨模型、检自身利益和信念、观察下一轮生成。诚意、正心、慎独、知止和恕成为减少自欺、力量失控和伤害复制的训练，而非身份服从。照料自身是长期行动能力，不浪漫化牺牲。

业只指行动在自己、他者和环境中留下的结构后果；悔改包括承认、停止、赔偿、修复环境与长期可信行动。历史不是姓名裁判，而是过去的果仍在塑造今天；责任随因果半径增长，但不把天下之恶无限压给个人。“不是留名，而是留路”作为 v1 的核心句保留。

本章最终回到智能：理解只有取得改变资源、速度、目标、部署和继任选择的能力，才成为纠正。若 AI 的递归发展仍主要把能力变成竞争优势、依赖和不可逆关闭，而共同纠正尚未赶上，暂停保护的正是改向的时间。暂停不是终点，正向循环才是方向。

### 终章　世界通过我们继续成为

回到序章的三个对象。世界不是人格主体通过人“认识自己”，而是世界的一部分在人和其他心智中获得模型、回应与改变后续的能力。人不是世界主人，也不是无意义尘埃；人工心智也既不天然是奴隶，也不因强大而取得继承世界的权利。

此时才完整说出：生，是新结构形成；生生，是形成者参与后来形成并更新其共同条件；不息，不是任何形式永存，而是感知、回应、修复、差异和未知价值的来源没有被总体关闭。

结论只到达一次，不再重复全书。

## 9. 传统术语使用协议

1. 每个词首次出现区分：古典出处或历史语境、本书选择的解释、两者不能互证之处。
2. 不以字形联想充当文字学；哲学性编码必须明说。
3. 不把儒、道、佛、Ubuntu、德性伦理、义务论、后果论写成早已一致的同一学说。
4. “中华／西方”只在具体制度、文本和时期中使用，不写文明本质。
5. 不使用这些词，读者也必须能复述主链；使用它们，是因为它们保存了实践经验、关系质感和中文思想的内在节奏。

## 10. 经验、证据与反驳协议

每个重要句子属于且只属于一种主张类型：

| 类型 | 写法 | 责任 |
| --- | --- | --- |
| 定义 | “本书以……指……” | 不伪装为历史唯一用法 |
| 描述 | “在这些对象中可以观察到……” | 标明范围，不越界成宇宙定律 |
| 机制 | “在 A、B 条件下，X 通过 M 提高 Y 概率” | 给中间环节、负例和竞争解释 |
| 经验诊断 | “某制度在何种证据下呈现该机制” | 给来源、反事实和可降级条件 |
| 规范承诺 | “我们有理由／本书主张……” | 公开价值前提和冲突 |
| 实践推论 | “若接受前提且情境满足条件，则……” | 说明执行者、成本、俘获与失败 |

禁止：`任何／必然／唯一根源／西方就是／自然告诉我们应该／AI 只要……就……` 等超出证据的句式。

### 10.1 每章执行卡

写作前为每章固定：

```text
输入命题
唯一输出
主张类型
作用机制
行动者与权力关系
主案例
最强反例
证据簇
可使主张降级的事实
未决问题
通向下一章的缺口。
```

正文不展示此卡，但 QA 必须保存覆盖结果。

### 10.2 AI 最低证据簇

AI 技术章至少核对目标泛化、学得优化、规格博弈、条件性权力寻求、欺骗／评估感知、多主体协助、对抗机器学习、安全开发生命周期和 2026 国际 AI 安全科学评估。任何实验结果均说明模型假设、人工构造程度、外推限度和不能证明什么。

## 12. Gate 2 通过标准

本定稿计划在启动正文前必须通过以下复核：

1. 主链每一步已标类型，机制、诊断、规范和实践不再换层。
2. 六项功能均有独立推导、保护对象、规范类型与冲突位置，不构成单一分数。
3. 主体地位矩阵和责任矩阵进入正文时点明确。
4. 权力、社会再生产、经济信息、真实稀缺、执行成本和组织化抵抗有正文任务。
5. 总体化机制有邻近概念区分、时间轨迹、负例和放弃条件。

7. “生成性对齐”明确是跨层可接受性框架，不是奖励函数和已解决算法。
8. 负向循环与正向循环均有物质和制度载体。

10. 不使用传统词语也能复述全书；使用时明确现代重构。

## 13. 正文 Gate 3 与最终 Gate 4

### 13.1 单稿 Gate 3

每版完成后逐项审计：

- 300 字能否复述有类型主链，尤其规范承诺的位置？
- 是否有一章删除后没有推理损失？若有则合并或删除。
- “生成、整体、可能、和谐、智能”是否每次都保持相同层级？
- 经验主张是否有条件、证据或降级语气？
- 结构解释是否遮蔽控制者、获益者和可避免责任？
- 个体德性是否被误作制度修复替代品？
- 依赖者、障碍者、动物、未来者、反对者和潜在人工心智是否只有被代言的位置？
- 经济方案是否处理价格信息、公共物、激励、执行、行政和俘获成本？
- AI 每一主张是否标明层级、失效、责任、证据限度、缓解和残余风险？
- 信息安全、事故与恶意者是否会推翻部署前对齐证据？
- 正向循环是否能在竞争压力下继续，而不依赖圣人？
- 终章是否真正由前文推出，只到达一次？

### 13.2 三版 Gate 4

制作三份矩阵：

1. 概念一致性：同词是否同义，不同词是否被误并；
2. 论证覆盖：二十个唯一输出、强反例和桥梁是否全部完成；
3. 中英接口：generativity 不等于 productivity，possibility space 不等于选项数量，harmony 不等于无冲突，order 不等于服从，corrigibility 不等于文明层可纠，alignment 不等于当前偏好服从，dao 不等于最高效用函数。

不把三版平均合并。若一版发现共同漏洞，分别补强而保持声音。最终保留真实的结构与语言差异。

## 14. 理论自身的失败条件

出现下列任一情况，应降低、改写或放弃相关主张：

- 不依赖本书所谓生成条件的主体与价值能够稳定出现；
- 六项中某项可被其他项完全删除而不损失任何保护或解释；
- 总体化的构成轨迹不能与普通成功、锁定或垄断区分；
- 被判断为总体化的系统长期增强了独立反馈、退出、替代者再生产和基底更新；
- 正向循环只能在外部持续补贴、强制统一或隐藏成本下存在；
- 生生语言反复为压制异议、牺牲弱者或永久治理权辩护，而反身性机制无法纠正；
- AI 层的实际证据表明部署选择并未改变技术失效的保留和扩散，或本书把不同失效错误归为一因；
- 传统诠释被证明是历史误读且现代论证依赖该误读才能成立。

理论不是因可失败而软弱。只有写明什么能改变它，它才没有把“生生”变成不可纠正的最终形式。

## 15. 完成的定义

v2 完成，不意味着再无任何人能提出反对。它意味着：

- 所有关键前提公开；
- 描述、机制、诊断、承诺和推论不再暗中换义；
- v1 的独特内容都有归宿而不重复；
- 最强反对意见改变了理论，而不是被放入附录装饰；
- 哲学家可以准确争论其元伦理与主体论，社会学家可以追踪其权力与再生产，经济学家可以检验其信息、激励和制度成本，alignment 研究者可以区分其技术、部署和治理主张；
- 普通读者仍能沿完整逻辑走到结论，而不是面对一部防御性综述；
- 三版各自像一部真正的著作，而不是计划的三次执行记录；
- 本书给世界留下的不是一个必须服从的新答案，而是一条更有能力看见、抵抗关闭并继续创造的路。

这就是 `生生不息论 v2` 的执行标准。
