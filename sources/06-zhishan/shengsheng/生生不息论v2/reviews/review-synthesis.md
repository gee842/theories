# 《生生不息论 v2》计划评审综合与修订裁决

## 一、Gate 1 结果

三路独立评审均判定 `00-PLAN-v2-initial.md` **未达到 Gate 2 可执行标准**：

- 哲学与逻辑审查指出，规范桥梁仍把最关键的地位判断放在“若”之后，六项条件尚未完成非任意推导，主体与道德地位未分层，`道／大道／生生`仍跨越描述与规范层，27 章与篇幅不匹配。
- 社会学、政治理论与经济学审查指出，权力、阶级、家庭与照料的社会再生产尚未成为主链内生变量；结构性机制与分层责任之间缺桥；制度章节仍是原则清单，缺少信息、激励、执行、筹资、制裁、行政成本和俘获机制。
- AI alignment、系统安全与科学方法审查指出，“生成性对齐”混合模型、代理、产品、部署、市场和治理层；技术失效、信息安全、部署保证与事故恢复没有完整位置；AI 单章过载；总体化吸引子尚未与普通反馈、锁定、垄断、俘获和支配充分区分。

三路意见并非要求放弃 v1 的方向。共同结论是：初稿已经知道必须回答什么，却还没有把这些问题变成三位独立作者可以一致执行的论证结构。

## 二、根本修订

### 2.1 从 27 章压缩为 20 章

初稿的完整性正在重新制造 v1 的重复。定稿改为六个运动、二十章，每章必须产生一个不可由其他章替代的论证输出。序章和终章不承担新证明。

合并或取消：

- 原独立“真善美与智的限度”章拆回认识论、规范冲突与终章；
- “正义、秩序、共识、调节”不再四章并列赞成，而进入“分配与稀缺—制度选择—执行与俘获”的机制链；
- “历史、业、责任”和“从一人到天下”合并为一章；
- AI 从一个过载章拆为“AI 如何进入选择生态”“技术与代理失效”“部署、权力与治理”三章；
- 传统术语集中在规范桥梁完成之后解释，不再分别在多章承担证明。

### 2.2 机制先行，规范承诺后置但不隐藏

定稿遵循：

```text
有限过程与边界
→ 反馈错配与差异性存续
→ 局部成功取得下一轮选择权
→ 环境、参与者和评价尺度被重塑
→ 替代者失去独立再生产能力
→ AI 加速或重组这一选择生态
→ 关闭究竟毁掉什么
→ 公开作出规范承诺
→ 推出生生的保护功能与正向再生产循环。
```

规范承诺不会被包装成系统科学的必然结论。定稿明确承认：逻辑不能强迫一个一致的支配者关心他者；理论能做的是公开说明自身所保护的价值来源、揭示支配会毁掉什么、说明受影响者为何有理由抵抗，并接受对该承诺本身的批评。

### 2.3 “最低公共伦理”与“厚的好生活”分层

生生不息论不规定唯一幸福、人格、文明或未来。它给出一层薄而有力的公共底线：不同价值来源不被任意抹除，共同条件不被某一局部目的永久占有，错误与新价值仍能进入未来。

爱、照料、友谊、创造、意义、美、宗教、逍遥、卓越与不同共同体的生活理想属于更厚的善。它们可以互相争论，但不能把公共底线变成自己独占的通道。这样既避免“生成”成为新的唯一最高效用，也避免理论因拒绝终极蓝图而退化为价值虚无。

### 2.4 六项条件改为六种由失败机制推出的保护功能

定稿不再声称宇宙天然写有六条原则，而从“何种缺失会使多元价值来源和纠错过程消失”进行删除测试：

1. 没有承载感受、行动、照料与价值的中心，便没有需要被保护的价值来源——推出**主体地位**。
2. 后果不能越过决策边界返回，系统便无法从现实和受害者学习——推出**真实接触**。
3. 一个中心若能任意控制他者基本条件，其他中心的理由便失去因果资格——推出**非支配**。
4. 所有替代者若只在符号上存在而无独立形成、维持和影响未来的能力，失败会成为普遍锁定——推出**可再生的多元性**。
5. 一个过程若消耗生态、身体、照料、信任、注意、知识和基础设施而不补充，它的延续只是透支——推出**基底再生**。
6. 任何认识和制度都会犯错；没有中断、申诉、回滚、修复、退出和接续，错误会随能力扩大——推出**纠正能力**。

这些功能互相依赖但不等同：真实接触是认识条件，纠正能力是改变后续的因果能力；主体地位说明谁不能被抹除，非支配说明权力关系不能任意；多元性保护独立的替代与学习来源，基底再生保护其物质和社会承载。

它们不相加为单一分数。主体地位与反灭绝构成强底线；真实和纠正主要是程序条件；多元与再生是跨时系统条件；紧急例外仍须经必要性、比例性、时限、审查和恢复路径检验。

### 2.5 主体与道德地位分层

定稿加入以下区别：

- 道德患者：能够感受福利或伤害，不以能否表达理性理由为条件；
- 行动主体：能建模、选择并造成后果，因能力不同承担不同责任；
- 人格／政治主体：享有不可因暂时能力不足而取消的平等资格，包括婴儿、障碍者和依赖者；
- 集体行动者：组织、企业和国家可有决策与责任结构，但不能被拟作一个能替成员感受的超主体；
- 共同基底与生态：既可能具有非工具性价值，也因承载现有和未来生命而受保护；两种理由不混同；
- 未来者：身份未知但可预见的基本利益不能因此归零；
- 人工系统：功能代理性、意识和道德患者地位分开；在意识不确定时采用调查、可逆与避免不可逆虐待的审慎原则。

### 2.6 权力与责任成为主链变量

“多个主体”不再被假定为抽象平等者。正文必须追踪既有产权、阶级、性别、种族化、家庭继承、照料分工、国家强制、殖民历史和技术基础设施如何预先分配：谁能行动、谁能等待、谁能退出、谁能定义事实、谁的损失被称为外部性。

结构解释不免除责任。定稿提前加入责任矩阵：因果贡献、控制能力、可知性、获益、角色义务、可避免性与修复能力；据此区分道德谴责、法律责任、赔偿责任、预防义务和修复义务。

### 2.7 制度章节改为比较，不再列美德

每个制度案例均采用同一分析接口：

```text
行动者
→ 资源、产权与依赖
→ 决策权与议程权
→ 信息与激励
→ 收益者和成本承担者
→ 执行、制裁与救济
→ 俘获和规避
→ 可观察结果与反事实。
```

经济章节必须分别说明价格、产权、利润、工资、租金、竞争、金融和增长何时传递信息与支持试验，何时因公共物、外部性、市场力、信息不对称、路径依赖和规则购买而失灵；比较制度组合及其创新、行政、合规与寻租成本。真实稀缺必须处理分配损失，不能只呼唤富饶。

### 2.8 总体化吸引子降为可反驳的中层机制

定稿区分：

- 正反馈：结果增强再发条件；
- 锁定：转换成本使替代变难；
- 垄断：少数主体控制某资源或市场；
- 俘获：规则制定者被受规制者影响；
- 支配：一方任意改变他者基本条件而缺乏制衡；
- 总体化机制：局部评价尺度取得资源，资源转为下一轮规则权，尺度跨域复制，成本被转移，参与者被筛选或塑造，独立反馈与替代者再生产能力下降。

若资源优势不转化为规则权、目标长期停留于局部、多种评价保持独立、规模扩大同时增强退出和反馈、人员更换或冲击可迅速改向，则不得把普通成功追认为总体化。`吸引子`只是描述轨迹反复回返的分析透镜，不冒充新的数学定理。

### 2.9 AI 采用七层社会—技术栈

定稿区分规格／训练、模型、代理系统、产品互动、部署组织、市场／国家选择和治理七层。每层都要写明对象、失效方式、责任主体、证据、缓解和“本层成功不能证明什么”。

“生成性对齐”被严格降格为跨层可接受性框架，不是奖励函数、算法解或“让 AI 最大化生成”。一个模型技术上诚实可停，不足以证明其监控制度正当；一个用途合法，也不足以证明代理不会在分布外越权。

AI 章节必须处理：规格博弈、目标泛化、谄媚与欺骗、监督限制、条件性权力寻求、关停与回滚、代理权限、偏好完整性、认知去技能化、多主体冲突、竞争部署、差异化发展、集中与开放的真实权衡、信息安全、事故响应和监管俘获。

### 2.10 正向循环必须与负向循环同样具体

定稿的正向机制为：

```text
被影响者能够感知并使后果返回
→ 决策者必须承担或修复代价
→ 共同基底得到补充
→ 能力与收益循环而非单向积累
→ 更多中心获得独立理解、拒绝、建设和维护能力
→ 多元观察、实验和纠错增强
→ 公共知识与基础设施得到更新
→ 下一轮共享能力和合作更可行。
```

善意不是载体。时间、资源、照料、知识、维护、组织、训练、法律资格、冲突处理和抵抗俘获的能力才使这一循环可存续。正向结构也会失败或被捕获，因而必须保留独立知识、替代基础设施、继任和站下机制。

## 三、不采纳或限定采纳的建议

1. **不把全书扩到 9—12 万字。**理论需要深度，但 v1 的主要问题之一就是重复。选择压缩到 20 章、主文 5.5—8 万汉字，并把证据矩阵和技术分类放在尾注或伴随 QA 文件。
2. **不把六项功能形式化为总分。**形式化可帮助识别变量，但单一指数会立即重演本书批判的代理指标总体化。
3. **不把正文变成 AI 安全手册。**七层栈和关键失败必须准确；具体控制清单只在必要处出现。AI 的任务是检验全书理论，而非吞噬全书。
4. **不删去道、仁义礼智信、大同等语言。**它们是 v1 的内在生命，但只作为明确标注的创造性重构和实践资源，不承担证明现代制度主张的逻辑重量。
5. **不声称已经解决所有价值冲突。**完整理论必须说明冲突怎样被正当处理、哪些底线不可交易、谁有发言和复议资格；它不能伪造一个不存在的万能答案。

## 四、Gate 2 复核条件

修订后的计划只有同时满足以下条件才通过：

- 主链标明描述、机制、诊断、规范承诺和实践推论，箭头不再偷换层级；
- 六项保护功能均有独立推导、保护对象、规范类型、冲突位置和失败条件；
- 主体与道德地位矩阵、责任矩阵进入正文任务；
- 权力、社会再生产、集体行动、经济信息与执行成本进入主链而非问题清单；
- 总体化机制有构成条件、负例、可观察轨迹和降级条件；
- AI 七层均有不可替代任务，alignment 与 security 不互相替代；
- 正向再生产循环具体说明自身如何在选择压力下生存，又如何防止自我总体化；
- 全书压至 20 章，每章有唯一论证输出和明确字数；
- 不使用传统词语也能完整复述论证；使用时明确现代重构身份；
- 三位作者仅凭定稿计划即可写出理论上相容、文体上独立的完整版本。

以下 `PLAN-v2.md` 按这些裁决重写，并作为唯一执行计划。
