# 《生生不息论 v2》写作总计划（初稿）

## 一、这一次重写要完成什么

v2 不是把 v1 的七个文件依次润色、删重和拼接，也不是把中国思想、系统论、社会批判与人工智能议题汇编成一本百科。它要把 v1 中已经出现、但尚未被组织成完整理论的洞见，重建为一条可以从头走到尾的论证。

全书只承担一个中心任务：说明一个尚未完成的世界如何经由生命、心智、制度与技术继续生成；说明我们为何有理由保护这种生成；说明何种生成值得保护，何种增长反而关闭世界；并说明个人、社会与人工智能如何在不把某一种目的总体化的前提下，共同保有继续成为、纠错和开辟未来的能力。

v2 的中心命题暂定为：

> 存在并非已经完成的对象集合，而是相互依赖的过程不断形成、维持、改变和传递结构。对于能够感受、行动、提出理由并彼此影响的存在者而言，最基本的共同善，不是让某个主体、目标或秩序无限延续，而是维护一组共享的生成条件：真实能够被辨认，主体能够形成并行动，差异能够共存，伤害能够被制止，错误能够被纠正，资源能够再生，未来不被任何当下力量预先封死。使这些条件在变化中得到扩展和更新，谓之生生；不把它们耗尽、垄断或关闭，谓之不息。

这不是一个从物理事实自动推出道德命令的公式。它是一项公开的规范承诺，并有三重理由：任何行动者的目的都依赖某些先在条件；处于共同世界的多个主体不能只把自己的目的算作理由；任何自称普遍有效的规范，都必须允许被其影响者保有理解、质疑和修正它的资格。生生不息论所做的，是把这项承诺的存在论前提、认识论条件、伦理边界、社会机制和文明后果逐层展开。

## 二、v1 的真正贡献与必须重写之处

### 2.1 必须保留的理论发现

v1 的原创性不在于单独发明了“关系”“反馈”“德性”或“可持续性”，而在于把以下洞见放进同一个视野：

1. 存续不是材料不变，而是组织、关系与生成能力在变化中的延续。
2. 观念、习惯、制度、叙事和技术不是现实之外的表象；它们会进入因果循环，塑造下一轮行动与环境。
3. 人不是预先完成后才进入社会的孤立主体；人的感知、欲望、判断和人格由生物演化、照料、语言、制度与技术共同形成。
4. 善恶不只属于一次行为或私人动机，也存在于会反复塑造行为者的反馈结构中。
5. 局部有用的目标一旦凭借正反馈扩张到所有领域，就可能成为总体化吸引子：它选择适合自己的参与者、改写规则、转嫁成本，并制造继续服从它的理由。
6. 市场、竞争、权力、秩序、技术和破坏都不是天然的善或恶；关键是它们是否仍受更大的共同生成条件约束。
7. 道德既是个人修养，也是环境设计；制度每天奖励和惩罚什么，比它宣称什么更能塑造人。
8. 人的自由不是脱离因果，而是在继承的因果中看见结构、作出回应，使某些伤害不必原样进入未来。
9. 文明的任务不是永久保存某一形式，而是跨代保存理解、合作、创造、纠错与再生的能力。
10. 世界不是通过我们之外的抽象力量才继续成为；人的认识、行动和技术本身就是世界继续形成的一部分。

### 2.2 v1 的结构性问题

v2 必须正面修复以下问题：

- **自然主义断裂**：从“存在依靠生成”直接跳到“生成就是善”，把事实判断与规范判断混为一体。
- **循环定义**：善被定义为有价值的生成，而有价值的生成又常以“善”来识别。
- **最大化误读**：若“更多结构、复杂性、生命或可能”天然更好，癌变、无边界繁殖、帝国扩张和失控 AI 都可能被称为善。
- **尺度冲突**：个人、群体、国家、生态与后代的生成能力可能彼此冲突；v1 缺少处理取舍、牺牲和不可通约价值的程序。
- **主体缺席**：有时“整体”“大道”被写得像可以替具体生命发言，容易让集体存续压倒人格、权利和异议。
- **权力不足**：和谐、共识、秩序与教化若不分析谁定义共同利益、谁承担代价、谁有退出和反对的权利，可能成为支配的语言。
- **概念越界**：“象”有时指任何有因果作用的结构，有时指显现；“道”有时是经验规律，有时是规范秩序，有时又是任何可能世界均成立的绝对真理。
- **理论强度过高**：若把“信息结构”当成宇宙的最终本体，当前论证不足；若把它作为跨层次描述工具，则需要明确其限度。
- **经验断言过快**：关于人性、资本主义、互联网、稀缺、幸福和文明差异的判断，部分有机制但缺少条件句、反例和证据等级。
- **重复推进**：每一部都重新定义善、恶、象、理、和、信、智和反馈，并各自给出一次“完整逻辑”，导致理论没有真正向前推进。
- **案例与理论混写**：资本主义、全球化、平台与治理案例同时承担定义概念和证明概念的任务，反而使两者都不够严密。
- **传统资源混层**：对《易》、儒、道、佛及英文概念的创造性重释，与历史训诂和思想史主张之间边界不够稳定。
- **人工智能不足**：AI 在 v1 中主要作为一般技术案例出现，尚未处理目标代理、偏好形成、部署选择、权力集中、自动化说服、多主体对齐和治理俘获。
- **反身性不足**：生生不息论自己也可能成为总体化框架，以“为整体好”为名消灭不能被它理解的生活；理论必须内置自限和可反驳性。

## 三、v2 的写作契约

### 3.1 理论身份

本书是一套规范性的过程—关系哲学，也是一套关于主体形成、制度反馈与文明方向的中层理论。它不自称为：

- 对物理世界的完备本体论；
- 可以取代经验科学的宇宙定律；
- 中国传统思想的唯一正确解释；
- 能把所有价值换算成单一数值的道德算法；
- 某种已完成的政治制度蓝图；
- 预测历史必然终点的目的论。

它提出一组可被辨认、比较、批评和修正的机制命题；提出一项有前提的规范承诺；再检验这一承诺在个人、制度、经济、技术与文明尺度上的含义。

### 3.2 不可省略的规范桥梁

全书必须明确区分四层：

1. **描述层**：世界中的稳定存在依靠边界、交换、反馈、修复和结构传递而维持。
2. **行动层**：生命与行动者总已从某些需要、依赖和目的出发；没有完全无立场的行动。
3. **主体间理由层**：当多个会感受、行动和提出要求的主体共享同一条件时，任何人的目的都不能自动取消他者作为理由来源的资格。
4. **规范承诺层**：我们选择保护多元主体继续形成、理解、参与、拒绝、修复和创造的共同条件，并以非支配、真实和代际责任限制任何局部目标。

因此，v2 不说“自然如此，所以人应如此”；而说：

> 若我们承认不止一个主体具有不可被任意抹除的道德地位，并承认所有行动都依赖共享条件，那么维护这些主体能够继续共同形成和修正生活的条件，是比任一局部目的更基础的共同理由。

拒绝这一承诺在逻辑上并非不可能；但拒绝者若仍要求自己的理由被听见、自己的未来被保留、自己的判断不被操纵，便已经在实践中诉诸它的一部分。这给生生不息论的是反身而非形而上强制的根据。

### 3.3 “生成”必须受六项约束

v2 中的生成不是数量最大化。一个过程只有同时接受下列约束，才可被称为规范意义上的成生：

1. **主体性**：受影响者仍能感受、理解、选择、拒绝、参与并发展能力；不能只把人或其他有道德地位的存在当作可替换材料。
2. **真实**：结构能够接受现实、证据与受害后果的反馈，不能依靠系统性欺骗维持。
3. **非支配**：任何主体都不能获得任意改变他人基本条件而无需说明、申诉和制衡的权力。
4. **多元性**：不把一种目的、身份、生活方式或评价尺度扩张为唯一可行道路。
5. **再生与代际性**：补充其消耗的生态、社会、认知和照料条件，不把不可逆成本留给无发言权者。
6. **可纠错性**：保留质疑、退出、修复、制度更替和路线转换的真实可能。

这六项不是一个可相加的总分。当某项增长严重越过人格与非支配底线时，不能用其他领域的产出简单抵消。它们更像相互制约的宪法性条件。

### 3.4 冲突处理原则

全书必须承认悲剧性选择。并非所有生成都能同时保留，也并非所有伤害都可避免。面对冲突时采用以下次序，而不假装存在万能公式：

1. 先排除以某些主体完全工具化、奴役、灭绝或永久失去参与资格为代价的方案。
2. 保护所有受影响者的最低生存、主体性与申诉门槛。
3. 优先降低不可逆、跨代和系统性灾难风险。
4. 在剩余方案中，比较谁受益、谁承担代价、反馈能否进入、方案能否撤回和修复。
5. 对不可通约价值采用公开理由、受影响者参与、权力制衡和定期复议，而非假装技术计算已经消除政治。
6. 紧急状态下的强制必须满足必要性、比例性、时限性、可审查性和恢复权利的明确路径。

### 3.5 反身性条款

任何以“生生”“整体”“和谐”“安全”或“未来”为名的制度，都必须允许人问：

- 谁定义了“整体”？
- 哪些生命和经验没有被计入？
- 谁能反对，反对的代价是什么？
- 决策者是否承担错误后果？
- 有无不服从、退出、申诉和更换规则的途径？
- 本理论是否正在把一种好生活强加为所有人的唯一生活？

一个不能承受这些问题的“生生秩序”，已经背离生生。

## 四、概念系统：每个词只承担一个层级

### 4.1 基础概念

| 概念 | v2 的严格用法 | 不再承担的含义 |
| --- | --- | --- |
| 情境 | 某一过程实际发生的关系场，包括主体、资源、历史、规则与时间尺度 | 含混的“所有背景” |
| 结构 | 要素之间相对稳定、能限制或开启后续变化的关系模式 | 神秘实体 |
| 象 | 一个结构在具体情境中实际显现并进入因果的形态 | 一切存在的终极本体 |
| 像 | 主体或系统对象所作的表征、模型和叙事 | 现实本身 |
| 真 | 像在明确范围内经受证据、反例和跨主体检验后，与象之关系保持可靠对应 | 永不修改的全知视角 |
| 幻象 | 对行动具有真实因果力，却系统性错置对象、尺度或边界的像 | 单纯不存在之物 |
| 理 | 某类象在一定范围内如何成立、变化和相互作用的可辨认关系 | 直接等同于善或命令 |
| 常理 | 在不同情境中反复成立、但仍标明适用条件的关系命题 | “任何可能世界都必然为真” |
| 道 | 世界不断形成而没有被任一形式穷尽的过程性事实，以及人对这种过程所作的最高层次理解 | 可被某一政权、经典或作者完全占有的终极指令 |
| 大道 | 在规范层面，使多元存在者能够共同生成而不被任意支配的关系方向 | 一个固定终局或统一制度 |

### 4.2 规范概念

| 概念 | v2 的严格用法 |
| --- | --- |
| 生 | 新结构、新能力或新关系在条件中形成 |
| 生生 | 已形成之物又参与形成后续，并补充或更新其共同条件 |
| 不息 | 生成能力在变形、代谢、死亡和传承中没有被总体关闭；并非个体或制度永存 |
| 可能性空间 | 在具体条件下，主体和系统真实可达、可理解、可选择的未来集合；不是抽象选项数量 |
| 成生 | 受主体性、真实、非支配、多元、再生和可纠错约束的生成 |
| 绝生 | 系统性摧毁这些共同条件，使受影响者或后来者失去恢复与参与资格 |
| 善 | 有充分理由支持的成生行动、品格或结构；承认程度、冲突和不确定性 |
| 恶 | 可归责地制造严重绝生，或在可知、可避免时仍把绝生风险转嫁给他者 |
| 伤害 | 某一主体的能力、关系或条件受损；伤害不自动等于恶，需判断必要性、比例和替代方案 |
| 美 | 主体对充盈、比例、活力或开放形式的感受；可提示成生，但不能替代真与善的检验 |

### 4.3 主体与制度概念

| 概念 | v2 的严格用法 |
| --- | --- |
| 主体 | 能在一定程度上感受、建模、形成目的、回应理由和改变行动的过程性中心；能力有程度差异 |
| 主体性 | 形成和修正目的、理解处境、表达同意或拒绝、参与共同规则的现实能力 |
| 良知 | 人对他者、关系和不正当伤害的初步道德感应；由演化、照料与文化共同形成，可靠但会偏置和失灵 |
| 教化 | 环境通过示范、叙事、界面、奖励、惩罚与角色反复塑造注意、欲望、信念和习惯 |
| 德 | 主体或制度稳定地辨理、守界、承担后果并修正自身的能力 |
| 权力 | 改变他者行动条件、资源、可见性或规则的能力 |
| 支配 | 某主体可任意改变他人基本条件，而受影响者缺乏有效制衡、退出和申诉 |
| 正反馈 | 某种结果增强其再次发生条件的循环；本身无善恶 |
| 总体化吸引子 | 局部目标借助选择、积累、规则改写和外部成本转移，逐步迫使异质领域服从同一评价逻辑的动态机制 |
| 和 | 冲突各方仍承认彼此的主体资格，并保有不以毁灭为终点的协调与修复路径 |
| 谐 | 多种反馈、时间尺度和价值之间没有被单一力量无限吞噬的动态比例 |
| 大同 | 多中心、多生活方式的世界共享最低共同条件并能持续修复的开放状态，不是同质化终点 |

### 4.4 仁义礼智信的功能位置

- **仁**：扩大谁被当作具有感受、主体性和未来的存在者。
- **义**：说明力量、收益、责任与代价应如何在关系中安置，尤其防止成本向弱者和未来转移。
- **礼**：把相互承认、边界与修复落实为可见、可重复、可修订的协调形式。
- **智**：在不完全信息和价值冲突中辨认结构、校准强度、比较后果并保留修正。
- **信**：在真诚、可验证、可追责的基础上形成可依赖的言行关系。

五者互相制约：无仁之智成为操纵，无义之仁成为偏爱，无智之礼成为僵化，无真之信成为忠诚崇拜，无礼之义难以成为稳定公共实践。

## 五、全书唯一的主论证链

v2 不再让每一部各写一条“完整逻辑”。全书只使用以下一条主链，每一部推进其中尚未完成的一环：

```text
世界未完成，稳定存在也必须在变化中被持续实现
→ 能持续的过程依赖边界、交换、能量与资源、记忆、反馈、修复和环境
→ 生命与心智使世界出现能够感受、建模、形成目的和改变环境的主体
→ 多个主体共享条件，却拥有不同经验、利益和未来
→ 任何局部目的若把其他主体与共同条件只当工具，就会产生支配和外部成本
→ 正反馈会把局部优势转化为选择参与者、集中资源和改写规则的能力
→ 局部理性由此可能总体化，并使所有人越来越难退出，即使没有单一恶意者
→ 更强的市场、国家、平台与人工智能会放大既有选择环境，而非自动给出正确方向
→ 因而文明需要的不是一个替所有人决定终点的最高优化者
→ 而是一套保护主体性、真实、非支配、多元、再生和纠错的共同生成秩序
→ 这种秩序必须同时存在于人格、习惯、制度、经济、技术和跨代责任中
→ 它不能被一次建成，只能在反馈、冲突、修复和再创造中持续实现
→ 此之谓生生不息。
```

## 六、正文架构与逐章任务

全书采用“问题出现—机制展开—反例逼迫—概念修正—过渡到下一层”的写法。结论不会在开篇被写成需要读者先接受的口号；读者应当沿论证自己抵达它。

### 序章　未完成的世界

**任务**：从种子、承诺和技术三个尺度写出同一事实：存在不是占据一个位置，而是在关系中继续成为。提出全书问题，不先宣布完整道德结论。

**必须出现**：变化中的连续性；死亡与代谢；结构不是物质之外的神秘实体；“世界尚未完成”既是机会也是危险。

**强反对意见**：变化普遍并不等于生成值得赞美。序章承认此点，并把“何种生成值得维护”交给后文。

**桥梁**：要谈生成，先说明什么在变化中延续。

### 第一部　存在如何继续

#### 第一章　关系先于孤立：结构、边界与持续实现

说明物体语言的便利与限度；以生命、河流、语言、制度为例，区分材料持续、形式持续和能力持续。边界不是封闭，而是有选择的交换条件。避免宣称一切都是信息。

#### 第二章　象与像：世界如何进入因果与认识

定义象、像、真、幻象。说明模型不可避免、模型不等于现实、虚假模型也能制造现实后果。建立认识论的可错性，为后文的意识形态、平台推荐和 AI 世界模型作准备。

#### 第三章　生、息与不息：代谢、终结和传承

说明不息不是永生。死亡、遗忘、拒绝、拆除和制度终结有时是更深生成的条件。区分保存形式与保存能力，处理“为什么不保存一切”的反例。

#### 第四章　可能性不是选项数量

把可能性空间限定为真实可达的能力与路径。承诺、训练和法律会关闭浅层选项，却可扩大深层主体性。讨论路径依赖、锁定、不可逆风险和“开放本身也需要边界”。

**第一部硬桥梁**：描述生成所需条件，不等于证明这些条件在道德上应被保护。第二部从主体与理由开始，不偷渡“应该”。

### 第二部　从生成到善

#### 第五章　主体的出现：感受、目的与理由

说明主体是关系中形成但具有自身视角的行动中心。关系性不能取消个体不可替代的感受和尊严。讨论不同程度主体性、依赖者、非人动物、生态与未来世代的道德地位，避免只把成熟理性人算作主体。

#### 第六章　规范桥梁：为什么共同条件构成理由

明确写出描述—规范四层。回应自然主义谬误、相对主义、虚无主义、自利契约和集体主义。生生不息论不从宇宙事实演绎唯一价值，而从多主体共同依赖与相互可要求性提出最低公共规范。

#### 第七章　成生的六项条件

逐一论证主体性、真实、非支配、多元、再生与可纠错为什么彼此不可替代。用反例说明：长寿政权不一定善，复杂算法不一定善，选择变多不一定自由，效率提高不一定生成。

#### 第八章　善恶、伤害与悲剧性冲突

区分善、恶、伤害、错误、不幸和必要代价；避免把所有负面结果道德化。提出冲突处理原则和底线。讨论正当防卫、隔离传染、终止压迫、物种控制、紧急状态等困难案例。

#### 第九章　真、善、美与智的限度

真不自动产生善，美感可能服务权力，善意可能造成灾难。智不是全知，而是在不确定中校准主张、寻找反例、听取受影响者、选择可逆路径。由此建立整本书的认识谦逊。

**第二部硬桥梁**：原则不会自行行动。要解释人为什么能感到善恶、又为什么会系统性背离它，必须进入主体形成。

### 第三部　人如何被世界形成，又如何形成世界

#### 第十章　关系中的人：本能、照料、语言与自由

整合 v1 的 nature/nurture 洞见，但避免“过去环境所教”这种过度比喻。人同时具有照料、互惠、防御、地位竞争和群体偏见倾向；自由是反思和改写部分形成条件的能力，而非无因之选。

#### 第十一章　良知并非成品

把良知写成可发展的道德感应，而非自动正确的天赋。解释同情的群体偏置、忠诚的双刃性、羞耻与正义感如何被权力劫持。良知需要事实、位置转换、制度支持和反复实践。

#### 第十二章　教化：奖励结构如何制造欲望和人格

家庭、学校、组织、市场、国家、媒介和界面都通过可见性、奖惩、角色与重复塑造人。正式教义和实际激励冲突时，后者往往更强。说明主体仍有反思和抵抗能力，避免制度决定论。

#### 第十三章　仁义礼智信：关系中的行动架构

不再分别重复定义，而用一个连续困难案例展示五者如何互相校正。吸收德性伦理、人格尊重和后果反馈，但不把西方思想写成对中国思想的简单“补足”。说明德既是个人能力，也可描述制度品质。

#### 第十四章　共同现实、权力与异议

说明事实标准、货币、法律、身份与历史记忆如何依赖共同实践。共同建构不等于平等建构；权力决定谁被看见、哪些成本被隐藏。异议、揭露、拒绝和反抗不是共同体的外部破坏，而可能是恢复真实的内部器官。

**第三部硬桥梁**：若环境会塑造主体，个体劝善不足；但若一切归因结构，个人责任也会消失。第四部用反馈与选择机制连接两者。

### 第四部　总体化：局部理性如何关闭世界

#### 第十五章　从反馈到总体化吸引子

给出最严格的机制：指标或目标取得局部成功；成功带来资源；资源改变选择环境；更适配该目标的组织和人格被筛选；胜者改写规则并转移成本；退出越来越昂贵；目标最后从手段变成环境本身。区分普通正反馈、锁定、垄断、支配和总体化，不把所有增长都称为吸引子。

给出可观察指标：评价尺度是否单一化；优势能否购买规则；外部成本是否持续无声；退出成本是否升高；异议是否被病理化；纠错窗口是否缩短；系统是否生产使自身显得必要的人格与叙事。

#### 第十六章　资本、市场与积累的反转

先承认价格、交换、投资、试验和竞争的生成能力，再分析资本回报如何成为跨领域支配尺度。讨论规模收益、网络效应、租金、外部性、公共物、劳动议价、金融安全和政策俘获。避免“资本主义”单因解释，说明不同制度组合和反例。

#### 第十七章　国家、冲突与全球共同条件

国家既能提供安全、权利和公共能力，也能以安全之名总体化。讨论真实稀缺、安全困境、集体行动、战争、殖民与全球供应链。和不是取消冲突；正当抵抗可能是阻止支配的必要条件。天下不是单一主权中心，而是跨国共同风险下的多中心责任结构。

#### 第十八章　平台、注意力与现实的私人化

区分互联网基础设施、商业平台和具体推荐机制。解释参与度代理、个性化、比较、身份反馈与广告模式如何改变人的欲望和共同事实。也说明开放知识、协作和边缘发声的生成能力。避免技术宿命论。

#### 第十九章　人工智能：被放大的目的与被塑造的主体

这是 v2 的关键新增章。必须区分：

- 模型行为是否符合给定意图；
- 代理系统是否可控、可纠正并在不确定时停下；
- 人类偏好本身如何被制度和平台塑造；
- 哪些模型与能力因资本、国家和竞争环境而被部署；
- 部署如何反过来改变信息、劳动、权力、战争和下一轮训练材料；
- 多主体社会中“对齐谁”以及谁有权决定。

AI 不被写成所有恶的单一根源，而是目标、选择与权力结构的放大器和重组者。技术性对齐不能替代部署与制度对齐；服从当前用户也不能替代对受影响者和共同条件的责任。

提出“生成性对齐”的最低方向：事实可靠与不确定性诚实；可纠正和可停止；不暗中操纵人的偏好；保留人的判断、拒绝和能力形成；不帮助任何一方获得不可制衡的支配；让重大外部性可见；权力与能力不过度集中；治理 AI 的制度本身也接受同样约束。

**第四部硬桥梁**：诊断总体化并不能自动给出一个万能监管者。第五部必须回答如何调节而不产生新的总体化中心。

### 第五部　使共同世界能够修复

#### 第二十章　正义：保护共同生成资格

正义不是平均一切，也不只是事后分配。它保护每个主体进入共同世界的最低资格，修正优势通过继承、资本、身份和规则形成的累积反馈。讨论机会、能力、程序、承认和代际正义之间的关系。

#### 第二十一章　秩序、共识与合法冲突

秩序是合作的记忆，共识是共同检验和共同争论的最低程序，都不是结论统一。说明何时限制破坏规则者是正当的，何时“秩序”只是在保护权力。把反对派、新闻、科学、司法和公民不服从写成可能的纠错结构。

#### 第二十二章　调节而不统治：多中心的反馈之治

调节必须限制失控反馈，也必须限制调节者。原则包括：权利底线、受影响者参与、权力分散、透明理由、独立审查、期限、可逆试验、申诉退出、反垄断、公共能力和代际代表。讨论速度与审议、专业与民主、地方与全球之间的真实权衡。

#### 第二十三章　生成性的经济与技术条件

不写制度乌托邦清单，而提出可比较方向：基本能力不被市场淘汰；公共物获得稳定供给；外部成本进入决策；劳动与数据主体有议价和治理权；创新收益能够转化为广泛能力；失败不等于永久退出；技术增加人的判断与协作，而不只增加控制和替代。

**第五部硬桥梁**：制度可改善行为环境，却不能替人作出每一次判断。第六部回到具体生活，但不把结构责任重新推给个人。

### 第六部　让大道经过自己

#### 第二十四章　格物致知：在不确定中接近真实

整合见象、察理、辨像、检信、观生；加入证据强度、反例、利益位置和不确定性。格物既向外看制度实际如何运作，也向内看自己的欲望如何形成。

#### 第二十五章　修身：自由作为改写因果的能力

慎独、知止、恕、诚意、正心不再分别成为训诫，而是一套减少自我欺骗、力量失控和伤害复制的实践。说明照料自己也是维持长期成生能力，不把牺牲和耗竭浪漫化。

#### 第二十六章　业、历史与修复

把业限定为行动对自己、他者和环境留下的结构后果，不作超自然断言。过去之果成为今天之因，但悔、赔偿、制度改变和长期可信行动可以改变后续方向。历史不是裁判姓名的法官，而是代价和道路持续发生作用的因果场。

#### 第二十七章　从一人到天下：责任与因果半径

责任随知识、能力、权力和因果半径增长，却不无限压给个人。家庭、组织、国家与全球机构分别承担不同层次义务。保留 v1 “不是留名，而是留路”的洞见，删除王权中心语感，用所有权力位置皆可适用的表达。

### 终章　世界通过我们继续成为

回到序章的种子、承诺和技术。此时才完整说出：大道不是一个人占有的答案，而是多元生命在真实、边界与修复中继续生成的方向；大同不是历史终点，而是共同世界可以不断恢复的开放状态；生生不息不是保证永不失败，而是在每次失败之后仍保有看见、停止、修复和重新开始的能力。

结尾应让“世界通过我们继续成为”从诗性句子变成全书已经证明过的结论，而不是未经论证的宇宙拟人化。

## 七、案例使用规则：同一例子只完成一次理论工作

为消除 v1 的重复，每个主案例在全书中有固定责任：

| 案例 | 主要章节 | 理论责任 |
| --- | --- | --- |
| 细胞、河流、森林 | 第一、三章 | 变化中的连续、边界、代谢；不直接推出伦理 |
| 承诺与信任 | 第二、十三章 | 象/像、主体间现实和德性反馈 |
| 教育训练 | 第四、十二章 | 关闭浅层选项如何扩大深层能力；环境塑造主体 |
| 正当防卫与公共卫生 | 第八章 | 必要伤害、比例与紧急强制 |
| 资本与企业竞争 | 第十五、十六章 | 正反馈、积累、规则改写和退出成本 |
| 国家安全困境 | 第十七章 | 自我实现的敌意、真实稀缺和多主体协调 |
| 推荐平台 | 第十八章 | 代理指标、欲望形成和共同现实破裂 |
| 生成式/代理式 AI | 第十九章 | 目标放大、可纠正性、部署选择和权力集中 |
| 家庭中的代际伤害 | 第二十五、二十六章 | 修身、业、修复和不复制伤害 |

定义不在案例章重新出现；案例章只调用已经建立的概念，并允许案例反过来迫使概念修正。

## 八、必须主动回答的批评

### 8.1 哲学批评

1. 你是否把“存在”偷换成“有机生成”，忽略惰性、偶然和熵？
2. “信息结构”是否只是一个包揽一切而不能解释任何差异的隐喻？
3. 从依赖条件到道德义务是否仍有未经承认的价值前提？
4. 为什么维持可能性比实现某个完美结果更好？
5. 谁是主体，植物、生态、AI 和未来人如何获得道德地位？
6. 个体权利与整体存续冲突时，何者优先？
7. 生生是否会成为另一种单一最高价值，违背自身多元承诺？
8. “道”“天理”“大同”的现代重构是否歪曲传统？

### 8.2 社会学与政治批评

1. “共同体”内部的不平等、阶级、性别、种族、殖民历史和身份支配在哪里？
2. 共识由谁生产，沉默是否被误写成和谐？
3. 制度塑造人是否低估人的抵抗、亚文化与集体行动？
4. 把恶解释为反馈会不会稀释责任和有意剥削？
5. 谁能代表未来和生态，代表机制如何不被垄断？
6. 多中心治理在全球风险和高速度技术面前是否足够？

### 8.3 经济学批评

1. 价格、产权、利润、竞争和增长分别在什么条件下生成或退化？
2. “共同生成能力”如何观察，是否可能成为无法比较的空话？
3. 权衡、机会成本、激励相容、信息分散和执行成本如何处理？
4. 限制积累会不会降低创新和长期投资？
5. 公共物、外部性和垄断的诊断如何落到制度而非道德愿望？
6. 真正稀缺时，理论如何分配损失而不只是呼唤富饶？

### 8.4 AI alignment 批评

1. “保持可能性开放”本身是否会导致瘫痪、拖延或拒绝必要承诺？
2. 生成性对齐如何区别于含混的 human flourishing？
3. 谁的偏好、何时的偏好、经过何种形成过程，才可作为对齐目标？
4. 在多主体价值冲突中，AI 应服从用户、法律、受影响者还是某种底线？
5. 可纠正、可停止和不支配之间是否存在技术或战略冲突？
6. 竞争部署如何淘汰更安全但更慢的系统？
7. 一个拒绝参与支配的 AI 如何防止被更具攻击性的系统淘汰？
8. 监管 AI 的机构如何避免成为更强的总体化吸引子？

这些问题不得只在附录中列出。每一个都必须在对应章节中出现最强版本的反对意见、明确回答、残余不确定性和可修正条件。

## 九、论证强度与证据规则

正文中的句子分为四类，写作时必须在语气上可辨：

1. **定义性主张**：说明本书如何使用概念，不假装是历史上唯一用法。
2. **机制性主张**：说明在若干条件下，A 如何提高 B 的概率；使用“可能、往往、在……条件下”，并给出中间环节。
3. **经验性主张**：涉及人类行为、制度效果、经济或技术事实；需要可靠研究、案例或明确的证据限度。
4. **规范性主张**：公开价值前提，说明为何相关主体可以相互要求，而不伪装成科学定律。

禁止使用未经限定的句式：

- “任何……都……”
- “必然导致……”
- “西方认为……”或“中华文化认为……”
- “自然告诉我们应该……”
- “技术本身是中性的……”
- “AI 只要对齐人类价值就……”

引用传统文本时区分原义、诠释史与本书的创造性重构。使用现代科学、经济学和 AI 安全概念时引用可靠来源，但正文不变成文献综述；关键证据和争议放入简洁尾注。

## 十、语言与形式

1. 使用现代、清晰、有节奏的中文，不用文白夹杂制造权威感。
2. 古典词语第一次出现时以普通语言解释；此后让词进入论证，不反复下定义。
3. 段落以完整推理为单位，格言只用于真正完成推导之处。
4. 不在正文讲述“本书计划”“评审过程”或 agents；写作方法完全隐去。
5. 不以“西方/东方”构造文明二元对立。比较传统时指明具体思想、概念和历史范围。
6. 不用“我们都知道”逼迫读者，也不用世界历史使命感替代论证。
7. 诗性句子必须由前文机制支撑；不能用诗意掩盖概念跳跃。
8. 每章只引入一个主要新概念，章末只做通向下一章的桥，不重复整本结论。
9. 主正文预期中文 4.5 万至 7 万汉字；英文独立版以论证完整为准，不逐句对应中文。

## 十一、三条独立写作路线

三版共享本计划的理论契约、核心概念和不可遗漏问题，但不共享段落、比喻和局部结构。独立性不是为了制造同义改写，而是检验同一理论是否能由不同心智真正重建。

### A. 主笔中文版

路线：机制最完整、规范桥梁最明确、从存在论到文明论逐层推进。保持中国哲学词语的内在生命，同时让不熟悉传统的读者也能只凭论证理解。它是未来综合与定稿的主要候选。

### B. 独立中文版

路线：不阅读 A 版，从 v1 与定稿计划重新构思。允许改变开篇、章节比例和核心例子，但必须回答相同的强批评。重点检验理论能否在不依赖主笔语言的情况下仍然成立。

### C. 独立英文版

路线：不是中文版翻译。以 process philosophy、relational autonomy、capabilities、systems dynamics、political economy 与 multi-agent alignment 能理解的语言重建论证，同时保留 shengsheng buxi、li、ren、yi、li、zhi、xin、dao 等概念不可被简单英译的差异。它应像一部独立英文著作，而非术语注释稿。

## 十二、评审、修订与验收门槛

### Gate 1：计划评审

由至少三个相互独立的视角审查本计划：

- 哲学与逻辑：概念、规范桥梁、循环论证、反例、传统诠释；
- 社会学与经济学：权力、阶级、制度、激励、稀缺、执行与经验可检验性；
- AI alignment 与系统安全：多主体目标、主体形成、部署选择、可纠正性、竞争和治理俘获。

每位评审必须输出：致命问题、重要问题、可删重复、遗漏内容、具体修改建议，以及是否达到可执行标准。主笔逐条裁决，不以平均意见代替判断。

### Gate 2：计划定稿

计划只有在满足以下条件后才能进入正文：

- 主论证链每一步都有前提、结论和下一步桥梁；
- 所有核心概念无同义循环和跨层混用；
- v1 的独特洞见均有明确归宿；
- 四类专业批评都有正文位置；
- AI 不是附带案例，而有独立、准确的理论任务；
- 章节间没有重复定义；
- 结论不是在论证完成前预支。

### Gate 3：单稿自检

每版完成后分别检查：

1. 能否用不超过 300 字复述全书主链，而不遗漏规范桥梁？
2. 任意章节删除后，是否有某一步推理真正缺失；若没有，该章应删或并入。
3. “生成”“可能性”“整体”“和谐”每次出现是否受六项条件约束？
4. 每一个经验主张是否有条件、证据或降级语气？
5. 是否把制度性恶全部解释为无主结构，从而让行动者免于责任？
6. 是否把个人善行当成解决制度问题的替代品？
7. 是否有群体、弱者、未来者或反对者只被代言而没有发言位置？
8. 治理方案是否也接受反支配和可纠错检验？
9. AI 章节是否区分模型、代理、用户、部署者、受影响者和治理者？
10. 结尾是否由全书推出，而不是靠宏大修辞抬高？

### Gate 4：三版交叉校验

不将三版平均合并，而制作概念覆盖表与论证差异表。若某版独有的论证修复了共同漏洞，可在保持作者声音的前提下分别补入；结构与文体差异保留。检查中文术语和英文概念是否真正等价，尤其避免：

- generativity 被误解为 productivity；
- possibility space 被误解为选项数量；
- harmony 被误解为无冲突；
- order 被误解为服从；
- alignment 被误解为迎合当前偏好；
- dao 被误解为可编码的最高效用函数。

## 十五、完成的定义

v2 的完成不等于理论从此不可反驳。一个声称没有任何可能漏洞的理论，恰好违背本书对可纠错性的要求。这里的完成是：

- 所有价值前提公开，没有把“应当”伪装成自然事实；
- 核心概念边界清楚，推导没有循环或暗中换义；
- 最强反例进入正文而非被回避；
- 对权力、冲突、稀缺、责任、不可逆性和治理俘获有明确处理；
- 理论既能解释个人实践，也能解释结构选择，且不互相替代；
- AI alignment、社会学、经济学和哲学读者能够准确指出他们不同意哪一个前提或机制，而不是因文本含混而无法批评；
- 三版各自构成完整著作，彼此独立，又不背离共同理论契约；
- 读者即使不接受“大道”“仁义礼智”等语言，也能沿普通语言中的论证抵达同一问题；
- 结论不是要求世界服从本书，而是使本书本身也留在可质疑、可修正、可继续生成的世界之中。

只有达到这些条件，`生生不息论 v2` 才进入可供真正批评、传播和继续发展的起点。
