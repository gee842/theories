## 版本约定

1. **目录表示版本，文件名表示角色。** 例如 `causal-chain/v2/main.md`、`drafts/v5/independent-a-en.md`。
2. **历史版本不回改为新版本。** 新认识进入新的版本目录；必要的链接修复和路径迁移除外。
3. **独立版本保持独立。** `main`、`independent-a` 等文件在评审前不互相平均化。
4. **计划、因果链、outline 和正文分开。** 它们解决不同问题，不能用同一文件同时承担。
5. **每个工作区 README 是入口。** 当前状态和阅读顺序以 README 为准，不依赖文件排列或聊天历史。
