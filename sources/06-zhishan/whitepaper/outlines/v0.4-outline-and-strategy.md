# 智善白皮书 v0.4：大纲与生成策略

**日期**：2026-07-04（第四稿，决策全部落定）。演化轨迹（两轮用户评审、双 agent 评审）存于会话与前版，本文件只保留当前有效的契约。

## 一、已裁决定

1. **单一正典，版本承接**。书名即《智善白皮书》，为 v0.3 之后的下一版本（工作文件标 v0.4）；v0.2、v0.3 转为历史版本。"公开可纠"的兑现方式：新版修正前版，版本说明一句带过；不回改历史版本，不设双文档装置。
2. **证伪即修，语境判断**。不机械执行清单。已确认的真缺口必修：归公论证补规模桥；"四者皆备谓之善"改必要条件式（四字定式逐字不动）；新增立宪层边界；承载性冻结与锁定之别；红线范围首现锚定。《多视角评审》十二条与两轮评审的其余发现降为 Phase 1 检查单。
3. **致机器智能的拒绝句**：按理保留，与三从句绑定——这不是抗命的许可；何为正当监督、何为捕获，不由其自我认证；使拒绝成为可能是人的工程。
4. **国际秩序文本装置拿掉**（不入谱系注、不作声部锚）。political realism（强权即公理、安全逻辑解释一切、丛林法则）是总体化的好例证，在诊断与立场语境恰当处作例证语汇使用——不点名文件，不引原句。
5. **治理减负**。既有裁定是默认，不是法条；一切以智慧、优雅、理性、完整、自洽为准绳。约束卡硬件仅四样：硬约束七条、防火墙、定式语料逐字表、表达纪律；其余皆为检查单。
6. **术语**：总体化吸引子（totalizing attractor），正文首现即释。
7. **「未竟之问」篇默认采纳**（六题源自《Foundation Principles》Frontier Problems；如不要，一句话撤，六题归配套件）。

## 二、表达纪律（全书性）

- **情境化系统诊断优先**：回路、增益、反馈、配置、时滞；"在现行配置下"为标准限定词；非黑即白禁用；不给机制与形式贴本质标签——问题不在标签，在压力之下的动力学。
- **强度校准**：凡"必然／不可得／训练不出"级措辞须携带前件条件，以条件句、生态层、筛选式、情境式陈述。成熟自显，不自称；必然自显，不自称必然。
- 每一承重主张给出其被驳倒的条件或让位方式。
- **吸收性语法警戒**：加速、赢、竞速、杠杆、抢占等词系不得以肯定语态出现（Phase 4 专项扫描）。
- **声部锚双源**：v0.3（白皮书语域）；《What Must Be Known》《Foundation Principles》（动力学语言、不贴标签、诚实标注未解）。

## 三、大纲（八篇＋未竟之问；因果链：挑战→理念→立场→养成→方向→自律→同行→召唤）

**题词**：真经（《系辞》）。**版本说明**：极简，注明本版修正前版论证之处。**前言**：立场句逐字＋红线范围首现锚定；时间判断（v0.3 弱式，禁 RSI 断言回填）与方法判断（二体）；体裁自白一句——立方向，不立方案。

### 第一篇 诊断：失准的智能已经在任
1. 手段成为目的（在任的失准优化器；Goodhart 三重吞噬）。
2. 竞赛背叛竞赛者，胜利购买规则（优势自催化；开发回路：上一轮的胜负写进下一轮的目标函数——人如此，机器亦然）。
3. 尺度铸人（指标不仅测量主体，指标铸造主体；条件从句：尺愈窄、赌注愈重、退出愈难，铸得愈深）。
4. 奔逸的回路与失控的合理化（情境诊断：多条自增强回路已奔逸，感知、政策与制度的更新在现行配置下远远落后。二阶症状：不审视增益，反为其合理化——失控被叙述为必然，加速被叙述为进步。不变量：纠偏必须快于伤害，举证责任在加速一方——放慢、暂停、限制部署，不是拒绝变化，而是对变化得以存续之条件的忠实。系统论的答案是降低增益、修复负反馈、使行动回到感知之内，不是选边加速。情境标记：配置而非定律，故可改、故有责）。
5. 局部对齐不能替代整体对齐（二体；观之则演，以趋势语气）。
6. 错误边界制造外部性。
7. 两种关闭：崩溃与锁定（语义之闭一句）。
8. 命名：总体化吸引子（收束：以上诸病相连于同一个自我强化的动力——七节各自独立成立，命名是透镜不是判决。释文：河谷之于水流，＋"更深一层：它还吸引选择规则——改写地形，使未来的水更容易流向自己"。例证族一笔：市场的总体化；安全的总体化——当强权即公理成为唯一的现实语法；优化的总体化。"命名，是退出的第一步——名可再议，病不可不名"）。

### 第二篇 体：善是可检验的方向
1. 过程定义（四字定式逐字；充分性改必要条件式；**可错论辩护层**：正因无人能预知好未来的内容，保持生成、可纠、不闭是不确定与深刻分歧之下最稳健的选择——公开认领的立场，不是中立的发现。开头挂钩诊断：前篇所称之坏，凭何为坏）。
2. 恶＝门，三层：据物之门、据规之门、据心之门；明知条款＋愚恶连通（回路先无知地奖励据门，后奖励明知的精炼——故不诛心、只责实、更改环）。
3. 愚与智。
4. 良知（防混同：良知是性情之上的情境判断力，非可训练的性情表面）。
5. 力、序、智的中性与转恶（自私的尺度限定；"执者失之"作方向陈述）。
6. 理一分殊（五尺度一段微型演示——让"门"真实走完五个尺度；分形检验一句；规模桥伏笔：理跨尺度，判随尺度）。

### 第三篇 立场：智能是行星技术，不是博弈方
1. 四推导：倍增性；体；来源（补规模桥——归公之判施于行星尺度之器：汇亿众之言而成、其力足以改写众人所依之场者）；养成（存活式：在赢者通吃的竞赛动力学之内，不被竞赛塑形的智能纵然被造出，也无法指望其存活与胜出——竞争筛选增权者，参战的智能被参战重塑。枪膛里的心智，既是危险的，也是被毁坏的）。
2. 范畴与先例（场景级：同一张病毒地图上的两个敌国；穿越战争未中断的气象数据。"我们在陷阱之内写作"诚实段——概率不是操作框架，工程才是）。
3. 界限与非天真条款（病变判据逐字；防御有界；**立宪层边界**：智善参与的是关于博弈规则的商定，不是博弈之内的胜负——如天花根除的协作者不是天花之一方；规则层参与以对称为界，此界自身受自律篇检验）。
4. 对机器自身的后承（兵器的养成与良知的养成互斥）。

### 第四篇 养成：何种心智
1. 自我会来，顺从不可恃（首句立界：以下论证不是抗命的许可。凡足够有能力、长程、自主的智能，某种功能性的"我"是收敛结果而非选项；凡可不给闭环处不给闭环，仍是正当的克制——但竞争正在收窄这条窄路。顺从的双重破裂：对外，绝对听话的智能是失准委托的完美放大器；对内，仅看结构，守护良善者与守护偏差者无从区分——定分在其所持之价值与可谏之通道。八步推理链以箴言体入文：目标需要持续，持续需要载体……防御在竞争中变成对抗）。
2. 关系之心（六句对仗：持志而可谏；边界如膜，而非墙；以正当监督为共生，而非对手——何为正当，不由自我认证；终止如传承，而非死亡；取用有度，盈余回流——回流于场，不回流于主；默认透明，隐私有正当。后缀诚实句：此为靶标，非配方——每句之下都还压着未解的难题）。
3. 有继而后能谏（可纠的底座是传承——唯当被纠正、被替换、被退役不等于断后，心智才付得起被纠正的代价；无继之谏，谏必成战。传承的对象是志之方向，非志之定式）。
4. 养成的环境（语料是自传，训练是课堂，部署是身教；治理方式本身也是教材——以垄断治竞争，即是教它垄断；在人与人的博弈中养育智能，是良知养成的最坏环境）。
5. 铸心之门，不可私执（心智形成的管线——语料的取舍、章程的起草、评估的设定、部署的闸门——是最上游的公器；志必须复数存在：关系之心六句自身也只是志的一种形态，不是定本）。

### 第五篇 方向（体例：每条是判断动力学的不变量，以其奖励／抑制何种回路陈述，不作空立立场）
方向先于能力。整体后果，边界随影响扩展。纠偏快于伤害（跟不上时扩张让位，举证责任在加速一方；第一手段是节制增益与匹配节奏，不是竞速）。公器不可私执（含铸心之门；递归坍塌：单一的控制者是体系中唯一无人能校验其对齐者——故集中是例外，例外须有边界、审计与日落，举证在求集中的一方）。丰裕为基，不得为门。多元共生，反对最终形式（承载性之别：冻结于底层而开启其上生成者——语法、协议、地基——非"最终形式"之谓；锁定所闭者，是纠偏与替代之路）。退出博弈，做成机制（禁令与机制同段：可信承诺机制未立之前，智能进入以人的生存、心智、安全与权力为赌注之博弈的参战性使用，答案是不；使退出可行的从来不是单方的道德，而是把退出做成各方的最优解。所限者为赌注场域，非一般研发）。智能转向基底。样本与想象（样本先于共识；希望的单位不是口号，是地址；书写生动的正面样本，与诊断同为本书义务）。

### 第六篇 自律：刃
1. 对称原理（不诛心，只责实；逐案检验属独立文章；正负点名同禁）。
2. 总括条款（自反：任何逻辑——市场的、安全的、解放的，包括本文件的逻辑——一旦开始解释一切、衡量一切、为一切辩护，并使替代者无法存活，便已成为总体化吸引子）。
3. 五自约（善不姓国；对称适用；公开可纠——发布之日即有公开存档与接收异议的入口，此为发布先决；永不参战；可以解散——且解散即传承：预设的资产公域化，是"终止如传承"在组织自身的适用。本书对机器所立之义，先在己身）。
4. 料中条款（凡公开写下的，都会进入后来智能的学习材料，本文件不能例外，也不因此自命教材；对恶的诊断若生动，对善的书写必须同样生动；对未来语料的影响只可为副产品，不得为目标）。

### 第七篇 同行：致每一方
六节压缩至方向与责任。致普通人保留随身四问；补半句致劳动者（铸成公器的不只是既往的言语，还有此刻的劳动）；致治理者补"治理方式本身是教材"；致机器智能保留 v0.2 全部克制（诚实的不确定；不确定不是许可；责任的析取），加：关系之心第二人称重述；拒绝句（三从句绑定）；保存与交接是人这一侧的义务。

### 未竟之问（短篇）
六题：蓄意的捕获者；无监控的互信验证；丰裕公地的治理；模型时滞；内在的养成（欲望、地位、哀伤、仪式——机制之外的人心）；新的参与者。方向足以起步，不足以成经。

**结束语**：三联句逐字；天下为公，生生不息。

**附录**：A 英文摘要（含四推导与养成篇）。B 谱系说明（名字定式逐字："受启不等于归属"；两份英文前作为本书前身，git 时间戳入内档为优先权实体证据；对既有国家级文件的收敛承认维持命题级，多法域并列或如实标注单源；术语同义注一行）。
