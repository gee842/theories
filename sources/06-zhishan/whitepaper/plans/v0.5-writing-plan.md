# 智善白皮书 v0.5 写作计划

> 路径说明：本计划中的历史产物名保留其逻辑名称；实际生成的新文件应按 [`whitepaper/README.md`](../README.md) 的版本目录规则放置，不再写回仓库根目录。

本文件只制定 v0.5 的写作计划，不生成 v0.5 大纲，不生成正文。下一步应先按本计划完成“硬桥梁调查包”，再生成 v0.5 大纲。

## 一、总判断

v0.4 虽有漏洞和结构问题，但整体仍然很强。它之所以能成立，不是因为一次性写作，而是因为前期采用了类似 deep research 的策略：多源材料整合、多轮论证、多视角审阅、逐步收敛，最终让“失准优化、总体化吸引子、行星技术、关系之心、自律之刃”形成了一条完整思想链。

v0.5 的目标不是推翻 v0.4，也不是把它改成政策手册。v0.5 的任务是升级生成方法：把 v0.4 中最有力但最脆弱的强桥梁，先做成可审查、可反驳、可修订的写作工件，再让正文吸收。

一句话策略：

> v0.5 不从改正文开始，而从制造硬桥梁开始；先调查、分层、定判据、定机制，再出大纲，再逐章生成，再单手合成，再总体校验。

## 二、v0.5 的核心目标

v0.5 应把《智善白皮书》从“强思想性白皮书”推进为“可经专家审阅的分层论证白皮书”。

具体目标：

1. **保留主旨**：智能应为善；AI 不应成为人类高赌注博弈的一方；智能的正当位置应趋向行星公器。
2. **保留深度**：不把 v0.4 压扁成政策条文，不牺牲机制推导、中文思想文的节奏和自反性。
3. **修复强桥梁**：把“本质上”“必然”“归公”“自我会来”“答案是不”等强句改成分层、条件化、可反驳的命题。
4. **补足可审性**：让 AI alignment、社会学、经济学、哲学专家能看见定义、边界、成立条件、反例、指标和机制。
5. **减少重复**：每章只承担一次主论证；后文调用前文概念，不再重演完整推导。
6. **保持结论后显**：让读者先理解失准配置、判断判据、风险分层与参战边界，再推出中心立场。

v0.5 合格的标志，不是文字更顺，而是：

> 一般读者仍能读到 v0.4 的庄重、锋芒和美感；专家读者则能指出每个强主张的定义、成立条件、可能反例和检验程序。

## 三、v0.4 问题到 v0.5 任务的转换

| v0.4 问题 | v0.5 写作任务 | 产物归属 |
| --- | --- | --- |
| 智能、对齐、主体层级混用 | 建立层级风险模型，区分技术失败、部署脚手架、委托人失准、市场竞赛、制度捕获、主体形成 | 大纲前置工件；正文短引；附录详表 |
| “AI 不入博弈”边界不够可判 | 制定参战性使用三档判据：允许、限制、禁止/暂停 | 正文桥梁章；附录案例矩阵 |
| 规范红线与可执行机制之间有缺口 | 拆分“规范答案是不”与“均衡机制如何可行”；建立激励相容退出模型 | 正文机制纲领；附录模型 |
| 公共来源推出公器归属过快 | 改为“公共治理义务”：当 AI 栈某层成为众人必经之门，触发反捕获约束 | 正文重写；附录 AI 栈表 |
| “自我会来”过于必然化 | 改为“无身自维结构的条件性形成模型” | 正文养成章；附录条件表 |
| 善/恶定义存在张力 | 善改为最低方向；恶拆为恶性配置、恶行、恶意 | 正文体篇；术语表 |
| 总体化吸引子宏观有力但中层机制不足 | 建立权力捕获机制图谱：所有权、标准、接口、数据、劳动、法律例外、平台锁定、专业权威 | 正文诊断章；案例库 |
| 行星技术先例外推过快 | 将先例改为可能性证明，并补条件比较 | 正文短段；附录比较表 |
| 纠偏快于伤害缺变量 | 定义可纠偏指标：发现延迟、申诉延迟、回滚能力、迁移成本、替代可得性、审计独立性 | 附录指标；正文只写原则 |
| “致机器智能”有安全风险 | 改为协议语言：拒绝边界来自外部授权、公开政策、日志、审计和申诉链 | 正文短版；文学长版可入附录 |
| “不点名”削弱可证伪性 | 区分阵营式点名与中性案例研究 | 自律章；配套件规则 |
| 第五篇、第七篇重复推进 | 第五篇只写判据和机制骨架；第七篇只写各方新增责任 | 结构调整 |

## 四、v0.5 的总写作原则

### 1. 机制先行，结论后显

v0.4 的中心立场仍保留，但 v0.5 不应一开始就把“AI 不应加入人与人的博弈”完整展开。前言可以立方向，但不可提前完成第三、第四、第五篇的工作。读者应先经历：

失准配置已经在任 -> 善恶判据何以成立 -> AI 风险层级如何相连 -> 什么叫参战性使用 -> 为什么行星公器是正当位置。

### 2. 硬桥梁先于正文

v0.5 的最大风险，是继续用优雅语言掩盖桥梁不足。因此在写大纲之前，必须先产出硬桥梁工件：

- 核心术语表。
- 命题强度表。
- 层级风险模型。
- 参战性使用判据。
- 无身自维结构条件模型。
- AI 栈公器属性表。
- 激励相容退出机制最小模型。
- 行星技术先例条件比较表。
- 纠偏与伤害操作化指标。
- 中性案例与反例库。

这些工件不是全部塞进正文。正文保留理论推进；附录承接专家审查。

### 3. 正文优雅，附录硬

正文不应成为表格堆砌，也不应丢掉 v0.4 的声部。表格、三档判据、案例矩阵、指标和机制模型优先进入附录；正文只吸收它们的结论性桥句。

### 4. 强句必须带前件

所有“必然”“本质上”“任何”“所有”“不可避免”“归公”“自我会来”等强句都要被检查。保留强句时，必须写明：

- 适用层级。
- 成立条件。
- 让位方式。
- 可驳倒情形。

### 5. 反总体化必须反用于自己

v0.5 不能把“智善”写成不可反对的总理论。每个核心主张都要保留自反刀口：它如何可能变成新的门、尺度、认证权或总体化吸引子。

## 五、阶段流程

### Phase 0：契约冻结

目的：在调查和写作前，冻结 v0.5 的目标、边界和不可动约束。

输入：

- `whitepaper/drafts/v0.4.md`
- `whitepaper/reviews/v0.4-multi-review-report.md`
- `whitepaper/outlines/v0.4-outline-and-strategy.md`
- `whitepaper/process/v0.4-drafting-constraints.md`
- `whitepaper/reviews/v0.4-multi-perspective-review.md`

产物：

- `v0.5 写作契约`
- `v0.4 问题台账`
- `不可动约束表`
- `正文 / 附录 / 配套件边界表`

子agent：

- 主编 agent：冻结目标和工作边界。
- 约束管理员：确认四判据、善不姓国、对称之刃、永不参战、公开可纠等约束。
- 红队预检 agent：标出任何会直接导致 v0.5 重蹈 v0.4 漏洞的方向。

闸门：

- 每个高优先级漏洞必须被归类为：入正文、入附录、入配套件、承认开放、拒绝采纳。
- 若高优先级漏洞无归属，不进入 Phase 1。

回滚：

- 若发现目标混乱，例如同时要“白皮书正文”“政策方案”“传播口袋版”，则退回契约冻结，拆分版本族。

### Phase 1：硬桥梁调查

目的：先补 v0.4 的承重桥梁，不写大纲，不写正文。

产物：

1. **核心术语表草案**
   - 智善
   - 善
   - 恶性配置 / 恶行 / 恶意
   - 总体化吸引子
   - 支配性优化
   - 门 / 捕获
   - 行星技术
   - 行星公器
   - 主体四分
   - 无身自维结构
   - 可纠错性
   - 非支配自由

2. **命题强度表**
   - 定义
   - 规范判据
   - 经验机制假说
   - 条件预测
   - 政策推论
   - 修辞召唤

3. **层级风险模型**
   - 模型能力层
   - 训练/目标层
   - 部署脚手架层
   - 委托人/组织层
   - 市场与安全竞赛层
   - 制度治理层
   - 潜在主体形成层

4. **参战性使用判据**
   - 允许
   - 限制
   - 禁止/暂停

5. **无身自维结构条件模型**
   - 长程目标
   - 持续记忆
   - 环境行动
   - 资源调度
   - 自我状态建模
   - 在线更新
   - 竞争性部署
   - 低替代性

6. **AI 栈公器属性表**
   - 知识
   - 数据
   - 算力 / 能源
   - 模型权重
   - 接口 / 平台
   - 高赌注部署场景

7. **激励相容退出机制最小模型**
   - 参与者
   - 行动集
   - 可观察项
   - 守约收益
   - 背弃成本
   - 核查机制
   - 争端解决
   - IC/IR 条件

8. **案例与反例库**
   - 灰区案例：教育推荐、医疗分诊、法律检索、劳动自动化、内容推荐、网络防御、自动裁断、军事/安全治理、开源模型。
   - 正面样本：公共数字基础设施、互操作标准、开放科学、地方公地、合作社式数据治理、公共卫生 AI。
   - 反例：防御性 AI、开源双刃剑、公共 AI 被国家垄断、竞赛产生公共能力的情形。

子agent：

- 概念分层 agent：术语表、主体四分、善恶分层。
- AI safety agent：层级风险模型、无身自维结构、机器拒绝协议。
- 经济与博弈 agent：激励相容模型、退出机制、丰裕底座。
- 制度社会学 agent：权力捕获机制、行动者图谱、中层组织路径。
- 系统科学 agent：回路、增益、负反馈、纠偏速度、条件预测。
- 案例 agent：中性案例与反例库。
- 逻辑红队 agent：定义循环、莫特-贝利、不可证伪、自我豁免。
- 政治误读 agent：盗用、阵营化、命名来源和善不姓国风险。

闸门：

- 每个调查包必须包含：可支持主张、反例、成立条件、失败条件、最小文本影响。
- 只产出口号的调查包，不得支撑正文；要么重做，要么降为开放问题。

回滚：

- 若某一承重主张找不到成立条件或可检验边界，则不得进入正文作为强断言，只能进入“未竟之问”或配套研究。

### Phase 2：v0.5 大纲生成

目的：用 Phase 1 的硬桥梁生成大纲。此阶段才开始设计 v0.5 的正文结构。

产物：

- `智善白皮书-v0.5-大纲.md`
- 章级 brief
- 承重命题图
- 正文 / 附录 / 配套件分配表
- 重复压缩表

大纲原则：

1. 不让前言提前完成第三、第四、第五篇工作。
2. 不把“AI 不应加入博弈”作为未经推导的开场结论。
3. 新增或强化桥梁位置：风险分层、参战性使用、规范红线与均衡机制。
4. 每一章只完成自己的论证任务。
5. 第五篇之后只调用前文概念，不再完整复述。

推荐的结构方向，不是最终大纲：

1. 前置导读：术语与命题分层。
2. 第一章：失准配置已经在任。
3. 第二章：善、恶、智、愚的最低判据。
4. 第三章：从技术对齐到文明失准的层级模型。
5. 第四章：什么叫 AI 加入人与人的博弈。
6. 第五章：智能的位置：行星技术与公器资格。
7. 第六章：无身自维结构与关系之心。
8. 第七章：方向不变量与退出机制纲领。
9. 第八章：自律之刃、同行与未竟之问。
10. 附录：术语、模型、案例、谱系、英文摘要。

闸门：

- 读者必须能从机制推到立场。
- 每个承重命题必须有章节位置。
- 每个专家漏洞必须有正文或附录归属。
- 若大纲只是 v0.4 旧结构加补丁，则退回重排。

### Phase 3：章节 brief 与约束卡升级

目的：在逐章生成前，给每个章节明确任务和禁区，避免 chapter agent 自由发挥。

每章 brief 必须包含：

- 本章要解决的问题。
- 本章承接上一章的入口。
- 本章输出给下一章的结论。
- 本章可以使用的术语。
- 本章不得重演的前文论证。
- 本章强断言清单及条件化要求。
- 本章应引用的 Phase 1 硬桥梁。
- 本章应留给附录的内容。

升级后的约束卡必须包含：

1. 机制先于判断。
2. 强断言必须条件化。
3. 术语不得跨层漂移。
4. 不重复证明，只允许必要回声。
5. 不用阵营式点名；案例研究另有边界。
6. 不用“公器”掩盖制度设计。
7. 不让机器自证正当监督。
8. 不把附录欠条伪装成正文完成。

闸门：

- brief 未通过，不允许进入起草。
- 若一个章节需要修改核心定义，必须回到总纲仲裁。

### Phase 4：逐章生成

目的：按 brief 逐章生成草稿，保持并行效率，但避免并行造成术语漂移和重复。

分工：

- 每章一个起草 agent。
- 相邻章节互审 agent，检查承接和重复。
- 术语守门 agent，维护术语表。
- 强度审计 agent，扫描“必然”“本质上”“任何”“所有”等词。
- 附录映射 agent，检查该进附录的内容是否误入正文。

每章交付：

1. 章节草稿。
2. 入口承接句候选。
3. 出口结论句候选。
4. 自查表。
5. 强断言列表。
6. 术语使用列表。
7. 重复风险说明。
8. 未决问题。
9. 溯源注记。

闸门：

- 机制链条完整。
- 本章没有承担别章任务。
- 强断言有前件和让位方式。
- 术语未漂移。
- 不靠修辞跳桥。

回滚：

- 若章节靠警句替代论证，退回 brief。
- 若章节重复前文完整推导，退回压缩。
- 若章节修改核心概念，暂停并回到 Phase 2/3 仲裁。

### Phase 5：单手合成

目的：把逐章草稿统一成一个声音。合成不是拼接，而是重写。

原则：

- 只允许一个统稿者执行最终合成。
- 其他 agent 此时只提供问题清单，不再改正文。
- 统稿者有权删并重复、重写承接、移动段落、压缩附录化内容。

产物：

- `智善白皮书-v0.5-draft1.md`
- 删并表。
- 术语一致性表。
- 变更说明。
- 附录映射表。

闸门：

- 声部统一。
- 前言不吞掉后文。
- 第五、第七、第八章不重复前文。
- 附录不制造悬空承诺。
- 核心术语全书一致。

回滚：

- 若合成改变论证含义，相关章节回炉。
- 若语域塌陷成政策报告，回到 v0.4 声部锚重新统稿。

### Phase 6：总体校验

目的：对 draft1 进行多路审阅，找出结构性问题，而不是只修句子。

审阅组：

- AI alignment / AI safety。
- 社会学 / 制度分析。
- 经济学 / 博弈论。
- 哲学 / 概念分析。
- 系统科学。
- 逻辑红队。
- 政治误读红队。
- 普通读者。
- 劳动者 / 被部署影响者视角。
- 文风与术语审校。

产物：

- 审阅矩阵。
- P0/P1/P2 问题表。
- 修订计划。
- 是否可进入 final candidate 的裁定。

问题分级：

- P0：概念矛盾、结构坍塌、核心命题不可判、严重自我豁免。
- P1：承重论证薄弱、强断言未条件化、机制缺口、章节重复。
- P2：术语小漂移、表述重复、局部例证不足、行文不顺。

闸门：

- P0 必须为零。
- P1 必须全部有修法、承认开放或明确承受。
- 所有“必然 / 本质 / 不可得 / 任何 / 所有”必须被标为演绎、机制、倾向或断言，并相应修正。

回滚：

- P0 回到大纲或硬桥梁阶段。
- P1 回到章级修订。
- P2 进入统稿修订。

### Phase 7：最终整合

目的：定稿前只做收敛，不再扩张。

产物：

- `智善白皮书-v0.5-final-candidate.md`
- 最终校验报告。
- 附录清单。
- 配套件清单。
- 后续版本问题台账。

闸门：

- 无新增承诺。
- 无旧强断言残留。
- 正文、附录、配套件边界清楚。
- 公开可纠入口和版本谱系状态清楚。
- 机器智能段不构成自我授权。
- 公器论证不偷换为单一公共所有。
- 参战性使用有可判边界。

回滚：

- 终审若新增大结构问题，冻结发布，回到对应阶段；不做临场补丁。

## 六、子agent 配置

v0.5 建议使用以下最小 agent 组：

1. **主编 agent**
   - 负责契约冻结、总纲、统稿、最终裁定。

2. **机制主线 agent**
   - 保证“失准配置 -> 支配性优化 -> 参战风险 -> 退出机制”的链条完整。

3. **概念分层 agent**
   - 负责智善、善、恶、主体、公器、行星技术、总体化吸引子、支配性优化、无身自维结构。

4. **AI safety agent**
   - 负责技术对齐与文明对齐分层、无身自维结构、机器智能段、拒绝协议、corrigibility 相关风险。

5. **经济与博弈 agent**
   - 负责激励相容、可信承诺、核查、背弃收益、制裁、融资、丰裕底座。

6. **制度社会学 agent**
   - 负责行动者图谱、权力捕获机制、中层组织路径、劳动与平台关系。

7. **案例 agent**
   - 负责灰区案例、正面样本、反例与案例边界。

8. **逻辑红队 agent**
   - 抓定义循环、莫特-贝利、不可证伪、自我豁免、裁判权问题。

9. **政治误读 agent**
   - 抓国别化、阵营化、盗用、武器化、宗教化风险。

10. **普通读者 / 劳动者视角 agent**
   - 检查是否有人、事、场景；检查劳动者和被部署影响者是否仍缺席。

11. **文风守护 agent**
   - 保持 v0.4 的语气、节奏、警句密度和机制优先，不让文本变成政策备忘录。

12. **术语守门 agent**
   - 维护术语表与全书术语一致性。

## 七、写作声部与术语约束

### 1. 四个核心术语的层级

- **支配性优化**：机制。指优化结果被转化为支配位置的动态：优势取得资源，资源购买规则，规则筛选下一轮优势。
- **总体化吸引子**：系统形态。指多个领域被同一种“何为胜”的语法吸入，并进一步吸引选择规则。
- **无身自维结构**：潜在心智 / 代理结构。不是灵魂、意识或权利判断，而是条件性功能结构。
- **行星公器**：正当位置与治理资格。不是单一公共所有，而是反捕获的公共治理义务。

不得互相代替。

### 2. 不允许回退的表达纪律

- 不把“善”写成充分公式。
- 不把“恶”完全系于主观明知。
- 不把“AI 对齐”完全吸收到文明论。
- 不把“公共来源”直接推出“公共所有”。
- 不把“自我会来”写成无条件必然。
- 不把“退出博弈”写成单方道德呼吁。
- 不让“行星技术”成为自我授予的称号。
- 不让“八问”或任何判据成为新的合规证书。

### 3. 警句规则

v0.4 的美感来自推导后的警句。v0.5 仍应保留，但必须遵守：

- 没有机制铺垫的警句，降级为待论证句。
- 同一警句全书最多完整展开一次。
- 后文可回声，不可重复证明。
- 警句必须能被其前文支撑，而非替代前文。

## 八、目标结构方向

这不是 v0.5 大纲，只是大纲生成时的结构方向。

1. **前置导读：术语与命题分层**
   - 让专家知道本文不是把所有问题压成一个总理论。

2. **失准配置已经在任**
   - 诊断现行配置，不提前推出完整 AI 立场。

3. **善、恶、智、愚的最低判据**
   - 建立判断尺，不写成文化中立发现，也不写成充分公式。

4. **从技术对齐到文明失准的层级模型**
   - 新增桥梁，阻止跨层偷换。

5. **什么叫 AI 加入人与人的博弈**
   - 新增操作化章，处理允许、限制、禁止三档。

6. **智能的位置：行星技术与公器资格**
   - 在前述桥梁之后正式推出中心立场。

7. **无身自维结构与关系之心**
   - 保留原创性，但条件化主体形成。

8. **方向不变量与退出机制纲领**
   - 压缩九条原则，拆开规范红线与均衡机制。

9. **自律之刃、同行与未竟之问**
   - 防止智善自身成为门；分配责任；保留开放问题。

10. **附录**
   - 承接术语、表格、模型、案例、谱系、英文摘要。

## 九、v0.5 的附录策略

正文负责推导；附录负责可审。

建议附录：

1. 核心术语表。
2. 命题强度表。
3. 层级风险模型。
4. 参战性使用判据与灰区案例矩阵。
5. 激励相容退出机制最小模型。

- 正文引用附录时，只引用已经被消化过的结论。

## 十、质量门槛

### P0：不可进入下一阶段的问题

- 核心术语跨层漂移。
- “AI 不入博弈”仍无可判边界。
- 公器论证仍从公共来源直接跳到公共所有。
- 无身自维结构仍被写成无条件自我必然。
- 善恶判据仍存在充分性或主观明知硬矛盾。
- 规范红线与均衡机制仍混在一段不可区分。
- 文本自身形成免疫结构，无法被同一判据审查。

### P1：必须修或明确承受的问题

- 行星技术先例外推过快。
- 纠偏快于伤害缺指标。
- 中层制度机制不足。
- 劳动者、普通受影响者、地方组织缺席。
- 第五篇和第七篇重复推进。
- 机器智能段有自我授权误读。
- 不点名原则削弱案例检验。

### P2：统稿阶段修正的问题

- 局部重复。
- 警句过密。
- 表格或附录引用不顺。
- 章节承接略硬。
- 术语首现解释不足。
- 英文摘要与正文不一致。
