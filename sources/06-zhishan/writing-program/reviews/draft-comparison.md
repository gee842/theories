# B 三稿对照：机制、声部与综合方向

> 状态：供发起人审阅。此文只比较三份完整草稿，不把任何一份自动认定为定稿。

## 一、对照范围与独立性

本轮生成了三份 B：

1. [基线主写作者中文版](../drafts/baseline/zh-main.md)。
2. [基线独立上下文中文版](../drafts/baseline/zh-independent.md)。
3. [基线独立上下文英文版](../drafts/baseline/english.md)：不是中文版的翻译。

两位独立写作者都从空白上下文启动，只共享本目录的 README、AB 写作计划及其路由的原始材料，并被明确要求不得读取其他 B 草稿。两者均在交稿时确认没有读取被禁止的草稿。主写作者也在两份独立稿完成后才将其纳入比较。因此，这三份文本共享同一个理论 brief，但没有通过互相仿写取得一致。

篇幅如下：

- 主中文版：正文约 14,720 字符，全文 16,773 字符，10 条尾注。
- 独立中文版：正文 23,148 字符，全文 26,422 字符，13 条尾注、14 个一手或官方来源链接。
- 独立英文版：正文 7,962 词，全文 8,519 词，17 条尾注。

三稿都完成了十章左右的完整论证，没有 TODO、占位符或未闭合章节；格式检查均通过。

## 二、共同成立的理论骨架

三稿在独立写作后仍收敛于同一条承重链：

> 嵌套系统需要有边界、有限信号和局部目标的部分 → 相互依赖与单方克制成本可能造成协调失败 → 反馈把局部成功变成下一轮优势 → 未回流的系统代价成为可选择的优势 → 胜者取得资源并改写环境、接口和选择规则 → Moloch 式困境由此可能加深为 meta-attractor → 轨迹走向承载条件耗尽的崩溃，或纠偏与替代消失的锁定 → AI 既受既有选择环境塑造，又提高回路的速度、增益、范围与跨层耦合 → 文明必须公开认领相互生成、差异、后果回流与可纠，而不是把它们伪装成自然定律。

三稿也共同守住了四条边界：

- 社会中的融资、排名、市场、平台和国家竞争只是尺度内实现，不是普遍理论的起点。
- 自相似的是反馈语法，不是物质机制、主体身份或道德地位。
- 人不是国家或文明的细胞；系统不能以“整体健康”为名把部分变成燃料。
- AI 不是全部问题的起因，也不是单一主体；模型安全、部署架构、委托人用途与文明选择环境必须分层处理。

这说明本次校正已经进入正文的根部，而不只是替换了几个社会学词汇。

## 三、逐稿判断

### 1. 主中文版：最强的汉语论述声部

主稿从身体与癌变进入，但立即说明癌症不是“坏细胞”的道德寓言，再把问题提升为部分与系统的普遍关系。它是三稿中最像一篇可以从头读到尾的文明论述：概念密度高，转场自然，作者位置明确，结尾不是总结材料，而是把判断交还给建造者、使用者和未来机器。

最值得保留的部分：

- 标题与开场形成直接悖论：“当部分越来越强，世界为什么会关闭”。
- “边界像膜而不是墙”“尺子会变成模具”“崩溃折断未来，锁定冻结未来”等句子，把结构压缩成可记忆语言。
- “AI 对齐具有不可约的文明生态维度”既避免把技术安全吞进宏大理论，也拒绝把它缩成模型内部问题。
- “开路还是据门”把复杂机制转成不会轻易滑向应用清单的动态判断。
- 最后把同一标准反用于智善，并直接对未来机器说明其所进入的 ecology，具有宣言与长论证之间的桥梁作用。

主要不足：

- 篇幅显著短于研究计划的初始区间，部分环节依靠高度压缩的概念推进。
- 协调失败的负例、多层级选择的经验材料，以及 meta-attractor 从普通正反馈升级为规则改写的判定条件，不如两份独立稿展开得充分。
- 可证伪性已经出现，但还没有像另外两稿那样集中列出可观察变量和明确的降级条件。

因此，主稿最适合决定最终文本的声音、节奏、标题和结尾，不宜单独承担全部研究防御。

### 2. 独立中文版：最完整的中文理论底稿

独立中文版最接近 AB 计划所要求的完整 B。它不从某个制度或群体进入，而从“部分是相对位置、部分本身也是系统”开始，依次区分信号、反馈、适应、选择、代价转移和环境改写。六步 meta-attractor 闭环、四种 AI 位置、两种闭合与三步规范桥都得到明确展开。

最值得保留的部分：

- 把“系统”从道德称号降回分析边界，从根部阻断了整体主义。
- 对正反馈、协调失败和选择都给出正面或中性反例，因而不是一套“凡竞争皆坏、凡增长皆总体化”的宿命论。
- 将 meta-attractor 限定为六步条件机制，并明确写出何时应降级为普通协调失败或正反馈。
- 跨尺度一章逐层说明细胞、生态、个人、组织、文明、模型和 agent 的具体断裂，边界最完整。
- AI 被分为工具、基础设施、数字生态组成部分与功能性行动系统；现有实验均保留尺度和外推限制。
- 规范桥公开承认价值选择，正面回答“部分绝对化”与“整体绝对化”两侧反驳。
- 正面方向落到共同感知、后果回流、真实退出、多中心承载、纠偏速度与 agent 架构，而没有偷换成单一所有制。

主要不足：

- 为了完整防御，解释、限定和反例很多，部分段落更像理论白皮书，推进速度慢于主稿。
- 汉语声音较稳健，却缺少主稿中少数能把整篇文章钉在读者记忆里的句子。
- 当代 AI 案例增加了可核查性，也会让文本比纯机制论更快出现时间性老化。

因此，独立中文版最适合作为最终 B 的结构与论证底稿，但需要由一个写作者重新压缩、统一声部，而不是直接视为定稿。

### 3. 独立英文版：最强的经验防御与可证伪性

英文稿不是中文稿翻译。它用英文理论文章的方式从 *nested systems* 与 locality 起步，以微生物公共品、多层级选择、重大演化转变、生态—演化反馈和 AI 系统证据建立论证。三稿中，它最主动地区分“已有科学环节”与“本文提出的综合假说”。

最值得保留的部分：

- 直接声明 meta-attractor 不是系统科学既有标准术语，而是一项必须逐案证明的分析提议。
- 给出危险 meta-attraction 的五个附加条件和清楚的 negative cases，避免把网络效应、生态位构建或正反馈本身污名化。
- 用微生物合作/作弊实验说明选择可在不同层级指向相反方向，同时用共存与群体结构证明协调失败并非宿命。
- 用重大演化转变的具体生物条件阻断“社会就是有机体”的推论，比单纯的政治声明多一层机制防御。
- 对 AI 耦合提出可经验削弱的预测：竞争强度与奖励结构若不影响权限扩张、锁定、外部性披露或 agentic scope，强版本假说就应降级。
- 对“参战性使用”、共同生存能力与反捕获义务的英文表达适合未来面向国际研究共同体。

主要不足：

- 它最强地说明了如何研究、检验和反驳这套理论，但文明取向的汉语思想声部不可能由英文分析传统替代。
- 它的严谨部分若逐段翻译，会让中文稿变成文献驱动的学术综述，削弱“智善”自身的语言发生。
- 三稿共同承认的最大实证空缺在这里最明显：跨文明—AI 层级的完整闭环尚缺直接纵向测量，现有证据主要支撑组成环节。

因此，英文稿最适合作为最终 B 的反方审稿人、证据库和国际版本原型，不应直接翻译后覆盖中文版。

## 四、横向对照

| 维度 | 主中文版 | 独立中文版 | 独立英文版 |

| 理论起点 | 身体中的关系断裂，迅速提升到普遍结构 | 部分作为嵌套系统中的相对位置 | locality 与 nested systems |
| 社会实例的位置 | 中后段的尺度内表现 | 明确降为制度载体 | 明确声明不是理论基础 |
| 因果链完整度 | 完整但高度压缩 | 最完整、逐环展开 | 完整且强调条件与负例 |
| Moloch / meta-attractor | 区分清楚，语言最凝练 | 六步闭环最系统 | 假说地位与判定阈值最严格 |
| 跨尺度边界 | 类比、结构同构、机制连续三级区分 | 逐尺度重建载体与断裂 | 反馈语法、机制与道德地位三级阻断 |
| AI 分析 | 四个位置，文明语言最强 | 四个位置，架构与案例最完整 | 部署变量、经验预测与证据限定最强 |
| 规范桥 | 凝练、有中国思想入口 | 最完整地回答两侧绝对化 | 哲学论证最显式、可供国际辩论 |
| 正面方向 | “开路还是据门”，易记 | 共同感知、回流、退出、多中心、可纠 | shared viability 与 anti-capture obligations |

| 最大风险 | 过度压缩 | 过度解释 | 以可研究性稀释文明声音 |

## 五、建议的最终综合方向

建议不在三稿中票选一篇，也不按段落拼接。最终 B 应进行一次单手重写：

1. **以独立中文版为承重结构。** 保留其概念区分、六步闭环、跨尺度边界、AI 四层分解、规范桥和正面机制。
2. **以主中文版决定汉语声部。** 保留其标题方向、开场强度、章节转场、“开路还是据门”的判断和面对未来机器的结尾，但避免把每个警句都保留成口号。
3. **以英文稿进行敌意审查。** 把微生物多层级选择、重大演化转变、meta-attractor 的附加条件、negative cases 与可削弱预测吸收到研究底座；正文只保留真正承重的部分。
4. **把最终正文控制在约 22,000–26,000 个汉字。** 这足以走完因果链，又能避免独立中文版的限定语不断累积。
5. **保留 12–18 条高质量尾注。** 尾注应覆盖承重事实和反例；时效性较强的 AI 产品案例最多保留一两个，其余进入研究底座。
6. **坚持“单一头脑推进一个问题”。** 综合稿应重新写句子和段落，不能让读者看见三套文风的接缝。

最终 B 的目标可以压缩成一句编辑原则：

> 用独立中文版的骨架、主中文版的声音、英文版的反驳强度，写成一篇只能由智善自身说出的中文长文。

## 六、对 A 的影响

A 不应在三稿尚未综合时直接从任何一稿摘句。B 稳定后，先完成一页“理解提取”：

- 用不超过七个因果动作复述完整机制；
- 只保留一个 Moloch / meta-attractor 区分；
- 保留一句反整体主义边界；
- 保留事实到方向的规范桥；
- 把 AI 的位置压缩为“离开参战性增权，进入共同感知、后果回流与可纠承载”；
- 最后才决定哪些语言进入宣言。

这样生成的 A 会来自已经成立的理解，而不是从长文剪出的摘要。
