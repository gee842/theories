## 2. 发现清单（按严重度排序）

**承重级发现：无。** 以下为句级与精修级。

**F1【句级】L105–L107** — "不能把决定后来道路的智能交给**一个正在消灭独立回答的选择过程**"；紧接 L107 无条件的"我们必须改变方向。"
问题："一个正在消灭……的选择过程"在指称上双解：类指读法（任何这样的过程——已被授权）与特指读法（现实中正在运行的那个——断言了 L59 明确拒绝断言的东西："我们还不能诚实地说……已经控制文明"）。
最强攻击：引 L59 与 L99（"当前结论不依赖全球元吸引过程已经被证明"）对照 L105 的进行时"正在消灭"，指控文本在情绪顶点偷运回第三节亲手悬置的强假说，L107 的无条件祈使句正是靠这个特指读法的暗示获得力度。
最小修法：标明类指——"交给**任何一个**正在消灭独立回答的选择过程"；或在 L107 前补一句条件承接（"在第五、六节条件已对具体前沿递归成立的范围内"）。

**F2【句级】L49** — "让**不可替代的**独立感知、拒绝、纠正、退出、维护替代与生产后继者的能力逐渐失去因果作用……只有当这些功能的损失无法由其他真正独立的中心补偿，总体化的判断才成立。"
问题：定义句先行预设"不可替代"，而句末的"只有当……无法补偿"检验恰恰是用来确立不可替代性的。预设读法下，检验必然通过（不可替代的损失按定义不可补偿），L47 承诺的诊断克制（"总体化不能由集中、依赖或增长本身宣布"）就成了空转的护栏。
最强攻击：任何被指控侵蚀"不可替代"能力的回路都自动通过检验——该定义在弱读法下自我确证、不可证伪。
最小修法：删去首句"不可替代的"，让补偿检验独自定义不可替代性："让独立感知……的能力逐渐失去因果作用，**且这种损失无法由其他真正独立的中心补偿——只有此时**，总体化的判断才成立。"（未升承重，因 L59 未套用此判断、L99 已解耦。）

**F3【句级】L83** — "能力不等于可靠部署，部署不等于关键权限与规模，规模也不等于净方向。只有当**前者**形成集中回报、依赖与后继影响，而反向能力没有获得相当力量时，AI 才提高斗争回路的净增益。"
问题有二：（一）三环链条之后的"前者"无唯一先行词（能力？规模？整条链？）；取最弱读法（前者＝能力），该句与它紧跟的"能力不等于可靠部署"自相顶撞。（二）"只有当……才"只断言必要性；而本节随后（L81、L87、L89）逐项记录这些条件正在成立，语用上诱导读者得出"净增益正在提高"——肯定必要条件推不出结论，这个方向文本从未以充分条件形式断言。
最强攻击：敌手可以承认 L81–L89 的全部事实然后说："按你自己的逻辑形式，这些只是必要条件，你没有证明任何净增益上升。"
最小修法："只有当**这些能力经由部署、权限与规模**形成集中回报、依赖与后继影响，而反向能力没有获得相当力量时——**也正是在此时**——AI 才提高斗争回路的净增益。"（未升承重，因 L99 的结论不经由净增益引理。）

**F4【句级】L15** — "只有进入存续、资源、许可、声誉、复制或部署的后果，才会稳定改变后来选择。其余后果即使被知道，也**可能**没有足够因果力量。"
问题：第一句是严格必要条件；第二句"可能没有"承认可能有——同段两句互相顶撞。且"后来选择"层级不明（个体选择还是选择环境）：取个体读法，L65"道德传统……而后才成为因果力量"即是文本自产的反例。
最强攻击：用文本自己的第四节击打第一节——若道德认识可以成为因果力量（L65），则六通道清单的"只有……才"为假。
最小修法：钉住层级并对齐限定："只有进入……的后果，才会稳定改变**后来的选择环境**；其余后果即使被知道，**通常**缺乏足够因果力量。"

**F5【句级】L73** — "凡一种条件塑造他者的生活与后继能力，受影响者必须拥有受保护的争议、拒绝、组织反制、共同决定，以及在代表者背叛关系时撤换他们的能力。"
问题：无限制的全称"凡"是一个比论证所需强得多的规范前提（隐藏强度，属类3边缘）。
最强攻击：归谬——养育、教学、任何写作都"塑造他者的生活与后继能力"，该原则遂要求儿童对父母拥有组织反制与撤换权；这是政治哲学中著名的"全体受影响者原则"的过宽版本。后文实际只使用支配/高后果限定版（同段"在支配关系中"、第六节的角色条件）。
最小修法："凡一种条件**以支配性或高后果的方式**塑造他者的生活与后继能力……"

**F6【句级】L43** — "斗争不再只产生胜者。它开始生产一个更需要斗争才能继续的世界。"
问题：本节主干（L35、L39）全部由"当……时"守卫，结尾却以一般现在时＋"不再/开始"宣告现实达成——这恰是 L87 自设禁令（"低层事实不能借最高层语言改写时态"）所指的时态改写，是全文唯一违反自身规则的地方。
最强攻击：引 L87 打 L43：条件化机制在小结处被改写成已然事实。
最小修法：接续条件——"**在这些条件成立之处**，斗争不再只产生胜者……"

**F7【句级】L95、L97** — "**生成性方向**因此不是最高善"；"**非耗材化原则**也适用于文明可能制造的心智。"
问题：两个术语均首次出现却以已定义状态使用（"因此""也适用"预设了此前的引入），盲读下"因此"的推理对象悬空。
最强攻击：公开读者无从确定"生成性方向"指什么，L95 的"因此"推理（稳定自纠正的秩序仍可不义→生成性方向非最高善）在辨认出该词指本文倡导的反封闭方向之前无法评估。
最小修法：首次出现处加同位语："本文倡导的方向——保持未来可感知、可拒绝、可纠正的**生成性方向**——因此不是最高善"；"非耗材化原则"同理（可回指 L95"把生命永久降为手段"）。

**F8【句级】L39（连带 L5、L9）** — "当科学、教育、合作和公共利益必须证明自己能够促进**增长、安全与相对优势**，才获得高杠杆资源，斗争便从策略上升为元选择。"
问题：按 L27 自己的定义，斗争环境的判据是"继续存在依赖**相对**优势"；而 L39 的门槛清单含非竞争性的"增长"（L5 还含"效率"，两处清单不一致）。若门槛清单按"任一即可"读，纯增长门槛也被冠名"斗争成元选择"，超出自家定义。
最强攻击：反例——一个以绝对增长（非零和）为门槛的资助体系满足 L39 前件，却不满足 L27 的斗争判据。
最小修法：补一个系词把增长挂回竞争条件（"在存续依赖相对位置的环境里，增长本身就是相对优势的通货"），并统一 L5/L39 清单。（最终结论不受损：L99 的条件是"强竞争和集中回流"，真属斗争。）

**F9【精修】L99、L107、L109** — 结论的四个条件 (a)–(d) 各自在文中有出处级支撑（L81 集中、L87 后继影响已实际形成、L85/L91 风险路径、L89 纠正未闭环），但全文没有一处把它们对**同一个具名角色**（前沿后继生产）一次性合拢实例化；L107 的"必须"由这个分布式装配隐性授权。另 L109 的"无法……被改向"未指明由谁、按何标准判定——应显式回指 L91 的角色测试（独立发现、归因、干预权、恢复）。
最小修法：在 L99 或 L105 前加一句合拢句，并令 L109 引用 L91 的判据。

**F10【精修】L97 × L101** — L97 列"终止"于不确定性所不许可的行为之中（"不许可无限训练、复制……或终止"），L101 又命令"应停止相应训练、发布、权限或部署"。靠"无限"二字两句不构成矛盾（特定的、有理由的停止≠无限终止；停止部署≠删除），但两条原则的交互（对可能是道德病人的系统，克制应取保存而非删除的形态）全文未处理。
最小修法：在 L103 的正当克制清单中加半句"并以保存而非抹除的方式对待可能的体验主体"。

**F11【精修】L101** — 决策规则漏第三种情形："较轻措施若能及时恢复可逆性……就不应建立更大的停止权；若不能，而继续会先消灭纠正条件，就应停止……"——较轻措施不能恢复可逆性、但继续也**不会**先消灭纠正条件时，规则沉默。该角落大体无害（纠正条件尚存），但作为文章唯一的操作性判据，穷尽性缺口值得补一句。

**F12【精修】L53** — "当一个回路的成功不只增加自身规模，还改变后来的选择环境、参与者和可行未来，我们可以称它为元吸引过程。"
问题：定义方向中立——按 L33 自己的让步（"一切长期的善也会改变未来"），照护与开放标准生态同样满足该定义；L55"值得严肃对待的迹象"的警示力全靠例子内容而非定义本身，L59 的"控制文明"又给该词加上了定义里没有的内容。
最小修法：在定义中补上压制差异项（"同时削弱独立回答能力"），或明言该词本身方向中立、总体化才是其恶性走向。

## 3. 幸存的最强反对

**可回答克制的存在性问题。** 文本自己的证据（L89：军事、国防与国家安全系统被排除在主要框架之外，跨法域一致性、独立审计、阈值前执行"尚未闭环"）意味着：对最有能力推进高杠杆递归的行动者（国家安全体系、秘密项目），文中要求的那种克制——多中心、可争议、可撤换执行者、可退场（L103、L111）——目前**没有一个存在实例**。于是 L101 菜单里"协调暂停"的可回答版本可能是空集，而 L103 又命令拒绝封闭版本：在最需要克制的地方，框架可能给不出任何可执行选项，其全部规范力量退化为"重建"这个未经展示可能性的许诺。

正文对它的最好回应在 **L101**（较轻措施优先的比较程序，不必一步跳到大停止权）与 **L103 末句**（"如果一种暂停只是把封闭移到新的闸门，它也必须被拒绝或重建"——用迭代重建吸收失败）。但对"当可回答的克制在军事/秘密领域没有实例时怎么办"这一步，正文没有回应：L89 承认了缺口，然后没有回来处理它。作为反对者，我会坚持：一个把全部实践重量押在"可回答的克制"上的论证，欠读者一段关于这种克制在其最关键场域如何可能存在的论述。
