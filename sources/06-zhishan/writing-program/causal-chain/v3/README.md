# Causal-chain v3

v3 以斗争如何从一种策略成为元选择机制、AI 如何进入并放大这一方向为中轴。

## 写作依据

- [`plan.md`](./plan.md) — 十二节点写作计划、证据责任与承重检查。

## 三个独立初稿

- [`main-zh.md`](./main-zh.md) — 主上下文中文版本；十二节，完整展开文明传统、当代轨迹、两条 AI 路径与决策桥；
- [`independent-zh.md`](./independent-zh.md) — 独立上下文中文版本；从“被迫参战”直接进入元选择，结构更紧；
- [`independent-en.md`](./independent-en.md) — 独立上下文英文版本；经验限定、反证条件和 proof burden 展开最显式。

两个独立版本只读取 `plan.md` 与既有 v2/context/foundations 材料，没有读取其他 v3 草稿，也没有长度或章节数量目标。三稿保持原样，已完成独立红队审查与综合；下一版不得直接生成平均稿。

## 审查

- [`reviews/`](./reviews/) — 四份独立红队审查，以及深度综合与下一版方向。
