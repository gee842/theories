# Causal-chain v2 reviews

本目录保存对 v2 四个独立版本的红队审查与综合判断。审查的目标不是替既定结论寻找更多修辞，而是暴露每一处经验跳跃、概念偷换、规范前提和行动推论。

## 独立审查

- [`systems-science-red-team.md`](./systems-science-red-team.md) — 系统科学、演化动力学、控制论与可证伪性；
- [`normative-philosophy-red-team.md`](./normative-philosophy-red-team.md) — 规范前提、价值冲突、道德不确定性与行动正当性；
- [`ai-empirical-red-team.md`](./ai-empirical-red-team.md) — 前沿 AI、递归研发、部署生态、工程与政策证据；
- [`cross-version-red-team.md`](./cross-version-red-team.md) — 不依赖前三份报告完成的跨版本结构审查。

## 综合

- [`deep-synthesis-and-v3-direction.md`](./deep-synthesis-and-v3-direction.md) — 对四份审查的深度裁决、最短承重链、v3 合成架构与下一轮验证协议。

## 阅读顺序

若只阅读一份文件，先读综合。若要追查某个判断的依据，再进入相应独立审查。独立报告保留差异，不因综合结论而回写。
