# V8 行动原则与政策手段：层级、冲突与反俘获审查

## 审查范围

本报告只依据任务指定的本地材料。它不替 V8 写正文或计划，也不试图给出一份完整政策白皮书。它只回答一个承重问题：既然当前 AI 的主导选择环境正在把更强智能加入利润竞争、组织支配和军备竞赛，那么结论究竟应是“尽量改向，实在不行才暂停”，还是“必须停止给这个方向增力；改向与暂停只是实现停止的不同方式”？

## 一、总裁决

应当采用后一种结构。

> **必须停止向斗争性、支配性和军备竞赛性的回路继续增加智能。能被实质改向的，改向本身就是停止旧方向；在改向得到证明以前，训练扩张、竞争性部署和扩张性资本都不应继续。暂停不是改向失败后的软备选，而是旧方向尚未被证明已经停止时的默认状态。**

这比 V5—V7 常用的“若不能及时改向，就暂停具体递归”更强，也更清楚。旧句容易产生三个误读：继续扩张仍有默认许可；证明“不能改向”的责任落在反对者；只要宣布正在改向，能力、部署和资本便可在原回流中继续增长。V8 应当倒转举证责任：**想继续增加能力的一方，必须先证明选择环境、权限、收益回流、依赖和后继效应已经改变。**

但这并不等于把每一项具体禁令提升为永恒原则。必须严格区分：

1. **原则结论：** 不得再给会把相对胜利转化为支配、依赖与后继控制的回路增力；这是方向判断，不是可选建议。
2. **强默认规则：** 商业领域不得部署超过基准能力的模型；受规制的高杠杆 AI 不得成为私人盈利和新增扩张性投资的对象。它们是在当前条件下倒转举证责任的规则性禁令，不是关于一切时代、一切价格交换和一切投资的形而上真理。
3. **具体工具：** 训练规模上限、角色部署限制、许可、资金与算力追踪、国际核查、全球 AI 安全组织等，用来使默认规则真实生效。它们必须比较有效性、规避路径和俘获风险；原则强烈不等于任一工具已经被证明最优。
4. **允许方向：** 公共科学、共同基础设施、照护、生态与其他真正扩大共同感知和独立生成能力的用途可以获得许可，但“公共”“安全”“国家利益”“开源”或“非营利”都不是自动豁免标签。

用户提出的商业部署、盈利和投资禁令因而不应被降为政策菜单中的普通选项。它们应被写成**当前转型期的强默认规则**；训练上限与全球组织则处在下一层，是实现、核查和协调这些规则的手段。

## 二、“继续用 AI 放大斗争与竞争是自取灭亡”怎样才强而可辩护

“自取灭亡”若被理解为“某个模型必然在某时导致人类灭绝”，现有材料并没有证明它。若被理解为一种**结构性自我破坏的方向判断**，它可以成立，而且比精确灾难预言更贴合本项目。

| 判断层 | 可辩护的内容 | 不应偷换成 |
| --- | --- | --- |
| 因果判断 | AI 降低搜索、预测、说服、监测、协调、复制和研发的成本；当能力取得高后果权限，收益集中回流为算力、基础设施、许可和后继生产，而独立纠正没有取得相当力量时，商业与安全竞赛的有效增益上升，替代、退出和改向条件受压。 | 所有 AI 使用都造成净损害；正反馈必然收敛；当前已证明唯一全球吸引子完成捕获。 |
| 规范判断 | 任何当前中心都无权为了自己的相对胜利，不可逆地夺走后来存在感知、拒绝、纠正、实践真善美和生成不同未来的条件；把人、生命与可能的 made minds 预先变成竞赛耗材，本身已经错误。 | 只要整体能延续，具体生命就可被牺牲；“生成更多未来”是压倒一切的新总目标。 |
| 决策论判断 | 在损失可能不可逆、后果极大、继续行动会反过来削弱以后判断与叫停能力的条件下，等待精确概率不是中立。稳健的选择是保住纠错和改向能力，并把继续增力的举证责任交给增力者。 | 只要能想象最坏情况就应任意禁止；无需识别可信机制、现实暴露和干预代价。 |
| 预测判断 | 锁定、共同坍塌和更自主的闭合都是可信终局；具体概率、时间和终局仍不确定。 | “若不采用某一项指定政策，文明必然按一条精确路径灭亡。” |

这里的“自取”也不应暗示存在一个统一文明主体有意选择灭亡。更准确的含义是：许多局部上可理解的选择，正在把智能交给一个会消耗自身共同基底和纠错条件的结构。它可能以锁定终结文明的自我决定能力，也可能以坍塌终结其继续存在的条件。两者都是自我终结性方向。

V7 系统审阅正确指出，三稿尚未用一条当前事实链证明“全社会净 possibility loss”已经完成。V8 不应遮掩这个经验缺口。但该缺口也不推出“照常扩张”。恰当结论是：**不把方向判断伪装成精确概率预测，同时在可信的不可逆路径与内生纠错损失面前倒转默认许可。**

可以在正文中这样表述：

> 继续把更强智能交给利润领先、支配位置和军备优势的竞赛，不只是承担一种外部风险。它是在用更强的行动能力破坏文明赖以感知后果、共同改向和继续生成未来的条件。这是一种朝向自我终结的理性倒置，不需要先预测某一灾难发生的精确概率，才足以撤回继续增力的默认许可。

## 三、V8 应采用的行动层级

| 层级 | 内容 | 稳定性与举证责任 |
| --- | --- | --- |
| 1. 原则 | 智能不得被用来使一个支配性回路取得对共同基底、后继规则和后来智能的不可回答控制；错误方向必须停止。 | 最稳定。实施困难不能把它降成选项。 |
| 2. 默认规则 | 未被证明已改向的前沿／高杠杆 AI，不得增加商业能力基准、不得成为私人利润抽取对象、不得获得新增扩张性资本；现有高风险权限也不因“已经存在”而自动合法。 | 当前条件下强推定。请求例外者承担证明责任。 |
| 3. 允许方向 | 对公共利益、公共科学和共同基础设施给予受约束许可和积极资源，但必须证明其真实回流扩大共同能力而非伪装竞争优势。 | 个案、限期、可撤回；机构标签不能替代证明。 |
| 4. 工具 | 训练规模上限、部署与权限限制、投资控制、核查、国际协调、全球组织、公共资助等。 | 可替换、可组合、必须接受效果与副作用审查。 |
| 5. 实施与反规避 | 功能性定义、覆盖关联主体和资本／算力绕道、处理开源与分布式训练、无军事豁免、约束既有巨头。 | 随技术与规避变化更新。 |
| 6. 反俘获 | 权力分立、透明、申诉、撤换、期限、代表性、独立资助、无单一重启权。 | 原则对自身手段的递归应用；不可删去。 |

这一层级解决了“原则太软”和“政策被神圣化”两个相反问题。原则层的命令是无条件的：停止给错误方向增力。默认规则则把该命令变成现实中的禁令。工具层承认我们仍须学习哪一种组合最有效。反俘获层确保停止者不能借停止占有未来。

## 四、三项强默认禁令的精确裁决

### 1. 商业领域部署高于当前能力的模型

**它切断的回流：** 更高能力 → 商业采用与规模 → 收入、数据、依赖和分发 → 更多资本、算力、人才与政治许可 → 更高能力和更深后继控制。

这项禁令应成立为默认规则，因为它直接阻止能力增量变成竞争优势，再由竞争优势生产下一轮能力。可是“当前能力”必须冻结为一个明确日期和系统级能力范围，不能随着行业继续前进而自动移动；评估对象也必须包括工具、脚手架、代理、模型组合、后训练和推理时扩展，而不只是一张基础模型榜单。

主要漏洞与副作用是：

- 冻结既有巨头，把当前模型、接口和依赖变成永久租值；
- 用多个“未超过基准”的模型、代理脚手架或大规模部署合成更高系统能力；
- 转入海外、军方、情报系统、政府承包或名义非营利机构；
- 继续扩大现有能力的权限和规模，虽无模型能力跃升却仍提高有效增益；
- 以开源权重、微调、蒸馏或分布式训练绕开单一部署者。

因此，它必须与**既有高风险部署的权限收缩、无祖父权、系统级聚合计算、军民同规则和公共替代建设**相连。能力上限只限制增量，不能证明现有存量安全。

### 2. 禁止以受规制 AI 商业化盈利

**它切断的回流：** 商业收入与估值 → 私人资本和算力 → 产品依赖、市场权力和后继研发 → 更多收入与估值。它还削弱“越快部署越能融资”的选择压力。

这项主张最强、也最可辩护的版本不是“任何与 AI 有关的交易都不得收费”，而是：**前沿／高杠杆 AI 不得成为私人剩余抽取、资本增值和竞争性再投资的来源。** 经审计的成本回收、合理劳动报酬和公共服务采购可以存在；利润不得分配给私人所有者，也不得经关联交易、云服务、芯片、咨询、广告、数据租金、股权升值或交叉补贴回流为新的支配能力。

若把“盈利禁令”写成对所有价格交换的永恒道德禁令，会产生两种反效果：只有已有巨额资产的公司、富豪或国家能长期承担亏损；真正的公共服务也失去维护资源。真正应禁止的是**集中收益转化为后继选择权**，不是把会计上的每一笔收入当作恶的本体。

### 3. 禁止进一步投资

**它切断的回流：** 对未来超额收益与战略领先的预期 → 股权、债务、云额度、芯片与数据中心扩张、人才争夺和政治游说 → 更快训练和部署 → 更强领先预期。

它也应是强默认规则，但对象必须写成：**禁止向未获允许的前沿能力、竞争性部署及其支撑设施提供新的扩张性资本或等价资源。** 安全收尾、风险降低、转换现有设施、公共科学、共同基础设施和受约束的允许方向仍需资金，否则投资禁令会亲手饿死正向递归。

规避会经由留存收益、债务、并购、供应商资本开支、云额度、主权基金、国防合同、关联企业和境外载体发生。因此，规则必须跟随受益所有人、实际用途和等价资源，而不能只盯“AI 公司获得股权融资”这一种法律形式。

### 对三项禁令的共同裁决

三者不是彼此替代的政策偏好，而是分别截断同一回路的三个位置：

> **部署禁令截断能力进入现实竞争；盈利禁令截断胜出回流；投资禁令截断回流再次变成能力。**

它们共同构成当前商业前沿的强默认防线。它们仍不是永恒原则，因为未来若出现不以私人积累和相对领先为选择器、且能保持多中心纠正的制度，具体财务形式可以改变；但在这种改变被证明以前，不能把继续扩张当作默认。

## 五、允许的公共方向不是标签豁免

真正服务公共利益、公共科学和共同基础设施的方向应被允许，甚至积极供给资源。否则禁令只会留下现有权力，而不生产替代。但允许必须通过实质测试：

1. **目的：** 主要作用是扩大共同感知、科学、照护、生态修复、教育或独立创造，而非把商业、国家或机构优势包装成公共利益。
2. **能力必要性：** 使用完成公共目的所需的最低充分能力、权限与规模；“有益目标”不能自动授权前沿最大化。
3. **所有与治理：** 受影响者、独立专家和公共代表具有真实争议、申诉和撤换能力；开发者不能自我认证。
4. **收益回流：** 收益、数据、基础设施和知识回到可共同继承的能力，不进入私人资本积累、军事领先或单一机构的后继垄断。
5. **依赖与替代：** 接入可携带，退出真实，存在独立替代和维护能力；公共服务不能成为新的服从闸门。
6. **后继效应：** 不以公共项目为掩护生产更强竞争性模型、训练管线、权重或战略能力。
7. **可逆与期限：** 许可限期、可审查、可撤回；一旦回流改变方向，例外随即失效。

“公共科学”也不等于无条件公开所有权重、训练配方和危险能力。公开知识可以扩大共同纠正，无法回收的高风险能力扩散也可能摧毁纠正。可公开什么、受约束共享什么，仍应按扩散、权限、可逆性与后继效应判断。

## 六、训练上限、部署限制与全球组织的工具层裁决

### 1. 训练规模上限

训练上限可以在一个相对可见的上游节点降低能力增长和后继研发速度，是重要工具，但不是原则本身，也不是充分条件。

它可能被算法效率、数据改进、后训练、蒸馏、模型合并、推理时算力、多次小训练、跨组织分布式训练和现有开放权重绕过；固定算力线还会优待已有大模型和更高效率的既有巨头。因而上限必须动态关联**总有效资源与系统能力**，聚合协调运行，覆盖训练之外的关键增力步骤，并与部署权限和收益回流规则同时工作。它不能把“低于算力线”变成安全认证。

### 2. 部署与权限限制

部署限制直接切断 `capability → consequential permission → dependency/harm`，比只管训练更接近现实后果，也能处理现有模型存量。应按角色的高后果执行权、扩散、依赖、不可逆性和后继影响判断，而非只按行业名称。

漏洞包括 API 套壳、下游微调、代理组合、开放权重、本地部署、跨境出口和把高风险功能拆成多个低风险组件。过度集中式监控又可能把平台变成执法闸门。因此，需要在高杠杆供应、部署和基础设施节点核查，而不是把全社会变成普遍监控对象。

### 3. 全球 AI 安全组织

全球组织的正当功能是切断安全困境：共同阈值、相互核查与可执行承诺降低“我若先停就会被对手淘汰”的风险；它还能把分散知识转化为共同反馈，并支持公共科学和转型能力。

它不是原则来源，也不能成为唯一的文明大脑。其主要失败路径是：

- 既有强国和巨头把当前领先冻结为合法基线；
- 商业受限后，能力转入不透明的军事和情报系统；
- 组织垄断风险定义、证据入口、许可与重启权；
- 核查演变为全球监控基础设施；
- 发展中地区和受影响公众承担成本，却没有决定权；
- “公共利益”例外成为大国战略项目的合法外衣。

所以全球组织只能是一个**权限有限、权力分立、可被争议和撤换的协调器**：科学评估、核查、执法、许可和申诉不应集中于同一中心；军事与情报活动不得享有空白豁免；应有地区与机构冗余、透明标准、独立资助、任期与日落条款，且任何单一机构都不拥有永久重启世界 AI 发展的权力。

### 工具层的总判断

训练上限、部署限制、全球组织、验证与共同协调都应被支持为有力候选，但它们的地位是：

> **用来落实“不得继续给错误方向增力”的手段，而不是用来决定这一原则是否成立。**

若一种工具未能切断目标回流，或制造了更强的锁定，就应替换或修正工具，而不是恢复原方向的扩张许可。

## 七、实施与反规避的最低结构

V8 无需写出完整制度，但必须让读者知道强禁令不会只停留在名词上。

- **按功能与回流定义对象。** 看能力、工具、权限、规模、收益集中、依赖和后继影响，不以“公司／大学／非营利／开源／政府”标签划线。
- **覆盖整个系统。** 模型、脚手架、代理、工具调用、模型组合、后训练、推理时扩展和大规模复制应聚合判断。
- **跟随实际资源。** 资金、债务、云额度、芯片、数据中心、权重、数据、人才和政府合同都是扩张性投入的等价物。
- **无国家安全豁免。** 纯商业禁令若把前沿能力推入军事秘密系统，会强化最难回答的竞争回路。必要秘密可由多方保密核查处理，不能变成免于规则。
- **处理公共利益伪装。** 例外申请者必须公开可验证的收益回流、治理和后继效应；不得自证，且许可可撤销。
- **处理开源与分布式训练。** 开源可以保护替代，也可以造成不可回收扩散；分布式可以分权，也可以聚合成规避训练上限的单一工程。应保护安全、可维护的开放公共能力，同时按协调关系和总有效能力覆盖危险权重、训练与部署。
- **不冻结既有巨头。** 现有模型没有祖父权；既有高风险权限、依赖和回流也要缩减。公共替代、可携带标准和转型支持必须同步建立，否则禁令只会把领先变成永久地租。
- **保护先行动者。** 可信协调、相互验证和对违规加速者的约束，是使停止不被选择淘汰的因果条件，而非实施以后才补的公关工作。

## 八、反俘获不是附带条件

本项目的原则必须递归作用于执行者。一个足够有力的禁止制度也足够有力地占有未来，所以至少需要：

1. **无单一闸门：** 规则制定、事实评估、核查、制裁、许可和申诉分离；存在多个相互审查的中心。
2. **无既有者否决权：** 前沿公司、强国和军事机构不得控制席位、标准或例外；利益冲突公开并回避，公共机构有独立资金。
3. **受影响者有实质地位：** 不只被咨询，还能争议证据、提出申诉、要求复核和撤换执行者；转型成本不能只转嫁给劳动者和较弱国家。
4. **权力可退场：** 授权有范围、期限、复审和 stand-down 条件；紧急权不得自动永久化。
5. **证据入口保持多元：** 独立科学、举报者、民间社会和不同地区必须能够提出被正式处理的反证；不能由被监管者垄断模型与风险信息。
6. **例外可被反向审计：** 公共利益项目的实际收益、依赖和军事／商业转化持续接受审查，名称与初始意图不能永久免责。
7. **组织本身接受同一测试：** 它是在增加多个中心感知、拒绝、修复和重启的能力，还是使所有道路都必须经过自己？若是后者，它已成为需要被限制的回路。

反俘获不等于把协调做弱。弱到不能约束竞赛的组织只会给继续加速提供道德外衣。所需的是**足以执行、又不能垄断未来的强协调**。

## 九、几个必须明确裁决的冲突

| 冲突 | V8 应作的裁决 |
| --- | --- |
| 改向还是暂停 | 不是先后顺序，而是同一停止原则的两种实现。已证明实质改向者可继续受限学习；未证明者默认不增力。 |
| 强原则还是工具不确定 | 原则不因执行困难而变软；工具因效果未知而保持可修订。 |
| 商业禁令还是军事竞争 | 商业禁令是最低默认，不是国家与军方豁免。否则能力只会迁往更不透明的斗争回路。 |
| 盈利禁令还是公共服务融资 | 禁止私人剩余抽取和竞争性再投资；允许受约束的成本回收、公共补偿与共同能力维护。 |
| 开源还是集中控制 | 二者都不能凭标签获胜。保护可纠正的开放替代，限制不可回收的危险扩散，同时防止安全成为巨头垄断借口。 |
| 暂停还是冻结既有巨头 | 无祖父权、现有高风险权限同步收缩、建设公共替代；否则暂停不合原则。 |
| 全球协调还是新主权 | 需要全球共同底线与核查，但不需要一个拥有全部证据、许可和重启权的全球中心。 |
| 公共利益还是公共利益伪装 | 看所有、权限、回流、依赖、后继效应和受影响者权力，不看声明。 |

## 十、给 V8 作者的最小写法

正文不需要逐项展开本报告。它只需守住四层：

1. 用因果链说明为什么利润、支配和军备回流会借 AI 取得更高增益，并侵蚀改向条件。
2. 公开承担规范与决策桥：后来者的回答地位不可被当前胜者占有；不可逆和内生纠错损失足以倒转举证责任，而不需要精确灭亡概率。
3. 明说方向原则与默认规则：停止给错误方向增力；商业能力扩张、私人盈利和新增投资未经实质改向证明即禁止。
4. 用一句话保留工具可修订与手段反俘获：训练上限、部署限制、全球核查和共同协调都是手段，任何手段若冻结支配、转入秘密竞赛或垄断未来，也必须被纠正或停止。

可作为 V8 行动段的骨架句是：

> 我们必须停止向以利润领先、支配位置和军备优势为选择压力的回路继续增加智能。停止并不只意味着关停：若目的、所有、权限、收益回流、依赖和后继生产已经可验证地转向公共科学、共同基础与多中心生成，改向本身就是对旧方向的停止；若这种改变尚未成立，就不应继续增加商业能力、私人利润、扩张性资本或高后果权限。训练上限、部署限制、全球核查与共同协调帮助我们做到这一点，但它们无权把自己变成新的最终中心。

最终层级必须保持清楚：**停止错误方向是原则；商业部署、盈利和投资禁令是当前强默认；公共利益是须证明的允许方向；训练上限、全球组织和验证协调是实施手段；反规避与反俘获是所有手段必须通过的递归检验。**
