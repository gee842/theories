# V8 reviews

本目录保存首稿完成后的攻击记录与修订复核。报告保留初稿曾经出现的问题；每份报告末尾另记修订后的通过状态，因此“必须修复”与“已通过”并不矛盾。

- [`main-zh-review.md`](./main-zh-review.md) — 主中文稿的事实、举证责任、收益回流、载体中立与 commons 承重审阅；
- [`independent-zh-review.md`](./independent-zh-review.md) — 独立中文稿的逐项 contract 审阅；
- [`independent-en-review.md`](./independent-en-review.md) — 独立英文稿的 load-bearing audit；
- [`cross-draft-flow-review.md`](./cross-draft-flow-review.md) — 三稿的流动、漏损与主稿复读审阅。

三稿修订后均通过各自报告。交叉复读确认主稿已修复六处流动问题与四个缺失桥梁，没有引入新的严重断裂。这里的通过只表示 V8 写作与承重合同闭合，不表示三稿已经比较、选优或合成。
