## 本轮核心裁决

V8 不再把 “redirect or pause” 写成两个顺序性的政策选项。旧的斗争性方向必须停止；选择、控制、回流、依赖与后继生产已真实改变，且递归仍可被独立发现、中断和恢复时，继续才构成转向。商业、战略与军事载体受同一顶层规则；能力扩张、收益回流和新增扩张性投入是当前强默认禁令；训练上限、部署限制和全球协调组织是使原则生效的可修订工具。

## 独立性与材料边界

三位作者在首稿阶段不读取写后 contract，也不读取彼此的正文。两个独立 lane 不读取 V7 正文与 V8 preparation。独立中文 lane 原计划只读取 baseline 的前三部分；由于 baseline 的章节标记与预设停止条件不一致，它额外读到了该 baseline 的后续部分。它仍未接触 V7、V8 preparation 或另外两份 V8 正文；这一偏差在以后比较三稿时应保留为来源说明。

写后阶段不再保持材料隔离：每一稿均按同一 contract 复核，主稿另接受事实与流动交叉审阅。修订只修承重漏洞，不要求三稿采用相同结构、长度和措辞。

历史版本与 V7 reviews 保持不变。
