## V6 的历史停止裁决

V6 当时依照停止协议结束了版本循环。后来关于“克制”与“理性”、future／possibility space 以及当前 AI 发展方式已经改变未来可达性的反馈，构成了承重问题，因此开启了 v6.1—v7。原停止审阅仍作为历史验证材料保留，不再描述当前版本状态。

## 版本保存规则

每个新版本目录至少保留：

- `preparation.md`（若有新的承重判断）；
- `main.md`；
- 独立版本按角色命名。

不得覆盖历史目录中的 chain。
