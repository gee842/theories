# Causal-chain v4

v4 回应 v3 红队审查，但不把文明方向论证收缩成治理 checklist。它以 totalizing dynamics、文明内在 counter-dynamics、stance/means 区分和非认证式的 generative direction 重建因果链。

## 写作依据

- [`plan.md`](./plan.md) — 六个 movement、十四个承重点，以及对 v3 review 的逐项回应。

## 三个独立初稿

- [`main-zh.md`](./main-zh.md) — 主上下文中文版本；六个 movement，最精炼，强调 totalizing dynamics、文明内在方向与最后的文明决断；
- [`independent-zh.md`](./independent-zh.md) — 独立上下文中文版本；更充分展开两条斗争路径、回路收敛、传统道德 counter-dynamics 与纠错窗口；
- [`independent-en.md`](./independent-en.md) — 独立上下文英文版本；六个自然 movement，对动态 totalization、AI 递归与 stance/means 的英文表达最完整。

两个独立版本只读取 `plan.md` 与既有 v3/context/foundations 材料，没有读取其他 v4 草稿，也没有长度或章节数量目标。三个版本保持原样，下一步先独立审查，不直接生成平均稿。

## 审查

- [`reviews/`](./reviews/) — 四份独立红队审查，以及深度综合与下一版方向。
