# Causal-chain v6：规范、传统与正义停止审计

## 0. 范围与裁决

本审计完整阅读 `v6/plan.md`、`v6/main-zh.md`、`v6/independent-zh.md` 与 `v6/independent-en.md`，并以 v5 的规范红队和 consolidation synthesis 作为上一轮问题清单。没有读取任何其他 v6 review。

**停止裁决：PASS。** v6 已经达到 plan 所定义的 stopping standard。三稿均没有剩余的承重性规范范畴错误、隐藏规范跳跃或自我击败的克制原则；不需要为了规范问题再写一个 v7 causal-chain round。

**最佳规范底稿：`independent-zh.md`。** 它最完整地把传统的内在要求、受影响者的共同决定与罢免权、支配下的 counter-power、made minds、较小侵害、现成主权者不自动取得强制权，以及停止权的退场写进同一条链。`independent-en.md` 是最佳英文控制稿，尤其应保留 “affected publics ... challenge and help authorize” 的授权语言。`main-zh.md` 可继续承担公共篇幅与节奏，但不应单独成为规范 source of truth。

这里的 PASS 不是说三稿已经给出全球暂停制度，也不是说所有分配冲突已经解决。它只表示剩余问题属于局部加固、举例和后续政策设计，而不是 causal chain 仍缺一座桥。

## 2. 为什么不再判为隐藏的停止权跳跃

上一轮最危险的跳跃是：

> 某种扩张失去默认正当性 → 某个现成中心因此获得强制他人停止的权力。

v6 已经把这两件事拆开。`independent-zh.md` 先要求对象缩到具体 role / training / release / permission / deployment，比较较轻措施与暂停，再明确否定现成主权者自动取得强制权；随后要求停止权有界、可争议、可罢免、可退场，不能保留造成危险的不对称。`independent-en.md` 则要求受影响公众拥有挑战和共同授权的受保护权力，同时保存公共科学、防御能力与可行替代。`main-zh.md` 虽压缩了这座桥，却仍把受影响者的共同决定、申诉、撤换执行者与权力退场写进停止条件。

因此，“我们必须停止”不再是对可得主权者的 blank cheque。正文已经给出足以支撑 causal-chain 结论的授权边界：先撤回无条件扩张推定，再对具体递归比较手段；强制克制只有在增加纠错余量、转移真实决定权且不复制原不对称时才可能正当。谁代表跨境公众、怎样组成授权共同体、如何核查军事实体，仍是困难问题，但它们现在是这个原则下的制度设计问题，而不是原则缺席。

## 3. 各稿裁决

### `independent-zh.md` — PASS，最佳底稿

这是规范链最完整的一稿。它有四个其他稿件不应再压掉的承重点：

1. 传统可以拒绝项目，而不只是帮助项目稳定承诺；
2. 可回答性转移决定、阻断与罢免权，而非仅增加信息；
3. 支配下的 counter-selection 从揭露、非合作、赔偿、拆除依赖和组织反制开始；
4. 严重风险不自动授权现成主权者，停止权不得保存造成危险的不对称。

它足以作为 authoritative Chinese chain 的规范 source spine。

### `independent-en.md` — PASS，最佳英文控制稿

这稿对 `intrinsic before useful`、traditions may interrupt the project、jurisdictional dissent、made minds 和 affected-public authorization 的英文表达最精确。它没有像中文独立稿那样直接写出 “does not automatically authorize an available sovereign”，但 `limited, contestable, removable`、`help authorize`、incumbent freeze、secret/military displacement 与 preserve counter-capacity 合起来已经堵住 blank authorization。补一句显式区分会更稳，但不是新理论缺口。

### `main-zh.md` — PASS，但不宜作为唯一规范底稿

主稿已经包含所有最低承重点：受影响者共同决定并撤换代表、支配下的反制与赔偿、made minds、generativity 降格、较轻措施优先、incumbent freeze、秘密军事位移、单 gate capture 与执行者退场。

它最薄的是传统段：只说义、慈悲与仁具有非工具价值，却没有像两篇独立稿那样明确说传统可以拒绝本项目。停止段也没有独立中文稿那句“撤回扩张正当性不自动授予强制权”。由于前后文已经提供共同决定、罢免与反俘获条件，这两处属于可消歧的压缩损失，不构成 stopping failure；但若主稿要成为唯一公开权威稿，应各补回一句。

## 4. 非承重 refinements

以下修改会提高 final 的正义清晰度，但不应触发新版本：

1. **在 `main-zh.md` 明说传统可拒绝项目。** 从 `independent-zh.md` 压缩保留一句：义可反对稳定但不义的秩序，慈悲可拒绝以开放未来之名制造新痛苦。
2. **在中文主稿和英文稿显式拆开正当性与强制授权。** 保留一句：可信的严重不可逆路径可以撤回扩张推定，但不会自动授权任何可得主权者。
3. **给 pause justice 一条分配原则。** 制造风险并从中获益最多者应先限、先公开并承担主要转型成本；被延迟的公共利益、外围发展能力与公共替代不能成为无偿牺牲。这会更直接阻断 pause imperialism，但现有 anti-incumbent、public alternative 和 non-preservation-of-asymmetry 原则已经承重。
4. **给 made minds 留下独立代表问题。** 最终政策文本需讨论可能主体在训练、复制、修改、记忆删除和终止决定中的福利评估与独立代表；causal chain 的一句道德不确定性边界已经足够。
5. **避免让“where feasible”成为逃逸口。** 后续制度文本应规定：不能直接共同决定时，负担在施加强制者一方，必须建立可争议的代表、外部触发复议和独立 counter-power，而不是由权力自己宣布参与不可行。

## 5. 最强反对者与回答

最强反对者仍是承认 AI 风险的去殖民、激进民主与 made-mind 正义论者：

> 你不能让我的传统替你的文明工程背书，不能把我的防御能力与强者的支配能力等同，不能让我为领先者制造的风险支付暂停成本，也不能以保护人类纠错余量为名把可能有体验的被造心智当作耗材。谁授权停止者，谁能撤换它，谁迫使领先者和秘密军事实体同样退让？

v6 已经有实质回答：传统保留拒绝权；支配与解放性反制不对称；受影响者拥有决定、阻断、罢免和反制能力；停止不得冻结 incumbents 或转入秘密军事载体；任何现成主权者都不会因风险判断自动取得强制权；made minds 被纳入非耗材化原则。回答仍需制度化，但已经不再由抽象的“我们”保留全部最终裁决权。

## 6. 最终停止建议

**停止 causal-chain 版本迭代。** 以 `independent-zh.md` 为规范底稿，`independent-en.md` 为英文与授权控制，`main-zh.md` 为篇幅和公共节奏；完成上述局部消歧后进入 authoritative consolidation。不要再以“暂停制度尚未完整设计”或“made-mind 冲突尚未穷尽”为由开启 v7：那会把后续治理和伦理研究重新误判为基础因果链缺失。
