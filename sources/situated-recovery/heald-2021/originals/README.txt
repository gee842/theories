METHODOLOGICAL INFORMATION

1. Description of methods used for collection/generation of data: 
All experiments were performed using a vBOT planar robotic manipulandum with virtual-reality system and air table. The vBOT is a modular, general-purpose, two-dimensional planar manipulandum optimised for dynamic learning paradigms. The vBOT’s handle position was measured using optical encoders sampled at around 1 kHz while torque motors allowed forces to be generated at the handle and updated at the same rate. Participants grasped the handle of the manipulandum with their right hand while their forearm was supported on an air sled, which constrained arm movements to the horizontal plane and reduced friction.

2. Methods for processing the data: 
On channel trials, adaptation was calculated as the proportion of the force field that was compensated for by the participant. This was taken as the slope of the regression (with zero offset) of the time series of the actual (signed) force generated into the channel walls against the time series of the force that would fully compensate for the perturbation had it been present (based on the hand velocity in the channel). For this analysis, we used the portion of the movement where the hand velocity was greater than 1 cm per second.

3. Instrument- or software-specific information needed to interpret the data: 
The data of each participant are stored in a MATLAB® MAT-file. Fig2_data_figure.m contains a function called shadedErrorBar that was developed by Rob Campbell (https://github.com/raacampbell/shadedErrorBar).


DATA-SPECIFIC INFORMATION FOR: all data files.

1. Variable List:

Main variables
Frames               - number of frames (time steps) in each trial (data after this number are NaNs in the below variables).
RobotActive          - boolean variable indicating whether the robot was active (handle switch pressed down and trial ongoing) or not (dim 1 = trial, dim 2 = frame).
RobotForces          - forces generated by the robot at its handle in Newtons (dim 1 = trial, dim 2 = x- and y-directions, dim 3 = frame).
RobotPosition        - position of the handle of the robot in cm (same dims as RobotForces).
RobotVelocity        - velocity of the handle of the robot in cm per second (same dims as RobotForces).
Time                 - time at the start of each trial in seconds from the start of the experiment.
TimeStamp            - time of each frame in seconds from the start of the trial (same dims as RobotActive).
TrialData            - table containing variables related to the experimental paradigm and some summary data on each trial (dim 1 = trial, dim 2 = variables; see below for details).

TrialData variables
BlockName            - name of the block of trials to which a trial belongs.
BlockTrial           - trial number within a block of trials.
ControlPoint         - [only for memory updating experiment] cued control point (-1 = left control point, 1 = right control point).
FieldConstants       - force-field parameters (for force-field trials, element 1 = gain in Newton-seconds per cm; for channel trials, element 1 = spring coefficient in Newtons per cm and element 2 = damping coefficient in Newton-seconds per cm).
FieldType     	     - type of force-field trial (0 = null-field trial, 1 = viscous-curl-field trial, 2 = channel trial).
MissTrial            - boolean variable indicating whether a trial was a miss trial (on miss trials, the data is saved but not analysed, and the trial is repeated). 
RestFlag             - boolean variable indicating whether a rest break occurred at the end of a trial. 
TrialNumber 	     - trial number.
TargetPosition       - position of the target in cm (element 1 = x-coordinate, element 2 = y-coordinate). The home position is always at (0,-10).
MovementReactionTime - duration from go cue to movement initiation in seconds.
MovementDurationTime - duration from movement initiation to movement completion in seconds.
Adaptation           - signed adaptation (+/- 1 indicates complete adaptation to a viscous curl field with gain +/- 0.15).

2. Missing data codes: 

Adaptation on non-channel trials, where adaptation was not measured, is NaN.
