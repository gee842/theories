# API transition: dated plans, continuation and retained dependence

2026-10-09. AI-authored source assessment for the [existing market study](../../../_process/research/2026-10-05-generative-foundation-review/foundation-assessment/MARKET-INTERNET-DEGENERATION.md#continuation-with-retained-control). This extends the same software-continuation assessment; it is not a new independent result or an endorsement of either party's account.

[manifest.json](manifest.json) binds eight retained documents covering seven primary statements and one date-search response. Five dated developer posts are newly examined; the Reddit policy statement and Apollo homepage were already used in the study and are reread here. Their republication is not new independent evidence.

## Representation and preservation

The two `.html` files preserve original response bytes. The five post files and date-search file preserve **web-reader/search response text**, including the tool's extraction and link markers; they are not original Reddit HTML. A direct request for the public Reddit JSON representation returned HTTP 403, so it was not used. No link rewriting or reconstructed “original” was performed. The manifest hashes the saved representations. These are current retrievals of historical pages, not contemporaneous snapshots: posts can have later edits. In particular, the September release post now links the October pricing revision. Its later pricing text cannot be treated as a September prediction.

Only the developer's main posts supply the attributed claims below. Other comments, vote counts, incidental personal information and accusations are excluded. The separately retrieved date-search response corroborates the four Narwhal publication dates. These materials support a dated reconstruction, **not a prospectively registered forecast or a guarantee that each sentence was unchanged at publication**.

Original URLs and source identities remain in the manifest. No source's mention of another counts as statistically independent corroboration. The participants' arrangements differ, so Apollo and Narwhal are **not matched treatment/control units**. The source check verifies saved text, dates and attribution anchors; it does not establish a numerical transition threshold, identify the effect of an extension, or reconstruct undisclosed negotiations.
