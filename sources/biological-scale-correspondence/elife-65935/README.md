# Published measurements for biological scale correspondence

Original source-data bytes from Filipowicz, Lalsiamthara and Aballay (2021), [eLife 10:e65935](https://doi.org/10.7554/eLife.65935), CC BY 4.0. Downloaded from the publisher CDN, using links obtained from the publisher API and matched to the PMC captions. [Manifest](manifest.json) records filenames, original URLs, byte sizes and SHA-256 hashes. These are imported originals, not newly collected data.

- `elife-65935-fig2-data1-v2.xlsx`: Figure 2B intestinal lumen diameters, anterior and medial regions. Micrometre units were checked against the original [Figure 2](https://iiif.elifesciences.org/lax/65935%2Felife-65935-fig2-v2.tif/full/full/0/default.jpg).
- `elife-65935-fig4-data1-v2.xlsx`: Figure 4C lawn-occupancy fractions at 1–5 hours, WT and two npr-1 strains, with chamber removal after hour 4.

Preserve the original spelling in source bytes. Analytical metadata normalizes “P. aerugonisa” to “P. aeruginosa.” Blank spreadsheet cells are unfilled observations, not zeros. Different regional counts and absent cross-figure identifiers prohibit assumed individual-level pairing. No source workbook was edited.
