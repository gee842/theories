# Original bands through one developmental imaging history

This collection preserves 251,170,816 additional original bytes from [BioImage Archive S-BIAD2117](https://doi.org/10.6019/S-BIAD2117), retrieved on 8 October 2026. The acquisition is `Yuya_Karita/AxioZoom/20231123-WS-KB-dilution6-1x/from-t5h-01.czi`, recorded on 23 November 2023. The parent [publication and license record](../README.md) identifies Karita et al. and the CC BY 4.0 archive.

The [prospective protocol](../../../../_process/research/2026-10-05-generative-foundation-review/root-foundation/DEVELOPMENTAL-HISTORY-PROTOCOL.md) selects scene 0/P6 and the central 512 × 512 pixel square at all 91 time points. Each downloaded horizontal band contains rows 848–1359 across the original image width. The analysis uses columns 1120–1631. The extra columns arise from contiguous range access to uncompressed original rows; they are not extra independent samples. Existing original headers and first/last pixels are reused by reference from [microscopy-metadata](../microscopy-metadata/README.md), without changing that collection.

Each `tNNN/ranges.json` records original offsets, sizes, request and response headers, ETag, URLs and body SHA-256. Every new response is HTTP 206 with the precise requested Content-Range and the unchanged source ETag under If-Match. Response bodies are unmodified. The [collection manifest](manifest.json) binds all 91 per-frame manifests, including the two frames needing no additional body. These are partial original ranges, not complete CZI files or verified whole-file publisher checksums.

Decoded frame records, measurements and figures live in the [analysis package](../../../../experiments/integrated-correction/general-framework/generative-basis/ecological-selection/microscopy-correspondence/developmental-history/README.md). The [independent reader and numerical receipt](../../../../experiments/integrated-correction/general-framework/generative-basis/ecological-selection/microscopy-correspondence/developmental-history/measurement-verification.json) checks all 91 subblocks and 23,855,104 crop pixels. Repeated images of one field are not biological replicates. Scene identity is not a supplied treatment-to-culture or descendant link.
