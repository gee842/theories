# Division timing preprint source

Cedeño-Pérez et al., *Cell division timing shapes the morphology and size of nascent multicellular organisms*, [DOI 10.1101/2025.04.23.650085](https://doi.org/10.1101/2025.04.23.650085), version 3 dated 28 May 2026. This version is a preprint, not a journal peer-reviewed result.

[article.xml](article.xml) is the complete, unchanged public JATS XML retrieved from Europe PMC on 8 October 2026. [The manifest](manifest.json) records the URL, byte count, local SHA-256 and the source's CC BY-NC-ND 4.0 notice. The original is preserved without adaptation; research interpretation is separate.

The present reading covers results sections S3–S8 and methods S17–S22, especially the declared growth/fragmentation model and settling calculation. The original simulation code, underlying lineage data, supplementary DOCX figures and videos have not been retrieved or validated. No author-code replication is claimed.
