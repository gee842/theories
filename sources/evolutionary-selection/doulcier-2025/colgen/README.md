# Colgen source versions inspected for forecasting

Original source bytes retrieved 8 October 2026; [manifest](manifest.json) records URLs, sizes, checksums and read members. No author package was installed or executed.

- `colgen-master.zip` is the **1.0** release from [Zenodo 7342768](https://doi.org/10.5281/zenodo.7342768). Its MD5 agrees with the publisher's `d69d18082ef0deaa1b04905997ce6327`. The preserved API response identifies its version.
- `colgen-2.0-retrieved.zip` is the actual response from the paper's dependency URL, `https://gitlab.com/ecoevomath/colgen/-/archive/2.0/colgen-2.0.zip`. Its SHA-256 is `d4d4f92234f16fd0441050b1dc8daf33e44c5cde8c23c484fef4ab9f04348b88`, **not** the dependency's pinned `38e9197142457bbd525d332384e2a9525e855641524edea4e1fe1f08ac827baa`. It is not certified as the paper's exact software artifact. The filename distinguishes the retrieved bytes.

The initial retrieval was rejected for a pin match and neither installed nor executed. Subsequent retrieval preserved the mismatching response explicitly for source inspection. We have not established whether the mismatch reflects archive regeneration or a substantive change since the pin. Comparing the verified 1.0 release with retrieved 2.0 does show changed code, so 1.0 cannot silently stand in for the dependency.

Reading covers the beta transition implementation in both archives, and `survival.py` plus `bn_discrete.py` in retrieved 2.0. The latter uses maximum-product latent configurations and parameter optimization in a procedure labelled expectation–maximisation. It returns fitted latent MAP values, not chronological posterior predictive probabilities. The analysis filename's `1500` specifies an upper parameter bound; it is neither an iteration count nor a fixed fitted concentration.

The retrieved beta source integrates a Beta(1+σp, 1+σ(1−p)) density across each probability bin, then multiplies by a midpoint survival/death emission and a grid constant. Our separately written forecasting implementation uses this transition family with normalized probabilities, posterior averaging over an explicit finite σ prior, and only past observations. Constant grid factors do not enter its normalized model. The 1.0 source uses a different integrated observation expression. We claim neither package replication nor equivalence of these versions.
