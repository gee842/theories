# Ratcliff 2013 survival data

Source: Ratcliff, William C.; Pentz, Jennifer T.; Travisano, Michael (2013). [Data from Tempo and mode of multicellular adaptation in experimentally evolved Saccharomyces cerevisiae](https://doi.org/10.5061/dryad.2hr77). Dryad version 1, published 27 February 2013, dataset 7855, version 7893. The dataset is released under CC0. [Primary article](https://doi.org/10.1111/evo.12101).

Retrieved 8 October 2026. The public browser preview contained the complete 30-observation survival table. Direct file downloads returned HTTP 403, the download API required authentication, and browser download attempts yielded no file handle. No credentials or protected access were used.

- [Normalized preview transcription](survival-preview.csv) preserves the displayed table with LF line endings.
- [Original-byte reconstruction](settling%20survival%20compiled%20data.csv) restores CRLF line endings. Its 643 bytes and MD5 `686faa3b6b625634c073bfc33095d4a0` exactly match Dryad's published file metadata. This is reconstructed from the public preview, not represented as a direct file download.
- [Dataset metadata](dataset-metadata.json) and [file metadata](file-metadata.json) retain the original public API response bytes. The [manifest](manifest.json) records URLs and preservation hashes.

Only this CSV is imported and analyzed. The size/velocity preview is truncated: 164 data rows are exposed and its final row is incomplete. The full 157,710-byte file and the other data tables have not been obtained or analyzed. The metadata listing is not a substitute for those files.

See the [research integration](../../../_process/research/2026-10-05-generative-foundation-review/root-foundation/ECOLOGICAL-SELECTION-INTEGRATION.md) and [analysis](../../../experiments/integrated-correction/general-framework/generative-basis/ecological-selection/analyze_survival.py). No raw values are corrected or replaced. The five cultures per isolate/regime are separate observations; row order does not establish pairing.
