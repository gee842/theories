- Article: Ehsan Sedaghat-Nejad and Reza Shadmehr, [The cost of correcting for error during sensorimotor adaptation](https://www.pnas.org/doi/10.1073/pnas.2101717118), PNAS 118(40), e2101717118 (2021). DOI `10.1073/pnas.2101717118`.

These files are metadata originals, not our interpretation or source code.

The workbook contains participant-level **binned** adaptation and decision values. It is not a raw eye-tracking or trial-event export. The repository's prospective secondary-analysis scope is in [the retrospective protocol](../../experiments/motor-learning-cost/PROTOCOL.md).

The primary article's methods, experiment/figure descriptions, data statement and model equations were inspected through the publisher text. The publisher article is linked, not republished here. Public stimulus/filter code and two large model-fit MATLAB files are listed in the OSF metadata; those files were not downloaded or analyzed. No undocumented raw values are reconstructed from them.

The OSF node metadata reports public read access and a null `node_license`; no reuse license is inferred from public access. Crossref metadata and OSF metadata remain separate records. We preserve only the source material necessary for this bounded research audit and do not infer anonymous participant identity across experiments.
