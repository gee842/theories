The three `.lfs-pointer.txt` files are the original Git LFS pointers for Sono's complete processed datasets. Their 713,631,608-byte combined payload was downloaded to temporary scratch and matched to the pointer hashes and lengths. It was **not deserialized or numerically analyzed** and is not imported here. Static pickle opcode inspection revealed pandas/numpy structures; that is not a scientific-data audit. The pointers, pinned URLs and hashes enable later retrieval. The author's reduced image test set is expressly insufficient to reproduce all published plots. No plot was digitized, dataset reconstructed, author contacted or experiment replicated for this addition.
