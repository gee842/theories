# Review L: Coherence audit — PLAN v0.3 vs SPEC v0.4 and vs itself (fable, 2026-07-30)

**VERDICT: sound enough to execute after a patch revision (~a day of writing, zero code). Architecture survived. Precision did not, at exactly the seams the three folded reviews touched simultaneously: the law is stated wider than true; the waist separation was announced then violated on the same page; ~20 things are named without definitions.**

## 1. The acts-only law, traced and broken

The word **"Every" is the bug**: the law covers *extend* moments and is silent about the other two mechanisms SPEC §3.2 names (extend, restart, originate).

**(a) memory note — holds, with two leaks.**
1. **Nobody executes the memory tool.** tool_port has only "bash + read/edit"; the mind can't do I/O (E6 stubs fs to explode). Only coherent reading: state-directed tools (memory/notes/intentions) have a **trivial executor** — validate and echo the requested mutation as the observation — and **the reducer is the only writer**, at SETTLE live and at fold identically. If someone implements the memory tool as a file-writer at ACT, there are two write paths and fold diverges the first time reducer and tool disagree — Pain-1 reborn one layer down.
2. **The generic `edit` tool can write `states/` directly.** Guard must extend: inside the world-tree, `edit` denied for `stream/`, `states/`, `present/`. states/ writes go through state tools; programs/ self-edit is separate; world files outside the tree remain A5 effects.

**(b) dream — holds by an argument the plan never makes.** Dream writes must be **acts by the being** (memory-tool calls creating chronicle entries + rewriting MEMORY.md), observed, reduced, folded, commit stamped op `dream`. But: nothing says dream writes ride the acts path (dream.py "reads like a module that writes files"); `Phase` reserves `dream` while v1 phases are attend|settle, so how a v1 dream moment runs is unstated (someone will implement it as a bypass around the cycle, breaking A1); **the change-report has no recorded home** (SPEC §5.3 makes it mandatory — experience? op payload? file? — and it is recorded bytes, so it's a format decision).

**(c) operator revise — THE LAW IS FALSE AS WRITTEN.** A revise is an op, not an act: no act, no observation, no reducer; the delta comes from `$EDITOR`. Missing rule:
> **The fold is defined per mechanism.** *Extend* nodes fold by reducers over their experiences. *Restart* nodes (revise, reunite, migration) **re-baseline**: their committed tree is accepted as new ground truth for `states/`, verified against the exact patch recorded in the op payload; reducers do not run across a restart. *Originate* nodes seed the fold.
Corollary that must be nailed simultaneously: **A8 lets the *receipt* carry "the diff or its summary"; the *op record* may not summarize** — else `fold --verify` cannot check the restart node and the record has an unverifiable hole.

**(d) crash recovery — ambiguous.** If "tail reconcile" means fold synthesizes resolutions at fold time, the committed node's stream lacks resolutions → violates A1's resolution invariant and makes resolutions derived rather than recorded (A3/A4 breach). Only coherent reading: **recovery appends synthesized `observation{outcome: cancelled|unknown}` as real experiences, then commits at q3**; fold never synthesizes for committed history. A reducer over `unknown` emits no Changes. Also unstated and format-grade: **the mid-THINK crash representation** (N closed parts, no message-close → truncated `thought` + `error`, usage `unknown`, never re-sent).

**(e) reunite — leaks.** (1) PLAN claims it "pre-answers SPEC §11.1"; SPEC keeps §11.1 **open**. Soften: the law gives §11.1 its vocabulary, not its answer. (2) "Re-applied at fold" is ill-defined across a merge: two `set`s to one path resolve by interleave order = silent clobber, contrary to §5.3's "surface contradictions rather than overwrite." (3) Repair already licensed: A8 names reunite a restart-op → apply (c): merge performed at reunite time, conflicts recorded in the op payload, fold re-baselines at the committed tree after independently folding both parents. DAG-shaped fold still right (walks both parents for verification/provenance) but **verifies branches and accepts the recorded merge; never re-merges.** (4) **The deterministic interleave key must be pinned now** (e.g. `(moment, stream_id, seq)`) — views depend on it, and it's exercised by no golden lineage.

**Two cross-cutting leaks:**
- **"observations" is too narrow** — denied proposals persist in states/intentions/, rulings arrive as `sensed`, receipts/span-summaries are `sensed`. The law should read "reducers fold **experiences**" — the prose contradicts its own type signature.
- **THE NATURE OFF-BY-ONE.** ProgramHost loads programs/ from the face at LEASE = the **parent's** committed nature. A mid-moment self-edit lands in N's tree and takes effect at N+1. But `Ember-Nature` stamps N's *own* tree hash. So piecewise fold must reduce node N's experiences under **nature(parent(N))**. SPEC A6's "the nature in force" is undefined; the plan defines nothing. Will be built wrong, discovered when golden lineage #1's E2 nature change folds differently than lived, then baked into append-only fixtures.

## 2. Two waists: announced, not carried through
PLAN §1 claims the format waist is "~4 shapes." §3's own code block puts **five classes** in the format section — Experience, Content (13-member union), Sensed sub-union (6), Change, Op (+7 OpPayloads), Part → honestly **~25+ shapes**. This is v0.2's "six types and four protocols" sin — which §2 calls "marketing" — recommitted at the format level in the very revision that diagnosed it. **E10 is unimplementable as specified**: no enumeration of the format waist exists to count.

Rulings (one-way doors, decisive):
- **`Change` = schema-format, lifetime-process.** Never serialized in v1 (reducers derive it live and at fold). But reunite/migration will record Change lists in op payloads. → **Freeze the schema now** (`path`, `op: set|merge|append|delete`, `value`; no floats), register it, count it in E10, **state that v1 never stores one**. And **define `merge` semantics** (deep-merge on JSON) before fold.py — apply-at-SETTLE and re-apply-at-fold must be byte-identical, so application semantics are format-grade.
- **`Part` = format** (verbatim inside `thought`, and in cassettes). **But `kind: Literal["text","thinking","signature","tool_call"]` is a closed literal that CONTRADICTS THE VERBATIM VOW**: Anthropic returns **`redacted_thinking`** plus server-tool and search-result content types → closed literal cannot store them → **verbatim capture fails on real traffic in week 2**. Fix: `kind: str` with the four values reserved and unknown kinds passed through byte-faithfully ("strict where you write" applies to the envelope, not a provider's grammar), or an explicit `other(raw)` arm. Versioned either way.
- **`Phase` = process** (only inside TickInput, never in bytes). Two hygiene problems: kinds.py houses it beside format enums; §9's never-cut "all reserved enums including ext" sweeps a process enum into the frozen list. E10 counts format enums only (Kind, Visibility, OpName, span reasons, outcomes, EdgeName, consent).

Never-cut audit: three items are **conduct rules, not format** — fsync-before-dispatch, secret redaction at WAL write, sims' world-write denial. Irreversible but invisible in bytes → split the list into "format doors (E10-counted, registry-versioned)" and "conduct rules (test-guarded)". **MISSING ENTIRELY: the blob encryption header.** SPEC §2.3 is explicit ("the header bit is not [deferred]"); PLAN's stream.py row and never-cut list never mention it → **a direct SPEC violation in the byte layout v1 writes from day one.** Add `enc: none` to the v1 blob envelope and to never-cut.
Also secretly format: **`present/messages.json`** — recorded in every node, "what other decades must read," yet the `Message` type appears once in TickOutput and is **never defined in either document.**

## 3. Contradictions

**3.6 Internal contradictions.**
1. **Attention purity vs nondeterminism**: §3 corollary allows "token estimates and other nondeterminism"; §7.2 states "attention is a pure function." Both can't stand. Replacement: "deterministic given its inputs (which include the pinned estimator version); never re-run by fold (present/ is recorded), so estimator drift can't endanger replay — but reattend/present-diff requires pinning the estimator with the nature."
2. **E5 as worded breaks `ext`**: "only the fold refuses" → the fold would ALWAYS refuse ext, making the flagship being-extensible slot unfoldable. Restore: "fold refuses **only if no reducer claims it**."
3. **E1 unimplementable as scoped**: MEMORY.md and chronicle entries are prose *inside states/* = fold **outputs**; editing them makes verification fail by definition. Scope E1 to prose under `programs/`.
4. **Week-2 claims A8 live; A8's test needs week-3's revise.** Either say "hand-authored op fixture" or move A8 to week 3.
5. **Multi-writer interleave built but never exercised** (twin cut from v1 CLI; golden #1 has one writer) — E4's own logic demands a golden lineage with ≥2 stream_ids, especially as the ordering rule is format-adjacent.

7. **Slot-1 locality vs piecewise fold**: §2's table implies core reducers live in the package, but piecewise-by-nature is only real if **ALL reducers ship in the tree** (seeded from the template), package holding only the enum + engine. Otherwise a kernel upgrade silently changes how old nodes fold and SPEC §2.4 is false for the commonest kinds. **State it.**
8. **SPEC has seven ports; plan has five** — IndexPort and EventPort absent from §3 *and* from §9's cut list (only their backings are cut).

## 5. Verdict

### Must land before the first line of core/
1. **Restate the law with mechanism scoping**: state-tool executor (reducer is the only writer), extended edit guard, **restart-op re-baseline fold semantics**, op-payload exactness (receipt may summarize, op record may not), reducers-fold-**experiences**, and **the nature off-by-one** (fold node N under nature(parent(N))).
2. **Enumerate the format waist + fix `Part.kind`** (open it — the closed literal *will* force a model_port rewrite and re-minting of every cassette); rule Change schema-frozen/lifetime-derived; move Phase out of the frozen sweep; **add the blob `enc` header**.
3. **Pin the canon-adjacent behaviors**: deterministic interleave key; Change `merge` semantics; truncated-thought crash shape; recovery-writes-resolutions-to-the-stream. Golden #1 bakes these in week 1 and the suite is append-only.
4. **One-page schemas for the compatibility surfaces**: .ember/* files (versioned), messages.json, world bootstrap + world.yaml, born_from_seed hash, SpanSummary + money representation.
5. **SPEC v0.4→v0.5 amendment batch in one commit**: add ext/wandering/reincarnate/SpanSummary; add Ember-Nature to §3.1 (reconcile Ember-Meta); add refs/ember/world to §3.3; widen §3.2 selection; rewrite §11.5; amend §0.4's M2 adapter line (or revert the plan); list the v1 staging deviations.
6. **Resolve attention purity** (§3 vs §7.2) and **state that all reducers live in the tree**.

### Fixable during the build
E1 scoping; E5 wording; E4 fakes clarification; four→six comment; 495→525; +110 double-count note; §2 v1/non-v1 labels; authority home + seed permissions.yaml; verifier's four checks; Query's loop (or honest reservation); receipt-walk marker; rites terminology; multi-sid golden lineage; change-report home; end's final moment; fatigue estimator; cli_obs −55; config.py; week-2 A8 claim; pyproject alignment.

### Forces a rewrite if found in week 2 (ordered by pain)
**(1) `Part.kind` closed** — first extended-thinking conversation returns `redacted_thinking`, verbatim capture throws, fix invalidates every cassette and golden thought · **(2) the nature off-by-one** — goldens fold differently than lived, and the append-only suite makes wrong fixtures forever · **(3) restart-op fold semantics absent** — week 3's revise lands, `fold --verify` has no rule, and the deadline improvisation is exactly the second state-reconstruction path SPEC §2.4 forbids · **(4) state-tools executor ambiguity** — if the memory tool writes at ACT the law's point is silently lost, discovered only when a reducer change diverges old lineages · **(5) unpinned interleave/merge/crash canon** — invisible until the first twin or crash, then permanent.
**Everything else is documentation debt; these five are format debt, and format debt in this project is the one kind the thesis says can never be refinanced.**
