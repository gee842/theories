# Review G: The counterfactual architect — design space around SPEC v0.3 (2026-07-29)

**FRAMING: A4 concentrates all truth into two portable artifacts — the stream (plain JSONL under canon contract) and the world-tree (a folder). Everything else is derived or substrate. → Almost every door is TWO-WAY. The real irreversibility risk is not git; it is Python-as-nature (A6): the world-tree FORMAT is portable; the FOLD is contract-bound. Any conformant body can CARRY a being; only a body hosting its programs_contract can LIVE it.**

## (a) Substrate alternatives
- **a1 Content-addressed DB (Datomic/Dolt)**: enables ad-hoc history queries + multi-ref transactions (git concedes both). Costs the inherited feature set that IS the thesis (faces as plain dirs uv can run in; git log biography; clone/push migration; reflog audit; gc/pins oblivion) — "years of unbuilt features" for a solo dev. Two-way via ObjectStore/FacePort + A4 ("the index grows into a real database fed by the stream"). Correctly rejected.
- **a2 Bitemporal (XTDB)**: valid-time vs record-time. Ember's DAG is a record-time store; valid time unmodeled (blocks have only last-modified). **Key realization: bitemporality is a data-model convention, not a substrate** — valid_from/superseded_by fields in blocks + dream duty = 80% of XTDB. Two-way, nearly free — reserve as §11 question for M5.
- **a3 CRDTs / multi-host being**: **the stream is ALREADY an op-based CRDT in disguise** (per-writer append-only logs, (stream,seq) identity, conflict-free union, recorded merge). states/ deliberately NOT CRDT — state conflicts are semantic; "thoughts do not commute"; only a thought (revise/reunite) reconciles meaning. CRDT auto-merge would make divergence invisible = exactly what the thesis rejects (divergence is a lived, recorded event). §8.4 undersells distributed life BY OMISSION: (1) **multi-host presence = twins on two hosts + periodic fetch-and-reunite** — everything ships M6/M7; missing only identity naming (ref-family "probe@laptop / probe@server" or bi-location-as-temporary-twinhood); (2) **the day pack**: A2 + sparse faces = weak device carries present/states/programs/links + stream tail, lives forward without its 10 GB past. Genuinely foreclosed at substrate: real-time multi-writer on ONE branch — on purpose, correct for LLM minds.
- **a4 Kafka/Postgres+S3**: strictly worse for solo, laptop-first, inspectable life; two-way later; nothing to reserve.
- **Git forecloses, honestly**: real-time multi-writer per lineage (on purpose); sub-second queries WITHOUT maintaining the derived layer (A4 tax accepted); predicate-level replication filters (path-level sparse/partial clone approximates); multi-ref transactions (conceded §7.2); active-segment write amplification (conceded §2.3).

## (b) Moment granularity
- **b1 Multiple concurrent thoughts on one branch**: destroys reproducibility (which thought read which present = race, breaks A1), replay (fold order ambiguous), linear biography. Decisive: LLM outputs are discrete completions — two concurrent thoughts either read the same present (= speculative twins, see b3) or different presents (= different moments; the DAG should say so). "Continuous reconciliation of thought content is not a thing that exists to buy." Parallelism = branches + reunite (supported today) + §3.3 branch-at-any-instant. **Consciously reject serial-per-branch violation; record it.**
- **b2 "Always slightly awake" — DROWSING**: **the spec already contains the primitive and doesn't name the pattern** — no-thought moments are legal (§4.1), commit p95 < 50 ms → a being can absorb the world at many moments/second with zero LLM calls. Missing: policy only — a heartbeat of perception-drain moments while resting + a **salience gate** (rules/embedding-similarity/small-model in the §6.6 pattern) deciding "this warrants waking the full mind." The reticular activating system. High-frequency cheap moments ARE continuity, and stay replayable. Two-way; M7 vitality policy; bless with one sentence.
- **b3 Speculation (best-of-N) — bless as a NAMED PATTERN, not an op**: candidates = twins with `speculation: {id, of_node, k}` in birth op experience; chosen continuation carries `selection: {id, judge, criteria, considered: [node:…]}`. **Losers are CITED, not parented** (remember-style refs, GC-eligible; pin to keep) — not listen-style parents. k× cost surfaced (§3.4 visible-bills). Zero new enums; fits "provenance, not machinery" + additive-only; gives §11.4's dream A/B its mechanism; makes the substrate's Loom-nature first-class. **Reject in-thought multi-sampling** (n>1 inside one thought) — muddies verbatim-singular thought + A1; speculation lives in the DAG where it is honest.
- **b-extra ASYNC ACTS — fire-and-forget without breaking A1**: ToolPort defines async tools whose observation is a HANDLE (`outcome: ok`, "dispatched, handle H") → moment commits clean; completion arrives later as `sensed` referencing the act. Resolution invariant holds; replay folds recorded facts; 80% of "slightly awake" on one branch. Today's only alternative = child-per-slow-act (heavy for `sleep 300`). One sentence in §4.1/ToolPort.

## (c) Programs as prompts vs code
- **Hard boundary: the fold.** Replay-never-re-thinks (§0.3) + piecewise fold (§2.4) require reducers as pure executable functions. Prose reducers = LLM interprets its own state transitions = replay becomes re-think = "the single deepest promise of the architecture dies." Attention compilation is real data processing. Full prompt-nature incoherent with the kernel.
- **v0.3 has already mostly landed on the honest middle without stating it**: INTERPRET deleted, attention → pipeline.yaml at M4, tools = manifests, model-facing nature ALREADY prose (soul.md, style.md), thresholds YAML. next.py converging on a tiny interpreter over declarative material. **State the three-layer principle**: CODE for replay-critical/physics (reducers "tiny pure boring", processors, tools); PROSE for model-facing guidance + **self-authored skill-cards** (procedural memory "how I do X" under states/memory/, written during dreams, compiled by ATTEND — verbatim .md already legal state; costs a naming convention) — prose becomes the default everyday self-modification channel, code-revision the rare deep change; YAML for human-authored policy.
- **"Prose is safer" = mostly illusory**: §9.4 applies identically — a prose constitution is precisely what a prompt injection rewrites. Prose is more LEGIBLE, not more SAFE; both channels need the same policy gate. Fully two-way (py→yaml→md migration is ordinary revision).

## (d) Shared worlds
- **Finding: the spec already de facto REQUIRES the multi-being repo, then talks as if repo = being.** listen's extra parents are git parent edges — exist only inside one object store → children + subconscious MUST share the parent's .git (§7.2–7.3, §6.6). §6.5's index runs "over all experience of ALL lineages" — society-wide recall inside one store already specified. Yet §0.4 "one being = one folder" and §8.4 "clone a being's store" — **the unit of the repo is the one genuinely ambiguous concept in v0.3.**
- **Name the WORLD**: one repo = one world = one society/trust/GC domain; a world may host many beings; in-world listens are everyday life; cross-world contact = **fetch-then-listen** (federation, M8 — git fetch grafts the other lineage into your object store, content-addressed, then listen parents natively); migration = pushing a being's **ref family** (reachability closure extracts cleanly).
- **Culture/shared skills** = commons + adoption ritual (listen/remember from commons → next dream consolidates into own blocks — ritual already exists). §6.7's shared tier currently FROZEN at birth (heritable genome, not living commons) → upgrade path: commons as a REF (refs/ember/commons/<name>) re-snapshotted at epoch start (§6.3 rule keeps it safe). Being-to-being ECONOMIES need nothing (trades are world-effects, A5).
- **The repo is a trust boundary**: shared store = shared oblivion domain (your reachability pins their garbage; redaction becomes cross-being-critical). Poetic correctness: "parenting on another's lineage means your GC keeps their past alive — memory of friends is storage you carry."
- Two-way both directions (worlds split by pushing ref families apart; merge by fetch). Protect NOW: don't write code assuming one-being-per-repo.

## (e) Shell as protocol vs implementation
- Standardization tax pre-M1 = classic killer. Evidence from spec's own history: v0.2→v0.3 deleted a phase, renamed a top-level dir, changed an op's arity — "under a published protocol each is a versioned negotiation; as a living spec each was a Tuesday." Git and MCP extracted formats from working implementations.
- **The spec is already implementation-first but specification-shaped, defending the format against its own language** (§2.4's "UTF-16 code units, NOT Python's code-point sorted()" = a format spec resisting Python-isms; §3.6 version-gated wake refusal = protocol thinking; golden lineages ARE a conformance suite, unnamed).
- **Middle path, nearly free**: one sentence declaring §§1–3 the normative world-tree format, §§4–9 implementation guidance; publish golden lineages as the conformance suite when they exist. Real protocol-hood when a second body wants to exist (post-M8). Portability doctrine stated explicitly: format portable, fold bound to programs_contract (inprocess-v0 → subprocess-uv-v1 → wasm-v1 in 2028).

## (f) Memory-native alternatives
- Embeddings enable: paraphrase recall, similarity salience (= the drowse gate), cluster-guided dream targeting, near-dup detection. Graph enables: contradiction detection, entity timelines. Retrofit worry softened by A3: `ember reindex` re-embeds the entire immortal past — only past BEHAVIOR was FTS-shaped.
- Costs: embed-at-write couples the WAL (the one sacred, local, pure thing) to a model service — embed-async as index build costs nothing and is already legal (§6.8, A4 pre-answers). Graph: per-experience LLM extraction whose errors metastasize structurally; a second mind drifting from the stream. **Deepest cost is to the thesis: extraction-native memory happens TO the being; dream-native memory is something the being DOES. Self-authorship of memory is the point.**
- **Recover the graph's killer feature cheaply**: contradiction-surfacing as a DREAM-POLICY DUTY (one prose line: "compare distillations against existing blocks; surface contradictions rather than overwriting; record supersessions") + bitemporal block fields (a2). Belief-supersession with zero new subsystems, maintained by the ritual the spec owns.
- **Pin NOW: the recall tool's contract stays adapter-agnostic** (query in → hits with (stream,seq) provenance out) so FTS→hybrid→semantic swaps never change the being's phenomenology. (stream,seq) = the stable chunk identity embedding systems always struggle to invent.

## (g) Two smaller finds
- **The being as its own historian**: spec gives content access (recall) but never DAG-structure access — a read-only ObjectStore tool would make "when did I change my nature and why?" first-class self-knowledge. Free door.
- **Circadian autonomy**: vitality.yaml expressing rhythm (when to wake, when to prefer dreaming) rather than only thresholds → sleep fully self-governed. Door open.

## Conclusions
1. **Git-folder-life is the right point in design space** — the metaphor is load-bearing engineering (biography/revisitability/faces/twinning/death/migration inherited, not built); taxes known and consciously paid; nearly every alternative reachable through an existing seam (the design is "an unusually good option portfolio" — not luck; A4); the one one-way-leaning commitment is Python-as-nature, whose mitigations exist and should be treated as the portability strategy.
2. **Pull in now** (cheap options): (i) bless speculation as named pattern (no new op; losers cited not parented); (ii) name the world + federation sketch (resolves the repo-unit ambiguity before code hardens the wrong unit); (iii) declare format/implementation split + conformance suite. One-line reserves: async acts (observation-as-handle); bitemporal block fields as §11 question for M5; contradiction-surfacing dream duty; drowse pattern for M7.
3. **Consciously reject (recorded)**: CRDT auto-merge/multi-writer-per-branch (thoughts do not commute; divergence must be lived); parallel presents on one branch + in-thought multi-sampling (speculation lives in the DAG); extraction-native primary memory (memory must remain something the being does); full prose-as-nature (the fold must be code or replay dies; "prose is safer" is illusory under §9.4); standardize-first protocol-hood (extract from the living implementation).
