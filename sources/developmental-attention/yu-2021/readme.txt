Infant attention to the intended objects in parent speech is measured by defining a temporal window from the onset of a parent naming utterance to a fixed internal (0.5, 1, 2, 3, 4 or 5 seconds, etc.). 
Each data file is based on one specific temporal window. Within each file, there are a set of naming events, with one row for each naming event. 
Each row has 7 fields:
field 1: subject ID
field 2: onset of a naming event
field 3: offset of a temporal window (for example, the file named "onset-0.50" defines a temproal window with 0.5 sec from the onset)
field 4: object/toy ID, there are 24 toys 
field 5: naming instance ID
field 6: attention/gaze on target, measured as % of time within the temporal window
field 7: attention/gaze on other objects (any other objects), measured as % of time within the temporal window
