- **Serene J. Khader, “Must Theorising about Adaptive Preferences Deny Women's Agency?” (2012).** The preserved file is the author-hosted penultimate manuscript, whose spelling/pagination differ from the [publisher's version](https://onlinelibrary.wiley.com/doi/10.1111/j.1468-5930.2012.00575.x). Read the main argument, manuscript pp.1–12 (§§1–5); later endnotes are outside this reading. Reported field studies were not independently checked.
- **Richard Holton, “Rational Resolve” (2004).** The preserved author-hosted manuscript says “Forthcoming in the Philosophical Review.” Focused reading covers the introduction, discussion of retained ability to reconsider, and conditions for rational persistence; see the manifest for precise pages. The [author's course bibliography](https://web.mit.edu/holton/www/courses/moralpsych/home.html) identifies the published article. This is not a full-paper reading or an empirical replication.

The comparison distinguishes source claims from the current project's proposed test and ethical argument. Neither author is presented as deriving this project's universal ethical minimum without premises.
