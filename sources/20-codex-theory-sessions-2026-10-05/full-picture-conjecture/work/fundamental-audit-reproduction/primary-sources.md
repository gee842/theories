# Primary source anchors

Actual source bodies were inspected for this focused comparison. This file records locators rather than reproducing source text. The audit report contains the substantive comparison. This is not a comprehensive literature or priority review.

- J. C. Maxwell, A Dynamical Theory of the Electromagnetic Field, 1865, Part VI, sections91–97,100,102,105: https://en.wikisource.org/wiki/A_Dynamical_Theory_of_the_Electromagnetic_Field/Part_VI . Transcription linked to original work; electrical-to-optical quantitative comparison and its stated assumptions.
