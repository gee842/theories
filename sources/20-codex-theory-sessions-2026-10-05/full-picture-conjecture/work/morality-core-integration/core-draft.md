# 良知与共同生成：核心增补草案

**规范根原则。** 生生的道德方向，是使具有感受或自身能动性的主体能够生活、回应、行动并修正其生活。每一主体的基本感受与能力都构成应被考虑的理由；这些理由的分量，不因主体的名字、身份、物种归属或阵营而任意消失。相关差别可以支持不同安排，差别本身及其后果须能公开说明。这是本论承认并继续辩护的规范起点。

共同生成要求把受影响者纳入同一判断：谁获得了新的可能，谁承担了代价，谁还能表达异议、改变关系和纠正损害。扩张一方的能力，不能仅凭总量增长就获得正当性。若一个安排的延续有赖于持续剥夺他者的基本回应与修正能力，它便对共同生成负有解释与改变的责任。

保护并不要求让每个现存过程永远延续。行动条件会相互冲突，某些限制、中止和退出能够维护更广的生活与能动性。此时需要说明必要性、可替代方案、损害分担以及修复途径；紧急措施也应保留复核与解除的条件。普遍性首先落实为理由可以换位检验、主体不会被任意排除，而具体冲突仍需审议。

**良知的机制假说。** 良知是主体将自身感受、他者处境及行动后果纳入判断，并据此约束欲望、审查理由和修正目的的能力。对人类而言，本论把它的身体与情感基础置于演化之中，把其具体形成置于成长、照护、交往、文化与制度之中。哪些机制促进关切、哪些机制固化偏见，以及其他物种具有何种相关能力，均须由经验研究分辨。

良知的形成使共同生活的条件成为内在的关切。痛苦、同情、羞愧、愤怒或不安能够提示有待回应之处；判断还须经过事实核查、他者表达与角色交换。成熟的良知保留纠正自己的能力：当新的主体、损害或依赖关系进入视野，原有的善恶判断也应接受重审。良知的权威由这种持续负责的实践获得支持。

受到保护的资格与承担责任的能力分别判断。一个主体即使不能回报、论证或履行义务，其感受和基本利益仍应被考虑；责任则随可知信息、可用能力、可选方案及其参与形成约束的方式而变化。物种差异可以影响这些事实，不能单独替代对事实与理由的说明。

生成与损害还可以形成反馈：互信、照护、可靠知识、可申诉的权力及修复能力，可能相互增强；掠取、欺瞒、压制异议及透支再生条件，也可能相互强化。两类反馈为善恶提供可研究的机制形态。它们是否出现、如何转换、能否长期稳定，取决于具体条件；本论将其作为经验假说，不预设世界恰有两个吸引子。

**条件定理与实践检验。** 规范原则确定应保护谁、保护什么；经验研究确定依赖、风险和可用机制；延续与复现定理检验这些要求能否共同实现。将各主体已获辩护的基本要求写入保护条件，将必要的服务、回应与修正写入进展条件，便能追问：是否存在一个真实可执行的政策，使共同保护持续成立，并使必要活动反复得到实现？

这种检验把道德承诺落到资源、信息、权限、记忆、执行与维护之上。若共同可行集为空，应查明冲突来源，审查可改变的制度与技术，并为不可避免的取舍给出理由。若存在可行政策，则还须证明实际安排能够执行它、承担其成本并保留纠错。由此，良知提出和修正保护的理由，共同生成约束安排的方向，动力学检验承诺的实现条件。
