# 核心增补草案：实质审阅

2026-10-05。审阅对象：`work/morality-core-integration/core-draft.md`。未改动理论正文，未重跑研究或构建。

**结论：可纳入，建议先做以下四处限定，并在来源记录中保留第五项区分。** 草案已经把规范起点、机制假说与条件定理分别陈述；也正确区分受保护资格与承担责任的能力，并明确否认“世界恰有两个吸引子”。没有发现需要推翻增补方向的问题。

1. **避免从纯功能性能动性自动推出道德地位。** 首句“具有感受或自身能动性的主体”中的“自身能动性”可能把任何目标追踪、优化或自维持系统直接纳入道德患者。建议紧接补充：“感受能力提供直接纳入考虑的理由；若以能动性作为独立根据，还须说明该主体何以具有自身可受损的利益。仅有功能性的目标追踪、自调节或扩张，并不足以自动确立道德地位。”这不预先排除非人类或人工主体，而是保留论证义务。也防止把不能论证或互惠者排除在外；草案后文对此已处理正确。

2. **把良知形成与规范上成熟的良知区分。** “良知的形成使共同生活的条件成为内在的关切”容易被读成无例外的经验结论。建议改为：“良知的形成可以使共同生活的条件成为内在关切，但内化的判断也可能夹带偏见、服从与排斥。”后面的事实核查、他者表达、换位和重审正好承担规范筛选工作。演化、成长与文化提供形成机制，不保证每次良知体验都正确。

3. **反馈形态不能直接充当善恶判据。** 保留“不预设世界恰有两个吸引子”，并把“两类反馈为善恶提供可研究的机制形态”改为：“这些反馈为某些维护或侵蚀共同生成的安排提供可研究的机制假说；其道德评价仍须依据受影响主体的利益与上述规范原则。”合作可以发生在损害更大共同体的局部系统内；反馈的正负、稳定性或强度本身不决定正当性。这里也不应把生物性损害写成细胞的道德罪责。

4. **明示条件定理的适用域。** 建议把“延续与复现定理检验这些要求能否共同实现”限定为“在已声明并经适用性检验的模型、信息及扰动范围内，延续与复现定理检验这些要求能否共同实现”。可紧接一句：“现有有限模型中的复现指指定进展条件反复满足，不等于无穷的语义创新，也不单凭形式证明保证现实永续。”共同可行集为空，首先是所述模型和约束下的结论；草案已有制度、技术与取舍复核，可一并包含模型复核。

5. **来源记录按实际证据类型登记，避免把五项合成一个演化证明。** Warneken等支持有控制条件的工具性帮助；Koenigs等支持特定脑损伤对特定困境判断的选择性影响；Henrich等兼有跨群体共同模式和显著差异；Choi–Bowles是有明确前提的演化模型，作者未声称证明相关战争倾向基因存在；Archetti等是肿瘤细胞体外实验与模型，不能登记为整个人体适合度或治疗效果的证明。五者都不直接确立普遍规范正当性。特别保留：早期帮助不等于完整反思良知；神经基础不等于“良知中枢”；选择成功不等于共同生成或道德正确。

上述修改旨在使已接受的规范承诺与经验支持各有清楚位置，不要求把规范原则降格为任意偏好，也不否认生物学可以为伦理论证提供事实前提。
