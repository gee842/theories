# Diagnostic-value follow-up

Exploratory continuation of the access study. The original study is unchanged. This bundle checks a one-round state outside its starting grid and an additional evaluation. It contains no substantive-domain transfer result.

Read work/research/inquiry-limits-and-horizon.md for the analytical argument. The burden score is a limited proxy, not total harm.

Extract, then run with Python3.11+ (standard library only):

    python3 work/inquiry-followup/check_diagnostic_value.py
    python3 work/access-study/followup-audit/diagnostic_mechanism.py

The first checks informative/uninformative outcomes and all eight original-sensor actions against the independent oracle. The second independently enumerates the actions and exact vertices of lotteries subject to expense/burden constraints. Local result files are overwritten by rerunning. The copied original main output is present only so the audit can confirm its hash is unchanged. No network or reference workspace is needed.
