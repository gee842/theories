## Portable reproduction

Use Python 3 and its standard library from an extracted copy of this bundle:

```
python3 verify_root_scope.py
python3 universality_barrier_examples.py
```

The default root-scope replay uses the bundled source manifest as frozen provenance and checks the arithmetic against the inspected definitions. It does not access the original source repositories or independently verify that those repositories still have the recorded contents. The optional `--inspect-live-sources` mode refreshes source hashes and excerpts from the absolute paths recorded in the script; it is unnecessary for portable arithmetic reproduction.

The scripts rewrite their result JSON in the extracted copy. `manifest.json` hashes every other payload file. Source hashes refer to the inspected originals, while bundle hashes refer to these delivered evidence files.
