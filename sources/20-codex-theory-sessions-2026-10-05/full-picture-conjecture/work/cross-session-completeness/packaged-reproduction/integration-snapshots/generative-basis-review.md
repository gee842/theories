## 1. Formal scope and proof review

**Faithful quotient.** Equality of all within-block transition sums, separately for every permitted input pair, is exactly the necessary-and-sufficient condition for the specified all-initial-states quotient. The definition deliberately requires abstract-state transition preservation, a stronger contract than equality of selected label traces. The note correctly avoids claiming necessity for every weaker predictive abstraction.

**Path laws and policies.** Conditional next-block rows coincide for each fine state in a block, so conditioning on an abstract history merely mixes identical rows. Induction proves equality of finite cylinders; uniqueness of the product path measure supplies infinite-history event equality. This uses the same admissible policy and boundary-input process. A hidden fine-state-dependent input rule cannot be replaced by an abstract-history rule without further assumptions.

**Protected labels versus information.** The note explicitly separates the analyst's outcome labels from observations available to participants. Retaining a label does not permit a participant to condition actions on it. State-dependent action availability is included in the initial partition and compared only on enabled inputs. This distinction is essential for the continuing-participation and inheritance examples in the integration map; the code's refusal labels should not be read as a worked strategic equilibrium.

**Coarsest partition.** Each strict refinement increases block count. If a stable partition refines the current partition, each current block is a union of its stable blocks; equality of probability sums therefore prevents the next refinement from separating any of its states. This proves coarseness, uniqueness and termination. The stated minimality is correctly restricted to deterministic state partitions under the fixed contract. It is not a minimum among arbitrary hidden-state models or a unique social ontology.

**Expanded contract.** Adding inputs, labels or kernel-family requirements shrinks the admissible set of faithful partitions, so the new coarsest partition refines the old. The note correctly distinguishes a common partition with different model-indexed quotient kernels from one identical kernel across all models. It does not silently treat an unknown model index as observed.

**Composition.** The sequential identity follows from matrix associativity. Mixture weights constant on a block preserve equality of block sums; a hidden guard may destroy it. Product composition requires the full joint product law, not merely matching marginals. Shared noise is a substantive interface condition. Intermediate observations or hazards must be included if they are relevant, rather than inferred from endpoint equality.

**Generating instructions.** Every bounded finite program using rational independent coin instructions gives rational path probabilities. Conversely, sequential conditional probabilities reproduce any finite rational row. The proof's treatment of zero remaining mass and deterministic final mass terminates correctly. The source/input lookup is generated by bit tests, not supplied as an oracle. The finite fair-coin restriction is also correct: padding paths to equal depth gives dyadic output probabilities, while common-denominator bit allocation generates every finite dyadic kernel.

These are expressiveness and reduction results using supplied mechanisms. The note explicitly preserves that limitation and makes no unsupported novelty, empirical universality or alignment guarantee claim.

## 2. Implementation review and independent coverage check

The producer's refinement computes exact `Fraction` transition sums, starts from label and permission equality, and carries the old partition identifier into each signature. Its exhaustive comparator tests all within-block pairs against all target blocks directly; it does not call the refinement function to determine stability.

The restricted-growth partition enumerator is sound by the usual unique first-appearance labeling of blocks. To check completeness independently, [review_checks.py](review_checks.py) enumerates **every function** from an n-element set into itself for `n=1,...,6`, turns its fibers into an unlabeled partition, and compares the resulting sets with the producer's output. This visits 50,069 functions and confirms exactly the Bell counts `1,2,5,15,52,203`, without duplicates or missing partitions in the producer. The reference does not use restricted-growth recursion or iterative refinement.

The producer then verifies that its answer is stable and coarser than every exact stable candidate, in addition to testing unique minimum block count. The coarseness test is the appropriate stronger check; minimum block count alone would not establish a unique coarsest ordering relation in an arbitrary family. The 36 generated rational systems are supplementary constructed cases, not independent empirical samples or a substitute for the theorem.

The paired-block example has genuinely differing internal rows and equal protected-block sums. The delayed example needs more than one label-based refinement, so the suite is not solely testing trivial singleton outcomes. The action-extension and permission-label examples test distinct interfaces. A successful random-case count should nevertheless not be presented as scientific validation of the proposed substantive mechanisms.

## 3. Resolved compiler discrepancies

The initial code inspected used a whole-memory equality guard (`ifbits`) and a direct stochastic branch. Those were equivalent to expressible macros but did not literally implement the primitive syntax stated in the note. The producer now uses only `ifbit`, deterministic one-bit writes, sequences, and `coinwrite` into a scratch register followed by `ifbit`. Old-state registers are distinct from next-state output registers, and the row checks assert the old bank remains unchanged. The output distribution marginalizes scratch information. Invalid source encodings deterministically write output zero.

The row sampler repeatedly renormalizes the remaining distribution. If the current first positive probability is `p<1`, the failure continuation uses each other mass divided by `1-p`, so its unconditional output probabilities are unchanged. A single remaining positive target is written deterministically. Reused scratch storage is overwritten by each fresh coin and therefore does not introduce accidental dependence between draws.

The compiler is a macrostep evaluator, not a model of paid computation, an asynchronous institution, or a decentralized execution system. In particular, the check does not charge instruction time or establish safety during writes, nor does it model an external intervention between them. This boundary is explicit in the formal note and in the recorded results.

## 4. Two independently reconstructed boundary witnesses

**Joint noise.** Drawing one fair bit and returning `(z,z)` gives both coordinates fair but equality probability one. Returning `(z,1-z)` gives the same two marginals but equality probability zero. The independent script calculates all four marginal equalities and both joint probabilities explicitly. This separately checks the example in the formal note; the producer uses the equally valid independent-versus-shared version.

**Atomic transfer.** Consider finished next-state code `01` and old-state code `10`, with three intended states `{0,1,2}`. Copying the next bank to the old bank one bit at a time, low bit first, gives old-state codes `2 → 3 → 1`. The intended source and destination are valid, but an observer allowed to interrupt the transfer can see code three. This is not a flaw in the producer, which preserves the old bank throughout its macrostep and does not expose this transfer. It is a concrete reason the optional subsequent transfer requires the atomic boundary specified in the note, or an expanded program-counter/register model. Endpoint equality alone cannot answer an intermediate-state safety question.

## 5. Additional structural-closure audit

The structural theorem is a valid sufficient result. Parent closure ensures each retained coordinate reads only retained old-state values, and the common state-independent joint-noise law supplies a pathwise coupling of all retained updates. A policy must use the stipulated permitted observations and corresponding internal memory. Treating an interacting hidden environment or a state-dependent noise selector as unconditioned fresh noise would invalidate the proof; the note explicitly excludes this.

I checked the ten-coordinate example's equations against every listed parent set. No-change branches correctly retain their old coordinate as a dependency. The seed `{b,v,p}` adds `{y,c,m,k}` and then `{r,a}`, leaving only the badge `j` outside. Shared `E` in several updates does not undermine the theorem because the whole vector uses the same joint draw. The restricted model is synchronous: its across-time feedback creates no unresolved simultaneous next-state equation.

The independent script transcribes the local old-state equations and compares both badge values for every one of the 512 retained states, all sixteen inputs, and all four joint-noise values. All **32,768 paired branch comparisons** give identical retained next vectors. This checks the claimed projection more strongly than comparing output marginals. It also independently recovers the omitted-maintenance burden probabilities `0` and `1/4`, and the expanded badge-mode next-authority values `0` and `1`. These are exhaustive finite comparisons in a constructed example, not independent empirical replications.

The badge-dependent mode therefore genuinely invalidates the old nine-coordinate quotient, not merely its syntactic certificate. The theorem correctly avoids claiming that nine coordinates or 512 states are the smallest semantic model; canceled reads and restricted reachable sets can permit additional reductions. Added protected significance can also make the badge relevant even without a dynamical edge, by placing it in the seed. This preserves the distinction between causal relevance to a specified outcome and moral relevance.

No correction beyond a minor phrasing cleanup was required; the producer changed “strict additions of rounds” to “strict expansion rounds.” The new finite-coins sentence in FORMAL.md also correctly makes explicit that rational probabilities are encoded data, not a fixed finite menu of biases.

### Structural producer and a protected-output witness

I subsequently inspected the separate structural producer. Its coordinate order, synchronous old-state equations, joint-noise weights and mode-specific authority guard agree with the formal note and the independently written review implementation. For each source bit, its dependency audit toggles that bit from zero to one while holding every other old-state bit, proposal and noise value fixed. The resulting `10 × 512 × 16 × 4 = 327,680` comparisons per mode family correctly determine **extensional branchwise reads** on this full Boolean domain. They do not prove coordinate necessity for a marginal stochastic quotient. The producer separately compares the exact projected joint distributions for `512 × 16 = 8,192` badge pairs/input combinations; this preserves correlations that marginal-only comparisons could miss.

The added three-step witness reaches an **original protected outcome**, rather than only an internal authority coordinate. Start at `(c,y,r,k,a,v,m,b,p,j)=(0,0,1,1,1,0,0,0,1,j₀)` and use badge-sensitive authority throughout. Proposals are no execution, then execute, then no execution, with the other three proposal bits always zero. Let `E₁,E₂,E₃` denote the three fresh circumstance shocks. Direct substitution gives:

- After step one: `y₁=0`, `k₁=1−E₁`, `a₁=j₀`, and `m₁=1`.
- After step two: `y₂=j₀(1−E₁)`, `c₂=E₁ xor E₂`, and `m₂=j₀`.
- Therefore `j₀=0` gives `b₃=E₁ xor E₂`, with probability `2(1/4)(3/4)=3/8`.
- For `j₀=1`, `b₃=(not E₂) or E₃`, with probability `3/4+(1/4)(1/4)=13/16`.

Fresh badge shocks do not enter these final expressions; they affect later authority but not this selected three-step burden path. The independent script additionally enumerates every complete three-step joint-noise word: 64 words per initial badge value, 128 total. It does not call the producer's `propagate` or use its recursive state aggregation. Both calculations recover exactly `3/8` and `13/16`, and the recorded producer result agrees. Thus the new intervention changes the answer even to the original burden question, not merely the stronger nine-coordinate state contract.
