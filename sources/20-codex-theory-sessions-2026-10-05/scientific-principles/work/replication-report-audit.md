# Audit of the integrated investigation: replication and inquiry resources

5 October 2026. Read-only audit of outputs/scientific-principles-investigation.md, especially lines 193–241. Source checks use primary material already retrieved for replication-memo.md. No edits to the integrated report.

## Findings needing correction or clarification

1. **Line 241: matching a mediator is not a general falsification test.** The report says loss of advantage after “matching informative observations and costs” would count against the implementation. If calibration/revision access helps precisely by obtaining informative observations, equalizing those observations removes the hypothesized mediator. Disappearance is compatible with, and potentially supports, that mechanism. Suggested replacement: “An observation-matched control tests any claimed advantage beyond information access. Disappearance of the effect there would not refute an information-mediated explanation. Failure to improve under the originally specified equal-resource comparison, or failure of the predicted information mechanism, would count against that implementation.” Also distinguish matching ex ante resource allowances from post-treatment matching on realized spending.

2. **Line 237: a diverse channel can help without fully resolving an ambiguity.** “Helps only when it breaks a remaining ambiguity” is too strong if “breaks” means achieves identifiability. A channel can reduce finite-sample error or improve precision while some parameters remain nonidentifiable; ordinary additional iid measurements can help even in an already identifiable model. Suggested wording: “A diverse channel can improve diagnosis when it adds relevant information; its benefit depends on the remaining uncertainty, dependence, and cost.” The original sentence is defensible only with an explicitly narrow definition of “helps” as distinguishing previously identical worlds.

3. **Line 235: distinguish protocol confirmation data from final evaluation data.** Calling data used to revise the models “fresh evaluation data” risks consuming the final evaluation set adaptively. Say “fresh confirmation observations available to the protocol,” then preserve separate held-out evaluation worlds whose labels and aggregate scores do not influence protocol development. Adaptation *within* an evaluated world is allowed under the frozen protocol; adaptation *to the final evaluation results* requires a new analysis or untouched evaluation.

4. **Line 205 and dependency table: state the ideal decision-theoretic law.** The information-option argument assumes a fixed joint probability law/prior, integrable loss, and optimization over rules able to ignore the added signal. “Truthful information” alone does not imply that a bounded reader interprets its statistical implications correctly. Suggested insertion: “under a supplied, correctly specified joint law and the ideal optimal decision rule.” The subsequent cost and behavior caveats are good.

5. **Line 215: make renewal conditional on exhaustion.** Finite worthwhile inquiry can finish from a sufficient initial reserve without renewing anything. Suggested wording: “When continued inquiry would exhaust its initially accessible enabling resources, it requires renewal, replacement, or further supported inputs.” The existing prefix-financing statement is correct when time is resolved at each actual payment event.

6. **Line 201: the independent comparison changes marginal miss probabilities.** The common-failure example has individual miss rate \(q+(1-q)r=.28\), whereas the cited independent benchmark has miss rate .2. Both reported numbers are correct, but they do not isolate dependence. An equal-marginal independent benchmark gives \(.28^5=.0017210368\), still far below .100288. Either add this benchmark or explicitly state that .00032 removes the common-failure mechanism while retaining residual miss rate.

## Primary-source support

**NASEM terminology: supported, with a small wording improvement.** The report's [Summary, definitions on p. 1](https://www.nationalacademies.org/read/25303/chapter/3) defines computational reproducibility through original data, computational steps/methods/code, and analysis conditions. Replicability concerns consistent results for the same scientific question from studies obtaining their own data. Add “addressing the same scientific question” to line 193. NASEM Chapter 5, pp. 73–75 and 85–90, supports uncertainty-sensitive replication criteria and multiple possible sources of non-replication. The report does not overclaim from this source.

**Perdomo: supported within the deployed-prediction scope.** [Performative Prediction, §2, Definitions 2.1/2.3 and Example 2.2](https://proceedings.mlr.press/v119/perdomo20a/perdomo20a.pdf) explicitly evaluates risk under deployment-dependent \(D(\theta)\) and distinguishes performative optimality from stability. Line 207 accurately describes prediction-induced distribution change. Tighten “The object of assessment must then include the intervention or deployment rule” to “Assessing predictive performance after deployment must then account for that deployment rule.” A historical predeployment distribution claim does not become false merely because later deployment changes the distribution.

## Overall judgment

The replication formula, conditional-error interpretation, distinction between reproduction and empirical truth, and resource limitations are sound. No fatal defect was found in these sections. The mediator issue is the main substantive correction; the others make hypotheses and evaluation boundaries explicit.
