# Scientific principles research

The investigation finds conditional derivations of testability and possible adverse evidence, with qualified justifications for checking, disclosure, uncertainty reporting, and revision. Causal embeddedness alone does not derive an entire scientific method or its ethical aims.

Start with the [main report](scientific-principles-investigation.md). It contains the dependency map, definitions, minimal model, worked examples, exact testing comparison, counterexamples, and next research design.

- [Primary source map](primary-source-map.md): verified readings, differences between traditions, and access gaps.
- [Formal supplement](formal-supplement.md): extra proofs, assumptions, and verification scope.
- [Research decisions](research-record.md): claim status, rejected overclaims, and corrections retained after review.
- [Exact results](verification-results.json) and [reproduction script](reproduce.py): standard Python, no third-party dependencies.
- [Complete research bundle](scientific-principles-research.zip): deliverables, independent checks, review notes, and supplied-framework snapshots.

To reproduce the main exact calculations, run `python3 reproduce.py` from this folder or pass its absolute path. It writes `verification-results.json` next to itself. The longer independent checks and audit records are in the bundle. No rich laboratory comparison or empirical study has been run in this pass.
