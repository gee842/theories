# Scientific principles and scientific change

Start with the completed [integrated inquiry report](integrated-scientific-inquiry.md). It joins ordinary work, income, question formation, maintained checking capacity, institutional purpose change, fresh method checks, and subsequent practice in one executable community. Its 1,920 frozen evaluation runs include both successful adaptation and retained failures.

- [Complete integration bundle](integrated-inquiry-bundle.zip): reports, code, frozen protocol, evaluation records, independent audits, and development history.
- [Results at a glance](integration-summary.csv) and [predeclared example trajectories](integration-trajectories.png).
- [Protocol](protocol-v3.md), [independent audit](integration-independent-audit.md), and [reproduction instructions](integration-reproduction.md).

The result is a bounded candidate mechanism. Computation establishes what this declared model does; it does not establish a universal or empirically validated theory of human science. Its finite grammar, council constitution, ultimate concerns, contracts, and atomic-review conditions are supplied.

The earlier stages remain available:

1. [Scientific principles](scientific-principles-investigation.md): conditional derivations of testability, adverse evidence, checking, uncertainty reporting, and revision, with a [formal supplement](formal-supplement.md) and [source map](primary-source-map.md).
2. [Formation of questions and concepts](theory-of-scientific-change.md): bounded representation construction and method selection.
3. [Mechanisms of scientific change](mechanisms-of-scientific-change.md): broader synthesis, actual rule revision, transfer limits, repeated reversals, and [formal results](scientific-change-formal-results.md).
4. [Integrated inquiry](integrated-scientific-inquiry.md): the completed community loop and all evaluation outcomes.

The original [scientific-principles archive](scientific-principles-research.zip) remains an unchanged first-stage snapshot. Its `bundle-manifest.json` describes that original archive, not the later files added here. `integration-delivery-manifest.json` describes the current integration delivery; `integration-freeze-manifest.json` separately records the source freeze before evaluation.
