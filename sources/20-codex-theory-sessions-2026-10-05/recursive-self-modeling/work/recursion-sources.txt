Recursive self-modeling: finite self-reference, stopping, and exact scope
Research note, 5 October 2026 (Asia/Bangkok)
Status: source audit plus elementary derivations; no claim of mathematical novelty or empirical psychology.

CENTRAL FINDING

A finite system can contain self-referential descriptions, reapply one procedure to its previous outputs, or unfold descriptions to any requested finite depth. These are different constructions. Neither the existence of self-reference nor a semantic fixed-point theorem establishes stable dynamics, accurate introspection, unlimited implemented depth, or normative authority. Conversely, diagonal impossibility theorems rule out specified universal guarantees; they do not rule out accurate limited self-prediction.

DISTINCTIONS TO KEEP IN THE MAIN SYNTHESIS

1. Object nesting versus process reuse. A nesting R(R(x)) concerns what is represented: the outer object has a representation as its target. A program repeatedly applying R need not possess separately designed machinery for each level. Sequential reuse can overwrite the prior state; simultaneous access to all levels requires storage or recomputation. Conversely, repeatedly applying the same update rule is not automatically meta-modeling: it may merely refine an estimate of the same target. Specify target identities, retained states, and decoding functions.

2. Finite graph versus infinite unfolding. A finite directed graph can include a node referring to itself. Following the edge repeatedly generates an arbitrarily long walk; the stored graph has not grown. The infinite unfolding of that graph is a mathematical construction, not evidence that the physical system has traversed every branch or step.

3. Indefinite extensibility versus completed infinity. The claim "for every finite n, this rule specifies a depth-n expression" has quantifier form forall n exists expression. It does not imply one completed execution realizes every n, or that one finite budget supports them simultaneously. For step durations tau_k >= tau_min > 0, n steps require at least n*tau_min. Without such a lower bound, a formal Zeno schedule tau_k=2^(-k) fits infinitely many steps into a finite mathematical interval; whether physically realizable is an additional physical question. Likewise, total resource R bounds level count only when each active level incurs positive minimum cost or another explicit non-summability assumption.

4. Semantic fixed point versus dynamical convergence. A program p and transformed program T(p) can have the same input/output partial function even though their text differs; this is an extensional/semantic fixed point. A state x* with F(x*)=x* is a dynamical fixed point. Its existence does not imply convergence of x_(t+1)=F(x_t). Example: F(x)=1-x on [0,1] has x*=1/2, but every x0 other than 1/2 alternates forever. Under F(x)=a*x+(1-a)*b with |a|<1, x_t-b=a^t(x0-b), so convergence follows from the contraction assumption, not from self-reference. If |a|>1, the fixed point is unstable.

5. Termination versus usefulness. A fixed iteration cap ensures termination but not accuracy or benefit. A convergent sequence may converge to a wrong model. A semantically self-reproducing program can terminate; a non-self-referential loop can run forever. These properties are logically independent.

SMALL CONSTRUCTIONS AND CHECKED PROPOSITIONS

A. Finite self-reference without an infinite tower.

The following Python program, under ordinary Python string formatting, prints exactly its own source line:

    s='s=%r;print(s%%s)';print(s%s)

The data s contains a finite template; %r supplies its quoted representation and %% supplies a literal percent sign. Formatting the template with itself produces the source line. A terminating quine demonstrates a narrow kind of syntactic self-reference. It is not a model of its runtime state, a model of an emotion, or evidence of consciousness. It supplies a counterexample to "self-reference requires infinitely many separately stored representations."

B. A minimal obstruction to universal feedback prediction.

Let a predictor emit a bit p in {0,1}. Let a system receive that bit and act a=1-p. The predictor is required to predict the resulting action exactly using the same bit: p=a. Combining gives p=1-p, impossible for a bit. This proof assumes (i) the prediction is delivered to the target, (ii) the target can implement this response, and (iii) correctness is demanded for this case. It says nothing about forecasts withheld from the target, probabilistic forecasts, restricted targets, stable policies, or predictions at a coarser resolution. Adding another finite meta-level does not fix these three mutually incompatible requirements. Removing or changing one can.

C. Complementarity defeats the naive one-step reflection rule.

Let Z1 and Z2 be independent fair bits whose values are not yet accessible to a decision-maker. The target is theta=Z1 XOR Z2. Choose an action a in {0,1}, receiving 1 when a=theta and 0 otherwise. An allowed computation exposes one Zi at cost 0.1; each can be exposed once. This may represent a costly examination of two stored diagnostic results. It is a stipulated computational uncertainty model, not proof that deterministic processing creates information.

Before either computation, best expected terminal payoff is 0.5. After either single result, theta is still fair, so the payoff remains 0.5. A one-step rule evaluates each computation as 0.5-0.1=0.4 and stops. But doing both yields payoff 1-0.2=0.8. Exact backward induction therefore chooses a first computation (value 0.8), then a second (remaining value 0.9), then acts. If cost is 0.3 per computation, the two-computation value is 0.4 and stopping at 0.5 is better. This elementary constructed example establishes why "no immediate benefit from one more step" is not a generally valid stopping certificate.

D. An operational finite-budget reflection criterion.

State s contains the current information, available actions, relevant environment state, and remaining integer budget b. Let g(s)=max_a E[u(a,theta)|s] be the value of acting now. Every feasible reflection c has integer budget consumption k(c)>=1, net cost K(c,s), and a specified transition model s'~P(.|s,c). Include time effects, target changes, and opportunity costs in s, K, and P when relevant. Set:

    V_0(s)=g(s)
    V_b(s)=max{g(s), max_(c:k(c)<=b)[-K(c,s)+E[V_(b-k(c))(s')|s,c]]}.

Reflect exactly when its best continuation value exceeds g(s); break ties by acting. Each actual reflection reduces budget at least one, so execution terminates within b operations. The recurrence is exact in this declared finite-horizon decision model. It does not justify an agent recursively spending unlimited computation to solve its own recurrence: policy construction and policy execution must also be implemented and paid for. Practical options are an offline compiled policy, fixed small lookahead, or an empirically learned stopping policy, with their own errors and overhead measured.

For a PURE INFORMATION variant with a static target, fixed utility/action set, and no direct effect of computation except revealing information and paying cost, the gap E[max_a u(a,theta)|s]-g(s) bounds the possible gross improvement. If this gap is below the cheapest possible first computation, any continuation has negative net value. This is a sufficient stop certificate, not a necessary one. It does not apply unchanged when reflection changes the target, available actions, utility, or future environment.

Sections 6–8 concern universal-machine simulation and diagonal arguments; the paper's original formulation uses circle-free machines and computable sequences. Use it to delimit universal effective decision procedures over a computational model class. https://arxiv.org/abs/0708.1362

Definitions 1–4: a device is (X,Y) over possible worldlines U, with binary surjective conclusion Y; weak inference requires a nonempty setup fiber for each single-value binary probe, and correctness everywhere on that fiber. Proposition 1(ii) has a direct diagonal obstruction: a probe demanding -Y cannot equal Y on any setup. Theorem 1 prohibits mutual weak inference when every pair of setups is jointly possible. These are precise relational impossibilities, independent of a chosen dynamical law. The model also permits successful restricted inference; it does not show all self-observation inaccurate. S6. F. William Lawvere (1969), Diagonal Arguments and Cartesian Closed Categories, Lecture Notes in Mathematics 92, 134–145.
Original scan inspected: https://www.its.caltech.edu/~matilde/LawvereDiagonalArgCartesianClosedCats.pdf
Official reprint listing found: https://www.tac.mta.ca/tac/reprints/articles/15/tr15abs.html
Pages 136–137 state and prove the fixed-point theorem under a weakly point-surjective representation map in a cartesian closed category. In sets, the diagonal proof is transparent: if E(a,x) represents every map A->Y, then for t:Y->Y represent x->t(E(x,x)) by a; y=E(a,a) satisfies y=t(y). If t is Boolean negation, this contradicts universal representability. The strong representability premise must be established before use. This theorem does not imply that psychological reflection converges to a fixed point, that a feeling must be self-contradictory, or that every abstraction preserves its target's properties.

REJECTED FORMULATIONS

- "Self-modeling inevitably creates a completed infinite regress." Finite graphs and finite self-reproducing programs are counterexamples.
- "Any fixed-point theorem proves reflective equilibrium." Semantic identity and dynamical attraction differ.
- "Every finite resource bound imposes a maximum depth." Requires explicit per-level costs and a definition of implemented versus describable depth.
- "A positive computation cost gives a fixed deterministic stopping deadline." False without further assumptions; expected and worst-case bounds differ.
- "One more step has no immediate expected benefit, so all further reflection is useless." The XOR example disproves this.
- "Turing/Gödel prove all complete self-knowledge impossible." No target, formal language, allowed query class, or success criterion has been specified.
- "Universal invariance follows from embeddedness." At most a universally quantified participation constraint follows once implementation in the world is assumed. Preservation under a map requires a separate commuting relation or other explicit proof.

OPEN ISSUES

- When does the recorded representation preserve a target's information sufficiently for later questions, and when does meta-modeling merely reiterate lost information?
- How can a learned value-of-reflection estimate be calibrated under distribution shift without reopening a supposedly solved infinite metaregress?
- What temporal indexing correctly distinguishes observing a present feeling from remembering the earlier feeling changed by observation?
- Which physical cost bounds are empirically defensible for active human recursive reflection? Computability alone does not supply them.
- What would count as revising the frame/action set rather than simply obtaining better estimates within a fixed decision problem? The finite-budget recurrence assumes the relevant transitions are already represented.
