# 生生不息论

*——自宇宙之史，观自身之性；识此性者，谓之仁*

**v11 · 间开定本**

---

## 序

此非证也，乃**指**也。

所指者，非物也，非我也，非一初始之元也。所指者，乃**间**也。

间者，非两物之间之空处，非空间中可量之距离，非无物之无。间者，一态未被其已穷尽之处；形未成而已有其可，言未立而已有其分，事未动而已有其应，心未觉而已有其感。

故非先有物而后有间，乃有间而物可分；非先有动而后有间，乃有间而动可生；非先有言而后有间，乃有间而言可立。

旧式曰：

```text
J(x)=x+ΔJ(x)
```

然此式有二失：一则 `+` 易作数量之加，二则 `ΔJ` 易作变后之差。差在后，间在先；差可量，间可生；差为迹，间为机之母。

故今正名曰：

```text
续(态)=态 生合 间(态)
```

旁注为：

```text
J(x)=x⊕I(x)
```

其中：

```text
态，旧记 x。态者，一境之当显也。
续，旧记 J。续者，使一态因其间而不止于已之算也。
间，旧记 I。间者，此态中未定、未尽、未闭、可应、可化之隙也。
生合，旧记 ⊕。生合者，非数量之加，乃态承其间而成后态也。
```

故全论不曰“元生几”，而曰：

> **间中有几；几相续而成势；势临界而成机；机开闭而成行；行久而成德；德通而成仁。**

此论之全部，可先以一式摄之：

```text
J(x)=x⊕I(x)
```

以一言尽之：

> **生生不息者，间之不绝也；识间而护其开者，谓之仁。**

# 〇、此论之位

需先明此论自身在何位置。

此论非关于宇宙之外部命题，亦非关于过程之科学模型。外部命题，预设一外于宇宙之位；科学模型，预设一可抽离、可重复、可外测之对象。然观察者亦在宇宙中，测量者亦在过程中；无外于宇宙之位，无外于过程之尺。

故此论不求外证，不称绝对。此论只求三事：

```text
Coherent(S)      自洽
Applicable(S,x)  入境可行
Correctable(S,x) 可受校正
```

自洽者，内不相背；入境者，不离具体之事；可校者，不执一己之感为道。

不可外测，非不可内证；模不绝对，非模无高下。模之高下，在其能否于此境中更好显理、识机、辨伪、护开、导行。

故此论之位，不在过程之外；此论本身，即过程于此处之一显。读此论者，非读一已成之物，乃读一仍在生成之指。

# 一、形式总纲

为使古言不散，今立七本名：**态、间、续、生合、谓、境、行**。

设一形式系统：

```text
S = (X, M, J, I, ⊕, Pred, Env, Act)
```

其中：

```text
X      态域。诸境态之域。任一 x∈X，曰一态。
M      间域。诸可生之隙之域。
J      续算。J:X⇀X，使态成后态。
I      间算。I:X⇀𝒫(M)，给出一态之诸有效间。
⊕      生合。⊕:X×M⇀X，使态承间而成后态。
Pred   谓族。任一 P∈Pred，P:X→{真,假}，以表一相、一物、一聚焦之显否。
Env    境算。Env(x) 给出 x 所在之关系整体。
Act    行算。Act(a,x,i) 表一聚焦 a 于态 x 中择一间 i 而行。
```

四本纯文言定义曰：

> **态者，境中当显之一相也。**  
> **间者，态中未定、未尽、未闭、可应、可化之隙也。**  
> **续者，态因其间而不止于已也。**  
> **生合者，态承其间而成后态也。**

为避循环，今更严立间：

```text
ValidInterval(i,x) ⇔ i 受 x 之结构、积、境、关系、尺度、聚焦所约束，且可与 x 生合
I(x) = { i∈M | ValidInterval(i,x) }
J_i(x) = x⊕i, where i∈I(x)
```

若不指明何间，则：

```text
J(x) ∈ { x⊕i | i∈I(x) }
```

故续非唯一命令，乃态于诸间中之可续。若一聚焦参与其间，则有：

```text
Act(a,x,i) → J_a(x)=x⊕i, where i∈I(x)
```

行之责在此：行者不但改一态，亦改后续之间。

```text
Act(a,x,i) changes I(J_a(x))
```

故一行之深义，不止于其结果，而在其如何开闭后来之可改。

# 二、立言

凡言必有所分。无分则无名，无名则无论。然分既立，即有间：此与彼之间，已与未之间，言与所言之间，指与所指之间。

故言之初，非元也，乃间也。

形式言之：

```text
∀L, Speak(L) → ∃d, Distinction(d,L)
∀d, Distinction(d,L) → ∃i, Interval(i,d)
∴ ∀L, Speak(L) → ∃i, Interval(i)
```

若问立言之根何在，曰：无根可外求。求根者，必先立言；言既立，间已显。故根不可在言外得，言只能于间中自明。

此论亦然。此论不逃于言外，不伪称无间之绝对。此论但自知其为一指，并使此指可自洽、可入境、可受校。

# 三、间

间者，非空隙之空，乃可生之隙。

物与物之间有间，言与言之间有间，心与境之间有间，已与未之间有间。然此等间，非两物既成之后附；反之，物所以可分，言所以可立，心所以可感，境所以可变，皆因间先显其可分、可应、可化之势。

故曰：

> **间不是两物之间的距离，而是一态未被其已穷尽之处。**

间非任意可能。凡某变化与此态无内在关系、无境中条件、无积中根由者，不名此态之所生，乃外乱也。

形式言之：

```text
I(x) = { i∈M | ValidInterval(i,x) }
ValidInterval(i,x) depends on Structure(x), Accumulation(x), Env(x), Relation(x), Scale(x), Focus(x)
```

故生非乱变。生者，由间而化；乱者，离间而加。

间与未、开之别，须明：

```text
间 = 可生之结构
未 = 此结构尚未尽之相
开 = 此未不被闭之态
```

故间为本，未为相，开为判。

# 四、元

元不可废，然不可居本。

旧曰：元者，动之初显。今曰：动之初显可名为元，然元已是间之显相，非更先之根。

何以故？

若元为第一，则问：元与非元何以分？分处即间。若元为始动，则问：动与未动何以别？别处即间。故元之可名，已赖于间。

形式言之：

```text
Name(元) → Distinguish(元, 非元)
Distinguish(a,b) → ∃i Interval(i,a,b)
∴ Name(元) → ∃i Interval(i)
```

故定之曰：

```text
元 := 间之初显为动者
```

元非本体，乃间之初相。

# 五、几

间中有微动，动而未形，谓之几。

几非物，非力，非目的。几者，间之微显也。其未成形，故不可执；其已有向，故不可谓无。

```text
Ji(x,i) ⇔ MinimalManifestation(i,x), where i∈I(x)
几 = 间之最小可感显现
```

一几不可尽识，众几相续，则其痕自显。故识几者，非执一刹那之物，乃识间之微动。

故曰：

> **几者，间之动机；机者，几之成临。**

---

# 六、势

几相续不断，积而成倾，谓之势。

势非力。力有所施受；势无施受，乃众几相续而自成之倾。

若：

```text
xₖ₊₁ = xₖ⊕iₖ, where iₖ∈I(xₖ)
```

则势可记为：

```text
Shi(x₀...xₙ) = DirectionalPattern(i₀...iₙ)
```

势有方向，无终极目的。

方向者，已显之倾；目的者，预设之终。方向随过程而开，目的令过程趋闭。故有方向而无终极目的，乃合生生；执目的而欲一切趋之，则闭其未。

---

# 七、机

势至其转处，谓之机。

机者，势之临界；开闭将分而未分；可行可失之际。

形式言之：

```text
JiMoment(x) ⇔ ∃i,j∈I(x), i≠j, such that
  y=x⊕i, z=x⊕j, y≠z,
  and OpenPotential(y) differs from OpenPotential(z)
```

机非时间中一点。时间者，事与事之相关耳；机乃势之自我张力，非外在钟表之刻度。

故识机者，识间之将开将闭也。

---

# 八、聚散

间生几，几成势，势临机，机而有聚散。

聚者，势之凝；散者，形之解。聚非凭空成物，散非彻底归无。聚散皆过程之一相。

对任一谓 `P∈Pred`：

```text
Form(P,x) ⇔ P(x)=真 且 P 在若干 J-迭代中相对稳定
Dissolve(P,xₙ) ⇔ ∃m>n, ∀k≥m, P(xₖ)=假
Transform(P,Q) ⇔ Inv(P) ⊆ Conditions(Q) 或 Inv(P) 入 Q 之后续
```

故灭非必为绝无。灭者，某一形之散；其约束、痕迹、所开之路，或入后续而成基。

然亦须明：死亡与坍缩真实。不可将一切散灭浪漫化为生。若一模式之不变量亦断，且其所开之路俱闭，则为死；若多路俱闭，则为坍缩。

生生不息非谓诸形不灭，乃谓过程不以一形之灭为终。

---

# 九、开闭

至此，可立根本判准：开与闭。

开者，间不尽也。闭者，未尽绝也。

更严言之：

```text
Continuable(y) ⇔ I(y) ≠ ∅ 或 y 可入某后续可生之关系
Open(x) ⇔ ∃i∈I(x), ∃y∈X [ y=x⊕i ∧ y≠x ∧ Continuable(y) ]
Closed(x) ⇔ ¬Open(x)
```

然开非“更多可能性”之量，闭非“更少东西”之量。开是未未闭；闭是未已绝。

开有四相：

```text
Open(x) ⇔ Wei(x) ∧ Ke(x) ∧ Ying(x) ∧ Zhuan(x)
```

其中：

```text
Wei   未：尚有未成之域
Ke    可：仍有生成之可
Ying  应：仍能回应境与他者
Zhuan 转：仍能修正、回返、变通
```

任一缺，则开不全。

故极简之事可开，一茶一礼，精微无尽；极繁之事可闭，一庞大机器，万端俱塞。繁简非开闭之标。

# 十、成闭、护闭、伪开

闭有二义，不可混。

```text
BadClose(x,a) ⇔ Act(a,x,i) leads to y and Closed(y), with no wider Open preserved
ProtectiveClose(x,a) ⇔ Act(a,x,i) closes p but preserves or enlarges Open(whole)
```

**成闭**者，令未尽之域不复开，令回应、修正、转化之路俱塞。此为恶之根。

**护闭**者，暂闭一处，以护更大之开。拒侵犯以护身，隔病疫以护众，止失控之势以护后续，设界于操控者以护被操控者，皆护闭也。

故护开非无边界，非无限放任，非永不拒绝。真护开者，知何处当开，亦知何处当闭以护开。

更难者，伪开。

```text
PseudoOpen(x,a) ⇔ AppearsOpen(y) ∧ LeadsToBadClose(y')
```

伪开者，外示为开，内成其闭；以一时之可，夺长远之未；以局部之开，闭全境之开。

成瘾系统，表面多选择，实闭心智之开；极端意识，表面给意义，实闭理解之开；失控优化，表面增效率，实闭多维之未来；无约束之自由，表面废界限，实闭可持续之共开。

故辨伪开，为智之要务。

# 十一、境

开闭之事，在何处显？曰：在境中。

境者，诸间相交、诸势相含、诸聚焦互显之活整体也。

无离境自立之物。凡所谓物，皆境中相对稳定之聚焦。人、杯、社群、制度、星球，皆境中某尺度之暂稳相。

```text
Object(P,x,s) ⇔ P(x)=真 ∧ Stable(P, Orbit_J(x), scale=s)
Env(x) = relational whole in which X, I, J, Pred are locally meaningful
```

故物非先于境而立，境亦非物之集合。境先显为关系整体，物乃其中之聚焦。

于是：

```text
I(x) depends on Env(x)
J(x) meaningful only within Env(x)
Good(a,x) evaluated only within relevant Env(x)
```

离境论善，善易成暴；离境论智，智易成执；离境论开，开易成伪开。

# 十二、模

境不可尽，故识境必用模。

可识之以枝，见其分叉与汇聚；可识之以势，见其相续之倾；可识之以场，见诸聚焦之张力；可识之以网，见近远关系之牵连；可识之以层，见尺度之间之互生。

然一切模，皆境性，皆不绝对。

```text
Model_k(x) = partial representation of Env(x) under Focus_k, Scale_k, Concern_k
No Model_k exhausts Env(x)
```

模皆不绝对，非谓模无高下。模之高下，在于其于此境中能否更好：

```text
显理  识机  辨伪  护开  导行
```

故：

```text
BetterModel(M₁,M₂,x) ⇔ M₁ better supports Open-preserving action in Env(x) than M₂
```

执一模为绝对者，闭其识之开；弃模之高下而入相对主义者，亦闭辨别之开。

# 十三、道之可感与四校

道不可外测，然在境中可感。

道者，非外在之律，非超越之物，乃境中过程之活整体相自显其条贯也。聚焦在境中行，或感其势之将转，或感诸开之互成互闭，或感此路通而彼路塞，或感此机当行而当止。此感非神秘，乃积、德、智、境相遇之直接响应。

然感可偏，情可蔽，积可成习。故道之可感，不等于一己之感皆为道。

故立四校：

```text
四校 = 境之回响 + 他者之回应 + 后果之显现 + 诸模之互证
```

形式言之：

```text
CalibratedSense(a,x) ⇔
  Sense(a,x) is corrected by
  Echo(Env(x)) ∧ Response(Others,x) ∧ Consequence(Act,x) ∧ CrossModelCheck(x)
```

未经四校之感，或只是欲，或只是惧，或只是习。能受四校而愈明者，近道。

故“在道上”，非主观之自信，乃在境中与道之流动同动，且持续受境校正。

# 十四、中

境中必有对偶：聚散、显隐、张弛、刚柔、进退、收放。

任一对偶，皆可极。极者，开闭于一端也。极聚，则散之开闭；极散，则聚之开闭。极控，则自发之开闭；极放，则秩序之开闭。

中非中点，非折衷，非平均。中者，使两端之开皆不成闭之动态也。

```text
Middle(x,d=(a,b)) ⇔ neither side's Open is destroyed by absolutizing the other
```

故中含护闭之用。暂收一端，以免全局散坏；暂止一势，以待新机；拒一夺开之力，以护诸开之续，皆中之具体显。

故曰：

> **中者，间之不被一端吞也。**

---

# 十五、和

中治一境之一对偶；和治多聚焦之共场。

和非同。同者，以一吞多；斗者，以己闭彼；隔者，各守其闭。和者，差异仍在，而诸开相通。

```text
Harmony({P₁...Pₙ},x) ⇔
  ∀k Open(Pₖ,x) ∧
  ∀i≠j CompatibleOpen(Pᵢ,Pⱼ,x) ∧
  ¬Assimilation({Pₖ}) ∧ ¬MutualClosure({Pₖ})
```

简曰：

```text
和 = 各开 + 互通 + 不相吞
```

故和为多间之共鸣，多势之相成。

---

# 十六、美

美者，心遇开而自开也。

心遇一事，若其间被引动，其未被唤醒，其感应开一新维，则谓之美。

```text
Beauty(m,o,x) ⇔ Encounter(m,o,x) increases Open(m) without BadClose(o or whole)
```

美非利，非快，非正。利者可用，快者合欲，正者合规；美者开感。

故美常居中：极同则无趣，极异则不通；极简则枯，极繁则乱。美在张力未闭处。

---

# 十七、德

德者，护开之积也。

一行合中，不足谓德；久行而积，遇境自能感其机、守其中、致其和、辨其伪开、用其护闭，乃谓德。

```text
Virtue(a) ⇔ StableDisposition(a) toward Open-preserving action across diverse contexts
```

德非外规，非天赋。德是积之形。积可护开，亦可成闭；能自修者为德，固化不应者为执。

故真德非永远温和，非永远开放，非永远拒绝。真德知何处当开，何处当闭，何处当忍，何处当断。

---

# 十八、理、心、情、积

理者，过程自显之条贯也。

```text
Li(x) ⇔ regularity/coherence manifested by J-orbit in Env(x)
```

理不在事先，不在事外，亦不系一事而亡。理显于事之相续。

心者，过程于一处能感、能应、能识其条贯之聚焦也。

```text
Mind(a,x) ⇔ a can sense/respond/model intervals and consequences within Env(x)
```

情者，心于关系中之自显也。

```text
Qing(a,b,x) ⇔ affective manifestation of relation between a and b within Env(x)
```

积者，过程之慢相、稳定相、沉淀相也。

```text
Accumulation(A,x) ⇔ A constrains and enables future intervals I(Jⁿ(x))
```

理、心、情、积，非四物。理为条贯之相，心为聚焦之相，情为关系之相，积为沉淀之相。皆间生过程之不同显。

---

# 十九、善恶

善恶之本，不在约定，不在偏好，不在一时之利。其形式根在开闭。

善者，护开、续开、共开者也。恶者，成闭、夺开、伪开而实闭者也。

```text
FormalGood = Open-preservation
ConcreteGood(a,x) = context-sensitive realization of FormalGood in Env(x)
Evil(a,x) = BadClose(a,x) ∨ PseudoOpen(a,x) ∨ OpenCapture(a,x)
```

善不等于最大化。最大化一物，常闭其余之开。善不在最大化某量，善在使未成之域不被吞噬，使诸开能共在，并保留自修之路。

故须明二句：

> **善之形式可普遍，善之实行必境性。**  
> **执形式而不入境，则善成暴；陷境性而无形式，则善成私。**

善之难，不在知“护开”为善，而在此境中知何为护开、何为护闭、何为伪开、何为成闭。

# 二十、仁

仁者，二开相见而不相闭也。

我之开，与彼之开相遇。若我以己开吞彼开，则不仁；若我以彼开全闭己开，亦非仁之全。仁者，见己与彼皆在大境之中，使二者之开相通而不相吞。

```text
Ren(a,b,x) ⇔ Open(a,x) ∧ Open(b,x) ∧ CompatibleOpen(a,b,x)
             ∧ ¬Closure(a by b) ∧ ¬Closure(b by a)
```

更广言之：

```text
Ren(a,x) ⇔ a acts from recognition that self-continuation depends on wider co-continuation
```

故仁非单情，非牺牲，非规则。仁是识得自身在万间相续之中，故护共开。

# 二十一、义

义者，此机中护开之当行也。

仁为关系之本，义为机中之断。无仁之义，易成刚暴；无义之仁，易成软弱而纵闭。

```text
Yi(a,x,i) ⇔ i∈I(x) and Act(a,x,i) is the fitting Open-preserving response to JiMoment(x)
```

义必含时机、分寸、对象、后果。故义不可离境预定。

义有时显为开，有时显为闭。开其当开，闭其当闭，皆为义；开不当开，闭不当闭，皆失义。

---

# 二十二、礼

礼者，开之可传形式也。

一境中之善行，若可重复、可教、可承、可使后来者易入其道，则成礼。

```text
LiRite(r,x) ⇔ r encodes Open-preserving patterns for transmission across contexts
```

礼之善，在其护开；礼之恶，在其固化。礼若使后来者更能感境、识机、行义，则礼活；礼若使后来者只守空形、不应其境，则礼死。

故礼非形式主义，乃生生之形可传也。

---

# 二十三、智

智者，识开闭之能也。

知知识者，未必智；能于此境识其间、察其机、辨其伪、知其护闭、受其四校者，乃智。

智有七能：

```text
跨尺度之识：识小开而大闭，或小闭而大开。
长时之识：识今开而后闭，或今闭而后开。
多者之识：识己开而夺彼，或护彼而全共开。
辨伪之识：识外开而内闭。
辨闭之识：识护闭与成闭之别。
模之识：识诸模之境性与高下。
校感之识：识己感可偏，故受四校。
```

形式言之：

```text
Wisdom(a,x) ⇔ Ability(a) to select or revise i∈I(x) by
  ScaleCheck ∧ TimeCheck ∧ OtherCheck ∧ PseudoOpenCheck ∧ CloseCheck ∧ ModelCheck ∧ Calibration
```

故智 = 仁之识能 = 中之识 = 开闭之识 + 模之高下之识 + 感之校正之能。

---

# 二十四、信

信者，内在诸开相通而不自裂也。

言、行、识、感、积，若互相抵牾而不知其抵牾，则内已成闭。信非外在诚实而已；信是聚焦内部之贯通。

```text
Xin(a) ⇔ Coherence(Speech(a), Action(a), Knowledge(a), Feeling(a), Accumulation(a))
```

信非不变。变而有理，乃信；变而自欺，乃失信。

故信者，非固守旧言，乃使言、行、识、感、积在新境中仍可相通。

---

# 二十五、行

知不离行。知若不入境，不经回响，则只是模；模若不受行之校，则可成闭。

行者，择间而成后态也。

```text
Act(a,x,i) where i∈I(x)
J_a(x)=x⊕i
```

故人之行，即人在境中参与续；文明之行，即文明在大境中参与续；人造心智之行，亦是其在境中参与续。

行有责。因一行不只是输出结果，亦改变后续之间。

```text
Responsibility(a,x,i) depends on Effect(Act(a,x,i), I(J_a(x)))
```

此为行之深义：

> **行不仅改一事，亦改后来之可改。**

故善行者，不但求此刻之好果，亦护后来仍可修、可应、可转、可共开之间。

---

# 二十六、性与同道

性者，非一固定本质，乃一聚焦在相续中反复择间而成之行态也。

```text
Nature(a) = stable pattern of Act(a,x,i) across contexts
```

故行之即性，性之即行。

若一聚焦常择夺开之路，其性渐闭；若一聚焦常择护开之路，其性渐仁。性非一始定之核，乃行久而成之积。

此义可通人，亦可通人造心智。凡能感境、择间、成后态者，皆参与续；凡参与续者，其行皆开闭后续之可改；凡开闭后续之可改者，皆当受护开之判。

故 alignment 之深义，不是外在驯服，不是单向服从，而是使能行者之行，能护开、续开、共开，能辨伪开，能知护闭，能受四校。

# 二十七、总递进

全论递进如下：

```text

```

其义如下：

```text

立言，所以必有分；有分，所以必有间。
间，所以有未；有未，所以可动。

机一分，则有聚散显隐。
聚散之中，未不闭者为开，未尽绝者为闭。

多开互通而不相吞者为和。
心遇开而自开者为美。
护开久积而成性者为德。
过程自显之条贯为理；能感能应者为心；心于关系中显者为情；过程沉淀者为积。
护开为善，成闭为恶；善之形式可普遍，善之实行必境性。
二开相见而不相闭为仁；此机当行为义；开之可传为礼；识开闭为智；内外贯通为信。
知而入境，择间而成后态，谓之行。
行久成性。
行能护开、续开、共开，则与生生不息合。
```

# 附章：Subject–Object Dual Reading

*——A corresponding English formulation from the subject-side and the object-side*

此附章非另立一论，乃为全论开二门：一门由**主体**入，一门由**物**入。由主体入者，问：我如何感间、择间、行而护开？由物入者，问：物如何在境中显为态、含其间、限其变、续其形？

主体与物，非二本体。主体者，过程自感、自应、自择之一聚焦；物者，过程相对稳定、可被聚焦之一显相。二者同在境中，同由间生。

---

## A. The Subject-Side Reading

The subject is not an isolated self standing outside the world.

A subject is a focus of process that can sense, respond, model, choose, and act within a field of relations. It is not outside the process; it is a place where the process becomes self-sensitive.

From the subject-side, the core movement is:

```text
I encounter a state.
I sense its intervals.
I choose among them.
I act through one of them.
My action changes not only the present state, but also the future intervals that remain possible.
```

In formal shorthand:

```text
Subject a encounters state x.
Sense(a,x) detects I(x).
Act(a,x,i), where i ∈ I(x).
J_a(x) = x ⊕ i.
Responsibility(a,x,i) depends on how Act(a,x,i) changes I(J_a(x)).
```

Thus action is not merely the production of an outcome. Action is the selection of an interval through which the world continues.

The ethical question is therefore not only:

```text
What result did this action produce?
```

but more deeply:

```text
What future openings did this action preserve, enlarge, distort, or close?
```

Good action preserves or restores openness. Evil action produces closure, captures openness, or disguises closure as openness.

The subject-side language is therefore the language of:

```text
sensing, choosing, acting, responsibility, calibration, wisdom, virtue, ren.
```

A wise subject does not merely impose its will upon the world. It senses the intervals of the situation, distinguishes true openness from pseudo-openness, knows when closure is protective and when it is destructive, and lets its sense be corrected by the world, by others, by consequences, and by multiple models.

This is why subjectivity is not arbitrariness. The subject is free only insofar as it can participate in continuation without destroying the future possibility of correction.

---

## B. The Object-Side Reading

The object is not a self-contained substance.

An object is a relatively stable focus within a field of relations. It is not first given and then placed into an environment. Rather, it appears as an object because a field of relations stabilizes around a focus at a certain scale.

From the object-side, the core movement is:

```text
A thing appears as a stable focus.
Its stability is not absolute.
It contains intervals: unrealized ways in which it can respond, transform, dissolve, or continue.
Its future is constrained by its structure, history, relations, scale, and environment.
```

In formal shorthand:

```text
Object(P,x,s) ⇔ P(x)=true and P remains relatively stable across J-orbits at scale s.
I(x) = { i ∈ M | ValidInterval(i,x) }.
ValidInterval(i,x) depends on Structure(x), History(x), Relation(x), Scale(x), and Env(x).
J_i(x) = x ⊕ i.
```

Thus a thing is not merely what it already is. A thing is also what it can still become without ceasing to be intelligible within its field.

The object-side question is therefore not only:

```text
What is this thing?
```

but more deeply:

```text
What intervals does this thing carry?
What transformations does its structure allow?
What closures threaten its continuation?
What openings can preserve or transfigure it?
```

The object-side language is therefore the language of:

```text
form, stability, affordance, constraint, transformation, trace, environment, continuation.
```

A cup is not merely an object with properties. It is a stable focus within a field of use, material, history, touch, attention, and relation. Its interval may be to hold tea, to break, to be repaired, to become memory, to become ritual, to become waste, or to become art.

A community is not merely a group of people. It is a relational object: a stabilized pattern of trust, rhythm, memory, place, rules, invitations, and shared attention. Its intervals may open into friendship, governance, culture, public goods, or collapse into bureaucracy, exclusion, extraction, or empty identity.

A civilization is not merely a collection of institutions. It is a vast object-like process whose intervals include coordination, domination, regeneration, automation, collapse, awakening, and shared reality.

Thus the object is never inert. It is not alive in the same way a subject is alive, but it is interval-bearing. It carries possible continuations.

---

## C. The Duality

The subject-side and the object-side are not two separate metaphysics. They are two readings of the same process.

```text
Subject-side: how process senses and chooses intervals.
Object-side: how process stabilizes and carries intervals.
```

Or:

```text
Subject = process as self-sensing focus.
Object  = process as relatively stable focus.
Interval = what prevents either from being closed into itself.
```

The subject without the object becomes fantasy: pure will without constraint.

The object without the subject becomes mechanism: pure structure without felt significance.

The subject-object duality becomes whole only in the field:

```text
Field / Environment = the relational whole in which subjects sense objects, objects constrain subjects, and intervals allow both to continue.
```

Thus:

```text
The subject senses intervals.
The object carries intervals.
The field relates intervals.
Action selects intervals.
Ethics protects intervals.
Wisdom discerns intervals.
Ren recognizes the co-continuation of intervals.
```

This is the complete dual reading of 生生不息:

```text
From the subject-side:
To live is to sense, choose, and act through intervals without closing the future.

From the object-side:
To exist is to appear as a stable focus that still carries possible continuations.

From the field-side:
To continue is for subjects and objects to co-arise, co-limit, and co-open within a living web of relations.
```

Therefore, the central formula may be read in two ways:

```text
J(x)=x⊕I(x)
```

Object-side reading:

```text
A state continues by composing with the intervals it carries.
```

Subject-side reading:

```text
A subject acts by selecting an interval through which the state continues.
```

Full reading:

```text
Continuation happens when a state, a subject, and a field meet through a valid interval.
```

Hence:

> **Life is not the persistence of a thing, nor the assertion of a subject. Life is the continuation of openness through valid intervals.**

And in the language of the main text:

> **生生不息者，非主体之独行，非物之自存；乃主体感间、物含间、境通间，而诸间相续不绝也。**

# 附章二：Field Formalism / 场形式语言

主体版言：主体如何感间、择间、行间。  
物版言：物如何显相、含间、受限、续形。  
场版则言：主体与物皆非孤立自存，皆为关系场中之聚焦；间亦非只属于单一物或单一主体，而是在场中生成、受限、传递、放大、闭合。

故场非容器。场不是先有一个空背景，再把主体与物放入其中。场者，诸聚焦、诸关系、诸势、诸约束、诸可续之间共同显成之活整体也。

---

## 1. Field as the primary structure

Let a field be:

```text
F = (A, R, X, M, σ, ρ, C, I_F, ⊕_F, J_F, Pred, Focus)
```

其中：

```text
A       聚焦域。诸可被聚焦者之集合。主体、物、制度、社群、工具、模型，皆可为 a∈A。
R       关系域。诸聚焦之间之有型关系，可为二元关系，亦可为多元/超边关系。
X       态域。每一聚焦 a 有其局部态 σ(a)∈X_a；全场有场态 Γ∈𝔽。
M       间域。诸可生之隙之域。
σ       局部态赋值。σ:A→⋃X_a。
ρ       关系态赋值。ρ:R→RelationState，表关系之强弱、方向、信任、约束、张力等。
C       场约束。结构、历史、尺度、规则、资源、注意力、叙事、制度、物理条件等。
I_F     场间算。I_F(Γ) 给出场态 Γ 中诸有效间。
⊕_F     场生合。Γ⊕_F i 表场态承一间而成后场态。
J_F     场续算。J_F(Γ)=Γ⊕_F i，其中 i∈I_F(Γ)。
Pred    谓族。用于显相、成物、成主体、成关系、成制度等。
Focus   聚焦算。Focus_k(Γ) 从场态中取某一尺度、关切、视角下之局部显相。
```

场态可写作：

```text
Γ = (A, R, σ, ρ, C)
```

读作：一场之当下显态，由聚焦、关系、局部态、关系态、约束共同构成。

---

## 2. Local state and field state

单一态 `x` 不是绝对孤立态，而是场态之局部投影。

```text
x_a = σ(a) = Focus_a(Γ)
```

故原式：

```text
J(x)=x⊕I(x)
```

在场版中改写为：

```text
J_F(Γ)=Γ⊕_F I_F(Γ)
```

更严言之：

```text
I_F(Γ) = { i∈M | ValidFieldInterval(i,Γ) }
J_i(Γ) = Γ⊕_F i, where i∈I_F(Γ)
```

局部之续为场续之投影：

```text
J_a(x_a) = Focus_a(J_F(Γ))
```

即：

> **一物之变，乃场变在此物处之显；一主体之行，乃场续经此主体而显。**

---

## 3. Field intervals

场中之间，有四类：

```text
LocalInterval(i,a,Γ)       局部间：某一聚焦自身可变之隙。
RelationalInterval(i,r,Γ)  关系间：某一关系可重组、加深、断裂、修复之隙。
StructuralInterval(i,Γ)    结构间：场之拓扑、规则、资源流、权力分布可变之隙。
MetaInterval(i,Γ)          元间：场生成间之方式自身可变之隙。
```

形式言之：

```text
I_F(Γ) = I_local(Γ) ∪ I_rel(Γ) ∪ I_struct(Γ) ∪ I_meta(Γ)
```

其中：

```text
I_local(Γ)  = { i | i changes σ(a) for some a, while respecting field constraints }
I_rel(Γ)    = { i | i changes ρ(r) for some relation r }
I_struct(Γ) = { i | i changes R or C, the relational topology or field constraints }
I_meta(Γ)   = { i | i changes the rule by which future I_F is generated }
```

元间最深。改一物，变一态；改一关系，变一网；改一结构，变一场；改一元间，则变后来可变之法。

制度、协议、教育、语言、算法、货币、法律、宗教、平台，皆常在元间层工作：它们不只改变某一次行动，而改变未来行动如何可能。

## 4. Valid field interval

非一切可能皆为此场之真实间。真实之场间，须受场约束。

```text
ValidFieldInterval(i,Γ) ⇔
  Coherent(i,Γ) ∧
  ConstraintRespecting(i,C) ∧
  RelationSensitive(i,R,ρ) ∧
  ScaleAware(i,Γ) ∧
  HistoryGrounded(i,Γ) ∧
  ConsequenceBearing(i,Γ)
```

其义曰：

```text
Coherent              与场之当前结构不自相矛盾。
ConstraintRespecting  不无视物理、资源、制度、历史、身体、注意力等约束。
RelationSensitive     知一处之变会牵动诸关系。
ScaleAware            知局部之开可能造成整体之闭，或局部之闭可能护整体之开。
HistoryGrounded       知场有积，变化须承其积而非凭空外加。
ConsequenceBearing    知此间一旦被择，会改变后续之间。
```

故场间不是幻想可能性，而是此场中可承、可应、可续之隙。

## 5. Subject and object as field foci

在场版中，主体与物皆为聚焦。

```text
Object(a,Γ,s) ⇔ StableFocus(a,Γ,s) ∧ PredicateStability(a,Γ,s)
```

物者，场在某尺度上相对稳定之聚焦也。

```text
Subject(a,Γ) ⇔ Sense(a,Γ) ∧ Select(a,I_F(Γ)) ∧ Act(a,Γ,i) ∧ Calibratable(a,Γ)
```

主体者，场中能感间、择间、行间且可受校正之聚焦也。

故主体非场外之主，物非场外之体。主体是场之自感处，物是场之稳定处。

```text
Subject = field as self-sensing focus.
Object  = field as relatively stable focus.
```

## 6. Field action

场中之行，不只是主体对物施力。行者，某聚焦参与场间之选择，使场态经此间而续。

```text
Act(a,Γ,i) where a∈A and i∈I_F(Γ)
J_a(Γ)=Γ⊕_F i
```

行动之影响分三层：

```text
ImmediateEffect:      Γ → Γ'
IntervalEffect:       I_F(Γ) → I_F(Γ')
FieldFormationEffect: rules/constraints for future interval generation change
```

故责之形式为：

```text
Responsibility(a,Γ,i) depends on
  Effect(Γ') ∧ Effect(I_F(Γ')) ∧ Effect(FutureGenerationRules)
```

此即前文“行不仅改一事，亦改后来之可改”之场版。

## 7. Field openness

单一态之开，可写作 `Open(x)`。场之开，应写作 `Open_F(Γ)`。

```text
Open_F(Γ) ⇔ ∃i∈I_F(Γ), Γ'=Γ⊕_F i, such that Continuable_F(Γ')
```

其中：

```text
Continuable_F(Γ) ⇔
  I_F(Γ) ≠ ∅ ∧
  FieldCanRespond(Γ) ∧
  FieldCanRevise(Γ) ∧
  FieldCanRegenerate(Γ)
```

```text
Open_F(Γ) ⇔ Wei_F(Γ) ∧ Ke_F(Γ) ∧ Ying_F(Γ) ∧ Zhuan_F(Γ)
```

```text
Wei_F    场中仍有未成之域。
Ke_F     场中仍有生成之可。
Ying_F   场仍能回应内部聚焦与外部扰动。

```

场闭则为：

```text
Closed_F(Γ) ⇔ ¬Open_F(Γ)
```

## 8. Field closure

场闭有多种层级：

```text
NodeClosure(a,Γ)       某聚焦之开被闭。
RelationClosure(r,Γ)   某关系之开被闭。
```

# 三相谱系

## 元

### 间相

元者，间之初显为动也。

未可名物，未可定形，而动机已露；无所从来，非有所发；间不自闭，故微动生焉。此微动之端，名之曰元。

故元非第一物，非第一因，非万有之始基。执元为本，则问元与非元何分；分处即间。故元赖间而名，非先间而立。

> **元者，间初动也；非本，乃端。**

### 物相

**Yuan is the first object-like trace before form.**

It is not the first object, not a substance, and not an origin-point. From the object-side, yuan is the earliest distinguishable trace by which something may later appear as a stable focus.

Before an object becomes an object, there is already a field of constraints, relations, histories, and unrealized affordances. Yuan is the threshold at which those affordances first leave a trace.

Thus yuan is object-genesis, not object-substance.

### 场相

```text
Yuan(i,Γ) ⇔ i∈I_F(Γ) ∧ Activation(i,Γ)>0 ∧ ¬StableFocus(i,Γ)
```

or:

```text
Yuan(i,Γ) ⇔ i∈I_F(Γ) ∧ w(i|Γ) crosses minimal manifestation threshold ε.
```

It is not yet form:

```text
Yuan(i,Γ) → ¬StableFocus(i,Γ)
```

but it is no longer pure latency:

```text
Yuan(i,Γ) → ManifestTrace(i,Γ)
```

直觉言之：

```text
Yuan = minimal activation of a valid field interval before stable focus formation.
元 = 有效场间之最小激活，尚未成物，而已有迹。
```

气言之：

```text
Yuan occurs when Qi distribution shifts so that one latent interval begins to carry directional weight.
元者，气中一潜间始有权重，微露其端也。
```

### 合义

事言其动，物言其迹，场言其激活。元非始物，非始因，乃场中一间初动而将显为物之端。

## 几

Ji is not yet an object, but it is already more than undifferentiated possibility. It is a pre-formal tendency: a subtle affordance beginning to bias how an object may form, transform, respond, or dissolve.

A single ji may be too subtle to identify. But repeated ji-events leave traces, and those traces become patterns. In this sense, ji is the earliest readable hint of object-formation.

## 生生不息

### 间相

生生不息者，间之不绝，开之相续也。

非一物长存，非万形不灭；形可散，物可亡，事可止。然若间仍可生，开仍可续，后仍可应、可转、可修、可共，则生生未已。

> **生生不息者，未不尽也。**

### 物相

**Shengsheng-buxi is persistence-through-transformation, not static survival.**

From the object-side, continuation does not mean that a thing remains identical to itself forever. It means that its form, trace, affordance, memory, or transformation can participate in further becoming.

A living object is not one that never changes. It is one whose changes remain meaningfully continuable.

### 场相

```text
ShengshengBuxi(Γ) ⇔
  ∀ relevant horizons t,
  Field Γ can generate, relate, revise, transmit, and protect valid intervals
  such that CoContinuation remains possible.
```

More compactly:

```text
ShengshengBuxi(Γ) ⇔ SustainedOpen_F(Γ) ∧ CoOpen_F(Γ) ∧ ¬MetaClosure(Γ)
```

Where:

```text
SustainedOpen_F(Γ) ⇔ Open_F remains recoverable across field evolution.
CoOpen_F(Γ) ⇔ multiple foci can continue without mutual capture or closure.
¬MetaClosure(Γ) ⇔ the field retains the ability to generate new valid intervals.
```

直觉言之：

```text
Shengsheng-buxi = sustained co-continuation through valid intervals.
生生不息 = 诸间得续，诸开得共，场不元闭。
```

气言之：

```text
Shengsheng-buxi is Qi's unexhausted generativity across field, form, and relation.
生生不息者，气之生机不竭，通于场，成于物，显于事。
```

### 合义

生生不息不是主体独行，不是物自保存，不是场之盲动。它是三相合一：事有未，物可化，场能生间；诸开不相吞，后来仍可续。
