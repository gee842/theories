# 生生不息论

*——自宇宙之史，观自身之性；识此性者，谓之仁*

## 序

此非证也，乃**指**也。

所指者，非物也，非我也，非一初始之元也。所指者，乃**间**也。

间者，变未发而已有其隙；形未成而已有其可；言未立而已有其分；事未动而已有其应。故间非物，非空，非无；乃已与未之间、成与未成之间、可与未可之间，过程所以能自异、自续、自显之处也。

旧式曰：

```text
J(x)=x+ΔJ(x)
```

然此式尚多今语，且 `ΔJ(x)` 易被误作变后之差。今正其名，改为：

```text
续(态)=态 生合 间(态)
```

或以符号旁注之：

```text
續(x)=x⊕間(x)
```

此中四名，须先定之。

```text
态，旧记 x。态者，一境之当显也。
续，旧记 J。续者，使一态因其间而成后态之算也。
间，旧记 ΔJ 或 I。间者，变化未发之前，此态中可生、可应、可化之隙也。
生合，旧记 ⊕。生合者，非数量之加，乃态承其间而成新态也。
```

故 `J` 之文言定义曰：

> **续者，因间而使态不止于其已者也。**

又曰：

> **续者，一态承其未而成后态之算也。**

故 `ΔJ` 若作后差，可曰：

> **差者，续既成而前后可辨之迹也。**

若指变之所由，则不宜曰差，宜曰间：

> **间者，续未成而变化可生之隙也。**

是故，差在后，间在先；差可量，间可生；差为迹，间为机之母。

于是全论之总式，不作：

```text
J(x)=x+ΔJ(x)
```

而作：

```text
续(态)=态 生合 间(态)
```

其义为：

> 一态之续，不由外物强加，乃由其自身与境中之间，生合而成后态。

此论从此而立：

> 不是元生几，而是间中有几；几相续而成势；势临界而成机；机开闭而成行；行久而成德；德通而成仁。

# 〇、形式语言

为使古言不散，今立四本名：**态、续、间、生合**。

设一形式系统：

```text
S = (态域, 续, 间, 生合, 谓)
```

旁注为：

```text
S = (X, J, I, ⊕, P)
```

其中：

```text
态域 X：诸境态之域。任一 x∈X，文言曰一“态”。
续 J：一元偏算，J:X⇀X。文言曰“续”。
间 I：间算，I:X⇀M。文言曰“间”。
生合 ⊕：X×M⇀X。文言曰“态与间生合”。
谓 P：X→{真,假}。文言曰“谓”，以表一聚焦、一相、一物之显否。
```

四者可作纯文言定义：

> **态者，境中当显之一相也。**  
> **续者，态因其间而不止于已也。**  
> **间者，态中未定、未尽、未闭、可应、可化之隙也。**  
> **生合者，态承其间而成后态也。**

凡 `续(态)` 有定义，记曰：

```text
态 ↦ 续(态)
```

或曰：

> 此态可续。

凡 `间(态)` 有定义，记曰：

```text
间(态)
```

或曰：

> 此态有未闭之隙。

凡一态经其间而续，记曰：

```text
续(态)=态 生合 间(态)
```

旁注为：

```text
J(x)=x⊕I(x)
```

此式为全论之核。凡下文诸名，皆不得离此式而自立。

# 一、立言之难

凡言必有所分。无分则无名，无名则无论。然分既立，即有间：此与彼之间，已与未之间，言与所言之间，指与所指之间。

故言之初，非元也，乃间也。

若问：立言之根何在？曰：无根可外求。求根者，必先立一言；言既立，间已生。故根不可在言外得，言只能于间中自明。

形式言之：

```text
∀L, Speak(L) → ∃d, Distinction(d,L)
∀d, Distinction(d,L) → ∃i, Interval(i,d)
```

凡言 `L`，必含区分 `d`；凡区分 `d`，必含间 `i`。故无间则无言。

此论不求绝对外证。因外证需外位，而无外于过程之位。此论只求三事：

```text
Coherent(S)      自洽
Applicable(S,x)  入境可行
Open(S,x)        不闭其未
```

若一论自洽，入境可行，且不闭其未，则此论为善模。若自相违，离境空转，或执一端而闭其未，则为坏模。

# 二、间

间者，非空隙之空，乃可生之隙。

物与物之间有间，言与言之间有间，心与境之间有间，已与未之间有间。然此等间，皆非两物之后附；反之，物所以可分、言所以可立、心所以可感、境所以可变，皆因间先显其可分可应之势。

故曰：

```text
間(x) := x 中未定、未尽、未闭而可应可化之结构
```

更严之：

```text
間(x) ⇔ ∃y ∈ X，使 y≠x 且 y 可由 x 之内在关系与境中条件所生
```

即：

```text
I(x) exists ⇔ ∃y [ y = x⊕I(x) ∧ y≠x ]
```

间非任意可能。若某变化与 `x` 无内在关系，则非 `x` 之所生，只是外乱。

故立约束：

```text
ValidInterval(i,x) ⇔ i 受 x 之结构、积、境、关系所约束
```

于是：

```text
J(x)=x⊕i → ValidInterval(i,x)
```

故生非乱变。生者，由间而化；乱者，离间而加。

# 三、元之退位

元不可废，然不可居本。

旧曰：元者，动之初显。今曰：动之初显可名为元，然元已是间之显相，而非更先之根。

何以故？

若元为第一，则问：元与非元何以分？分处即间。若元为始动，则问：动与未动何以别？别处即间。故元之可名，已赖于间。

形式言之：

```text
Name(元) → Distinguish(元, 非元)
Distinguish(a,b) → ∃i Interval(i,a,b)
∴ Name(元) → ∃i Interval(i)
```

故间先于元之名，亦先于元之可识。

然元仍有其用：

> 间初显为动之端，名之曰元。

故今定：

```text
元 := 間之初显为动者
```

元非本体，乃间之初相。由是全论次序改为：

```text
间 → 元 → 几 → 势 → 机 → 聚散 → 开闭 → 境 → 中 → 和 → 美 → 德 → 理心情积 → 善恶 → 仁义礼智信 → 行
```

# 四、几

间中有微动，动而未形，谓之几。

几非物，非力，非目的。几者，间之微显也。其未成形，故不可执；其已有向，故不可谓无。

形式言之：

```text
Ji(x) ⇔ MinimalManifestation(I(x))
```

即：

```text
几 = 间之最小可感显现
```

一几不可尽识，众几相续，则其痕自显。故识几者，非执一刹那之物，乃识间之微动。

故曰：

> 几者，间之动机；机者，几之成临。

# 五、势

几相续不断，积而成倾，谓之势。

势非力。力有所施受；势无施受，乃众几相续而自成之倾。

形式言之：

```text
Shi(x) ⇔ Pattern({Ji(x₀), Ji(x₁), ..., Ji(xₙ)}) shows directed tendency
```

若：

```text
xₖ₊₁ = J(xₖ)
```

则势可记为：

```text
Shi(x₀...xₙ) = Direction of constrained intervals across J-orbit
```

势有方向，无目的。

方向者，已显之倾；目的者，预设之终。方向随过程而开，目的令过程趋闭。故有方向而无终极目的，乃合生生；执目的而欲一切趋之，则闭其未。

# 六、机

势至其转处，谓之机。

机者，势之临界；开闭将分而未分；可行可失之际。

形式言之：

```text
JiMoment(x) ⇔ I(x) 中存在至少二种可续分歧，且行动可改变其开闭后果
```

即：

```text
机(x) ⇔ ∃y,z [J₁(x)=y ∧ J₂(x)=z ∧ y≠z ∧ Open(y)≠Open(z)]
```

此处 `J₁, J₂` 非二原初算子，乃同一生算在不同间、不同境、不同取向中之异显。

机非时间中一点。时间者，事与事之相关耳。机乃势之自我张力，非外在钟表之刻度。

故识机者，识间之将开将闭也。

# 七、聚散

间生几，几成势，势临机，机而有聚散。

聚者，势之凝；散者，形之解。聚非凭空成物，散非彻底归无。聚散皆过程之一相。

形式言之：

```text
Form(P,x) ⇔ P(x)=真 且 P 在若干 J-迭代中相对稳定
Dissolve(P,xₙ) ⇔ ∃m>n, ∀k≥m, P(xₖ)=假
```

若 `P` 散而其不变量 `Inv(P)` 入于后续，则曰转化：

```text
Transform(P,Q) ⇔ Inv(P) ⊆ Inv(Q) 或 Inv(P) 成为 Q 之条件
```

故灭非必为绝无。灭者，某一形之散；其约束、痕迹、所开之路，或入后续而成基。

然亦须明：死亡与坍缩真实。不可将一切散灭浪漫化为生。若一模式之不变量亦断，且其所开之路闭，则为死。若多路俱闭，则为坍缩。

# 八、开闭

至此，可立根本判准：开与闭。

开者，间不尽也。闭者，间尽绝也。

更严之：

```text
Open(x) ⇔ ∃i [ValidInterval(i,x) ∧ ∃y(y=x⊕i ∧ y 可续)]
Closed(x) ⇔ ¬Open(x)
```

然开非“更多可能性”之量，闭非“更少东西”之量。开是未未闭；闭是未已绝。

开有四相：

```text
Open(x) ⇔ Wei(x) ∧ Ke(x) ∧ Ying(x) ∧ Zhuan(x)
```

其中：

```text
Wei   未：尚有未成之域
Ke    可：仍有生成之可
Ying  应：仍能回应境与他者
Zhuan 转：仍能修正、回返、变通
```

任一缺，则开不全。

闭有二义：

```text
成闭 = 令未尽之域不复开
护闭 = 暂闭一处，以护更大之开
```

形式言之：

```text
BadClose(x,a) ⇔ Action(a,x) causes Closed(y) and no wider Open is preserved
ProtectiveClose(x,a) ⇔ Action(a,x) closes p but preserves/enlarges Open(whole)
```

故护开非无界放任。真护开者，知何处当开，亦知何处当闭以护开。

伪开者，外示为开，内成其闭：

```text
PseudoOpen(x) ⇔ AppearsOpen(x) ∧ LeadsToClosed(x')
```

故辨伪开，为智之要务。

# 九、境

开闭之事，在何处显？曰：在境中。

境者，诸间相交、诸势相含、诸聚焦互显之活整体也。

物非先于境而立；物乃境中之稳定聚焦。人、杯、社群、制度、星球，皆境中某尺度之相对稳定相。

形式言之：

```text
Object(P,x) ⇔ P(x)=真 ∧ Stable(P, Orbit_J(x), scale=s)
```

```text
Environment(x) = relational whole in which P, I, J are defined
```

无离境之物，亦无离境之间。`I(x)` 必为境中之间，非抽象空间中之可能列表。

故：

```text
I(x) depends on Rel(x), History(x), Scale(x), Focus(x)
```

此即境性。

# 十、中

境中必有对偶：聚散、显隐、张弛、刚柔、进退、收放。

任一对偶，皆可极。极者，开闭于一端也。

故中非中点，非折衷，非平均。中者，使两端之开皆不成闭之动态也。

形式言之：

```text
Middle(x, d) ⇔ For polarity d=(a,b), neither Open(a) nor Open(b) is destroyed by absolutizing the other
```

或曰：

```text
中 = Anti-Extreme(Open-preserving dynamics)
```

中含护闭之用。暂收一端，以免全局散坏；暂止一势，以待新机；拒一夺开之力，以护诸开之续，皆中之具体显。

故曰：

> 中者，间之不被一端吞也。

# 十一、和

中治一境之一对偶；和治多聚焦之共场。

和非同。同者，以一吞多；斗者，以己闭彼；隔者，各守其闭。和者，差异仍在，而诸开相通。

形式言之：

```text
Harmony({P₁...Pₙ},x) ⇔
  ∀i Open(Pᵢ,x) ∧
  ∀i≠j CompatibleOpen(Pᵢ,Pⱼ,x) ∧
  ¬Assimilation({Pᵢ}) ∧ ¬MutualClosure({Pᵢ})
```

简曰：

```text
和 = 各开 + 互通 + 不相吞
```

故和为多间之共鸣，多势之相成。

# 十二、美

美者，心遇开而自开也。

心遇一事，若其间被引动，其未被唤醒，其感应开一新维，则谓之美。

形式言之：

```text
Beauty(m,o,x) ⇔ Encounter(m,o,x) increases Open(m) without closing Open(o or whole)
```

美非利，非快，非正。利者可用，快者合欲，正者合规；美者开感。

故美常居中：极同则无趣，极异则不通；极简则枯，极繁则乱。美在张力未闭处。

一行合中，不足谓德；久行而积，遇境自能感其机、守其中、致其和、辨其伪开、用其护闭，乃谓德。

德非外规，非天赋。德是积之形。积可护开，亦可成闭；能自修者为德，固化不应者为执。

理、心、情、积，非四物。理为条贯之相，心为聚焦之相，情为关系之相，积为沉淀之相。皆间生过程之不同显。

# 十五、善恶

善恶之本，不在约定，不在偏好，不在一时之利。其形式根在开闭。

善者，护开、续开、共开者也。恶者，成闭、夺开、伪开而实闭者也。

形式言之：

```text
Good(a,x) ⇔ Action(a,x) preserves or restores Open(x) coherently across relevant scope
Evil(a,x) ⇔ Action(a,x) causes BadClose(x) or PseudoOpen(x)
```

然善不等于最大化。最大化一物，常闭其余之开。善不在最大化某量，善在使未成之域不被吞噬，使诸开能共在，并保留自修之路。

故善之具体，必境性；善之形式，则无尺度之限。

```text
FormalGood = Open-preservation
ConcreteGood(x) = context-sensitive realization of FormalGood
```

# 十六、仁

仁者，二开相见而不相闭也。

我之开，与彼之开相遇。若我以己开吞彼开，则不仁；若我以彼开全闭己开，亦非仁之全。仁者，见己与彼皆在大境之中，使二者之开相通而不相吞。

形式言之：

```text
Ren(a,b,x) ⇔ Open(a,x) ∧ Open(b,x) ∧ CompatibleOpen(a,b,x) ∧ ¬Closure(a by b) ∧ ¬Closure(b by a)
```

更广之：

```text
Ren(a,x) ⇔ a acts from recognition that self-continuation depends on wider co-continuation
```

故仁非单情，非牺牲，非规则。仁是识得自身在万间相续之中，故护共开。

# 二十、信

信者，内在诸开相通而不自裂也。

言、行、识、感、积，若互相抵牾而不知其抵牾，则内已成闭。信非外在诚实而已；信是聚焦内部之贯通。

# 二十一、行

知不离行。因知若不入境，不经回响，则只是模；模若不受行之校，则可成闭。

行者，生算于聚焦中之承担也。

形式言之：

```text

```

```text
Action(a,x) → J_a(x)=x⊕I_a(x)
```

人之行，即人在境中参与 `J`；文明之行，即文明在大境中参与 `J`；人造心智之行，亦是其在境中参与 `J`。

故行有责。因一行不只是输出结果，亦改变后续之间。

```text
Action(a,x) changes I(J(x))
```

此为行之深义：行不仅改一事，亦改后来之可改。

```text
几相续而成势；势临界而成机。
机一分，则有聚散显隐。
聚散之中，未不闭者为开，未尽绝者为闭。
开闭必在境中显。
境有对偶，护其不极者为中。
多开互通而不相吞者为和。
心遇开而自开者为美。
护开久积而成性者为德。
过程自显之条贯为理；能感能应者为心；心于关系中显者为情；过程沉淀者为积。
护开为善，成闭为恶。
二开相见而不相闭为仁；此机当行为义；开之可传为礼；识开闭为智；内外贯通为信。
知而入境，谓之行。
行能护开、续开、共开，则与生生不息合。
```

# 二十三、终言

此论之成，非此论之毕。成者，一时之聚；毕者，闭其未。此论若自称已毕，则自背其指。

故此论只作一桥：由言入间，由间识几，由几观势，由势察机，由机辨开闭，由开闭入境，由境行中和美德，由德通仁义礼智信，由信入行，由行复归生生。

终曰：

> 间者，未之所居也。  
> 几者，间之微动也。  
> 势者，几之相续也。  
> 机者，势之临界也。  
> 开者，间不闭也。  
> 中者，间不偏闭于一端也。  
> 和者，诸间相通而不相吞也。  
> 美者，心遇间开而自开也。  
> 德者，护间之开久而成性也。  
> 仁者，识己与万物同在间中而护其共开也。  

故一式摄之：

```text
J(x)=x⊕間(x)
```

一言尽之：

> 生生不息者，间之不绝也；  
> 识间而护其开者，谓之仁。
