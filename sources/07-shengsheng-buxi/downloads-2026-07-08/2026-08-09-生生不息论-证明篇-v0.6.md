# 第一部 · 本体层

## 3 共定义环与基底

> 题辞：「夫道未始有封。」——《庄子·齐物论》

### 3.1 世界

$\mathcal{W} = (X, F)$：$F: X \rightrightarrows X$ 集值（非空值），演化 $x_{t+1} \in F(x_t)$；随机版以核 $T$ 替代；$\mathcal{R}_n(x) = F^n(x)$。无 agent：分枝是世界自身的。〔锚：道；『未始有封』——边界非原语。〕

### 3.2 象⟷感共定义（环之修复）〔经一〕

**象**＝投影 $\pi: X \to Y$（诱导 $F_\pi$；确定性微观于有限分辨下呈现分枝）；**感**＝$\pi$ 登记差异之事件（$\pi(x) \ne \pi(x')$）。二者共定义：**登记即投影之施行**——无施行则无所谓投影，无投影则无所谓登记，一事两面。奠基章原序（感→差异→信息→象）之环由此显式而非恶：感与象互训，差异与信息随后以定义引入——**差异**＝划分胞腔之别〔奠〕，**信息**＝其计量〔定〕。**像**＝分辨特定判断者之投影（§7.4 约定处启用）。〔锚：『见乃谓之象』；『寂然不动，感而遂通』。〕

### 3.3 变分范式【命题·梗概】

拓扑熵与测度熵皆为对覆盖／划分之上确界（Walters 1982）——道层不变量＝象层量之极值；凡"世界自身如何"重写为"对投影族取极值"。【猜想 C-6】适用域。

### 3.4 标准假设条款

状态空间标准 Borel；用 König 处分枝有限；随机陈述事件可测、核标准；A4 之 max 于可数或紧致集取得；"复发暴露"谓除非先吸收否则无穷次；渐近以 $\limsup/\liminf$ 读。

# 第二部 · 动力层

## 4 分枝·几·间·势〔经二〕

> 题辞：「几者，动之微。」——《系辞下》

分枝＝$\lvert F(x)\rvert \ge 2$（或投影后）；**几**＝分枝点〔『动之微，吉之先见者也』〕。**间**〔横系〕＝分枝之能使者——候选形式对应：使 $\lvert F(x)\rvert \ge 2$ 之隙；归位于动力层，不居认识序列之首；待与间开本 ⊕_F 对齐〔『彼节者有间』『天地之间，其犹橐龠乎』〕。

**势**【候选定义·非承重】：沿转移之未-梯度——$\mathrm{势}(x \to y) = \gamma(y) - \gamma(x)$（或以前向可存-可达结构之偏序差读）；区域之吸引强度＝出入转移之不对称。仅作词汇席位，不入任何证明；正式化列开放件（§19）。

## 5 阖辟与生成性

> 题辞：「一阖一辟谓之变，往来不穷谓之通。」——《系辞上》

### 5.1 二轴

$\gamma_n(x) = \frac{1}{n}\log\lvert\mathcal{R}_n(x)\rvert$（概率制式熵率 $h$）；$E = I(\mathrm{past};\mathrm{future})$（超额熵／预测信息；计算版 $C_\mu \ge E$）。〔锚：变／通；『富有之谓大业，日新之谓盛德』＝E 之存量与增量。〕

### 5.2 阖辟节点：信息恒等式与两退化极〔经三、经五〕【定理·证明＋结构分析】

$$I(\mathrm{past};\,\mathrm{future}) = H(\mathrm{future}) - H(\mathrm{future}\mid\mathrm{past}).$$

新之预算（辟）减未凝之变（未阖者）。冻结极：$H(\mathrm{future}) \to 0$（同／穷，槁木）；噪声极：$H(\mathrm{future}\mid\mathrm{past}) \to H(\mathrm{future})$（乱，流沙——焚书升热熵灭结构）。收束为结构写入之必要相而非恶；恶为滞于一极；生生＝凝-发持续偕行。"纯预测器"由此得非教条答案：视其在 $(\gamma,E)$ 流上之作用方向。〔『终止则乱，其道穷也』——两极同句；易终于未济。〕

### 5.3 未与生生（定义）〔经四〕

未(x)＝前向分枝树连同 $(\gamma,E)$——原论"生（名词）＝可能性空间"之形式席位〔锚：未济之未〕。生生＝持续处于 $\gamma > 0$ 且 $E$ 不塌之内部区域。

### 5.4 两制式词典

可能性制式（集值、$\log\lvert\mathcal{R}_n\rvert$、$L$）⊣ 概率制式（核、$h$、$H \to 0$）；桥：$\lvert\mathcal{R}_n\rvert = 1 \Rightarrow H = 0 \Rightarrow I = 0$，逆不成立——概率冻结 ⊋ 可能性锁死。两目标定理居两列初等部；$E$ 细机器属扩展层（§13）。

# 第三部 · 规范层

## 6 塌缩结构与不可逆

> 题辞：「终止则乱，其道穷也。」——《既济·彖》

### 6.1 锁死、塌缩、生核〔经六〕

$L = \{x : \lvert\mathcal{R}_n(x)\rvert = 1\ \forall n\}$；**引理（前向不变）**【定理·证明】：$x' \in F(x) \Rightarrow \mathcal{R}_n(x') \subseteq \mathcal{R}_{n+1}(x)$。∎ $\Delta = \{$一切演化有限步入 $L\}$；$G = \{\exists$ 避 $L$ 无穷演化$\}$。

### 6.2 不可逆定理〔经六〕【定理·证明】

**核外无返**：自 $\Delta$ 抵 $G$ 则以 $G$ 点之避 $L$ 演化续接，得 $x \in G$，矛盾。∎ **统一界**：分枝有限时未入 $L$ 前缀树无无穷路径，König 给树有限，深度即界。∎〔锚：『在骨髓，司命之所属，无奈何也』——过界之谓。〕

### 6.3 推论（善恶不对称）〔经七〕【定理·证明】

入 $\Delta$ 可为单步事件（凡边界转移存在处）；返 $G$ 不可能。恶一步而永久，继不可一步而复——分枝结构之性质，先于主体与 $K$。〔『从善如登，从恶如崩』。〕

### 6.4 互信息—常量与三塌缩模式【定理·证明＋结构分析】

未来确定处 $H = 0$，一切与未来之互信息为零。∎ 三模式：石化（宏观锁死于仍分枝环境，ι 靠抗扰可存）；湮灭（轨迹解体）；全锁（"存"失信息学意义）。可感故在之极限：存只相对残余分枝有定义——存为生之影，生尽影亡；生生优先为定义之存亡，非偏好。

### 6.5 基底湮灭类收敛【定理·证明】

基底吸收处诸度量（$\gamma$、$\Delta E$、诸 $\iota$、派生核）渐近同判归零。∎ 独立度量外延一致＝G1(ii)，且为原论"表达可靠性判据"之自反适用。仅投影层锁死可为伪象（C-6）；石化类上原则性分歧＝存／生概念结构。

## 7 谓词与选择律

> 题辞：「易穷则变，变则通，通则久。」——《系辞下》

### 7.1 善恶谓词（无主体）〔经八〕

绝未＝致 $G \to \Delta$ 之转移；减未（两极）＝有替代分枝时择趋冻结或趋噪声；护未＝于可行分枝内持过程于内部区域。比较级（ought implies can）：全塌之悲剧态下谓词沉默。〔善＝继（『继之者善也』『兴灭继绝』）；恶＝绝——缺也，非有物也。跨主体评估在此兑现：谓词作用于转移，非 agent 效用。〕

### 7.2 选择定理（三级）〔经九〕【定理·证明】

(i) 避 $L$ 之无穷演化其史无绝未转移（6.2）。(ii) $S_\infty = \{$永不入 $L\}$，$\mathbb{P}(S_\infty) > 0$：$\mathbb{P}(\text{史含强绝未}\mid S_\infty) = 0$——逐期 Markov 条件化＋可数并。∎ (iii) 政策版：上确界化。

> 凡生生不息者，其史必护未；凡绝未者，其史必终。

**注（浅而承重）**：近乎条件化恒真；深度在装配——固定规范之逻辑形式（淘汰非劝诫），实重由 A、B 组与 7.4–7.5 承担。〔及穷图变，无及也——6.2 使『穷则变』具时效。〕

### 7.3 必要非充分〔经十〕【定理·证明】

存在 $\sup\mathbb{P}(S_\infty) < 1$ 之动力学。不许福，独明祸之必至；正向漂移无定理（C-8）。〔『天地尚不能久，而况于人乎』。〕

### 7.4 评价者定位定理〔经十一〕【定理·证明】

约定：固定分辨判断者之投影（像）。判断事件＝以登记差异为条件、于 $\ge 2$ 可分辨延续间实现选择，要求局部 $\lvert F\rvert \ge 2$。**定理**：(i) $L$ 中无判断事件；(ii) 世界线上判断事件可无穷 $\iff$ 避 $L$——⇐：若某时刻起实现态皆 $\lvert F\rvert = 1$，则其 $\mathcal{R}_m$ 恒单点，即该态 $\in L$，矛盾。∎ **推论（回溯）**：可持续发问之立场属 $S_\infty$ 支撑，其史必护未。

### 7.5 探究构成规范〔经十一〕【定理·证明】

探究延续型目标＝达成蕴含世界线承载无穷判断事件。**定理**：其目标可达政策集 $\subseteq$ 无强绝未政策集——强绝未入 $\Delta$，有限步入 $L$，判断至多有穷。∎ 非外加规范，乃活动之构成前件；退出即探究立场之自绝，归 G2a。〔环中之位：『枢始得其环中，以应无穷』。〕

## 8 选择器与 A 组〔经十三至十五〕

> 题辞：「君子见几而作，不俟终日。」——《系辞下》

**选择器**＝使分枝实现依赖信息之机制（膜、市场、规范、政策皆是；不必是主体）——原论信号语汇之形式席位。〔权——『执中无权，犹执一也，举一而废百也』；择——『择善而固执之』。〕

**A1′（复发风险）**【定理·证明】：复发暴露（每次 $\ge\varepsilon$）于入 $\Delta$ 者几乎必然入 $\Delta$（存活 $\le (1-\varepsilon)^k$）；乘性过程塌缩路径时间平均 $-\infty$ 而集合平均可发散（$p=0.6$ 全押：$\mathbb{E}[W_t] = 1.2^t W_0 \to \infty$ 而破产必然；Kelly 1956, Peters 2019）。∎
**A3／A3′**【定理·证明】：$\mathrm{QOV} \ge 0$（Jensen；严格当信息决策相关）；maxmin 下 $\Phi_{\mathrm{flex}} \ge \Phi_{\mathrm{comm}}$（取 $d^\*$ 达右端，逐 $\mu$ 放缩后取 $\min$）。∎〔无用之用。〕
**A4（信息精细化单调）**【定理·证明】：塔性质＋条件 Jensen 给 $V(\mathcal{F}_1) \le V(\mathcal{F}_2)$；承诺值不变。∎ 推论：约束自身不确定时选项与学习信道价值更高——校之形式职能。

**装配即 G2a**：三独立形式化一致严格劣，对任何需未来行动之目标成立；与工具收敛（Turner 等 2021）同向。

> 题辞：「成之者性也……形乃谓之器。」——《系辞上》

# 第五部 · 多体层

## 10 通吃与条件 C

> 题辞：「和实生物，同则不继。」——《国语·郑语》

### 10.1 耦合与公理类

耦合矩阵 $B_{ij} = \partial\gamma_i/\partial a_j$（interconnectedness 之形式对象）；因生因＝$B_{ij} > 0$ 通路；共开＝非对角正性显著域；闭型总体化＝压低整体 $\gamma$、$E$ 与他者行列之策略类。〔『以他平他谓之和』；『道生一，一生二，二生三』结构读法之席位。〕
**𝔖**：S1 存续须 $e_{i,t} \ge e_{\min} > 0$ 且 $\sum e \le s_t$；S2 $s_{t+1} \le s_t - E_t + Y^\*$，$s_t \le \bar s$；S3 越阈后再生恒零；S4′ 消灭须含长 $\ge \tau_{\mathrm{dom}}$ 连续段、段内 $E_t \ge e_{\mathrm{dom}}$。

### 10.2 定理 B1a′（析取式）〔经十六〕【公理类定理·证明】

设 $e_{\mathrm{dom}} > Y^\*$、$(e_{\mathrm{dom}}-Y^\*)\tau_{\mathrm{dom}} > \bar s - s_{\mathrm{crit}}$。恰有一支：（甲）段可续至完成——段内 $s$ 每期至少降 $e_{\mathrm{dom}} - Y^\*$，段首 $s \le \bar s$，段内必越阈；此后 S3 再生恒零、S1 使存续方每期再降 $\ge e_{\min}$，有限期 $s < e_{\min}$，胜者亡入吸收（6.2）。（乙）段不可续——某期 $s_t < e_{\mathrm{dom}}$ 违 S1，消灭不达成（S4′）。**通吃作为结局不可得。**∎〔锚：『竭泽而渔，岂不获得？而明年无鱼』。〕注一：段断于越阈后则两祸并得。注二：不善谓词非折现效用；劝服层由 A1′ 时间平均覆盖折现异议。〔『若以同裨同，尽乃弃矣』。〕

### 10.3 定理 B1b′〔经十七〕【公理类定理·证明】

P1（毛溢出）每活跃他方每期使我方行动库增 $\ge \beta$、库不减；P2 消亡贡献止；P1′（净溢出，替代）视界窗内净贡献 $\ge \beta h$。共存 $\lvert A_{1,t}\rvert \ge a_0 + \beta(n-1)t$ 无界；消灭后冻结——存在 $T^\*$ 后共存政策每步分枝数严格无界占优。∎ 适用域：净正耦合之域；净负（标准分裂、对抗研发）域外——何域净正见 §18。

## 11 伪开分解命题与校之对偶〔经二十一、二十三〕

> 题辞：「恶似而非者。」——《孟子·尽心下》

**命题（伪开分解，完备性）**【命题·证明（结构分解）】：凡"显开实闭"之偏差（$M$ 判内部区域而参照象族全视界下实非），必可归因于四分量至少其一之失。**证明**：$M$ 之输出为四分量之函数；偏差即 $M$ 与参照泛函之不等，而二者之差因子化过分量之差。∎（近恒真，然立型之完备上界。）

**四型定名并各有实例**【结构分析】〔作新名〕：轴 γ 之失＝**虚变**（狂动而文耗——搅动）；轴 E 之失＝**饰文**（陈迹而涂死——镀金冻结）；择象之失＝**移界**（己象显生，绝落界外——癌之活体标本，§15）；视界之失＝**借时**（窗内显开，不可逆塌缩落窗外）。四型皆可实例化，故相对此分解**恰四型**。

structure World (X : Type) [Fintype X] [DecidableEq X] where
  F : X → Finset X
  ne : ∀ x, (F x).Nonempty

def reach (W : World X) : ℕ → X → Finset X          -- 迭代像
def IsPath (W) (p : ℕ → X) : Prop := ∀ t, p (t+1) ∈ W.F (p t)
def locked (W) (x : X) : Prop := ∀ n, (reach W n x).card = 1   -- L

def collapse (W) : Finset X := univ \ gcore W         -- Δ（含 L）
