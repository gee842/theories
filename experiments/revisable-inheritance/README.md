# Revisable inheritance

An exact finite-team experiment joins paid archive inspection, diagnostic readiness, communication, and successor action. Its central comparison concerns summaries sufficient under a constant-rate model but insufficient after temporal-change models are admitted. The [research synthesis](../../sources/15-codex-theory-conversations/2026-10-05-inherited-evidence-under-model-revision.md) explains the findings and their limits.

Two histories with the same final state and total switch count imply next-need probabilities .44835 and .05165 under the ordered-regime family. Timed counts preserve this distinction; total count does not. In the integrated decision, successors condition on readiness and silence as well as payloads. A no-payload control can still transmit evidence through paid readiness.

## Reproduce

From this directory with Python, numpy, and matplotlib:

```sh
python -m unittest -v test_model.py
python analyze.py
```

The runtime used was `/private/tmp/meta-attractor-plot-env/bin/python`. Results are exact finite-model expectations evaluated numerically; no random seeds or sampled trials are used. The examples are exploratory. Rerunning the analysis replaces current outputs.
