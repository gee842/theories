# Exploratory systems analysis protocol

5 October 2026. This study analyzes the existing four-state institutional model and a declared five-state controller extension. It is exploratory mathematical work, not preregistered empirical research. The initial controller examples were located before this protocol was saved; the following checks audit and display them.

## Fixed-rule system

- Inventory the equilibria, including mixed states and the depleted equilibrium family. Check residuals and eigenvalues independently of the algebraic derivation.
- Map a two-dimensional initial-state slice in payer participation x and genuine-maintenance share h, holding C=G=3 and all parameters fixed. This is a basin slice, not a complete four-dimensional phase portrait or a parameter phase diagram.
- Classify only when a numerical trajectory enters an analytically proved recovery or loss region. Keep long unresolved trajectories visibly unresolved. Repeat with half the integration step and independently check selected trajectories with an adaptive solver.
- Plot the two invasion exponents at the full-participation equilibrium while varying the fixed maintenance-contract parameter m. A loss of local stability is not a proof of global failure.

## Explicit rule adaptation

Add a manager who changes m according to m_dot=epsilon*m*(1−m)*(G_target−G). This manager reacts to a verification-capacity target. It is a deliberately limited local controller; it does not represent the requested full plurality of changing goals or selection among governance constitutions.

Compare the same initial state under different response speeds. Independently check the desired equilibrium's eigenvalues. If a fast response fails while that equilibrium stays locally stable, describe global basin dependence or overshoot, not a Hopf bifurcation or an established universal tipping mechanism.

For target 4, verify numerical entry into the proved loss region x<1, h≤.1, C≤108/29, G≤1, m≥.9. Compare a lower feasible target as a negative control against the claim that faster response always destroys the system. Record the two inspection-related constraints on m separately; do not add them into a hidden welfare score.

## Interpretation

The operating states are bounded. Reinforcing feedback can accelerate institutional loss or recovery, but unbounded runaway is not possible in these equations. Separate role populations do not constitute a full theory of multilevel selection. The proposed broader architecture must distinguish actions, resource and network conditions, institutions, cognitive frames and changing evaluative relations, and identify which mechanisms have actually been specified and tested.
