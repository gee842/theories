This is the ReadMe.txt file for the replication archive that accompanies:

"Identifying Legitimacy: Experimental Evidence on Compliance with Authority"
Eric S. Dickson, Sanford C. Gordon, and Gregory A. Huber
Science Advances

In addition to this file, there are 4 other files in the archive:

Experiment_1.dta and Experiment_2.dta are Stata 11 datasets with the data for, respectively, experiments 1 and 2.

Experiment_1_Analysis.do and Experiment_2_Analysis.do are the Stata syntax (.do) files that analyze their respective datasets.

Note that to run the Stata syntax files you need to create an empty output directory called "output"

The output that will be produced in the directory is:

	Experiment_1_results.log 
	Experiment_2_results.log
	Figure 2.pdf
	Figure 3.pdf
	Figure 4.pdf
	Figure 5.pdf
	Figure 6.pdf
	Table 3.tex
	Table 3.txt
	Table 5.tex
	Table 5.txt

The contents of Table 1 are in Experiment_1_results.log and the contents of Table 4 are in Experiment_2_results.log
