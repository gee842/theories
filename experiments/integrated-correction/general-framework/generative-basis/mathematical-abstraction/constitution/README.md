## Reproduce

The only Lean import is `Std`. An installed Lean **4.29.1** toolchain and Python 3 are required. From the repository root:

```sh
python3 experiments/integrated-correction/general-framework/generative-basis/mathematical-abstraction/constitution/check.py
```

The checker creates a fresh temporary object directory, compiles both source modules with the pinned toolchain, and compiles [KernelAudit.lean](verification/KernelAudit.lean) against those fresh objects. It rejects proof holes, custom axioms, `native_decide`, compiler diagnostics and unexpected axiom dependencies. No dependency installation or cached project object is needed.

The saved [verification receipt](verification.json) reports **43 named theorems and 84 explicitly named source-level declarations audited**, and records source and verification hashes. Observed dependencies are Lean's `propext`, `Classical.choice` and `Quot.sound`; per-declaration dependencies appear in the receipt and [audit log](verification/KernelAudit.log). These counts exclude automatically generated projection and recursor names; the full source modules are kernel checked. The [WitnessHull log](verification/WitnessHull.log) includes its source-local theorem audits; the [EqualityGenerativity log](verification/EqualityGenerativity.log) is empty because its clean compilation emits no text. Its declarations are covered by the common audit driver.
