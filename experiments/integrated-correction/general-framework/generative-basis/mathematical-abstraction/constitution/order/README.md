# Dense order witness generation

[DenseOrder.lean](formal/DenseOrder.lean) gives a checked extension of the neighboring pure-equality study to the language of equality and strict order. For dense linear orders without endpoints, finite equality/order patterns determine every formula. Before, after and between operations suffice to generate existential candidates; explicit rational arithmetic implements a recursive Boolean evaluator. Its sentence answers are proved correct for every supplied order in the class. The least domain generated by these selected operations is also an elementary substructure.

The [correspondence record](../../../../../../../_process/research/2026-10-05-generative-foundation-review/history/root-foundation/ROOT-MATHEMATICAL-COVERAGE-ORDER.md) specifies all assumptions and limits. Density, linearity, absence of endpoints, syntax and semantics are supplied. This package proves neither universal mathematical coverage nor exclusive metaphysical grounding. Arithmetic appears in the witness implementation, not in the interpreted pure-order language.

## Check

```sh
python3 experiments/integrated-correction/general-framework/generative-basis/mathematical-abstraction/constitution/order/check.py
```

Only `Std` is imported. The checker builds a fresh temporary object and compiles a saved [audit driver](verification/KernelAudit.lean). The [receipt](verification.json) records **33 named theorems, 58 explicitly named declarations audited**, source hashes and all dependencies. The only observed axioms are `propext`, `Classical.choice` and `Quot.sound`. Every named source theorem, definition, structure, inductive and instance is audited; automatically generated members are checked with the complete module but not separately counted.

The source includes kernel-reduced evaluations of the density sentence and the false existence of least/greatest elements. No custom axioms, proof holes or `native_decide` are used. The earlier neighboring package remains independently checked and unchanged.
