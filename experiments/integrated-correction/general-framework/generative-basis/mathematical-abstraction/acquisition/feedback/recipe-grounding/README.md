# Grounding the operative reader recipe

This additive study constructs a two-row decoder from actual bound reference
contacts, then uses those retained connections in the existing calibration
continuation. Identity and inverted transduction both work; missing or constant
signals prevent completion, while coherent reference faults can cause false
confidence. Correctly formed readers can reach diagnosis yet lack support for
continued retention.
