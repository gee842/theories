## Resource and information boundaries

The meter models abstract symbol cells and declared operation envelopes. It does not measure Python allocations, instruction count, wall time, joules or chemical work. Eight fixed controller cells, separately encoded histories/suffixes/cache entries, candidate tables, table scratch and command buffers count toward capacity. Dynamic diagnostic logs belong to the external auditor and cannot influence learner decisions. The supplied operation recipe implements these logical cells; it is not derived from the older two-slot mechanism.

Each paid event takes one tick plus its symbolic work count. Tariffs charge work, growing persistent storage, all live-cell retention, and physical-interface operations. Temporary workspaces remain rented across intervening target queries. Denial leaves the committed archive unchanged and earlier costs spent. The [protocol correction record](PROTOCOL.md#instrumentation-corrections-during-review) preserves repaired omissions in the first instrumentation draft.

The `certified` field is a historical paid-test result under declared assumptions. `retained` additionally requires paid compaction and one final retention epoch. Neither validates those assumptions; `status=complete` means the scheduled operations completed, not that the hidden real contact was correctly interpreted. Each result separately reports analyst equivalence and actual productive use. An inverted sensor demonstrates the distinction.

The target's phase/readiness law is stationary and resets exactly in the primary case. The whole resource system is not stationary: tests consume fuel, a use consumes source, and no reset undoes either. All-word semantic prediction refers to the phase projection, not unlimited affordable execution or indefinitely available packets.
