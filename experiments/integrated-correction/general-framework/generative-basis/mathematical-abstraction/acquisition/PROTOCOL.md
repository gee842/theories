## Declared resource law

Use exact rational units of the inherited abstract fuel. Each reset, primitive target action and endpoint read costs 1/4. Work costs 1/64 per declared symbolic work unit. Each additional persistent cell costs 1/64 to write; all live cells cost 1/65536 per declared clock tick for retention. Each event takes one tick plus its work count, including reset/action/read events. Installation costs 6. A final retention epoch additionally costs 1/64 per retained cell. A retained final model and one later use each require their specified paid operations. Work envelopes cover word construction, cache lookup, row extraction/comparison, table scanning, candidate construction, simulation and validation; they are stipulated abstract machine tariffs, not Python instruction counts or measured joules. The implementation documents each envelope and capacity estimate, including bounded temporary workspace. Audit logs are external readouts unavailable to the learner.

All charges are prepaid and sunk, and every prefix must be affordable. A denied operation leaves the committed archive unchanged; earlier payments remain spent. Capacity failure also stops acquisition. There are no acquisition rewards or refunds. A later productive extraction, if affordable and correctly timed, consumes one existing packet and transfers its ten units only after the work. It cannot finance earlier observations retrospectively. Source and fuel are reported separately.
