# Follow-up numerical sensitivity

Added after the planned analysis. Four unconstrained fitted-level curves (S3, S5, E5, E6) approached q=1 with large cancelling coefficients and negative far-future levels. The finite predictions are computable, but the level parameter is not substantively identified. Preserve that initial run and report it.

The paper's public Extended Data 6 specifies a nonnegative asymptote. Add a clearly post hoc sensitivity using the same split, all participants, and c >= 0 in y(n)=c+a*q^n. The amplitude remains free, allowing initial recovery or decline. For each q the bounded optimum is the unconstrained linear fit when its c is nonnegative, otherwise the c=0 boundary fit. This is an implemented numerical procedure, not a new proof claim. No model is chosen on held-out performance and no participant is removed. This sensitivity concerns forecast stability and does not reproduce the published COIN model or its full-data BIC comparison.
