# Surface-material history: reproducible inspection

Source: [Ferguson et al. 2013](../../../../../../sources/evolutionary-selection/ferguson-2013/README.md). Research interpretation: [mat-history integration](../../../../../../_process/research/2026-10-05-generative-foundation-review/root-foundation/MAT-HISTORY-INTEGRATION.md).

Run `python3 inspect_movies.py` with Pillow, ffmpeg and ffprobe available. The source package already contains the originals; no network or scientific fitting is involved. [inspect_movies.py](inspect_movies.py) checks original lengths and hashes, probes every encoded video frame, selects frames by ordinal and produces five contact sheets. A separate complete-video RGB `framemd5` decode checks every selected frame's pixels without reusing the selection filter. Both paths use FFmpeg; this is an extraction check, not independent biological validation.

[verification.json](verification.json) records **4,795 decoded frames, 44 unique selected frames**, five sheet hashes, exact rational playback timestamps, the code hash and tool versions. These numbers are media-processing quantities, not experimental sample sizes. Source movies remain unchanged. Full views are resized from 640 × 480 to 480 × 360; the S1 detail uses the recorded crop at original pixel scale. Brightness, color and contrast are unmodified. Figure labels give **encoded playback seconds**, never biological hours.

Run `python3 check_record.py` for a lightweight check of saved source/media bindings, local links, unchanged completion requirements and the paired C14 row. [check_record.py](check_record.py) writes [the scoped integration checks](../../../../../../_process/research/2026-10-05-generative-foundation-review/root-foundation/MAT-HISTORY-CHECKS.json). This does not repeat decoding or validate biological interpretations. Outstanding reviews of concurrently changed sources remain outside this package's certification.

## Visually inspected records

- [S1 overview](figures/s1-overview.png) and [S1 detail](figures/s1-detail.png): material extends downward from the interface, changing shape while bottom material accumulates. In the dense selected sequence 972–1104, the right-side hanging material recedes/displaces downward. The source reports repeated raft formation and descent; the selected frames do not independently count every event or track a marked cohort.
- [S4 pH growth](figures/s4-overview.png): the labeled pH treatments develop different spatial appearances. The final pH 6.5 vial retains a relatively clear upper broth and bottom deposit, while higher-pH vials show more diffuse broth cloudiness. Some turbidity differences are already visible at encoded frame zero. Thus that frame is not assumed to be a common clear inoculation baseline. Pixel brightness is not calibrated biomass or growth rate.
- [S5 postgrowth flocculation](figures/s5-overview.png): low-pH vials develop clearer upper broth and accumulated material below; the highest-pH vials remain visibly more turbid. This is a separate postgrowth assay, not the same vials followed from S4 into descendants.
- [S6 structural contrast](figures/s6-overview.png): surface-associated material develops in both vials with different appearances. The visible genotype labels disagree with the legend's exact attribution. That discrepancy is preserved in the source manifest; no allele-specific effect size is estimated. Sparse oblique images do not yield a complete surface-coverage measure or tensile strength.

Inspection is AI-authored and qualitative. No event count, hazard, cell count, calibrated area, elapsed acquisition time, independent biological replicate or viable descendant is inferred. Reformation is the primary paper's temporal result; our selected images corroborate the material-history interpretation without constituting an exhaustive reanalysis of raw acquisition photographs.
