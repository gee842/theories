The checked cross-multiplied identity avoids division at a zero denominator. Equal per-template common access (`x=k*a, y=k*h`) is neutral at this scope. Formation, death, losses, state-dependent future events and long-run selection are not included in this one-step statement. Conditioning on the declared event classes is not an unconditional trend for the full native process.

General weights still require an explicitly corresponding native event allocation; this is not a full stochastic refinement.

A four-cell transmission table distinguishes template and descendant response types. Rows count template opportunities; columns count descendant structures. Faithful copying makes these equal. The weaker condition of equal cross-transfers also suffices; fidelity is not necessary for a response to increase. In the checked all-positive table `(AA,AH,HA,HH)=(1,5,2,2)`, A has six of ten template opportunities but only three of ten new response structures. From counts `1,1`, its next expected fraction falls from `1/2` to `13/30`. This transmission table is a declared extension of the accounting interface: mutation is **not** installed in the original native chemistry.
