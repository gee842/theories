# Retained-controller corroboration

6 October 2026. This executable supporting study shows that the saved controller contains information sufficient to expose the existing archive-tag fault, under an explicit proposed read interface. It does not implement that read or establish general calibration. See the [protocol](PROTOCOL.md), [model](model.py), [derived inputs](inputs.json), and [exact results](results.json).

The new projection recovers the actual retained `q` and positive qualification flag `last` from the frozen original archive. Their hashes bind each recovery to its original state, history and parent publication. The original archive-tag intervention changes the asserted command while preserving this acquired controller memory. Requiring a controller to be currently active would wrongly erase half of the retained positive evidence; installed, recoded, qualified memory can remain even after its execution reserve is exhausted.

These are exact conditional masses under the declared finite law and preparation. Countermodels are labeled separately in every result. They are not empirical frequencies, deployment success rates, or new independently sampled recipients. All 666 frozen rows in 54 complete arms are retained. Sixteen inspection scenarios produce 10,656 comparisons with an ordinary table/equality implementation; that comparison matches exactly. The independent [checker](check_model.py) and [verification receipt](model-verification.json) audit reconstruction and the updater separately. [Formal proofs](formal/README.md) establish the abstract implication under its causal premises, not Python-to-Lean refinement.

The common-fault countermodel supplies a fresh current publication after upstream corruption, rather than silently altering a token under its original content-derived identity. It assumes that publication's trusted registration; it does not replay the whole registry pipeline. The self-import failure instead uses an actual admitted corrupt-source fixture.

The direct-controller comparator matters: once a qualified candidate exists, reasoning does not improve its binary command accuracy in these fixtures. Reason replay contributes an explicit scoped recommendation under the supplied objective, not a new uniquely available action bit. Other cases retain qualified controller memory while the current reason is absent; its direct candidate is still not an authorized, funded or physically routed act.

`corroborated`, `disagreement`, and `unknown` concern this consistency comparison. A positive qualification flag is meaningful only through its acquisition history and retained causal meaning. The code does not infer those semantics from the flag alone. In particular, writing a reason into `q` and setting `last=1` destroys the independence required for this check. A material join needs a check before that write, or a separately preserved memory and a paid read route. All model outputs keep stocks unchanged and report no implemented read, execution, or established calibration.

The [updater snapshot](evidence/identification-model.py) is an exact preserved dependency, with [provenance](evidence/manifest.json), matching the earlier transport manifest's SHA-256. It is a source record for checking, not a working copy to edit. Existing snapshots remain untouched. To reproduce the abstract mechanism, run `python3 model.py` from this directory. The independent checker and formal compilation have their own scopes and entry points.
