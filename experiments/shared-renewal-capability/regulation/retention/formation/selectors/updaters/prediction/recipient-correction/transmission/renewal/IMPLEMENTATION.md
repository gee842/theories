# Repeated actual-successor composition

6 October 2026. AI-authored implementation specification. The repeated wrapper and its self-checks are implemented; acceptance depends on the separately recorded independent checks. This directory composes the distinct [successor-learning protocol](../../successor-learning/PROTOCOL.md); it does not replace that study or independently reimplement its paid probe law.

## Interface that must be preserved

The input is an actual retained child of the parent transmission result, including its route, acquired packed record, learner cash, recipient reserve, and action-enabled flag. The original actor stays a separate account. A merely copied but unretained tuple is not an admitted learner. The complete parent witness or parent distribution entry remains attached as ancestry.

One generation executes the single-block protocol unchanged: n warm-up probes, one changed-target probe, one further paid probe, then the parent's generic copying/action/hold process. Each probe uses its current retained template; the next generation uses the actual resulting grandchild template and cash. A target schedule is an external plant input, never an initializer for the learner's record. No agent, route or record is selected using a diagnostic correctness flag.

The wrapper supplies one finite source and component inventory for the complete requested horizon. Assigning an already declared packet or blank to a block changes its location in this inventory; it does not replenish the total. Old unused or inaccessible sources remain separately accounted. Every old carrier and every actual new copy receives an explicit lineage identity, with parent identity, copied route and copied record. Incomplete assembly and unretained copies remain visible. Terminal failure stops generational progression and leaves future inventory unspent.

`run_lineage` accepts an actual transmission state and a list of single-block case dictionaries. It returns exact weighted branches with complete block inputs, outputs, probe traces, counts, descendant handoffs, a global energy account and all new component stocks. `compose_entries` retains every original preparation/transmission branch and its original probability. `summarize` reports unconditional counts; its route contributions retain their one-quarter proposal mass and are not normalized as conditional route probabilities.

The added packet allocation rule requires all n+3 packets for the next block to remain in the finite bank before that block starts. Insufficient stock stops before any operation of that block. This is an explicit supplied scheduling rule, not a derivation from the underlying event dynamics. Once a block starts, the imported single-block law governs every individual expenditure, missed opportunity and inaccessible copying source. A missing bundle instead passes zero parts to that ordinary law, preserving its paid partial failure.

The module pins the actually loaded single-block and parent source bytes and rejects later changes. Each run additionally compares complete dependency snapshots at entry and exit. Self-run `results.json` supplies hashes and full long-chain witnesses; its status explicitly distinguishes self-checks from independent acceptance.

## Expected analytic boundary under the primary supplied law

An admitted TARGET learner with zero learner cash, recipient reserve B and an inherited recipient response that is correct at entry obtains +3 from each successful warm-up. The two reversal probes together change recipient reserve by -4. Generic retransmission, including the grandchild's own productive action and finite hold, changes it by -1. Therefore an entirely completed generation changes reserve by 3n-5. Its exact ordered-payment condition is `(n = 0 or B >= 6) and B + 3n >= 15`: when n is positive, the first warm-up must be funded before its return arrives. This statement presupposes the required parts, live installed machinery, correct addressing, actual availability, faithful writes and an unchanged productive target during grandchild action. Mere retention of a child whose inherited response is incorrect does not meet these entry premises; nonzero learner cash requires the full account calculation instead.

For n=2 the actual inherited B=10 child can complete a generation and leave B=11. For n=1 that same child can acquire and use a corrected record but cannot complete the generic retransmission sequence. The global recurrence is conditional on completion of every stage; a positive terminal resource expression is not sufficient if an earlier payment fails.

## Explicit comparison scope

Independent review must compare every stage with a conventional finite-state evaluator, retaining ordinary routes, acquisition-disabled or record-clamped diagnostic laws, target reversals, source outages, missing evidence, missing parts and incorrect copies. Alternative route or record substitutions are interventions with declared provenance; they are not unchanged-law formation frequencies. Preserving a child is distinct from productive use: sufficient reserve can retain a wrong child.

An arbitrary finite successful chain is not a claim of an infinitely provisioned physical process, generation of new routing recipes, correction of the update algorithm itself, or justified ethical concern. Material renewal, calibration, reserve transfer rights, the available repertoire and conflict between donor and recipient remain supplied or unresolved interfaces.
