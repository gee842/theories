## Exposure order and accessible learning

At each opportunity:

1. Assemble absent/expired hardware in the order above. A missing affordable stage blocks trial; unused source opportunity is lost.
2. If the predictive circuit is active, prepay memory retention `h=1`. Failure to pay destroys its accessible record and blocks trial.
3. The normal action is1 ifq>2,0 ifq<2, and last ifq=2. The response work and observation together costd=3 before any return. The forecast of capture is q/4 foraction1 and1−q/4 foraction0, recorded before the outcome. It is a declared forecast decoder, not automatically a calibrated probability.
4. An available packet is captured precisely when action equals hidden plant orientationz. In the primary law availability is1. Capture transfersG and pays circuit/updater maintenance r+v=2, restoring both lifetimes. Failure gives no return and reduces both lifetimes byone at the end of the trial. Every source opportunity consumes one packet whether captured, failed or inactive.
5. The actual trial receipt gives a labelY=action oncapture andY=1−action onfailure. Only action and receipt enter this decoder. A write costsw=1 after the physical return/maintenance; an unaffordable write leavesq unchanged. Fast writesq=4Y; Slow increasesq byone toward4 whenY1, decreases byone toward0 whenY0, clipped atbounds. Write precedes end-of-trial wear. The last field becomes the actual action. The transient receipt is not a free persistent record.

Capture and expenditure remain real even when a record or command is experimentally altered. The controller cannot readz, the initial hidden condition, future availability, reversal dates or analyst success measures. At dependency change all accessible state and resources persist; no change-triggered reset occurs. Hiddenz is initially fair and changes after exposure6. In outage cases a compatible action sometimes fails: the same declared decoder then produces erroneous labels rather than receiving corrected hidden-state information.

## Comparisons fixed before outcomes

- `variable`: fair Slow/Fast gates on each paid formation.
- `conventional`: separately expressed finite-state conventional realization with the same law, complete observations, costs and register.
- `fixed_fast` and `fixed_slow`: type-fixed hardware still pays all formation, retention, operation, write and renewal costs.

## Readouts and acceptance

Report all-history preparation entrance, trials/captures, writes, memory rents, gate/circuit formations, updater changes, postchange captures, aggregate pre-outcome Brier loss and its scored-trial coverage, retained fuel, total cost/waste and strict correction probability. Brier loss is `(forecast−actualcapture)^2`. Its ratio to expected trials is explicitly a trial-weighted diagnostic; stopping/failed preparation cannot count as accurate predictions. It is never an updater reward. Also count decoder errors against the analyst's hiddenz to identify outage misspecification, without giving that variable to the mechanism.

The strict witness is instance-specific: a circuit has made an acquired nonneutral forecast and captured before the first boundary; its retained old action is then used unsuccessfully after the boundary; paid writing changes its subsequent command; a later paid trial executes that changed command and captures. The paid write must changeq and flip the issued command with `last` fixed to the just-executed action on both sides; changing `last` alone cannot count. Circuit destruction resets the witness-in-progress; gate replacement does not. A completed witness remains a historical outcome. Memory reset followed by new learning does not count as correcting that same retained prediction. Initial priorq2 is not acquired evidence.

Verify a same-physical-state register clamp that changes a command, a paid complete preparation-to-correction witness, an exact resource identity including failed preparations, and the ambiguity of a no-return record under source outage. Independent implementation must match all64case-arms using exact rational arithmetic. Formal verification and probability/implementation checks have separate scopes. Controlled-refinement cannot automatically collapse several paid phases into an uncharged step; a generic macro-step interface is concurrent complementary work.

Positive outcome would close this finite conditional prediction-to-action bridge, not explain the recipe's origin, long-run calibrated learning, another center's standing or shared evaluation. Superior conventional or direct-record results and adverse-regime failures remain part of the account.
