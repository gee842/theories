The event interface supplies an exclusive interval. The consume/install pair separates two facts. Origin is consumed before the attempted parent import even if no import can be afforded. A pending command in that interval represents the already captured local approval in the executable call; it is not a reusable outward permission. The faithful import retires it. The formal `retired` phase after successful import compresses the executable's consumed phase with a historical `approved_import` marker; neither authorizes another inspection. Early bypass and naive post-import controls are not certified imports.
