# Frozen implementation details before first execution

6 October 2026. This prospective clarification instantiates the fixed protocol; no new numerical outputs have been computed.

The case dictionary is `cases.json`. All context/publication/destination interruptions and any instrumented controller write retire acquisition-origin permission permanently, clear both latches/approval, and reject a later attempted read without charging a nonexistent read. The controller-write interruption changes only the recipient command component through the actual register-write interface, setting its flag to1; it is an exogenous instrumented intervention, not paid new acquisition. Each interruption arm includes an explicit rejected retry. Common corruption instead uses the actual consistently-corrupt source history and an uninstrumented pre-read recipient-bit flip, breaking acquired-register integrity; it does not change a registered publication's bytes.

A damaged candidate read spends1 and returns no bit, ending the inspection with unknown. A damaged flag read follows a successful candidate read, spends its own1 and ends unknown; total spent2. An authentic unqualified flag0 is a readable value and reaches the paid comparison (total3), whose judgment is unknown. A missing module incurs no inspection charge. An unaffordable next step retains prior charges/latches and cannot advance. Every read attempt still passes one-shot phase/origin checks.

A completed comparison is terminal for reading. Corroboration can issue one import permit; disagreement/unknown retire the module. Immediately before any actual import attempt, including an intentionally early import, origin permission and the permit are consumed. A successful monitored import remains marked as having used a prior valid permit; that historical marker cannot authorize another inspection. Reuse probes after import, trial or replay do not call import again. The early-import arm executes the real parent import, then attempts inspection; the certified route has no approval. The naive post-import ablation deliberately bypasses origin for its paid comparison, records `independent=false`, and may execute the already-imported ordinary reason route. This is not an accepted origin test.

The source-command read precedes inspection. Unsupported reads stop this route with their actual actor charge; no inspection reserve is spent merely to fabricate an absent-source comparison. Later reconstruction uses its original isolated24 whenever present, even if this action route failed, and never resets the inspector. Ordinary learned-register and unaudited controls use the parent's existing schedules without command/inspection assemblies; all formation charges, unused components, saved assembly units and the unspent inspection reserve remain accounted.

Runtime may inspect the paid latches, fixed structural presence/phase guards and current publication/scope metadata. The physical recipient law appears only in the work event and observer output. No free post-import register verification is added. New-evidence recovery remains outside scope.
