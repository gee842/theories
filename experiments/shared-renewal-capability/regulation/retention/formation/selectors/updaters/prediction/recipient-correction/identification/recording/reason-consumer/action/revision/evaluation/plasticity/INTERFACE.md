6 October 2026. Prospective serialization contract; no outcome is claimed. The operational law is [DRAFT-PROTOCOL.md](DRAFT-PROTOCOL.md), with the literal menu in [cases.json](cases.json).

Results expose `parent_catalog`, `preparations`, and `cases[name].variants[name].producers[name].paths`. The catalog retains every actual selected revision predecessor, exact probability, original path/prefix indices, complete immutable parent state, state digest and observer provenance. Catalog entries are archival references, never additional spendable actors. Each path contains `predecessor_ref`, unchanged `probability`, `runtime_trace` of event plus full live state, its final `state`, separate observer data, and all advertised metrics. Aggregation includes each inherited distribution's entire unit mass.

The single live parent is reconstructed by deep-copying the catalog state and replacing its core, four physical fields (`core_phase`, `core_target`, `core_action`, `acquired_record`) and three inherited binding fields (`scope`, `permission`, `delivery`). Every other parent field remains identical. The checker may retain a complete embedded parent instead; correspondence must be lossless.

The extension state contains `native` (n, completed count, finite phase, two latched cells), `links` (two empty or occupied sockets with immutable part identity and signed conductance), `retired` links, `inventory` (backed cells/adapter, primary blanks, replacement blank, access and omitted parts), `reserves` (protected primary/revision fuel and inaccessible idle/saved accounts), six `own` and six `recipient` source packets, and the finite one-use `port`. Each latch is a single Boolean value plus adapter-provided mode: empty, actual return, acquired shortfall or missing. Acquisition overwrites the return bit in place; any historical echo belongs only to the trace. No extra runtime copy of the four latent words is stored.

The finite port retains its read command and phase/assessment authorization under the supplied recipe. Signed transmission is combinational: actual/raw transmitted input is computed from the current graph and n, then recorded only as observer diagnostics. No subsequent controller event reads a retained numeric copy. A filtered port computes raw graph input but transmits zero. Exogenous shortfall schedules and the inherited hidden work law appear only in observer metadata and as inputs to physical return/work events; they are not inputs to reading, binding, native writing or assessment.

Account fields distinguish immutable inherited spend/retained coordinates, extra construction, all new actor and recipient bills, waste, and current accessible/inaccessible stocks. Audit-only outcomes record completed acquisition, attempted/completed action, receipt and failure status; runtime guards must use actual physical state rather than these flags. An account offset summarizes the independently accepted inherited prefix; it is not claimed to recover a missing microscopic expenditure distribution.

Preparation traces retain every constituent formation, component assembly, adapter and pre-prefix isolation event, with the exact old-word projection and all protected stocks. The precursor has resource505 and material68. Any control that withholds access preserves its material and energy in idle accounts.

The independent oracle is authored from the protocol and accepted ancestor laws without importing new producer transitions. Its separately preserved pre-execution source may use a different state representation and event spelling. Any adapter must compare complete physical state, phase/latches, graph identity, paid events, parent provenance, account balances and all metrics. It must not repair a mismatched transition, erase an inconvenient field or compute the expected state with the producer. Representation differences must be declared before comparison acceptance.

The accepted evaluation module may be reused by the producer only for archived result loading and predecessor extraction; its revision ancestor supplies unchanged command decoding, parent accessors and formation reactions. These shared accepted dependencies are frozen and disclosed. The new paired, link, assessment and execution suffix is separately implemented and independently reconstructed. No numerical result is a full simulator-to-Lean refinement theorem.
