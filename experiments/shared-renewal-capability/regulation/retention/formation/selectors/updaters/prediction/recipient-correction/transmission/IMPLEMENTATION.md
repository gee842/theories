## Route formation and correspondence

Represent the evidence route as retained physical state, using four declared configurations: actual target input, disconnected recipient input, private-zero input and frozen writing. All use the predecessor's indexed record interpretation. The installed configuration, current payload and paid target report determine behavior. No experiment-arm string, retrospective witness, decoder-error count or hidden target law enters that policy.

Use the actual saved predecessor distribution, retaining failures. Common setup costs two actor units, followed by a two-unit route/recoding stage. A successful second stage consumes one auxiliary blank carrier and one routing part and installs the selected route before the four original recipient/actor exposures. These are declared new component stocks, not the two occupied actor slots and not an identified realization of the parallel A/H material law. Missing second-stage components retain the first paid setup charge.

With sufficient parts, each formed configuration must project exactly to its corresponding original indexed, private-only, private-proxy or frozen arm: same state fields, receipts, memory changes, failed payments, metrics and probability masses. The independent implementation must not call the parent suffix as its transition law; the parent is the comparison reference. Test all existing fixtures and upstream producers. Conventional indexed equivalence remains inherited from the original study; no new novelty or superiority claim follows.

The assembled route is chosen by an explicit uniform finite proposal law, independent of hidden efficacy and downstream outcome. Conditional per-route projections and the actual mixture have distinct meanings. Positive probability of formation under a supplied proposal law does not yet explain the origin or natural prevalence of the assembly recipes.

## One same-target successor

Use the primary four-exposure endpoint, with no old action packets remaining. Preserve its actor fuel, recipient stock, packed estimate and formed route. Add a separately declared finite receiver inventory and one ten-unit source packet from the beginning of the extended experiment. This extra inventory/source is included in the combined account; it is never a refill of the exhausted parent supply.

The following sequence is the declared local law. Each step needs its actual predecessor stock, and a failed step retains all earlier charges. The recipient floor is one unit.

| Step | Payer and charge | Physical effect |
|---|---|---|
| Donor retention | Actor, one | A finite donor-read window, matched across the four active-route comparisons; no recipient-funded renewal of original actor hardware. |
| Recipient continuation | Recipient, one above its floor | A declared local use operation. This supplies an operational demand, not an ethical valuation. |
| Template acquisition | Recipient, one above floor | Consume a receiver blank as a paid latch holding the actual module configuration and payload. |
| Receiver assembly | Recipient, one above floor | Consume a routing part; a missing part leaves the occupied latch and prior charges sunk. |
| Commit receiver record | Recipient, one above floor | Commit the acquired fields on that same carrier; no extra provenance record appears. |
| Seed transfer | Recipient, five above floor | Move five existing units to the child account. This is a transfer, not energy creation. |
| Child retention | Child, one | Holds the copied carrier for this operation. |
| Target access | Child, one | Supplies the same named recipient query under the declared calibrated addressing law. No new carrier-self correspondence is inferred. |
| Work | Child, three before any return | Consume the separately declared source packet. A matching action transfers its ten units to the recipient; a nonmatching action loses it. The original actor receives nothing. |
| Local child retention | Recipient, one above floor if available | Retain the new carrier for the declared finite interval. Without that payment it is not retained. |

On the faithful indexed witness, actor nine pays one and remains eight. Recipient ten pays its own use, acquisition, assembly, writing and seed transfer, leaving its floor one. The child spends all five seed units, and a correct action returns ten to the recipient. One further local retention payment leaves recipient ten and a retained child. All numbers must be checked against actual event accounts.

The proxy's matching endpoint also has recipient ten. It must obtain the same initial copy and seed access. Its wrong retained estimate makes the new action fail in the primary context, leaving only the floor and no child-retention payment. This is a difference generated after copying, not a copier's judgment of provenance.

## Limits and adverse comparisons

The child action is read-only. It demonstrates expression of the transmitted estimate and addressing; it does not exercise the copied evidence channel's later acquisition/update function. Retaining the route field and proving its update equations does not by itself establish an operational learning cycle in this child.

A frozen route given the correct record should match the faithful route in this stable one-action continuation. A changed target can reverse the advantage. A copied action gate or missing route must block expression even when a correct payload is present. Missing components, unaffordable donor retention, recipient use that consumes the reserve, and a seed bill that cannot be prepaid must block the corresponding continuation. Include donor refusal/cheaper omission as an alternative to the matched retention bill; the construction does not prove that an actor chooses to participate.

Template substitution or public support for an unrelated template must remain possible comparison laws; recipient production alone does not establish the required association with its producing route. Such interventions must explicitly say which physical state or rule changed. They cannot be presented as unchanged-law histories.

Record formed, copied, successfully acting and retained-carrier counts separately. Actual finite proposal and retention transitions can yield different one-cycle count distributions. Those are narrower than selection for truthful channels as a class, an expected fixation claim, sustained population growth or renewal through indefinitely many generations. The original actor and recipient continue to have separate accounts and significance; aggregate copy count is not their welfare.

## Verification boundaries

The executable construction must freeze the parent source/fixture hashes, compare independently implemented route behavior with the original references and record actual variant mixtures and sequential successor failures. Its material and energy invariants include receiver stock, seed transfers, wasted source and occupied incomplete carriers.

The separate Lean interface imports the existing packed-record functions and verifies its explicitly declared formation/copy/payment law. It does not claim to prove the full Python stochastic producer. Conversely numerical agreement with the parent does not derive the new recipes or chemically identify the blank carrier and routing part. Report these scopes separately.
