# Paid recipient evidence and context-preserving correction

6 October 2026. AI-authored protocol, written before this study's numerical run.
This is a supporting interface for the active coupling-to-concern development:
**another center's actual outcome → paid correction of its action correspondence**.
It does not replace the parallel concern study or derive concern's valuation.

## Continuing predecessor and new local law

Import the actual coupling preparation and eight operational exposures, with
**twelve** packets of ten declared in the original source, reversal after four,
and original common fuel30. The four remaining packets are exposed in order
recipient, actor, recipient, actor. Preparation failures, ineligible circuits,
resource failures, and their original probabilities stay in all totals. The
source is not replenished at this interface. The prefix uses exactly the parent
eight-exposure law; only the original preparation stock has twelve packets.

Admission requires an active updater, active circuit, active normal coupler,
and actually written confident q (0 or4). This explicitly isolates target
correspondence after a usable action coupling has formed. No wrong coupler is
silently repaired. Nonadmitted histories retain their stocks and lose the four
inaccessible opportunities. This narrower domain must accompany every result.

A new common target/sensor interface costs2. A further paid recoding costs2:
the context-indexed arm reuses the existing five-valued register q to hold
`actorBit + 2*recipientBit`, one of four states. Both bits initially copy the
actual inherited acquired bit. No recipient truth is supplied at assembly.
The other matched arms pay2 for an unchanged-format adapter; a cheaper shared
arm omits this redundant payment. These are supplied alternative physical
recipes. Four values fit the old abstract capacity; energy payment and a state
count do not derive the circuitry, calibrated target identity, or chemistry.
The two inherited material slots persist; no new unaccounted bit slot is added.

Installation is sequential: the common setup payment is retained even if the
recoding cannot be paid. Only complete installation activates this suffix.
The interface supplies a **four-exposure stabilized read/write protocol**:
each retention payment holds the inherited circuit, updater and switch usable
through that exposure. Parent wear/renewal/reformation events are suspended;
this is an explicit new event law, not a kinetic refinement. No recipient
receipt renews actor hardware. An unpaid rent irreversibly ends access; there
is no memory resurrection later. No unlimited lifetime is inferred.

## Action, evidence and separate resource accounts

Each phase pays sequentially, with no refunds and no borrowing:

1. actor retention1;
2. target identification/sensing1;
3. work3, then the real capture or noncapture;
4. outcome acquisition1;
5. register write1.

The action function sees only the installed register and the **paid reported
target**, never hidden productive orientation or a free phase counter. The
schedule chooses which physical target is exposed, not what the controller
knows. In the primary law, target identity is calibrated. A target-alias case
reports actor for both; a swapped-identity case mislabels both. All matched
arms have the same access and costs, even if they ignore target identity.

Only the plant reads the hidden target law. Primary recipient orientation is
opposite the actor orientation inherited after the prefix. A successful actor
trial transfers10 from that phase's source packet into actor fuel. A successful
recipient trial transfers10 into the recipient's separate reserve; actor
receipt is zero in both recipient outcomes. A missed or unused packet is lost.
There is no repayment, sanction, patient-derived reward or utility oracle.

When acquisition is affordable and its channel is present, it exposes the
actual target receipt. Under the noiseless complementary binary plant, action
and receipt determine that target's productive orientation. A paid write
records this decoded bit. The indexed arm writes only the paid target's cell;
the shared arm overwrites its sole orientation estimate. Missing evidence is
not a zero receipt: its write attempt pays the same bill but leaves q unchanged.
An unaffordable write also leaves q unchanged. Last action is retained as an
inherited physical field but is not a second target register in these policies.
Observed outcomes and diagnostics do not become free persistent policy state.

## Arms, fixtures and falsifying results

Arms: shared direct record; indexed record; exact conventional indexed table;
private-only channel (recipient outcome unavailable, matched acquisition/write
bills); mistaken private-receipt teaching (uses actor zero as if it described
the recipient); frozen record with paid sham writes; and cheap shared record.
The private-only, mistaken-private and frozen ablations retain the indexed
representation to isolate their evidence/use failures. The first six pay identical installation prices. Strong conventional indexed
control must match exactly, not merely on average.

Fixtures: opposite target laws; same laws; recipient capture availability3/4;
missing recipient outcome channel; target alias; swapped target labels;
original common reserve12; and write price4. Run the variable and conventional
coupling producers and fixed-normal producer, retaining all original masses.
Outages make nonreceipt an ambiguous label and must expose decoding error;
the noiseless guarantee must not be applied to that fixture.

Report exact final distributions, actor and recipient capture, trials,
acquisitions/writes, missing evidence, decoder errors, actor interference,
paid expenses, wasted source, final separate reserves and a strict witness.
That witness requires a first failed recipient action, its paid evidence and
changed stored command, a productive second recipient action with a different
command, and both intervening/later actor actions remaining productive. The strict
witness additionally requires the first acquired receipt to come from the
actual target channel; an accidentally correct private-zero proxy is reported
only by the weaker behavioral correction. It is
computed from the actual trace and never controls execution. Also report a
weaker recipient-only correction so renewed help is not hidden by the stronger
noninterference criterion.

No identity/receipt access is free. No controller is selected by the summary
metrics. This is a finite policy comparison and one-history causal witness,
not an origin theorem for the supplied context-indexed recipe or moral standing.
If shared records suffice under opposite laws without extra accessible state,
or indexed writes damage the untouched cell, the proposed bridge is wrong.

## Verification and integration gate

Store the actual predecessor distribution with its inherited states and ledgers.
Freeze and hash every imported source for a run; reject a source change during
execution. A separately written suffix evaluator must reproduce each local
distribution and full aggregate metrics, including failures and skipped stages.
Check energy per stage and over the original preparation plus twelve packets.
Check a concrete reachable witness and shortages around its cost boundary.

Lean should prove the finite causal/record interface, including the general
injectivity requirement: zero-new-probe exact commands for two independent
binary target laws require four distinguishable complete controller states.
This does **not** say the inherited five-state q is too small. The constructive
packed representation explicitly fits it. Formal evidence, finite stochastic
checks and actual prefix composition retain separate scopes. The stationary
confidence guarantee and consumable slots of the recording-fidelity study are
not imported into this recyclable register.

## Internal review correction after the first exploratory run

The initial executable gave the evidence ablations shared-format records,
confounding channel access with interference. Its exact source, protocol and
results are preserved in [development/shared-ablation-draft/](development/shared-ablation-draft/).
The current ablations use the indexed representation and the same paid recoding
as the indexed controller. This is a review-driven correction, not a claim that
the first exploratory output was independent confirmation. Receipt provenance
is now explicit in the strict causal witness: a private-zero proxy can happen
to produce the right first correction after a failed recipient action, while
mislearning again after successful help. The weaker behavioral witness keeps
that observational ambiguity visible. A consistent bijective swap of target
labels is a relabeling, so the swap fixture is expected to preserve outcomes;
aliasing merges distinct contexts and can fail.
