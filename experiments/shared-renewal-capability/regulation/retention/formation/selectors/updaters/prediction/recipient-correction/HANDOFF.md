For admitted indexed histories, the paid recoding stores `q = actorBit + 2*recipientBit` in the inherited register. This is the final two-bit payload, not a retained sequence of outcome records. The existing `last` field contains the last issued action. No additional persistent per-cell provenance, sample count, confidence certificate, identity history or write-validity tag has been constructed. Both cells were initialized from the old actor bit; a cell value alone does not certify that that target was ever observed.

During each completed phase, the controller bought the target report before action and the actual target receipt before writing. An acquired action/receipt pair identifies the target law only under the noiseless complementary binary plant. Source outages break that inference. Calibrating or reconstructing the identity channel is still an input obligation.

The trace's `receipt_source`, hidden target laws and witness flags are retrospective audit data. They never enter the policy. A downstream mechanism cannot read this saved trace as if a paid runtime tape were present. A new phase must pay to acquire any observation not already in its retained accessible state. Physical recipient reserve is also not automatically a controller observation.
