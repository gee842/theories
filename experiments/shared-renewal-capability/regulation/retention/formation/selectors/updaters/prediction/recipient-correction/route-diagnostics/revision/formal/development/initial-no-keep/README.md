# Reconstructed initial no-keep checkpoint

This is the reviewed 41-theorem source checkpoint before the explicit no-swap continuation was added. It is reconstructed by reversing the recorded source patch, not recovered from a versioned snapshot. [provenance.json](provenance.json) records the reconstruction hashes, independently recorded original checker/protocol/clarification hashes, the corrected monitor-dependency receipt hash and the unavailable original revision artifacts.

The original fresh check passed 41 new audits across seven modules, and the independent reviewer verified its then-current source and log hashes. The checker later overwrote that receipt and those logs. Their original bytes, original revision receipt hash and per-module source hash map were not retained. A previously attributed receipt hash was corrected to the monitor formal dependency; it does not identify the original revision receipt. Therefore this directory does not claim to contain the original verification receipt or to establish reconstructed source identity by comparison with that unavailable map. It has not been rerun solely to produce a replacement receipt.

The preserved limitation is concrete: `learn` required phase `changed`, reachable only by a swap. A paid read that did not request replacement remained in `inspected`; its unchanged-route numerical continuation was outside that wrapper. The narrower swapped witnesses were sound. The [current model](../../RouteRevision.lean) adds an explicit guarded zero-fee `keep` event preserving the physical state, and the [current succession proofs](../../RevisionSuccession.lean) cover its actual continuation plus the grant13/14 boundary.

`check.py` and `lean-toolchain` retain their old bytes and relative-path assumptions; the archived checker is not directly runnable from this nested location. `README.original.md` is the reversed original prose and retains links interpreted from its former formal-directory location. Use this note and the current formal README for navigation.
