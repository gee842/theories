## 3. Fixed addresses and runtime phases

There are three fixed frame addresses, one for each recipient query in the
five-query schedule. Each owns four physical bit cells. Its target and trial
identity are bound by a supplied finite address plan **before outcomes**.
The reader/workspace recipe backs a bounded query pointer, tag latch and
three-entry `Option Bool` cache. The pointer advances at each actual paid
recipient sense, even when no archive frame is admitted. It is not an observer
phase counter. The primary desired-orientation vector `(0,1,0)` is also fixed
before outcomes. The old law ends core access permanently on an unpayable
query, so its later absent queries cannot shift another actual sense backward.
Archive absence at address zero cannot shift another query into that address.
The core controller does not gain access to the archive, observer flags or
hidden target law.

A complete frame is `(context, action, present, receipt)`:

- Context and actual issued action are bound after the core's paid recipient
  observation, before core reserve/work/receipt. The binding/service charge
  covers the supplied finite context-report and tag-latching operation. Its
  context is not a later analyst label, hidden target law or reversal schedule.
  The primary runtime context is constant false.
  The positive protocol holds context stable during the admitted query.
- `present` states whether the original paid acquisition delivered a receipt.
- If present, `receipt` is exactly that acquired receipt. If absent, the
  receipt cell is canonically zero; it is not evidence of a negative outcome.

The parent identification query still pays its full eight-unit working bill,
including its own acquisition and q/qualification writes. If that query can
execute, the sidecar decides record admission **before work and outcome**.
It requires the address's four blank cells and five archive units. It spends
one for binding/service, reserves the four cells and escrows four archive
write units. The work and actual actor/recipient/source transfer then occur
exactly once under the original law. Only the original paid acquisition can
provide the archive latch. Hidden capture truth and saved observer output
cannot fill a missing acquired receipt.

Four paid bit writes consume the reserved escrow and make that frame complete.
The supplied finite completion schedule runs those writes before the next
query in the primary experiment. A partial write remains represented by its
pending bound tag, actual latched frame, written cells and remaining escrow;
neither interruption nor loss of access creates an erased/refunded retry.
Incomplete frames decode unknown. A context change during binding/latching
violates the positive stability condition and must not relabel the frame into
the new context; its interrupted state is retained and cannot be used as a
current completed frame.

If the sidecar cannot admit, its fixed address stays empty. The original core
query may still execute unchanged. Its acquired internal update is not an
archive entry. This is essential: insufficient archive funds or cells are not
passed to the old core as a fake query failure. Sufficient archive15 and all
twelve cells support all three completed recipient frames; they do not
guarantee that all three core queries can afford or complete their own work.

## 4. What the reader may conclude

For a prebound query about orientation `Z=d`, the partial decoder returns

`Some(action == d)`

only from a complete frame whose binding and current context match and whose
`present` and `receipt` bits are both one. Otherwise it returns unknown.
A positive receipt for the opposite action can therefore give `Some False`;
a zero receipt cannot. This follows from the original no-false-positive
capture law and stable target/context correspondence, not from persistence or
payment. Missing channels, missing frames, stale bindings, zero receipts and
partial writes remain distinguishable runtime conditions even when the reader
returns unknown for each.

This is not the old reader's raw-Bool `decodeAt` or an automatic discharge of
its `Assayed` premise. Any later reason transfer additionally needs an explicit
interpretation of `Z=d`, its relevant edge and the positive root. Historical
receipt truth and current response orientation must not be interchanged.
The consumer owner must accept this partial interface rather than treating a
zero as a calibrated false factual premise.

activation1 clears the bounded cache; paid current-context observation1
obtains its token; each of three four-cell reads costs4. The reader uses only

The cache carries the paid sensed-context tag. Current-use soundness requires
