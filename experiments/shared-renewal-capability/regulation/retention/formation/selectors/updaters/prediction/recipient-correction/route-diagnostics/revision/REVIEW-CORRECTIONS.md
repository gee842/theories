# Corrections during implementation review

The first producer run passed its local invariants over 74 cases and 180 mixtures. Its source files, data contract, freeze receipt and verification record are preserved in `development/first-run/`; they are historical evidence, not current acceptance records. No empirical observations are added by these corrections.

1. Independent reconstruction matched every payment, resource, material, phase and outcome but initially retained four prior operational register values at the next rent. The contract had called the remaining original fields historical without distinguishing current trial registers from retained monitor cells. The current DATA-CONTRACT explicitly gives those four registers' lifecycle; all are again included in independent comparison. The producer's operations and substantive outcomes are unchanged by this documentation correction.
2. Review found that the prespecified “before probe3 and/or child action” comparison lacked the joint reversal case. Add `joint_reversal`, applying both declared reversals, with every original cohort and failure retained. This extends the executed prespecified comparison, without replacing the original adverse cases.
3. The first Lean revision law admitted learning only after a swap. This omitted the intended paid no-swap continuation after an unresolved/target verdict. Add an explicit no-cost finite control transition from a paid, unarmed, still-bound inspection to ordinary continuation. It preserves the old route, record and stocks. The numerical policy already followed this branch. Preserve the initial formal source and review receipt; the corrected law needs a fresh frozen build.
4. `route_changes` originally counted different recipe names but the data contract called it functional change. CLOSED and FROZEN have equal recipient-update behavior despite different wiring. Retain the original configuration metric and add separate recipient-update-class change and behaviorally changed productive-successor metrics. The primary TARGET conversions satisfy both. No physical transition or old outcome metric changes; the correction prevents promoting recipe distinction to a behavioral result in other regimes.

The rejected pre-execution retention4 design, already recorded in the protocol, remains distinct from these later implementation-review corrections. Scientific acceptance depends on the final source-bound checks, not the fact that an earlier snapshot was saved.
