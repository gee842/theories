# Paid consequence-to-learning interface

6 October 2026. AI-authored specification written before the executable results.
This supports the [unified derivation](../../../../../../theories/becoming/chapters/GENERATIVE-GROUNDING.md)
while the parallel selector-revision study develops its own mechanism. It does
not replace that study or claim to derive the learner's architecture.

## Question and declared scope

When can an actual consequence supply the teaching input assumed by the
[concern learner](../../../../../../_process/research/2026-10-05-concern-theory/learning-formal.md)?
We separate physical target, accessible record, paid memory update and subsequent
action. A target for predicting a material consequence is not thereby felt
valence, a policy objective, another center's standing, or shared evaluation.

## Deterministic gate interface

A damaged capture gate starts with no acquired record or learned coefficient.
An unobserved source contains either zero or one packet. The declared task is
delivery of that packet through an intact gate. Before any capture, restoring
the gate changes task feasibility by exactly the source bit. That operational
contrast is the target; it is not a separately supplied reward.

There are four events. Probing costs one common-fuel unit and records the source
bit; writing the acquired record to the coefficient costs one unit; first repair
costs one unit; capture converts a source packet to one common-fuel unit after
repair. A persistent receipt marker records whether capture occurred. The probe
reads source plus receipt, so a later probe identifies the original task's
source bit too. This persistence, sensor, copying rule and actuator interface
are explicit architectural inputs. The receipt marker is not an additional
fuel unit. Every event preserves the actual successor state.

Primary decision order: probe, write, first repair, capture. A supplied controller reads the acquired observation, writes the coefficient,
and issues a repair command only when the coefficient is positive. Clamping
the coefficient to zero must change that command with the plant held fixed. Initial common fuel three suffices in
the source-present world; two cannot fund this order. All reachable event
histories at each tested reserve are checked, not only the successful history.
The source-absent world can be identified but cannot deliver a nonexistent
packet. Both worlds have the same initial accessible state.

Prespecified counterpaths: at reserve two, probe, repair, capture, write can
deliver and learn retrospectively; repair, capture, probe, write can do so too.
A controller acting directly on the probe record need not pay the separate
coefficient-write price before repair. Thus the three-unit bound is specific to
the stated memory-mediated order, not a universal cost of intelligent action.
After capture, the original target remains historically identifiable but the
current gate-restoration contrast is zero: a target cannot silently be reused
after its enabling source is consumed.

## Stochastic paid prediction interface

A supplied read/write circuit starts at coefficient zero. Each operational
round prepays two units: one for operation and one for observation/update. With
probability one half it receives two usable units from an explicitly counted
source store; otherwise it receives none. Source stock starts at twice the
declared three-round horizon. No receipt can precede payment.

The observed target is the round's actual net common-fuel loss divided by two:
zero for a full receipt and one for no receipt. The transition law, rather than
an injected target constant, gives conditional mean one half whenever a round
can be prepaid. The coefficient updates with gain one quarter. No memory decay
is assumed in the primary comparison. If payment is impossible, no observation
or update occurs; an inert stored coefficient remains an observer readout, not
a functioning learner. All histories, including these stopped histories, remain
in the distribution.

Compare initial common reserves six and two over three opportunities. Six funds
all three updates even in the all-loss history. Two stops after the first loss.
Before running, the predicted means are respectively 37/128 and 7/32. In the
scarce case the probability of retaining enough common fuel to prepay another round is 1/8,
and those reserve-positive histories all have coefficient zero. Their incident
source has been exhausted, so this is not a guarantee that another round can
obey the same receipt law. This distinguishes an unconditional
retained-memory statistic from a functioning-survivor statistic.

Additional exact checks cover loss probabilities 0, 1/4, 1/2, 3/4, 1; gains 1/4,
1/2, 1; horizons zero through six; and reserves zero, one, two and twice the
horizon. An optional physical decay law checks the general recurrence, without
claiming that real memory has this particular implementation. Stochastic
assumptions, calibration, source conditions and the update rule remain supplied.

## Acceptance and revision criteria

A downstream threshold check was added during interface review, before the
independent execution: in the funded fixture the mean coefficient exceeds 1/4,
but only half the histories have a coefficient strictly above 1/4. Thus a mean
recurrence cannot substitute for the concern theorem's pathwise strict choice.
Held-out prediction errors are analyst diagnostics, never runtime rewards;
their calculation does not assert that another paid physical trial occurred.

Check exact event ledgers, inaccessible-source ambiguity, reachable-history
order bounds, valid counterpaths, full probability mass, closed source/common
fuel accounting, prepayment, and the paid-update moment identity. A separately
implemented enumerator must reproduce the primary rational results. Positive
results supply only this finite teaching interface. Any failure of observability,
calibration, funding, timing or target stability blocks substitution into the
downstream recurrence at that scope. No empirical experiment is reported.
