This package leaves the accepted parent event law unchanged and adds a mathematical addressed-claims ledger plus an actual-trace adapter. The ledger is proof-level state, not a newly formed memory device. Normative grounds, permission, action choice and factual calibration remain explicit premises.

- `formal/check.py` builds frozen source bytes in a fresh temporary directory under Lean 4.29.1, audits every new theorem, checks allowed standard axioms and records hashes. It does not modify or reconstruct the parent results.

Run from the repository root:


The temporal claim is exact for the inherited cumulative-harm semantics: protection throughout consecutive actual histories requires protection of the same patient in each segment. Earlier success cannot certify an expanded horizon by itself. An unresolved certificate does not prove harm; a payment failure does not justify erasing an admitted claim. Revised grounds and legitimate responsibility transfer require their own contracts.

The parent model remains authoritative for physical costs and alternatives, including voluntary safeguards and harmless withdrawal. This package adds no new stochastic run, ethical priority rule, empirical evidence, mechanism of concern formation or full Python refinement.
