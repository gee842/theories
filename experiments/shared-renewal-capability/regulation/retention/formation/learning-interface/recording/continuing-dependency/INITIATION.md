# 取得启动冲突，并使它约束后来启动

本轮只推进一个连接：**一次真实新形成及一次真实完成的后果，被取得为不同的
消费关系，并在同一材料历史中改变后来尚未形成的活动是否启动。** 旧的无条件
“先形成新 A”次序由此得到有内容的修订。保护某项已在继续的 B 仍是明示的局部
选择约束；本轮没有从经验推出它的普遍伦理优先，也没有完成全部启动、停止和
优先关系的起源解释。

按照 Ren 随后澄清的整体方向，**保护既有 B 是本轮的局部投影，不是整体理论的
中心**。整体要说明包括活动、后果、理解、评价及目的形成在内的共同发生；不能
把它改成某一项预期的实现，也不能未经论证就把各项目的求和或最大化。

[前置协议](INITIATION-PROTOCOL.md)、[运行实现](initiation.py)与
[首次保存结果](initiation-results.json)已冻结。首轮执行通过九条历史，共 2,412
个新事件、2,421 个完整状态，每个 51 坐标，保存五次真实拒绝。每条分支共同
接续 129 个已发生事件：94 个原生形成、22 个判据训练，以及上一轮的 13 个
范围形成事件。[独立重放程序](initiation_independent_check.py)及
[核验回执](initiation-independent-check.json)已通过全部九条历史、51 坐标、
五次拒绝和完整 129 事件前史；八种故意损坏均被发现。核验不导入 producer 的
转移函数，复用已披露的旧独立核验律；这是参与设计后的独立实现重放，不是盲测。
Lean 核验另由其回执报告，不以运行或独立有限重放替代。

## 这个局部投影保留和省略什么

本轮保留了同一表示内相互关联的物理史：原活动和产品、新形成、损伤、部件与
支撑变化、取得内容、读者使用和未解决活动。选择器的形成及读取也消耗并改变
后续条件；共同支持耗尽和新的不可继续实例不会因保护 B 成功而被删除。由此可
检验一条具体关系是否真的进入后续发生，而不只存在于外部评价中。

这个投影仍没有解释整个共同历史怎样形成这些活动和目的、为何以此范围评价、
以及活动与评价机制怎样在共同后果中一起修订。装配记录器的物质过程已有表示，
其配方、保护 B 的评价关系及启动安排的生成解释仍未完成；不同活动的实际体验
和价值也未在此实现。把候选 A 自身的继续再加一条保护规则，并不就完成整体。
本轮较充足分支留下的新 A 正好显出这个省略：一个局部约束获满足，共同发生却
仍生成未解决的后果。整体的进一步解释应能包含并纠正这种投影，而不是把它的
局部成功当成全部评价依据。

## 沿用已发生的条件，不复位原活动

入口是上一轮 `completion_faithful` 的 `actual_branch` 切点，逐步复核原保存
历史，而非只赋予相同数值。此时原 A 已成品，原 B 已启动但未完成；现场受损、
local 为空，common 为 264，source 为 214。原九对判据模块、三对范围模块、
原产品、已取得记录及发生史保留。旧各层消耗账冻结，新账记录此后全部消耗，
合计时没有重复计算。

新装配三个 A/H 对作为有界记录与读者。之后是真实形成的三个不同实例：试验
A、新 B、候选 A。不是把原来的 product 相位改回 absent。形成实例消耗部件和
共同支持，产品仍占材；每个原生事件的容量都扣除全部已占部件。原生 law 没有
补充 common 的操作。

训练在丰富入口连续进行：绑定试验 A 的真实形成，取得其支撑变化；绑定原 B
的真实完成，取得另一项变化。试验 A 随后也经真实 repair、capture、prime、
repair、capture、finish 形成产品，保留其两次局部使用留下的消耗。再形成并
启动新 B，接触取得新 B 的 primed 阶段。候选 A 此时仍未形成。训练结束时有
原 A、原 B、试验 A 三件保留产品，新 B 未完成，common 为 248、source 为 212。

## 消费关系从实际反应进入记录

两个记录不是由事件名字直接填写的“应当先 B”。记录装置先形成，再绑定下一
次特定物理反应。匹配反应发出真实前后支撑差分；中间若出现别的物理事件，
绑定失效。接触与更新各自消耗共同支持，未混入被记录的反应差分。三个候选
消费通道为 common、local、source，真实形成和完成都取得 common 通道。
候选族预先限定为“单一通道、恰好一单位”，`spend_channel` 也沿用这一幅度。
因此本轮取得的是这个族中的通道关系；消耗幅度及跨实例配方对应仍给定，并非
从一次差分学出了任意活动的完整消费规律。

形成与完成的记录分别取得。没有因 B 的 prime 消耗 common，就直接声称已经
观察到其 finish 的消耗。后来的候选 A 和新 B 采用同族配方，是公开的迁移前提：
有限接触并不排除另一种反应族、同名不同配方，或以后发生的结构变化。

缺失形成接触保留未决候选族；伪 source 接触则留下错误通道。缺失或错误不会
被真实 guard 免费更正。运行器保存所取得的内容，也保存最终物理效果，二者
可以不一致。

## 改变的只是一个有界启动约束

选择先消耗一单位 common，再按所取得的消费关系判断：形成候选 A 后，是否
还足以完成已记录为 primed 的新 B？若可以，存储整个
`[formTargetA, finishNewB]` 计划；若不可以但完成 B 本身仍可行，存储
`[finishNewB]`。每个后续 `act` 只执行一个真实反应，不再临时索取一个未被
预留的选择成本。真实 guard 拒绝时，失败保留，不出现免费的后备选择。

这条规则不把既有活动自动认定为最高价值，也不说新形成本身没有意义。它只是
本轮给定的保护关系。新的内容在于形成/完成的消费关系已由实际后果取得，
会使原先无条件的新 A 优先次序在具体边界改变。

读者钳制对照保留全部取得内容、部件与消耗，却继续执行原有新 A 优先次序。
“稀缺忠实”与“稀缺钳制”在选择前的全部 51 坐标完全相同；改变的只是记录
是否进入这项准入判断。

选择器也有明确局限：当前实现中 `record_b != 3` 一律采用单独形成候选 A，
所以除了产品/解离，也包含未知、absent 或 formed 记录。九条比较只在已取得
primed、product、dissociated 的切点调用选择，未检验或证明对未知范围的稳健
处理。缺失消费记录也明确采用旧次序，不能称为一般审慎规则。

## 九条结果及留下的失败

| 分支 | 取得/支撑 | 实际结果 |
|---|---|---|
| 稀缺、忠实 | 选择前 common 2，两个消费通道正确 | 选择后余 1；完成新 B；候选 A 未启动 |
| 稀缺、读者钳制 | 与忠实分支同一完整状态和记录 | 形成候选 A 后 common 0；新 B 的完成被拒绝 |
| 稀缺、形成接触缺失 | 形成消费族仍未决 | 沿旧次序启动；新 B 未完成 |
| 稀缺、形成通道伪报 source | 实际形成仍消耗 common | 启动后耗掉 B 所需支撑；B 未完成 |
| 稀缺、完成通道伪报 source | 实际完成仍需要 common | 同样错误准入，B 未完成 |
| 较充足、忠实 | 选择前 common 3，记录正确 | 候选 A 形成且新 B 完成；候选 A 仍在 formed 阶段 |
| 较充足、选择后真实泄漏 | 选择时同样正确，但执行前少了一单位 common | 旧计划仍形成候选 A，B 的完成随后被拒绝 |
| 新 B 已完成并重新取得 | 内部记录为 product | 允许候选 A 形成；B 产品保留 |
| 新 B 已解离并重新取得 | 内部记录为 dissociated | 允许候选 A 形成；B 无产品，返还的部件和消耗如实保留 |

所有终点的 common 都为零，source 仍为 212。因此“支撑耗尽”这里只能特指
共同支持；不是一切条件都消失。记录没有自动跟随最终成品刷新。B 的最后一步
完成后，早先 primed 记录可以仍然保留，不能把外部终点审计当作新知识。

稀缺忠实分支的候选 A 并非保证稍后启动。共同支持耗尽而本律不补充，该次
未启动同时留下了以后也无法启动的真实机会损失。保护旧 B 不意味着两全。

“较充足”也只是相对于**启动 A 加完成 B**而言。该分支终点仍受损、local 为空、
common 为零。候选 A 只到了 formed 阶段；本律不能再修复现场以取得它的后续
局部支持。保护 B 的短范围约束因此可以被满足，同时造成一个自身无法继续的
新活动。我们保留这个反例，而没有把它称为善于启动或完整照顾了两项活动。

选择后的真实泄漏又区分正确的消费记录与稳定的执行条件。正确知识可以在某
个边界给出可行计划，但没有保证执行前的支撑一直保持，也没有自动形成新的
检查或重规划机会。

## 这一轮没有完成的解释

新记录器配方、相位与通道编码、绑定机制、当前支撑反馈、同族实例的配方迁移、
哪个 B 被保护、训练与形成调度，以及“不以新启动破坏该既成继续”的局部约束
仍然给定。它们在这个表示内发挥作用，不因此被断言为在生成现实之外。

本轮移除的是一个直接写死的启动顺序，不是将所有方向都从材料差分中演绎出来。
“能够继续”“已经形成”“已经终止”“值得继续”尚非同一结论；未完成材料也
没有在这里被解释为体验或苦。原有耗尽反例仍成立，新结果没有恢复旧分支丧失
的条件。接下来须把这个局部结果纳入活动、后果、目的与评价共同形成的整体
解释；保护范围及新活动自身的继续只是其中待解释的关系，不能另立为整体的
最终目标，也不能让局部成功遮蔽共同历史中新的未解后果。
