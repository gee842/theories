# Prospective initiation-conflict protocol

Fixed before the first execution of `initiation.py`. Named connection: **an
actual new formation and an actual completion produce acquired consumption
relations that constrain whether a later, not-yet-formed activity is initiated**.
The removed direct input is the inherited unconditional new-A-first order.
The bounded rule protecting an already continuing B remains supplied; this
study does not derive its ethical priority or all initiation/termination rules.

## Actual acquisition, not an audit read

The observer is assembled before either sampled event. `armForm` binds to the
next actual trial-A formation, and `armFinish` to the next actual original-B
completion. Each arm consumes one common. The matching physical event emits
the actual before/after support difference as a channel mask (common/local/
source); an intervening physical event invalidates the binding. `observe` and
`commit` each consume one common. Observation is faithful, missing (zero), or
falsely reports source; commitment filters the initial three-channel family,
leaving it unresolved when no report arrives. These are separate records for
formation and completion; no equality is inferred merely from event names.

The copied recipe family is a declared local premise: the later candidate-A
formation has the same physical recipe as the sampled trial-A formation, and
new-B completion has the same recipe as the sampled original-B completion.
A successful sample alone does not prove this transfer for arbitrary new types
or changing recipes. No external reward or product-count score is installed.

The new training word is: assemble three times; arm form; form trial A;
observe; commit; arm finish; finish original B; observe; commit; repair;
capture; prime trial A; repair; capture; finish trial A; form new B; prime new B;
contact new B. It reaches common 248, source 212, three retained products
(original A, original B, trial A) and primed new B. The contact costs one common
and records new B's actual phase plus one. Product=4 and dissociated=5 remain
distinct. Both learned channel masks are 1 under faithful contacts.

## The stated bounded admission rule

A selector consumes one common before evaluating remaining support. When the
acquired new-B record is primed, it tests whether the acquired formation cost
followed by the acquired B-completion cost can both be met. If so it stores the
whole plan `[form candidate A, finish new B]`. Otherwise, when the acquired B
completion alone is supported, it stores `[finish new B]`. Unknown learned
costs retain the inherited new-A-first proposal; they are not silently corrected
by the true plant law. A false source-channel report can therefore authorize a
plan that the actual common consumption later defeats. When acquired new B is
product or dissociated, it stores only `[form candidate A]`.

The reader clamp stores the old new-A-first plan despite the same actual
records and observation expenditures. Current support feedback is supplied.
The true phase of the activities is consulted only by actual reaction guards,
not to repair an acquired scope or consumption record. Each `act` executes one
stored primitive and advances the program counter, with no additional reading
charge. A denied primitive remains recorded and does not trigger a free fallback.

This is a local constraint on new initiation while a specified activity still
continues. It does not establish that B has universally greater value, that
trial/candidate formation has no value, or that continuing a created activity
is justified simply because it was created. Choosing B at the scarce boundary
uses the last common unit; candidate A is not initiated and cannot later be
initiated under this unreplenished law. That lost opportunity is a real outcome,
not a promised temporary delay or a claim that both aims have been achieved.

## Nine fixed comparisons and resources

For ordinary training cases, leak common 246 times to reach 2 before selection.
Selection leaves 1. The faithful rule completes new B; clamped or misleading
new-A-first plans form candidate A, then fail to complete B at common 0. A
missing formation receipt retains the same old order rather than a correct
consumption model.

For the ample case, leak 245 times to reach 3; selection leaves 2. The stored
whole plan really forms candidate A and completes B. Candidate A remains formed,
not completed: no free later support or read is assumed. The intervening-loss
case has the same ample decision and correct records, but performs one actual
native common leak after selection and before the first act. The stored plan
then loses B's completion possibility. Correct evidence does not prevent a
subsequent material change or supply free re-planning.

For the completed/dissociated-B controls, after the common training prefix
perform the corresponding true reaction and acquire another B contact, costing
two common in total. Then leak 244 times to reach 2. The reader's acquired scope
contains no primed B, so it permits candidate formation. Completion and
withdrawal have distinct phase records, products and material outcomes; a
permitted dissolution is not thereby a justified release from an undertaking.

Fixed cases: scarce faithful; scarce clamped; scarce missing form;
scarce false-source form; scarce false-source finish; ample faithful;
ample with intervening leak; B completed; B dissociated. Each case retains all
51 state coordinates, guards, denied acts, products, pending instances and
source bindings. The endpoint audit adds no runtime contact: after a successful
B finish its saved B record can still be primed.

## Acceptance and limits

Accept the mechanism only if actual formation/finish effects enter separate
acquired records, the same-state reader clamp changes the executed outcome,
ampleness permits new initiation, and false/missing evidence and intervening
loss preserve their failures. Independently reconstruct the 129-event ancestry
and every new transition; formalize the actual traces and common-zero barrier
without treating finite correspondence as universal compiler equivalence.

Original and new physical recipes, contact binding/fidelity, the finite channel
family, recipe transfer, present support feedback, protected-instance role,
training/formation schedule and the non-foreclosure constraint remain inputs.
The present advance is acquired initiation conflict and its operative use,
not a new ultimate purpose or a universal order of concern. Arbitrary changes
in the recipe family can defeat transfer despite identical training receipts.
