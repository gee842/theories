# 活动范围的形成、取得与解除：原生连接

本轮把上一轮仍由 `cfg.later_repair` 指定的范围，连接到实际形成并发生变化的
活动关系。得到的是**有条件的活动范围形成与内部修订**：新组织产生新的可继续
反应；接触取得这些关系；完成或解离改变其中一项，而历史影响与另一项仍保留。
这还不是“为何应当开始、继续或解除活动”的普遍正当性证明。

[前置协议](SCOPE-PROTOCOL.md)在首轮执行前固定；[源码](scope.py)首跑通过，
[保存结果](scope-results.json)含九条完整分支、2,920 个新事件、36 个状态坐标，
以及共同的 94 个原生形成事件和 22 个旧判据训练事件。
[独立重放程序](scope_independent_check.py)及[核验回执](scope-independent-check.json)
已通过：逐一核查 2,929 个新状态的全部 36 坐标、四次真实拒绝，并独立重构上述
祖先与训练。程序没有导入 producer 的转移函数；祖先与训练复用上一轮冻结的
独立核验律。物料、历史、缺失接触、另一活动、隐瞒拒绝和虚报产品六种故意
损坏均被识别。核验者参与了设计讨论，因此这是独立实现重放而非盲测。Lean
验证另由其形式文件与回执报告，不能以此处的有限重放替代。

## 继承的是同一发生中的已形成能力

从原 FormedSelection 实际祖先开始，逐步执行上一轮相同的模块装配、受阻接触、
真实修复、取得其 common 通道消耗、恢复接触与保存。采用旧轮已保存的窄范围
配置 `later_repair=False`，因此旧 `criterionActive` 为假，而 common 通道记录
真实已取得。新的 `Config` 不再含未来修复范围参数。没有直接赋予新起点一条
未经形成的学习结果，也没有使用旧较宽范围的判据替新读者工作。

共同训练终点为 `(29,30,1,1,1,274,215)`，分别是 free A、free H、resident、
intact、local、common、source。旧九对模块、count 完成史及所有旧非物理字段
均保留。新增读者占三对 A/H，两项活动各占一对 A/H；装配、形成、接触与选择
均消耗真实 common。所有原生事件按扣除这些占材后的容量执行，新增原生复制
不能再使用已装配的部件。新消耗账与旧消耗账分开保存，两者均未归零。

## 活动如何形成自身后继所需的条件

两项活动都经历 absent → formed → primed，再转为 product 或 dissociated。
这些相位有不同的物质、支撑和可执行反应：

| 活动 | 第一实际使用 | 尚未完成时的后继 | 完成后保留什么 |
|---|---|---|---|
| A | 消耗 local，留下 damaged site 和 primed 耦合体 | local 已空，须经原生 repair → capture，再进行最终转化 | 占材产品、既有消耗和最终使用留下的损伤 |
| B | 消耗 common，留下 primed 耦合体 | 再消耗一单位 common 形成产品；不要求 intact 或 local | 占材产品与已耗 common |

A 的第一使用实际造成随后继续的修复依赖。这里没有先输入“未来将损坏、所以
必须预留修复”的任务开关。A 的最终转化也会留下损伤，所以 **损伤仍在** 与
**A 仍需继续** 已成为不同事实。B 可以在该损伤仍在时完成。

解离只允许对未完成耦合体进行；它消耗 common、返还该对部件、生成 dissociated
相位，没有产品。已有损伤与消耗仍在。相位 3 的产品不能再被这个解离事件抹除。
因而“当前不再有此反应”不等于“已经实现其后果”，也不等于“退出必然正当”。
这里形成和解除的是操作范围；正当退出仍须由更完整的关系加以说明。

## 取得的范围确实被用到

每次接触消耗一单位 common，记录该项实际相位加一。记录 4 表示产品，记录 5
表示解离，内部记忆没有把两者合并为单一 finished 位。首次取得的 primed 记录
另有保存，供旧读者与陈旧接触对照。

选择器只读取得的相位记录、旧轮实际学到的 common 通道，以及所声明的当前
支撑反馈。它不读 A/B 当前真实相位来纠正记录。它先为记录中 primed 的 A 选
支撑上可行的继续序列，否则为记录中 primed 的 B 选转化。选定序列存入状态，
其后每个 `act` 只执行其中一个真实反应并推进程序计数。物理反应自身的 guard
仍会拒绝不再存在的转换；拒绝不会自动改好内部记录。

这同时保留两层差异：真实活动与其取得的范围可能不一致；取得正确记录与正确
使用记录也可能不一致。末尾的 `clamp` 对照取得同样的当前真实记录，却仍使用
原先的 primed 快照。该对照不是观察者把结论标签改掉，而是实际使用规则产生
不同的后继事件。

## 九条分支的已得结果

共同新前缀先取得 absent A，再形成并使用 A、取得 A，最后形成并使用 B、取得
B；范围依次从空扩展为 A、A+B。各分支经过实际完成、解离、保持未完或源耗尽，
再进行等成本接触。终点前共同 common 为 2；选择消耗 1，余下 1 用于实际反应。
泄漏次数在首跑前固定，未根据结果调整。

| 分支 | 新取得/实际使用的 A 内容 | 选择及实际后果 |
|---|---|---|
| A 完成，忠实接触 | 产品；读者使用新记录 | B 成品；A 产品和损伤保留 |
| A 完成，陈旧接触 | 原 primed 快照 | 修复、capture 后无法再 finish A；B 未成品 |
| A 完成，缺失接触 | 没有新载荷，旧记录保留 | 同样耗尽 common；B 未成品 |
| A 完成，读者钳制 | 新记录确为产品，读者仍用旧快照 | 与陈旧分支相同 |
| A 解离，忠实接触 | 解离，非产品 | B 成品；A 无产品，部件返还 |
| A 解离，陈旧接触 | 原 primed 快照 | 修复、capture 后 finish A 被拒；A/B 均无产品 |
| A 未完成，忠实接触 | primed | 原生 repair、capture 后 A 成品；B 尚未完成 |
| A 未完成，伪缺席接触 | absent，实际仍 primed | B 成品，A 未完成；虚假范围缩小没有实现 A |
| A 未完成，源真实耗尽 | primed 且 source=0 | A 仍在取得和实际范围中，但当前无法继续；B 成品 |

“完成忠实”与“完成钳制”在选择之前的 **全部 36 坐标完全相同**，包括新取得的
产品记录和此前全部资源投入。读者对新记录是否起作用，改变了那最后一单位
common 究竟用于 B 的真实转换，还是用于没有对应 A 待完成反应的修复。两条
分支新总消耗相同，区别在实际留下的产品、支撑形式与未完成活动。

源耗尽分支包含 215 次实际 capture/leak-local 配对。不能因为源不足就把 A
宣布完成，或从范围中删除；本轮程序保留其 primed 内容并继续可执行的 B。
这也区分“该活动仍未完成”与“当前有路可走”。

最终 B 形成产品之后，历史的 B 记录仍为 primed，因为没有资源支撑一次额外
接触。这一点明确保留在结果中：物理上完成不等于读者已免费取得完成。同理，
A 忠实未完分支实际形成产品后，最后已存记录仍是 primed。本轮没有把观察者
终点审计当作机制的新知识。

## 此轮移除与保留的依赖

移除的是新选择器对旧 `later_repair` 任务开关的依赖。A 第一使用形成实际的
受阻关系；完成或解离改变该项的可继续反应；取得这些变化使机制改用支撑，
同时保留 B 的独立作用。由此比“固定范围内更新手段”多连接了一步：在既有
发生中，新组织与其实际变化形成、扩大和缩小了被机制处理的活动范围。

仍然给定的是材料类型、反应配方、接触机制、相位含义、可用支撑反馈、活动
启动与分支安排、A 优先规则，以及先前学习消费通道的有限候选族。选择器仅为
本轮 primed 阶段实现继续策略，并没有穷尽 formed 或所有多活动冲突。它不能
区分未观察到的任意新反应，也不能排除另一种世界中的隐藏补充通道。相位的
物理作用不是从逻辑本身推出的；它是公开列出的局部生成律。

因此，本轮没有把最终价值、承诺、合理退出或非工具性关切改写成相位定义。
我们也没有证明固定已知法则的控制器不能完成同样工作。所推进的是生成树内
一个可检验的连接：**形成与使用改变后继关系，关系变化进入内部记录，并通过
实际反应改动后续发生。** 下一步的强问题仍是这些活动为何应被继续、如何与
别的活动共同纠正，以及何时退出具有正当性。
