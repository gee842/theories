# Finite reopening extension — frozen before execution

5 October 2026. Baseline results are already known and remain preserved. This extension was requested after the retained-wrong-frame limitation was identified. It is a targeted, post-baseline mechanism extension, not an independently preregistered prediction. No parameter search is planned.

Keep every physical, statistical, normative, effort and succession parameter in PROTOCOL.md:25 rounds,5 inquiry cases, ν=.10, group cap.20, burden cap.45, complaint admission.5, same successor weights and retention probabilities. Change only the following inquiry/replacement rule:

1. An adaptive incumbent at skill2 with a pending admitted complaint undertakes Q **whether or not a frame is already installed**. Skill1 still requires T before inquiry, and volume still performs F. A previously installed frame and commitments remain active on ordinary F/T cases while fresh inquiry is incomplete. Q itself remains a randomized experimental case plus record work.
2. After five new linked records, choose uniformly among the minimum empirical-mismatch expressions. **Replace** the installed expression with this nominee, using the same candidate-model feasibility and ratification rule. Do not inspect the true expression or retain an incumbent merely because it is physically correct. A misleading sample may replace a correct frame with a worse one.
3. At every completed batch, clear the pending complaint, including a ticket arising in that final experimental case, so another inquiry requires a subsequent admitted complaint. Reset the counters. Complaint-triggered reopening can recur through the same finite state space. Package loss still erases both partial inquiry and the installed expression.

Run exactly two additional arms: ordinary endogenous succession, and the explicitly exogenous protected-selection-plus-retention benchmark, both with this same reopening rule. Compare each to its preserved baseline with no reopening. Report endpoint actual plural compliance, ratified but violating probability, skill survival, cumulative ordinary/inquiry cases, training/record effort, separate ordinary/inquiry harms, action-1 uses, completed nominations and expected replacements of an already installed expression. Also report expected actual improvements and deteriorations among those replacements, determined only by analyst physical evaluation after the transition, never used by the institutional replacement rule.

Use full reachable-state enumeration, no trajectory sampling or probability pruning. Preserve baseline source and result hashes. A separate extension script may reuse baseline transition construction with the two explicit rule modifications and must record the baseline hashes. Checks: mass conservation, work conservation, no hidden physical-correctness query in replacement, old-frame execution during incomplete inquiry, pending-complaint reset, possibility of both correcting and corrupting an incumbent, protected skill survival, and agreement with the earlier baseline kernel when the modifications do not apply.

This is a rule for continuing revision within a supplied expression grammar and commitment menu. It does not create new sensors/categories, justify the norms, or preserve the constitutional rule endogenously. The result may be worse than the baseline: additional inquiry uses time, harms experimental cases, and can erase a good incumbent decision with a worse estimate.
