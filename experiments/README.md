# Experiments

Applied experiments and prototypes informed by Ren's theories and values. These projects explore what those ideas might imply in practice; they are not part of the canonical theory corpus.

Each experiment owns its assumptions, implementation choices, evidence and limitations. Links back to theories describe intellectual provenance, not proof. A result changes the experiment; incorporating it into theory requires a separate explicit decision.

|---|---|
| [Circular construction](circular-construction/README.md) | A speculative, regenerative construction system demonstrated with Blender, robotics dynamics, structural analysis and an interactive 3D construction sequence. |
