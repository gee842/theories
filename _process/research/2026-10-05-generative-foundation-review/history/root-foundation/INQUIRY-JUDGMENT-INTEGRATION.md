## Nondual reconstruction and substantive counterreview

The body coordinates, source, record, readout bias, operative description and response are dependent aspects of one declared process. Case distinctions express uncertainty about its readout relation, not a separate world outside a subject. Practical assessment concerns those same actual consequences. The analytical decomposition retains joint accounting and timing but omits formation of the sensor, case domain, menu and judging mechanism.

The strongest retained rival is the fixed response itself: the previous sensor revision is causally useful against a matched clamp yet unnecessary for success in these particular conditions. This study credits that rival and shows its comparative consequence. It does not infer that fixed response is generally superior. A changed loss law, inadequate fixed dose, a basic competing claim on source, or an available superior route could defeat this menu's conclusion.

An apparent dilemma between inquiry and action is not fully resolved: **every plan still includes the inquiry prefix**. Their final responses differ. The fourth policy implements one installed selection rule using an actual acquired field. Claiming rule discovery, an optimal inquiry schedule, an early-intervention comparison or formation of an autonomous selector would exceed these results. General calibration bounds are assumed, while the concrete example checks only bias 0 and −3. Neither case labels nor timestamps justify a sensor's truth.

The continuation predicate has the same threshold and deadline for all plans. A refused response with `a=0` and a funding-denied earlier state with `a=3` both fail enactment. It does not change the deadline or reduce the target to rescue a proof. The underlying denial model stutters; physical continuation during halted computation remains outside this law.

The companion claim is deliberately narrow. It retains `b` and nonnegative source, not every contributor's life, authority or downstream use. Application must add any threatened basic source claim before using dominance. No scalar sum of basic claims, hidden burden weights or universal duty is introduced.
