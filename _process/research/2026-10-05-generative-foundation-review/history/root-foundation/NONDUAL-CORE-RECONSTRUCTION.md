# 非二元核心与主体的生成：从共同历史到分化的位置

2026年10月6日。AI 撰写，响应 [Ren 的核心／延伸指令](../../../../sources/15-codex-theory-conversations/2026-10-06-nondual-core-and-subject-extensions.md)。本轮连接是：**无预设主体切分的生成历史 → 可形成、重叠、改变的作用范围 → 主体与关切的有条件延伸。**

这一步调整解释顺序。上一轮把患者事件与执行者列为参数，检验患者根据如何跨执行位置保持。那个局部问题有效，但不应把这种参数化升级为根本本体论。当前核心本来没有 `Actor` 或 `Patient` 类型；本轮要将这个事实发展为明确的架构要求，并给边界的派生一个实际构造。先前的[非二元重构](NONDUAL-GENERATIVE-RECONSTRUCTION.md)已经提出临时回应如何形成，本轮承接该义务，不把它记为新发现。

## 1. Core 的正面表述

> 活动通过其形成、维持和改变的关系，改变后续活动的条件；感受、观察、行动、建模以及“我／世界”的区分，是在其中形成的不同组织方式。

这是一项待发展的生成解释，不是“先有一个绝对整体，再由它创造万物”。共同核心指解释不需要两个先验隔绝的存在域，并不指所有发生都是一个实体、共享一种体验或必然互相作用。无主体的事件也在适用范围内。

现有接口是 \(\mathcal P=(S,A,E)\)，其中 \(E(s,a,t)\) 指允许发生的变化。`Action` 在原代码中只是事件标签，既不要求意图，也不要求一个先在的行动者。状态可以包含完整的相关历史；没有一个站在现实之外的物理观察者是该定义的隐含组成部分。但数学家给出状态与关系，仍是形式描述，不等于模型已经解释了数学家及其描述活动。

非二元在这里首先成为**架构约束**：主体／客体、行动者／患者、内部／外部的具体切分不能无说明地进入核心。若一个局部模型使用它们，就要说明它们来自哪些活动、维持关系、记录与实际能力。另一个更强命题——现实必然具有这种本体论——仍需独立论证。架构上的可实现性不必等到这一更强命题证明以后才成立。

## 2. 主体不是删掉，而是分层派生

不能用一个笼统的“中心”承担所有解释工作。至少需要区分：

| 派生结构 | 需要说明的东西 | 本轮范围 |
|---|---|---|
| 作用范围 | 哪些实际连接共同使一次变化可能；连接改变时范围如何改变 | 构造可形成、重叠并失效的互补作用范围 |
| 持续组织 | 何种支持、修复、替代使同一组织延续 | 重用已有组织与续生分支；新范围实例不自动具有这些能力 |
| 观察与控制位置 | 哪些差异能进入证据，哪些变化实际可执行 | 当前模型的动态条件；普遍辨认方法仍需推导 |
| 取得的自我表征 | 组织如何学到“此处的活动改变此处的持续条件” | 接到已有取得记录与行动效应研究，不将分析者的标记当作内部学习 |
| 体验连续性 | 何处确有承受、其持续与边界怎样辨认 | 未由连接图或可计算性证明 |
| 实践角色 | 谁能响应，谁受到怎样的影响，有哪些权限与责任 | 是上述关系的局部表达；规范地位需进一步证成 |

同一部分可以参加多个作用范围；同一组织可以既施加影响又承受影响。响应的范围可以包括多个组织，而不构成一个新的共同体验者。主体也不必等同于固定身体边界、叙事名称或一个永不变化的数学类型。

这不是把所有边界都说成任意。连接是否存在、能力是否消失、记忆是否连续、创伤是否累积，可以约束划分。允许边界变化，需要更好地追踪差异，而非把差异抹平。

## 3. 从实际历史到角色表达

令 \(h\) 是原 `Process` 的一段真实允许的 `Trace`，而 \(\rho(h)\) 是从该历史读出的关系描述。用 \((h,\rho(h))\) 表达历史时，角色信息没有另加一个独立主体世界。遗忘附注仍回到同一历史；一致地恢复附注不会多出或丢失原来允许的事件。

这给出一个有用但有限的保守性要求：**角色表达不能偷偷改写原过程的可能历史。** 若所谓主体划分禁止了本来允许的变化，或允许了本来不存在的控制，就不能再叫同一过程的纯读出。

这里形式化的 `ActualHistory` 保留起点、事件词、终点以及允许轨迹的命题证明。它不是可读取所有中间状态的物理日志，也不区分起点、事件词和终点都相同的全部非确定分支。当前终态连接足以回答本轮的范围问题；若问题依赖已丢失的中间差异，必须进一步丰富记录。

读出函数本身仍是模型输入。单独给出 \(\rho\) 不解释任何边界怎样产生。因此新增构造从没有连接的同类型节点开始，实际连接形成互补作用范围，两个范围可以重叠，断开必要连接会撤除相应能力。范围由当前实际作用条件读出，而非由先行 `Actor`／`Patient` 标签决定。节点、激活和连接形成法则仍供给；这是一条有条件的边界生成机制，不是现实基本法则的推导。

另一个必要区别是：给历史加上分析者的角色附注，并没有在系统内部形成一个表征。如果系统自己形成“我／外界”模型并按它行动，那些记录、更新与使用必须成为动态的一部分。已有[取得行动效应的自我研究](SELF-ACQUISITION-BRIDGE.md)接近后一任务，本轮的保守性定理不替代它。

对简化模型还需回答：它有没有合并对目标问题不同的历史？例如一个共同参与的连接端点不能因为跨过了“主体边界”就从实际响应条件中被删去。[形式说明](NONDUAL-CORE-MATH.md)把角色／后果剖面的精确表达接到既有摘要标准。这个标准相对于所问的剖面；它不证明任何有限剖面已经包含所有实际差异。

## 4. 关切的问题随之重写

根本问题可以从“一个主体的价值如何跨越隔离边界到另一个主体”转向：

> **某种真实承受怎样在生成活动中发生；哪些可实现的继续方式改变它；响应能力、认识与选择怎样在同一活动中形成，并对这种差别作出恰当回应？**

这里有三种不同的关系：负担在哪里发生，什么能够改变它，以及哪些改变有根据地值得发生。它们需要连接起来解释，不需要先赋予一个独立所有者以创造价值的权力。描述／评价的区分也是解释中的区分，不能仅凭符号不同就断言现实中存在两个彼此隔绝的领域。

对一个实际历史 \(h\)，可以先比较实际可行的继续方式 \(\tau\)，记录其对已识别的连续性 \(\gamma\) 的后果：\(Y_\gamma(h,\tau)\)。若其中确有体验性负担，真正缓解要改变它的实际继续，而非只改变一个旁观者的评分。“患者”是此处的承受关系；“响应者”是某个能够实现变换的位置或形成中的协作。标签来自同一问题的不同关系，不是必须互斥的两种本体。

这个顺序可以容纳还没有稳定行动者身份的集体回应。它也能容纳一个已有主体的自救、对陌生生命的救助、以及必要的休息或停止破坏。非工具性意味着所比较的患者侧改善不是仅因它给某个预先指定的主体回报才有意义；这仍是待证成的构成性候选，不是从关系图中自动读出的伦理事实。

这使上一轮的 C2 获得更准确的位置：它是具有实际承受、合宜能力和理由解释的局部展开所要通过的测试，**不是定义 generative core 的独立原始公理**。但从 core 的签名移走 C2，不等于已经证明其内容。还需要说明某种真实缓解为什么构成有根据的方向，以及为什么这项根据在相关的响应位置适用；把这种方向记成一个对继续方式的谓词，也不会自动减少证成义务。

共同生成并不要求把全部后果加成一个总分。不同连续性的利益、冲突、同意和损伤都要保留。消除独立所有者的先验地位，也不产生一个有权代表整体控制所有部分的超级所有者。

## 5. 正向结果与失败条件

本轮的正向推进有两个不同层次。解释架构明确采用无原始主体切分的 core，将主体、患者与回应者放在内部生成的延伸层。条件构造则展示，从同一实际事件历史中可以读出形成、重叠和失效的互补作用范围。这比给预设主体重新命名多了一项形成机制。

它并未导出完整主体、现象体验、普遍关切或基础动态法则。这个限度不是对非二元方向的反驳；它说明已完成的接口和继续需要解释的接口分别在哪里。

| 检验 | 若失败，应修订什么 |
|---|---|
| 删除先行主体标签，事件与实际效力仍可完整表达 | 若丢失效力，检查是否暗中把关键机制藏在标签里 |
| 形成与拆除实际连接，所读出的共同作用能力随之改变 | 若不变，所谓边界可能只是外加命名 |
| 两种角色表达遗忘后回到同一历史 | 若事件被添加或删除，不能再声称只是表达变换 |
| 区分共同参与、共同观察与共同体验 | 若混同，就把作用范围错误升级为主体 |
| 压低报告但保留负担，与真正缓解保持区别 | 若混同，就把选择器的成功偷换成患者改善 |
| 高效破坏与有根据的关切都可进入同一核心 | 若把前者定义出去，core 已偷偷含入所求的善 |

前四项得到形式或构造上的局部检验；后两项在既有研究中有对应案例，本轮没有新增经验性检验。当前最有价值的下一步，是把已形成并重叠的作用范围接到实际学习、证据修正和后果识别，进一步解释何时这样的范围成为一个持续组织或体验连续性，而不是再预装一个统一善意主体。
