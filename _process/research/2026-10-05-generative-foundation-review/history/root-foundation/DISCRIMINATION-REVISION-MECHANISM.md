# An acquired experiment changes the operative discrimination criterion

6 October 2026. AI-authored scoped construction under the [nondual method](../../../../theories/becoming/chapters/NONDUAL-METHOD.md). Named connection: **a failed prediction → formation of a retained distinguishing experiment → changed distinctions and subsequent encounters**. The [prospective protocol](../../../../experiments/integrated-correction/general-framework/generative-basis/mathematical-abstraction/acquisition/discrimination/PROTOCOL.md) was preserved before execution. This is a small causal test of the existing standard observation-table learner, not a new learning algorithm or an origin story for its entire architecture.

The result narrows an earlier omission claim. A fixed global transition law does not mean every operative discrimination criterion is fixed. The learner already acquires the experiment set by which it decides whether two histories can be represented together. The new test isolates the use of that acquired set while preserving the original all-future prediction contract.

## The existing mechanism and the question tested

In [the unchanged ancestor source](../../../../experiments/integrated-correction/general-framework/generative-basis/mathematical-abstraction/acquisition/model.py), histories \(s,t\) are provisionally identified when their rows agree on the retained suffix set \(E\):

\[
\operatorname{row}_E(s)=(F(se))_{e\in E}.
\]

If two rows agree but an action leads to different successor rows, an acquired suffix \(ae\) separates them. Adding it preserves old distinctions and rejects this formerly merged pair. [The earlier acquisition mathematics](ABSTRACTION-ACQUISITION-MATH.md) already explains this standard active-learning construction. The test below adds direct causal evidence about the retained suffix's subsequent use.

The unchanged binary target has outputs001 and two actions: `a` advances through the three-cycle, while `b` returns to state0. Bound3, the stable target law, faithful reset/reading interface, physical source20 and tariffs remain supplied. A first one-state candidate predicts0 for `aa` and observes1. The learner adds the counterexample's prefixes. The inconsistent successor rows then cause it to write `a` into \(E\).

The original separating evidence is already cached: `a→0` versus `aa→1`. The newly formed criterion uses those acquired answers as a column that distinguishes the empty history from `a`; it also generates new endpoint requests to populate other histories' rows. The new requests are a consequence of using the distinction, not the original discovery of it.

The study captures the first post-suffix-write checkpoint through an audit-only subclass. | Acquired reader |empty,`a`|empty,`a`|00 / 01|`ba`,`aba`,`aaaa`,`aaba`|

The external intervention masks only consumption of the new suffix by the table reader. It neither removes the retained descriptor nor refunds its formation. Both use the same history set and initial cache. The masked computation uses the old view for its row columns, query concatenations and corresponding work/workspace envelopes, while storage still counts the actual new descriptor. Thus subsequent computation and resource consumption differ as consequences of the intervention; there is no claim of matched post-probe costs.

Both probes finish this one table and stop. The masked arm is **not** a new internally realized revision event, a completed alternative acquisition, or a claimed valid predictor. The checkpoint copies are experimental counterfactuals, not duplicated usable resources in one physical history.

The result identifies a real causal path: acquired suffix formation changes the operative comparison, and reading that suffix changes native encounter generation. It does not enlarge the action alphabet. The unchanged all-word certificate will eventually include these words anyway; what changes here is their generated role and timing, as well as the rows that organize the candidate construction.

## Criterion revision has several concrete forms

The [inquiry-sufficiency reconstruction](INQUIRY-SUFFICIENCY-INTEGRATION.md) correctly identified the method-family learner's fixed singleton rule. That scoped fact should not become a statement that this entire repository lacks acquired operative criteria. Here the discrimination contexts \(E\) change while the final all-future claim and its certificate remain fixed. No one-step task replaces that claim.

The concurrent [inquiry-revision extension](../../../../theories/becoming/history/INQUIRY-REVISION.md) realizes a different connection: a formed contact acquires retained consequences and changes an actual encounter limit from six to four, opening the existing response route in the same concern history. Its independent runtime acceptance is established; its formal status belongs to its own current receipts. The two constructions must not be silently spliced into a single physical history, nor can either be credited as this study's new invention.

Both illustrate effects becoming conditions of later activity. Neither derives the supplied rule for interpreting those effects, selects its own justified overall task, or establishes ethical authority. The remaining stronger question is how the relevance and scope of competing discrimination or rewrite arrangements are formed and corrected through the continuing activity they affect. A fixed explanatory law does not make that question impossible; another favorable rule installed by the analyst would not answer it.
