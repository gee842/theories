"Before" is the step-0 audit's grade where it covered the module (only `CorrectionInfrastructure`), and F3C's own grade against the core otherwise; "after" is the grade against the core with the new core modules. A module is **ported** when every theorem is same or step after. Every new core module compiles from the prelude with an empty axiom report; one theorem takes a choice principle as a named hypothesis (`uniform_policy_iff_fiber_feasible`).
