- *The liar with a third value.* Add a third value, undecided, below true and false in information, with the strong tables. The liar then rests undecided at every stage, and a run of its revision from any start rests exactly where it is undecided (`Undecided.liar_rests`, `Undecided.liar_rests_iff`, [Becoming.Undecided](../../../experiments/integrated-correction/general-framework/generative-basis/lean/becoming/Becoming/Undecided.lean)). Revision of `N` sentences that speak only of one another, run from all undecided, rises at every step and settles within `N` steps at the least fixed point; a chain of denials shows the bound exact (`Undecided.settles`, `Undecided.least_fixed`, `Undecided.chain_exact`). A system with no constant stays wholly undecided (`Undecided.stays_undecided`). Where the two-valued revision has no fixed point, every fixed point and every run that rests leaves a sentence undecided (`Undecided.undecided_of_moves`, `Undecided.rest_undecided`). So the diagonal's gap reappears as undecidedness: the liar never rests with two values and rests undecided with three (`Undecided.liar_both_sides`). The run of a map monotone in information from the undecided value rests from its first step, so the gap needs a map that decides the undecided, which is not monotone (`Undecided.monotone_run_rests`, `Undecided.moves_not_monotone`). A family of three-valued readings within what it reads is still incomplete (`Undecided.incomplete`). The undecided value is what revision has not decided, not a third truth [AI reading, D{D}].
