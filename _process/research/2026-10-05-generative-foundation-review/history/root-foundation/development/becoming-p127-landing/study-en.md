**Where a run goes on: within finitely many configurations a run is a course into a return, and in general it is dependent choice (P127, 16 October 2026).** P81 (`Becoming.Branching`, §99) states its laws along runs taking the run as given; building a run from every configuration that can move takes a continuation at every step, a selection, which it left as its next step; `Becoming.Lasting` left “a run without a selection (the boundary of dependent choice)”. `Becoming.Onward` (28 theorems, 40 declarations, no premise beyond what each theorem names) answers both.
- **Within finitely many configurations a run is a course into a return.** A course as long as the list repeats a configuration, which returns (`returning_of_continues`); round the return, preceded by the course, is a run (`run_of_returning`). So a run starts exactly where a course as long as the list does, exactly where courses of every length do and exactly where a course leads to a return (`run_iff_continues`, `run_iff_unbounded`, `run_iff_returning`), with no decision and no selection; where the successors are listed whether one starts is decided (`run_decided`); where branching is infinite courses of every length give no run (`fan_no_run`).
- **A family that keeps moving** (`KeepsMoving`): within finitely many configurations a run starts at each member and stays in it (`KeepsMoving.run`).
- **The laws along runs with no run given.** Merging nothing, a configuration returns exactly where a course as long as the list starts there (`lossless_returns_iff`), each member of a family that keeps moving returns (`KeepsMoving.returns`), nothing rises within the family and a rise needs a merge (`lossless_no_rise`, `rise_needs_merge`), and a configuration with courses of every length that never returns needs openness (`lossless_unlisted`).
- **Searched moves.** Where a test recognizes among enumerated moves a step staying in the family (`Finds`), a run is built as data by search through accessibility, with no axiom and no selection (`search`, `searchedRun`); testing each move is such a test where steps and the family are decided (`decidedTest_finds`).
- **In general.** A run from every member of every family that keeps moving, asked of every process, is exactly dependent choice (`runs_iff_selection`, `DependentSelection`).
