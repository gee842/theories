# 一项回应结束之后，还有什么没有结束

2026年10月6日。AI 撰写。本轮检验的连接是：**真实处境变化怎样改变回应范围，而不会把原有历史及别处仍在发生的需要一起取消。** 遵循[非二元方法](../../../../theories/becoming/chapters/NONDUAL-METHOD.md)，从同一发生过程中的作用、取得、反应和接续来辨认位置；实验中的“儿童”“成人”“帮助者”是具体互动中的分化位置，不能由角色名称先推出自利、利他或伦理地位。

这是一项经验接口及识别方案，尚不是新实验，也不是对材料模型的经验验证。它补充[此前共同形成的经验比较](PARTICIPATION-CONSEQUENCE-COMPARATORS.md)，不将不同论文、样本或材料运行拼成一个发展历程。[原始论文与保存说明](../../../../sources/42-helping-scope-2026-10-06/README.md)保留字节及阅读范围。

## 1. 两项有区分力、但不能包办解释的观察

**局部需要满足未必要求我来执行。** Hepach、Vaish 与 Tomasello（2012；36名两岁儿童）比较自己帮助、第三人帮助和无人帮助。无人帮助时瞳孔变化较大；两种帮助之间未检出差异，不能据此证明等价。关键细节：成人取回物件后没有继续原任务；三种情境中伸手均停止。因此本实验分辨了物件取得与仅停止伸手，却没有证明原活动整体完成。瞳孔是唤醒指标，不能直接等同关切或体验好坏。[原论文](https://www.eva.mpg.de/documents/Sage/Hepach_Young_PsychScience_2012_1567500.pdf)

**相似的局部恢复不必消除对先前作用的不同理解。** 后续研究（2016在线版本；两岁、三岁各64人）交叉改变谁被安排为损害来源、谁实施修复。事故由装置预设，儿童被引导相信自己或另一成人导致了它。在前一种条件下由第三人修复，唤醒较高；交互作用三岁组 p=.04，两岁组 p=.058，合并分析 p=.01。两组分别排除25、45人；程序并不完全相同。这不能识别真实责任；本轮未重分析原始数据。[原论文](https://sites.duke.edu/tomasellolabduke/files/2017/06/Hepach2c-Vaish2c-Tomasello.pdf)

上述是论文结果的有限摘要。以下是本研究提出的推论与识别要求，不是作者已经证明的结论。

## 2. 对生成解释新增的约束

第一，回应范围不能只绑定执行者身份。若研究声称所关切的是一项实际缺失，那么不同位置的活动改变了同一个缺失时，内部判断须能取得这种变化。“必须我来帮助”需要另有内容，不能仅由“我的关切”推出。

第二，局部后果相同不表示完整关系相同。帮助前的作用可能已经形成另一项内容：说明、承认、恢复信任，或当事人希望不再接触。它们不能由“物件已归位”统一判为完成，也不能由研究者把所有剩余唤醒命名为道德责任。实验中取得的因果归属还可能失真；理解、真实作用与正当责任须分别检验。要辨明具体剩余内容，必须另有观察。

第三，一体展开容纳这两点，而无须把它们处理成利己与利他的矛盾。原来的失所、回应过程、取得变化及对历史的理解属于同一关系的不同环节；位置不同会改变实际作用，不必成为利益只能回流自身的理由。反过来，这个整体描述本身也尚未排除自我唤醒缓解、社会期待或事件闭合等竞争解释。

**本轮经验接口因此给出一项明确要求：用于指导回应的范围记录，至少须区分当前依赖、已发生的作用和对这些变化的取得。** 这不是宣告三种独立本体。把它们合成一个“仍需帮助”位，会抹掉需要解释的不同接续。

## 3. 下一项可区分检验：当前缺失、历史关系与取得条件

以下是尚未实施的研究设计，不声称已获伦理审查、样本、数据或统计功效。可从无伤害的成人共同任务开始，参与者自愿组织活动，并允许退出；不必先用婴幼儿或受苦情境。

| 保持或改变的关系 | 要观察的区别 | 对生成解释的检验 |
|---|---|---|
| 位置甲已完成，位置乙的独立困难仍在 | 是否停止甲处多余介入，同时保留对乙的有效回应 | 排除把“看见一次成功”当作全局结束信号 |
| 同一困难由自己或第三人真实解除 | 能否更新范围，而不要求把成功归给自己 | 检验对实际后果的取得是否超出执行身份 |
| 可见求助停止，困难仍在；或表面动作继续而困难已解 | 判断与行动跟随哪项事实 | 区分真实关系与简单线索消失；不能把被迫沉默当作同意 |
| 局部后果已恢复，但先前作用与修复约定不同 | 是否能够辨明还有什么未解决，或已无继续义务 | 检验历史内容，避免将一切持续投入认作更仁 |
| 自愿结束一项活动、真实完成、强行拆除活动 | 当事人的表达、后续可行性及对退出的理解有何不同 | 区分合理拒绝、完成和更有效控制；成功率不是唯一识别标准 |
| 真实后果保持，接触缺失或错误 | 何时误判、怎样接受纠正；纠正后是否改变后续活动 | 检验取得机制，而不是让分析者直接替参与者知道 |

共同任务的目标和完成方式应在互动中可以形成、说明、修订；研究者仍须公开材料、提示与编码规则。不能一方面把规则全部设定好，另一方面称实验已经显示目的从无到有。测量也须分开当前活动是否可继续、参与者自己的说明、旁观识别和行为影响；单一量表不得同时定义“真实关切”并证明它。

竞争解释至少包括固定动作规则、学习到的任务奖励、自我唤醒缓解、关系维护和情境敏感的普通控制。若它们保存所有待解释现象且同样解释数据，就应承认本轮接口没有辨认生成理论的独特优势。更有效控制若使当事人可表达的内容、真实退出和后续活动变得更窄，不能仅凭局部完成更多而算复通。

## 4. 接入形式模型的准确位置

本轮材料模型可以检验活动复合体的形成、实际阶段、取得范围和后续使用是否连贯，并保留完成与解离不同的历史。这个接口有助于发现解释中漏掉了哪条关系，但材料产物不是生活完成，部件消耗不是痛苦，活动解离也不是人的合理拒绝或死亡。

因此，应分开三项交付：材料机制的真实运行与证明；生活情境中这些关系的独立识别；使某种回应成为正当根据的论证。前两项能使第三项有明确内容、可接受纠正，却不能以表格映射替它完成普遍证成。本轮新增的是一个可检验的桥梁要求与反例安排；实际跨情境验证、发展起源及无假设普遍根据仍待完成。
