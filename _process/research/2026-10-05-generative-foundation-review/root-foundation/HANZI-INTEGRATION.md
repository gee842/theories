## 2. 内部审读及接受的修订

三路 AI 研究分别负责当前节点与谱系、构形证据、映射条件，随后交叉审读主稿对应部分。它们不是外部同行评审，重复使用同一原文也不算独立历史见证。

| 审读事项 | 最终处理 |
|---|---|
| 义项限制可能被误读为不准直接用单字作形式标识 | 主稿区分历史对读与受控命名；后者可由词表固定单字用法，域外多义不妨碍域内唯一 |
| “关系保留”若仅看是否能表达理论，会形成自证 | 补充历史关系须由原文独立确定，分别核查关系类型、方向与条件；同构主张还须反向检查 |
| 将理论树一律改称图可能扩大用户的局部对应问题 | 保留局部树形入口，只为交叉依赖和反馈另记有类型的关系 |
| 说理论“开始拥有中文表达”会抹去其既有中文谱系 | 改为在已有中文术语基础上进一步整理词表，并明确不是本轮首次翻译为中文 |
| 将事实“理解为理由”易跨过正当性接口 | 改为事实证据与理由适用建立有根据的联系；明确本轮没有新增其因果形成机制 |
| 生、化、成、习等的数据库解释可能被误作定论 | 构形研究者复核九项相关条文，确认主稿与试读保留“疑”、论者归属和未校原拓的范围；没有宣布单一读法为全体学界共识 |
| 武例可能被说成纯和平主义，或一次字源纠正取消全部思想价值 | 保留《左传》的规范性重释及对部分征伐的认可；区分早期足形解释、训释与现代保护映射 |
| 旧聊天文件日期与具体消息日期不同 | 原始文件名照旧保存；命名直觉的消息按实际 2026-05-05T07:56 记录，未把文件名的 05-04 当成逐条消息日期 |

主稿和四份笔记在这些限定下完成本轮整合。没有把用户的提问改写成已经证明所有汉字一一映射，也没有以全语言多义否定他提出的有限子集。
