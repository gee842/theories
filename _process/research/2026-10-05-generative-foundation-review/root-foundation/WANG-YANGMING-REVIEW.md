# 王阳明比较：反例、前提与旧形式主张审查

2026年10月6日。AI 撰写的独立审查，服务于[王阳明比较主文](../../../../theories/shengsheng-buxi-generative-existence/unified-2026-10-05/WANG-YANGMING.md)。它不是 Ren 的原话、外部同行评议或对旧仓库的全面审计。本轮只审查比较主文、直接相关的现行根基和两份指定旧件，并只读核对一份旧件所指的当前源代码；没有修改旧件、重跑旧形式库或增加经验实验。

本轮所服务的根本连接是：**受影响者自身真实的善恶根据 → 无既有角色或先行助人意愿的有能力行动者的实践理由**。行动理由的正当性、理由被认识、形成动机以及实际执行，应分别论证，再连接起来。支持文献与文本范围见[来源笔记](WANG-YANGMING-SOURCES.md)，机制条件见[机制分析](WANG-YANGMING-MECHANISMS.md)。

## 1. 审查结论

比较主文可以作为一轮有边界的概念整合。它明确区分古典解释、现代重构、条件机制和最强必然性，没有将相似术语直接视作证明。知行工夫、去蔽、事上磨炼以及超出互惠的一体之仁，确实向现有研究提出相连且有内容的问题。当前主文没有发现必须阻止交付的过度声称。

这里的接受只针对本轮比较的表述与推论范围。它不认证全部心学，不验证某种良知训练方案，也不完成患者根据向陌生行动者的理由过渡。正式推论仍须保留[最强目标](../../../../theories/shengsheng-buxi-generative-existence/unified-2026-10-05/STRONGEST-FOUNDATION-CLAIM.md)和[伦理根基](../../../../theories/shengsheng-buxi-generative-existence/unified-2026-10-05/UNIFIED-ETHICAL-GROUNDING.md)中的未决前提。

## 2. 五组对应及其风险

| 比较项 | 可接受的解释接口 | 不能借对应偷带的结论 |
|---|---|---|
| 心即理 | 实践辨识、评价和行动属于心智的真实运作；道德认识不能永远停留在外在指令 | 心属于世界不推出心的当前判断必真。内在一致或持续成功也不认证道德权威 |
| 心外无物 | 意所涉及的事、感应及其对主体的意义需要实际关系；认识者在世界之内 | 没被某人感知不等于不存在。现行根基明确把可产生后果的差异与观察者描述区别开 |
| 良知与致良知 | 实践辨识可形成、去蔽、扩大并修正自身评价方式 | 形成评价者不证明评价正确；可培养不证明先天无误。不能把当前内在偏好或外加奖励命名为良知即结束解释 |
| 万物一体 | 共同生成关系与独立他者的处境一起进入解释；非工具性关切是强候选目标 | 同源、相依、对称不自动推出跨主体理由；总量增长不能抹除各患者的不同损失与权限 |
| 知行合一 | 真切理解可通过评价与实际回应进入同一生活过程；口头复述不足以认证实践吸收 | 事实知识不保证动机、资源和权限。若真知完全由必然善行定义，则相应结论是定义内推论 |

此处的“患者”沿用当前伦理研究，指受到好坏影响的主体，不限于医疗病人。不能假定一切能被保全的对象都有同样的体验、权利或理由。阳明对草木瓦石的顾惜，比仅以痛苦为起点的最小论证范围更广，后者的成功不认证前者的全部对象范围。

原典也不能被削弱成单纯的现代功能主义。来源笔记保留了良知与造化、灵明与天地的更强说法。另一方面，原典允许具体求知、开悟扩充和情境差等；把它说成拒绝经验、当下意见无误、所有对象应获完全相等对待，同样不成立。本轮直接复核[卷二十六《大学问》](https://zh.wikisource.org/zh-hans/王陽明集/卷26)的至善问答，确有轻重厚薄随感而应的表述，因此主文关于该篇保留差等的引文定位可接受；[卷三](https://zh.wikisource.org/zh-hans/王陽明集/卷03)另有更具体的厚薄问答。

## 3. 已有反例阻止哪些强推论

### 3.1 对称性仍可保留自他割裂

[慧根的双轨道结果](../../../../theories/shengsheng-buxi-generative-existence/unified-2026-10-05/HUIGEN.md#5-the-ethical-bridge-now-has-an-exact-test)指出，规则

\[
r(a,p)=1\quad\Longleftrightarrow\quad a=p
\]

在所有主体同时换名时保持不变，承认每个主体的自身损害，却不给跨主体理由。换名保持 self/other 之别。已有手证及有限穷举支持这个相对不蕴涵结果；本轮没有重跑。它并不证明利己主义正当，而是表明“同具一个结构”不能独自承担非排他关切。

[理由传递结果](HUIGEN-REASON-TRANSPORT.md)进一步区分患者范围与行动者范围。只传播既有理由不能为未被锚定的患者自动产生第一项理由，也不能仅凭复制记录将一个人的理由变成另一个人的理由。把万物一体直接编码成完整传递边，会把核心争议放进前提。

### 3.2 学得更多也能撤回有据帮助

[评价塑性](../../../../theories/shengsheng-buxi-generative-existence/unified-2026-10-05/EVALUATIVE-PLASTICITY.md)和[评价奠基的修正比较](../../../../theories/shengsheng-buxi-generative-existence/unified-2026-10-05/EVALUATIVE-GROUNDING.md#what-correct-revision-must-preserve)保留一组有力反例：两边获得同样后续资料，保持相同手段知识，也都负担得起服务，但连接更新后的一边撤回服务，保留原正连接的一边仍行动。若独立成立的修复根据未变，更新即偏离该根据。

这反驳一般的“知识增长或适应成功必然成善”，不直接反驳阳明限定意义的真知。要提出后者的因果必然性，必须给真知独立识别标准，不能因反例不行善便自动宣布它不算知。动机受蔽、事实错误、无力实施、许可缺失和正当冲突也不能合并成私欲。

### 3.3 患者未变不等于一切理由条件未变

[统一伦理根基](../../../../theories/shengsheng-buxi-generative-existence/unified-2026-10-05/UNIFIED-ETHICAL-GROUNDING.md#what-changing-the-operator-can-establish)积极辩护陌生行动者也有初步理由，但仍要求解释为什么患者的真实好坏对这个行动者有实践效力。替换行动者会改变 actor–patient 关系；不能在未论证其相关性前称它只是换名。相反，单凭行动者漠然，也不能证明患者根据已失效。

## 4. 旧“伴随”方案：已提出结构，未提供语义证明

指定旧件：[jian-ontology-v7.md](../../../../sources/08-jian-wen-language/downloads-2026-05/jian-ontology-v7.md)。本轮定位如下：

- §21.3 列出五对认识与主体模式的伴随，包括“知 ⊣ 修”；§24.2 将之列作法则 10。
- §25 的 Phase 5 给出 `cognitionModeAdjunction` 与 `zhi_xing_he_yi` 的计划签名，没有给这些签名的实现或证明体。
- §26.2 由 `知(事) ⊣ 修(事)` 推到不能知而不行、不能行而不知。这一步未陈述其独立语义桥，也没有在这段给出范畴、函子、同态对应或单位余单位验证。
- §29.4 的勾号处于未来成功条件列表；§29.3 仍列阶段工期，§30.2 的风险 5 明说法则 10 的证明仍有待主体结构展开。因此不能只摘勾号或定理签名报告为已完成机器证明。

伴随本身也不等于两个算子互逆、两个活动必然同时发生或行动必善。一个基本手算反例是二元偏序 `0 ≤ 1` 上的常值映射 `F(x)=0` 与 `G(y)=1`：对所有 x、y，`F(x) ≤ y` 与 `x ≤ G(y)` 都真，所以 `F ⊣ G`；但 `GF(0)=1 ≠ 0`，`FG(1)=0 ≠ 1`。这排除从裸伴随直接推出互逆或同一的推理。它不是阳明的反例，因为尚未把这些映射独立识别为阳明的知与行。

因此该旧稿在本比较中的正确地位是**有待构造和解释的数学结构候选**。即使今后证成某对算子确实伴随，仍要说明它为何充分表达切身认识、评价与躬行，以及数学关系为何支持具体的实践结论。这轮未检索和审计所有后续伴随实现，也不声称它们全部不存在。

## 6. 阳明对我们构成的实质挑战

1. **“理解”是否被削成预测。** 同样事实预测下的冷漠反例，只排除弱认知必然产生关切；它尚未排除具身、切身而实践的理解确有更强作用。需要独立测量后者，且保留其失败可能。
2. **价值为何在对象中显现。** 若患者的真实负担已经具有理由意义，学习可能是在发现而非创造这种效力。我们不能永远先给一个外部目标再称其形成已经解释，也不能用内在奖励直接回答正当性。
3. **去蔽如何检验。** 内省须能暴露选择性注意、自利解释与反馈压制；接受他人纠正、实际权限及真实后果不可由自称诚意替代。当前[可错的良知提案](../../../../theories/shengsheng-buxi-generative-existence/unified-2026-10-05/GENERATIVE-GROUNDING.md#良知-as-a-developing-capacity-within-generation)已提供此接口。

旧综述已保存对“良知不可 Goodhart”和误读“四句教”的批评，见[智善文本综述](../../../../theories/zhishan-intelligence-must-be-good/synthesis-a-texts.md)的相关未决问题。本次不能通过换名为切身理解，使一个不可独立检验的内在裁判重新免于审查。规范判断有真伪与有限主体可能误判，可以同时成立。
