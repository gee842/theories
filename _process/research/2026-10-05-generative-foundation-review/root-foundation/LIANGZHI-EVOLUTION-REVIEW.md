# 良知的生成演化：肯定路线、失效条件与独立反审

2026年10月7日，Asia/Bangkok。AI 内部分工反审，依据[Ren 要求记录并推进的方向](../../../../sources/15-codex-theory-conversations/2026-10-07-liangzhi-generative-evolution.md)。中心连接是：**回应的实际后果如何进入差异延续、再形成与传递，进而解释社会性生活中关切结构的形成及其对个体的先在作用。** 这为普遍元伦理研究提供能力来源、可靠范围与失败条件的解释，不将一次有利选择自动算作规范奠基。

本稿遵循[同一过程内的关系方法](../../../../theories/becoming/chapters/NONDUAL-METHOD.md)。识别种系、个体、情境与关切，都是对同一形成历史中具体关系的分析；没有先放置独立利益所有者，也不把规范评价移到生成现实之外。所有新增数学主张须以对应的实际 Lean 检查为准，哲学反审本身不代替机器证明。

## 1. 这条路线的肯定内容

「本然」可以有生成史。对一个具体生命先于反省起作用的感应倾向，可以由先前历程中反复形成、维持和传递的组织构成；它无须是无来历的天外原则。这是一种有内容的现代生成解释，不直接等同阳明关于天命之性、本然良知与造化的全部主张。还应区分初始倾向、发育条件、经验形成的辨别，以及已经能据理纠正自己的伦理判断。先于反省不等于出生时一切都已完成，种系形成也不取消每个个体的实际发展。

演化来历与非工具性关切同样相容。某种结构在历史上因共同生活的继续条件而被保留，不意味着它现在每次回应都在计算自己的未来回报。它可以使另一处的实际处境直接进入注意、痛惜、安慰与行动选择，也可以在没有预期私人收益时继续如此。这一区别分开的是形成原因与当前组织方式，二者仍属同一历史。仅见无即时回报，尚不足以识别这种组织方式；反过来，发现形成过程中的延续优势，也不证明当前关切其实只为回报。

最强的正面路线因此是：社会性生活的活动改变后续共同生活；差异回应改变某些结构得到再形成、发展与传递的实际关系；这种历程保留某些易于感应、照料、协同和纠正的能力；能力在个体中经过发育取得具体内容。它能够解释为什么一些道德感应不必每次从自利推算开始，而不是把善的偏好预先命名为赢家。

## 2. 先信用已完成的连接

[既有变体形成整合](../../2026-10-05-support-and-shared-generativity/completion/FORMED-VARIANT-SELECTION-INTEGRATION.md)已经给出同一法则内的实例：两种响应最初均不存在，形成、结合、修复、取得支持与复制相接，竞争变体仍在场，原有条件没有在中途重置。有效后果进入后续复制，不依赖分析者给「成功」另加奖励。该局部结果不能被新章重新描述为完全缺失。

[后果与差异留存研究](../../2026-10-05-support-and-shared-generativity/completion/CONSEQUENCE-RETENTION-SELECTION.md)又保存共同池中有用修复增加总再形成、却不增加其生产者预期比例的情形，以及占据、磨损与接续者改变支持归属的反向情形。其中随机频率推论原为手证、数值及内部审查，不能追溯称为本轮 Lean 已检查；早先 Lean 事件结果保留其各自范围。

[评价发展](../../../../theories/becoming/chapters/VALUATION-DEVELOPMENT.md)已包含经验形成回应联结、更新方式修订、谱系的继承／分枝，以及共同过程的不同切分。[评价继承](../../../../theories/becoming/chapters/EVALUATIVE-SUCCESSION.md)更已在同一有条件的材料历程中建立：已取得的评价影响经实际接口为不同后继所访问，后继取得新证据、纠正手段判断，并据此选择实际回应；原先组织及其历史没有被重命名为后继。先前基础的叙述性缺口清单不能盖过这些后来的结果。这里并非所有响应能力的代际接合仍未完成；尚不能由这些有限接合直接获得的是多种可传递响应组织在共同发展与社会性交往中的差异选择，以及社会动物关切的实际来源。

本轮真正需要的新对应是：可传递的是什么组织，它怎样在接续生命的实际发展中实现回应，其效果怎样进入差异传递；相应何种历史使这种连接失效。若新形式化只给两种已定行为贴标签，再令较多后继带有某标签，所得可是一项有用的传递条件，却还不是关切能力起源的证明。应准确报告已经接上的接口，而不是以「从零」「本然」扩张语义。

## 3. 生成性怎样成为演化压力

活动能够改变继续条件，是这条路线的根。要进一步解释有遗传意义的选择，须说明差异怎样延续到再形成之中，以及为什么后续差异与此前回应有实际关系。某条路径断绝只是该路径无法继续，尚不独自表明某种可传递倾向因此增加。可以从具体生成关系推导这些条件，不必另设一个外部选择者；但不能省掉它们。

应特别保留改变中的共同条件。形成了照料、合作或控制的活动，也可能改变谁与谁反复相遇、后继怎样发展、哪些关系还能被修正；因此不能只在一个永远固定的背景上比较两个不变标签。如果一个局部模型固定这些关系，应明确其时间范围和保留的内容。局部法则给定不等于现实外在，仍有待解释也不等于整条生成路线已经失败。

差异传递也不须还原为某个原始所有者的「利益回流」。再形成可以沿实际亲缘、教养、共同生活、模仿或组织继承发生；哪些通路存在，应由研究对象说明。共同改善与某种结构被保留之间的关联，必须来自这些关系，不能因我们希望它成立就把「仁」写成较高复制率。

## 4. 哪些情况会改变正面结论

以下不是自由切换善恶标签的反模型，也不是本轮新动物实验，而是应被保存或实际检验的具体关系差异。

| 情形 | 正论证必须解释的后果 |
|---|---|
| 改善为多种结构共同取得，而产生改善的倾向没有额外传递联系 | 总体再形成增加与该倾向的相对保留可以分离；必须明确研究的是总数、比例、分枝延续还是实际照料能力。 |
| 有效回应带来磨损，随后接续者获得其留下的支持 | 后果确实有用，也确实在同一历史中继续，但支持可能更有利于另一倾向；不能只凭用途解释原倾向的保留。 |
| 原本频繁相遇的关系断开，后继进入不同发展条件 | 已保留的倾向可能不再实现原有作用。要区别结构传递失败、发育表达改变与判断在新处境中失准。 |
| 小范围照料有效，而不同关系中的伤害也促进该结构的传递 | 社会性与非工具性的小范围关切不自动扩展为对整个关系网络的可靠回应；不得把两种后果拆开只保留有利一边。 |
| 准确理解人情提高合作，也提高操纵能力 | 被选择的可能是可朝不同方向使用的能力；出现感应能力不能独自决定仁的实现。阳明自身已承认精通人情可用于不善。 |
| 倾向通过后继而持续，但后继只复制动作，未取得原辨别与纠正能力 | 行为谱系不是完整能力谱系；同样表面动作对不同处境可以具有不同作用。 |
| 原结构并不持续，但它形成了更可纠正的后继关系 | 结构自身的消失不自动等于整体变坏；用原标签留存作为唯一目标会漏掉这种转化。 |

这些情形决定结论的适用范围。它们不要求先给每个片段分配独立固定价值；受益、承受、形成与传递的位置可以随历史变化。尤其不能把「被选择」定义为在整体伦理上得到支持，再由选择结果宣告伦理可靠。

## 5. 怎样检验良知而非只检验行为数量

对于社会性关切，至少需要辨明被保留的回应是否追随实际处境变化：需要已解除时会否停下；表达受到压抑时是否误判为无事；原办法造成新负担时能否修订；帮助者没有即时私人回报时是否仍然在意；相应能力能否跨越已熟悉对象而又尊重具体关系的差异。这些是可能有区分力的辨认问题，不能把所有答案预设为正确，再称所得能力是良知。

同样，宽广而可修正的回应也不是不加限定地越多越好。合理拒绝、自我照料、有限责任、实际权限及有根据的停止，都属于共同生活的辨别。若一个演化模型只奖励更多干预，它还没有说明这些能力。若经验研究仅观察递物、安慰或合作次数，应按这个测量范围使用，不能从一个表现推到本然道德全知。

规范可靠性是在同一生成过程内对这些实际关系的说明。它不因有演化来历而自动消失，也不因保留成功而自动成立。正面工作应解释：某种响应为何能追踪被指认的整体生活改善，何时这种追踪会被截断，以及何种纠正能恢复它。即使这些可靠性关系已成立，其跨全部相关智能的规范效力仍有更强的论证义务。普遍范围容许差异化的实践意义，不预定一切位置必须作出相同帮助。

### 肯定论证及来源范围审查

完整阅读[肯定论证](LIANGZHI-EVOLUTION-ARGUMENT.md)。接受其积极方向及当前范围：它已信用既有的后果—复制实例，新的接口明确为模板复制与后继响应结构可能分离，而不是将旧材料修复换名为良知。三种跨度属于同一历史，出生前形成、出生后发展和具体工夫没有被分成互不相关的来源。识别方案明确为待执行的研究设计，没有据此宣布社会性必然走向完整良知。

亦完整阅读[三项来源评估](LIANGZHI-EVOLUTION-SOURCES.md)，接受其分别支持比较关联、共同生活改变帮助范围、照料经发展再形成的范围。共同育幼比较没有直接测得选择率；大鼠寄养的早期同品系接触、焦虑与控制限制没有删去；跨代母性照料提供的是实际非基因组传递线索，不是自动获得伦理优越或繁殖优势。这三项不属于同一连续观察，不能接成已经识别完整种系—发育—良知链。本审查仅核对来源稿，不重新访问原始论文，不能加算一个独立原文确认。

### 新形式源码及实际检查的审查

完整阅读 [ConsequenceTransmission.lean](../../../../experiments/shared-renewal-capability/regulation/retention/formation/evolution/ConsequenceTransmission.lean)，并核对它引用的既有 `FormedSelection` 事件、使能条件、计数与材料守恒。其新内容不是另一套良知机制，而是把旧复制频率问题中的一个明确切片迁入 Lean，并区分模板复制与后继响应组成。

通用算式处理一次选择事件：复制 A、复制 H，或两类数量不变。当前数量与总权重为正时，前后分数在同一正分母上比较；均值增加的精确条件为 `copyA * h > copyH * a`。所谓中性只指这一切片中的计数不变，不意味事件对后续条件毫无作用。原生法则允许形成与磨损，这些事件不能混入「数量不变」类；新结果没有声称给出完整原生随机核、连续时间漂移或长期方向。

原生对应中，复制通道的正权重由现有使能条件限制；实际复制的同类数量增量来自既有事件律。新继承反向实例从两类均缺席开始，形成两个 A 和一个 H，A 修复后原驻留 A 磨损，另一个 A 留在场，H 随后取得驻留位置并利用保留下来的修复后果。每个步骤从真实前态接续，没有在转移边界补种 A。它与原有捕获正例都到达一 A、一 H 的组成，却具有相反的局部复制访问。两条形成史及初始支持不同，因此这不是仅改变一个因素、初始条件相同的因果实验，也不是从相同组成推同一选择结果。

本反审提出的两项修订已在最终源码落实：

- 具体已到达比较状态中的数量不变权重，可以赋予真实使能的 `damage` 事件，并已证明该事件保持两类计数。一般任意数量不变权重仍不自动获得原生事件解释；除去形成和磨损的切片限制继续有效。
- 忠实复制是模板权重和后继响应权重一致的充分条件，不能称为必要条件。新增 `balanced_transfer_matches_template` 表明双向改变权重相等也足够；非忠实传递仍可能增加同一响应类型。

四格传递扩展的行计模板机会、列计后继响应类型。四格均为正的反例保留两个原类型：模板 A 获得六份、H 四份机会，后继却只有三份为 A、七份为 H，响应 A 的下一事件均值由二分之一变为十三分之三十。这是扩展的分类权重结果，不是原生材料律已经演化出突变架构，不是后继已形成伦理判断，也不是所研究动物的实测比例。

**核对结果：** 通过回执的四个现行源码、四个编译日志、检查器与 Lean 编译器的 SHA-256 均经本审查者独立复核相符。[回执](../../../../experiments/shared-renewal-capability/regulation/retention/formation/evolution/verification.json) SHA-256 为 `1798cc32373a8b032996d36194f6c29e616ea17ffd7e58938be860796f013f5c`，记录 Lean 4.29.1 的新鲜构建通过，总计90项声明审计，新增19项，其中6项命名公理依赖为空，另13项仅依赖 `propext`。本审查未重复编译；这不是第二个独立科学运行。两次此前失败的构建保留，不计作通过或否定演化方向的反例。

### 最终主文、数学说明与整合接受

完整阅读[当前理论页](../../../../theories/becoming/chapters/LIANGZHI-EVOLUTION.md)、修订后的肯定论证、完整数学说明及[整合记录](LIANGZHI-EVOLUTION-INTEGRATION.md)。本然的三种形成跨度、演化来历与当前动机、模板与后继类型、计数切片与完整历史、经验表现与规范可靠性均已清楚区分。没有发现把修复 A 命名为仁、将出生标签当作能力发展、或从 core 宣告必然收敛于良知的推论。

数学说明已经采纳两项最后的对应精确化：原生同型复制与非忠实四格推广分开归属；下一接口明确接在已完成的实际评价继承之上，研究多种可传递响应组织在共同发展中的差异再形成，未重新宣布所有后继关切接口缺失。候选识别包括回应如何随真实处境、后果与发展史而变化，也保留拒绝、自护及合理停止；它们没有被既定复制分数替代。

**最终结论：接受本轮首个形成／传递接口及证据评估的完成，没有需要阻止交付的实质问题。** 肯定进展包括：内生选择无需外在奖励者；种系及共同生活形成可以与个体先于反省的倾向相容；模板延续与后继响应组织有精确、已检查的区别。后一数学区别不独自证明前两项在全部自然情境实现。本轮仍未完成良知的整个社会性演化史、选择关系与发展关系的全部接合、伦理可靠性或普遍规范根据；这些目标没有被缩成模板数量增长。
