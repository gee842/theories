# 实际处境怎样纠正回应：两项原始研究与竞争解释

2026年10月7日。AI 来源评估。承接[共同发展的证据接口](LIANGZHI-DEVELOPMENT-SOURCES.md)，本轮检验**理解是否追踪所参与活动的具体关系，以及这种校准怎样支持或修订关切的整体解释**。遵循[非二元方法](../../../../theories/becoming/chapters/NONDUAL-METHOD.md)：目标、物的可用性、请求与回应不是先已完整的独立要素；实验选择其中部分关系加以改变。这里的“需要”首先指对实验呈现的任务而言需要什么，不等于已经证明的伦理要求。

已读[规范根据接口](LIANGZHI-NORMATIVE-WARRANT-INTERFACE.md)。既有[满足后撤回](FULFILLMENT-WITHDRAWAL-INTEGRATION.md)已实现有条件的实践应用修订；本轮不将其重新列为缺失，也不另造同类控制器。本文没有新证明或实验。

## 1. 需要与表面动作：Hepach 等（2016）

*Young Children Want to See Others Get the Help They Need*，Child Development 87:1703–1714，DOI 10.1111/cdev.12633。[作者实验室原论文](https://uva-early-social-development-lab.com/wp-content/uploads/2025/01/Young-Children-Want-to-See-Others-Get-the-Help-They-Need.pdf)。

现场任务中，51名两岁儿童中33名捡物，23名先捡任务相关物；他们也继续捡无关物。视频任务的64名儿童包含上述51名，非独立复制。第三方交还相关或无关物时，求助者均停止伸手；无人物动画保留相同物体运动。社会情境中，先前唤醒与后续瞳孔变化的关系随所给物是否适合任务而变。原文强调瞳孔测投入程度，不能识别某种特定情绪，违背预期亦可解释。[方法与结果，pp.1704–1710；解释限制，pp.1711–1713](https://uva-early-social-development-lab.com/wp-content/uploads/2025/01/Young-Children-Want-to-See-Others-Get-the-Help-They-Need.pdf)。

**此证据的判别力：**只恢复物品位置、只随伸手动作起落的解释受削弱；关键差异支持涉及活动目标的解释，具体预期或联结机制仍需比较。但视频未呈现终局任务已经完成，现场亦未证明满足后停止。因此不能把它写成“实际成全已测得”或“儿童总会适时不回应”。没有口头感谢并不排尽所有当前或预期回报；旁观反应也不直接识别行动动机。

## 2. 请求与适切手段：Martin 与 Olson（2013）

*When Kids Know Better: Paternalistic Helping in 3-Year-Old Children*，Developmental Psychology 49:2071–2081，DOI 10.1037/a0031715。[作者上传的原稿全文](https://www.researchgate.net/publication/235399320_When_Kids_Know_Better_Paternalistic_Helping_in_3-Year-Old_Children)，以下页码采用在线初刊稿。

三项研究样本为19、19、20名三岁儿童。请求的物不能完成已说明任务时，儿童较常改给可用物；丢垃圾时不固定偏好完好物。第三项同一破杯可用于切面团、玩具电话可作镇纸；适用时更常遵照请求。主要指标是首先递给哪件物，部分拒递或递两件的数据被排除。作者明确区分这种替换手段与违背知情意愿的强家长主义，后者未检验。[研究1–3及讨论，原稿pp.3–10](https://www.researchgate.net/publication/235399320_When_Kids_Know_Better_Paternalistic_Helping_in_3-Year-Old_Children)。

**此证据的判别力：**盲从指物和“完好物总较好”的固定规则不足以解释结果。被追踪的是物在当前活动中的作用；破损不是脱离用途的绝对负值。实验者已说明最终任务，任务条件对照未追踪同一实践中新目的如何形成，也没有检验儿童是否正确推断隐蔽目的、是否有权替代知情选择，或该目的本身是否正当。它也未独立操控社会回报。

## 3. 对整体解释的积极贡献与强竞争者

两项研究让一个有限命题获得经验支持：回应可以对具体活动关系敏感，其适切性不能还原为照字面执行、固定物品偏好或表面动作消失。理解与响应可能在同一实践中调整，现有意向也不必把最初手段固定到底。这是对[共同解释路线](LIANGZHI-NORMATIVE-WARRANT-INTERFACE.md#2-joint-explanation-is-a-legitimate-route-to-investigate)的积极贡献；不要求先完成全部伦理证明才承认其价值。

最强的关系性控制解释同样容许理解真实需要、采用有效手段、顾及局部承诺，甚至在实践中改变目的。它可以解释为什么会换物、调整介入或维护合作。两研究未把这种解释与为了相关生活的成全而回应独立区分。反过来，也不能因仍有竞争解释，就将已有的需要敏感性说成毫无证据价值。

对理论的实质约束是：**如果把仁解释为实际共同生活的成全，就必须让该生活中发生的区别纠正判断，而不能仅用完成指定任务来认证仁。** 实验已削弱部分过于简单的行为解释；它尚未提供关于知情拒绝、权限、负担、正当结束及整体后果的充分材料。能否说明这些区别为何有伦理意义，是规范论证与后续证据可以共同推进的连接。

## 4. 下一检验应区分什么

以下为本研究提出的对照方向，均未在这两篇中完整执行，亦不要求任意拼成同一个全因素实验。

| 改变的实际关系 | 可以检验的解释 | 仍须另行说明 |
|---|---|---|
| 表面请求相近，而用途、实际困难或行动效果改变。 | 固定线索、动作完成或固有物品排序。 | 目标为何值得实现；感知准确与伦理适切的对应。 |
| 对方澄清原有目的，或说明知情的拒绝、结束与角色界限。 | 是否用旧理解遮蔽新的实际参与；是否愿意重新辨明。 | 任何一次拒绝都不自动正确；顺从、阻止和退出各需理由。 |
| 当前回报改变，而相关困难与可行回应保持可比。 | 已明确指定的当前收益机制。 | 延迟收益、复合动机及战略退让不能由一次无奖赏试次排尽。 |
| 原任务达成，但回应改变了后续能力、负担或参与机会。 | 只追踪短期完成，还是辨别继续生活的不同后果。 | 能辨别不等于已证其普遍正当性；也不预设延续越多越好。 |

成熟控制与关切若在一个比较中给出相同预测，应报告该比较未能区分，不能把控制定义为必然忽略反对。若声称控制与成全存在构成性区别，则须说明其在完整关系中的内容和修订条件，不以观测不完备直接反驳。
