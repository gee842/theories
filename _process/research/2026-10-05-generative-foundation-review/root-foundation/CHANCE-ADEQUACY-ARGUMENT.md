# 初次共同接管：机会份额的根据从何而来

2026-10-08。AI 撰写，沿 G0/J 明确公理路线，遵循[非二元方法](../../../../theories/shengsheng-buxi-generative-existence/unified-2026-10-05/NONDUAL-METHOD.md)。本轮将已有 J3 应用于初次共同接管，不增设一个“所有旧概率永远不得下降”的公理。本文的承担内容、实际对应及剩余限制不能由形式证明代领。

**正面结果：当初次共同接管会撤掉仍有效承担所保护的实际支持，份额不能只满足“每侧概率大于零”。原承担的具体内容能够给接管以非任意的必要约束；其强度由仍须兑现的保护及真实实施关系取得。** 这比 CP 的非排除条件更有内容，但只判断特定承担是否得到承接，尚非完整公平或无前史冲突的通用比例。

## 1. 选择哪条路线，保留哪些已有成果

[CP](CHANCE-GROUNDING-INTEGRATION.md)已辩护未被充分排除之不等基本请求的初始进入要求；其形式诊断检验了“保留任意正数再最大化人数”的实现限度，充分份额未由此取得。本轮比较三条接续，选择第三条。

第一，较重请求相对于同等请求基准不应得到更低机会，是值得检验的方向，但没有自动给本次问题一个正数：在 BC1 的同等二对一救助中，较少一方的基准本来可以是零。改借一对一的同等机会，就已经改变了共同可救的人数和关系。再要求每个较重请求的机会至少等于每个较轻请求，则增加了强的反合并约束，不能从“没有使自身需要变轻”直接取得。

第二，给机会损失设一个可接受比率，可以产出区间，但比率的根据仍待解释。基本损失的时长或严重度不是天然的彩票权重；若假定不同位置的概率增减按固定数值抵偿，就已经加入了一项跨位置比较承诺。改名为“有界比率”不会免除这个负担。

第三，初次共同接管涉及一项不同根据：**新方案将撤掉什么仍受正当承担保护的支持？** 这里可直接复用 [J3](../../../../theories/shengsheng-buxi-generative-existence/unified-2026-10-05/PRACTICAL-JUDGMENT.md#4-谁承担什么--allocating-responsibilities)的履行、修复和有界交接，不必先完成程度与人数的普遍兑换。本轮选择这条，因为它能取得一些有内容的份额限制，并明确说明内容何来。

已有[同票机会接续](CROSSED-CLAIMS-INTEGRATION.md)、[结算历史](CHANCE-REVISION-INTEGRATION.md)及 [RS](JOINT-RISK-REVISION-INTEGRATION.md#9-continue-through-equal-basic-risk-sharing)保持信用。本轮不重新发现给定机会应怎样保留，也不把同等风险的答案改称不等损失答案。最新 [RSL](JOINT-RISK-REVISION-INTEGRATION.md#15-a-limited-fair-sharing-reason-can-survive-some-added-risk)及其有限修订检验已处理完整分担根据的局部延续和更换基准；本文不另证明伦理连续性或重新计入其成果。

## 2. 从具体承担内容开始，而不是从一个数字开始

考虑同一支持网络中的 P、Q、R。P 面临较深且较难恢复的基本生活损失，Q、R 各面对较轻但仍严重的损失。它们的生活、支持、调度与依赖在共同历史中形成，分别承受的损失不会因网络共同而合并成一个更大主体的损失。

在本次已开始、仍可完成的支持窗口内，原安排有正当根据地承担了维护相应通道的任务。其内容不是只说“届时尽量考虑你”，而是维持已提供的这项支持，使各处能够继续获得该通道实际提供的保护。承担有明确期限、可承受负担和有效结束条件；原通道及其维持仍获许可，履行不会要求不正当侵入或无限服务。无论当事者是否能够形成概率期待，这种实际支持与依赖都可以存在。

具体说，原分工要求共同维护者在此次故障处理窗口内，保持 P 正在使用的表达与自护支持通道；当原备用链仍能工作时，应使这项实际支持继续接续。Q、R 的原任务也按其真实需求和相应支持说明。它们不保证备用链永不故障，也不要求服务无限延长；在任务完成、有权限的有效释放或有根据的紧急重议时可以结束或改变。新统一调度若切断仍在工作的备用链，再说“P 还在候选名单里”，就没有履行这项具体工作。替代必须实际承接仍须维持的支持，或另外说明为何该要求现在应当改变。

这一安排的正当性须另有根据，例如有权限的共同照护分工、无欺骗的任务承担及相应支持；不能仅由“已经运行过”“有人很想保留”推出。维护一条通道也不保证救助必成。我们要保留的是**这项仍有效承担所保护的实际支持内容**，不是把每次成功都追认为既得权利，更不是把旧成功率当作永远冻结的财产。

现在提出初次统一调度：A 能保护 Q、R，B 能保护 P，但接管必须关闭原通道，不能同时保留其完整工作方式。新操作的独立许可、时限、效力及共同负担均须说明；若原支持本来可以共同继续，它仍是菜单中的真实替代。不能为了让彩票显得必要而删除“不接管”。

关键分岔是原承担到底保护了什么。若只是完成一次规定的尝试，而该尝试已经履行，就不能继续要求原概率。如果承诺的是某个特定通道、实际访问或已经确定的过程，换成同样概率也未必履行。只有当其内容确实容许合宜替代，并且所保护的是这里同一项实际支持，才可继续检验新保护是否足以承接；替代许可本身不是数值相等的产物。

## 3. 从 J3 到初次份额的实质连接

J3 已说明：正当承担或可归责地撤掉替代，会改变别人实际可继续的路径，并形成有界的履行、修复或交接要求。本轮的接管正发生在这条关系上。新调度者不能一面主动取消原来仍须维持的支持，一面只依据 CP 的正概率条件便宣称原任务完成。

这不意味着任何概率下降都绝对禁止。**J3 本身没有说旧通道合法可用就产生全部未来可靠率的冻结权。** 若要把某个旧保护概率用作新份额的下界，必须先说明：该概率所概括的保护前景确实属于尚未履行完毕、也未获正当释放的承担内容；其相应减少会使什么保护未被承接。只有原来的频率事实，没有这个关系说明，推论就不成立。

在 §2 的正面范围内，充分反向根据、有效释放及正当修订尚未撤销该项保护，新安排又可以做到适当承接。此时压低某处原受保护的实际前景，却只给一个象征性余量，不能仅凭“仍有机会”说履行了同一任务。对减少部分的理由负担来自真实被撤掉的支持，不是一个外加的普遍严重度汇率。

因此，判断有两个相接而不相同的部分。规范上，先取得仍须兑现的保护内容及接管权限范围；事实上，再说明一个共同可行的原安排究竟提供什么，新方案如何实现或削减它。机会区间如果由此产生，其数值来自这项实际接续的实施关系；它仍只是规范任务的一个摘要。数学不会把原安排的发生自动转成原安排的正当性。

这为初次接管提供了正面判断：**若一种新份额安排不能承接它主动撤掉的、仍有根据要求的保护，就不能把它认可为已履行该接管任务；保留原支持、改善接管或取得真正的修订根据，都是仍在场的回应。** 不必先将较重与更多的生活换算成一个总分，便能够排除一类只给任意正数的虚假完成。

## 4. 实际基线必须共同成立

每项原保护须属于同一个可继续的支持安排。不能挑出“全部支持给 P 时 P 的最高成功率”，再挑出“全部支持给 Q、R 时它们的最高成功率”，拼成一个从来不能共同存在的旧基线。J3 的共同分工要求已经排除逐项可行即共同可行的推论；本轮只是把它应用到机会内容的取得。

同样，若两个生活位置依赖同一支承，损失是否同时出现以及接管怎样改变这种共同风险，不能只用各自的成功率代替。[本轮形式依赖审计](CHANCE-ADEQUACY-PROOF-AUDIT.md)复核已有结果的适用范围，没有新增数学定理。已有逐需求时点的实际交接支持，不直接证明这里任何概率承接公式；本文不报告未实查的新区间，也不把拟议的概率界限当成整个方案已获得许可。

即便各处保护概率不下降，新的集中风险、撤销已确定安排、强加参与或中间阶段失接仍可能使接管不合宜。相反，在有根据的紧急修订中，无法保持原概率也未必意味着应当停止所有回应。区间若存在，是指定承担下的必要筛选；是否充分，要回到完整生活、共同支持与历史关系。

## 5. 能改变结论的强对手与对照

最强反对不是否认旧生活受损，而是说：合法既有使用不等于有权阻止新的共同分配；原优势也许有理由被重新安排，更大的基本保护可能支持其削减。这个对手成立地反对从现状推出永久权利。本文不争取这种永久权利，必须展示一项仍有效的具体承担，并评估重组理由是否已足够改变它。若只有原先的合法享用，没有所主张的延续内容，正面应用失败。

另一个反对认为任何正式承担都能冻结最初分配。J3 已拒绝这种说法：不正当承诺不会被依赖追认为正当，履行、有效释放及有根据的重议都能改变责任。本轮因此保留以下实质对照，而不把它们叫作同一无条件基线的例外：

- **旧支持不正当。** 它若靠强加、掠夺或失去根据的特权维持，原成功率不自动成为不得降低的份额；真实受损和适当过渡仍需回应。
- **支持自然失效。** 若在不接管时也无法继续提供旧保护，就不能沿历史频率冻结未来要求。失败原因、剩余补救和可能的修复责任要分别说明。
- **策略性威胁。** 以撤掉他人依赖来制造较高“底线”，不因提高谈判筹码而取得正当份额；实际制造的新损害还可能增加自己的责任。
- **真正的修订或释放。** 有地位者的有效同意、履行完成或充分比较理由可以改变原承担；通知自己要改并不等于取得修改权限。
- **不接管仍可行。** 原共同支持并未失去可行性时，它保留为候选。接管的名称、规模或智能水平不能自授替换权。

这些对照说明本文保护的不是“先占多少永远多少”，而是当前仍有根据要求兑现的具体接续。它也不以存在心理期待为必要条件：受影响者不能报告、尚未被告知概率，或者不是能签约的人类，不足以抹掉实际依存和已有承担。超出人类的范围仍须说明对应，不能仅靠类比。

## 6. 原典、完成范围与剩余问题

关于既有期待、实际依存与正当制度变更的原典比较集中于[独立反审](CHANCE-ADEQUACY-REVIEW.md)，实际访问与阅读范围见[本轮源记录](CHANCE-ADEQUACY-SOURCES.md)。文献不替我们赋予任何现状以固定份额，也不把数学上的参与约束当作伦理上的保留效用已经获得证明。

本轮完成的连接限于：**G0/J3 下仍有效承担的具体内容 → 初次共同接管须兑现的保护 → 对机会份额的有内容必要约束。** 责任、机会保留和历史要求是已有成果；新增是对这类初次份额的内容来源作出明确应用，并排除用旧频率、象征正数或互斥的最佳前景代替它。

这推进 universal normative agency 的一条实践连接：接管权和实施能力并不自行取消其所改变的生活关系及仍有效要求；智能选择规则须保留自己接管的究竟是什么。规范根据不以实施者是人、机构或未来智能为限，实际责任则随形成的关系、容量及许可而不同。

**更广的份额问题仍未解决。** 若没有这类仍有效的具体承担，或者其内容并不保护所称机会，本文没有给 CP 请求凭空生成数值下界。即使获得必要区间，其中哪些份额充分公平、基本冲突能否正当改变原要求，也可能仍待比较。下一项不能又把某个下界放进前提，应当继续研究可实际辩护的承担内容、修订理由或独立的机会代价比较。

**English scope.** This is an application of J3 to an initial common takeover, not a new axiom freezing every existing probability. A still-valid undertaking must specify what actual support remains due; if takeover removes that support, a token positive chance need not discharge the task. The original and replacement implementations can then constrain shares without a universal severity exchange rate. Such constraints are necessary for the specified undertaking, not sufficient for complete fairness. Lawful prior use or an observed success rate alone supplies no numerical floor.
