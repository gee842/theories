# 从构造应用到真实资料：共同厨房的参与条件与判断修正

**本轮后续校准：** [有限资料的精确范围与评价修订](SITUATED-KITCHEN-PARTIAL-INFORMATION.md)补出配对样本的肯定界限，新增7项 Lean 定理／12项声明审计：至少5份记录进入食品安全分级，离开者份数仍未辨明；原文的统计、因果及伦理范围保持不变。下文“无新定理”指首次资料接续轮。

2026年10月8日。AI 撰写，落实 Ren 在共享厨房构造校准之后的“请继续”。承接[原应用](../history/root-foundation/SITUATED-KITCHEN-CALIBRATION.md)，复用 G0、公开 J1–J4 与真实对应 E。本轮新增的是**公开原始研究约束下的应用修正**：核读一个实际项目的完整研究及另一项社区样本研究的原始摘要，复核已公布的汇总数据，明确改变方案的哪些部分。没有新现场干预、个体资料重分析或数学定理。

**当前结论：支持实际形成的供给、理解、收入和共同生活，同时把能够参与这些活动的时间、照看、取用与支持关系纳入安排。留存者的收益不能替代退出者及未进入者的处境。对现有材料，合适的回应是有根据地保留并调整，而非把培训、参与率或组织存续单独当作整体改善的认证。**

## 1. 原始证据及其范围

### E1：黎巴嫩两个厨房的 HKHC 项目

[Sahyoun 等，2019](https://link.springer.com/article/10.1186/s12889-019-7950-3)评估在两个巴勒斯坦难民营中，将厨房改造、在岗学习、有补偿的轮值劳动、学校销售渠道及儿童照看组合起来的项目。研究为八个月前后测加期末访谈，无未接受项目的对照组。本文读取完整正文与两张表；[原始 XML、许可、读取范围和哈希](../../../../sources/community-kitchen-evidence/README.md)均已保存。

参与者报告了技能、共同协作、收入及相处方面的收益。与此同时，时间投入影响了首周留存；留存者原有社会支持高于退出者。量表与访谈回答的内容并不完全相同，不能互相删掉。研究未测家庭实际食物消费，也不能单独确定培训、收入或其他组成部分的因果效应。机构后来经营餐饮的描述，不等于长期个体收益或无外部支持接续已经验证。

以下数据直接来自原文 Results 各节及 Table 2；比率只作描述性核算，原文显著性标签未经本轮重做检验：

| 项目 | 已报告数据 | 校准意义 |
|---|---|---|
| 样本流程 | 初始51人；首周退出18人；另1人缺期末问卷；32人完整前后测。 | 18/51＝35.3%；32/51＝62.7%。不能只用32人描述全部51人的体验。 |
| 食品安全分级人数 | 基线安全／中度不安全／重度不安全：14／12／6；期末19／8／5。 | 两次都合计32。期末仍有13户中度或重度不安全；分类的原文检验均为 NS。 |
| 食品不安全评分 AFFSS | 中位数4降至2，原文 p＝0.006。 | 评分变化与分类检验分开；不能以一个显著结果替换全部指标。 |
| 心理健康 MHI-5 | 21人的得分提高，11人降低；总体变化为 NS。 | 保留异质变化；下降不能未经对照就归因为厨房损害。 |
| 社会支持 DSSI | 两次中位数均为24，原文 NS。 | 访谈中的相处收益有其具体内容，不能改写为量表已显著改善。 |
| 重大支出的单独决定 | 3/32至13/32，原文 p＝0.038。 | 仅指该调查项目，不等于所有生活决定权全面改变。 |

同样重要的是：18户到13户是汇总净变化，不能认定恰有五户个人由不安全转为安全，更不能认定项目“治好了五户”。没有公开的成对状态表就不构造这些转移。原文把19/32写为59.3%，常规一位小数为59.4%；本轮保留原始字节和人数，不将小数误差夸大为结果失效。正文总家庭开支的13%变化与表内人均开支中位数属于不同统计对象，不能互算或合并。完整提取见[可重跑记录](../../../../experiments/integrated-correction/general-framework/generative-basis/situated-kitchen-evidence/published-evidence-checks.json)。

### E2：社区样本中的未参加者

[Loopstra 与 Tarasuk，2013](https://link.springer.com/article/10.1007/BF03405655)的原始摘要报告：485个家庭的基线样本中，371个家庭完成一年后访问，仅16个报告参与社区厨房；不参加的理由涉及可及性及活动与日程、兴趣和需要不适合。这里的16/371约为4.3%，是随访社区样本中的使用情况，不能与 E1 已表达兴趣者的留存率相加、平均或直接比较。

本轮只核读摘要及书目信息，没有读取其完整方法、编码或亚组结果。它足以提示本例应纳入未进入者，但不能证明所有不参与都由排斥造成，亦不能证明某个具体厨房无益。两篇论文的样本、年代及社会条件不同，不将它们拼成一个共同项目的前后历史。

## 2. 哪些具体判断得到支持，哪些必须改写

**得到支持的正面连接：** 工作、食物、理解、友谊与可支配条件可以在同一共同实践中相互形成。E1 的描述使原构造中的“供给＋学习”有了更具体的实现方式：场所、收入来源、销售关系、轮值和儿童照看共同参与，既有技能及生活经历也参与新组织的形成。这提供真实对应线索；无对照的研究不能认证每项因果贡献，更不能独自证明 G0/J1–J4。

**必须修正的情境边界：** 原例容易把已进入厨房的人当作需要判断的全部范围。现在至少区分有兴趣但无法继续、从未进入、参与而仍有未满足需要，以及正在供给或承受其他负担的位置。区别来自实际参与历史，均可变化；它们不是固定的主体类别。一个活动可以对部分生活有真实好处，同时对另外一些生活尚不可及。

**必须修正的损失描述：** 不能将所有投入时间都记为失去“自由晚上”。共同劳动本身也可能是相处、理解、愉悦与自我实现；相同工时在不同历史中并不同义。反过来，愉快相处并不抹除另处照护或休息的损失。原 Lean 投影为明确限定的时间取舍仍然有效；它没有为现实劳动的意义作完整编码。

**必须修正的认识推断：** 不参加或退出，不能直接读成不愿共同生活、缺乏成长意愿或已经有更好替代。研究者称作动机的指标也须保留操作定义，不能扩展成伦理资格。需要直接辨明时间、照看、可及性与实际选择。相应地，高留存也不独自认证参与自由；低留存也不独自证明活动有害。

## 3. 据此作出的下一步应用决定

下面是依据历史证据，对原构造安排所作的修订建议，不是对2019年项目现状的命令或一次已经执行的现场决定。

| 待决安排 | 本轮采取的判断 | 根据及会使其改变的条件 |
|---|---|---|
| 是否用教学替换当前已成立的食物支持 | 继续保留直接支持路径，将自愿学习作为并行可能。 | 技能与收入、取用、时间均相关，现有资料不支持“学会即可撤供”。具体替代已经及时可靠时，才重议原供给。 |
| 是否照搬一套轮值与培训时间 | 把儿童照看、交通／取用、完整任务及可选择时段纳入同一方案，再邀请具体承担。 | 这些不是参与者个人应自行解决的剩余项。需要及效用有根据时，可减少门槛；不能未经证据宣布某项补助必然有效。 |
| 已进入者反映获得收入、理解与相处，是否应停止项目以等待完备证明 | 可在原有权限、有限承担和持续可行性有根据时保留这些活动，同时修正未经支持的整体成效声称。 | 没有对照不抹除具体经历，也不证明相对其他安排最优；确切危害、无效或更好替代可以改变决定。 |
| 如何评估下一轮 | 同时记录所声称的收益、未解决的需要、负担变化及参与路径；为愿意回应的退出者／未进入者保留低负担表达渠道。 | 不将“提升参加率”设为必须实现的目标；有根据的不参加本身可以是合宜结果。缺失资料明确保留，不推为零损失。 |
| 是否可以据此扩大或宣布独立接续 | 不以培训完成、留存者均值或机构仍运作单独认证扩张及交接。 | 要另查需求、支持来源、接受的承担、真实能力与窗口；保留无法继续时的有界通知、过渡及结束。 |

这里没有从“资料不完备”推出停住，也没有凭某个平均改善授予全面推广权。G0 给实际生活和共同形成以正面意义；J3/J4 支持有范围地继续、分工及修正。J2 的强比较仍要求具体基本条件及其他基本保护确获说明：AFFSS、MHI-5 或 DSSI 的某个分数不会自动变成该规范分类。本轮没有给这种转换虚构阈值。

## 4. 对原两周安排的四项实际修订

1. **将共同实践的内容写清。** 逐项说明供给、理解、相处、收入或可用条件中哪些是本次真正目标，哪些只是希望产生的后果。时间投入同时记录其实现与被挤占活动，避免一律计为损耗。
2. **把参与条件放进分工。** 邀请承担之前核对照看、取用与其他任务；若有可行调整，参与者可以选择。不同生活路径不必全部收敛到厨房培训，已成立支持也不以进入学习为交换条件。
3. **区分四种证据。** 出勤／完成记录说明发生了什么；具体经历说明怎样被体验；功能核查说明什么实际可做；前后量表说明其指定范围内的变化。它们可能相容也可能相互挑战，不用一个综合“成功分”替代。
4. **明确保留与撤回的范围。** 保留有根据的具体活动，撤回未经支持的普遍成效或因果声称；遇到基本保护受损、承接失败或参与条件改变时，重排、减量、替代或合宜结束。没有要求等待全部学术争论解决才能回应眼前生活。

## 5. 实质反审

**原研究没有对照，你仍然说保留是否过强？** 保留是对具体安排在已有权限、承担与可行性成立时的有条件实践判断，另有 G0/J3/J4 的根据；并非由显著性推出的因果认证。证据可以支持某种活动值得继续了解或有理由有限继续，而不足以支持替代所有既有支持。实际决定仍须核对该场域，不能从文献直接指派劳动。

**退出就是自由选择，何必把他们纳入？** 自由退出的意义得到保留；但不能未查便把时间与照看障碍解释为知情偏好。核查的目的在于理解并修正活动的可及条件，不是提高留存率或把退出者拉回来。能够从容不参加也可以是支持生活的结果。

**量表不显著，是否应删掉共同相处的好处？** 不显著不足以证明零效应；访谈也不能因此升级为显著量表改善。两者所问内容、时间和测量范围不同。当前证据保留经历与未解差异；不能靠新取一个“整体更好”名称来消除它们。

**将工资、托育、学校纳入后，是否还能说是厨房的效果？** 不能把整个组合的变化归给烹饪或学习一个环节。本轮改以共同安排的具体组成和后续关系作为应用单位。标准项目评价同样可以保留这种内容，本理论没有因此获得独有经验优势。

**平均改善是否足以适用 J2？** 不足。某些家庭的改善和另一些位置的未满足可以并存，基本条件也不能由量表直接兑换。J2 所需的完整包含前提在这些汇总资料中没有被建立，因此这轮输出以有界保留、调整和定向核查为主，未宣布所有相关生活的严格改善。

## 6. 此轮完成什么，怎样进入下一次判断

本轮完成两项新的实际约束：**把未进入及退出的生活纳入应用范围；把学习产生作用所需的共同条件与学习本身一起检查。** 原九项 Lean 结果及其形式范围保留，没有新数学主张需包装为又一组证明。八行原始表格、样本流程与汇总人数已由[脚本](../../../../experiments/integrated-correction/general-framework/generative-basis/situated-kitchen-evidence/check_published.py)核对，不能称为个体统计复现或新实验。审查为作者实质反审，没有独立 agent 验收。

这是对 E 的真实资料约束与应用方案修正，尚未完成 Ren 某个实际项目的现场校准。下一次进入具体场域时，优先取得能改变上述安排的材料：完整负担、不能参与的具体关系、所称能力的实际可用性，以及承接窗口。对这些已查明后，才有根据决定保留、调整或结束哪一项活动；不再重复一般实践公理的已完成论证。

对更广的智能判断，这一应用检验的是：当评价只看留下来的记录与单项成功时，如何重新把产生这些记录的参与条件、遗漏和未满足带入理由。这个教训来自实际对应问题，既不把统计选择效应宣称为新的普遍定理，也不把所有未观察到的后果都当作灾难。
