## 1. The positive connection and its limit

The finite-domain result addresses a real part of the whole-family question. One target-independent finite construction covers all predicates on an independently supplied finite carrier. Empty formation, singleton formation and finite combination then suffice for full admission. The construction does not simply receive a separate target-dependent family for every predicate.

The recursive finite-type proof strengthens that result: the same finite argument applies at each declared function or predicate type over a finite base. This is a genuine removal of an infinitary closure premise at those scopes. It does not derive the base carrier, the finite formation operations or classical logical interpretation from the root without assumptions.

A whole generative account can explain the relevant distinctions and formation operations within one process. This supports a relative route to finite admission. The theorem alone does not establish that every differentiated organization supplies all singleton distinctions or every combination required by the model. Those are exact formation commitments to justify in an application.

## 2. The infinite-domain inference remains unsupported

The finite result cannot be extrapolated merely by allowing more and more finite stages. The earlier [assembly theorem](ROOT-MATHEMATICAL-ASSEMBLY-LEAN.md) shows that, on `Nat`, finite admission plus every increasing finite-chain union already has full predicate strength. The new `nat_not_finite` also directly prevents using the finite-carrier theorem there.

This is not a universal impossibility result. It states where the new proof applies and where the previously identified whole-family warrant remains needed. Neither reusing full ambient function spaces nor quantifying over all model interpretations independently explains their availability.

## 3. What the signature extension actually closes

The earlier language could use free parameters but had no general theorem for named symbols and whole theories. The new module removes that representational omission. Symbol compatibility is stated at the type-map level; truth preservation is proved, not built into the compatibility condition. Backward interpretation ensures the semantic consequence and satisfiability results cover every model of the completed presentation in the declared model class.

The type grammar, supplied base and full-domain interpretation remain the semantic resources. Arbitrary theories expressed in this grammar are covered; an assertion that every mathematical subject has already been faithfully expressed in it is not. In particular, no dependent-type translation, internal-universe semantics, foundation-wide coding theorem or root-derived base-domain construction is part of this package. No set-theoretic model is inferred merely because a signature can name a membership relation.

The Boolean symbol-mismatch example is a boundary of an omitted correspondence premise. Since it changes the symbols' interpreted relation, it is not the matched rival required for a criticism of the fuller generative account.
