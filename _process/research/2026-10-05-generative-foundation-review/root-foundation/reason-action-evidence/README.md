# Public evidence access and derived reading table

6 October 2026. Source: Gerber, Schweinfurth and Taborsky (2020), *The smell of cooperation*, [article](https://pmc.ncbi.nlm.nih.gov/articles/PMC7739497/) and [Dryad dataset](https://datadryad.org/dataset/doi:10.5061/dryad.h18931zjd), version 93077. The public API identifies the dataset license as CC0. This directory preserves API metadata and a derived reading edition, not downloaded original experimental CSV bytes.

`metadata-receipt.json` records the exact public API requests and hashes of the three saved JSON responses. The manifest lists four experimental CSV files and a readme. Direct website downloads returned HTTP 403, and the API download endpoint returned HTTP 401. No authentication or access control was bypassed. Public browser preview is separately available.

`experiment4-preview.tsv` transcribes the public HTML table shown by **Preview experiment4.csv**, read on 6 October 2026. Its 48 numbered rows each have ten cells and cover 24 focal-rat identifiers in both displayed treatments. The otherwise blank first header is renamed `preview_row`; the other headers and cell strings are retained. This conversion has its own hash. It is not asserted to match the original CSV's manifest hash or bytes. Original experiment4.csv is listed as 2,348 bytes, SHA256 `5875db96822a78ce91708f8cb385b4941ecf689d6bfa999177e02a3aebdfab29`.

Experiment3's preview was visibly truncated in row 74. It cannot support a claim to have inspected that whole dataset. Its partial table is not substituted for the complete experiment or combined with experiment4. The downloadable readme was unavailable through the attempted public routes; column interpretation must be checked against the article, and `NA` and the 420-second observation boundary must remain explicit.

The associated [source audit](../REASON-ACTION-EMPIRICAL-CANDIDATES.md) describes the experimental manipulations and limits. No new experiment or inferential replication is reported. Any descriptive calculation on this preview is retrospective: both the published findings and table were seen first. The bounded check reports only table integrity, paired treatment coverage, raw pull totals and paired differences; its reproducible receipt is `preview-check.json`. The preview has 24 paired focal identifiers while the published experiment4 analysis reports n=23; that discrepancy is unresolved and no exclusion is invented. No fitted mechanism, p-value, welfare estimate or energetic-cost conversion is authorized by those quantities alone.

A separate collaborating agent independently recalculated the TSV in JavaScript without using `check_preview.py`. It confirmed 21/53 total pulls, a paired mean difference of 4/3, 17 increases, four decreases, three ties and two `NA` cells confined to `Pull6`. It also matched saved API byte counts/hashes and the table/checker receipts. The article's Methods itself says n=24 while Results says n=23. This is an internal independent arithmetic/provenance review. The historical DOM snapshot was not separately preserved; matching its recorded fingerprint establishes transcription consistency, not independent authentication of that extraction or the original CSV.
