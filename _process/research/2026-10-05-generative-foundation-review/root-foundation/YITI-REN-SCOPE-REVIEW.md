# 活动范围形成：前提与结论的独立审查

2026年10月6日。AI 撰写的内部协作审查。作者参与本轮准入条件和对照设计；独立指阅读与推理分工，不是盲测、外部同行评议或新经验复现。遵循[非二元方法](../../../../theories/becoming/chapters/NONDUAL-METHOD.md)。本文件只审查本轮新连接，保留[上一轮判据审查](YITI-REN-CRITERION-REVIEW.md)的冻结结果。

## 1. 固定被替代的输入与准入条件

上一轮在给定维护方向下取得修复通道，并用它改变完成判据；`later_repair` 仍由配置指定。[本轮规范论证](YITI-REN-SCOPE-GROUNDING.md)不将去掉这个变量等同于去掉方向的全部来源。必须检查三个不同问题：实际后续反应是否在同一材料历史中形成；判断是否取得并使用其改变；这个反应为何值得继续或有权结束是否也得到解释。

当前接受的设计要求是：从同一实际形成史承接支持与学习记录；真实部件形成甲乙两项耦合；甲的已发生反应本身留下依赖，不能另外宣布未来会损伤来制造该依赖；完成甲与解离甲不同，且都不能抹除已有消耗、损伤或乙的继续；接触取得实际阶段，之后有带消耗的使用。范围扩大不是预先认定的好结果，去掉已失效的甲处修复也可能是本轮成功。

## 2. 必须保留的错误与竞争解释

| 检验 | 接受的辨别 | 不能宣称 |
|---|---|---|
| 甲结束而乙继续 | 删除或完成甲没有全局结束乙 | 一次不再响应就证明所有关切已经完成 |
| 完成甲与解离甲 | 都可不再待反应，但产品及发生史不同 | 解离就是完成，或一切解离都不正当 |
| 已完成甲但损伤仍在 | 相同损伤未必仍与当前反应相关 | 损伤已不存在，或一切修复都没有价值 |
| 错误、缺失、过期的阶段接触 | 实际关系与取得内容分离，后续作用可错 | 取得必然正确，分析者知道等于内部知道 |
| 保留记录而钳制读者 | 记录存在与起操作性作用不同 | 一条成功路径说明所有调度可靠 |
| 原生支持不可恢复的失败 | 学习与范围修订不创造支持 | 把另一条历史的余量移入当前历史 |

一个诚实的较弱解释是：给定装配、反应及读者规律，在材料内形成不同待反应关系，再由取得的阶段选择不同操作。这是真实机制进展；它同时说明，较大的组织方向与用途仍可以由设计者供给。不能把这个竞争解释叫作否认生成，也不能只凭删除配置项反驳它。

## 3. 前提账目必须保留的位置

| 关系 | 本轮可能替代的直接输入 | 仍须公开的来源 |
|---|---|---|
| 当前活动范围 | 直接给定是否需要后来修复 | 活动装配及分阶段反应律、所取阶段族、调度和入口历史 |
| 对范围的判断 | 对真实范围的免费全局读取 | 接触配方、阶段编码、记录及使用条件、错误模式 |
| 对修复通道的认识 | 预填通道名称 | 上轮实际取得记录、其有限候选族及取得机制 |
| 继续与停止的选择 | 个别预填正确动作 | 优先规则、材料可行性、目标使用方式及新增操作的成本 |
| 何为正当回应 | 没有被材料反应替代 | 具体生活关系的识别、根据及权限、真实拒绝和冲突 |
| 形式证明 | 没有被空公理报告替代 | 定义、类型及事件律、定理条件、标准逻辑依赖与实现对应 |

“仍输入”指本地解释的边界，不说明它在生成现实之外。进一步追问其形成时，应明确追踪哪条关系，而不是笼统宣告所有结果依赖假设所以毫无进展。反过来，将输入写进初始状态、数据结构或函数定义，也不会仅因定理签名更短而消除它。

## 5. 冻结原生实现的源码与结果审查

已完整读取[实现](../../../../experiments/shared-renewal-capability/regulation/retention/formation/learning-interface/recording/continuing-dependency/scope.py)、[前置协议](../../../../experiments/shared-renewal-capability/regulation/retention/formation/learning-interface/recording/continuing-dependency/SCOPE-PROTOCOL.md)、[机制说明](../../../../experiments/shared-renewal-capability/regulation/retention/formation/learning-interface/recording/continuing-dependency/SCOPE.md)，并解析[保存结果](../../../../experiments/shared-renewal-capability/regulation/retention/formation/learning-interface/recording/continuing-dependency/scope-results.json)。九个分支共2,920个新增事件，每状态36坐标；共同前史为94个原生事件和22个旧判据训练事件。结果文件的14项来源哈希均与本次读取一致。此项校核没有运行生产转换，也不是逐步重构的替代。

源码检查支持以下具体结论：

- 新 `Config` 只有接触模式与读者钳制，不含 `later_repair`。旧参数只在训练前史固定为假；该前史取得 common 通道记录，旧 `criterionActive` 为假。新选择器不读取该旧激活位，不借旧宽范围判据工作。
- 新 `selection` 读取实际保存的相位记录或快照、既得通道记录，以及明示给定的当前支持反馈，不读取活动真实相位。真实相位进入收费接触和物理反应的准入条件。末端 `actual_pending` 只用于审计，不被选择器调用。
- 完成相位3与解离相位4、对应记录4与5保持区别。解离返还部件但不生产产品；已有损伤、消耗和乙的反应不被清除。产物保持不是根据“已无待反应”反推出来的。
- 完成忠实分支与完成钳制分支在选择前36个坐标逐项相同，包含真实新记录。钳制分支后续真实修复与捕获，最终再次完成甲的事件被物理条件拒绝；它并未在拒绝后自动修正记录或换去完成乙。
- 源耗尽时，甲在实际与取得范围中仍为未完；选择乙没有把甲判成完成。反过来，末端实际完成的乙仍有 primed 旧记录，未虚构一个免费终点取得。

有两项精确限度必须保留。当前支持量及可行性反馈仍给定，不能将它与相位取得一并称作自发发现。取得范围的定义包括 formed 与 primed，但该选择器只执行 primed 的继续策略，不能据此宣称它会自主开启一切已形成活动或解决所有冲突。A 的先行优先、固定计划菜单及分支调度也没有被生成或正当化。

**接受：源码及保存结果与所宣告的条件机制、错误对照及范围一致。** 后续独立重构及形式验收分别记录于下。

## 7. 新形式构建的最终验收

已读最终[AcquiredActivityScope.lean](../../../../experiments/integrated-correction/general-framework/generative-basis/noninstrumental-concern/AcquiredActivityScope.lean)及[核验器](../../../../experiments/integrated-correction/general-framework/generative-basis/noninstrumental-concern/check_scope.py)，并逐模块重解析[成功回执](../../../../experiments/integrated-correction/general-framework/generative-basis/noninstrumental-concern/scope-verification.json)所绑定的审计日志。五模块全部通过，共106项审计；其中新增14项源码声明、12项生成对应，另80项为继承审计。新增26项中只有旧激活位不影响选择的等式报告空逻辑依赖，其余依赖具名标准项，并集为 `propext`、`Quot.sound`、`Classical.choice`。没有无假设或全部空依赖宣称。

最终接受的证明内容是：

- 旧训练有实际路径，继承的激活位不是新选择输入；实际甲初次反应留下受损、局部支持为空的继续状态，直接成品与原生捕获都因此受阻。
- 在所定义过程的任意获准历史中，旧历史完成记录及已形成产品保持。原生投影一般定理直接针对 `.plant e` 事件；`.act` 所执行原生事件在实际有限对应中受检，没有冒称已证明任意 Python 执行的通用精化。
- 若共同支持已经为零且乙仍在已启动的中间阶段（phase 2），所有获准后继历史都保留这两个事实。因此在这份规律内，乙既不能再成品，也不能免费解离；这比“当前选中的计划没完成乙”更强。添加补给或新的解离律会改变定理所研究的过程。
- 九条保存历史的全部36坐标、2,920事件、2,929状态、四次拒绝，以及94事件祖先和22事件训练取得形式对应。另两条明示为 Lean-only 的富支持短历史在乙成品后真实接触，取得范围同为空，甲产品与甲解离却不同；它们不是九条 Python 分支，也没有改写耗尽终点。

`ending_A_preserves_B` 是原生字段保持性质，其可实行性由具体获准路径落实。通用历史／产品保持与零支持保持并不等于全部包装过程的全史守恒定理。反应配方、相位族、接触、有限计划、支持反馈、优先关系、起始状态和调度仍是所解释过程的输入。

本审查重新计算了最终模块与生成文件、五份日志、编译器、检查器及辅助文件、原生结果与14项原生来源的绑定，并核对日志声明与回执逐项相符，全部一致，无警告。成功目录为 `scope-checks/1791287626704976000/`；规范回执与该目录回执字节相同，其 SHA256 为 `fab218a73c7a57ca5e88093523339fab02f63b97f292290716971ceca28f7b3b`。本审查没有重新编译。
