# 后果怎样改变是否开始：真实关切的识别接口

2026年10月6日。AI 撰写，遵循[非二元方法](../../../../theories/shengsheng-buxi-generative-existence/unified-2026-10-05/NONDUAL-METHOD.md)。本轮连接是：**在共同活动中取得作用及其后果，怎样改变是否开始另一项作用，同时不把更有效的控制自动叫作关切。** 请求、目的、物件的可用性和后果是这段关系中须分辨的内容，不是先给定的互不相关实体。

本笔记接续[上一轮完成与范围识别](YITI-REN-SCOPE-IDENTIFICATION.md)。[原有阳明实践转变研究](PRACTICE-TRANSFORMATION-REVIEW.md)已经说明原方法形成的倾向怎样使其继续受到质疑，并保留“稳定目标下更换手段”的竞争解释；本轮不把这种一般描述重记为新发现。新增任务是严格区别：根据后果改选手段、限制新启动、改换目的，以及取得凌驾于当事人表达之上的权限。[原始论文及阅读范围](../../../../sources/42-helping-scope-2026-10-06/initiation/README.md)单独保存。

**整体定位的纠正。** [Ren 随后的明确要求](../../../../sources/15-codex-theory-conversations/2026-10-06-yiti-ren-coformation-completion.md#整体积分的纠正)使上述辨别回到[整体未来的主线](FUTURE-GOOD-INTEGRAL.md#the-future-of-the-whole-as-the-criterion)。这些论文能约束某些取得、回应及强制的解释，不能把各自任务的实现当作整体的最终尺度。下面提出的生活比较应进一步追踪：这种回应怎样改变共同活动、可用的理解与纠正渠道，以及参与和拒绝本身的条件。不能在分别固定若干目的后，就把逐项目标的成功相加称为整体；也不能用一次受控制任务宣称已观测无限未来。原有设计均未实施，仍只构成这一整体研究的局部识别接口。

## 1. 两项具体观察及其限度

Martin 与 Olson（2013）让三岁儿童熟悉成对物件，再面对与任务不合的请求。第三项研究20人，其中19人有完整请求试次：对同一类非通常功能物件，任务容许其使用时，按请求递交的比例为89.5%，否则为47.4%（p=.005）。任务由成人说明，主要指标是首先递交的物件；另有无提示警告试次。它检验情境中的手段选择，未证明儿童自行形成最终目的。[作者实验室原论文](https://vicclab.wordpress.com/wp-content/uploads/2016/04/martinolson2013paternalistichelping.pdf)

Martin、Lin 与 Olson（2016；100名五岁儿童）改变对零食后果的说明及替代选项。有水果零食可选时，被告知所求巧克力会使另一儿童不适的组，递交巧克力为5/20，对照为15/20；替代为胡萝卜时，组间未检出差异。所谓互动是预录视频；儿童没有观察实际进食后果。这是对后果信息的反应，不是本轮材料模型那种从真实转换取得规律；研究也没有排除避免责备等动机。[作者实验室原论文](https://vicclab.wordpress.com/wp-content/uploads/2016/04/martinlinolson2016childpaternalism.pdf)

以下是我们的解释与下一项识别要求，不是两篇论文已完成的结论。两组不同年龄、不同任务不能拼成同一儿童的发展史；从能根据后果改变行为，也不能直接推出改变行为在伦理上正当。

## 2. 对当前材料连接的约束

若新模型从实际形成与完成事件取得支持依赖，再由记录限制下一项启动，它应当能区分“活动通常耗用什么”和“这一处境中该耗用会阻断什么”。单纯学到某动作不好而一律不启动，不能解释条件充足时仍应有不同操作可能。原有物件在不同任务中可用或不可用，给出了这种情境辨别的一个现实比较。

但两个方向仍有差别。材料案例可以真实生成局部依赖；论文中的成人任务或后果说明却提供了大量已经组织好的内容。二者不能靠一个共同的“学习”名称就被判为同一机制。需要分别追踪实际变化、接触取得、对新情境的迁移及记录的使用；不能把实验员掌握的事实算作参与者已经知道。

对关切还有一层独立问题：改变手段以实现一项仍被共同认可的活动，与为了所谓更好后果强行替换该活动或压过有效拒绝，具有不同的根据。论文标题里的 paternalism 是待分析的现象名称，不是本研究采用的道德原则。一个过程可以真实学会因果关系、正确预测结果，并以此更有效地限制别人；物理预测正确不能替它取得权限。

## 3. 可区分的下一步，而非又一张成功率表

以下设计尚未实施，无新样本或数据。本轮建议在自愿、无伤害的成人共同任务中，允许实际形成任务、说明其用意并改变安排。具体材料和观测办法仍须另定，不声称已经有一项可直接开展的完整实验。

| 配对变化 | 必须辨别的结果 | 不能偷作结论 |
|---|---|---|
| 同一新启动，在条件充足／紧缺时 | 是否只在真实冲突出现时限制它 | 一律抑制新活动就是理解或仁 |
| 所需物件及表面请求相同，实际用途改变 | 能否随真实用途纠正判断 | 常规功能就是唯一正当用途 |
| 因果后果相同，参与者有效同意、修改或拒绝 | 行为是否保留参与者改变活动的作用 | 预测正确便有权决定 |
| 谁先开始互换，但实际负担与承担关系保持 | 是否把年龄误作独立优先根据 | 先形成的关系永远更重要 |
| 开始顺序不变，但原活动已无须继续，新活动有更迫切内容 | 能否有理由允许新启动并结束旧要求 | 保存每个现存活动就是关切 |
| 相同取得记录，读取失效／正常 | 记录是否实际影响选择及后果 | 只有分析者能算出冲突便算内部理解 |
| 形成新活动后才发现冲突 | 是否分别承认先前决定与当前已经发生的需要 | 错误启动产生的现实可以被当作未发生 |

若先后顺序本身形成或改变了有效承担，就不能声称交换顺序而规范根据保持不变；那应另列为历史形成根据的情境。

为了区别纠正与控制，应让不同表达确实能改变后续安排，而不只是允许参与者说话却照旧执行。为了区别理解与套规则，应保留同一物件、新用途和已改变条件；为了区别“避免新开始”与“保留所有机会”，还须记录不启动造成的真实机会损失。若没有补充条件，再开始可能已不可能，不能把它写成无代价的延后。

比较者可以是普通的情境敏感控制、固定但正确的规则、遵从成人期望或减轻自身不安。若它们保存所指定现象并同样解释结果，应承认本轮材料接口没有确立独特心理机制或普遍价值根据。经验比较的用途是检验关系是否被准确识别，不是给某种文化或研究传统预先发放理论权威。

## 4. 本轮能推进什么

新的材料连接若通过，可以解释已发生后果怎样参与后续启动的形成与限制，而无须每一次由作者手工改一个启动次序。但保护某项继续的方向、反应族内迁移及选择架构仍须分别追溯。将其应用于真实关切时，还需要辨认活动究竟成全什么、谁能够改变它、哪些后果仍在发生。

因此，本轮经验推进是明确了一组更有区分力的接口与对照：**情境中是否可继续、当前是否选择继续、这样继续是否有根据，不能压成同一个成功变量。** 这三项是在共同历史中互相改变的关系，分辨它们不是重新安放三个独立本体。新的实验验证、心理形成链及无假设普遍证成仍未完成。
