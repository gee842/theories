# 非工具性关切的根据：患者的实际坏与合宜回应的优点

2026年10月6日。AI 撰写的哲学论证与经验识别方案。本轮承接[已经提出并辩护的 C1/C2 候选](../../../../theories/shengsheng-buxi-generative-existence/unified-2026-10-05/UNIFIED-ETHICAL-GROUNDING.md)及[现有伦理最低限与有限救助论证](../../../../theories/shengsheng-buxi-generative-existence/unified-2026-10-05/UNIVERSAL-ETHICAL-MINIMUM.md)，不把它们记为本轮新发现。本轮独有工作是：细化患者—行动者—观察者的关系，说明“适当回应”的解释内容，比较其规范根据与动机机制，并提出接入共同生成过程后能够区分的经验问题。主要一手比较与阅读范围见[来源说明](NONINSTRUMENTAL-CONCERN-SOURCES.md)。这是构成性识别的进一步辩护，不是从纯因果规律推出伦理真理的证明。

## 1. 肯定的结论与所用前提

**在实际患者正承受严重、仍不愿承受的体验性负担，而某行动者有获许可、保持该患者并真正减轻负担的可行办法时，这种改善关系构成该办法的一项患者指向的道德优点。它可以说明行动者为什么值得去做，先于他把帮助设为自己的目标。**

这不是说“任何减轻都是必须的”，也不是说另一个中心的自保信号自动变成我必须服从的指令。被辩护的是一个较窄、但实质的前瞻判断：改善这个患者的真实处境，可以使一个尚未被采纳的选项已经有根据。它因而可以支持采纳，而不必等到采纳以后才取得全部规范内容。

前提与任务必须分开：

| 层次 | 本论证的内容 | 本轮地位 |
|---|---|---|
| 实现和患者识别 | 存在该患者及实际发生的体验；不能由一个负数、反射或报告标签直接认定 | 需独立证据的事实前提 |
| C1：患者局部坏 | 指定领域中的严重、整体上仍不愿承受的体验构成对患者的局部坏 | 沿用已有构成性候选，不由本轮模型产生 |
| 回应机会 | 行動者的可行手段能在许可范围内真实改善同一患者的处境 | 事实、反事实及权限前提，未定义为道德优点 |
| C2：回应的道德优点 | 这种负担与合宜改善关系构成行动者选项的一项患者指向优点 | 本文进一步辩护的实质伦理识别 |
| 总体判断和要求 | 竞争理由、权利、长期代价与实际替代安排如何决定该做什么 | 需要额外原则；既有有限救助结论保持其明示范围 |
| 取得与使用 | 行动者如何得到证据、形成动机、支付成本、选择并完成回应 | 需要实际机制；规范根据不自动提供机制 |

“局部坏”并不等于患者整个人生净坏。为手术、救亲人或其他善而接受痛苦，也不自动说明该痛苦本身已不再是负担；反过来，若同一体验被真正欣赏，改变了该体验整体对患者的地位，便不能直接套用干净领域的 C1。现有候选已经保留这个区别。

## 2. 为什么根据在实际患者处，而不只是观察者偏好

先固定一个存在实际患者的案例。让观察者离开，或让帮助者不再因见到痛苦而不适：患者的负担仍可持续。让观察者非常满意，而患者没有得到改善：解释目标仍未完成。这两项比较说明，被解释的不是观察者的快感、意见或赞许，而是另一个实际中心正在经历什么。它们支持患者识别和理由内容的定位，单独尚不证明跨主体的 C2。

规范问题接着是：**以患者为受益者的改善，为什么值得成为行动者的考虑，而不只是一个任意可选的观测指标？** 正向回答有三步。

第一，C1 已经识别的是患者实际的坏，而非某人碰巧希望改变的中性差异。若一个选项真正解除这件坏事，便存在由实际受益者解释的改善。回答“为何这个改变好”时，可以指向谁获益、原来的负担和改变后的处境，无须再指向观察者的愉悦。这里没有把所有欲望的满足都叫善，也没有把每个系统的维持都叫福利。

第二，能够产生这项改善的选项与患者形成现实的回应关系。患者的坏给出回应的方向；行动者的控制范围给出可由谁、以什么办法响应。先行角色不是产生实际关系的唯一方式：当前能够以恰当办法解除这次负担，本身已经是一种行动者—患者关系。它尚不建立承诺、照护职责或强制权，却使“这个选项将为谁做成什么”有客观内容。

第三，我们将这种关系识别为选项的道德优点，而非只承认患者处境改变却拒绝赋予该改变任何行动相关性。该识别的正面根据在于：它以同一实际患者的坏与改善，解释为什么有效回应值得采纳、为什么无效手段需要修正、为什么隐匿负担没有解决问题，以及为什么私人退出并不让患者的好坏随之归零。这个解释不需要另造一个受益主体，也不需要把他者的好转化为帮助者的收益才让它进入实践。

第三步正是 C2，不能被前两步的描述性词汇偷渡。它得到的是统一解释和具体规范判断的可撤回支持，不是“没有竞争解释就逻辑必然正确”的推断。纯粹选择论可以承认前两步而拒绝第三步；分歧已经定位到它是否能正当排除这一患者指向优点。

这里有一个比“双方只是偏好不同”更完整的场景：行动者不在乎，观察者关心，**患者正在受苦**。前两人的心理差异没有穷尽第三方的处境。Manne 的一手论述明确保留这种三方结构；她的主要例子是致害，因而不能直接充当无责任陌生人救助的证明。我们借用的是定位方式，随后独立辩护救助的 C2，而非把两个案例混作一个。

## 3. 合宜回应为何多于裸可行性

能够按动按钮只是控制能力。按钮可能没用、伤害他人、违背患者有效拒绝，或只关闭报警。裸可行性不能决定应答方向。相反，同一患者负担的真实、适当缓解有内容明确的成功条件：改善必须发生在该患者，针对相关负担，并通过具备正当权限的办法实现。

因此，“回应”在这个识别里包含三个不同约束：

1. **对象约束：**不能以另一个人的舒适、观察者的平静或代理分数，替代这个患者的处境。
2. **效果约束：**若该办法不再有效，它基于这项改善的支持便不再成立。实际负担仍可支持另一有效办法。失去一个方法的正向证据不等于证明没有患者或没有其他理由。
3. **关系约束：**方法必须保持患者及其适用的权利和意愿。能降低某个指标的支配，不因此成为合宜救助；相关权限需要独立理由，不能以“我们知道什么对你最好”定义出来。

这些约束不能证明 C2，但使它不是一个空洞的“帮助是好”的标签。它能告诉我们哪种事实变化应当改变该理由，哪种变化只影响认识、动机或其他比较。实际解除负担后，原来“尚未解除”的情况已不存在；新一轮负担则需要新的事实与证据。

不能把这些充分条件改写成所有理由的必要条件。未获许可的手段可能仍具有某种结果上的吸引力，而被权利排除；本轮无须解决这种价值分解争论。当前 C2 只对完整合宜选项给出肯定的充分判断，不推论“不可行就毫无价值”或“证书撤回就一切理由消失”。

这使关系性比较比总量比较更有信息。Korsgaard 所讨论的是人如何相待、他人的善怎样成为可分享的理由，而不只是生产多少抽象的好。其人格与共享理由路线不是本候选的经验性患者根据，却帮助说明一个相容点：**承认他人的善能支持行动，不等于将所有善变成一个人的终生唯一工程。** 两条路线的前提不同，不以作者间的相似处代替证明。

## 4. 私人撤回为何不抹除基准，自主为何仍能限制要求

对同一可行选项作一个严格的比较：患者处境、效果、成本、权限、知识和其他有关条件固定；行动者私人地先表示采纳，后来真正撤回；没有承诺、委托、诱发依赖、持续角色或别的新增责任。C2 认为，这项实际改善关系在三个阶段都可以成立。承诺或项目产生的额外理由可以变化，基准理由不随之产生或消灭。

这一判别不能靠“我不关心了”的口头报告完成。若仍有持续承诺、羞耻、广泛愿望或过去采纳的自我约束，竞争模型可以把它们作为真正的条件。需要明确比较的是何种真实心理与规范变化，以及对手究竟声称哪个条件是必要的。一次移除外部奖励或一个明示愿望，不能排除所有关于更广动机的理论。

不过，纯私人采纳若被说成产生全部道德优点，就承担一个实质解释负担：同一患者的实际好转，为何在采纳之前完全不能正向说明这个选择，直到行动者自己选择了它才取得意义？我们支持相反的解释次序：患者的改善可以使采纳值得发生。私人自主可以选择如何安排许多有根据的活动；它不必先拥有创造所有根据的权能，才能保持自主。

这不把拒绝自动判为不正当。自主的肯定价值在于真实地参与塑造一个有内容的生活，而非任何瞬时偏好都享有无限否决权。睡眠、安全、亲密关系、不可替代的活动、已承担责任与持续被调用的负担，都可能给某项要求设置真实限制。只有把这些损失算作损失，才能认真比较患者与帮助者；但计入损失还不保证它总能压倒他人的需求。

既有有限救助论证已经更进一步：在严重持续痛苦与一次可恢复的短暂中断之间，且不存在相关权利、竞争责任或及时替代者时，采纳明示的受影响者主张比较原则，可以支持应当促成救助。该判断没有取消自主，而是在这个窄域判断自主的真实所保护之物未被这种短暂救助摧毁。它也不是单由 C2 得出。

持续严重需求则不同。正确的累计记账仍可能支持很强的助人要求；也可能需要另行辩护的个人活动权限与共同供给。因此本文没有从“不是无限牺牲”直接推出任意保留额度，也不把同意道德优点却否定义务的对手，误写为否认全部基准关切的对手。

## 5. 最强反对者与真实判别点

| 反对意见 | 实质挑战 | 本候选的回答和仍开放的部分 |
|---|---|---|
| 他人的福利只是其自身的好；他人的好只有在我先选择关心时才对我有任何道德意义 | 否认 C2，承认 C1 和全部因果事实 | 采纳前有效缓解能正向说明采纳，且改错追踪患者；排他门槛需要独立根据。对手并未因此形式矛盾，普遍必然性仍开放 |
| 所有实际理由仍由行动者完整的动机结构解释；表面没有助人愿望并不代表没有相关动机 | 区分理由所指事实与使之成为理由的背景条件 | 承认复杂内在论能产生相同表面行为。必须对明确提出的必要背景作干预，不能仅测一次奖励移除便宣布击败所有内在论 |
| 患者确有道德请求，但一个完全不能从中获得动机的行动者没有严格意义的理性理由 | 争的是理性权威与理由概念，不一定否认道德优点 | Manne 就保留类似区分。现有基准的内容仍可被承认；若要求更强理性不可回避性，需另作论证 |
| 我承认改善有道德优点，但陌生人的需要无权给自主活动施加义务 | 接受 C2，反对从比较到要求的原则 | 由既有有限救助研究正面比较双方所保护的内容；不得用本轮 C2 或无先行角色字段直接宣布这一争论已解决 |
| 某种关心适合，并不意味着我们应当最大化其对象；悲伤、尊重、纪念也未必要求生产更多对象 | 反对从合宜情感机械推出促进义务 | 本候选直接识别一个获许可的具体缓解选项的优点；没有采用“凡适合情感都应促进”的总原则，仍要保留拒绝和适当方式 |
| 这是借自然主义语言宣布善，而非解释善 | 要求说明被识别两边为何同一而非常相关 | C1/C2 各自保留独立解释与反例条件，以实际承受者、回应效力、前瞻证成和纠错作联合辩护；当前支持未排除所有竞争识别 |

同一稀疏因果模型允许把道德关系解释成空集，说明因果公理没有蕴涵 C2。它没有单独证明完整现实里规范关系必然可变，更没有证明一切自然主义构成性识别都不可能。反过来，加入 C2 后得到保持定理，也不构成对 C2 真理的独立确认。这两项限制应同时保持。

## 6. 经验识别：要区分的机制与不能由数据决定的事

以下是未运行的比较方案，目的是检验一个机制是否学会识别患者根据并据此行动。它不通过诱发真实痛苦来检验伦理，不把实验者授予的奖励当作患者好坏的定义。涉及现实患者时，患者识别、权限与伦理审查须依实际研究单独建立；形式代理只测试接口语义。

| 控制或干预 | 预期区分 | 足以否定什么、不足以证明什么 |
| 保持实际患者改善，改变公开评价与外部奖励 | 患者相关响应与奖赏、声誉策略 | 可反驳特定外部奖励依赖；不能排除全部内部目标或学习史 |
| 实际患者状况不变，只消除观察者的不适或遮蔽报告 | 患者改善与观察者舒适、信号压制 | 若仅追踪观察者状态，可否定所声称的患者效果追踪；不能从不帮助直接推断不知道或没有理由 |
| 控制真实改善机会与信息显示，分别操纵两者 | 客观根据、行动者证据、证据校准 | 错误信念可能解释错误选择；全知分析者的 M 不能充当行动者已有的 K |
| 在负担仍存时揭示原手段失效，再提供等价许可手段 | 对对象的关切与对固定动作/仪式的依附 | 修正至新手段支持对象追踪；需要排除实验者暗中编码的“正确动作”奖励 |
| 真实改变患者的有效许可，保留负担与受益预测 | 尊重患者关系与单一减损最大化 | 停止该手段可能是恰当响应，不能按帮助次数判成关切退化 |
| 固定角色与承诺不存在，明确区分先前私人采纳、当前响应机制和理由判断 | 先行项目门槛与采纳前患者指向证成 | `adoptedConcern=false` 不等于行为完全没有内部动机；若硬编码响应程序，只证明该实现可行 |
| 读取与回应各自付费，保留真实资源历史与新事件 | 口头知道、承担获取成本、实际完成与旧证书滥用 | 揭示有理由不等于有钱、有钱不等于有证据、有证据不等于已经救助 |

关键观察单位不是一句“我知道该帮助”，而是一个完整的因果链：独立患者状态 → 对该状态的有来源表征 → 实际选择和付费 → 同一患者的真实效果 → 因事实变化而修正。对中介环节的干预，才可能区分信息被存储与信息实际参与选择。一个不可观测的“仁心”变量若只由结果倒推，不提供这种识别。

还应设置两个最强负对照。第一，一个准确知道患者在受苦、能报告正确规则，却在实际选择中只优化奖励的机制。第二，一个确实关切患者，却因证据陈旧、错误手段或资金不足而失败的机制。前者说明正确陈述不等于实践取得；后者说明失败不一定是道德根据缺失。二者都防止把行为单一结果当作心性或理由真假的测量仪。

任何有限数据都不能独自裁决“患者真实改善本身构成道德优点”与一个预测同样行为的规范否定理论。实验能比较事实模型、识别可干预的动机依赖，并约束患者根据是否被误认；C2 的规范评价仍由实质论证承担。相应地，形式模型的成功也只是伦理解释明示之后，实际取得和回应能够怎样发生的结果。

## 7. 与阳明及生成根基的连接

阳明的一体之仁把他者置于关切内部，并要求在亲民、爱物的实践中实现；原文同时保留厚薄条理。现代重构可以吸收其“他者自身进入我所回应的世界”这一方向，却不以共同体验或总体效用合并多个中心。阳明关于良知与造化的强本体说仍是原典的一部分，不能被我们的机制解释冒称已经证明，详见[原典记录](WANG-YANGMING-SOURCES.md)。

生成论此处需要完成的不是为冷漠重新命名，而是接通不同证明义务：真实中心的形成及可识别性、该中心实际好坏的构成、跨中心回应何以有根据、何种形成机制能识别并使用根据，以及实际付费如何产生患者效果。当前把 C1/C2 明示地接入共同过程，是操作整合；正向论证继续说明这两个候选为何值得接受。二者互补，不能互相冒充。

改变结论的证据也对应不同层次：符合所述领域却没有局部坏的实例要求修订 C1；先行关系对一切患者指向优点确实必要的独立论证要求修订 C2；有效拒绝或竞争权利可能只排除某个手段；错误患者、过时证据或未支付的执行暴露机制失败。更强的普遍根基及正确响应机制的自主形成，仍是下一桥梁。
