## 2. Track possible present configurations through their histories

A represented `World` pairs one of the preceding three control arrangements with either no current diagnostic fault or one current root cause among 0–4. There are eighteen possible configurations. Root 4 affects the fifth diagnostic position only; the other roots have the preceding shared-control interpretation. At a read, a position exposed to the current root may report either answer or remain silent. An unexposed position must report the current structural answer if it responds. Missing reports do not exclude candidates.

A read filters the current possibilities by that event's report. Between reads, `predict` expands them through a supplied transition relation. Four relations are implemented:

| Represented change | Possibilities admitted by the relation |
|---|---|
| `steady` | Same arrangement and same current fault |
| `mobile` | Same arrangement; any represented current fault or none |
| `control` | Any represented arrangement; the same current root fault |
| `reset` | Any represented arrangement and current root fault |

`reset` means an uncertainty expansion over both fields. It is **not** a physical recovery operation or a claim that errors were erased. A `mobile` event can similarly express a conservative opportunity for movement; it need not report which root actually changed. The public record stores only the transition kind. The predictor receives the existing possibilities and this kind, never the actual successor identity. Actual successors enter the physical simulation and the proof's correspondence condition separately.

Keeping paired possibilities matters: evidence may constrain both the arrangement and which root could explain earlier lies. At a later change, only the dependencies preserved by the transition law may be carried forward. The current-state representation merges paths ending in the same pair. This is appropriate for the supplied transition and report laws, whose future possibilities depend on that pair and the next event kind. It is not a general sufficiency result for hidden histories with additional persistent effects.

`received_actual_retained` and `prediction_contains_successor` prove the two local retention steps. `lawful_history_preserves_known` composes them across any finite history satisfying the stated report and transition laws. The actual configuration remains among the retained possibilities, and all possibilities remain represented. This is a forward coverage guarantee, not a promise to identify the unique configuration or eventually eliminate every false alternative.

The final possibilities are projected to their command arrangements and pooled using the preceding certificate construction. Duplicated arrangements only repeat certificate conditions; they do not add independent evidence. `history_to_current_certificate` connects the maintained coverage to the current command evidence. `history_to_actual_completion` additionally applies the earlier completion theorem with current faithful/responsive command reports, separation of the pooled envelope, a fresh request and remaining work/time.

The fifth diagnostic cause is projected out of the four-position command interface. A checked finite lemma verifies that this projection preserves every represented command failure outcome; a second lemma establishes the inherited command-root coverage for every represented configuration. Thus a diagnosis-only fault does not silently become an uncovered command cause.

The final command still uses the inherited stable, protected transaction. Changes may occur throughout the earlier inspection history; arbitrary interference inside command collection/execution is not newly solved. ## 3. Moving compromise defeats an instantaneous bound

Take actual left sharing, so the structural answer is true. Before reading positions 0, 1, 2, 3 and 4, let the active cause be respectively 0, 0, 2, 3 and 4. At each read exactly one root is active, and that root exposes the position being read. Every received answer can therefore be false.

`single_cause_at_each_read_can_forge_whole_transcript` checks that each response is allowed at its own read. Passing those five false answers to the earlier **fixed-fault** filter retains only right sharing, which is wrong about the actual arrangement. This does not refute the earlier theorem: its collection-wide fault assumption is violated. It refutes the attempted application based only on a one-cause-at-each-instant premise.

`temporal_observer_does_not_infer_false_right_sharing` checks the same changing history with `mobile` prediction between observations. All three structural possibilities remain. Five reads are paid, the ten movement/read records are kept, and the actual left-sharing configuration remains represented. The observer preserves uncertainty when this evidence cannot resolve it.

This is a model of **which current responses may be corrupted**. It does not implement recovery of process memory, revocation of stolen keys, or elimination of malicious state after a root stops being active. The stipulated response law says that currently unexposed positions again produce correct present reports. Persistent effects would require additional state or a wider transition/report law. The model therefore does not establish full mobile-Byzantine process tolerance.
