# Acquired application distinctions: technical comparators and identification

6 October 2026. AI-authored, link-only primary comparison under the [nondual method](../../../../theories/shengsheng-buxi-generative-existence/unified-2026-10-05/NONDUAL-METHOD.md). Named connection: **different acquired consequences within one operative application class → refinement of that distinction → changed subsequent application**, while the retained sensory model remains valid. This note does not accept an implementation, run a new experiment or claim a new abstraction algorithm.

## Primary antecedents

**McCallum (1996), *Learning Visual Routines with Reinforcement Learning*.** [Publisher PDF, AAAI FS-96-02, pp. 82–86](https://cdn.aaai.org/Symposia/Fall/1996/FS-96-02/FS96-02-018.pdf). Reading scope: “The U-Tree Algorithm,” “How it Works,” “The Chain and the Tree,” and “Building the Tree,” pp. 83–85; task specification on p. 85. This is the title of the inspected publication, not the similarly titled talk or dissertation.

Source-derived capsule: U-Tree retains action–percept–reward experience and groups instances in tree leaves used for action values. Starting without state distinctions, it considers additional perceptual or historical features in a fringe. Statistical differences in estimated future discounted reward can promote fringe distinctions into operative leaves; retained instances are redistributed accordingly. Feature vocabulary, fringe depth and task reward remain specified. This is established experience-driven construction of task-relevant distinctions, not merely learning values for an immutable state partition.

**Li, Walsh & Littman (2006), *Towards a Unified Theory of State Abstraction for MDPs*.** [Author-hosted primary PDF](https://thomasjwalsh.net/pub/aima06Towards.pdf). Reading scope: §§2.1 and 3.1–3.4, especially Definitions 2–3 and Theorems 2–4. No independent proof verification or reproduction of simulations.

Source-derived capsule: The paper distinguishes abstraction preserving action-wise reward and next-block transition probabilities from weaker preservation of action values or optimal actions. Its refinement relation compares partitions. An abstraction permitting an optimal common action need not provide all the guarantees of model preservation; planning and learning claims depend on the particular abstraction and learning assumptions. The finite MDP, reward criterion and action repertoire are part of the supplied problem.

## What would identify refinement here?

Let \(\phi_t\) denote the grouping the application procedure actually uses, over a specified common domain of accessible pre-decision histories. The distinction must affect a prediction, application judgment or subsequent choice; an auditor-only label does not suffice.

For strict refinement on that domain, a later \(\phi_{t+1}\) must preserve previous separations and separate at least one previously merged pair. If the update also merges old classes, call it repartitioning unless refinement is established on an explicitly restricted domain. A change in a confidence value, candidate count or one global interpretation flag is not automatically either.

The useful implementation record would establish:

| Link | Evidence required for the named claim |
|---|---|
| Former merger | Identify two histories or accessible conditions that the actual application procedure treated as one class. |
| Acquired conflict | Show which enacted operation produced which consequence and how that relation became available and retained. |
| Supported discriminator | Show which available feature/history separates the consequence-relevant cases and what assumptions support reuse of that distinction. |
| Changed grouping | Reconstruct the before/after application mapping without reading hidden target or scorer fields into the learner. |
| Operative continuation | Show the new distinction being used in a later prediction, inquiry or action; retain the original sensory achievement. |

If the sensory model already distinguishes phases while application groups them only by their current sensor output, selecting phase as relevant can be a genuine new **application** distinction. It is not discovery of a previously absent sensory state. Conversely, rewriting sensory outputs to agree with productive outcomes can destroy a valid sensory model while hiding the missing interpretation.

Candidate elimination and refinement are not mutually exclusive. Eliminating hypotheses may realize a changed partition. The test is the demonstrated grouping and its use, not whether the implementation belongs to an approved algorithmic category. If a fixed candidate family already encodes all possible distinctions, learning which applies is still acquisition, with that representational repertoire explicitly supplied.

## Counterexamples and scope limits

Different observed consequences do not, without further conditions, show that a class is inadequate. The same stochastic state can yield different outcomes. Remaining stock, action identity, changing circumstances or elapsed opportunity can also explain the difference. Under a deterministic stationary application contract, a genuine conflicting pair defeats a deterministic class-level prediction; it does not by itself identify the correct replacement distinction.

An outcome received after an action cannot be used retrospectively as an available pre-action discriminator. Retaining it can change later decisions, but matching that later record to the appropriate application remains part of the mechanism. A time index or unique episode identifier can memorize every exception without establishing useful generalization. Equally, the finite history need not establish a complete new quotient to demonstrate one justified local distinction.

A strong ordinary comparator receives the same observations, retained history, available features, operations and resource conditions, and may update its task-state representation. A frozen lookup table is a useful exclusion control, not the strongest baseline. Exact agreement with ordinary refinement would preserve the local connection while withholding algorithmic-superiority claims.

## Relation to the generative question

The operation that changes support conditions can also produce what later differentiates application. The effect, its acquired record, the new distinction and the ensuing action must be connected through actual transformations. Naming them separately makes the causal claim assessable; it does not posit independent ontological domains.

The selected consequence criterion must remain connected to the independently specified continuing activity. Substituting a new favorable score after a failure would change the question. Preserving that activity while discovering which distinctions matter can realize acquired relevance under a stable encompassing law. It does not explain every supplied sensitivity, learner procedure or action repertoire, and supplies no ethical warrant by itself.

This comparison therefore supports a bounded question: **does acquired consequence information reorganize the application's operative distinction in the existing history?** It neither requires a new controller nor establishes the origin of all undertakings.
