## CoMemBench: supplied handoff contract, unavailable execution records

**Paper scope.** [CoMemBench v2](https://arxiv.org/html/2609.32192v2), 29 September 2026, describes typed/versioned handoffs, verification, bounded revision and matched pollution. Its graph nodes denote task dependencies, not necessarily separate physical agents. Isolation is conditioned on clean-target success. The design can connect artifact exposure to downstream verification; those described execution records were not present in the inspected public release.

**Access.** The [official site](https://comembench.world/) links [Hugging Face](https://huggingface.co/datasets/anonymous-submission-333/anonymous-submission), inspected at commit `d1cef0fb70ada0ddf9b80d23aa30ed86ee56e016`. The full recursive tree, commit metadata, README, LICENSE and eight small schemas are preserved in [source 34](../../../../sources/34-memory-correction-2026-10-06/README.md). The README identifies a task-side release, excludes evaluator oracles, gold trajectories and pollution plans, and withholds the certified code-image registry during review. No per-run model outputs or receipts appear in that tree. No bulk task files were downloaded.

The artifact schema describes `producer_node`, `entity_scope`, `version`, provenance and verification status/receipt fields. The handoff schema requires `latest_verified`; the node-view schema specifies incoming artifacts. These are observation contracts, not measured executions. CC BY 4.0 covers the released annotations/workflows/contexts/indexes, subject to upstream terms; withheld materials are excluded.

**Our discriminator.** With complete outputs, select all bounded-revision/stale-version pairs for one fixed executor/backbone before outcome calculation. Bind the original claim, verifier response, corrected artifact, actual consumer exposure, operation and native receipt. Report the full paired outcome table before conditioning on successful controls. Distinguish a genuinely reset consumer context from another graph node sharing context. The evaluator's version/authority rules remain supplied premises; adopting the latest label alone would not show independent calibration or concern.

## MemSecBench: repair and action occupy separate branches

**Paper scope.** [MemSecBench v1](https://arxiv.org/html/2607.27080v1), 29 July 2026, describes Write, Execute and Forget with memory snapshots and controlled effect records. Execute and Forget independently restore the same post-Write state. Forget evaluates target removal/neutralization and benign-semantic preservation. Section E.4 expressly separates preservation from later retrieval/use. Controlled or synthetic targets are specified in the ethical statement.

**Access.** The complete primary HTML contained no author release/repository hyperlink. A bounded exact-name GitHub repository search returned zero items. The paper describes retained case bundles (§D–E), but no retrievable bundle was located. No code/data license was verified; the article displays the arXiv non-exclusive license. This establishes the limits of this search, not universal unavailability.

**Our discriminator.** A recorded post-repair dependent task is needed to join the endpoints. Compare its warranted action and preservation of useful behavior with an otherwise matched unrepaired state, retaining identical task facts and relevant authority. The separate poisoned Execute run cannot supply that observation. Final snapshots can identify a narrower storage change, and physical deletion is only one possible repair. Neither a changed memory entry nor its apparent semantic correctness proves that a future consumer receives or follows it.

## SND: primary claim available, corpus access unresolved

**Paper scope.** [The Misattribution Gap v1](https://arxiv.org/html/2605.22842v1) presents memory-poisoning and attribution experiments plus an observational-indistinguishability claim. Its [project site](https://supreme-lab.github.io/snd/) links an anonymous corpus. The source says release upon acceptance, while Appendix K refers to released result files; this wording does not establish accessible outputs.

**Access.** The exact linked endpoint is [Semantic_Norm_Drift-D412](https://anonymous.4open.science/r/Semantic_Norm_Drift-D412). The coordinating agent's web reader returned zero extracted lines; its direct request returned HTTP 403, with no body retained. The article and official site are preserved. No anonymous corpus, attack file or result file was downloaded. The site states a prospective CC BY 4.0 release; this is not a verified license for inaccessible corpus bytes.

**Our discriminator.** A causal source claim needs a declared observation set and admissible interventions. Matching one behavioral record across explanations leaves those explanations underdetermined for that record; it does not show equality of all observable distributions, or impossibility under additional provenance/inspection interventions. The parallel mathematical review evaluates the theorem. A retrospective empirical audit would additionally need full context/condition IDs, per-example outputs, source provenance and any matched memory intervention, not selected examples or aggregate tables.
