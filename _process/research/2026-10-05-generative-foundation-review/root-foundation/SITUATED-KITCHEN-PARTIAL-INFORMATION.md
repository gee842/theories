# 有限资料如何给出具体行动根据：共同厨房的转移界限与评价修订

2026年10月8日。AI 撰写，承接 Ren“继续”。沿[已有真实资料应用](SITUATED-KITCHEN-EVIDENCE.md)推进，复用已完成的一般实践判断与目标修订，不重开规范起点或另造学习机制。

**本轮结论：有限资料可以同时给出确定的正面内容和明确的未决范围。依据原文关于同一32份配对记录的说明，至少5份记录由食品不安全转为安全；由安全转为不安全的份数则可能为0至13。这个界限足以纠正成效表述和下一轮评价安排，尚不足以认证项目的因果效果、所有生活的改善或扩张决定。**

推进的连接是：**真实对应 E 所支持的有限认识 → 与所需前提相称的实践理由 → 评价目标及后续安排的修订**。G0、公开 J1–J4 的伦理根据与这里的计数证明分列。审查为作者实质反审，没有新增独立验收。

## 1. 保留同一生活历史中的前后联系

[Sahyoun 等2019年原始研究](https://link.springer.com/article/10.1186/s12889-019-7950-3)的 Methods / Quantitative data、Results / Characteristics 与 Table 2 说明：32位妇女完成前后测，所报告家庭的食品安全分级人数为14→19。样本最初51人，18人首周退出，另1人缺期末问卷。原始 XML、许可、哈希和阅读范围见[来源说明](../../../../sources/community-kitchen-evidence/README.md)。本轮重读上述原文、食品安全结果及表格，未取得个体资料或联系作者。

把“中度不安全”和“重度不安全”合并为一个分级，仅为检验“进入／离开食品安全分级”这个命题。前后分类描述同一组所报告家庭历史的两个时点；它们并非两群固定且独立的人。分类还省略了时点之间的经历、分级内变化及其他生活关系，不能把省略部分写成无损失。

对应前提为：原文的32份记录确为同一配对样本，人数抄录正确，所用分级在两个时点可按原文比较。核对出版物支持这种读取，但不替代原始问卷审计。AFFSS 的操作分级不直接等于伦理上的基本保护已成立；本轮的“安全”仅指该量表分类。

## 2. 已知内容的精确范围

令 a 为前后均安全，b 为安全→不安全，c 为不安全→安全，d 为前后均不安全的记录份数。公开人数给出：

\[
a+b=14,\qquad a+c=19,\qquad a+b+c+d=32.
\]

所有变量为非负整数。因此 c＝b＋5，且 b 可以恰取0至13的每个整数；给定 b，其余人数被唯一确定。以下两种匿名汇总历史都与已公布人数相容：

| 相容情形 | 前后均安全 a | 安全→不安全 b | 不安全→安全 c | 前后均不安全 d |
|---|---:|---:|---:|---:|
| 无安全分级流失 | 14 | 0 | 5 | 13 |
| 安全分级流失最多 | 1 | 13 | 18 | 0 |

**确定的正面内容：至少5份、至多18份配对记录进入安全分级。确定的认识限制：无法从这些边际人数辨明是否有人离开安全分级，可能份数为0至13。** 总共14张相容二元转移表由脚本枚举，并与一般 Lean 结论交叉核对。它们不是14个等概率情形，也不是对实际变化的14次观察；端点13不是估计实际受损人数。

原研究分类检验的 NS 标签仍保留。这里是在假定公布的样本记录正确时推导样本计数必然满足什么，不作总体显著性推断。至少5次进入某分级也不等于至少5次由项目造成的改善。中度与重度之间的变化、量表误差、共同生活的其他收益和负担，均不被这个二元投影认证。

上一轮“不能认定恰好五户改善”的限制继续成立；现在补上其肯定面：“至少五份记录进入安全分级”可以确定。用“未知”概括全部内容，会丢掉已经取得的认识。

## 3. 怎样实际修改判断和记录

以下是对已建立的构造应用及下一轮评价设计的修订，未实施于2019年的历史项目，也未取得 Ren 的现实场域资料。不会仅凭文献为实际参与者分派新任务。

| 当前要做的事 | 现在已有根据的决定 | 进一步决定所需的资料 |
|---|---|---|
| 表述这项历史结果 | 写为“完整配对样本中安全分级净增5份；至少5份进入安全分级，离开者份数未辨明”。 | 若要报告实际改善与退步各多少，需匿名配对转移表。不能把相容上限13报告为发生13次。 |
| 继续供给、学习与相处 | 沿上一轮已成立的具体权限、承担、可行性和收益，有界保留并调整；这组界限本身不要求停止。 | 新发现的具体未满足、负担或更好替代应进入比较。仅有逻辑可能性，不能当作已发生伤害或任意补上概率。 |
| 宣称所有基本生活均得到保护 | 撤回由净人数增长推出这种认证的依据。 | 即便取得 b＝0，还须校准量表与实际需要、其他位置的后果及遗漏范围；配对表单独不足以满足 J2。 |
| 下一轮收集什么 | 若保留了允许用于本目的的配对记录，先在原保管范围汇总转移；同时分别保留退出、缺失与未进入的资料状态。 | 若没有配对资料，明确保留未知；只有会改变决定且负担合宜的补充调查才值得开展。不能为填表要求人人回应。 |
| 是否扩张或撤去现有支持 | 将这项决定与现有活动的有限继续分开，根据新增规模、承接与负担另作判断。 | 需要实际需求、支持来源、完整负担、替代能力及可接受的承担。当前计数不能提供这些前提。 |

由此得到一份可以直接采用的评价记录结构：**样本进入与退出流程；固定配对组的两个时点与四格转移；量表外已查明的需要和负担；缺失与未核实项；具体安排、责任范围和会触发修订的证据。** 不设置一个把这些内容合并后便自动给出决定的总分。

实际回应也不能机械地定为“补测所有人后再行动”。例如已经查明某次取用在既定窗口无法完成，而具有权限与能力的替代方式已成立，可以先处理这条具体接续，同时继续辨明整体效果。反之，只知道相容表中存在退步，尚不足以指认某份实际记录或某位参与者需要何种补救。所缺资料相同，决策前提不同，调查的紧迫性就可能不同。

## 4. 从成效评价到目标本身的校准

[目标形成与修订](../../../../theories/shengsheng-buxi-generative-existence/unified-2026-10-05/GOAL-FORMATION-AND-REVISION.md)已经完成相连说明；[同一历史中的目标修订与后续分配](GOAL-REVISION-CONTINUATION.md)也已完成有前提的机制实查。本轮直接应用其区别：**记录中获得奖励的成功、实际发生的后果、继续追求该目标的伦理根据**不能互相代替。新七项定理只证明计数关系，不另声称证明目标生成机制。

对厨房案例，单以留存者末期安全比例或参加人数来评价，会遗漏不同的配对历史及不能进入的条件。因此修订的目的应具体写为：在有界可行的共同安排中，支持食物、理解、相处和可用能力的形成，并能够辨认和回应已查明的未满足及负担。参加率、末期人数和课程完成仍可作相应用途的指标，但其角色须由这一目的说明。

这不是要把所有退出阻止下来。增加可选择时段、照看或其他支持，有时使参与可行；承认不参加与有界结束，有时更符合具体生活。评价应能记录这两种结果。以固定样本保留可比性，也不意味着把人固定在原来的参与关系中。若有新的参与者，他们有自己的进入条件与观察范围，应另行说明。

上述修订是关于怎样使用真实证据的实践理由，未指控原项目操纵样本，也未证明该项目按旧指标实际行动。现有资料中的退出与留存差异提供校准需要，具体动机及制度行为仍须另有证据。

## 5. 实质反审与理论限度

**是否仍回到了“有人得益／有人受损”的对立起点？** 这里先保留共同活动形成供给、技能、相处与支持的肯定内容，再检验汇总投影丢掉的前后联系。四格是同一实践历史的有限表述；既不预设两类对立者，也不声称存在冲突。保留可能差异是为了使整体判断对其内容负责。

**数学相容就足以阻止行动吗？** 不足。14张表限定单凭这些汇总数能断言什么；没有给它们赋予可信度，更没有完整枚举所有后果。对“无人离开该分级”这样的全称计数认证，一个相容反例足以表明现有数目不能支持它；对有界继续、特定补救或现实风险决策，仍须使用相关证据及既有 J3/J4。不能把认证不充分改写为行动必然不正当。

**既然净增5，为什么不能接受总收益？** 净增是确定且相关的信息。若进一步采用可加总的福利规则、可比较的测量和相应代价权衡，可能取得其他判断；这些实质承诺必须公开，不能由人数算式自行推出。这里复用的 J2 是公开且可争论的基本保护优先承诺，其完整前提并未由边际计数建立。

**取得完整配对表是否就完成伦理校准？** 没有。它只关闭一个明确的资料缺口；同分级中的变化、食品以外的生活、未进入与退出，以及安排本身的因果作用仍各有范围。不能把更精细的记录再升为整个生活的替身。

**这是否是本理论独有的新方法？** 不是。配对转移与边际界限是普通计数方法。这里的新研究贡献是将这个确切资料限制接入已有 E／实践判断／目标修订，并据此改变本应用的成效表述、调查对象和决策边界。它未证明本理论比常规项目评价更优。

## 6. 形式实查与完成范围

[Lean 源码](../../../../experiments/integrated-correction/general-framework/generative-basis/lean/universal-ethics/generative-capacity/KitchenTransitions.lean)包含7项新定理、12项显式顶层声明；[实查回执](../../../../experiments/integrated-correction/general-framework/generative-basis/lean/universal-ethics/generative-capacity/kitchen-transitions-verification.json)记录 Lean 4.29.1 的实际编译、签名与逐声明公理依赖。生成的投影、构造器不是另外计数的审计项目。

| 定理 | 精确内容 |
|---|---|
| `feasible_loss_iff` | 任意非负整数 N、B、A、b，相容四格表存在，当且仅当 b≤B、A＋b≤N、B≤A＋b。没有概率或伦理前提。 |
| `net_change` | 同一配对表的末期安全数等于基线数加 δ 时，进入数＝离开数＋δ。 |
| `published_loss_iff` | 32／14／19实例中，每个且仅有0至13的离开数可实现。 |
| `published_gain_bounds` | 同一实例中，进入数为5至18。 |
| `published_table_determined_by_loss` | 给定离开数，另外三格分别为14−b、5＋b、13−b。 |
| `no_losses_realization`、`losses_realization` | 上表两端点均满足同一公开边际人数。 |

审计使用标准 Lean 依赖 `propext`、`Quot.sound`、`Classical.choice`，按声明在回执中分列，无新增伦理公理、`sorry` 或未检查逃逸。初次编译仅端点见证缺少定义展开而失败，修正后完整重查通过；失败日志保留。数学定理不负责证明文献真实性、测量有效性、J1–J4 或实际决定权限。

[对应脚本](../../../../experiments/integrated-correction/general-framework/generative-basis/situated-kitchen-evidence/check_transitions.py)从保留 XML 提取三个数，与 Lean 常量及成功回执绑定，枚举14张相容表；[执行结果](../../../../experiments/integrated-correction/general-framework/generative-basis/situated-kitchen-evidence/transition-checks.json)保留全部匿名表和限制。数值枚举用于交叉检查，不代替一般证明；原有九项构造定理与一般实践／求知证明保持原范围，没有重复计数或重跑。

本轮完成了“有限资料不足”的一次正面收紧和可执行的评价修订。下一项需要真实材料的连接是：具体安排中，哪些已查明的参与条件、负担和承接关系会改变哪一项决定。若没有新增场域资料，不能靠继续细分这32份汇总计数宣布现场校准完成。
