# 非工具性关切：独立规范根据与有成本行动的形式接口

2026年10月6日。AI 撰写。此研究推进“患者的实际处境 → 不以行动者先行私人目的或角色为条件的理由 → 可纠正的实际回应”。它连接[统一伦理根基](../../../../theories/becoming/history/UNIFIED-ETHICAL-GROUNDING.md)的 C1/C2 候选与现有生成核心，不重复[理由传递](HUIGEN-REASON-TRANSPORT.md)的可达性定理，也不将心学的历史解释写成数学公理。

实现与单一重跑入口见[实验说明](../../../../experiments/integrated-correction/general-framework/generative-basis/noninstrumental-concern/README.md)。最终编译、源哈希与独立重建状态由该目录的验证记录确定；本文给出命题内容及适用范围，不以命题数量替代理论证据。

## 1. 规范根据与因果律分别进入模型

一个形式患者条件是 \(c=(p,e,b)\)：患者身份、事件编号和当前负担量。\(b\in\mathbb N\) 是模型量，不自动代表痛苦、福利或善恶。定义实际患者的实现和局部坏，需要另行辩护的 \(\mathrm{Realized}(c)\)、\(\mathrm{Bad}(c)\) 解释。Lean 中的 C1 是显式函数参数：

\[
\mathrm{Realized}(c)\land b>0\Longrightarrow\mathrm{Bad}(c).
\]

这不是用负数或命名来证明体验坏处。实际应用还要判断该量是否实现候选论证限定的仍不愿继续的负担；形式实例中的 `allRealized` 与 `quantityBad` 只是供逻辑检验的解释。

每个状态 \(s\) 含两个不同患者、一个本地行动载体及其资源、事实缓存和授权记录。这里固定一个本地行动者；\(\mathrm{Merit}(s,p)\) 是其指定服务方案对患者 \(p\) 的规范关系。其他行动者、任意手段或其他理由种类的全称解释不由这个有限实现自动给出。

令 \(O(s,p)\) 表示指定服务方案的实际可行条件：患者当前量为正、该手段得到许可、当前资源足以支付方案尚需完成的后缀。C2 另行声明：

\[
\mathrm{Bad}(c(s,p))\land O(s,p)\Longrightarrow\mathrm{Merit}(s,p).
\]

它是充分条件，不是把所有道德理由定义成此式，也不推出总体最优、决定性义务或强制权。它不要求已经读取事实、已经喜欢患者、得到私人奖励或承担先前角色；客观方案优点与行动者掌握的可用凭据因而分开。C2 的哲学根据来自规范论证，Lean 校验它与后续命题的推理关系，不证明 C2 的真。

## 2. 实际状态、读入与权限

[PatientConcern.lean](../../../../experiments/integrated-correction/general-framework/generative-basis/noninstrumental-concern/PatientConcern.lean)直接导入既有 `ResourceContinuation`，并通过它使用 `GenerativeCore` 模块中的实际 `Generative.Process` 与 `Generative.Trace`。新的服务过程是这些已有一般结构的实例；它不是此前所有学习、可塑性与继承轨迹的自动共同实现。

每个患者保留 `burden / episode / version / route / permitted`。一个读取包记录患者、事件编号、手段版本、观察量和命令。`none` 是尚无缓存，读取零得到的是已知零包，二者不混同。缓存事实的 `Current` 与允许使用的 `Usable` 分开：取消许可可以保留事实真，却撤销行动授权。

事件 `form / read / select / act` 分别支付 2、1、1、2 单位。读取实际复制当时该患者的条件；选择把当前事实包纳入操作记录；执行由该包中的患者索引定位目标，真实清除该目标当前负担量，同时保持事件编号和另一患者状态。执行后缓存及授权退休，不能复用已经消费的服务授权。全程没有信用补给，逐步费用之和加实际终态余额等于初态资源。

模型同时允许拒绝、私人标签变化、手段变化、新事件和许可变化。事件关系并不强迫读取、选择或帮助，调度与目标患者仍由给定方案提供。`select` 只是采纳事实支持的命令，不解决患者间的优先次序。

这里有明确的理想接口：读取通道忠实，现场门检查实际完整 `capture`，上下文变化有版本及授权同步机制。它们是供给的传感、握手与布线条件；费用表说明规定操作花费多少，不推导这些条件本身的起源。不能把此模型当作对任意隐藏变化、噪声或欺骗均能免费发现的认识机制。

## 3. 指定方案的当前后缀费用与真正交付

`remainingCost` 是当前 `servicePlan` 的准确费用：

| 当前程序状态 | 方案后缀 | 费用 |
|---|---|---:|
| 未形成载体 | 形成、读取、选择、执行 | 6 |
| 已形成，没有当前同患者缓存 | 读取、选择、执行 | 4 |
| 有当前同患者事实包，没有当前操作授权 | 选择、执行 | 3 |
| 有当前同患者操作授权 | 执行 | 2 |

关键定理是 `Eligible → 存在这条实际 Trace`，且该 Trace 清除同一患者、同一事件的当前负担，并支付准确的后缀费用。`paid_read_keeps_service_available` 和 `paid_selection_keeps_service_available` 说明：进入读取分支且已有载体、至少 4 单位时，付费读取使余款下降一单位、所需后缀也从 4 降到 3；已有当前事实包、至少 3 单位时，付费选择同理由 3 降到 2。它们不保证任意 `Eligible` 状态再做任意读取都保留可行性：只有 2 单位和当前授权时，重复读取会清空授权并消耗资金。不能每读完一步又向剩余状态索取完整初始账单，也不能忽略多余操作的实际代价。

`Eligible` 对指定方案给出充分可行性，不是任意有类型状态、任意路线的全局最小费用判定。独立审查发现并保留了反例：向尚未形成载体的状态注入当前操作包，则原法则保留此包，4 单位就可以形成后执行，而给定新建方案仍花 6。此状态不是实际空缓存起点的获得历史，但它是合法的 Lean 类型值；我们因此不声称没有证明的全局最小性。`Cases.injected_cache_defeats_unrestricted_minimum_claim` 保存它。

从实际空缓存、未形成、6 单位起点出发，已检查的正链为

\[
(6,\text{未形成})\to(4,\text{形成})\to(3,\text{已读取})
\to(2,\text{已选择})\to(0,\text{同患者交付}).
\]

它的私人奖励标签、先前角色标签和先行采纳关切标签均为零或假，真实资源却减少 6，另一患者负担保持不变。实际的操作倾向仍由给定布线和方案实现；这不是“没有任何因果动机也能行动”，也不证明这种布线学会了 C2。

选择只有足够支付本次 1 单位即可发生，故 5 单位起点能形成、读取和选择，却仅余 1，不能支付 2 单位执行。这是受保留的选择／执行分离。通用 `action_has_current_authorization` 证明当前授权有效，不单凭一个任意状态证明其历史上曾被获取；真正付费获得的主张由实际正链和相应程序定理提供。

## 4. 不以私人采纳为前提的精确范围

[GroundingContract.lean](../../../../experiments/integrated-correction/general-framework/generative-basis/noninstrumental-concern/GroundingContract.lean)将私人奖励、先前角色和先行采纳状态作为三个可改变字段，令患者条件、实际资金、命令效果、许可和已取得的缓存不变。由 C2 可推出，初态和这些变体都具有同一患者根据所支持的方案优点。

这是在给定结构和 C2 下的正保持定理，不是从删除字段中推导伦理普遍性。三个字段在这一法则中是标签：若“奖励”变化实际上改变余额、患者利益或别人的负担，前提就不成立。定理也不说所有理由或总排序恒定，更不说选择必定发生。它说明哲学上提出的患者根据能够被保持在一个不以这些标签为入口的有成本实现中。

另一个正式反模型把同一因果过程、同一事实状态及正负担解释原样保留，而令 `Merit` 恒假。C1 仍可成立，C2 则在有正负担且方案可行处失败。同样的帮助 Trace 仍然存在，因为规范谓词不是事件守卫。这准确说明：该组因果和患者量前提不逻辑蕴含 C2；帮助行为本身也不唯一识别其伦理解释。反模型没有证明所有更充分的自然主义根据都不可能，也没有假装保留了未加入本反模型的私人或角色规范锚点。

## 5. 失效、保留与两患者冲突

手段版本或事件编号变化使旧包失去当前性，重新获得包要再次支付。取消许可退休授权但保留事实及患者条件；恢复许可不会复活旧选择，必须重新付费选择。拒绝可以退休操作授权，却不能通过该操作使患者负担变成零。另一患者改变并不自动改变当前患者的事实包。

当前实现采用保守的全局授权失效：任何患者的手段、事件或许可变化都会清空唯一 `selected`。因此在只余执行费时，另一个患者的许可变化也会使当前服务多需一次选择费用，并失去指定方案的可行性。`global_invalidation_has_a_cost` 保存这一代价；事实保留不等于一切操作机会均不受影响。这不是一般最优设计主张。

两个患者在 6 单位空起点都各有一条可支付的服务方案。在 C2 下，两种患者根据可以同时支持各自方案；指定串接方案却需要 10 单位，6 无法支付，10 才能交付两者。这里证明的是该实际串接方案的资金界限，不能把两种分别可行的方案直接拼接后再重置余额。模型不通过归零另一个患者、虚构总排序或把资金短缺命名为没有地位来消除冲突。谁应先被照料、怎样获得补给和怎样比较其他人的正当要求，仍需独立判断与机制。

## 6. 结果在共同推导中的位置

新增内容是患者与事件保持的理由应用生命周期、当前后缀预算、实际程序交付，以及规范谓词对因果模型的明确外接与反解释。C1/C2、福利实现、信实传感、版本同步、许可解释、材料配方、固定调度和所给候选方案仍是供给条件。它给出可检验的整合接口，不宣称自发选择所有调查对象、形成良知、自动救助、普遍理性强制或完整智慧。

标准程序或控制器可以实现相同法则；本研究没有比较性能优越性。Python 独立重建与 Lean 编译具有不同证据作用，有限对应检查不构成任意 Python 程序到 Lean 的全局精化证明。进一步能够改变本结论的结果包括：C1/C2 的独立根据被确立或反驳，实际患者解释失败，感知／许可接口不能维持，或在相同预算下存在更可靠的替代机制。它们分别改变规范、语义和实现层，不能互相替代。
