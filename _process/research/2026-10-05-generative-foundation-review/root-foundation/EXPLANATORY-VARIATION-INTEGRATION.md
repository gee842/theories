## 2. Which variations suffice for identification?

Let `active q i` say that query/context `q` retains condition `i`. The joint response is `Response active value q := ∀ i, active q i → value i`. This is a conjunctive response family, not a model of all causal relationships. Dependencies permitting disjunction, compensatory tradeoffs or changing the factor itself need a different contract.

`Isolates active i` means some available query retains `i` and no different index. `WitnessRecovery active i` means that, for every valuation, `value i` holds exactly when some successful response involving `i` witnesses it. Lean proves these two conditions equivalent. The converse tests the explicitly stated unrestricted valuation class using the valuation true only at `i`; no excluded middle or choice is used.

An isolating query also guarantees that equal full response profiles imply equal truth of the selected factor. With isolation for every factor, response-profile agreement is equivalent to pointwise factor agreement. In the absence of isolation, the valuation true only at `i` and the all-false valuation give the same responses but disagree at `i`. Thus absence of isolation rules out universal factor identification over this unrestricted class.

**Exact scope:** the iff theorem is for positive witnessed recovery. The package separately proves isolation suffices for full-profile identification and that absence of isolation defeats it; it does not present an additional constructive equivalence between plain identification and an existential isolating witness. This distinction matters for arbitrary query types. No finite query enumeration, exhaustive experimental access or decision procedure is supplied.

### A substantive qualification: actual coupling can remove the need for isolation

The unrestricted comparison class is not an ontological claim that conditions vary independently. For two factors known to have the same truth value, their conjunction already recovers either factor, even though the sole joint query isolates neither. Two checked results establish this restricted identification. The coupling requires independent warrant; it cannot be assumed merely to get the intended verdict.

This prevents a false universal conclusion that all explanation or knowledge requires independently manipulating each condition. Existing relations, passive access or a narrower justified model class can carry the needed information. Arbitrary toggles in the broader formal class do not refute a richer, coupled proposal.

## 3. Connecting the queries to one supported process

`GateState` contains two gate statuses, a Boolean release-support field and a passage flag. A release event opens one specified gate and consumes the support; a passage event requires both gates open and changes the flag from false to true. These rules form one `Process` imported into the existing core. This is an exact toy mechanism, not a biological or engineering calibration.

Two initial configurations both block passage: left closed/right open, and left open/right closed. Releasing the left gate and passing succeeds in the first and fails in the second. Releasing the right reverses the result. A common current failure therefore does not identify which relation prevents continuation. A description accurate for the enlarged sequence family must distinguish the preparations.

The abstract tests are connected to this mechanism by proof rather than analogy. With support present and no previous passage:

* one passage is feasible exactly when both gates are open;
* release-left followed by passage is feasible exactly when the original right gate is open;
* release-right followed by passage is feasible exactly when the original left gate is open;
* `probe_matches_response` identifies these event-word feasibility answers with the corresponding `separate` conjunction responses.

Release availability is not free. Without support neither probe word is feasible. Every release consumes support, and no native finite continuation restores it. Thus the complete two-query profile describes separate possibilities from an initial configuration; it does not establish that both queries can be acquired sequentially in one history. A reset, new preparation or replenishment would require its own mechanism. An invariant also proves that one support unit cannot open two initially closed gates under any finite native history.

The model records successful passage, but a blocked sequence does not itself emit a negative receipt. Deciding failure by waiting, sensing it or retaining an attempted event requires a further interface. The current package therefore establishes conditional identifiability and supported positive realizations, not a complete empirical learner with reliable negative evidence.

## 4. Variation can erase the condition it changes

Releasing the left gate maps both initially open and initially closed left gates to the same open gate and spent support. With the right gate open, both preparations complete the same release-left/pass word and reach the same final configuration. No predicate of that endpoint alone can recover whether the left gate was originally open, uniformly over these preparations.

This is not just limited present-day evidence: the fixed model supplies an actual merger under the same event word. It remains relative to the represented state and the supplied transition law. If omitted physical correlations retain the original difference, then the smaller state description is inadequate for that historical question. We do not claim universal physical erasure or a thermodynamic theorem.

The positive lesson for the generative account is that activity changes not only the conditions for passage but also the conditions for knowing an earlier state. Increasing one capability can destroy a distinction needed for a different inquiry. This is a descriptive dependency result, not an ethical argument against change or a claim that all inquiry is destructive.

## 5. General recovery criterion and a connected repair

For a relation `R : S → T → Prop` and a prior property `P : S → Prop`, define recovery as existence of an endpoint predicate `read` satisfying `R s t → (read t ↔ P s)`. Lean proves:

**A prior property is recoverable from reached endpoints exactly when every pair of predecessors sharing an endpoint agrees about that property.**

The constructive sufficient decoder is `read t := ∃ s, R s t ∧ P s`. It is a semantic witness, not necessarily computable, accessible or produced by a knower. The criterion supplies no progress; it can hold vacuously for a relation with no transitions. The gate examples separately exhibit actual histories.

A further theorem shows that ambiguous predecessors stay ambiguous when a common endpoint has an admitted common continuation. If later dynamics only use that endpoint, it cannot selectively recover the different predecessors. The actual continuation hypothesis prevents an overstatement when all ambiguous paths instead terminate. Conversely, faithful readings compose when both successive relations preserve the appropriate intermediate reading.

`RecordedStep` makes the repair concrete. It extends the gate configuration with an optional retained Boolean. The release-left event copies the **pre-change** left status into this field while opening the gate and consuming the same release support; passage preserves the field. The previous contents can be absent. This is a stipulated jointly acting production rule, not an assumption that a correct record already existed. No claim is made that record formation is costless in reality: the common event law and storage reliability are explicit local-model premises.

Lean checks projection of each recorded step and finite history into the original gate process; constructs completed probes for both initial left statuses; proves that the reached record equals the initial left status; and constructs recovery of the original proposition. The richer description therefore repairs the precise information loss while retaining the original support depletion. Added storage does not create replenishment. This is one connected formal mechanism, not a juxtaposition of an unrelated learner and gate model.

## 7. Substantive counterreview and resulting revisions

Same-agent counterreview; no independent-agent acceptance is claimed.

**Changing the question might manufacture superiority.** The variation query family enlarges the earlier baseline target. This is justified only where condition changes belong to the real explanatory question. It does not defeat a competitor already preserving the same variations. The full static history account remains equivalent for the declared family. The result strengthens a necessary-content obligation, not unique ontological priority.

**The test theorem assumes independent knobs.** It quantifies over arbitrary valuations, but does not assert that all are physically possible. The coupled-factor result directly demonstrates why restriction to a warranted relational class changes identification. The gate step law accounts for the allowed changes internally, including support depletion. This prevents the weak formal class from being used as a refutation of the richer proposal.

**Identifiable profiles may never be acquired.** Correct. A complete profile is a semantic object. The shared support cannot enable both probes sequentially, and blocked words do not produce negative reports. The actual-history witnesses establish selected positive realizations only. A next inquiry must construct evidence acquisition and calibration rather than assume complete profile access.

**The merger proof omits hidden records.** Its claim is explicitly endpoint-relative. Adding a genuinely retained difference restores information, as the projected recorded process checks. A real application must justify which differences remain accessible and whether the model omitted a relevant relation. The general lemma does not prove physical annihilation of information.

**The repair builds the answer into a record.** The new relation explicitly writes a concrete pre-event Boolean in the same transition, not an arbitrary desired truth label. This provides a correct conditional mechanism; it does not explain the physical formation, reliability or energetic requirements of that write law. Those are substantive remaining dependencies. The proof does not identify semantic recovery with knowledge.

**This is established causal/information reasoning.** The principle that observations alone can fail to identify causal effects, and that intervention structure adds information, has clear antecedents. The merger criterion is an elementary factorization result. The contribution here is the checked integration of query conditions, native variation, finite support, information loss, record formation and the precise explanatory-necessity target. No global novelty claim or superiority to equally informed conventional models is made.

**Does this prove that generation is good?** No. The mechanism can enable passage, consume inquiry support and erase distinctions together. The work supplies a correspondence requirement for judging consequences; normative G0, comparisons and actual losses retain their separate grounding and the other sessions' scopes.
