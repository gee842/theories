# 非工具性关切：独立反例、形式范围与实现审查

2026年10月6日。AI 撰写的独立审查，接续[阳明比较审查](WANG-YANGMING-REVIEW.md)，服务于“患者自身的真实好坏 → 无既有角色的行动者的理由 → 有成本、可校正的实际回应”。这不是 Ren 的原话、外部同行评议或经验研究。主文见[非工具性关切](../../../../theories/shengsheng-buxi-generative-existence/unified-2026-10-05/NONINSTRUMENTAL-CONCERN.md)，实现见[模型包](../../../../experiments/integrated-correction/general-framework/generative-basis/noninstrumental-concern/README.md)。

## 1. 本轮判定

**接受这项明确有条件的规范—操作接口：C1/C2 被独立陈述，一个患者及其事件得到保持，指定回应方案可以在共同生成核心中由真实付费历史实现，且保留了理由、事实、许可、选择与执行的区别。** 独立重建及新目录编译通过，下面列出的范围修正和反例已经保留。

这一判定不声称 C1/C2 已从纯因果公理证明，也不证明一体之仁的全部对象范围、普遍理性强制、任意患者冲突的优先次序或自主道德成长。给定程序能实现一个有根据的回应，与程序因认识其道德根据而行动，是不同命题；此次运行守卫不读取 `Merit` 或 C2。

新增贡献比重复既有理由可达性定理更具体：此前[理由传递](HUIGEN-REASON-TRANSPORT.md)刻画哪些给定锚和有效传递能覆盖目标；[评价奠基](../../../../theories/shengsheng-buxi-generative-existence/unified-2026-10-05/EVALUATIVE-GROUNDING.md)已将形成的动机用于有根据的角色修复。这一轮把 C1/C2、患者/事件索引、当前方案费用及真实交付的相容条件直接落实于既有 `Generative.Process` 和 `Trace`。它是新局部实现，未声称继承旧可塑性模型的完整材料与学习历史。

## 2. 正向原则与仍需回答的对手

审查者认可的最强当前起点，是[最新构成性候选](../../../../theories/shengsheng-buxi-generative-existence/unified-2026-10-05/UNIFIED-ETHICAL-GROUNDING.md#the-constitutive-candidate-and-its-test)的 C2：在独立识别的干净领域内，同一患者确有严重、仍不愿继续的体验性负担；某行动者有保持该患者、合宜且有效缓解的现实方案，那么这种缓解构成该选项的一项患者指向道德优点，先于行动者私人采纳帮助目标。

正面理由是它能解释：为什么为这个患者选择真正有效的救助有根据；为什么同样费力的空转缺少这一优点；为什么只降低旁观者不适不是完成回应；为什么新发现的正确手段可以替代旧方法而不抹除患者根据。其充分性仍属实质伦理判断，不能通过把 `Merit` 定义为因果改善来取得。

必须保持三种不同挑战：

1. **私人采纳之前是否存在道德优点。** 真正的 elective-concern 对手承认患者之坏，却主张合法自愿关切或某种关系是这个行动者理由的必要部分。它必须说明选择之前的患者利益为何没有任何正向效力。承认客观道德要求而仅限制更强理性权威的对手，不是这个主张的直接反例。
2. **有理由是否已有义务。** 一个对手可承认 C2 的优点，却坚持陌生人的需要不能在没有责任关系时限制自主活动。本轮 C2 没有证明它错误；[有限救助研究](../../../../theories/shengsheng-buxi-generative-existence/unified-2026-10-05/UNIVERSAL-ETHICAL-MINIMUM.md#from-moral-favor-to-a-bounded-rescue-requirement)另行辩护从比较到要求的原则。
3. **持续需要下如何保留多元生活。** 将助手全部终身成本计入，仍可能与很强的持续救助要求相容。资源累计账本不能独自给出正当停止的阈值，也不能证明任何个体项目应让位或不应让位。

因此，本轮形式化接受 C1/C2 的明确地位，检验它们能否与同一操作世界相容；不以成功执行宣告上述争论完结。

## 3. 非循环形式门与代码对应

| 验收门 | 本轮实现与边界 |
|---|---|
| 患者好坏独立于奖励与名字 | `PatientCondition` 保留患者、事件及形式负担；`Realized`、`Bad` 是独立解释。正数本身不识别体验、严重性或局部坏 |
| 理由不是待证结论的别名 | C2 接受独立的 `Merit : State → Patient → Prop`。`candidateMerit` 只是满足 C2 的一个定义性解释；它不充当 C2 的独立证据 |
| 资格不预设已关心或先前角色 | `Eligible` 使用实际负担、许可与指定方案费用。奖励、角色、先前私人采纳仅是此实现中不参与运行律的标签；它们不代表所有现实动机或关系 |
| 证据与客观根据区分 | `none` 与读到的零不同；不知道不抹除实际负担。`Current` 现场核对真实条件，是供给的可靠接口，不是旧记忆自动发现隐藏变化 |
| 同患者、同事件且真实付费 | 末端实际动作改变所选患者的量，保持事件；合成定理同时给 `Trace`、末端负担为零和准确余额等式 |
| 保留失效与冲突 | 失去许可、钱不足或拒绝不改变尚存患者条件；旧事件/手段包失效；两患者的分别理由不自动提供联合计划资金 |
| 去掉 C2 后保留同一因果法则 | `zeroMerit` 与形式正负担及同一帮助历史相容，却不满足 C2。它证明所列前提不蕴涵 C2，不证明 C2 为假或利己主义正当 |

具体代码固定一个回应者和两个患者，候选选项由 `servicePlan(s,p)` 指定。一般论证可以讨论任意行动者及手段；本轮程序没有以此获得所有行动者、所有可能选项的实现。C2 为充分条件；没有这个证书不等于没有任何其他理由。

`run` 是按给定列表计算状态的纯函数，不检查事件是否允许。因此，仅证明其计算末端为零不能认证实际执行。当前总定理 `merit_and_actual_service_compose` 同时提供合法 `Trace` 与准确付费，其所用 `Eligible` 在执行证明中真正承担前提。这与只把“知”“行”标签合取的旧形式对应有实质区别。

## 4. 审查促成的修正与保留反例

### 4.1 已支付步骤不能再索取完整账单

最初讨论的固定“有载体需 4、无载体需 6”资格规则，会在实际 6→4→3→2→0 链中，付完读取后错误撤回仍可支付的服务资格。实现前已改为分缓存阶段的指定后缀费用：6、4、3、2。编译和独立路径检验支持该修正。

这些保证针对指定阶段的充分前提。额外进行非必要读取可以清掉已经选择的操作并花钱；例如只余 2 且已经选好时再读取，不会保持原服务可行性。相关文档现已明确读取分支至少需 4、选择分支至少需 3，未把任意额外操作称为无代价改进。

### 4.2 当前有效包不自动证明获取历史

任意类型状态可以直接含一个与现实恰好相符的包。通用定理已由 `action_has_acquired_authorization` 改名为 `action_has_current_authorization`，不再把当前相符当作过去已付费获取。实际空缓存起点的形成、读取、选择与执行历史另外给出了真正来源。普通程序状态的类型合法性与已初始化历史的来源可信性保持区别。

### 4.3 指定方案费用不等于任意状态的全局最小费

独立最短路径检查发现：未形成载体但被外部注入有效选择包的状态，沿原法则 `form` 后保留此包，只需 4 即能执行；指定新建方案仍需 6。这不属于实际空缓存起点的获取历史，但属于合法的形式状态。因此不接受 `remainingCost` 在所有任意状态上给出必要最小费的更强声称。

当前代码只证明该函数是 `servicePlan` 的准确费用，`Eligible` 足以执行该方案，未主张所有可行路线的充要条件。`Cases.injected_cache_defeats_unrestricted_minimum_claim` 将该反例正式保留，而非删除不利输入。

### 4.4 其他患者变化可以增加操作成本

目前任何患者的手段、事件或许可变化都会清除单一选择槽。只余执行费 2 时，即使改变的只是另一患者 q 的许可，也会清除已经选择的 p；p 的事实包、患者根据保持，但重新选择后至少需 3，已不可付。新案例及正式定理 `global_invalidation_has_a_cost` 保留此结果。

因此，“其他患者的事实未被覆盖”不能升级为已选动作或可行性的任意非干扰保证。这是声明的保守失效机制及其代价，不是声称设计最优。

### 4.5 联合计划与整个世界的可能性不同

6 单位起点可分别支付 p 或 q 的服务；指定完整双服务序列需 10。正式资金障碍针对该序列。环境事件仍可能改变世界，不能据此声称任何未来都无法缓解两人的负担。此模型既没有建立总量排序，也没有用某个患者未获服务来否定其根据。

## 5. 独立重建与新目录编译

可重跑的审查程序是 [independent_review.py](../../../../experiments/integrated-correction/general-framework/generative-basis/noninstrumental-concern/independent_review.py)，完整结果与冻结源哈希见 [independent-review.json](../../../../experiments/integrated-correction/general-framework/generative-basis/noninstrumental-concern/independent-review.json)。审查者从事先协商的事件规格及 Lean 定义独立编写不可变状态解释器，在编写时没有查看生产 Python 函数体；只将生产 `step`、`eligible`、`remaining_cost` 作为被比较对象。它未导入生产解释器来计算自己的预期值。

| 检查 | 结果与含义 |
|---|---|
| 保存场景重建 | 18 个场景、90 个顶层保存字段全部一致，包括每步完整状态、失败位置、末态、资格与费用 |
| 明列有限直积 | 14,080 个有类型状态 × 25 个事件，共 352,000 次完整转移比较一致；其中包括不可达的缓存组合 |
| 实际空初态路径 | 深度至 6 的 1,486 个去重可达状态、10,140 个事件比较一致；保留当前缓存/选择关系和准确支付 |
| 数据损坏 | 12 个患者、事件、版本、负担或路由包变体，在相应选择/执行检查中被拒绝 |
| 真正最短路径搜索 | 640 次 Dijkstra 搜索不调用后缀公式；352 个满足形成一致性条件的检查与费用相等，另保留 128 个注入缓存状态的更便宜路径 |
| 独立全新编译 | 以现有 Lean 4.29.1 在独立临时目录编译真实 `GenerativeCore`、`ResourceContinuation` 及三个新模块；66 个新增声明的依赖打印审计通过 |

所有编译步骤成功，无 error、warning 或 `sorryAx`。依赖仅含相应声明所用的标准 `propext`、`Classical.choice`、`Quot.sound`，不包含隐藏伦理公理。39 项既有模块依赖审计随新编译重查，不能计成新增定理。临时对象文件不纳入仓库，日志文本及源哈希已经进入独立 JSON 记录。

有限直积的数量、事件字段和缓存模式都由审查程序明列；它不是无界状态穷尽。不可达有类型状态检查结构守卫，不能因此取得获取来源。运行时与 Lean 的对应仍是声明范围内的重建与所选例子，没有任意 Python 程序全局精化定理。未增加现实行为、神经或患者实验，也没有普通控制器性能优越性结果。

## 6. 主文和共同理论整合的范围审核

已审核[主文](../../../../theories/shengsheng-buxi-generative-existence/unified-2026-10-05/NONINSTRUMENTAL-CONCERN.md)、[数学说明](NONINSTRUMENTAL-CONCERN-MATH.md)、[模型 README](../../../../experiments/integrated-correction/general-framework/generative-basis/noninstrumental-concern/README.md)、[形式核心 F14](../../../../theories/shengsheng-buxi-generative-existence/unified-2026-10-05/FORMAL-CORE.md#f14-noninstrumental-patient-reasons-and-paid-response)以及[统一理论 §10](../../../../theories/shengsheng-buxi-generative-existence/unified-2026-10-05/THEORY.md#10-shared-generativity-and-善)。它们应继续使用本轮的三个边界：指定方案的准确费用；固定行动者、分别索引的患者；存在合法实际历史而非所有调度必然实施。

F14 将 C1/C2 与先前 F1–F13 区分，没有追溯性地把伦理前提加入旧定理。`candidateMerit` 与 `zeroMerit` 的作用已明确：前者是合同的定义性实例，后者是去掉合同后的相对不蕴涵见证。正向哲学辩护的作用不由这两个形式解释取代。

缓存分支的通用定理承接给定状态中已有包，不重新证明起点之前的全部费用与获取历史。已建议主文明确“实际空缓存初始化历史”的来源范围，并区分符合有据理由的回应与把道德理由之为理由作为内部认识对象。这些限缩不减少已经完成的条件操作连接。

## 7. 仍供给的前提与下一桥

本轮仍供给患者领域及实现、C1 的局部坏识别、C2 的跨主体实践效力、许可的正当解释、忠实读取、现场核对、版本通知、材料配方、调度和指定操作程序。成本表说明供给的操作如何付费，不说明这些操作或其正确性如何自行生成。

下一连接应使实际形成的评价与认识机制能够可靠发现、保留和修正患者根据，而不预装本轮已经正确的解释与响应程序。患者身份或负担识别失败会修改实现/语义；满足当前范围却无所称局部坏的案例会修改 C1；有根据的先行关系限制会修改 C2；许可、正当成本与竞争根据改变会修改具体义务和选项；在所供给前提保持时的错患者、旧事件或未付费执行则会推翻相应实现结论。这些结果各自改变一段论证，不能互相冒充。
