## 1. What advances beyond the previous test

The previous model distinguished report content, admitted support and practical response, but the usability of a report was supplied. Its copied-error case showed why maintaining dependencies among accepted records could still admit a false answer.

The present model supplies a production process and lets acquired records constrain which production relationships are possible. Calibration, disturbances, reporting and subsequent assessment are moments of the same modeled activity. The learner is not given the actual route's identity or the live target. The inherited decoder, already formed through paired contacts, reads the new records; its formation is not counted again.

The new inference has three parts:

1. Probe how changes propagate through the reporting activity, retaining the resulting records.
2. Preserve every candidate route compatible with those records; unresolved distinctions stay unresolved.
3. Accept a live answer only when all compatible target/route/disturbance combinations agree.

This is a constraint-based realization of the generative proposal. It does not establish superiority over conventional causal inference. Its affirmative contribution is to connect acquired distinctions of dependence to the declared scope of reliance, rather than locating warrant in a source's name, agreement count or intrinsic reliability.

For the larger ethical programme, this advances **formed recognition and calibration → the factual understanding available to situated reasons and responsibility**. It does not add an ethical premise, prove G0 from source reliability or substitute reliable inference for justified concern. G0/J1–J4/E retain their separate, completed axiomatic scope.

## 2. One production process, four possible routes

The route has two structural features. One determines whether the second report copies the first report after a local disturbance. The other determines whether a common disturbance reaches both reporting paths. These are differentiated relations within the production process, not independent subjects confronting an external domain.

| Route feature | Physical consequence in the model | What it does not mean |
|---|---|---|
| Second report copies first | Changing the first report also changes the second | Copying is not itself falsehood or uselessness |
| Second report has a separate path | Local disturbance of the first leaves the second unchanged | Separate paths need not avoid a common failure |
| Common disturbance reaches the paths | Both can report the opposite of the actual target | Shared vulnerability is relative to this specified disturbance |
| Common disturbance is bypassed | That disturbance does not change these paths | This is not immunity to every possible failure |

Their combinations give four candidate routes. The laws are explicit Boolean transformations. The target, a disturbance of the first report and a common disturbance belong to each production event; two reports result. In a calibration event the target and applied controls are recorded. In live assessment the target and realized disturbance are not supplied to the learner.

The six calibration probes cover both target values with no disturbance, local disturbance alone, and common disturbance alone. A partial protocol uses only baseline and a local probe. The learned candidate list changes through the observations, not through a preassigned label stating which route is reliable.

The local projection preserves retained evidence, propagation of the declared disturbances, report decoding and subsequent inference. It omits actual laboratory apparatus, social source formation, intervention costs, probabilistic noise, uncertainty about which intervention occurred, changing routes, and the acquisition of the candidate vocabulary itself. In particular, it assumes that an induced disturbance is informative about the corresponding later failure and that the route law remains stable across the transfer. These are correspondence and applicability obligations, not separate ontological realms.

## 3. Checked affirmative results

| Test | Result | Explanatory consequence |
|---|---|---|
| Baseline report alone | All four routes remain possible | Initial agreement does not disclose its production history |
| Baseline plus local probe | Copying is resolved; shared vulnerability remains unresolved | A local independence test cannot settle a different common failure |
| Full calibration at both target values | Exactly the actual route remains, within the four-route family | A source distinction can be acquired from the consequences of controlled changes |
| Duplicate the same records | Candidate list is unchanged | Repeating these records adds no constraint; this is not a theorem about independently repeated noisy measurements |
| Recode signals and inherited calibration together | Learned routes remain the same | Acquisition does not depend on raw symbol shape |
| Separate path bypassing the common disturbance | The second report supports the target despite any of the declared disturbances | Reliance is justified relative to the covered routes and faults |
| Faithful copying with no admitted disturbance | A definite correct answer remains available | Dependence does not invalidate the evidence carried by a reliable chain |
| Copying with unknown local corruption | Agreeing reports leave opposite targets possible | Report count cannot repair ambiguity about their common origin |
| Separate paths with unknown common disturbance | Agreement again leaves opposite targets possible | Noncopying does not establish independence from common failure |

The correctness theorem is general over every probe list, not restricted to successful identification: if acquisition follows an included route, the live disturbance belongs to the declared possibility set, and the procedure issues a definite answer, that answer equals the actual target. Identification of a unique route is unnecessary when all remaining possibilities already support the same answer.

There is also a checked indistinguishability result. Two copied reports can be identical with a false target and no local disturbance, or with a true target and a local disturbance. No deterministic procedure receiving only that report pair can return a correct definite answer in both cases. The actual modeled histories differ; the available observation does not. The result concerns this observation boundary and these two cases, not all knowledge or every possible inquiry.

Thus suspension can be appropriate after learning as well as before it. Discovering the production mechanism need not remove uncertainty about what happened on this occasion. This is a distinction between a mechanism and its currently unresolved operation, not a demand for omniscience.

### Omitted joint failure

A fifth, explicitly defined production law agrees with the separate, common-disturbance-bypassing route on all six calibration probes. When local and common disturbances occur together, however, a newly represented joint path reverses both reports.

For an actual true target with both disturbances present, that law produces two false reports. The original learner, whose model family omits the joint path, identifies the apparently secure route from calibration and returns a definite false answer. Its declared disturbance envelope even includes both disturbances. The failure is therefore **omission of their joint production effect**, not merely failure to list the disturbance combination or test the other target value.

This is a causal counterexample to an overextended inference from this calibration. It does not freely switch a truth or understanding predicate, and it does not refute the full generative theory. It shows a substantive failure of the narrower route family under a concrete omitted mechanism.

Adding a calibration probe with both disturbances reveals the discrepancy. Every member of the original family is excluded, and the procedure suspends rather than treating an empty candidate set as certainty. The old records remain the prefix of the extended history. Correction adds counterevidence without rewriting what the earlier reports asserted or what was observed.

The current learner diagnoses inadequacy; it does not automatically invent and justify the correct expanded family. That remaining explanatory task is stated rather than concealed by supplying the replacement law to the learner. The joint-failure law belongs to the test harness and counterexample, not to its original repertoire.

### Why the limitation does not erase ordinary warrant

The theorem gives a conditional guarantee; ordinary warranted judgment need not eliminate every imaginable alternative. The earlier account already makes relevance, feasible checking, actual failure pathways and reopening conditions part of inquiry. This study specifies one such pathway and demonstrates the consequence of omitting it. Whether that possibility should have been investigated before acceptance depends on evidence of its relevance and the warranted demands of the actual inquiry.

Conversely, success within an explicitly closed model cannot itself establish that closure is warranted. The positive account requires proportionate, independently assessable reasons for the admitted scope. Those reasons can be acquired and corrected within the same activity; they need not arrive from an infallible outside evaluator. This is a philosophical proposal connected to the checked example, not a new formal theorem of universal justification.

## 5. Primary-source comparison

**Whalen, Griffiths and Buchsbaum, 2017.** Their three experiments compared judgments under different patterns of shared information. Experiments 1–2 distinguished shared underlying data from separate information but did not significantly distinguish independent from sequential testimony. Experiment 3 used a stronger contrast and found that distinction. The procedures supplied participants with descriptions of the information paths. They therefore support sensitivity to described dependence, without establishing discovery of hidden production routes. Their Bayesian comparison is a serious conventional account; aggregate fit does not uniquely identify a cognitive mechanism. Reading scope: model setup, experimental methods/results and discussion, pp. 1–17. No raw data were reanalyzed. [Primary paper](https://cocosci.princeton.edu/papers/Whalen_et_al-2017-Cognitive_Science.pdf).

**Yang, Katcoff and Uhler, arXiv v3, 2019.** Their treatment of general interventions characterizes causal equivalence under explicit graphical and intervention conditions. It reinforces the need to state what an intervention preserves and which distinctions it can identify. It does not authorize inferring arbitrary causal completeness from a short successful probe sequence. Reading scope: abstract, introduction, related work and §3.1–3.2 setup; the algorithm, empirical evaluations and full proofs were not independently checked here. Our Boolean construction is not an implementation or Lean verification of their DAG results. [Primary text](https://arxiv.org/html/1802.06310v3).

These comparisons locate the empirical relevance and the conventional alternatives. They provide no evidence that the complete theory is uniquely necessary. No source originals were imported in this round; these are linked primary readings with declared scope. Earlier empirical reproductions retain their original scope and were not rerun.

## 7. Substantive counterreview and the next boundary

**The candidate vocabulary is supplied.** Correct. The learner acquires which of the admitted production relationships holds, not the concepts or complete causal family from nothing. The result advances the prior usability-label boundary by one connected step; it does not silently eliminate all supplied structure.

**The intervention might change the route itself.** Correct. Stable transfer is built into this construction. A real application needs evidence about intervention specificity, alteration, recovery and temporal change. A manipulated report's effect alone cannot justify a claim about every unmanipulated reporting event.

**A conventional learner can do this.** Correct. The procedure uses ordinary filtering of production hypotheses and agreement over compatible cases. Its contribution is a clear realization and scope audit for the relational account. The previous exclusive-necessity limitation remains; a new dependency label does not create a new monopoly on explanation.

**Calling the result warranted may overstate it.** The checked result is conditional correctness and appropriate suspension under declared coverage. Philosophical warrant additionally concerns why that coverage, acquisition and transfer are adequately supported in the inquiry. The code calls its procedure `rely`; that name does not prove that every invocation is warranted.

**Must ordinary knowing include this explicit machinery?** No. The model articulates one reflective empirical practice. Stable skills, animal cognition and ordinary testimony need not contain an explicit enumeration of routes. Their explanation must be assessed at its own scope, preserving relevant formation and error relationships.

**Does shared vulnerability make every dependency suspect?** No. The clean-copy theorem preserves reliable transmission, and the scope of vulnerability is specific. Eliminating social dependence would destroy many actual paths of knowing. The task is to understand what information and failure pathways are transmitted.

The bounded connection is complete: acquired production distinctions now constrain reliance, preserve genuine uncertainty and expose a concrete failure of extrapolation. The next unresolved connection is **evidence-guided revision of the model family and transfer scope**, particularly how new failure possibilities become relevant without arbitrary patching or endless skepticism. Reuse the completed general accounts of projection and bounded inquiry; test their correspondence to an actual acquisition-and-transfer case with independently documented production paths. The current comparison supplies no empirical superiority, universal semantic sufficiency, consciousness result or necessity of the whole theory.
