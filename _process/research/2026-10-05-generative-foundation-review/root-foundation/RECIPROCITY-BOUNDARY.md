# “己所不欲，勿施于人”：生成模型中的位置与条件性结论

2026-10-06，Asia/Bangkok。AI 机制与条件审查，不是 Ren 原话，也不是《论语》的逐句历史训释。本页承接现行[慧根](../../../../theories/becoming/chapters/HUIGEN.md)、[伦理根基](../../../../theories/becoming/chapters/ETHICAL-FOUNDATION.md)、[他者校正](../../../../theories/becoming/chapters/RECIPIENT-CORRECTION.md)与[理由运输分析](HUIGEN-REASON-TRANSPORT.md)。本轮贡献是两个自足的条件性推论及其失效检查；不重复运行已有实验或 Lean 工程。

**初步结果：这句话可以成为生成模型中“由自身经历形成他者假设，再经校正成为行动约束”的有界原则。一个精确版本不是把自己的偏好直接复制给别人，而是：用自身厌恶发现可能的受损，在他者证据下修正；对充分根据相同的受损理由保持一致；若存在可行替代，且没有更强或其他未计入的相关理由，就不施加该损失。**

“有界”至少包含三种界限：适用对象与情境的范围；估计误差允许多大的结论；规范理由在冲突中能支持多强的行动要求。它不是一句“有例外”而已。本页分别给出可审查的条件。

## 1. 这句话跨过的五个环节

| 环节 | 可形成的正面结果 | 仍须识别的条件 |
|---|---|---|
| 自身经历→自身欲恶 | 形成对经历与后果的区分、记忆和反应 | 厌恶究竟响应实际受损、误信、习惯还是威胁；报告是否可靠 |
| 自身模型→他者估计 | 以自身为起始类比，推测他者可能遭受什么 | 情境、身体、目标、偏好与历史的差异；角色变换是否正确 |
| 他者证据→修正估计 | 保留目标身份，改正对他者后果的预测 | 证据来源、真实性、可辨识性、记录与获取成本 |
| 受损事实→行动理由 | 在得到论证的伦理根据下，该损失成为反对施加它的理由 | 正面的理由根据、患者范围、行动者范围及削弱／推翻条件 |
| 理由→不施加或保护 | 在可行选项中排除没有充分理由的额外受损 | 行动权限、实际资源、替代方案、其他患者与冲突义务 |

所以它不宜被放成一个脱离前后条件的根节点，也不宜被当作无实际内容的口号。它可以位于“已形成的自我预测→目标有别的他者预测→理由校正→可行行动”的中间连接，并反过来约束理论所允许的推理和决策。

认知在这里承担区分、预测、记忆与纠错；理论把这些关系、条件和反例组织成可复核模型；“理”若用来称呼其中成立的结构或推论，就必须连同其适用条件。这个定位是本研究的分析语言，不声称这三个汉语词在历史上各只有这一种意义。

## 2. 路线一：从自我估计到他者损失的界

### 2.1 模型及独立输入

固定一位行动者 s、一位受影响者 p、情境 c 和非空有限可行行动集 F。x 可以是施加某措施，y 可以是不施加，也可以是另一种措施；**不施加不预设为零损失**。

令 L_p(x) 为受影响者在该行动后的任务损失。这里的损失必须先明确所测维度与时间范围，不能一开始就定义成“所有人都应避免的东西”。它可先是某种可独立核对的功能损失；若解释成体验中的坏处，还需要另有识别根据。

以 T 表示恰当的角色／情境变换：不是只把名字换掉，而是把自己放在对方实际承受后果的位置。令

    M(x) = 自身模型对 T(x) 的损失估计。

考虑以下有实质内容、可失败的校准条件：

    对每个 x ∈ F，|M(x) − L_p(x)| ≤ ε，且 ε ≥ 0。       (E)

E 不是“人都差不多”的代称。它可由两项独立界组成：自身估计误差至多 ε_self；经 T 对齐后，自身与他者在该损失维度上的差异至多 δ；三角不等式给 ε＝ε_self＋δ。δ 必须由有关差异的证据约束，不能为了保住结论任意设小。

两端还必须在同一种可比较的损失标度上。把两个人各自任意缩放的厌恶评分直接相减，不满足这一要求。采用某个具体功能损失尺度，也不等于解决了人际福利比较或所有伦理价值的共同量尺。

### 2.2 命题 E1：有余量的厌恶差额可以保留损失次序

在 E 下，对任意 x,y ∈ F：

    L_p(x) − L_p(y) ≥ M(x) − M(y) − 2ε。

证明：分别用 L_p(x) ≥ M(x)−ε 与 L_p(y) ≤ M(y)＋ε，相减即得。

因此，若 M(x)−M(y) > 2ε，则 L_p(x)>L_p(y)。自己的经校准估计中，x 比 y 更不利的差额大于误差余量，足以推出对方也在该维度上更受损。若另给出某个阈值 τ，则 M(x)−M(y)>τ＋2ε 足以推出他者损失差额大于 τ。**阈值的伦理重要性不由不等式提供。**

这给“己所不欲”的一种积极解释：它能成为值得认真检查的损失信号，且在明确相似性与误差条件下可以成为可靠排序证据。只有“我不喜欢”这一二值信息时，尚不知道差额是否超过 2ε，不能自动套用本命题。

### 2.3 命题 E2：使用自身代理选择的他者遗憾界

令 x̂ 是 M 的 α 近似最小解，即

    M(x̂) ≤ min(x ∈ F) M(x)＋α，且 α ≥ 0。

在 E 下：

    L_p(x̂) − min(x ∈ F) L_p(x) ≤ 2ε＋α。

证明：取他者损失最小者 x*，则

    L_p(x̂) ≤ M(x̂)＋ε
            ≤ M(x*)＋α＋ε
            ≤ L_p(x*)＋2ε＋α。

这是相对于同一实际可行集合、同一损失维度的界。它不声称把他者损失最小化就是全部道德，也不证明所有主体共享同一效用。若均匀校准只在一个置信事件上成立，结论也只在该事件上成立；不能把平均预测准确率直接当成所有候选行动上的 E。

两个手算例子显示边界并非装饰。ε＝0.1、代理差额 0.4 时，他者差额至少 0.2，次序保留。若 M(x)＝0.5、M(y)＝0.4，而 L_p(x)＝0.4、L_p(y)＝0.5，两个行动误差仍各为 0.1，但次序反转：较小的自我差额不足以担保。另取代理值都为 0.5、真实损失分别为 0.6 与 0.4，平局选择较差行动可恰好达到 2ε；一般情形不能无条件收紧这个界。这些是展示性数学例子，不是新实验。

### 2.4 他者反馈怎样改进这个结果

自身信息可以启动估计，不应垄断估计。若实际他者证据产生一个新的估计 G，并获得更小的均匀界 η，E2 对使用 G 的选择给出 2η＋α。改进的是可证明的最坏情形保证，不是每个个案必然实际更好。取得证据的成本、延误与风险也要进入行动比较；不能用“更准确”就自动证明值得做任何检查。

现行[他者校正结果](../../../../theories/becoming/chapters/RECIPIENT-CORRECTION.md)已经给出更具体的机制见证：自己的有效反应可对另一个目标失败；保留目标索引、付费取得真实后果并改写对应关系，可以纠正他者行动且不覆盖自己的有效关系。它支持“推己必须能被他者校正”的接口要求。该模型的目标是资源账户，不是已被识别的体验主体；其结果没有测定这里的伦理损失或 ε，也没有解释关切为何获得规范效力。

## 3. 路线二：从具体根据到他者情境中的理由

### 3.1 先给正面根据，而非只要求形式一致

“所有人一视同仁”也可以被实现为谁都不在乎，所以只靠对称性不会产生第一个正面理由。现行[伦理根基](../../../../theories/becoming/chapters/ETHICAL-FOUNDATION.md)提出更有内容的路线：某些经历、剥夺与受迫处境对当事者有独立的好坏，并在共有行动中提供应被考虑的理由。

可选一个狭窄根据开始，例如当事者实际承受的、并非仅由旁观者不喜欢而定义的厌恶性经历。先论证它为何足以提供某一种反对施加它的理由，再检查改变受影响者或行动者后，充分根据是否仍在。理由的正当性不能靠把“厌恶”改名为“人人必须避免”来获得。

这是一条积极的规范主张：如果认可某经历因为它对承受者的坏处而提供理由，那么在这些坏处与适用条件保持时，仅由“承受者不是我”便将理由归零，需要一个真正相关的辩护。该主张不要求所有人同样感受，也不要求把特殊责任抹掉；它要求说明特殊责任怎样改变当前理由或增加另一种理由。

但“这个坏处是跨主体的充分理由根据”仍需实质辩护。现有因果模型并未独自完成它的必然性证明。本页沿用伦理根基对这一正面路线的支持，不把研究仍开放误写成没有任何规范理由，也不把支持误写成已完成的形而上学证明。

### 3.2 命题 R1：根据保留时的理由运输

令 R(a,p,c,k) 表示情境 c 中，患者 p 的某种处境给行动者 a 一个 k 类行动理由。作以下区分：

1. **正面锚点。** 一个具体 R(a₀,p₀,c₀,k) 已得到独立辩护；它可能首先从自身经历被认识，但“怎样认识”与“为何成立”不是同一件事。
2. **充分根据。** 给出 g 所记录的事实与规范适用条件，并论证对这一理由类别，保留 g 足以保留理由。g 不能为方便运输而默默删除真正相关的关系。
3. **目标符合。** 当前目标案例确实保留该根据，患者范围与行动者范围都得到覆盖；不存在使该理由不适用或被消解的新条件。

则目标 R(a,p,c,k) 成立。这是根据保留的有限推论，可以串联使用，并与[已有运输分析](HUIGEN-REASON-TRANSPORT.md)的锚点及有效运输链相接。它只推出一个可与其他理由竞争的理由，不推出相同总权重或相同行动。

这里没有把整句“己所不欲勿施于人”放进前提。正面锚点可以只关乎一种狭窄受损；g 可以容许偏好、责任、同意和情境的差异；有效运输的覆盖也可以局部。真正待论证的部分是该具体根据及其范围，而不是一个已经包含全部结论的“普遍善”定义。

反例也准确：令所有行动者只认可自己的受损理由，即 a＝p 时 R 为真，a≠p 时为假。它可保持同时重命名的一致性，却不产生他者理由。这表明从自身审慎与标签对称性到他者地位之间仍缺一步；不表明该自我限定在伦理上正确。欲使 R1 跨过这一步，必须辩护患者根据或共有行动的可问责性，不能用改名字代替。

### 3.3 一个更近于日常互易要求的正面起点

若我已经有理由向别人提出“你不要对我施加这种损失”的要求，起点便不是纯粹的 R(我,我)，而是一个明确的人际主张 R(别人,我)。若另一情境中角色互换而该要求的充分根据、责任与削弱条件均保留，那么相关一致性要求我也承认 R(我,别人)。这正是 R1 在互易情境中的一种有力应用。

它比从“我不喜欢”起步多了一个重要承诺：我主张自己的处境对别人的行动具有理由效力。它可以约束“只对我享有例外”的论证，但没有规定所有角色互换都在道德上相同。不能忽略对方的不同偏好、同意、责任或能力，再声称自己保留了全部相关条件。

这也不是报偿交换。若理由的根据是受影响者遭受的坏处，而不是偿还能力，它可以覆盖不能回报、不能争辩的人。是否确有这种根据及患者范围，应在锚点和运输依据中直接说明。

## 4. 两条路线相接后，什么条件下真的得到“勿施”

**命题 B：有限的非施加结论。** 对患者 p 与实际可行的 x,y，若：

- 经目标证据或 E1，x 比 y 在一个已识别的受损维度上更差；
- 该受损经独立锚点与有效运输，给当前行动者一个反对造成它的理由；
- 行动者能够选择 y，实际因果后果与执行条件已计入；
- x 与 y 的其余道德相关差别均已列入，且没有足以推翻该比较的相反理由；

那么当前理由结构不支持选择额外施加损失的 x；相对于 x，它支持 y，但不宣称 y 是整个行动集中的唯一最佳选项。这与伦理根基 D1 的有限支配判断相接。若 x 是施加、y 是不施加，便得到该情境下的“勿施”；若不施加同样伤害人，y 可以是另一种帮助或安排。

这不是借损失之名偷装一个外部奖励，再宣布形成了关切。E1/E2 只负责预测与决策性能；R1 负责显露规范根据；B 再加入实际选择与冲突条件。**为什么某种主体会形成、保存并据这些理由行动**，仍是需要因果机制解释的下一层。即便一个主体拒绝这样行动，也不直接推翻已经成立的理由。

若存在冲突，尚可得到较弱但有内容的结论：那位患者的理由进入比较，不能只因其无用、沉默或没有回报而被删掉。此时不保证禁止 x，更不从一个损失函数中直接生成所有人的优先次序。

## 5. 必须保持的反例和削弱条件

| 情形 | 粗糙版本怎样失败 | 可保留的结论或修正 |
|---|---|---|
| 偏好不同：我厌恶公开发言，对方希望发言 | 把自我厌恶直接当作对方损失，禁止其参与 | 目标差异使 E 可能失败；应更新他者估计，保留其选择 |
| 欲恶建立在错误事实或偏见上 | “我不愿被某群体接近”被搬成正当排斥原则 | 自身欲恶只是待解释证据；独立受损识别与理由根据不成立时，不能运输其规范结论 |
| 我厌恶被批评，而批评指出实际错误 | 将不愉快提升为免于一切纠错的权利 | 不愉快可能保留某种理由，但纠错、他人保护与职责可构成相关的相反理由；方式与必要性仍应检查 |
| 通过威胁、奖惩或信息封锁改变他者的表述 | 把“现在他说不介意”当成原损失已经被修复 | 分别检查经历、事实、表达渠道、拒绝条件与自主性。真实偏好也可能改变，但改变评价不自动消除独立损失 |
| 他者明确、自愿且知情地表达不同选择 | 坚持“我不愿，所以你也不该”而覆盖当事者 | 其表达是目标特定证据，并可能另外具有授权意义；真实性、信息及拒绝条件须核查，不把所有口头同意一律等同有效同意 |
| 他者不能表达、反馈丢失或表达受控制 | 把沉默当作无厌恶、无损失、无地位 | 将缺失标为不确定，检查替代证据与代表；患者地位不以发言或报偿能力为定义 |
| 我喜欢某刺激，对方不喜欢 | 从“己所欲”错误推出可以施予 | 原句的否定约束不提供这一许可；应使用对方条件，不能将命题擅自取逆 |
| 两位患者的保护竞争同一有限资源 | 对每人分别套“勿施”，声称已找到同时满足的行动 | 个别可行不等于联合可行；保留两方理由，再论证分配、降低负担与修复责任 |
| 不采取行动也会造成损失，或存在已成立的责任 | 把“勿施”误作永远不行动，忽略放任后果 | 比较实际可行行动的完整后果；禁止一次施加不能独自取消其他义务 |
| 有关角色不对称：承诺、负责范围、权限不同 | 简单换人名，宣称一切差别都是双标 | 记录并辩护真正相关的关系；特殊责任可增加理由，但并不自动消除他者的基础理由 |

这些情形不把每次反对都当成最终否决，也不让“有冲突”成为抹除患者理由的万能借口。须指出改变了哪个事实前提、哪种理由根据或哪项优先条件；否则只是把例外写成决定者的便利。

## 6. 已建立什么，下一连接是什么

本页建立了两个初等手推界：均匀误差下的损失次序余量，以及代理选择的 2ε＋α 遗憾界；它们未经过新增形式化或经验校准。理由运输与条件支配是对现有伦理根基的具体应用，不是新宣称其所有规范前提已从因果根基推出。

下一步最有区分力的对象，是同一个有学习历史的行动者，在自身和他者实际条件不同、反馈有成本、两者不能互相覆盖时，怎样修正“推己”的初始预测，并让经论证的他者理由进入行动。需要保留三份不同记录：**发生了什么、对谁有怎样的意义、为什么构成当前行动者的理由。** 只记录一个“负奖励”会掩盖正在解释的过渡。

对该连接，应分别记录仍由外部给定的目标损失解释、校准界、患者与行动者范围、理由依据、行动权限及资源。何种结果会改变本页：若目标证据系统性推翻自身代理，应收缩推己估计的范围；若运输根据遗漏了真实相关差异，应修正该运输；若有效理由不能进入选择或无法保存，应修正实现机制；若只有调整分析者评分才出现“关切”，则尚未解释其形成。

**可继续使用的限定表述：以己之经验察他者可能之损，以他者之实校正推己；同一充分根据不作任意例外，在可行且无足够反对理由时，不施其损。** 这是本文提出的现代展开，不替代原句，也不冒充古人已经给出的完整模型。
