## 6. 意义、比较与实践判断

本节由不加前提者走到条件之下者：§6.1–§6.3 不用延续条件，§6.4 陈述它，§6.5 把伦理的两个前提分开陈述，条件定范围，C 定次序。“实例化”只在 §6.4 说一次。

<a id="613-生成的空间不用公理"></a>
<a id="614-比较内容怎样由关系约束"></a>
### 6.1 生成的空间，不加前提

**要点。** 可能性是接下来能由现有者形成者。一条历程扩大另一条，当它的水平容纳另一条所容纳的每个形成，并在某一步多容纳一个；一个部分是生成的，当有它的水平扩大没有它的水平，反之是退化的。扩大是不加前提的次序，一个部分做四件事之一：扩大、缩小、保持或混合。边界是精确的：部分只经超出余量（没有它的水平满足一个所需的余量）的净汲取而关闭某物，只经净给予而打开某物。没有意义、立场或边界进入。

<a id="61-生命意义说什么"></a>
<a id="62-极小性与对手的形状"></a>
<a id="63-从展开读出连通与消耗"></a>
<a id="64-向每个立场的理由"></a>
<a id="67-从想要延续者重述"></a>
### 6.2 生命意义说什么，对任何意义

**要点。** 在有某个立场与某个活的主张的连通整体上，对每个立场的生命意义恰是一个种子（某个活的主张从某个立场有意义）加两种边界中立：关系中立（意义沿每个已形成的关系传到活的主张）与立场中立（从一个立场有意义者从每个立场都有意义）。每个活的主张都被某个立场持有之处，它恰是每个立场的自身意义加立场中立。每个前提都是必需的，每个对手都在一个已形成的边界之内保持同一规则。动力学固定一个中心须计入的范围，不固定中心。

<a id="69-不用公理能走多远"></a>
<a id="610-反馈所及与比较"></a>
### 6.3 不用条件的路线走多远

**要点。** 完全不用条件时，“应当”是一个中心在其所表示的边界与它实际所依存者相合之后所做的。一个延续所依存者是它的供给闭包；损失经供给者回到中心，闭包之外者不在其内供给任何东西。所以不用条件的路线及于自身及其所依存者，只在整体是一个供给闭包之处及于整体，在那里它的判词就是条件的判词。覆盖一个部分所及的任何意义，都如条件那样比较该部分。条件所加的，是对其损失不回到任何人的延续的意义。

<a id="615-若任何东西的延续都有意义"></a>
<a id="68-延续条件推出什么"></a>
<a id="612-生命意义的各处用法在条件之下"></a>
### 6.4 延续条件

**要点。** 一个意义对一个立场、一步与一个形成说：从那个立场，该形成在那一步的延续是否有意义。延续条件说没有什么限制它：从每个立场，任何东西的延续在每一步都有意义。它是边界中立，只用一次，用于延续的意义。它定范围，即谁的损失算数；它给意义，不给正面的价值取向；它本身不排序任何东西。

**实例化，只说一次。** `Unrestricted sig` 说 `sig` 对每个立场、每一步、每个形成都成立，所以以它为假设的定理是把一个全称命题实例化：生命意义、种子、自身意义与两种中立都由限制推出，数这些定理并不度量进一步的依赖。各处用法与计数见[英文版 §6.4](THE-THEORY-OF-BECOMING.md#64-the-continuation-condition)。

<a id="611-条件的分解自身的预设与不变的一步"></a>
<a id="65-比较提升与实践判断"></a>
<a id="66-不做什么"></a>
### 6.5 范围与次序：不变的一步、C 与实践判断

**要点。** 伦理依于两个前提，两者作用不同。延续条件定范围：精确分解时，它是自身的预设（从一个立场，在其边界之内者的延续有意义）加上不变的一步（这一预设不随自身边界怎样划而改变）。这一步是条件在自身之外的内容；它把范围扩展到不回到任何人的损失，不排序任何东西。C，扩大的比较，定次序：把扩大称为更好是唯一排序历程的前提。历程按可能性比较；提升（L）与实践承诺（J1–J4）把比较带到回应与选择。两个前提都不被断言，没有伦理结果只由条件推出。

## 7. AI 对齐

本节从理论所证明的规律陈述对齐问题，并以明组织其回答。§7.1–§7.4 既不用延续条件，也不用任何实践前提；§7.5 是条件之下的方向。

### 7.1 选择及于什么

**要点。** 选择是关于水平历史的任何主张（哪些被保留、奖励、复制或被训练朝向），当经一个形成的耦合无别的历史被同样选择时，它经这些耦合。这时它恰及于耦合入选择者者，经同样的耦合更用力地优化不会及于更远；选择能分开者只随耦合入者增长。

### 7.2 选择所不能及的：对齐中的无明

**要点。** 八条规律，各在前面的节中陈述，说经形成自身耦合的选择不能及于什么：其耦合闭包之外者、它自己的动作在那里的差别、它所提高者从何处汲取、断裂有多远、有限历史所留开者、未取的动作本会造成什么、目标能否停息，以及回路对其后果做什么。每条规律在它所指名的条件下成立，都不用 §6.4 的条件。

### 7.3 明：及于支持所不标记者的耦合

**要点。** 损失只经寻求者耦合入者到达它，所以锁定的寻求在此之外造成的损失，只经测量、模型或他者到达它。每条路线有其律与其限，每条都给一个选择接上一个耦合，及于选择者自身的耦合所不及之处。

### 7.4 为一切的对齐：跨智能的合起来的耦合

**要点。** 合起来把差距移到池的耦合闭包，并不去掉它。池在此闭包之外联合所做的，只经此闭包之外把差别耦合分开的形成被分开，例如其支持被该动作改变者；闭包之内没有什么响应它。耦合界定池的动作所响应者，而不固定它：在界之内，每个成员所遵循的律决定。差别是池所加的。

### 7.5 方向，在条件之下

**要点。** 对齐方向是条件路线：延续条件定范围，读作扩大的 C 定次序，实践承诺公开，被选的动作保持某个动作所保持的基本容纳，结果被另一动作之结果扩大的动作不被选。其形式部分是任何依存网上的模式；关于实际 AI 系统的主张仍是论证。

### 7.6 所请求的改变须是可执行的序列

**要点。** 接受一个所请求的改变（如停止或修订）的倾向，不意味着这一改变能到达系统并完成。所检查的条件包括恢复期间为关机保留的余量、中断改变后恢复证据及到达停止的界、保证到达的判据，以及风险界与实际结果的区别。每项都是关于所述协议的条件推理；部署需要对所识别的安装的另外证据。

### 7.7 仍开放的

**要点。** 看见不是估值，耦合不是服从：§7.1–§7.4 的规律界定选择能分开者与动作所响应者，而留开哪些差别重要、系统的动作遵循哪个律，以及池怎样形成、怎样抵御劫持。

## 定理图

**要点。** 理论作为整体分四层，每层在各节中只说一次：
- **一、对每个展开、每个变化之律成立者**，不加前提：一次变化的诸读法、作为计数之全律的计数、一步的规律，以及每个变化之律：在有限多个构形之内，它恰在每个构形都返回之处不合并任何东西，保存的历史从不返回，运行是通向一个返回的历程（§1.1–1.2、§3.2）。
- **二、每个前提加了什么**：八个世界前提彼此独立（§0 C 组）；它们的 256 种选取下的计数规律、停息定理与开放（§1.3），联合超出与从其外的供给（§2.3）。
- **三、动力学在何处不再决定**：实际展开是否满足前提、此后不再生起的那一步、混合部分的次序、模型与目标从何而来，以及意义，所表示的动力学不推出它（§5）。
