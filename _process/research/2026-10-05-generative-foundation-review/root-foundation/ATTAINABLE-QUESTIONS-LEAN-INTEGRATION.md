## What is now proved

[AttainableQuestions.lean](../../../../experiments/integrated-correction/general-framework/generative-basis/lean/inquiry-root/sufficiency/AttainableQuestions.lean) reuses the original `Policy`, `After` and `Sound`. Each inquiry acts through the actual process before filtering its acquired observation. The policy must choose a common enabled action, preserve its declared condition and account for every allowed successor. An initially empty possibility set cannot establish attainability.

A question is represented by an agreement relation. For a fixed answer function, two configurations agree when that function returns the same answer. `Identifies` requires an admissible inquiry and agreement at each reached terminal leaf. Logical termination uses the existing empty response word; a physical report, retained memory or decoder must be represented separately when that stronger implementation claim is made.

The constructive proofs establish:

- **Downward closure:** the same inquiry answers a coarser question. No monotonicity certificate is supplied as a premise.
- **A common inquiry for combined answers:** a single policy answers the conjunction exactly when that same policy answers both questions. Separate policies cannot be substituted for the shared policy. A corresponding family result preserves this quantifier order.
- **The obstruction to a greatest question:** if two attainable questions have an unattainable common refinement, no attainable question can refine both. Consequently no greatest attainable question exists in any proposed question family containing those two questions.
- **Continuation through actual reached conditions:** attaching a certified continuation at each actual leaf composes the inquiries while preserving native safety and progress. Preservation of the first target distinction is explicit. For fixed historical targets, a theorem derives this preservation from the native law's retention of their identifying coordinate.

The policy syntax and inquiry semantics were not replaced with a static partition calculation. The negative result concerns inability to acquire two compatible truths in one permitted history, not failure of logical conjunction after both answers have actually been acquired.

## Exact one-packet result

[OnePacketQuestions.lean](../../../../experiments/integrated-correction/general-framework/generative-basis/lean/inquiry-root/sufficiency/OnePacketQuestions.lean) formalizes the pre-existing permissive comparison on fixed initial targets A, B and C. A is open with matching readiness; B is open with reversed readiness; C is the blocked behavioral class. Either informative probe consumes the sole source packet. Their first observations remain:

| Fixed initial target | Test A | Test B |
|---|---:|---:|
| A | positive | negative |
| B | negative | positive |
| C | negative | negative |

The state retains the initial target after consumption. Arbitrary target-independent controls with any common observation remain available and do not replenish the packet. Further exhausted probes return a distinct common denial. This is more permissive than the saved finite graph, which disables a probe after exhaustion; denial adds no target information. Ordinary support, computation and logical observation-path retention are granted as in the original comparison.

For **every answer function** \(f\) on these three initial targets, Lean proves

\[
\operatorname{Attainable}(f)
\quad\Longleftrightarrow\quad
f(B)=f(C)\ \lor\ f(A)=f(C).
\]

Necessity is an induction over arbitrary finite adaptive policy trees. Before the first informative probe, common controls retain all initial possibilities. Either probe leaves a negative pair; after depletion that pair has identical subsequent observations for every available action. It cannot be separated by arbitrarily many further controls or denials. Sufficiency constructs the appropriate single-probe inquiry.

Thus “initial A?” and “initial B?” are separately attainable, their combined answer is not, and “initial C?” is also unattainable. There is no attainable common refinement of the first two, hence no greatest attainable fixed-target question. This is stronger than checking a selected two-command schedule and keeps current behavioral collapse distinct from knowledge of the initial target.
