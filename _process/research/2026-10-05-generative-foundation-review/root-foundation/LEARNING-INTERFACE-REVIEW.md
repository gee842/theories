## 1. A meaningful universal contract

A deterministic controller has internal memory, a command determined by that memory, and a memory-update function receiving an accessible consequence. A closed-loop history must also contain an actual plant transition: a command is not an executed event merely because the controller issues it. Consequences are computed from that transition, and the next memory and plant state are the actual successors. The same controller and initial memory receiving the same complete consequence history must issue the same command history and finish with the same memory.

The empirical premise is the factorization of the update through this interface. The mathematical implication is elementary and general; the substantive work is identifying the interface independently. A variable called `observation` must include every input on which the update actually depends, including accessible reserve, damage, clock or delay, occupancy, direct material interactions and any retained state not already placed in memory. Actions already determined by memory can also enter its update through that memory. Equality of one reporter alone is insufficient.

At two terminal plant states, supply continuation tasks as fixed future action words. A next command is compatible with a task when some actual plant history executes that command followed by its supplied word. If the sets of compatible next commands are disjoint, the same next command cannot support both tasks. Thus equal complete feedback from equal initial memory blocks simultaneous compatibility. The incompatible continuation sets are an explicit premise, not a universal property of all environmental differences. If one safe command works in both states, a controller need not distinguish them for that task. Disjoint immediately enabled command sets are the empty-suffix special case.

The formal compatibility predicate is existential `Feasible`. It does not say the controller will issue the supplied remaining word, nor that all nondeterministic outcomes permit it. The theorem is an obstruction to choosing a first command compatible with both specified future tasks. Describing this as a complete closed-loop success or robustness theorem would overstate the result.

This advances the derivation by exposing a necessary upstream input to consequence-sensitive revision: some difference must reach and be retained by a mechanism capable of changing later commands. It does not guarantee that the reached difference is reliable, useful, interpreted correctly, retained long enough or affordable to act on. No scalar reward or observer-defined fitness is required for this obstruction.

## 2. Counterexamples and scope boundaries

| Omitted condition or tempting claim | Counterexample or required qualification |
|---|---|
| Any consequential difference produces learning. | The consequence never reaches the controller, or reaches an update that ignores it. The plant can differ while the selector remains unchanged. |
| Equal current observation means equal future behavior. | Two memories retain distinct earlier observations, then receive the same current observation. Their next commands may differ. Match the relevant history and initial memory. |
| Equal reporter histories imply no consequence-mediated revision. | A resource packet or mechanical occupancy acts directly on memory although the measured reporter is identical. The proposed observation interface is incomplete. |
| Distinguishable consequences guarantee useful revision. | A reversed or obsolete consequence-to-command mapping produces the wrong choice. A controller that discards the distinction also fails. |
| A hidden environmental difference always needs to be sensed. | Both environments admit the same continuation command. Difference alone does not create an incompatibility obstruction. |
| Equal commands imply equal realized outcomes. | The plant's latent state changes what the same command does or whether it is enabled. Command equality is a controller statement, not plant equality. |
| A variable selector proves a variable learning algorithm. | Memory changes the command under a fixed update law. The rule that changes memory remains supplied. |
| An informative probe establishes affordable learning. | A separate finite reserve can be exhausted before the probe, replacement or useful operation completes. An uncosted witness establishes logical possibility only. |
| A supported formed-selection history pays for a separate controller witness. | The two modules have different states and transition laws. Their constraints do not compose automatically into one implemented, costed learner. |
| A changed population distribution proves individual revision. | Survival or reproduction removes one pre-existing state and enriches another. Track continuing identity and within-lineage state transitions. |

The generic theorem is deterministic. A stochastic mechanism can be represented pathwise only after random innovations are explicit additional inputs. Equality with a common innovation sequence then describes one coupling. Equality in distribution requires a matched noise law and causal interface, and does not follow from arbitrary reuse of a numerical seed. No probabilistic learning, convergence or exploration guarantee should be credited to the deterministic proof.

### The actual constructive witness

[FeedbackExamples.lean](../../../../experiments/integrated-correction/general-framework/generative-basis/lean/learning/FeedbackExamples.lean) supplies a two-regime world and a probe channel reporting the successor's regime. Its complete accurate-feedback path executes a probe, a matching response and a later use, spending one resource unit for each event. Both responses are physically executable: the mismatching one reaches a dead state. A misleading channel therefore changes the retained response and executes a paid failure rather than being excluded by a definition of admissibility. An arbitrary deterministic controller receiving a blind probe cannot choose a response preserving later use in both regimes. The general `AccountLaw` transfers to this same controller/world process, so the witness joins the information and support contracts within one declared event law.

This is a supplied diagnostic device, update function and response repertoire. The charge is for the modeled probe/response/use events; it does not derive a separate physical price for forming or maintaining memory. Three events require at least three starting units, and a prepared flag with no fuel cannot execute use. These are actual resource constraints, rather than a reward penalty in the update.

The world keeps its regime fixed throughout each history. The positive trace demonstrates acquiring a response from an informative probe; it does not demonstrate recovering after an earlier useful learned response becomes misleading. The retained-memory example shows that different earlier inputs can leave different memory values after a shared current input. Those particular final values issue the same `use` command, so that example must not be described as showing different next commands. The earlier mode-dependent response is the part of the construction where the retained distinction controls behavior.

## 3. Support accounting must use the existing event law

The existing [formed-selection module](../../../../experiments/shared-renewal-capability/regulation/retention/formation/formal/FormedSelection.lean) has independently declared enabled events and actual successor states. Formation, association, repair, copying and leakage have explicit expenses. Incident stock and locally usable fuel are distinct. The existing exact energy ledger includes finite incident stock, while common fuel cannot be replenished by a capture that creates only local fuel.

A new support-interface proof is useful when it derives its local balance from those actual transitions and then applies the generic prefix theorem to the same mixed history. It must retain the starting state and actual intermediate states, count captures where they occur, and preserve all other expenditure. Counting accessible provision as a consequence of capture is legitimate because capture is defined by the physical event law; assigning credits afterward to make a history successful would not be. The account covers executed events in the declared sixteen-event law. Rejected command attempts and any sensing or maintenance expense absent from that law have no new cost simply because an accounting theorem is applied.

Both accounts can be valid at once: conversion of incident stock is credit to usable reserve while remaining neutral in an account that already includes that stock. This boundary choice must be named. It does not establish that unlimited incident stock is accessible before assembly, that a later capture can fund a past formation, or that the source is inexhaustible. The proved three-common-unit startup obstruction remains relevant even when incident stock is present.

The bridge can establish a genuine premise match between the prior mechanism and the universal account. It does not establish that formed selection already implements the new controller's observation and update functions. A separate costed probe/controller witness can join information and support constraints within its own process; a further mapping is needed before calling the chemical event law an implementation of that witness.

The concurrent [formation account module](../../../../experiments/shared-renewal-capability/regulation/retention/formation/formal/FormationAccounts.lean) constructs overlapping usable/source/closed ledgers for the same event law, with an additional common-fuel account, reaction/loss split and explicit zero-demand damage event. The present [support bridge](../../../../experiments/integrated-correction/general-framework/generative-basis/lean/learning/FormationSupport.lean) additionally exposes the local store, local-copy/capture constraints and the actual post-repair handoff. These are compatible, partly overlapping formalizations of one supplied mechanism, not independent empirical evidence or two discoveries of the same accounting principle.

## 4. Identification and comparator contract

The [existing primary-source evidence audit](../../2026-10-05-support-and-shared-generativity/completion/ENDOGENOUS-REGULATION-EVIDENCE.md) already separates induction, passive material persistence, altered future responsiveness and selective survival. This review reuses that audited distinction; it makes no new empirical claim, imports no source data and does not assert that any surveyed biological system realizes the new Lean controller.

A future test needs the following independently specified measurements and comparisons. These are proposed identification obligations, not reported experiments or a preregistration.

1. **Identify the interface.** Measure or bound all channels reaching the candidate selector, its retained state, command, realized action, reserve and continuation endpoint. State the observational resolution and relevant delays. A direct resource or mechanical route counts as accessible consequence even when no symbolic reporter exists.
2. **Separate consequence from cue.** Preserve the cue and action history while diverting or changing the actual return through a declared channel. Verify what information and resources the intervention also changes. Restore that channel with an accounted rescue. If the selector still changes after a supposedly complete channel block, investigate omitted inputs before treating this as a contradiction of the theorem.
3. **Test retention.** Compare distinct earlier histories followed by a common present input; then disrupt the retained state without silently resetting resources or removing the acting apparatus. This tests a historical memory claim rather than instantaneous feedback alone.
4. **Retain complete histories.** Track individual or organizational identity, failed formation, unsuccessful probes, extinction and surviving lineages. A survivor-only report cannot identify unconditional recovery or distinguish population selection from within-lineage revision.
5. **Match the conventional controller.** Give it the same observation interface, memory, feasible commands, proposal opportunities, costs, timing, initial condition and intervention. A controller with the same full transition law must agree on corresponding histories. An outcome difference would expose a mismatch or implementation error; exact equivalence is a valid result.
6. **Include causal alternatives.** Compare ordinary reactive feedback, passive retained material, scheduled switching, and pre-existing heterogeneous modes with differential survival, where applicable. Disrupt memory and consequence channels separately. A competent adaptive comparator is required before claiming an advantage over feedback or selection generally.

The analyst may evaluate distinct endpoints—continued operation, reserve, delay, lineage persistence and effects on other centers—without feeding those scores into the selector. A future endogenous evaluation claim must show the actual causal return by which consequences maintain or revise the selecting mechanism. Private continuation alone neither discovers nor justifies wider concern.

## 5. Acceptance boundary and next connection

Acceptance requires compiled proofs without holes or custom axioms; theorem claims matching the exact controller and support contracts; explicit blind, misleading and memory-history boundaries; actual successor preservation; and a clear distinction between the supplied constructive witness and a derived architecture. Standard logical axioms, if reported, must remain visible. Mathematical verification does not verify physical identification.

The [frozen-source verification record](../../../../experiments/integrated-correction/general-framework/generative-basis/lean/learning/verification.json) passes seven modules and 140 requested declaration audits, including **48 new declarations**: 8 controller-interface theorems, 15 witness and boundary theorems, and 25 support-interface theorems. The 8 controller results report empty axiom dependencies. The other 40 new declarations report only the standard `propext` and/or `Quot.sound`; there are no added axioms or proof holes. The checker compiles frozen copies in a fresh temporary build, verifies all new theorem declarations appear in its audit list, and checks that canonical sources did not change during the build. This review inspected those checks and independently matched the recorded hashes rather than rerunning the unchanged proofs.

Interpretation repairs made during review distinguish complete history from a current reporter, existential continuation compatibility from robust closed-loop achievement, paid events from unmodeled hardware costs, first response acquisition from recovery after environmental reversal, and overlapping ledger formalizations from independent evidence. No blocking finding remains for those scoped results.

The useful outcome is a sharper conditional foundation: lawful consequence-sensitive choice requires an adequate causal information route, retention where the task demands history, and a physically affordable implementation. This is compatible with established feedback and learning descriptions. It carries no priority claim for the elementary impossibility argument or accounting bound.

The next missing connection is to form and revise the consequence-to-retention mechanism itself within the same costed process. That requires a demonstrated joint law, its failure regimes, and a mapping to downstream learning and concern premises. More declarations or a successful toy trace do not alone finish that connection or the [unified foundation](../../../../theories/becoming/chapters/GENERATIVE-GROUNDING.md).
