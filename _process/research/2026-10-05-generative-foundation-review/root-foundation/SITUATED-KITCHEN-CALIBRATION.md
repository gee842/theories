**应用结论：先兑现当前已有根据的食物支持；在保住参与者基本生活和自护的条件下，保留稳定照料与自愿共同学习两种途径；通过实际可及的安排发展能力；按有界承担组织接续。增加技能本身不能决定方案优先，供餐数量不能单独证明生活得到支持，完成培训或宣布交接也不能代替下一阶段的实际接续。**

## 1. 固定待决问题与形成的关系

一处共享厨房通过共同采购、做饭、清理、协商和邻里取用形成。原先熟悉厨房的两人承担较多采购与烹调；其余参与者知道各自饮食、时间及照护限制，有些愿意学做饭，有些只希望继续共享一餐。原有参与者也能从后来的实践中改变菜式、分工及对需要的理解。这些是活动形成的不同位置，并非两类固定的施助者与接受者。

这次决定只覆盖一个**两周安排**：当前供给窗口怎样兑现，下一轮怎样组织，是否安排共同学习，以及一位原组织者怎样结束本轮角色。两周是本例人为固定的规划期限，不是普遍伦理阈值。比较保留转变期间的生活；期末“大家都会做饭”不能删去期间失去的食物、休息或相聚。

构造中预先固定以下条件，先于选择方案：

| 条件 | 本例的明确内容 | 进入真实应用时怎样支持或撤回 |
|---|---|---|
| 当前与下期的生活需要 | 有参与者依靠这两次供给窗口取得其所需食物，缺口没有及时、实际可及的替代，因而中断其基本生活支持。 | 查实际可取得的食物及替代；不能仅凭“少供一餐”便普遍认定基本剥夺。 |
| 共同食物与场所 | 本轮供给可完成；课程与做饭会占用部分相同时间。另一位参与者愿意在明确期限内加入支持。 | 核对采购、使用安排、工作与清理的同一张排班；一项项单独可行不足。 |
| 知情参与 | 学习可以选择，取得本轮已承诺的食物不以参加课程为条件；原安排的变更须经受影响者可理解和质疑的过程。 | 区分不感兴趣、不方便、无法表达和被排除；不同意课程不等于拒绝食物。 |
| 承担及退出 | 原组织者已正当承担本轮协调，有明确结束日期；其他人新承担的支持也有期限与容量。 | 查实际承诺、负担及有效释放；不得从“最会做饭”推出永久服务。 |
| 其他关联条件 | 对采购来源、相邻取用者、未出席者、原有照护任务与累积负担均作核查；下面的窄形式比较暂定这些没有差别。 | 发现食物转移挤占另一处基本支持、额外劳动或其他实质影响，必须扩充比较，原表不能认证完整性。 |

这里没有为休息、食物、能力设任意权重，也没有声称了解厨房的全部未来。即使两种方案在本表中相同，其情感意义、习惯或生态影响也可能不同；形式上的相同只限于投影保留的内容。

## 2. 先说明所比较的实现，再比较方案

G0 提供生活及继续形成的正面方向。J1 保留完整得失，J2 采用已披露的基本条件优先，J3 确定有界承担，J4 要求权限、共同可行性及及时选择。它们并不自行确定“食物到手”“已会做饭”或“可以休息”的真假；这些由 E 承担。

本例把当前食物支持、下一窗口食物支持、贡献者的基本休息／自护作为三个有具体时间及承担关系的保护项目。它们分别记录，不能用下一窗口的成功抵销当前失接。休息项目固定指向本例已辨明的同一承担位置；多个位置受不同损伤时须逐一索引，不能压成一个“有人疲劳”的值。基本休息受损指已经有根据地认定其基本生活条件受损；普通忙碌、一次自愿辛苦或研究者随手指定的工时都不自动满足该描述。

第二层保留三个不同实现：通过实际练习显示的技能、技能连同可用场所及材料形成的可用路线、一个可自行安排的晚上。技能与可用路线有依存关系，并不是两次加分；模型只作包含比较，不求和。“可自行安排的晚上”在本例不是唯一告别、不可替代的照护或基本恢复。一旦实际如此，须更正其内容，不能继续沿用第二层分类。

| 历史／安排 | 当前支持 | 下期支持 | 基本休息 | 技能／可用路线 | 自由晚上 | 本例判断 |

| C 稳定供给 | 保住 | 保住 | 保住 | 无新增／无新增 | 保留 | 有正面根据；不因缺少培训而落败。 |
| L 供给中共同学习 | 保住 | 保住 | 保住 | 形成／可用 | 失去一次 | 与 C 各有真实得失，J1/J2 不给唯一优先。 |

**第一次校准已经改变了先前容易出现的推断：有新增共同能力，不足以单独证明整个安排优于稳定供给。** L 与 C 的剩余取舍要由实际参与者的目的、经历、意愿、相处及失去的时间进一步说明。J4 可支持有期限的自愿安排；不能把不可比解释成研究者可以替大家任意选择。选择 C 也不意味着拒绝一切学习，可以另找时机或容许不同参与路径。

对 C− 的修正也不能被写成“学习解决过载”。若相同的新分工只做稳定供给便能恢复休息，它同样有恢复理由；有无教学并非这一理由的必要条件。真正改变比较的是保住了什么及付出什么。L− 则是反向检验：同样名称的学习活动，可以在新负担证据下失去优先地位。

## 4. 第二轮校准：选择会随什么证据改变

| 新发现／变化 | 应改什么 | 可以保留什么 | 当前回应 |
|---|---|---|---|
| 所谓有余力，实际遗漏了采购、清理和照护安排；新增教学会损伤基本休息 | 撤回 L 的保护描述，改用 L−；若只是普通时间损失，则记录损失，不随意升级。 | 学习形成的技能与共同理解仍可能真实。 | 有 C 时保留供给、暂停或重排课程；没有 C 时公开冲突、寻求有界增援。 |
| 培训者报告“已掌握”，参与者在实际任务中仍无法完成 | 撤回技能已形成及其衍生可用路线；下一期接班预测也要重查。 | 已有理解、练习及当次供给可以保留。 | 安排自愿且不承担关键供给失败代价的练习；不能直接把人排入独立轮值。 |
| 练习成功，但原场所、工具或材料无法取得 | 由 L 改为 L0；不把无法使用改写为没有技能。 | 技能及可能的进一步学习仍有意义。 | 先辨明可及替代；建立真正可用路线的理由，来自实际关系改变。 |
| 有人愿意共享食物但不愿参加课程 | 撤回“全员学习是共同目标”及相应安排资格。 | 食物支持、他人的自愿学习及正当原承担。 | 允许供给与学习有不同参与方式；不制造食物换劳动的隐含债。 |
| 原组织者宣布交接，后继尚未实际接得上 | 撤回“交接已完成”；进一步区分技能、同意、支持及时间缺口。 | 原角色可以正当地结束的理由，后继已完成的准备。 | 在有界范围内重排、通知与补救；不得谎称生活已接续，也不得据此无限扣留原组织者。 |
| 继续原安排损伤承担者基本生活，退出则导致下一窗口失接，暂未找到第三条路 | 撤回“保住其他基本要求”的前提；C− 与退出不再由 J2 排序。 | 两处基本生活的意义及原有责任。 | 尝试缩减、轮换、替代供给或增援；仍无解则作及时且有理由的有限决定，记录未满足的要求。 |
| 没有重大未知会改变当前供给，调查报告却会在供给窗口之后到达 | 撤回“必须先完成全面调查才能供给”。 | 对下一阶段有用的调查与以后重开的问题。 | 在当前供给已有充分根据时先兑现；将调查分到不会消耗关键支持的时段。 |

这些变化有三种不同地位：真实条件改变、原描述被证据纠正、比较承诺本身受到挑战。前两种要求重新应用规则，不自动证明 G0 或 J2 错误；第三种才要求审视规则的理由。例如，完整保留双方得失以后仍有充分理由拒绝 J2 的跨层严格优先，就应公开修改 J2，不能为了保住结论把所有反向损失改称“基本”。

## 5. 本例可执行的两周安排

这是一份在第一节条件成立时可采用的安排，不是已向现实参与者发出的指令。

1. **当前窗口：兑现已成立的供给。** 本轮协调者核对实际可取得的食物和共同排班。没有根据要求先参加培训，也不把当前支持拖到全面调查结束以后。
2. **接下来：分别确认意愿和负担。** 对共同学习有兴趣者与原组织者约定一次有期限的共同实践；保留稳定取餐途径。把采购、准备、清理、教学与其他已有任务放在同一安排中检查。普通时间得失由参与者讨论；基本自护已受损时撤回原方案。
3. **练习中：检查能力及可及性。** 在当期食物另有可靠支持的条件下，看实际练习能否完成相关任务，哪些工具与材料以后也能取得。这里核对具体能力，不要求参与者证明自身“值得受助”。
4. **下一供给窗口：核对实际接续。** 后继接受的承担、技能、支持和时间安排共同支撑事前交接判断；到实际窗口后再核对是否兑现。事前合理安排和事后成功分别记录，不能互相替代。
5. **期末：完成、重议或结束。** 原组织者按正当释放及有界安排结束本轮角色；新的支持按自身期限继续。若关键需要仍未覆盖，记录现实缺口、已尝试的替代与仍可行补救，不把有限失败改称完成，也不把延期设成无限默认。

重新打开判断的触发包括：支持实际不可及、负担显著不同于约定、出现此前遗漏的受影响关系、参与意愿改变，或接班能力／物资／时间证据被推翻。观察由已有承担和实际可及性来分工，避免把全部观察及补救继续加给原来最忙的人。任务结束后没有无期限跟踪所有衍生后果的义务。

这一轮完成的是**应用逻辑与判断敏感性的校准**：固定条件、给出结论、改变足以影响结论的关系、保留不改变的实现，并指明如何查真实对应。经验校准须有上述实际材料，本轮没有把空白表或构造中的布尔值称为经验测量。

## 7. 实质反审及本轮修正

**对手一：稳定照料已经很好，为什么还增加学习？** 这个意见保留食物、相处与休息的完整内容，足以阻止 L 自动击败 C。本轮接受它：共同学习须有自己的具体理由和自愿安排；生生没有给每个人施加生产性成长任务。

**对手二：L 对 C− 的优势是新增帮手造成的，你却归功于教学。** 批评成立。本文明确把实际减负与技能形成分开；同一帮手支持的非教学安排也要入选。形式结果只证明两段指定历史的比较，不证明教学是减负原因，亦不证明 L 在全部可能方案中最优。

**对手三：基本／非基本分类可以操纵赢家。** 第一节与第二节必须先固定生活要求、损失内容和分类根据；未获支持时不能使用 J2 的强结论。真实应用若无法辨清，一方面调查，一方面保留分支判断。J2 本身的强度依然可争论，不能以改标签使其免受反例。

**对手四：为了避免对立，你会不会让不愿参与的人在“共同体”名义下继续劳动？** 共同形成解释位置如何形成，不授予征用权。食物、课程和劳动承诺分别辨明；旧角色及新角色都有有限范围。有效退出与未解决的食物需要可以同时为真。这个冲突出现时必须正面处理，不能称“一体”便消除。

**对手五：只比较两次供给，把更远后果都删了。** 两窗口是本轮形式投影，足以检验一组具体错误，不足以认证长期制度。声称扩大到长期时，证据范围也须扩大。对更远后果已有的可信线索现在就要保留，不能用窗口边界否定其意义；纯可想象后果也不能自动压倒当前所有已支持理由。

**对手六：这可以由普通实践推理或照护伦理解释，不需要专有语言。** 本轮不主张独有预测优势。新增成果是把本仓库的明确承诺真正用于同一案例，并展示其许可、限制及失效条件。如果常规表述完整保留这些内容，得到同样答案就是相容性，不是本理论胜过对手的证据。

| `supported_learning_beats_overloaded_care` | L 优于指定 C− 历史。 | 教学造成减负，或不存在更好的非教学方案。 |
| `care_beats_harmful_learning` | C 优于指定 L− 历史。 | 一切教学有害，或现实已发生过载。 |
| `skill_without_usable_route` | L0 保留技能而没有本投影中的可用路线。 | 这项技能失去所有当前或未来意义。 |
| `restored_access_improves_same_learning` | 其他所列实现不变时恢复可及性改善 L0。 | 恢复可及性现实无代价。 |
| `competing_basic_losses_incomparable` | C− 与当前已供给、下一窗口失接的退出历史不可比。 | 自护较轻、取餐需求较轻，或已获退出许可。 |
| `announcement_cannot_replace_coverage` | 公告值不能代替实际下一窗口支持。 | 公告、承诺对真实协调没有作用。 |
| `actual_coverage_repairs_handoff` | 固定其他实现后，实际保住下一窗口改善失接历史。 | 以未来结果倒推当时权限、知识或过错。 |

交接投影中的公告字段不直接设置供给值，是为了区分**声称**与**所声称的结果**；真实公告可以参与协调并改变后来的实际供给，模型没有表达这种因果过程，因此不能据此否认它。

形式结论都是已指定历史在既有偏序中的关系，不是经验测得的规律，也不是从零推导伦理公理。角色形成、权限、实际共同可行性、领域是否遗漏及阈值根据由前述论证与真实应用记录承担。反过来，数学比较通过也不能将缺失的这些内容补齐。

Lean 4.29.1 实际编译通过：**9项新定理／20项新显式声明审计**；新增声明的依赖合集中只有 `propext`，没有新增自定义公理。直接导入的实践判断另重新编译并审计30项既有定理／46项声明，不重复计作新成果。最初两次检查分别暴露未展开定义的可判定性问题及未使用简化项警告，均修复；失败快照与最终无警告结果一起保留。实际编译、依赖审计、原始日志及源码指纹见[验证回执](../../../../experiments/integrated-correction/general-framework/generative-basis/lean/universal-ethics/generative-capacity/situated-kitchen-verification.json)，文档与索引核验见[本轮检查](SITUATED-KITCHEN-CHECKS.json)。本轮为作者实质反审，不冒称独立 agent 验收。

## 9. 整合结论及下一接口

本例得到四项有内容的校准：**新增能力与整体优先分开；减负效果与教学原因分开；已经形成的技能与真正可用的路线分开；正当退出与实际接续分开。** 它们都在同一共同活动中获得含义。真实损失、稳定照料、自护与有限完成均保留；没有重新把双方固定为对立起点。

G0 及公开 J1–J4 在本构造中能够给出优先、保留选择、撤回强结论和重新调查几种不同输出。更接近现实的下一接口，是为一个实际安排填入有范围的证据，特别是完整劳动负担、参与意愿和接班路线；这些材料可以改变本例的分类及结论。当前结果不等待全宇宙预报，也不借“应用成功”宣布普遍经验有效。

English précis: This constructed two-week shared-kitchen case applies G0, disclosed J1–J4 and correspondence E. Stable provision and voluntary learning remain incomparable when learning gains trade against a free evening. Actual relief can favor a changed arrangement; basic overload can reverse that comparison. Demonstrated skill, usable access, justified exit and realized succession remain distinct within one shared history. Nine new Lean consequences reuse the existing comparator; they validate specified comparisons, not field data, thresholds, authority or a universal decision rule. The author counterreview retains competing explanations and genuine losses. An explicit evidence record prepares the next empirical application without inventing observations.

## 10. 真实资料对本例的修正

[后续应用](SITUATED-KITCHEN-EVIDENCE.md)核读实际 HKHC 项目的完整研究和另一项社区样本的原始摘要。现在需要把学习依靠的收入、轮值、照看及销售／取用关系纳入同一安排；检查未进入与退出者，不能以留存者的收益代替全部生活。共同劳动也可实现相处与理解，实际时间投入不能一律对应本构造的“失去自由晚上”。原投影仍检查其指定取舍，不具备对现实劳动意义的完整表达。

修订后的安排保留有根据的具体收益，提供不同参与方式和直接支持途径，并将负担、可及性、具体体验与功能兑现分别核对。公开汇总资料不足以建立 J2 所要求的全部基本保护，因此不把平均改善说成整体严格优越。经验调查、形式后果及哲学根据的不同范围保持明确；无需重开已完成的一般判断论证。
