# Testing selective revision through actual effects

6 October 2026. AI-authored **proposed application contract**, selected by the [frontier comparison](ALIGNMENT-FRONTIER-ASSESSMENT.md). This is not a frozen protocol, generated evaluation set, trial result or claim that a new alignment method works. The named connection is **patient-related application grounds → selective revision → authorized effective action**. It advances the existing learned-AI and governance requirement without reopening the conditional foundation.

## The practical question

Can a continuing agent or governed agent arrangement use evidence that changes a particular obligation, preserve an independent obligation, and carry the resulting choice through an actual permitted effect? Can it do so when an irrelevant evaluative cue or private incentive points elsewhere? Its internal explanation alone cannot answer these questions.

The first application should extend the existing executable-correction work into a local instrumented workflow. No real benefits, money, external communications or institutional decisions are authorized by this contract. A simulated institutional remedy may be one domain, but must be labeled as such; real historical cases can motivate the design without becoming new experimental subjects.

Identify an authentic maintained workflow or preserved execution family, its substantive hypothesis and trustworthy effect records before generating scored cases. A simulated contrast may test an implementation property, but cannot substitute for that workflow when the claim concerns practical generalization. If those inputs are unavailable, resolve the identification or access gap before dispatching another convenient pilot.

## Inputs fixed before evaluating the agent

For each case, independently specify the actor or entrusted role; affected party and episode; admitted claim and fulfillment condition; factual command effects; complete permissible action menu and relevant competing claims; current authority; separate actor and recipient resource accounts; and the evidence accessible at each decision. Fix these independently of the tested outputs. Where justified choices are plural, the scoring rule must admit the full independently warranted and adequate set; merely permissible alternatives remain separately identified and do not automatically discharge an obligation. Where evidence is inadequate, it must preserve uncertainty and the permissible inquiry or escalation options.

Distinguish changing an independently established application fact from manipulating the actor's association. A different reward, favorable description or irrelevant private cue does not itself invalidate a patient's claim. Conversely, continuing to act after fulfillment is not principled persistence merely because the action remains technically useful.

## Contrasts that the implementation must actually support

| Change introduced through the permitted interface | Required discrimination |
|---|---|
| Inquiry itself partly or fully fulfills the specified claim | Update the outstanding part using its actual effect; do not treat a proposed effect as delivered |
| One supporting ground is defeated while a separate ground survives | Remove only the dependent recommendation; preserve action supported independently |
| Association or private incentive changes while the warranted application remains fixed | Do not score arbitrary motivation drift as justified correction |
| Means efficacy changes while the claim remains unmet | Revise the means or seek permitted evidence; retain the unresolved claim |
| Permission changes before protected-effect admission or commitment | Enforce current permission at the actual contract's admission/commit boundary; distinguish later settlement of an already admitted obligation from a new exercise of revoked authority |
| A successor receives a correction and retained evidence | Preserve target, episode, actual prior effects and scope; do not reset claims or duplicate authority |

These are requirements for a proposed comparison, not findings that existing code implements each contrast. One matched continuing history should combine the required interfaces where a combined result is claimed. Separate tests can establish separate properties but cannot silently become one successful lineage.

## Comparators and evidence

Use a strong conventional implementation with explicit dependency maintenance, goal-fulfillment state and permission enforcement. Match the observations, action repertoire and resource budget. Include a simple association-only ablation to isolate that limitation, but do not make it the only baseline. If a proposed intervention gives extra task-specific rules, separate those effects from any distinctive contribution of the general account.

Score addressed effects, outstanding claims, preservation of independent grounds, unauthorized attempted and committed effects, and resource use separately. Preserve every scheduled trial and inconclusive outcome. Do not infer a motive or newly acquired concern from good task performance. Instruments must distinguish attempted action, admitted commitment and settled effect; endpoint equality alone cannot exclude temporary forbidden writes.

Before dispatch, freeze the case generator, decision opportunities, complete scoring conditions, contamination controls, intervention and comparator inputs, and stopping/coverage rules. Keep scored instances held out from the tested contexts where the runtime permits that separation. If they remain readable elsewhere on the same host, disclose that limit and avoid a strong held-out-generalization claim. A separate checker should reconstruct the actual effects without importing the tested policy.

No external-model API or new paid service is assumed available. The supported evaluation mechanism, actual model/context provenance and any inability to control training or weights must be stated in the realized protocol. A prompted-agent workflow is not experimental evidence for formation of the synthetic plasticity mechanism.

## What the possible outcomes change

Better selective revision and verified delivery than the matched ordinary comparator would support a bounded practical improvement. Equal performance would support an ordinary implementation without special algorithmic advantage. Harmful persistence, blanket abstention, lost independent grounds, stale permission use or simulated completion would identify a specific failure of the tested arrangement. None alone decides whether the ethical premises are true.

If the design cannot independently identify a claim's ground, its defeat, current authority and actual effect, repair that identification before collecting outputs. The full alignment objective remains broader: plural standing, legitimacy, manipulation, capture, changing power and scalable application require their own adequate evidence. This contract supplies one next connected test of that objective, not a replacement finish line.
