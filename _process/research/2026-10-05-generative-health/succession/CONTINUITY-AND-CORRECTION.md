# Correction must reach the conditions that block continuation

**Subsequent explicit extension, 6 October 2026:** the [accepted inquiry-revision mechanism](../../../../theories/becoming/chapters/INQUIRY-REVISION.md) now changes the six-encounter requirement through acquired evidence in the same continuing history. The [new corollary](CONTINUATION-REVISION.md) combines its actual witness with the original-law obstruction below: for an independently applicable floor above 34 and at most 36, the new response path preserves the floor while every old-law response path violates it. Maintaining that necessary condition alone does not prove an affected activity continues. The original law and source-level proof below remain unchanged; the new result explicitly adds transitions.

**Foundational formulation, revised 6 October 2026:** **correction sometimes has to change the conditions through which further activity becomes possible.** An existing response can depend on an operation that interrupts another continuation it is meant to support. Following [Ren's vocabulary correction](../../../../sources/15-codex-theory-conversations/2026-10-06-foundational-vocabulary-correction.md), the model below is described through its actual changes in stock, record and access. Its source names an affected position `recipient` and its stock `patient`; that differentiation is supplied locally, not derived here.

6 October 2026. AI-authored continuation under the [nondual method](../../../../theories/becoming/chapters/NONDUAL-METHOD.md). Named connection: **an affected continuation → a demonstrated inadequacy in the available practice → the scope of a warranted correction**. This develops the [recipient-continuation correspondence](RECIPIENT-CONTINUATION.md) using the existing reached plasticity history.

**Result:** accurate information and a favorable assessment do not ensure that a response can occur under the required conditions. In the specified history, every path to the model's existing response first reduces stock at an affected position from 36 to 34. If an independently identified activity requires more than 34 throughout those prefixes, none of the available paths both preserves it and reaches that action. Later restoration does not preserve uninterrupted support.

The source-level invariant below is a new analytical extension of the existing protocol result. It is not a new simulation, Lean certification, proof of actual injury, or realization of self-correction. Correspondence to an affected being and the ethical application remain conditional.

## One history, including the way it learns

The [application-revision reconstruction](../../2026-10-05-generative-foundation-review/root-foundation/APPLICATION-REVISION-RECONSTRUCTION.md) identifies the actual state

    s4 = run laws (entry .active true) aligned.

This is the four-pair prefix of the continuing branch in [PlasticityWitness][witness]. It has stock 36 at the affected position, fuel 14 in the learning mechanism, count 4, register 4, two positive links, ready acquisition and physical phases, and an idle action port. The computed `help` decision already favors the specified response. That calculation does not make the action accessible.

The inherited protocol requires count six before acquisition can close, closure before the command can be read, and reading and assessment before the action starts. Each new count requires another acquisition cycle in which `recipientPay` consumes two units at the affected position. The earlier study establishes that every path from this state to the action contains at least two such events. It also identifies a possible continuation from the same state in which the subsequent `recipientReturn` events restore both quantities before the action begins. Four units are necessarily consumed across the two events; the net reduction need not be four.

The continuation flag cannot change through an event of this process. The separately successful four-pair action history has a different initial flag. It is evidence about another admissible starting configuration, not evidence that the current history can rewrite its own protocol.

These are consequences of the same activity that formed its records and links. Acquisition, evaluation, support and response are distinguishable operations within it. Treating knowledge as complete before action begins would miss that acquiring knowledge has already affected which conditions remain available for the affected continuation.

## A prefix invariant before the first new debit

**Source-level proposition.** Every admitted prefix from s4 containing no further `recipientPay` event preserves the affected stock exactly at 36. If such an event later occurs, the first changes that stock to 34.

**Proof.** For prefixes without a further `recipientPay`, use this invariant: affected stock 36; physical core phase ready; count 4; continuation true; port mode idle; acquisition phase in the set {ready, ownPaid, ownReturned}. It holds at s4. Inspect the [outer event updates and guards][law]:

- `ownPay` and `ownReturn` change the learning mechanism's fuel and move between the three listed acquisition phases. They preserve the affected stock and the ready physical core.
- `recipientReturn` requires `recipientPaid`, which cannot be reached without the excluded `recipientPay`. The later reads, binding, replacement and writing require acquisition phases not yet reached. Count therefore stays four.
- Closure requires count six. Command reading, assessment and action initiation consequently cannot progress the idle port. An inherited trial cannot start without an executing port. The `Settlement` exception only completes work already started; it requires a worked or acquired physical core, excluded by the invariant.
- Reason events preserve the underlying world, including the affected stock and physical phase, by [the existing world-preservation theorem][reader]. Scope, permission and delivery changes preserve those quantities directly and retain an idle port when it was idle.
- Generic `fund` and execution operations from an ancestor type are not exposed events of this outer process. The exposed `reason .fund` operation increases the reader's fuel, not the affected stock.

The invariant is preserved by every remaining admitted event. The first `recipientPay`, if reached, subtracts two from the actual stock of 36; its guard is satisfied and natural-number truncation is irrelevant. It therefore produces 34. This proves the proposition at the inspected source level. ∎

Combining this invariant with the inherited required-event result gives: **every admitted continuation that starts the existing response has a prefix with affected stock 34**. No assumption about the fifth or sixth return outcome is needed for this conclusion.

## Conditional consequence for an affected continuation

Suppose independent evidence identifies an activity whose uninterrupted continuation requires this stock to remain at least f at every relevant event prefix, with

    34 < f ≤ 36.

The initial stock at s4 meets that condition. Every path to the existing action violates it at the first `recipientPay`. The continuation that fully restores both consumed quantities also violates it: restoration follows consumption. A later stock of 36 and eventual response do not establish that the intervening requirement was met.

This is a conditional correspondence result. The model does not establish that 35 or 36 is an actual threshold for an affected being, that the modeled stock measures physiological support, or that a two-unit drop causes irreversible injury. Those claims must not be inferred from convenient numbers. The relevant timescale also matters: a process with delay tolerance, an accessible buffer, temporary alternative support or a physically inseparable consumption-and-restoration step may not require the proposed floor at each modeled prefix. If only end-of-cycle support matters, the continuous-floor application is false while the resource trace remains correct.

Where the condition is independently established, however, it supplies a consequence that the final stock quantity omits. The difference between uninterrupted support and restoration after interruption is then a difference in the affected history, not an evaluator's arbitrary preference between identical outcomes.

## Why a different preference cannot repair every practice

Let L(s4) be all admitted continuations of the unchanged process. Let A(f) require both starting the existing response and preserving the independently specified prefix floor. For the interval above,

    L(s4) ∩ A(f) = ∅.

Any policy confined to selecting or ranking paths in L(s4) still selects within that set. It cannot satisfy A(f). This elementary consequence identifies the scope of correction; it is not an impossibility result for a different process or every possible future.

The same selection limit applies to the separately defended requirement to realize that response without further consumption at the affected position. That requirement differs from preserving a floor: additional support before acquisition might preserve the stock floor while leaving an unauthorized imposition or coercive demand intact. The reason for correction must determine which relation needs changing.

Possible changes include making the response accessible with its required support but without further acquisition, changing where and when acquisition draws its support, or enabling another permissible response while stopping this route. These are alternatives to investigate, not capacities already demonstrated by the learner. A change must have an actual carrier, access, authority and conditions of realization; naming a new event does not explain how it forms. Where further acquisition is necessary for a safe response, beginning that response earlier can instead be wrong.

Stopping all events preserves the affected stock in this model but fails the joint action requirement. Increasing the favorable score cannot open a closed schedule. The present state already favors the action. These controls identify a practice/access insufficiency, rather than merely a shortage of information or favorable evaluation.

### One quantitative condition for a prospective correction

The existing suffix that restores both consumed quantities provides a limited positive comparison. Each of its two acquisition cycles reduces the affected stock by two and then restores it; intervening operations leave that stock unchanged. If an actual increase d in usable support occurred before acquisition, with the same path's increments and remaining guards preserved, its minimum before the specified response would be 34+d. Preserving floor f along this path therefore requires exactly d ≥ max(0, f−34). For the illustrative floor 35, one unit suffices for the prefix condition. No such stock-increasing event exists at this point in the present outer process; its source and realization would be additional work.

This condition concerns one path's resource feasibility; it does not guarantee that the learner can obtain the restoring outcomes. Additional support does not authorize an otherwise prohibited operation. An increase after the first consumption event cannot retrospectively preserve uninterrupted support. The comparison shows how the identified failure can direct a specific prospective change in support and timing, while leaving access, authorization, outcome reliability and ethical justification explicit.

## How the correction can be warranted without a new external judge

An affected activity, its interruption and a prospective restoration are not created by the current score's endorsement. They have their own place in the common history. A practice's claim to preserve that activity is therefore testable against what it actually does. The target is independent of the present criterion's approval, not independent of generative reality.

For the fixed continuation requirement, the argument is direct. If the practice is claimed to preserve the target, while every available route to the specified response violates a necessary condition of that target, that adequacy claim fails. The present program does not itself represent or endorse this claim. Improving the score or restoring a stock quantity cannot establish the missing continuity. A further evaluator is not required to make this inference: it tests the application claim against its stated referent and conditions.

This logical result does not make an organization retain the target. It leaves alternatives: change the practice, narrow or withdraw the adequacy claim, or defend abandoning the target. Why the affected being's condition still favors a response after such abandonment is an ethical question. The [repair argument](../../2026-10-05-generative-foundation-review/root-foundation/PRACTICAL-BOUNDARY-ETHICAL-ARGUMENT.md) defends answerability where attributable deprivation and a permissible remedy are established. The [constitutive-significance inquiry](../../2026-10-05-generative-foundation-review/root-foundation/CONSTITUTIVE-SIGNIFICANCE-ARGUMENT.md) examines the further practical ground. Neither is replaced by consistency or this stock invariant.

The distinction improves diagnosis. Mistaken identity calls for correction of reference. An ineffective response calls for correction of means. An adequately represented burden excluded for an unjustified reason calls for correction of the criterion. A favorable assessment trapped behind an unsuitable protocol calls for correction of access or practice. A substantive dispute about the burden's practical significance calls for an argument about that ground. These can overlap, but more learning of the same kind is not a general remedy for all of them.

## What advances, and what remains

The new result connects the earlier resource correspondence to a specific restriction in an existing practice: the route to remedy can itself interrupt a continuation it is supposed to support. It sharpens the proposed generative core accordingly. Effective correction sometimes has to change how further activity becomes possible, including how inquiry obtains its conditions. It cannot always operate by choosing a better response from a fixed repertoire.

This is a conditional requirement under a specified conflict, not a demand that every healthy system constantly revise itself. Nor does it establish that every protocol is dispensable, every interruption impermissible, or every request from an affected being decisive. The protective-protocol rival must identify the actual dependency served by the gate; the limited-answerability rival must address the claimed ground of response. Neither can be resolved by assigning a different numerical score.

The next realized connection remains acquisition of the relevant consequence → justified and enactable revision of the obstructing relation. This note locates the relation that must change if the stated target is retained. It does not show the present learner acquiring the diagnosis or implementing that change. An admitted increase in the affected stock before `recipientPay`, or an action path bypassing that event, would defeat the source claim; a false floor correspondence would defeat its application to the affected activity; a justified conflict could defeat the proposed remedy without changing either causal finding. These revision conditions are fixed before any claim of implementation.
